# Daily Research Report

Write a compact daily report. Do not turn the day into a task log.

## Required Output

```markdown
# Daily Research Report - MMDD

## Today's Goal

## What I Did

## Key Results

## Interpretation

## Problems / Blockers

## Tomorrow's Plan

## Questions For Advisor
```

## Rules

- Read `CURRENT.md` and `mainline.md` first when available.
- Say whether the day updates the mainline.
- Separate result, interpretation, claim, and speculation.
- Keep advisor questions concrete.
