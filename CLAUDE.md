# Claude Code Compatibility

The imported `AGENTS.md` is mandatory repository policy.

Repository Skills are exposed under `.claude/skills/` from their canonical
source in `.agents/skills/`. Select the smallest primary task owner through
`docs/skills.md`, read its `SKILL.md`, and follow its reference routing. Add
another Skill only for a distinct necessary subtask; matching several descriptions
does not require a chain of all matching Skills. Reuse unchanged instructions
already read. User instructions take precedence.
