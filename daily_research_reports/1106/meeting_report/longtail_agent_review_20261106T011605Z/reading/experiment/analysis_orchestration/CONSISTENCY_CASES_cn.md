# 正确性、一致性与完整案例

独立工具export_consistency_cases.py不改冻结stats v2、评分规则或核心编排文件。实际结果由root最后分析时才调用；目前只用假数据测试。

逐事实保存原问/两改写的T/F/U正确模式，以及两heldout、三问的year答案一致性。多年份、缺失、年代或带不确定限定时一致性为Unknown。同一个错误年份可以高度一致，不能叫知识正确。提取year与标准答案另比；若与既有评分冲突则单标复核，不自动改分。

主表按事实/运行/教师来源/阶段/1或8配额报告；问法不增加分母。缺失和未决保留。标准答案只取可核验原数据，不用模型输出作真值。

完整案例可按显式ID导出，或按预定三类选择：目标答对而基线明确未成功、目标明确失败、同错一致或丢失基线已有成功。各类用固定hash排序取少量，记录所有候选数；缺某类就如实没有，不补造。多类别同运行/事实只写一次。案例不能代替总体比例，也不改变主统计。

案例保留原文、来源文件/记录ID/字节offset/答案跨度（原数据有的全部保留）、标准答案、三问，以及同seed下所有映射实验臂和阶段的原始输出/解析/评分。一并显示缺失和一致性字段。展示给读者的原文不意味着闭卷生成时模型读过它。主数据和诊断子集分开运行，不能把重叠事实合并计数。

4项CPU合成测试通过，覆盖同错但一致、歧义/缺失、评分冲突只标记不改分，以及完整offset/各臂原始输出导出。实际输出现在没有读取。
