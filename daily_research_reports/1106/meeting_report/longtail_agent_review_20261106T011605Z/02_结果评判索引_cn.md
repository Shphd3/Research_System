# 原计划的结果评判依据

整理既有比较，不添加事后通过阈值。

| 问题 | 比较 | 判断边界 |
|---|---|---|
| 模块是否学会可提取的事实 | memory_kl对none，独立生成 | 金标准前缀下NLL下降不等于闭卷会答。 |
| KV是否优于同参数 | memory_kl对CE+KL adapter | adapter关门或未学会限制结构解释。 |
| 教师分布的贡献 | memory_kl对memory_ce | 同事实、曝光、更新；教师闭卷和读原文分层。 |
| head64约束是否特殊 | head对KL/random为主，对L2为次 | 联看门控、增量、有效BF16增量及头谱能量；一般收缩是竞争解释。 |
| 学B能否保留A | 同臂同seed A afterB对afterA，同时看B习得 | 不学B的表面保持不算有用抗遗忘；A后零成功时条件保持无定义。 |
| 原有能力代价 | 128段独立文本NLL及128零曝光参照 | 有限保持检查，不等同全面通用能力。 |
| 回答是否依赖模块 | 固定64A+64B+64参照的开/关/单侧错配K/V | 正确性和一致性不同；同时排列K/V函数不变。 |

主指标按事实计算两未见模板均正确；原问、NLL、一致性分开。来源家族配对bootstrap5000次，seed分开；区间跨0代表证据不足，不证明无效。未做多重比较校正。未知、异常、失败和真实分母保留。

先核覆盖、匹配、曝光、A/B父检查点及恢复。MATCHING_NOT_VERIFIED只能描述数值。最大规模pre/A/B主要使用H100对应输出。出生年单关系、模板改写、读原文教师、人审0条、仅2seed及训练时已知答案前缀限制外推。小奇异值没有被证明等于自然长尾。
