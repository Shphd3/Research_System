**五、实现首版末层记忆**

冻结 Qwen3-0.6B Base 主干和原输出头；在最后一个 Transformer block 输出之后、最终归一化之前增加记忆旁路。设学生隐藏宽度为 d，以实际配置为准；设 N 个记忆槽、键宽 r：

- Key：N × r，可训练；
- Value：N × d，可训练；
- 查询映射：r × d，可训练；
- 记忆输出映射及门控：可训练。

当前学生末层 h 产生查询，与 Key 计算分数，经 softmax 得到读取权重，对 Value 加权形成 m；经线性映射和 sigmoid 门控，得到记忆增量 Δh，再计算 h + Δh，通过原模型归一化和输出头预测答案。

Value 是用于改变隐藏状态的表征，不是直接输出答案；不对 Value 强行套 ReLU。初始化使初始增量较小，同时验证所有预期训练参数能获得有效梯度，避免零初始化组合造成死梯度。

训练时只在答案 token 上计算任务损失。4B 可读经过核验的资料，学生只看问题；比较在相同规范答案前缀下的学生和教师分布。按实际 tokenizer／词表／特殊 token 对齐，不能仅凭大小相同就直接算 KL。

基础目标为：答案交叉熵 + 可调权重的教师分布 KL。确认训练过程中没有把目标答案或教师未来 token 泄漏到学生输入；回答时不提供教师或文档。

**六、实现并验证谱偏置**

在独立参考自然文本上、用冻结学生在**实际记忆注入位置**收集隐藏表征，组成矩阵，记录采样、token 位置、长度和中心化方式；通过 SVD／PCA 得到并冻结参考谱基。不要把已训练后发生漂移的基或最终确认答案混进参考。检查样本规模、有效秩和不同参考子样本下的稳定性；参考不足时停止谱因果解释，保留无谱基线。

首版以开发侧预先选定的头部维度为例（可从 64 开始），将记忆增量 Δh 投影到该头部子空间，加入适度惩罚：

总损失 = 答案 CE + λ_KL × 教师 KL + λ_spectrum × 头部投影能量。

归一化方式和权重由 DEV 确定后冻结。谱损失只表达“少改头部”的软偏好，不硬性抹掉头部贡献。务必同时记录 Δh 总范数、头部／非头部能量、门控分布及答案效果，排查把记忆输出缩到零的退化解。

对照中包含相同维数、固定种子的随机子空间惩罚，检查收益是否只来自一般正则化；若实验资源允许，增加其他预先定义的谱段敏感性分析。小奇异值是参考激活的统计方向，不能直接标为低频知识或语义标签。

2. **常见与少见知识**：只有在独立参考频率可靠时才按频率代理分组；报告题型、长度和实体差异，不能把代理频率误作预训练曝光。
3. **持续学习与旧知识保持**：在可控小规模任务中先学 A，再学 B，固定评测 A 的训练后与继续训练后的差异，也测 B 是否学会。记录是否只更新记忆参数；这不是无需梯度的一次写入。
4. **通用能力保持**：在未参与训练的通用问答或语言建模样本上报告 loss、正确率等；主干冻结不等于输出一定不受影响。
5. **教师可靠性与证据来源**：分别报告教师闭卷、教师给原文的正确性，以及学生使用不同监督的结果。
6. **模块机制诊断**：报告门控、各谱段增量、记忆关闭后的变化以及随机谱对照。不要仅凭谱能量或 feature 激活就宣称因果解释成立。

测试训练事实的新问法是否学会，和完全未训练事实是否泛化，要分开报告。零曝光事实答错不能自动认定为方法失败；不同事实的频率、难度和来源混杂要如实分析。

**九、自主执行与停止条件**

请按“资产／任务检查 → 开发与冻结 → 小规模冒烟 → 完整训练对照 → 评估与复核 → 报告”的顺序推进。小规模冒烟通过后，自动继续；训练中遇到可恢复错误，保留日志并自行修复、从可信 checkpoint 恢复，避免中途要求用户处理日常事项。

但如果出现下列情况，请停止受影响的步骤并报告：无法安全获取预留资源；无可核验事实或关键数据泄漏；训练梯度／恢复检查失败且无法修复；缺少必要权限；或继续运行会覆盖已有工作。不得为了“不中途停止”跳过安全与数据质量检查。无需为每个一般超参数调整询问用户，但必须把调整和依据写入日志，并保证确认集边界。

**十、最终交付**

提供：

- 模型、资源、数据来源、长尾／低曝光定义和样本筛选；
- 每个实验臂的训练条件、可训练参数量和实际成本；
- 逐事实数据、训练输出、checkpoint、可复现代码和日志；
- 低曝光学习、教师优势、通用保持、持续学习的各自结果及不确定性；
- 谱偏置、随机谱对照、门控和增量能量结果；
- 与会议 intuition 的对照：哪些得到支持、哪些仍是猜测、哪些结果相反；
- 失败、缩减、缺失与下一步，不得将结果写得比证据更强。
