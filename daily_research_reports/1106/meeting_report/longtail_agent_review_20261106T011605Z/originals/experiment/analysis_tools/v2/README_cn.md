# 事实级统计接口（资格审计修订v2）

代码已按用户合同、DEV工程计划和现有评测脚本字段实现。只跑过CPU合成数据，未读取实际模型结果，不作架构判断。正式入口为 `analysis_tools/v2/aggregate_facts.py --manifest 映射.json --out 新统计目录`；NumPy是唯一额外依赖。

主指标是**同一事实两个固定未见问法均正确**，训练原问法为次指标。按逐rank原始预测重建True/False/Unknown，fact_scores只用于一致性核查。只有一问正确、另一问缺失不能算成功；任一问明确错误则合取事件明确失败。按冻结的数据名单给分母，问题条数不充当事实数。未决/缺失保留，保守点估计计为非成功，同时给全部未决可为0或1的上下界；格式状态和原始评分理由单列。

每个seed、教师来源、cohort、规模、检查点阶段、事实A/B与1/8配额分别统计。计划配额与checkpoint里实际提交曝光分开：A后B尚未训练，实际曝光0；冻结none一直实际曝光0，共享配额只为配对分层。sentinel零曝光事实和通用语言模型NLL单列，不把未供给事实当作学习失败。

默认比较：各臂减none；head减KL/random/adapter/可用L2；KL减CE。事实来源家族成簇配对bootstrap默认5,000次，基础seed11050031，子seed按比较/分层/指标确定并记录。抽到家族时带上全部事实，分母按事实数，不平均家族均值。准确率差正值为改善，NLL差正值为变差。分别给保守未决=0的区间和未决最坏情况区间。各训练seed不合并；事实bootstrap不代表训练seed波动。单一家族的退化区间明确标记。

A→B同时报告全A变化，以及只在“A后明确已学会事实”上的保持率。两者分母不同。保留已知遗忘、未决和实际A曝光是否改变，检查同臂/同seed/阶段及继续训练历史。

NLL按总自然对数损失除以实际有效预测token数，不能平均段落或rank均值。缺任何应有NLL记录时，完整名单均值不可用；仅观察记录的均值明确标注，不能冒充全部结果。没有缓存评测输入时记NOT_RUN。

输出结构化CSV/JSON、逐事实表和三份审计：覆盖与评分、配对与曝光/来源、统计区间与解释。重复rank事实/问法、额外事实、源家族不符、记录的问题不符及checkpoint哈希不符会报错。配额、顺序、配置、实际曝光或继续训练证据不足会保留数字并标MATCHING_NOT_VERIFIED，不能据此宣称干净的方法收益。

示例映射里的路径都是占位符；没有暗称正式结果已存在。代码不会加载权重、改评分、筛选成功案例或覆盖旧统计目录。区间未做多重比较校正，也不自动决定科学结论。出生年单关系、自动模板、未人审来源和受控曝光的边界保持不变。

同一seed内1次与8次分层包含不同分配的事实。本工具只在同一配额内对实验臂做事实配对，不把1次和8次的直接差异冒充同事实配对。


v1根目录文件和哈希不变。v2只加强比较资格，不改主指标、分母、bootstrap或数值估计。新增条件化objective_contract：CE的KL为0，其他训练臂KL为0.5；head/random共用正式冻结的谱惩罚系数；L2按head_dim/d_model缩放，当前64/1024为0.0625。其余臂有效谱惩罚为0，不要求无作用的原始CLI系数也写0。没有正式head系数时明确未验证，不把默认0.1当正式选择。

所有训练臂（包括adapter）都比module_config、initial_delta_ratio、spectrum_sha256、head_dim及已有优化配置。实际可训练参数数需对应运行的initialization.json等收据，不能只相信映射裸数字；文件需位于checkpoint对应运行目录，并核对模块维度和参数预算。

A→B必须提供真实launch_receipt、实际argv中的--continue-from、启动时父checkpoint路径/哈希、当前父文件字节、映射声明的父哈希、已评测A的manifest哈希；还核对B的--out/--arm/--phase与被评测B checkpoint目录。phase_history含A只是辅助，缺真实哈希桥一律MATCHING_NOT_VERIFIED，数值仍保留。没有反序列化权重；只哈希checkpoint字节。优化器/RNG完整恢复资格仍由训练审计负责。

CPU合成反例包括：模块/初始化尺度/谱基/头维度/参数数不匹配，CE/KL与head/random/L2预定差异，只有phase_history却缺真实启动收据、错误父路径/哈希/当前文件和B输出目录。另验证v1/v2在同一合成输入上的数值估计与区间完全一致。修订过程没有读实际模型结果。
