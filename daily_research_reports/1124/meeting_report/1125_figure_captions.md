# Figure captions

**Figure 1. Cross-domain coverage, feature activity and projected variance in frozen Qwen3.5 base models.** (a,b) Fraction of held-out quantum-mechanics (QM) hidden-state energy captured by the leading 16 QM or abstract-algebra directions, before and after removing the decoded contributions of root and parent features (“upper”). Groups were defined from positive sparse autoencoder (SAE) activations using four external domain labels. Each condition used its own build-set means and bases (512 documents per domain). Points summarize four positions in each of 32 QM test documents. Bars give 95% document-bootstrap intervals (500 draws). (c) Mean number of positive SAE activations per token assigned to each group, across 8,167 test tokens in 128 documents. The 2B and 9B SAEs each select 50 features per token. The remaining activations averaged 36.47 and 37.85 per token, respectively. Bars give 95% intervals from 2,000 within-domain document-bootstrap draws. (d) Left, variance from measured decoder directions relative to the independent isotropic prediction, holding coefficient variances fixed. Right, variance including coefficient covariances relative to the diagonal approximation using the same measured directions. Each small point represents a selected feature–domain pair (2B, 49 pairs; 9B, 45). Open markers indicate medians and thick lines the interquartile range. The dotted reference at one denotes equality. Layers 11 and 15 were measured for the 2B and 9B models, respectively.

**Figure 2. Sensitivity to wording and answer choice for a quantum operator in two representations.** Thirty-two held-out document backgrounds were crossed with two test phrasings, two representations (position or momentum), and two operators (`x` or `p`), yielding 256 answer-free prefixes per model. Each condition had one correct continuation, *multiplication* or *differentiation*. “Upper” removes root and parent features. “Other leaves” removes features assigned to the three non-QM domains. (a) Percentage reduction in the root-mean-square projection difference between phrasings relative to random removal. The projection axis was fixed using the two answer means from 32 separate build backgrounds and two separate build phrasings. Positive values indicate less variation across phrasings. Both members of a wording pair had to match the random control in number of removed active features and in squared removal norm (within 10%, including exact zero matches). (b) Accuracy from the frozen model’s two next-token scores on all test prefixes after editing the final prefix position. Random controls correspond to their respective removal conditions. Ties receive half credit. The dashed reference marks chance (50%). Error bars are 95% percentile intervals from 2,000 paired bootstrap draws over background documents with the templates held fixed.
