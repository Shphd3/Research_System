# SAE表征空间分析计划：第二版资料包

首先阅读 `0920_SAE_表征空间分析计划_v2_CKA与数据构造.md`。本版依据用户提供的15B/21B下游评估，修订模型轨迹、优先级、数据质量要求和CKA流程。

## 文件用途

| 文件 | 用途与边界 |
|---|---|
| 主计划Markdown | 范围、模型谱系、CKA解释、数据构造、提取契约、判定树、能力判断 |
| `config.yaml` | 与主文档附录B相同的配置；`null`须由本地核验，不能自动猜测 |

| `cka_self_test.json` | 本次真实执行的合成数值单元检查结果，不是语言模型实验 |
| `build_p_rel.py` | 原样保留上一版受控关系面板生成器；本版做语法检查，未重新生成正式数据 |
| `pool_attention.py` | 原样保留上一版均值/末位汇聚函数；本次通过合成张量检查，不证明实际取点正确 |
| `verification_status.json` | 已完成与未执行事项、环境及文件校验和 |

## 本地先做什么

进入真实项目后先读 `AGENTS.md` 并遵循项目授权。按主文档第9节完成模型清单、数据审核和取点验收；不要先批量跑模型。该文件当前未提供，资料包不包含猜造的仓库路径或执行权限。

CKA检查仅需Python 3.10及以上与NumPy。在已有相应环境中：

```bash
python cka_reference.py --self-test
python cka_reference.py dense_L4_mean.npz sall_L4_mean.npz --out cka_pair.json
```

每个NPZ含 `features` 和唯一字符串数组 `sample_ids`。双方ID集合必须一致。正文哈希、模型取点、数据版本及来源独立性由上游清单验收，本程序不能仅凭ID验证它们。

`pool_attention.py`需要PyTorch。禁止把函数接在最终隐藏状态上，却将产物称为原始注意力输出。

`build_p_rel.py`会创建数据文件；获得相应本地授权后，使用一个**新的、空的输出目录**：

```bash
python build_p_rel.py --output data/P_rel_v1
```

生成结果还缺人工模板审查、实际分词器检查与数据冻结，不能直接称为已验收数据。本生成器尚未实现本版增加的同后缀、实体自然化诊断，它们须按计划另行实现并独立命名。

本资料包不含完整模型提取器、公开数据清洗流水线或真实模型结果；主文档明确给出了执行代理应实现的接口、参数和验收条件。它也不授权自动重训或覆盖已有数据。
