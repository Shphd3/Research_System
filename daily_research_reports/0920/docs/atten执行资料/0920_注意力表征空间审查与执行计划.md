**版本：v1.0；日期：2026-09-20。**  
**本轮对象：已有检查点中的原始注意力输出；不重新进行大规模预训练，不搜索稀疏预算。**  
**会话依据：**附件《explanation · 0916-forward-0914-模型分析与研究计划.md》；文中的行号均指该原始文件，不是本计划的行号。

> 核心问题：稀疏自编码器（SAE）旁支正则，是否改变了主干实际产生的注意力输出；这种改变能否使我们指定的语义因素在换措辞、换实体后仍容易识别，而不只是使重构结果的几何图形更整齐？

本文用“会话已定”“文献证据”“本次规定”区分来源。数据配额、控制实验和阈值中未注明已有者，均为本次提出的执行规定，不是已经完成的模型实验。

## 0. 先固定三个决定

**取点：第4、8层注意力输出投影之后、残差相加之前的向量。** 人类层号为4、8，通常对应代码索引3、7。不能用末层隐藏状态、归一化输出或注意力权重代替。

**汇聚：按问题分工，但每条输入同时保存均值和末位两种结果。** 受控关系短句以最后一个有效正文词元的向量为主；自然文本领域与自然句子相似性以正文词元均值为主。两种汇聚使用完全相同的输入和取点；另一种必须作为敏感性检查报告，不依据哪种更有利于正则模型来选结果。

**缓存：不把历史键值向量拼进主审查向量。** 注意力输出已经是当前查询读取历史键值后的结果。但它不等于全部历史记忆，也不等于整个模型状态。主实验保留完整的因果上下文；只有定位“历史信息存在哪里、为什么未被读出”时，才增加键值分析。

**当前最小执行顺序：取点验收 → 旧结果复现 → 10B的Dense/SALL原始输出比较 → 语义反例与自然数据确认 → SAE特征分析 → 扩展S7/S37和训练轨迹。**

### 1.2 两项必须修正的旧口径

**第一，旧图的取点并不就是原始注意力输出。** 会话明确指出，已展示的一组图取的是“末层Norm2之后、前馈网络之前”。该位置混入了残差并经过归一化。旧图应作为旧口径复现，不改标签，不把它们重新命名为注意力输出证据。没有原始逐词元缓存时，必须重新前向提取，不能从旧均值向量可靠恢复新取点。来源：会话第631—639行。

**第二，“表征变好”不以所有指标同时变大为定义。** 本轮主要检查：指定语义因素在未见措辞、未见实体上的读出是否改善。类间/类内比值、聚类和低维图属于解释证据；它们不能替代这个检查。反过来，分类器不变也不能推出整个表征空间没有变化。

### 1.3 预先声明的竞争解释

| 可能解释 | 需要的判别证据 |
|---|---|
| 主干产生了更容易读出的语义因素 | 原始注意力输出在独立确认集上改善 |
| 只是SAE提供了更合适的非线性读法 | 原始输出接近，编码或重构更容易读出 |
| 只是压低某些波动 | 类内散度下降，但跨表达读出或语义反例没有改善 |
| 只是更容易识别词汇、长度或模板 | 同分布优势存在，跨模板/实体优势消失，或简单干扰因素基线足以解释 |
| 变化局限于某些位置 | 末位、均值、逐词元结果不同；按位置分层后可定位 |
| 当前数据太容易或太难 | 基线接近满分或随机水平，缺少检测方法差异的分辨率 |

## 2. 表征位置：把“在哪里取”和“怎样汇聚”彻底分开

### 2.1 唯一主取点

用列向量约定，定义第\(\ell\)层、第\(t\)个位置的注意力写入量：

\[
a_{\ell,t}=W_{O,\ell}\operatorname{concat}_{h}
\left(\sum_{j\le t}\alpha^{(h)}_{\ell,tj}v^{(h)}_{\ell,j}\right)+b_{O,\ell}.
\]

这里，\(\alpha\)是当前查询对各历史位置的注意力权重；\(v\)是被读取的值向量；\(W_O\)把多头结果映射回主干维度；无偏置的模型令\(b_O=0\)。接着主干做：

\[
s_{\ell,t}=r_{\ell-1,t}+a_{\ell,t}.
\]

**本轮主审查的是\(a_{4,t},a_{8,t}\)，不是\(s_{\ell,t}\)。** 注意力头拼接后的投影前向量记为\(u_{\ell,t}\)，避免与SAE编码\(z_{\ell,t}\)混名。

这是会话第177—203行已定位置。公开Llama代码也展示了“输出投影→注意力返回→残差相加→后续归一化/前馈”的区分，但它只是参考实现，不能替代对你们8层模型源码的核实。[R3]

### 2.2 文献审查发现的取点差异

《Interpreting Attention Layer Outputs with Sparse Autoencoders》确实研究注意力的稀疏分解，但其方法部分明确使用**各头加权值拼接后、输出投影之前**的\(u\)，而不是本文的\(a=W_Ou+b_O\)。因此，这篇工作支持“注意力计算可被分解研究”，不能直接证明你们这个投影后位置的正则效果，也不能直接借用其字典。[R4]

数学上，即使\(W_O\)可逆，一般线性变换也不保持欧氏距离、夹角与协方差频谱；不可逆时还可能丢失信息。因此两个位置的几何量不能混报。这是数学推论，不是该论文已经验证你们方案的结论。

### 2.3 保留四类对象，但禁止相互替代

| 缓存名 | 定义 | 能回答的问题 |
|---|---|---|
| `attn_write_raw` | 原始\(a\) | 主干实际产生的表示是否改变？ |
| `sae_reconstruction` | \(\hat a=Dz+b\)，还原至原始单位 | SAE保留了哪些几何或标签信息？ |
| `sae_code` | 逐词元稀疏编码\(z\) | 什么因素由哪些特征/特征组响应？ |
| `sae_error` | \(e=a-\hat a\) | 被重构遗漏的分量还含什么可读信息？ |

另存`legacy_norm2_pre_ffn`只复现旧实验。比较局部变化是否传递时，可在**小诊断集**增加`residual_pre`、`residual_post_attn`及整层输出，但不得把它们并入主取点。

### 2.4 开始批量提取前，六项验收必须通过

执行代理先生成`site_contract.json`与`site_checks.json`，保存每个模型的模块全名、源码文件/行号、代码版本、张量形状、输出投影名称、SAE实际输入预处理、残差加法位置、并行汇合位置。

| 检查 | 操作 | 通过标准 |
|---|---|---|
| 模块与形状 | 同时记录投影输出、SAE输入、残差加法前后值 | 主张量为`[batch, sequence, hidden]`，不是注意力权重的四维矩阵 |
| SAE输入一致 | 比较捕获的\(a\)与旁支收到的值 | 若有缩放/中心化，记录精确变换；不能悄悄把归一化后的SAE输入当原始\(a\) |
| 残差恒等式 | 检查\(s-r=a\) | 与实际浮点误差相容；有额外门控/缩放时先把实现差异说明清楚 |
| 主路径不变 | 同输入比较关闭旁支与只读旁支 | 输出分布不变；有差异则当前不是纯观察器，暂停比较 |
| 填充不变 | 相同正文分别单条、左填充、右填充运行 | 对齐正文位置后\(a\)与汇聚结果一致；位置编号必须正确 |
| 因果与缓存 | 相同前缀后追加两种后文；再比较全序列与逐步缓存前向 | 前缀输出不受未来改变；逐步与全序列同位置结果一致 |

同时核实各条件的初始主干权重、训练数据顺序、分词器、有效词元计数、优化器及学习率日程。若初始化或数据预算并不匹配，本轮只能比较这些具体检查点，不能把差异单独归因于SAE正则。SALL与S7/S37的辅助梯度量级也可能不同，本轮不把位置/层数与强度的作用强行分开。

统一`eval()`、关闭随机丢弃和采样、固定注意力实现及精度。结构验收优先采用同一实现的单精度浮点数；以`atol=1e-5, rtol=1e-4`作为初始诊断标准。若未通过，输出绝对误差、相对误差及张量范数并调查，不能直接放宽到通过。低精度误差要单独与单精度参照比较，不把它误判为结构变化。

主干模型若使用张量并行，应捕获归并后的完整写入量，而不是某张卡上的局部分量。仅设置`output_hidden_states=True`通常不能得到这里的\(a\)；`output_attentions`返回的权重也不是\(a\)。必须根据实际源码安装只读提取钩子。[R3]

**证据边界：本次获得的是会话、图示和公开资料，没有获得你们的模型源码及检查点。因此已核实“应当取哪里”，尚未运行“你们代码实际取对了”的验收。该验收是第一步，不是假定已通过。**

## 3. 用句子均值还是最后一个表征？

### 3.1 结论：不存在脱离任务的统一最优选择

对固定输入\(x_{1:T}\)，在同一个注意力输出位置定义：

\[
h^{\mathrm{last}}_\ell=a_{\ell,T},\qquad
h^{\mathrm{mean}}_\ell=\frac1{|I|}\sum_{t\in I}a_{\ell,t},
\]

其中\(I\)只包含预先定义的有效正文词元位置，\(T=\max I\)。不是把各层相平均。

- **末位**测量“读完当前前缀后，这一位置从上下文读出并写入了什么”。它能访问全部前缀，但没有保证完整概括全文，也没有保证包含主干保留的全部信息。
- **均值**测量“这段输入在多个位置产生的平均写入模式”。它覆盖多个局部读取位置，适合段落主题统计，但平均的各项只见过各自前缀，不是每一项都看过全文；平均也可能抵消方向或稀释句尾关系。

若讨论第t个词元的在线路由，就只能使用当时的前缀；完整句均值包含t之后的位置时会泄漏未来。未来路由器若实际接收归一化后的残差，也需在那个真实输入位置另做验证，不能用本轮a上的结果替它证明。

上述因果限制由计算图决定；哪个汇聚的实测语义读出更好，必须在具体模型和取点上验证。[R1][R2][R3]

### 3.2 可核查的外部证据及适用边界

| 证据 | 实际发现 | 对本实验的含义 |
|---|---|---|
| SGPT | 比较了解码器句向量的末位、均值、位置加权均值；其设置下加权均值表现更好 | 反驳“因果模型必然末位最佳”；不证明原始注意力输出也如此 |
| Repetition Improves Language Model Embeddings，表4 | 在其Mistral-7B-Instruct零样本设置及56项文本嵌入评测中，常规表示的均值平均分42.38，末位31.94 | 表明末位能看全文，不等于读出质量最好 |
| 同一论文对因果汇聚的分析 | 均值可能稀释较晚出现的区别；末位可能偏重后半句 | 要用“信息出现位置”控制，而不是只争论一种汇聚 |

这些实验主要分析末层隐藏状态，**没有直接比较你们8层模型的投影后注意力写入量**。因此不能给出“文献已证明你们一定该用哪一种”的伪确定结论。[R1][R2]

本轮不采用重复输入、改成双向注意力、额外语义摘要提示或新增句向量微调来追求更高分：这些会改变被审查的计算过程。它们只作为解释汇聚风险的文献依据。

### 3.3 本轮固定口径

| 数据/问题 | 主汇聚 | 必须同时报告的对照 |
|---|---|---|
| 旧构造短句`P_old` | 原协议句末有效位置 | 正文均值；旧取点结果单列 |
| 新关系短句`P_rel_v1` | 最后有效正文词元 | 同输入正文均值；小诊断集增加最后实词位置 |
| 旧自然文本`N_old` | 原协议前256位置均值 | 对同一有效窗口取末位；核查原掩码实现 |
| 新自然领域`N8_v1` | 同一256正文词元窗口的均值 | 第256正文词元位置的\(a\) |
| PAWS句子对 | 每句独立编码后的正文均值 | 每句末位；不能把两句拼起来后再称独立句表示 |
| 当前词元的读取/潜在路由问题 | 指定位置\(a_{\ell,t}\) | 不用完整句子的均值替代 |

**这是一套按测量问题预先固定的设计，不是声称末位在关系任务中已被证明更准确。** 关系短句主看末位，是为了在关系信息全部出现以后测量一次局部读取；自然主题主看均值，是为了测量窗口整体统计，同时延续现有自然面板的思路。

### 3.4 分词、标点与填充的精确规定

1. 四种模型使用相同分词器及版本、相同正文字符串、相同特殊词元规则。不添加聊天模板。训练惯例需要的序列起始标记保留在模型输入中，但不计入正文均值；不为了“更语义”额外补结束标记。
2. `last`指最后有效**正文词元**。固定句末句号可以是正文末位；同时记录它的词元编号、解码片段与字符偏移。不能默认它是一个实词，也不能一律用张量最后一格。
3. 不用`input_ids != pad_id`构造唯一掩码：填充标记可能与结束标记同编号。结合`attention_mask`、实际插入的特殊词元位置和正文字符范围构造`content_mask`。
4. 左填充时，`sum(mask)-1`不是正确数组位置。使用`max{t: content_mask[t]=1}`，见附录代码。
5. 对`N8_v1`，先从独立记录选择前256个正文词元，再加训练必需的特殊标记；两种汇聚使用同一输入。第256位是**窗口末位**，未必是句末，不得写成“整篇文章最后表示”。
6. 完整句子不做损害标签的任意截断。`P_rel_v1`或PAWS任一句连同必要标记超过模型实际上下文上限，就排除整个对比组/句子对，记录原因。上限以实际配置为准，不直接假设512。
7. SAE必须先逐词元编码/重构，再汇聚：`mean(encode(a_t))`；不能换成`encode(mean(a_t))`。非线性编码使二者一般不相等。句子平均编码的非零特征数也不等于单词元的稀疏预算。
8. 均值采用单精度累加。主报告保留原始单位；单位长度归一化作为明确标注的第二口径，不能覆盖原结果。

## 4. KV缓存：你的考虑哪里正确，哪里需要调整？

### 4.1 正确的部分

键向量用来决定当前查询应当读哪里，值向量提供被读出的内容；在常规实现中，它们由该层的输入状态投影得到，**不是此前各词元的注意力输出a本身**。[R3]

生成下一个词元时，当前查询需要读取此前位置的键和值。把这些中间结果保存以免重复计算，就是**键值缓存（KV cache）**。对于常规因果注意力，每层维护自身的缓存，不能把各层键值看成同一个语义库。[R5]

处理前缀`x1…xt`时，在位置t得到的状态用于预测`x(t+1)`；不要把待预测答案先输入，再称其为“预测前的表征”。

### 4.2 需要调整的部分

**读取原始注意力输出，并不是忽略历史键值。** 第2节的\(a_{\ell,t}\)已经由历史键值参与计算。再把全部历史键值拼入\(a\)，会变成“整份记忆状态加当前写入”的新测量，而且输入维度随长度变化；它不能与原先的单向量结果等价比较。

但另一个极端也不对：**\(a_{\ell,t}\)不包含缓存中的所有信息。** 它只是当前查询实际读出的加权组合；缓存中仍可能有当前没有读出的内容。因此，单点读不出某个标签，只能限制这个位置及这种读法，不能推出模型没有存储相关信息。

进一步说，下一个词元的输出分布来自最后一层完成注意力、残差与前馈等计算后的状态，经最终归一化及词表投影得到；不是直接由\(a_{8,t}\)独自决定。选择审查注意力，是因为这是正则施加处，不是因为它是全模型的充分状态。[R3][R5]

### 4.3 本轮怎样确保没有遗漏上下文

**主提取采用完整输入的一次因果前向，`use_cache=False`。** 这只是“不保存供下一次复用的缓存”，不是“不计算历史键值”，也不是“移除历史上下文”。固定输入及正确掩码下，它与按同一文本逐步输入并使用缓存，在精确数学运算中应得到相同位置的结果。[R5]

缓存等价测试用32条固定输入：8条关系短句、8条M2D2记录、8对PAWS的16个句子。对同一模型比较：

```text
A：一次输入全部固定文本，记录a4、a8、最终输出分数。
B：每次输入该文本的下一个真实词元，复用此前缓存，记录相同量。
对齐相同原文词元位置，计算最大绝对差和相对差。
```

B不是让模型自行生成；不同模型自行生成的内容会产生输入混杂。缓存长度、注意力掩码、位置编号、特殊标记必须一致。

### 4.4 先做一个更便宜、直接的“上下文是否被读到”测试

由`P_rel_v1`建立独立的诊断变体：关系句后接**完全相同**的中性后缀，例如`" The description ends here."`，在后缀最后词元测\(a\)。对同一实体组：同义改写作为正对，关系反向作为反对；两类都使用同一后缀。

测量：关系方向的读出、同义与反向距离、候选SAE特征响应。最后局部词汇相同而表示可区分，只能说明这些表示利用了前缀差异；是否概括为关系语义，仍须跨模板/实体确认。后缀改变了查询，故该变体**单列，不替换原短句主结果**。

另外在N8同一256词元输入中记录第64、128、256个正文位置，画领域读出随可用前缀长度的变化。领域标签继承自记录，属于弱标签，不能假定前64词元已经完整表达其领域。

### 4.5 什么时候才深入K/V

只有出现“原始写入的差异已经确认，但来源不明”时，进入选定检查点的小样本分析，首批不超过64个固定样本：保存当前查询、历史键值和该查询的注意力权重。

可以分解历史位置\(j\)对当前写入的贡献：

\[
c_{\ell,t,j}=\sum_hW^{(h)}_{O,\ell}\alpha^{(h)}_{\ell,tj}v^{(h)}_{\ell,j},\quad
 a_{\ell,t}-b_{O,\ell}=\sum_j c_{\ell,t,j}.
\]

比较关系词、实体和无关前缀的贡献及候选方向上的投影。它是对**已实现计算**的线性分解，不等于删除该词后模型一定发生同样变化，因为重新计算时查询、权重及后续状态都会变。不能只看注意力权重大就断言该词因果重要。[R4][R13]

**实现提醒：**若改变早期输入或某层过去位置的注意力输出，应重新计算受影响的后续表示及上层缓存。原位置的注意力输出位于该层K/V投影之后；修改它并不自动修改同层已经算好的K/V。最安全的第一版干预是清空缓存、对修改后的整条输入完整重算。

### 5.3 新受控关系面板`P_rel_v1`

#### A. 为什么需要它

旧P领域读出接近满分，容易由领域关键词完成，未必能区分“只识别词”和“理解词间关系”。新面板控制词汇集合，同时改变关系方向。

例子：

```text
Objects in reference order: box 0001; box 0002.
box 0001 is to the left of box 0002.

Objects in reference order: box 0001; box 0002.
box 0002 is to the right of box 0001.     # 同一关系状态，换说法

Objects in reference order: box 0001; box 0002.
box 0002 is to the left of box 0001.      # 同样词汇，关系反向
```

上面`#`注释只是解释，**不输入模型**。开头的实体参考顺序固定，标签问的是“第一个参考实体相对第二个的关系”；不能用正文第一个出现的实体定义标签，否则会把目标变成模板识别。

#### B. 精确因素

| 因素 | 取值 |
|---|---|
| 关系家族 | 水平位置、垂直位置、先后顺序、包含关系 |
| 每家族基准关系 | 左于、高于、早于、位于内部 |
| 方向标签 | 0：参考实体1对实体2满足基准关系；1：实体2对实体1满足基准关系 |
| 实体组 | 200对；400个不同编号实体；120/40/40对分配到拟合/开发/确认池 |
| 表达模板 | 每家族8种；4/2/2种分配到拟合/开发/确认池 |
| 总量 | 4家族×2方向×200实体对×8模板＝12800 |

**主任务：分别在每个家族内做二分类，再等权平均四家的准确率。** 四类家族识别只作容易程度对照；不能用它代替关系方向。八个“家族×方向”标签仅用于明确标注的辅助聚类。

这是一种对**关系因素**的受控检验。换实体会改变完整命题，保持不变的是待读出的关系因素；不要说换实体前后“整句语义完全一样”。编号实体的跨实体泛化也不等于未见词汇泛化。

#### C. 划分表：交叉留出，不随机打散模板变体

| 集合 | 实体池 | 模板池 | 条数 | 用途 |
|---|---|---|---:|---|
| `fit` | 拟合 | 拟合 | 3840 | 拟合预处理、探针及无监督结构 |
| `dev_template` | 拟合 | 开发 | 1920 | 单独诊断新模板 |
| `dev_entity` | 开发 | 拟合 | 1280 | 单独诊断新实体 |
| `dev_joint` | 开发 | 开发 | 640 | 主调参集 |
| `test_template` | 拟合 | 确认 | 1920 | 只改变模板的确认 |
| `test_entity` | 确认 | 拟合 | 1280 | 只改变实体的确认 |
| `test_joint` | 确认 | 确认 | 640 | **主确认集** |
| `reserved` | 开发/确认交叉的剩余组合 | — | 1280 | 不参与选模型或主报告 |

`test_template`有意保留拟合实体；这是控制变量测试，不是假装实体独立。只有`test_joint`同时满足两种留出。各集合中两种方向成对保留；截断、清洗时不能只丢掉一方。

附录A给出完整生成代码和32个模板。它已通过条数、唯一性、实体池不重合、反向句词袋完全一致的自动检查；**尚未经过你们模型的分词长度检查，也需要人工审核模板语义**。特别是先后/包含关系，需确认表达没有额外引入歧义。

#### D. 两项直接测量

**跨表达读出：**用`fit`训练简单分类器，在`dev_joint`固定超参数后，分别测三个确认集，重点报告`test_joint`。两种方向使用相同词袋，所以不含顺序的一元词袋分类应接近50%；偏离时先检查划分、权重和数据是否仍成对。

**同义与反例距离：**在同实体、同家族下，令\(x\)与\(x^+\)为不同模板的同一关系状态，\(x^-\)为方向反向。用余弦距离\(d\)，报告：

\[
M=d(h(x),h(x^-))-d(h(x),h(x^+)).
\]

两种方向、两个模板轮换作锚点，负例同时覆盖同模板与异模板，避免只给负例增加模板差异。报告\(M\)分布及\(\Pr(M>0)\)，而不只报均值。确认模板只有两种时，将所有允许的轮换平均为每个实体组的统计量再估计不确定性。

距离主口径使用原始向量余弦；另存仅减去拟合集均值后的余弦敏感性结果，不能用确认集均值来构造读法。近零向量不能硬算余弦，应报告数量及有效覆盖率；模型比较用共同有效对比组，同时列出各自无效比例，不能悄悄删除正则模型坍缩的样本。原始向量的线性探针仍保留零向量样本。

距离为负不直接证明“没有语义”：其他因素可能主导原始欧氏/余弦几何；需结合跨模板探针。这里不强制所有相同关系的不同实体句都互相靠近。

### 5.4 自然领域面板`N8_v1`：确定使用M2D2

**固定八个发布配置：**

| 粗领域 | 细领域1 | 细领域2 |
|---|---|---|
| 计算机科学 | `cs.CL` 计算语言学 | `cs.CV` 计算机视觉 |
| 数学 | `math.AG` 代数几何 | `math.NT` 数论 |
| 物理 | `physics.optics` 光学 | `physics.flu-dyn` 流体动力学 |
| 定量生物学 | `q-bio.GN` 基因组学 | `q-bio.NC` 神经元与认知 |

这些配置已在官方数据卡核对存在。采用同为学术来源的八类，避免主要结果只是“百科与论文的文体差别”。这不消除全部来源混杂；领域标签也不是句级语义真值。[R6]

#### 下载和读取的实际约定

官方旧加载脚本的记录只有`text`字段；类别来自配置名。不能访问不存在的`row['label']`或假定有`article_id`。脚本使用每配置一个压缩包，内部读取`train.txt / valid.txt / test.txt`，逐行产生记录。[R7]

```text
数据仓库：machelreid/m2d2
压缩包模式：https://huggingface.co/datasets/machelreid/m2d2/resolve/{pinned_revision}/data/{config}.tar.gz
官方加载脚本预期成员：{config}/train.txt、{config}/valid.txt、{config}/test.txt
本地映射：train -> fit；valid -> dev；test -> test
```

先解析仓库提交号并固定完整版本；记录每个压缩包的SHA-256。当前数据卡的查看器因旧式自定义加载脚本不可直接使用，因此优先下载发布压缩包，用标准库安全读取预期文本成员，转为本地逐行JSON，不依赖执行远程数据代码。压缩包实际根目录必须检查，禁止路径穿越和符号链接；不盲目`extractall()`。

每条记录的来源编号为`revision/config/split/line_number`，标签写入元数据，不拼入正文。

#### 清洗、窗口和数量

1. 保留原文副本；仅为查重另建Unicode规范化和空白折叠后的哈希。不要全局小写或删除数学公式、否定、单位与标点。
2. 去空记录及明显解码损坏记录。标题/公式密度只记录，不因“看起来难分类”删掉。人工按每类40条抽查来源、语言及正文合理性，并在提取模型表征之前锁定规则。
3. 保留官方划分；相同全文跨集合时，保留确认集，删掉低优先级集合副本。跨类别的完全相同正文另存多标签记录，不进入主单标签面板。
4. 主面板只纳入至少256正文词元的记录；每条只取开头256词元，无外部前缀、不拼接不同记录。不足者进入`short_records`诊断，不用填充成256参与主均值。
5. 每类目标`fit=300, dev=100, test=200`，总计4800。按固定种子20260920对稳定来源编号抽样。若任一类不足，对该集合所有类采用共同数量`min(目标数, 各类可用数的最小值)`，不放回补样、不借用其他官方划分。实际数量必须报告；拟合集每类少于80或确认集每类少于80时，停止把它作为正式N8主面板，另建128词元版本并重新冻结，不能无声改变主协议。
6. 对抽出的每条记录保存全文来源编号、窗口起止、词元数和词元ID哈希。额外片段必须跟随原记录分组，不能跨拟合/确认划分。
7. 对选定窗口再做一次精确哈希去重，防止不同全文共享完全相同开头。用五词连续片段的Jaccard重合度排查跨集合近重复，阈值预设0.85；可先用候选检索加速，再精确计算重合度。命中记录人工核实后按确认集优先处理；仅做候选检索时要注明它不保证穷尽所有重复。不要删除公式或领域词来“消除捷径”。
8. **没有原文档编号时，不能宣称已经完成严格论文级查重。** 官方划分与全文去重是可以实现的保障；是否存在同论文不同段落交叉，仍属于数据限制。[R6][R7]

主报告细领域八分类及每个粗领域内的二分类；粗领域四分类辅助。若粗分更好、细分更差，应报告“粗化及细节损失风险”，不能笼统说语义改善。

### 5.5 自然语义确认：固定PAWS-Wiki Labeled (Final)

PAWS利用高词汇重合但可能因词序而意义不同的句子对，适合检查“不只是认关键词”。使用人工标注的`Labeled (Final)`，不混用`Swap-only`或未标注版本；非同义标签不必然表示逻辑矛盾。[R8]

官方发布规模为49401训练对、8000开发对、8000测试对；字段为`id, sentence1, sentence2, label`。本轮从对应官方划分按固定种子选8000/2000/2000对，尽量保持各划分原有标签比例，数量不足时报告实际值，不跨集合补齐。[R8]

```text
主数据：https://storage.googleapis.com/paws/english/paws_wiki_labeled_final.tar.gz
来源映射：https://storage.googleapis.com/paws/english/wiki_raw_and_mapping.tar.gz
```

**必须使用来源映射检查变体泄漏。** 官方映射包含最终句子到词序交换样本/回译样本的对应，回译样本又能追溯到交换样本。[R9]

处理流程：

```text
读取最终pairs + labeled_final_mapping/{train,dev,test}.tsv；按(split,id)连接。
解析mapping1、mapping2：
  swap_xxxxx_1/2 -> 对应swap_xxxxx；
  backtransl_*_2 -> 回译ID -> 其swap_id -> 对应swap根。
用共享swap根或相同规范化句子建立来源连通组。
保留官方test；剔除与test来源组重合的train/dev记录；
再剔除与保留dev来源组重合的train记录。
去掉规范化后完全相同的重复句子对；相同句子对标签冲突者单列。
最后才按固定种子和标签比例选配额，冻结清单。
```

若官方映射无法正确解析，停止“来源隔离版”的确认实验，输出缺失映射报告；可以运行明确标注的官方划分诊断版，但不能宣称其来源隔离已通过。

两句分别编码，缓存可按句子哈希去重节约前向。主分数为两句均值向量的余弦相似度，以**受试者工作特征曲线下面积（AUROC）**和**平均精确率（AP）**评价同义对是否排在非同义对前面；另报末位汇聚结果。AP必须同时报告同义比例，阈值相关的准确率只能在开发集选阈值。

不把0/1成对标签赋给单句后做聚类。若追加句子对分类器，输入`[|u-v|, u*v]`，必须标注为“带固定非线性交互的句对读出”，不能称原始\(a\)上的线性探针。主分析不必追加它。

**标签保护：**高词汇重合正是PAWS的测试目标，不能因同一对的两句相似就去掉反例。跨集合泄漏检查以来源映射和完整句重复为依据，不对对内两句套用去重。任一句超上下文上限则删除整对；不截断后仍沿用原同义标签。正文若实际以Python字节字面量存储，仅对确认属于该形式的字段安全解析并UTF-8解码，禁止`eval`，普通字符串保持原样。

### 5.6 为什么不再堆更多数据

M2D2已经覆盖领域组织；P_rel检验可控关系因素；PAWS提供人工标注的自然关系敏感性。新增简单主题分类不解决当前分类饱和的问题；直接测大量下游任务则偏离本轮冻结表征审查。

这些数据都可能与主干预训练语料存在重合。**探针的拟合/测试独立，不等于主干从未见过测试文本。** 本轮可以比较同数据下各主干的表征性质，但未经训练语料核对，不声称“对完全未见自然文本的泛化”。受控编号句降低直接记忆整句的可能，不替代严格污染核查。

若补语言建模护栏，优先使用你们已固定且能核实未训练的留出清单。DCLM-Baseline 1.0公开页面列的是训练划分，不能随手抽一批就称官方测试集；需与自己的训练记录去重。[R15]

## 6. 分析实现：保留A—E，但按证据依赖推进

### 6.1 共同规则

- 任何标准化、降维、聚类中心、探针及特征选择，只拟合`fit`；超参数只看`dev`；`test`只在冻结配置后计算。测试集标签不能选择层、方向、特征或最好看的聚类数。
- 不同模型用完全相同样本编号、输入词元、分层权重和探针训练量。标签只进入分析器，不进入主干。
- 主几何使用原始单位。探针允许仅用拟合集均值和**一个全局均方根尺度**做数值缩放；逐维标准化/白化会改几何，若使用必须独立命名，不混成原始空间结论。
- 各模型分别拟合自己的读出器，才是在比较各自可读性。另训练一个在另一模型直接使用，测的是坐标可迁移性，不是同一个问题。
- 模型训练随机种子、探针随机种子、聚类随机种子、数据抽样种子分别记录。增加分析随机种子不能替代重复训练主干。

### 模块A：原始表征的几何与读出

#### A1. 类间/类内散度分解

对\(C\)个类别采用相同权重\(\pi_c=1/C\)，定义类均值\(\mu_c\)、总均值\(\mu=\sum_c\pi_c\mu_c\)：

\[
B=\sum_c\pi_c\|\mu_c-\mu\|^2,
\qquad
W=\sum_c\pi_c\frac1{n_c}\sum_{i:y_i=c}\|h_i-\mu_c\|^2,
\qquad F=B/W.
\]

同时报告总散度\(T=B+W\)、平均平方范数、均值范数、零/近零向量比例。实现中验证分解恒等式；若\(W\)接近数值零，报告未定义，不通过任意截断制造大比值。协方差使用与上述一致的除数，避免混合\(n\)与\(n-1\)。

这个\(F\)是**散度迹比**，不是参数的Fisher信息，也不是已优化判别方向的Fisher判别值。各向同性缩放会同时改变B和W，不改变F；方向选择性缩放则可能改变F，却不一定增加标签信息。

在P_rel中分别按四家族的方向标签计算，再等权汇总；不能仅用易分的四家族或八大类掩盖方向读出困难。旧指标用旧公式精确复现，与新标准公式分栏。

#### A2. 线性探针：主要证据

使用带二范数惩罚的逻辑回归。惩罚逆强度固定候选`C={0.01,0.1,1,10,100}`；每个表征各自按同一开发集指标选C；优化器达到收敛或明确报告未收敛。主报告准确率、类别等权F1和交叉熵。

P_rel每个家族二分类；开发集用`dev_joint`，同分优先更强惩罚。N8报告八分类、粗四分类和四个家族内二分类。PAWS主任务不使用这种单句分类器。

主读出用全拟合集。额外做每类8、32、64条的低样本曲线，重复5次固定抽样；P_rel按实体组取样并成对保留方向，不能只选方便分类的单句。把“接近满分”与“需要较少样本才达到同分”区分开。

**控制：**长度、正文末词元编号/标点类型、向量范数的简易分类器；不含顺序的一元词袋线性分类器；按数据分组结构进行的随机标签负对照。P_rel的随机标签可在每个实体组内统一翻转方向，保持反对句成对及类平衡；N8可在记录/来源组层面打乱类别。另检查模板与来源是否可读，但“模板仍可读”本身不是坏事，关键是语义能否跨模板读出。探针的表现不能自动证明主干实际使用该信息。[R10]

#### A3. 小型非线性探针：定位读法难度

固定`d -> 64 -> C`的两层网络，中间使用整流线性单元（ReLU）。训练使用带解耦权重衰减的自适应优化器（AdamW），超参数为：学习率`1e-3`、权重衰减`1e-3`、批量128、最多100轮、开发集交叉熵10轮不改善即停止；种子17/29/43。只更新探针，不更新主干。

若线性不变但该探针改善，表述为“在此固定非线性读出预算下更可访问”；不能声称已经证明信息编码本质上非线性。拟合和开发样本相同；输入维度更大的SAE编码不能用额外参数预算冒充公平优势。

### 模块B：样本是否真的像语义小簇

使用均值聚类（K-means）作为明确的小球结构检验：P_rel在家族内固定K=2，辅助合并K=8；N8固定K=8；旧P固定K=4。仅在拟合集拟合中心，再分配确认样本。

固定5个分析种子17/29/43/71/97，每次20个初始解、最多300次迭代。主结果使用单位长度归一化向量，原始单位结果作为尺度对照，表格必须写清。此处是归一化数据上的普通K-means，不冒称为严格球面K-means。

报告**调整兰德指数（ARI）**、**调整互信息（AMI）**、**归一化互信息（NMI）**及簇大小；前两者考虑随机一致性，NMI作为延续旧结果的指标。另在来源组约束下做100次标签置换。五次聚类在同一确认样本上的两两ARI衡量算法稳定性。[R14]

K由假设固定，故不能据此宣称“发现真实语义簇数就是K”。聚类未改善但跨模板读出改善时，接受“语义因素可读，但不必形成独立小球”。不马上追加一大批聚类算法直到出现正结果。

### 模块C：SAE是否揭示稳定因素，而不是只给好看的重构

#### C1. 分开“主干变化”和“读法变化”

主干比较先使用\(a\)，不依赖是否已完成离线SAE。在线字典可立即用于描述S7/S37/SALL自身，但不能独自证明“正则主干比Dense更可解释”。

若要做后者，至少在10B的Dense和SALL、第4/8层各训练相同预算的离线观察字典，形成四格：

| | 原始注意力输出 | 同预算离线SAE读法 |
|---|---|---|
| Dense | \(a_D\) | \(z_D,\hat a_D\) |
| SALL | \(a_S\) | \(z_S,\hat a_S\) |

逐模型拟合，数据编号一致；复用项目当前的字典宽度、稀疏规则、输入缩放、优化器和训练日程，不在本轮改成另一个SAE类型。建议先固定200万词元拟合、12.8万词元验证，均来自已获授权且与表征确认面板去重的无标签文本；不足时两边同步缩减，并检查重构是否已经稳定。相同预算不保证两个字典都学好，未收敛时不能下结论。条件允许使用3个字典种子，不与主干种子混淆。

MP-SAE的逐步读取思路和Matryoshka-SAE的多层级字典提醒我们应同时检查共享因素与条件性差异；本轮据此设计审查，不把更换SAE结构也加进当前主对照。[R16][R17]

#### C2. 一个特征到底响应什么

先在拟合集统计每个特征的激活次数、激活强度、解码方向范数和各位置分布。低于20个有效来源组支持的特征只列为证据不足，不因一两个极端样本命名。

对每个预定义关系/领域因素，在拟合集按单特征AP选候选；每因素最多3个。同时加入12个频率分层随机特征。候选名单冻结后，制作特征卡：10个最高激活、10个中等激活、10个低/零激活样本，列误报与漏报，并在未见模板/实体上计算AP和召回。

逐词元卡必须显示**激活位置之前的可见前缀**。后文可以作为参考展示，但明确当时不可见，不能用后文给当前激活编造解释。不能只看最高激活样本就宣称“一特征=一概念”。对自然领域，继承的段落标签只是候选相关性线索。

#### C3. 单特征不够时，才检查小特征组

首先采用可控的稀疏读出：按拟合集候选排序，分别取1、4、16个特征，开发集冻结后测确认集。不同模型用相同特征数，防止宽字典的参数量优势混入。

共激活分析先只在拟合文本中、相同位置范围内计算；排除自动特殊标记。对活跃特征的二值激活列求中心化相关，负值置零，保留每节点最高20条正边，再对称化。若特征很多，固定选择频率位于1%—50%且满足来源组数阈值的至多2048个，公开筛选规则，避免构建完整巨大矩阵。

要进行**谱聚类**时，定义节点为特征、边为上面的共激活关系；对图度矩阵D和邻接矩阵A计算\(L=I-D^{-1/2}AD^{-1/2}\)，孤立节点单列；取最小特征值对应的向量后聚类。仅试K=4/8/16，按无标签的重抽样稳定性在开发文本选择，不能按确认标签一致性选K。分组后在确认集评价组内特征之和及固定小组读出的语义泛化。

再做一次“同领域内部”的共激活，判断原分组是否仅来自领域混合。样本聚类与特征聚类是两个不同问题，不共享结论。

#### C4. 重构保留与遗漏

报告归一化重构平方误差、\(a,\hat a,e\)上的相同探针及语义反例结果。重构误差可用拟合集方差作为共同归一化参照，并报告原始分子；不同模型不能只比未注明尺度的误差。

重构\(\hat a\)上的线性分类一般等价于\(a\)上的一种非线性读法，不等于原始主干更线性可分。误差\(e\)仍可读出标签，说明字典遗漏了某些可读因素，但不自动证明这些因素无法从\(\hat a\)恢复；无读出也不证明信息绝对不存在。SAEBench同样区分重构/稀疏代理指标与概念、应用指标。[R11]

### 模块D：哪些方向变化了？

D1主成分分析（PCA）：只在拟合集中心化后计算协方差频谱；报告累计解释方差曲线、均值方向占比及有效方差维数

\[
d_{\mathrm{eff}}=\frac{(\sum_i\lambda_i)^2}{\sum_i\lambda_i^2}.
\]

它是方差分布的集中程度，**不是语义数量、SAE激活数，也不是应该选择的稀疏预算**。高维小样本下最多估计到样本支持的秩，报告样本数与正特征值数量。

D2方向上的标签信息：固定相同维数r，分别用高方差方向、可重复估计的低方差方向、同维随机子空间训练相同线性探针。首选r=16，若样本不足则所有配对模型同步降到可估计的共同r。低方差方向必须在拟合集分半后可稳定重现；只剩近零、噪声方向时标记不可估计，不能把任意零空间叫作“低方差语义”。

D3类别内子空间：各类内部中心化，计算前r个变化方向的重合度，和同类别分半重合度、同维随机方向一起报告。不同类共享高方差方向可能是共享句式/长度，而非共享概念；方向重合少也不自动代表独立知识。流形的半径、维数、相关性可以影响可分性，但不能简化成“更正交就更好”。[R12]

**对应你们一直纠结的最大/最小奇异方向：不用先假定哪一侧是公共语义。先测哪组方向的读出能跨模板/实体保留，再解释其语义意义。**

### 模块E：训练过程中是何时发生的？

在全部检查点先重复最小指标：A1、线性探针、P_rel主确认结果、N8细领域读出、固定K聚类。小非线性探针只在0/5/10B，PAWS主确认先只在10B四模型；不要把所有昂贵分析乘满所有条件。

使用**中心化核对齐（CKA）**比较同一组固定输入在不同时刻的样本关系结构。线性版本为：

\[
\mathrm{CKA}(X,Y)=
\frac{\|X_c^\top Y_c\|_F^2}
{\|X_c^\top X_c\|_F\,\|Y_c^\top Y_c\|_F}.
\]

X/Y行必须是相同样本、相同顺序、相同取点和汇聚；CKA测相似程度，不测哪个模型更好。[R18]

轨迹图横轴用核实后的累计训练词元数。检查点缺失时保留缺失，不把训练步数直接当同样词元预算，也不插值得出显著差异。固定SAE编号只能追踪连续训练的参数槽位；独立离线字典的同编号不能当相同语义。

## 7. 统计、判定与汇报图：防止看见什么都能解释

### 7.1 预注册主比较

**主对照：10B的SALL对Dense。** 主取点第4与第8层分别报告；主语义指标为P_rel的`test_joint`四关系家族等权准确率差。自然领域N8和PAWS分别给出外部范围确认，不加权合成一个“总语义分”。

该规定是为了明确优先级，不预设SALL优于其他模型。S7/S37在相同流程下是关键次级条件。末位与均值两种口径均报告，不能只保留正值。

### 7.2 不确定性

在相同确认输入上计算配对差。采用按来源组重抽样的自助法，重复2000次，给95%区间：P_rel按实体组、PAWS按来源连通组、M2D2优先按已知原文档，否则按发布记录分组并注明限制。

探针种子、字典种子及主干训练种子的变化分开列出。仅一个主干训练种子时，区间只反映此已训练模型下的样本/分析不确定性，不能声称训练方法具有跨种子的稳定优势。若对两层主比较作显著性检验，使用Holm校正；其余大量分析默认探索性，不挑未校正的最小p值。

区间跨零只表示证据不足，不表示模型等效。要讨论实质等效，应预先设定可接受差异范围，而不是看到不显著再补。

### 7.3 判定树

```text
取点、输入、掩码是否通过验收？
├─ 否：先修复；不解释模型差异。
└─ 是：原始a在独立确认中是否变化？
   ├─ 几何变、跨表达读出不变
   │  ├─ B/W只由波动缩小解释：当前证据支持几何重排，不支持语义访问改善。
   │  └─ 局部位置结果不同：进入位置/上下文诊断，不推广到整个网络。
   ├─ 只有重构或编码更好
   │  └─ 检查同预算离线字典；暂称读法收益，不称主干塑形成功。
   ├─ 原始a跨模板/实体读出改善
   │  ├─ PAWS未确认：结论限于受控关系因素。
   │  ├─ N8只有粗分改善、细分变差：检查粗化及细节损失。
   │  └─ 自然语义也改善：支持当前检查点和取点上的更稳健语义读出。
   └─ 所有读出接近满分/随机或区间很宽
      └─ 当前尺子分辨率不足；报告饱和/地板/样本量问题，不宣布无变化。
```

即使最后分支积极，也没有证明专家路由更好、容量提高、知识更新更局部。下一轮才考虑针对性干预；本轮无需启动专家模块训练。

### 7.4 固定六张图的含义

| 图 | 横轴 / 纵轴 | 事前预期及可能认识更新 |
|---|---|---|
| F1 散度分解 | 训练词元 / B、W、F分别作图 | 原以为F上升代表更可分；若仅W变而读出不变，更新为几何变化 |

## 8. 给执行代理的工作顺序与交付接口

### 8.1 不需要用户再次决定的内容

本文件已经固定主要层位、比较条件、数据来源/配额、汇聚、划分、主要指标和判定分支。实际本地模型路径、分词器、旧数据清单、现有SAE超参数由执行代理读取配置补齐，不能用猜测占位运行。

模型没有对应检查点/数据时，写入`blocked_items.md`并继续不依赖该项的步骤。不随意新训一个模型当作原检查点，不把新造数据当旧P/N。

### 8.2 阶段安排

| 阶段 | 具体动作 | 必须交付 | 进入下一阶段的条件 |
|---|---|---|---|
| 0 配置与取点核验 | 读取真实配置、逐模型hook验收，32条缓存等价测试 | `model_manifest.json`、`site_contract.json`、`site_checks.json` | 取点及因果/掩码检查通过 |
| 1 数据冻结 | 复原旧P/N；生成P_rel；下载清洗N8/PAWS；人工检查；冻结样本ID | 数据逐行JSON、哈希、划分及去重报告 | 无标签写进输入，无跨集合来源泄漏或明确限制 |
| 2 最小原始输出审查 | 10B Dense/SALL，在第4/8层提取两种汇聚；先旧P/N和P_rel，随后N8 | 散度、线性读出、反例结果、初版判定 | 数值正确；不能要求先有正结果 |

这些是依赖顺序，不是臆测GPU墙钟耗时。先用128条输入测一次实际吞吐，估算总词元数与存储后再安排批次。

### 8.3 提取与存储预算

每条输入一次前向同时提取第4/8层，并同时计算均值与末位。**两种汇聚不需要两次模型前向。** P_rel主流程先提取`fit/dev_joint/test_joint`，其他留出用于随后诊断；PAWS按单句哈希复用缓存。

默认只持久化每样本的池化原始向量。逐词元原始/重构向量仅保存固定诊断子集：P_rel每个关系家族16个实体组，N8每类32条，PAWS128对。特征统计可在线累积；稀疏编码保存索引/数值，不把大字典保存成全密集矩阵。

存储量在执行前按下式计算，而不是假定某个隐藏维度：

```text
原始池化字节数 = 样本数 × 层数 × 汇聚数 × 实际hidden_dim × 每元素字节数。

```

## 附录A：可直接运行的受控关系数据生成器

保存下列代码为`build_p_rel.py`，在Python 3.10及以上运行：

```bash
python build_p_rel.py --output data/P_rel_v1 --seed 20260920
```

程序拒绝覆盖非空输出目录；生成的是待人工和分词检查的受控审查数据，不是实验成绩。

```python
#!/usr/bin/env python3
"""Generate the proposed controlled relation panel. No external dependencies.
This creates an audit dataset, NOT evidence about a language model.
Python >= 3.10. Usage: python build_p_rel.py --output data/P_rel_v1
"""
from __future__ import annotations
import argparse
from collections import Counter, defaultdict
import hashlib
import json
from pathlib import Path
import random
import re

TEMPLATES: dict[str, list[str]] = {
    "horizontal": [
        "{A} is to the left of {B}.",
        "{B} is to the right of {A}.",
        "To the left of {B} is {A}.",
        "To the right of {A} is {B}.",
        "The item on the left of {B} is {A}.",
        "The item on the right of {A} is {B}.",
        "{B} has {A} on its left.",
        "{A} has {B} on its right.",
    ],
    "vertical": [
        "{A} is above {B}.",
        "{B} is below {A}.",
        "Above {B} is {A}.",
        "Below {A} is {B}.",
        "The item higher than {B} is {A}.",
        "The item lower than {A} is {B}.",
        "{B} has {A} above it.",
        "{A} has {B} below it.",
    ],
    "sequence": [
        "{A} comes before {B}.",
        "{B} comes after {A}.",
        "Before {B} comes {A}.",
        "After {A} comes {B}.",
        "{A} precedes {B} in the sequence.",
        "{B} follows {A} in the sequence.",
        "{B} has {A} earlier in the sequence.",
        "{A} has {B} later in the sequence.",
    ],
    "containment": [
        "{A} is inside {B}.",
        "{B} contains {A}.",
        "Inside {B} is {A}.",
        "Surrounding {A} is {B}.",
        "{A} is contained within {B}.",
        "{B} has {A} inside it.",
        "{B} encloses {A}.",
        "{A} is enclosed by {B}.",
    ],
}


def split_name(entity_bucket: str, template_bucket: str) -> str:
    table = {
        ("fit", "fit"): "fit",
        ("fit", "dev"): "dev_template",
        ("dev", "fit"): "dev_entity",
        ("dev", "dev"): "dev_joint",
        ("fit", "test"): "test_template",
        ("test", "fit"): "test_entity",
        ("test", "test"): "test_joint",
    }
    return table.get((entity_bucket, template_bucket), "reserved")


def build(output: Path, seed: int) -> dict:
    output.mkdir(parents=True, exist_ok=True)
    # Refuse silent overwrites: versioned artifacts must remain immutable.
    if any(output.iterdir()):
        raise FileExistsError(f"Output directory is not empty: {output}")
    rng = random.Random(seed)
    entity_numbers = list(range(1, 401))
    rng.shuffle(entity_numbers)
    rows: list[dict] = []
    for pair_idx in range(200):
        # Reference order is independent of the truth value and number magnitude.
        e1 = f"box {entity_numbers[2 * pair_idx]:04d}"
        e2 = f"box {entity_numbers[2 * pair_idx + 1]:04d}"
        entity_bucket = "fit" if pair_idx < 120 else "dev" if pair_idx < 160 else "test"
        prefix = f"Objects in reference order: {e1}; {e2}. "
        for family_idx, (family, templates) in enumerate(TEMPLATES.items()):
            for t_idx, template in enumerate(templates):
                template_bucket = "fit" if t_idx < 4 else "dev" if t_idx < 6 else "test"
                for direction in (0, 1):
                    # 0: first reference entity bears R to second; 1: reverse.
                    A, B = (e1, e2) if direction == 0 else (e2, e1)
                    body = template.format(A=A, B=B)
                    text = prefix + body
                    sample_id = f"P_rel_v1.p{pair_idx:03d}.{family}.t{t_idx}.y{direction}"
                    rows.append({
                        "sample_id": sample_id,
                        "dataset": "P_rel_v1",
                        "text": text,
                        "body_start_char": len(prefix),
                        "split": split_name(entity_bucket, template_bucket),
                        "entity_bucket": entity_bucket,
                        "template_bucket": template_bucket,
                        "source_group_id": f"pair_{pair_idx:03d}",
                        "semantic_state_id": f"pair_{pair_idx:03d}.{family}.y{direction}",
                        "contrast_pair_id": f"pair_{pair_idx:03d}.{family}.t{t_idx}",
                        "template_id": f"{family}.t{t_idx}",
                        "family": family,
                        "family_label": family_idx,
                        "direction_label": direction,
                        "joint_label": family_idx * 2 + direction,
                        "reference_entities": [e1, e2],
                        "text_sha256": hashlib.sha256(text.encode("utf-8")).hexdigest(),
                    })
    assert len(rows) == 12800
    assert len({r["sample_id"] for r in rows}) == len(rows)
    assert len({r["text"] for r in rows}) == len(rows)
    groups: dict[str, list[dict]] = defaultdict(list)
    for r in rows:
        groups[r["contrast_pair_id"]].append(r)
    # The two opposite meanings in a contrast pair have the same word multiset.
    for pair in groups.values():
        assert len(pair) == 2
        assert {r["direction_label"] for r in pair} == {0, 1}
        wordsets = [Counter(re.findall(r"\w+|[^\w\s]", r["text"].lower())) for r in pair]
        assert wordsets[0] == wordsets[1]
    entity_sets = {
        bucket: {e for r in rows if r["entity_bucket"] == bucket for e in r["reference_entities"]}
        for bucket in ("fit", "dev", "test")
    }
    assert not entity_sets["fit"] & entity_sets["dev"]
    assert not entity_sets["fit"] & entity_sets["test"]
    assert not entity_sets["dev"] & entity_sets["test"]
    counts = dict(sorted(Counter(r["split"] for r in rows).items()))
    expected = {"fit": 3840, "dev_template": 1920, "dev_entity": 1280,
                "dev_joint": 640, "test_template": 1920, "test_entity": 1280,
                "test_joint": 640, "reserved": 1280}
    assert counts == dict(sorted(expected.items()))
    for split in counts:
        selected = [r for r in rows if r["split"] == split]
        with (output / f"{split}.jsonl").open("w", encoding="utf-8") as f:
            for row in selected:
                f.write(json.dumps(row, ensure_ascii=False) + "\n")
    (output / "templates.json").write_text(json.dumps(TEMPLATES, ensure_ascii=False, indent=2), encoding="utf-8")
    manifest = {"dataset": "P_rel_v1", "seed": seed, "n_records": len(rows),
                "counts": counts, "automatic_checks_passed": True,
                "human_language_review": "required_before_model_evaluation",
                "model_tokenizer_length_check": "not_run",
                "meaning": {"horizontal": "left_of", "vertical": "above",
                            "sequence": "before", "containment": "inside"}}
    (output / "manifest.json").write_text(json.dumps(manifest, ensure_ascii=False, indent=2), encoding="utf-8")
    return manifest


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--output", type=Path, required=True)
    parser.add_argument("--seed", type=int, default=20260920)
    args = parser.parse_args()
    print(json.dumps(build(args.output, args.seed), ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()
```

## 附录B：均值/末位汇聚与掩码单元测试

保存为`pool_attention.py`，在你们已有PyTorch环境运行`python pool_attention.py`。传入的a必须已经通过第2节的取点验收。该函数不会自动寻找模型模块，也不假定任何特定模型架构。

```python
"""Pooling helper. The caller MUST pass post-output-projection attention vectors.
content_mask selects text tokens only, not padding or automatically inserted specials.
This helper cannot establish the model's extraction site; see the audit plan.
"""
from __future__ import annotations
import torch


def pool_attention(a: torch.Tensor, content_mask: torch.Tensor) -> dict[str, torch.Tensor]:
    if a.ndim != 3:
        raise ValueError(f"Expected [batch, sequence, hidden], got {tuple(a.shape)}")
    if content_mask.shape != a.shape[:2]:
        raise ValueError("Mask and activation shapes differ")
    mask = content_mask.to(device=a.device, dtype=torch.bool)
    lengths = mask.sum(dim=1)
    if torch.any(lengths == 0):
        raise ValueError("An example has no selected text tokens")
    positions = torch.arange(a.shape[1], device=a.device).expand_as(mask)
    last_indices = positions.masked_fill(~mask, -1).max(dim=1).values
    x = a.float()
    selected = x.masked_fill(~mask.unsqueeze(-1), 0.0)
    mean = selected.sum(dim=1) / lengths.unsqueeze(-1)
    last = x[torch.arange(a.shape[0], device=a.device), last_indices]
    if not torch.isfinite(mean).all() or not torch.isfinite(last).all():
        raise FloatingPointError("Non-finite pooled representation")
    return {"mean": mean, "last": last, "last_index": last_indices, "n_content_tokens": lengths}


def _test() -> None:
    a = torch.tensor([[[100.], [2.], [4.], [999.]],
                      [[999.], [100.], [6.], [8.]]])
    mask = torch.tensor([[False, True, True, False], [False, False, True, True]])
    out = pool_attention(a, mask)
    torch.testing.assert_close(out["mean"], torch.tensor([[3.], [7.]]))
    torch.testing.assert_close(out["last"], torch.tensor([[4.], [8.]]))
    assert out["last_index"].tolist() == [2, 3]
    # Right- and left-padded views of the same content agree.
    x = torch.tensor([[[2.], [4.], [999.]], [[999.], [2.], [4.]]])
    m = torch.tensor([[True, True, False], [False, True, True]])
    p = pool_attention(x, m)
    torch.testing.assert_close(p["mean"][0], p["mean"][1])
    torch.testing.assert_close(p["last"][0], p["last"][1])
    try:
        pool_attention(x, torch.zeros_like(m))
    except ValueError:
        pass
    else:
        raise AssertionError("Empty content mask must fail")
    print("Pooling unit tests passed (synthetic tensors; no user model tested).")


if __name__ == "__main__":
    _test()
```
