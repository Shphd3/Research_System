# Token 表征的子空间分析与聚类

> 翻译说明：本文主体是 [`subspace_token_clustering.md`](subspace_token_clustering.md) 的中文伴随版本。末尾“结合当前研究线的认识边界”是根据当前 A15 实验背景补充的解释，不属于英文原文。

## 问题设定

假设共有 $N=1{,}000{,}000$ 个 token 表征。每个 token 都是 $D=1000$ 维嵌入空间中的一个向量：

$$
x_i\in\mathbb R^D,
\qquad i=1,\ldots,N.
$$

我们还有一个由同一嵌入空间中的 $K=500$ 个向量描述的参考子空间。把这些向量组成矩阵：

$$
U=[u_1,u_2,\ldots,u_K]\in\mathbb R^{D\times K}.
$$

目标是利用这个 $K$ 维子空间内部的变化，发现彼此相似的 token 群组。

## 为什么分析一个子空间？

原始嵌入包含 1000 个坐标，而 $U$ 中选定的向量表达了我们关心的某一种特定信号。把 token 投影到它们的张成空间中，实际是在提出一个更窄的问题：

> token 相对于这类特定信号，彼此怎样不同？

如果 $U$ 的列向量是标准正交的，那么 token 的正交投影为

$$
\hat x_i=UU^\top x_i.
$$

它的子空间坐标

$$
a_i=U^\top x_i
$$

包含重建该投影所需的全部信息：

$$
\hat x_i=Ua_i.
$$

而且，在所选子空间内部，距离得到保留：

$$
\left\|\hat x_i-\hat x_j\right\|_2
=
\left\|a_i-a_j\right\|_2.
$$

因此，可以直接比较 500 维坐标，而不必反复比较投影后的 1000 维向量。

## 第一步：把每个 token 投影到子空间

对每个 token，计算它的子空间坐标：

$$
a_i=U^\top x_i\in\mathbb R^K.
$$

把这些坐标按列堆叠：

$$
A=[a_1,a_2,\ldots,a_N]\in\mathbb R^{K\times N}.
$$

在当前示例中：

$$
A\in\mathbb R^{500\times1{,}000{,}000}.
$$

$A$ 的每一列表示一个 token 在所选子空间中的 500 个坐标。

如果 $U$ 不是标准正交的，那么 $U^\top x_i$ 通常不是正交投影。此时应先对 $U$ 的张成空间做正交化，例如使用 QR 分解，然后使用得到的标准正交基。

## 第二步：对子空间中的 token 做中心化

先计算投影后 token 的平均坐标：

$$
\mu=\frac1N\sum_{i=1}^N a_i.
$$

然后对每个 token 做中心化：

$$
\tilde a_i=a_i-\mu.
$$

中心化数据矩阵为

$$
\tilde A=[\tilde a_1,\tilde a_2,\ldots,\tilde a_N].
$$

中心化移除了 token 群体共享的公共偏移。后续分析衡量的是 token 相对一个典型 token 怎样变化，而不是它们离嵌入空间中任意原点有多远。

## 第三步：计算子空间中的协方差

矩阵

$$
AA^\top\in\mathbb R^{K\times K}
$$

是未中心化的二阶矩，通常不等于协方差矩阵。

样本协方差为

$$
C
=
\frac1{N-1}\tilde A\tilde A^\top
=
\frac1{N-1}\sum_{i=1}^N\tilde a_i\tilde a_i^\top.
$$

在当前示例中：

$$
C\in\mathbb R^{500\times500}.
$$

$C$ 的对角元素是在各个所选子空间方向上的方差；非对角元素表示哪些方向倾向于共同变化。

协方差能够概括百万 token 点云的整体形状，而不必构造全部 token 两两之间的距离。它的主要方向就是 token 坐标分布最分散的方向。

## 第四步：使用 PCA 寻找主要变化方向

PCA，即主成分分析，是把协方差矩阵分解为一组按方差大小排序的正交方向。对 $C$ 做特征分解：

$$
C=V\Lambda V^\top,
$$

其中 $V$ 包含标准正交特征向量，并且

$$
\Lambda
=
\operatorname{diag}(\lambda_1,\ldots,\lambda_K),
\qquad
\lambda_1\geq\lambda_2\geq\cdots\geq\lambda_K\geq0.
$$

保留前 $r$ 个特征向量，其中 $r\ll500$：

$$
V_r=[v_1,\ldots,v_r]\in\mathbb R^{K\times r}.
$$

token $i$ 的降维表征为

$$
z_i=V_r^\top\tilde a_i\in\mathbb R^r.
$$

对全部 token，可写为

$$
Z=V_r^\top\tilde A\in\mathbb R^{r\times N}.
$$

保留的方差比例为

$$
\frac{\sum_{j=1}^r\lambda_j}{\sum_{j=1}^K\lambda_j}.
$$

### 为什么在聚类前使用 PCA？

PCA 把投影坐标旋转为彼此不相关、并按 token 变化量排序的方向。保留主要方向可以减少冗余相关性，抑制部分低方差噪声，并降低对一百万个 token 做聚类的成本。

PCA 本身不会产生群组。它只提供一个更紧凑、数值条件更好的坐标系，使基于距离的聚类方法能够更可靠地比较单个 token。$r$ 应结合方差解释率、聚类稳定性，以及所得群组是否仍然有用和可解释来选择。

## 第五步：对单个 token 表征做聚类

协方差矩阵只是全局摘要，并不会给单个 token 分配群组。真正需要聚类的是每个 token 的降维坐标 $z_i$。

对于 $M$ 个群组，k-means（K 均值）求解：

$$
\min_{c_1,\ldots,c_N,\,m_1,\ldots,m_M}
\sum_{i=1}^N\left\|z_i-m_{c_i}\right\|_2^2,
$$

其中 $c_i\in\{1,\ldots,M\}$ 是 token $i$ 的群组编号，$m_j\in\mathbb R^r$ 是第 $j$ 个群组的中心。

这里的区别很重要：

- 协方差回答“token 沿哪些方向变化”；
- 聚类回答“哪些单个 token 在这些方向上彼此接近”。

不同的点云可能拥有相同的协方差，却具有完全不同的分组结构。

对于一百万个 token，mini-batch k-means（小批量 K 均值）是一个实际的默认方法，因为它处理小批量样本，而不需要反复扫描全部 token。它更适合 PCA 空间中紧凑、近似球形的群组。

如果希望得到软归属概率，可以使用高斯混合模型：

$$
p(c_i=j\mid z_i).
$$

如果不同群组具有明显不同的离散程度、细长形状或强烈重叠，则高斯混合模型或其他能够刻画群组几何形状的方法可能更合适。

## 推荐的完整流程

1. 构造 $A=U^\top X$，其中 $X=[x_1,\ldots,x_N]$。
2. 减去投影坐标的均值，得到 $\tilde A$。
3. 计算 $C=\tilde A\tilde A^\top/(N-1)$。
4. 对 $C$ 做特征分解，保留前 $r$ 个主成分。
5. 构造 $Z=V_r^\top\tilde A$。
6. 对 $Z$ 的各列进行聚类，例如使用 mini-batch k-means。
7. 使用重采样稳定性、代表性样本上的分离度检查，以及所得群组的解释来选择群组数量。

## 适用范围与局限

该方法只能根据所选 500 维子空间中可见的差异来发现群组。两个 token 即使在与该子空间正交的方向上差异很大，投影后仍可能看起来相似。

当 $U$ 标准正交时，token 的正交残差为

$$
r_i=x_i-UU^\top x_i.
$$

如果这些残差差异与应用有关，就需要纳入残差特征、扩展子空间，或者与原始表征空间中的聚类结果进行比较。

## 结合当前研究线：这种方法能够带来什么认识？

### 1. 它补充的是“逐 token 几何”，不是另一种公共基

当前 Mean Response 实验先把每层 Attention-write 汇总成 covariance、谱质心和谱带方差份额。这样的二阶统计可以说明总体方差如何分布，却不能判断单个 token 在候选方向中是否形成群组。

本方法假设参考子空间 $U$ 已经给定，然后保留每个 token 在该子空间中的坐标并研究点云结构。因此它可以把问题从

> 这组方向一共承载多少方差？

推进到

> 这些方向中的 token 是连续散布，还是形成可复现的若干群组？

它不能反过来证明 $U$ 是正确的公共基，也不能仅凭聚类结果定义 $U$ 的参数意义。

### 2. 它可能产生的四种直接认识更新

| 直接结果 | 允许的认识更新 | 仍不能推出 |
|---|---|---|
| 候选子空间中的 PCA 特征值集中在少量方向 | 该子空间内的 token 变化近似低维 | 新增信息低秩；低维方向有语义或功能 |
| 聚类跨重采样和新鲜数据稳定，并超过同维随机子空间 | 候选子空间包含可复现的 token 级群组结构 | 群组是 coarse/fine 类别或专家 |
| 稳定群组在留出标签上具有 coarse/fine 富集 | 该子空间的点云结构与语义粒度相关 | 这些语义是相对旧 residual 新增的 |
| 某些群组随层深出现、消失或分离增强 | 候选几何结构具有层位置依赖 | 深层逐层产生新知识；该结构值得路由 |

因此，相比现有“fine 的归一化方差位置整体更后”的结果，这套方法最多可以把结论推进一层：

> 候选子空间不仅具有总体方差差异，而且内部存在可复现、可能与语义粒度相关的 token 级组织结构。

这是比谱质心或谱带份额更强的几何结论，但仍然是描述性几何结论。

### 3. 它也能给出有价值的负更新

如果候选子空间的聚类不稳定，或不超过 rank-matched random/Haar 同维对照，则更合理的认识是：

> 当前谱位置差异可能只是分散的总体方差重分配，并没有形成离散、稳定的 token 群组。

如果群组稳定但与 coarse/fine 标签不相关，则可以更新为：

> 候选子空间存在非随机几何结构，但当前证据不支持把它解释为语义粒度结构。

这两种结果都会收窄后续解释，而不是简单意味着聚类算法失败。

### 4. 对当前 A15 结果的特殊风险

当前 coarse/fine shape 审计显示，两条归一化谱高度重叠，fine 的平均后移来自谱头份额下降与较后多个离散位置的小幅增加，而不是一个连续、唯一的 fine band。多数层的 coarse 总 raw variance 仍大于 fine。

因此，普通 PCA 有一个明确风险：它按总方差选方向，可能优先保留 coarse、模板、位置或向量尺度变化，丢掉较弱但更具 fine 区分性的方向。若问题是无监督发现自然群组，普通 PCA 是合理工具；若问题是专门检验 fine/coarse 结构，则必须明确中心化条件，并在独立 selection 数据上冻结 fine-versus-coarse 候选方向后，再在新鲜数据中做 PCA、聚类与语义验证。

同样，若每层分别拟合 PCA，所得坐标轴会随层改变；此时只能比较每层内部的群组结构，不能未经方向匹配就声称“同一群组随层移动”。跨层比较需要冻结同一 $U$、同一降维变换，或显式匹配子空间。

### 5. 认识更新的停止边界

这套方法本身不能建立以下结论：

- Attention-write 是 incoming residual 中不存在的新信息；
- 聚类方向就是稳定的粗粒度或细粒度语义方向；
- 一个群组天然对应一个 expert；
- 聚类标签能够降低 Router regret、语言模型损失或改善专家效用；
- PCA 保留的高方差方向就是任务最重要的方向。

要把结论从“语义相关几何”推进到“层新增信息”，仍需证明候选坐标在旧状态之外增加留出目标可访问性。要从“层新增信息”推进到“Router 信号”，还需在匹配负载和专家条件下验证 held-out functional utility。

### 6. 当前最准确的一句话定位

> 子空间投影、PCA 与聚类能够检验候选方向中是否存在低维、稳定并可能具有语义富集的 token 级组织结构；它把总体方差分析推进到逐 token 几何，但不能单独把这种几何认证为层新增知识或可用 Router 分区。
