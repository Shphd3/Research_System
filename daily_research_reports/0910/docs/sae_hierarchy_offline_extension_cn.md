# 离线层级分析：参数为何改变深度，新增层级怎样参与聚类

工作日：2026-09-10。处理Agent：Codex。版本：`offline_extension_v2`。

本附件由研究者明确追加：调整层级分析参数，观察层级是否增加，并对层级增加的情形进行聚类分析；需要直白说明SAE与层级的关系。它属于[完整矩阵计划](sft_representation_audit_plan_cn.md)的G8，原始输出放在新run的`offline_hierarchy/`。主模型的28原子教师先冻结；本附件不凭“更深”自动换教师，不增加新SAE训练或更多模型条件。

## 1. 先理解：我们究竟在改什么

SAE先把每个输入位置的向量分解成最多32个激活原子。30000个原子及编码器权重固定。层级分析随后查看这些原子的共同出现规律，在原子之间连边；改变连边规则会改变图，但不改变SAE本身。

举例：原子C出现时，B1、B2几乎总同时出现，我们把C标成由B1、B2组成的候选组合。若B1又可由D1、D2组合，图就出现C→B1→D1这条路径。这里高层C可以表示更具体、更稀有的组合，不保证它是更宽泛的语义类别。

深度是沿“组合→组成”到叶节点的最长路径长度。叶为0，0–3共有四层。增加一层的含义是找到更长的合格路径，不是神经网络加层，不是多训练了一个SAE，也不是把聚类数从8改成9。

参数可能改变三件事：哪些组成原子有资格被考虑；哪些边或组合通过；遇到多个候选时先选谁。新深度可能来自发现了遗漏中间节点，也可能只是放松要求接纳了不稳定关系。必须区分。

## 2. 三个问题和交付结论

目的：解释旧图为何最大深度3；检查候选池、排序和关系门槛能否暴露更深且有复现支持的结构；进一步观察这些节点能否覆盖足够的真实输入，并形成可解释的分组。

假设是候选池或原排序可能绕过中间原子。最强竞争解释是更深仅因为门槛更松、稀有节点更容易偶然共现，或只在发现缓存上成立。不能把“找到了深度5”当成功目标。

分析顺序：固定SAE与缓存，有限十配置扫描；分别画发现、原规则复现、支持量合格及统一严格复核的图；然后对各配置高层节点做原子分组与固定输入分组。节点来源、关系复现、任务来源分组和模型训练效果各自属于不同证据层。

最终必须分别回答：最大深度增加了吗；增加来自哪条具体路径/哪个门槛；新增路径在相同严格标准下是否仍成立；其激活覆盖怎样；对应分组怎样；不能由此声称什么。没有任何配置更深也是完整结果，不能继续无限扫参直到出现预期图。

## 4. 固定规则：概率与门槛分别是什么

令C为候选组合原子，B为组成原子。正向包含是P(B激活|C激活)，反向包含是P(C激活|B激活)，频率比是count(B)/count(C)。它们满足反向=正向/频率比。因此正向≥0.90且反向<0.70已隐含频率比>1.286；把显式频率门槛1.2降到1.1单独不会新增合格边，这是保留的负对照。

参考配置固定：组成候选池16000；组合发现次数≥50；正向≥0.90；反向<0.70；频率比≥1.2；每组合2–6个组成原子；全部组成共同出现给定C的概率≥0.85；采用historical排序。复现检查：每条边正向≥0.90、反向≤0.70，联合预测增益≥0.02；另要求复现组合次数≥30才称支持量合格。

联合预测增益沿用实际代码：P(C|全部组成同时出现)减max_j P(C|B_j)，不是简单共现更多就有效。发现反向用严格小于，复现用小于等于，忠实保留不偷改。不同gate失败计数会重叠，不能把它们加总当独立被淘汰节点数。

## 5. 怎样判定“层级增加”而不被放宽门槛误导

每配置输出四个视图，均重新计算深度，不借用更宽松图中的原深度标签：

1. 发现图：该配置在discovery选择出的组合及边。
2. 配置内复现图：使用该配置自己的复现规则通过的组合。
3. 配置内支持量合格图：再加复现组合次数≥30。
4. **统一严格复核图：**对该配置发现的组合，统一用复现正向≥0.90、反向≤0.70、联合增益≥0.02、组合次数≥30复核，保留通过组合的全部边，再重算深度。

第四张图保证“更深但标准变了”与“相同复核标准下更深”分开。它不消除发现候选差异，也不产生独立新数据，所以称严格再筛查，不称新的独立验证。

每视图报告最大深度、占据层数、逐层节点数、总边/节点/组件、孤立点、共享组成、hub集中度、跨层跳跃边，以及各层discovery/replication词元覆盖与支持量分布。以H0同视图为基准分别计算深度差。

对所有深度增加的配置，列出每个最深根节点及一条按ID确定的最长路径，逐边报告两个方向包含率、频率比、两split支持、联合增益；保存全部最深根的路径索引。解释新路径是加了新中间节点、改了原组成集合还是仅改复现准入。对未增加的配置也交结果行和至少一条原最大路径，防止只呈现成功配置。

统一停止规则：十配置全部有结果或明确不可构造状态即停止参数探索；不为了达到六层放宽更多门槛、不补造节点、不删除边来消环。检测到环是实现/定义错误，先定位，不能修剪成漂亮图。

## 6. 对什么做聚类？两种图都要交

**原子分组图：一个点是一个SAE原子。**它回答哪些原子的激活关系相近。**输入分组图：一个点是一条固定记录。**根据记录激活了哪些原子，把这些激活投到原子组，得到八维软分配，回答该分组覆盖/区分了哪些输入。原子分开不推出输入就分开，更不推出专家更有用。

每个配置至少分析支持量合格图与统一严格复核图（相同可去重）；保留深度≥2集合与非叶深度≥1集合，前者主读，后者覆盖补充。两集合按各视图重新计算深度，不把H0的28个错误当所有配置节点集。对发现图确实变深、但严格图未变深的配置，也画发现图深度≥2的聚类，明确只在发现阶段成立。这样所有“层级增加的情形”都被分析，又不将失败筛掉。

原子分组算法与主high28保持一致：固定历史discovery词元二值出现，重新构建所选节点集合的正phi图，最多50个正邻居后对称化；≤51个节点保留全部正边。分连通分量分配总8组，孤立点保留为单点分量；分量内部谱分组，主seed17、稳定性seed29/43。组件>8、支持不足、少于8节点或数值不可构造均输出明确资格失败及诊断图，不能自动减组数、删节点、加边或替换成decoder聚类。此情况的聚类解释是“当前8组合同不可构造”，不是漏分析。

当恰8个节点时可一原子一组并标“无聚类压缩”；少于8时不产生八组训练教师。新增配置只作离线分析，不能把seed29/43中较漂亮映射替换seed17主映射。

两类原子图：完整关系拓扑按真实深度分层排布、颜色按谱组；以及discovery/replication激活关系热图按同一组顺序排列。若画二维原子embedding，配置间节点集合/坐标不同，禁止把二维绝对距离跨配置作定量比较；应比较完整维度分组与覆盖。

## 7. 记录级覆盖、任务组成与公平读法

记录级读数优先复用已核验的segment→record缓存与explanation/check划分；该阶段每片段最长256token，统计某原子是否出现，是**片段存在性**，与训练时首个答案位置的**token激活强度**不同，必须分开命名和作图。

对每片段，将选中原子的二值出现按组相加、非零时归一化，记录分数是该记录**已覆盖片段的分布均值**，另报已覆盖片段数/全部片段数；全未覆盖记录的分数保持全0。已核验`record_scores`采用此规则，不能换成最大片段分数或将未覆盖片段偷偷计成均匀分布。无激活记录保持未覆盖，不从分母消失。拟合节点分组用discovery；任何组→来源解释映射只用explanation；最终量与文本示例分区按既有合同，不能拿check调阈值或选配置。

必须报告：总体及每来源记录覆盖、片段覆盖、分配熵、source×group列联、包含未覆盖的宏召回与覆盖内指标并列、条件来源熵、三聚类种子的关系稳定性。来源标签仍不是语义；不能将同数据来源集中直接叫概念纯度。

每组在explanation中按固定规则选中心/普通/边界各一条记录（ID tie-break），列record ID、来源、实际激活原子、短文本和组分数；只写观察到的共同格式/内容，不自动命名“数学推理专家”等。没有原文本映射就标该语义解释不可做，不用另一个缓存的文本假配对。

**覆盖与频率控制：**高层节点经常更少、更稀有。每配置将深度≥2与叶节点做5个频率rank桶、每桶两侧取相同数量、20个固定随机抽样（seed17），固定8组，对每个抽样用三聚类种子。统一用discovery频率选集，不碰check标签；不足8节点或断连过多则该抽样明确不可构造，记录所有20次状态。比较覆盖/分组指标在整个check和两组共同覆盖记录上的差异，不能以删除难样本创造纯度优势。配对record bootstrap2000次仅用于这些已固定对比，不为“挑最深配置”造显著性。

不额外开展层级边打乱、嵌套路由训练或全面功能干预；它们回答边的独立价值，不是本次参数深度与节点分组问题。既有stage2资料只作来源，尚未完成的无关工作不混入本次完成清单。
