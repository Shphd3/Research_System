# S7 原环境适配器契约

用途：把已核对的科学对象接到用户原环境的真实实现。**接口名是本次提案，不是声称原仓库已经有这些函数。**本文件不拥有数据、阈值或主判据；以 [Protocol](../documents/protocol.md) 为准。

## 1. 必須核对的代码与对象

加载源码入口可参考历史 `smoke_sites.py` 与 `resolved_assets.json`，但本轮权重仅取Protocol §7固定的33B完整里程碑，不能使用历史manifest的21B模型键或可变latest指针。执行Agent读取实际源码和权重，再建立适配器。不得把旧的down-only回放直接改名为attention-output回放。

| 返回对象 | 形状与意义 | 检查 |
|---|---|---|
| `W0` | [1024,2048]，末块注意力输出矩阵 | state哈希、真实模块、冻结 |
| `b` | [1024]，原有偏置；若无则零向量 | 不新增可训练参数 |
| `capture_native(ids, mask)` | 每个位置的c[2048]、a[1024]、块输入x[1024] | a=Wc+b，观察值就是原SAE输入 |
| `tail(a, x0)` | [N,1024]→[N,2] | 原残差、归一化、门控前馈、最终归一化、词表行100/101 |
| `encode_readonly(a)` | [N,1024]→字典系数与原空间重构 | 与原生SAE所有预处理相同，不改统计缓冲 |
| `decoder_native_directions()` | [1024,K] | 方向必须在原生a空间，不能遗漏逆预处理 |

不同模型实现可能把归一化、缩放、偏置或decoder转置封装在模块里；必须读取源码而不是按变量名猜。

## 2. 纯下游回放

`tail(a,x0)` 应复现：在最后一块的attention output替换为a后，由固定x0继续运行到二类别logit。必须禁用Dropout、统计更新和所有隐式训练状态；保留原模型真实的非线性计算。

应同时支持：

1. 通过a求导，而其他模型参数全部冻结。
2. 相同a重复调用获得相同输出。
3. 微批拆分不改变样本运算；没有跨样本耦合。
4. 输入a的设备和精度明确；尾部保持FP32数值路径，不自动回退到BF16；数值内核对返回的两个logit以FP64计算条件交叉熵。
5. 不改变原始W0、偏置、字典和任何buffer。
6. 四个独立进程各绑定一张H100，各自加载同一33B state；不做DDP梯度平均，同族配对全部留在同一进程。各进程记录state、代码、配置与basis哈希，rank0合并时拒绝不一致。

原生前向与指定FP32数值路径不是默认同一个数值模型。比较时应让完整前向采用相同FP32覆盖，再与纯tail核对；另记录与完全原生BF16的差异。

## 3. 必须先通过的比对

原生参考样本、同一路径零替换、随机小ΔW三种情况，分别核对：

- 真实观察位置与SAE输入一致。
- 修改后a−原始a与ΔWc一致。
- 完整改后前向与tail回放二类别logit和loss一致。
- 微批数改变不改变源梯度总分母。
- 逐样本e的平均贡献等于目标参数梯度与ΔW的内积。
- 重复零更新的最大loss差记录为ε_repeat，不能用native/FP32之间的系统误差替代。
- 前后完整W和SAEbuffer哈希一致。

如果尾部中存在尚未纳入回放的token交互，当前逐位置独立方案就不成立；必须停机修订，不得用较大的容差掩盖。

## 4. SAE 输出契约

稀疏存储可返回`indices[N,K_active]`、`values[N,K_active]`；统计时按固定完整字典身份累计。只在需要的小批次构造稠密z，避免无谓占用显存。

必须提供原生坐标中的重构a_hat以及对应字典方向。若编码前有逐样本非线性归一化或输入相关尺度，使固定解码列不能解释为原生a的固定方向，应明确记录并阻止当前P投影结论；不能静默当成线性字典。

静态/更新后编码必须复用同一冻结字典。字典量化、归一化或设备差异应写入manifest，不能仅用同一个文件名假定身份未变。

## 5. 失败收据

遇到缺文件、哈希不同、矩阵形状不同、SAE不在更新路径、尾部不可独立回放、重构坐标不匹配、重复噪声过大或显存超预算：写`preflight_failed.json`，包括实际值、预期值、已运行操作及未运行条件。禁止自动换另一个检查点、参数块或SAE。

接口资格通过后再由Agent实现主调度与冻结统计；通过资格只说明测量路径正确，不说明研究假设获得支持。
