## TL;DR

你的理解需要修正为：

> 粗、细区分度都不是随层深单调上升；它们在早中层下降或波动，约从 block 28 开始进入晚层上升阶段，其中细类上升更快，最终形成明显的细类相对优势。

此外，单独的方差不能代表区分度。线性 Router 在一次前向中看不到“总体方差”，只能看当前 token 的线性投影；但训练时，输入 covariance 会改变各方向的梯度尺度和学习速度，而损失函数决定这些梯度是否具有正确的功能方向。

## 1. 区分度是否随深度一直上升？

不是。实际轨迹大致分为三个阶段：

| 层 | 粗类 \(D_c\) | 细类 \(D_f\) | 细/粗比 |
|---|---:|---:|---:|
| block 1 | 0.536 | 0.456 | 0.85 |
| block 12 | 0.301 | 0.309 | 1.03 |
| block 22 | 0.244 | 0.252 | 1.03 |
| block 25 | 0.519 | 0.515 | 0.99 |
| block 28 | 0.710 | 0.938 | 1.32 |
| block 30 | 0.825 | 1.298 | 1.57 |
| block 32 | 0.972 | 1.577 | 1.62 |
| block 35 | 0.871 | 1.590 | 1.82 |
| block 36 | 0.823 | 1.513 | 1.84 |

正确读法是：

1. **早中层：**粗细区分度接近，而且整体有所下降；
2. **block 25 附近：**两者同时跳升；
3. **block 28 以后：**细类上升得明显更快；
4. **最后几层：**两者绝对区分度不再持续上升，甚至略降，但粗类下降得更明显，所以细/粗相对比继续升高。

因此不能说“越深区分度一定越高”，只能说：

> Qwen3-8B 在晚层出现了一次表征重组，使条件内细分类相对粗分类更清晰。

# 2. 区分度指标究竟是什么？

设表征为 \(h\)，类别标签为 \(y\)。

总方差可以分成：

\[
\operatorname{Cov}(h)
=
B+W.
\]

其中：

- \(B\)：类别间方差，表示不同类别中心相距多远；
- \(W\)：类别内方差，表示同一类别的样本散得多开。

## 类别间方差 \(B\)

假设 mechanics 和 optics 各自有一个中心：

\[
\mu_{\mathrm{mechanics}},\qquad
\mu_{\mathrm{optics}}.
\]

类别间方差衡量这些中心彼此的距离。

中心越远，\(B\) 越大。

## 类别内方差 \(W\)

mechanics 有多种描述：

- forces and motion；
- collisions and oscillations；
- orbital motion；
- action-based equations。

这些文本的表征不完全相同。类别内方差衡量它们围绕 mechanics 中心散得多开：

\[
W_{\mathrm{mechanics}}
=
\mathbb E
\left[
\|h-\mu_{\mathrm{mechanics}}\|^2
\right].
\]

所谓“聚得更紧”，就是：

\[
W_{\mathrm{mechanics}}
\]

变小了。

它并不意味着所有 hidden state 数值都变小，而是：

> 同一语义类别的不同措辞、模板和事实描述，在表征空间中的差异变小了。

---

## 区分度 \(D\)

实验定义：

\[
D
=
\frac{\operatorname{tr}(B)}
{\operatorname{tr}(W)+\epsilon}.
\]

人话解释：

> 类别中心之间的距离，相对于同类文本自身的波动有多大。

- \(B\) 大、\(W\) 小：容易区分；
- \(B\) 大、\(W\) 也大：未必容易区分；
- \(B\) 不大、但 \(W\) 很小：仍然可能容易区分。

这本质上是一个信号—噪声比：

\[
\text{区分度}
=
\frac{\text{类别身份造成的变化}}
{\text{措辞和样本差异造成的变化}}.
\]

# 3. “聚得更紧”的具体含义

假设只有一个维度。

### 浅层

mechanics：

\[
\{-3,\;0,\;3\}
\]

optics：

\[
\{1,\;4,\;7\}
\]

两个类别中心有差异，但每类内部很分散，彼此大量重叠。

### 深层

mechanics：

\[
\{0.9,\;1.0,\;1.1\}
\]

optics：

\[
\{2.9,\;3.0,\;3.1\}
\]

类别中心未必比浅层远很多，但同类样本变得非常集中，因此分类边界更稳定。

深层细类区分度的提升主要接近第二种情况：

> 模型把“描述方式不同但属于同一细类”的文本整理到更一致的表征区域。

# 4. 方差是不是最能体现某个方向的区分度？

单独的方差不是。

需要区分四种量：

| 量 | 回答什么 | 能否表示区分度 |
|---|---|---|
| 总方差 \(\lambda_i\) | 自然文本通常沿该方向变化多大 | 不能 |
| 类别间方差 \(u_i^\top B u_i\) | 类别中心沿该方向变化多大 | 不充分 |
| 类别内方差 \(u_i^\top W u_i\) | 同类样本沿该方向有多不稳定 | 不充分 |
| Fisher 比值 | 类间变化相对类内波动有多大 | 可以作为线性区分度 |

对具体方向 \(v\)，更合理的方向区分度是：

\[
J(v)
=
\frac{v^\top Bv}
{v^\top Wv+\epsilon}.
\]

一个方向即使方差很大，如果同类文本也在该方向剧烈波动，仍然没有良好区分力。

反过来，一个低方差方向如果：

- 类别中心有稳定差异；
- 同类内部波动极小；

它仍然可能有很高的 \(J(v)\)。

因此：

> PCA/covariance 方向寻找的是“数据变化最大方向”；Fisher 方向寻找的是“类别信号相对噪声最大方向”。

两者不是同一个对象。

# 5. 粗粒度语义方差是否肯定更大？

不能概括为“每层肯定更大”。

实际结果更复杂：

- blocks 1–2：粗类实际类别间方差在全部 16 个频带都高于细类；
- blocks 3–21：不同频带存在混合关系；
- blocks 23–24：细类实际类别间方差在全部 16 个频带反而高于粗类；
- blocks 25–36：粗类实际类别间方差又在全部频带高于细类。

以 block 35 为例，粗类确实更大：

| 频带 | 粗类 \(B\) | 细类 \(B\) |
|---|---:|---:|
| head | 38.08 | 24.97 |
| middle | 17.49 | 15.04 |
| tail | 15.91 | 13.42 |

但同一层细类区分度仍然更高：

\[
D_f=1.590>D_c=0.871.
\]

因此最准确的结论是：

> 晚层粗类通常产生更大的绝对类别间方差，但细类的类内扰动更小，所以细类具有更高的相对区分度。

不能把它压缩成“粗类方差大、细类方差小”这一条全层规律。

# 6. 线性 Router 能看到方差吗？

## 单次前向：不能直接看到总体方差

线性 Router 计算：

\[
z=Wh.
\]

对于一个 token，它只能看到当前表征在各权重方向上的投影：

\[
w_e^\top h.
\]

它没有显式计算：

\[
\operatorname{Cov}(h)
\]

或

\[
h_i^2.
\]

所以线性 Router 不能在单个 token 上直接问：

> 这个 token 来自高方差分布还是低方差分布？

如果两个类别均值相同，只是方差不同，纯线性决策边界通常无法分开它们。要识别“方差本身”，需要平方、范数、二次特征或上游已经形成的非线性编码。

## 训练过程：会受到 covariance 强烈影响

一般情况下，Gate 的梯度可以写成：

\[
\nabla_W L
=
\mathbb E[\delta h^\top],
\]

其中：

\[
\delta=\frac{\partial L}{\partial z}
\]

是损失函数传回 Gate logits 的误差信号。

在 covariance 方向 \(u_i\) 上：

\[
g_i
=
\mathbb E
\left[
\delta\,(u_i^\top h)
\right].
\]

这里有两个独立因素：

1. \(u_i^\top h\) 的尺度——由输入 covariance 影响；
2. \(\delta\) 是否与该方向相关——由专家能力和损失函数决定。

所以：

- 高方差、无任务相关性：梯度噪声大，但平均有用梯度可能为零；
- 低方差、强任务相关性：有用，但有限训练中可能学得慢；
- 高方差、强任务相关性：最容易被快速学到；
- 高方差、错误相关性：也可能形成危险的捷径。

因此：

> Covariance 决定“哪个方向容易学”，损失函数决定“应该朝哪个方向学”。

这也是为什么固定选择 head 不足以构造好的 Router。

# 7. Router 应该怎样捕捉粗细差异？

不建议直接规定：

```text
head = 粗语义
middle/tail = 细语义
```

因为新实验已经表明，晚层细类区分优势横跨大多数频带，没有稳定的 middle/tail 专属通道。

更合理的是显式学习“区分类间信号、抑制类内扰动”的功能投影。

## 一个诊断性投影

可以寻找：

\[
Pv
\]

使得投影后：

\[
\frac{\operatorname{tr}(PBP^\top)}
{\operatorname{tr}(PWP^\top)}
\]

最大。

它相当于寻找 Fisher 方向，而不是 PCA 方向。

## 一个更实际的双通道 Router

\[
z_\ell
=
W_{\ell,\mathrm{raw}}h_\ell
+
A_\ell P_\ell h_\ell.
\]

其中：

- 第一条通道保留原始表征；
- \(P_\ell\) 提取高区分度、低类内扰动的功能坐标；
- \(A_\ell\) 学习这些坐标如何影响专家分配。

但最终的 \(P_\ell\) 不应只预测 taxonomy 标签，而应预测：

- 哪个专家对该 token 的相对损失更低；
- 哪些 token 放到同一专家时梯度更兼容。

否则只能得到一个好的语义分类器，不一定是好的 Router。

当前只知道 block 输出在晚层发生变化，不知道来自 attention 还是 MLP。

\Delta B,\qquad
\Delta W,\qquad
\Delta D.

> block 28 以后，究竟是 attention 还是 MLP 主要压低了细类内部扰动？

这回答表征形成机制，但不训练 Router。

### Pass 条件

某一分支持续、跨模板地降低 \(W_{\mathrm{fine}}\)，且不是 residual scale 或 LayerNorm 造成的假象。

## 实验 B：分离 covariance 与损失信号的 Router 动力学

构造一个小型四层 MoE 层级任务，独立操纵两个变量。

### 因素一：输入方差

- flat spectrum；
- coarse/fine 信号位于高方差方向；
- coarse/fine 信号位于低方差方向；
- whitened control。

### 因素二：损失函数相关性

- 专家效用与粗变量相关；
- 专家效用与细变量相关；
- 专家效用与谱方向随机置换；
- 无专家相对优势的负对照。

形成一个因果矩阵：

| covariance | loss 偏粗 | loss 偏细 | 随机效用 |
|---|---|---|---|
| flat | 测功能信号本身 | 测功能信号本身 | 负对照 |
| coarse 高方差 | 方差与损失对齐 | 方差与损失错位 | 捷径对照 |
| fine 高方差 | 方差与损失错位 | 方差与损失对齐 | 捷径对照 |
| whitened | 消除速度差 | 消除速度差 | 负对照 |

记录：

- 每个方向的平均 Gate gradient；
- 梯度噪声；
- optimizer 实际更新；
- Gate 对各方向的等能增益；
- 达到稳定路由所需训练量；
- 专家选择遗憾；
- 专家内梯度冲突；
- held-out NLL/FLOP；
- 负载与路由坍缩。

它能真正区分：

\[
\text{信息存在}
\quad\text{vs.}\quad
\text{容易学习}
\quad\text{vs.}\quad
\text{损失函数奖励它}.
\]

# 9. 当前最重要的研究更新

我们现在不应继续问：

> 粗语义在 head、细语义在 tail 吗？

更准确的问题是：

> 不同层中，哪些方向具有较高的“功能信号/类内扰动”比例；输入 covariance 又如何改变 Router 学到这些方向的速度？

因此下一阶段的核心不再是固定谱带 Router，而是：

\[
\boxed{
\text{表征区分性}
\times
\text{covariance 学习速度}
\times
\text{loss 功能相关性}
}
\]

三者的联合动力学。

唯一建议的立即下一步是：先完成实验 A 的 attention/MLP 写入分解，定位 block 28 后细类类内扰动下降的来源；得到这个位置后，再把对应层和变量冻结进实验 B 的小模型因果训练 Protocol。
