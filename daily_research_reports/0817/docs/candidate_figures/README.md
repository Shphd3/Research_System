# 0817 汇报候选图与结论口径

## 主结论一：累计可读性上升，但本层新增是局部的

推荐表述：

> 模型对细粒度语义的累计可读性在深层后段整体快速上升，但每一层 Attention 带来的新增可访问性并不逐层增加。全层同时校正后，只有 block 24、28 得到确认，其中 block 24 的新增收益最大；block 25 虽然点估计为正，但区间跨过 0，仍然未决。这里的“新增”只指当前冻结线性读出族下的新增可访问性。

## 主结论二：功能可压缩到 256 维

推荐表述：

> 在功能正层 block 24、28 上，256 维是最小的注册 PCA 秩，能够在 CONFIRMATION 上通过完整功能保留判据：超过 80% full-\(R_U\) gain 阈值、胜过 64 个同维 Haar 随机子空间，并且全层×秩同时下界大于 0。因此当前证据支持“目标功能可压缩到 256 维”，不支持“功能被完整无损地保留”或“整体表征稳定低秩”。

rank 1–128 均未通过完整判据。PCA gain 高于 full-\(R_U\) gain 可能包含投影与重新拟合读出带来的正则化效应，不应解释成产生了额外信息。
