# 会议总结

## 1. 本次讨论形成的核心区分

### 1.1 表征秩与任务有效秩不同

一个语义对象可以在高维空间中发生变化，甚至在许多坐标上都不同；但若目标只是区分有限类别，一个低维判别投影仍可能保留足够功能。

因此：

\[
\text{表示/生成需要高秩}
\not\Rightarrow
\text{分类/gating 需要高秩}.
\]

### 1.2 宽方差谱可能是多类混合后的总体结果

总体谱很宽，至少有两种竞争解释：

1. 每一种单独语义本身都高秩；
2. 每种语义或每个局部任务较低秩，但不同语义位于不同子空间，混合后整体呈高秩。

现有总体 covariance/PCA 不能区分这两种解释，必须对语义条件化。

### 1.3 token-wise difference 不是干净的新知识

\[
\Delta h_{\ell,t}=h_{\ell+1,t}-h_{\ell,t}
\]

能够刻画同一 token 的状态变化，但其中可能同时包含：

- 旧 feature 的缩放或旋转；
- 来自其他 token 的信息搬运；
- 正负相抵的原子语义成分；
- 对任务无关的计算变化。

因此，difference 是“候选更新”，不能直接叫作“新知识”。

### 1.4 PCA 只保证重构/方差最优，不保证分类最优

PCA 的前几个方向最大化更新方差和低维重构质量。它们是否最适合 gating，必须由留出分类或专家效用验证。

# 最直接的 TODO

## TODO 1：用受控层级语义检验“整体高秩是否来自多种局部低秩语义”

构造或复用父类—子类数据：

- 全部类别混合；
- 固定一个父类，只比较其子类；
- 单独比较一对子类。

分别计算同一层更新的 covariance spectrum 与有效秩。若语义条件越窄，谱明显越集中，则支持“多个局部低秩子空间混合成总体高秩”。

## TODO 2：画任务性能—维数曲线，而不是只画累计方差曲线

对同一个候选更新空间，固定维数阶梯，例如：

\[
r\in\{1,2,4,8,16,32,64,128\}.
\]

比较：

1. PCA 前 \(r\) 维；
2. 随机 \(r\) 维；
3. PCA 尾部 \(r\) 维；
4. 监督判别子空间 \(r\) 维；
5. 完整表征。

主图应是：

\[
r\longmapsto \text{held-out classification gain/accuracy}.
\]

这张图直接区分“几何低秩”与“功能低秩”。

## TODO 3：明确“新 feature”的可计算定义

最低要求应同时满足：

1. 同一个 token、同一 hook 下的合法更新；
2. 排除旧状态可预测的重编码部分；
3. 在新鲜数据上提供旧状态之外的目标增益；
4. 超过同维随机或错配对照。

在满足这四点前，不把差分、PCA 方向或聚类结果直接命名为“新知识”。

## TODO 4：给出一个能在汇报中讲清楚的极简数学例子

使用四个原子方向：

\[
e_c,e_m,e_s,e_p
\]

分别表示组合、数学、固体、物理；构造两层混合过程，并展示：

- 完整更新 covariance 可以占据多个方向；
- 区分“组合数学”与“固体物理”只需一个或两个判别方向；
- 高秩变化与低秩 gating 可以同时成立。
