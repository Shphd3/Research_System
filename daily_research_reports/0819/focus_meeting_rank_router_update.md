**来源范围：**`0817_Missions_会议记录_校订版.md`、`0817_intuition_会议记录_校订版.md`，以及 0819 已完成的粗类—细类确认实验。  
**排除范围：**LoRA 参数更新秩、有限专家长期容量、持续学习遗忘与实际 Router 训练；这些没有被本轮实验直接测量。

## 1. 本次组会主题与核心问题

**主题：**表征很宽时，能否找到真正保留功能、并适合后续分发的低维方向。

**核心问题：**我们现在有多少证据能从“$R_U$ 宽谱”推进到“存在可用于 Router 的低维任务方向”？

## 2. 当前认识更新

我们现在更清楚地知道，宽谱、任务低维和 Router 价值是三件不同的事。不同学科的判别方向确实不完全相同，把它们合起来会增秩；但每个学科内部的完整 $R_U$ 也不窄，因此不能把整体宽谱主要解释为很多窄小子空间叠加。监督学习能在描述性曲线上很快找到少量分类坐标，而 PCA 需要数百维且没有稳健超过同维随机方向；这说明“变化最大”不是“任务最有用”。不过正确配对的 full-$R_U$ 尚未稳定超过错配对照，所以我们还没有正式功能秩，更没有 Router 结论。

## 3. 递进回答

### 3.1 整体高秩是否主要由多个局部低秩空间拼起来？

**直接回答：**本轮没有确认这个强解释。八个粗类的 rank-7 判别基合并后，有效秩约 48.7--48.8，明显超过同粗类重采样 null 的 22.4--25.0；但同粗类谱没有显著更窄，方向稳定性差也没达到注册幅度。

**能到哪里：**可以说不同粗类存在不同判别方向；不能说每个局部空间很窄，更不能说这些局部空间主要造成整体宽谱。

**为什么必须继续问：**即使几何并不局部低秩，具体分类任务仍可能只需少量功能方向，所以要转向未见数据功能而不是继续争论协方差秩。

### 3.2 单个细分类任务能否把 $R_U$ 压到低维仍保留功能？

**直接回答：**正式答案仍是未知。两层 full-$R_U$ 相对只用 $X$ 都有正增益，但相对 duplicate-$X$/错配-$R_U$ 的同时优势下界分别为 -0.0108 和 -0.0196，准入门关闭。因此所有 80%/90% 功能维数必须记 NA。

**最少旁证：**门前描述中，PCA 为 256/512 与 512/512，监督降秩为两层 8/8；但前者没有稳健超过同维随机，后者受 8-way 输出秩上限限制。

**能到哪里：**只能说监督任务坐标可能较低维，不能说 $R_U$ 表征低秩。

**为什么必须继续问：**只有先确认正确 $R_U$ 真有样本配对功能，维数和 Router 才有对象可谈。

### 3.3 为什么 gating 容易对齐 PCA 主方向，却不代表分发最优？

**直接回答：**因为 PCA 和 Router 优化的不是同一件事。PCA 找“哪里变化最大”；Router 应找“送到哪个专家相对更有收益”。大方差方向可能是所有专家共享的主题或表述变化，对专家之间的选择没有区分力；小方差方向反而可能决定专家相对效用。

**最少证据：**本轮 PCA 需要数百维且没有通过随机超额守卫，监督方向更快饱和。这个结果支持目标错位的理解，但没有真实专家，所以只到“不能用 PCA 方差代替路由效用”，不到“某个 Router 设计已经成立”。

## 4. 边界与唯一下一决策

- **已经理解：**表征宽度不能直接决定任务维数，PCA 主方向也不能直接决定 Router；当前最强证据只是“不同语义条件有不同判别方向”，不是“已找到可路由低秩子空间”。
- **仍不能说：**语义本质高/低秩、监督降秩的 8 维是表征秩、PCA/RRR 是最佳 Router 输入、专家学习和遗忘已经改善。

**唯一下一决策：**是否在真实用户请求的新确认集上，先只确认正确配对 full-$R_U$ 能稳定超过 duplicate/mismatch null。  
**完成标准：**至少一个预注册 block 的 full-minus-null simultaneous 95% LCB $>0$；否则停止读取功能维数，也不推进 Router。  
**恢复动作：**审核 CLINC 用户请求实验的 confirmation freshness 与 H-ADMIT 前置计算，不先执行完整维数曲线。
