# 0626 Meeting Brief：真实文本代理分区的发现、初始化与保存瓶颈

## 执行摘要

本次要请导师裁定的问题是：**真实文本中已经能被发现并初始化到门控器的代理分区，为什么不能穿过早期训练？**

这里的“代理分区（proxy）”指没有人工语义标签、但在隐藏状态中可重复出现的分组信号；“隐藏状态”指模型在门控器前看到的向量表示；“文本位置（token）”指输入序列中的一个离散位置；“专家子网络（expert）”指稀疏专家模型中被门控器选择的子网络；“门控器”指决定每个文本位置进入哪个专家子网络的线性打分模块；“归一化互信息（NMI）”在这里只表示分区标签的一致性，不能证明专家子网络有功能价值。

当前结论：**主线位置从“代理分区是否存在”和“能否初始化”推进到“训练是否保存”。真实文本数据流（DCLM）中的代理分区能被发现，也能在第 0 步转成门控器行向量；但普通下一词训练会在第 5/10 步覆盖这个分区。**

最小机制解释：隐藏状态可以分成共同成分、路由相关分区成分和噪声。第 0 步中心初始化能让门控器读出分区成分；但训练反馈很快放大新的共同打分偏置或负载集中，使原来的代理分区不再决定“只选最高分专家”的门控选择。

主边界：这不是“语义专家已经形成”的证据，也不是“代理分区初始化无用”的证据。它只说明：在当前真实文本设置和普通训练目标下，第 0 步按代理分区路由没有被保存。

执行动作：下一张主判定卡应测试**保存控制**，而不是继续证明代理分区存在。完成标准是：固定第 0 步代理标签后，某个训练控制能让第 5/10 步“代理标签和路由结果的一致性”明显高于普通训练，同时语言模型损失不明显变坏。

## 机制解释与最小模型

把进入门控器前的隐藏状态写成：

$$
h = c + r + \epsilon
$$

其中 $c$ 是许多文本位置共享的共同成分，$r$ 是和代理分区相关的成分，$\epsilon$ 是噪声。专家子网络 $e$ 的门控分数是：

$$
z_e = w_e^\top h = w_e^\top c + w_e^\top r + w_e^\top \epsilon
$$

这个模型给出三段裁定逻辑：

1. 如果 $r$ 稳定存在，说明“代理分区发现”可以成立。
2. 如果中心向量能让 $w_e^\top r$ 决定最高分专家，说明“初始化”可以成立。
3. 如果训练后 $w_e^\top c$ 或新的反馈项重新主导最高分专家，说明“训练保存”失败。

因此本次实验不是在问“有没有特征”，而是在问：**已经能被读出的分区，能否在训练反馈下保持。**

## 主结果

**本次完整运行没有推翻主线，而是把主线瓶颈收紧到训练保存：代理分区存在，初始化成立，普通训练覆盖分区。**

### 1. 真实文本中存在可重复的代理分区。

机制对应：如果隐藏状态中确实有稳定的 $r$，两份独立样本估计出的中心应该能给同一批未参与拟合的文本位置分出相似标签。

证据：A06_10 本地完整复现完成 96 行代理分区统计和 72 行隐藏状态审计。第 10 步原始/减均值条件的稳定性 NMI 是 `0.5211`，随机对照是 `0.0002`，频率解释是 `0.0401`，位置解释是 `0.0736`。

解释：代理分区显著高于随机，也不主要由粗粒度频率或位置解释。

边界：代理分区不是语义标签，不能据此声称真实语义专家已经形成。

来源：`Projects/from-attention-to-search/main/experiments/A06/A06_10_real_dclm_proxy_feature_operationalization/summary.md`

### 2. 代理分区中心可以转成第 0 步门控器行向量。

机制对应：如果中心向量能让 $w_e^\top r$ 被门控器读出，那么被选中的专家子网络应该和代理标签一致。

证据：A06_11 本地完整复现完成 264 行门控器统计和 48 行隐藏状态审计。直接使用原始隐藏状态中心的初始化，在原始输入上的“代理标签-路由结果一致性”是：使用第 0 步中心时为 `0.7449`，使用第 10 步中心时为 `0.8811`。

解释：失败不在“代理分区无法线性路由”。直接使用原始中心是当前最强实际初始化；减去共同均值后的中心在“输入也减均值”的诊断中强，但在原始输入上会受共同偏置影响。

边界：第 0 步可路由不等于训练会成功，也不等于专家子网络有功能价值。

来源：`Projects/from-attention-to-search/main/experiments/A06/A06_11_real_dclm_proxy_center_router_initialization/summary.md`

### 3. 普通训练会快速覆盖已经初始化好的代理分区。

机制对应：如果训练反馈重新主导最高分专家选择，那么第 0 步高“代理标签-路由结果一致性”会迅速下降，而语言模型损失不一定异常。

证据：A06_12 本地完整复现完成 12/12 个训练任务和 288 行轨迹记录。直接使用原始中心初始化时，“代理标签-路由结果一致性”从第 0 步的 `0.7549` 降到第 5 步的 `0.0410`，第 10 步的 `0.0131`。第 10 步语言模型损失是 `10.7222`，和随机对照的 `10.7190` 接近。

解释：这不是训练崩掉，而是普通训练目标把路由从代理分区拉走。当前失败点是训练保存。

边界：不能推出所有保存方法都会失败；只能说明当前普通训练设置失败。

来源：`Projects/from-attention-to-search/main/experiments/A06/A06_12_real_dclm_proxy_init_training_preservation/summary.md`

## 失败分析

本次真正失败的是两件事。

第一，真实文本数据流的普通训练保存失败。失败表现是：第 0 步分区强，但第 5/10 步接近随机。最可能机制是早期训练反馈改变了门控打分的主导项，使共同偏置、负载集中或专家子网络输出反馈覆盖原来的代理分区。语言模型损失正常说明它不是优化崩溃。

第二，A06_18 的无标签路由相关状态筛选没有通过。稀疏自编码器、主成分分析和瓶颈自编码器都没有接近“只用路由位置”的正对照。原因是这些方法主要优化重构、方差或压缩结构，不直接优化“路由位置是否可读”。稀疏自编码器重构误差很低，但特征一致性 NMI 反而不够，说明“重构隐藏状态”不等于“找出路由相关分区”。

关键区分：

```text
代理分区发现没失败；
第 0 步初始化没失败；
通用表征筛选和普通训练保存失败。
```

## 对主线的更新

主线更新为：

```text
层级 1 代理分区发现：已有真实文本支持
层级 2 初始化：已有真实文本第 0 步支持
层级 3 训练保存：当前瓶颈，普通训练失败
层级 4 功能价值：不能直接进入，除非先保存住分区
```

这意味着下一步不应继续扩大“代理分区是否存在”的证据，也不应直接声称功能价值。最小科学问题已经变成：

```text
哪一种训练控制能让第 0 步代理分区穿过第 5/10 步？
```

## 执行动作

下一步主判定卡：真实文本代理分区的早期保存控制。

目的：裁定普通训练覆盖代理分区路由的机制是否可以被控制。

最小条件：

| 条件 | 作用 |
| --- | --- |
| 普通训练 | 失败基线 |
| 冻结门控器 / 延迟更新门控器 | 判断是否是门控器更新直接破坏分区 |
| 降低门控器学习率 | 判断是否是门控器更新过快 |
| 负载或共同偏置控制 | 判断是否是共同偏置或负载集中主导 |
| 代理分区保存辅助损失 | 判断显式保存信号能否穿过第 5/10 步 |

主指标：固定第 0 步代理标签后的第 5/10 步“代理标签-路由结果一致性”。

约束指标：语言模型损失不能明显变坏；最大专家负载不能只是换一种集中到少数专家子网络的失败。

通过标准：任一保存控制让第 10 步“代理标签-路由结果一致性”明显高于普通训练的原始中心初始化基线，并且语言模型损失接近随机对照或普通训练基线。

失败标准：所有保存控制都只改善负载或语言模型损失，但“代理标签-路由结果一致性”仍接近随机。若失败，下一步拆分门控器更新、隐藏状态漂移、专家子网络输出反馈三个来源。
