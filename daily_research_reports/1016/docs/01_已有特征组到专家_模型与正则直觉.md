# 已有特征组怎样分给专家：优化问题与正则项

> 2026-10-16。仅补充用户报告中的“模型”部分，不重写报告结构。
> **这是后续建模提案，不是本轮已执行的分发方法。** 当前完成的是固定分发下的末端适配器对照，尚未训练本文正则化router。

#### 一、先用一分钟说清楚

我们已经通过共同激活关系得到若干feature组。下一步不是重新把feature拆开分组，而是在给定K个专家时，决定**哪些现成的组交给同一个专家**。

直觉是：尽量把频率接近、又有较强联系的组交给同一专家，同时避免某个专家接收过多输入。然后把这个分配作为候选标签，给router一个训练正则，使它倾向于按该方案选专家。

这里先讨论top-1路由；若实际使用top-k，需另定义多个槽位的标签和负载，单个专家交叉熵并未完整规定top-k分发。

这里有三个不同对象：**feature组 → 组到专家的分配 → 输入到专家的路由**。一个输入会激活多个组，因此中间必须明确“按哪个组来决定这个输入的专家”。最后还要用真实预测损失判断这个分配是否有用。

#### 二、一个不需要公式的例子

假设有四个已经确定的组、两个专家：
- G₁、G₂内部主要是相对低频的feature
- G₃、G₄内部主要是相对高频的feature

只考虑组内同频，会倾向于G₁/G₂共用专家1，G₃/G₄共用专家2。

但还有两个限制：
1. 如果G₁与G₃有很强的联系，把它们分开可能牺牲原来的关系
2. 如果G₃/G₄对应绝大多数输入，专家2会过载，专家1利用不足

因此问题不是“先规定同频一定最好”，而是：**为了组内同频，需要牺牲多少关系、造成多大负载差异；这种取舍有没有学习收益？**

此外，G₁内部若已经混有高低频feature，在不拆组的前提下，无论把G₁交给哪个专家，这个组内差异都还在。

#### 三、输入与符号

| 符号 | 含义 |
|---|---|
| M | 已有非空feature组数，本轮关系图为186 |
| K | 专家数；当前对照为4，后续模型可固定为指定K |
| G_g | 第g个已有feature组；这里假定所选组互不重叠 |
| n_g=\|G_g\| | 第g组的feature数量 |
| p_i | feature i在发现侧D的激活频率，要求为正 |
| a_i=log₁₀p_i | feature i的log频率 |
| μ_g、v_g | G_g内a_i的均值与总体方差 |
| A_gk | 二元变量，组g是否交给专家k |
| B_gh | 两个已有组之间的非负关系权重 |
| ρ_g | 在固定组判别规则下，组g被选中的输入比例 |
| q_k | 专家k的输入比例 |
| λ、δ、β | 分别控制频率取舍、允许的负载偏差、router正则强度 |

所有统计、分配阈值和超参数选择只使用发现/训练侧；复核侧用于评价。

#### 四、先固定输入属于哪个组

**这一步不能省略。** 设g*(t)为位置t在固定组评分规则下的获胜组。可以复用当前“组内激活比例经发现侧标准化，再取最高分”的规则；并列规则固定。

- 多组同时激活：当前最简模型取一个获胜组，不声称其他组的信息消失
- 没有合格组命中：使用预先规定的默认分发，单独报告覆盖率
- 以下负载ρ、q先定义在“有合格组命中”的输入上；实际全体输入负载还需加入默认分发部分

g*(t)应由冻结参考模型和CrossCoder或预先缓存标签得到；只冻结评分公式而让产生激活的模型继续变化，并不能冻结标签。标签只使用该预测位置已有的因果前缀，不使用真实下一词答案。若离线参考使用了后续模型层，部署时的router仍只能读取当前路由位置已有的hidden，不能在线借用尚未计算的层。

这一选择是为了先写出完整可执行模型，不说明top-1获胜组是最佳表达方式。若后续改为软组归属或top-2，需要相应重写负载与正则，而不是沿用同一公式。

#### 五、完整的组到专家优化问题

**1. 分配约束**

\[
A_{gk}\in\{0,1\},\qquad \sum_{k=1}^K A_{gk}=1,\qquad \sum_{g=1}^M A_{gk}\ge1.
\]

每个现成组交给一个专家，每个专家至少接收一个组；需K≤M。

**2. 专家内feature频率差异**

\[
\mu_g=\frac1{n_g}\sum_{i\in G_g}a_i,\qquad
v_g=\frac1{n_g}\sum_{i\in G_g}(a_i-\mu_g)^2.
\]

令n=Σ_g n_g，专家k承接的feature平均log频率为：

\[
c_k=\frac{\sum_g A_{gk}n_g\mu_g}{\sum_g A_{gk}n_g}.
\]

定义频率差异目标：

\[
F(A)=\frac1n\sum_{g,k}A_{gk}n_g\left[v_g+(\mu_g-c_k)^2\right].
\]

**如何理解：**专家内部的频率差异，来自“每个原组内部已有的差异v_g”，以及“被合并的各组均值不一致”。

因为每组只能被分配一次，Σ_g n_g v_g/n是常数。后续优化只能减少组均值间的混合差异，**不能修复原组内部已经存在的混频**。这是本建模最重要的限制。

**3. 保留组间联系**

设W_ij为原正phi互选图的边权，定义：

\[
B_{gh}=\sum_{i\in G_g}\sum_{j\in G_h}W_{ij},\qquad g\ne h.
\]

将强联系组分到不同专家的代价为：

\[
C(A)=\sum_{g<h}B_{gh}\left(1-\sum_kA_{gk}A_{hk}\right).
\]

使用总边权意味着大组可能有较大权重，这是明示的设计选择。若没有组间边，C恒为0，说明该关系图本身无法指导进一步合并，不应伪造连接。

**4. 真实输入负载约束**

在有命中组的输入上定义ρ_g=P(g*(t)=g)，于是：

\[
q_k=\sum_g\rho_g A_{gk},\qquad
\frac{1-\delta}{K}\le q_k\le\frac{1+\delta}{K}.
\]

ρ由输入统计得到，不能用组内feature频率相加代替。δ≥0决定允许偏离均匀负载多少。如果单个组的ρ已经超过上限，硬分组必然无可行解；即使每个单组都未超上限，也可能因整组不可拆而无法凑出满足上下限的分配。应实际检查可行性并报告不可行，再讨论拆组、软分发或调整负载约束，不能偷偷改条件。

**5. 优化目标**

\[
\min_A\; C(A)+\lambda F(A)
\]

满足上述约束。λ≥0表示愿意为降低频率差异付出多少关系切分代价；两项尺度与λ选择规则需事先固定。用不同初始分配及组移动/交换可作近似求解，不保证全局最优。

#### 六、怎样变成router的正则项？

求得候选分配A*后，位置t的专家候选标签为：

\[
y(t)=k\quad\text{当}\quad A^*_{g^*(t),k}=1.
\]

令π_θ(k|h_t)为router基于原始hidden表征h_t给专家k的概率，θ为router参数。对有组命中的输入加入：

\[
R_{\rm group}(\theta)=-\mathbb E_t\log\pi_\theta(y(t)\mid h_t).
\]

联合训练目标可写为：

\[
L=L_{\rm NTP}+\beta R_{\rm group},\qquad\beta\ge0.
\]

- L_NTP：正常下一词预测损失
- R_group：鼓励router与候选组分配一致
- β：这个先验对训练的影响程度；β=0是没有该正则的对照

**这是一种候选伪标签正则，并不证明标签是好的。** 当标签与预测任务不合适时，正则越强可能越差。硬分配方案的负载约束也不保证训练后的router实际负载相同，必须重新测量。

正则的意义是让“关系分组”进入训练目标，形成可检验方法；它没有直接最小化损失意义上的干扰。

#### 七、必须区分两种“专家内同频”

F(A)使用的是**被分给该专家的feature列表中，各feature的全局频率**。但专家实际接收完整输入，其中可能包含别组feature与common成分。

真正进入专家的事件频率应另测：

\[
p_{i\mid k}=P\big(X_i(t)=1\mid r(t)=k\big),
\]

其中r(t)是实际路由。它与p_i并不相同。

因此，论文或报告应区分：
1. 候选列表更同频，属于优化设计
2. 实际进入专家的输入是否更同频，属于需要验证的路由结果
3. 学习是否更好，属于最终效用检验

不能把第1步当成后两步已成立。

#### 八、可直接补入你原报告的简要版本

> 固定已有feature关系组，给定K个专家，我们优化“组到专家”的分配。目标是在控制输入负载的条件下，尽量将频率接近且联系较强的组交给同一专家。由于不拆开原组，这一步只能减少不同组被混合产生的频率差异，无法消除原组内部已有的差异。随后，按固定规则确定每个输入的获胜组，将组分配转成专家候选标签，并用交叉熵正则引导router。该正则只是候选先验，最终还需检查实际输入频率分布和下一词预测损失，不能由组内同频直接推出学习收益。
