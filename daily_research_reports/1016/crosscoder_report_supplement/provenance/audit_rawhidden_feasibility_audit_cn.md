# 原始 hidden 命中位置谱：可行性与推理审计

处理者：Codex `/root/spectrum_audit`。时间：2026-10-16。此次只检查已有缓存接口与命中支持；没有计算原始 hidden 的经验谱，没有新增模型前向或训练。

## 可以使用的真实对象

`analysis/relation_learning/20261015T164000Z/data_eval512/eval.pt` 确实保存 `hidden[523136,1024]`，BF16；producer `data_routes.py` 把 `raw[:,-1,:]` 直接写入，并没有用 decoder 重建或用适配器输出替代。这是 Qwen3 第 28 个 block 的 residual-post，位于最终 RMSNorm 之前。

同一 payload 同行保存 `feature_ptr[523137]`、`feature_ids[132917355]`、唯一的 `position_id[523136]` 和 `block_id[523136]`（512 个 context）。CSR 中是完整正门控激活 feature ID；没有系数 z 的数值。定义“组内至少一个 feature 在此位置激活”只需 binary ID，因此不缺该命中规则所需数据。若改为需要激活幅度的组得分规则，本缓存没有 z 值，不能暗中补作。

该缓存来自原 CrossCoder **TRAIN** bin `local-shard_2_of_10_shard_00000247_processed.bin` 的固定 512 个 context；它曾作为适配器学习实验 EVAL，但不是结构分析的 V。字典训练见过该文本来源，原始文档和近重复独立性仍未知。不能将这里的 hidden 与旧结构 V 的 z 按行拼接；应将固定 D feature 分组应用于这里同一 payload 的 CSR。

结构 V 的旧 phase1 cache manifest 只声明 CSR ptr/ids/z，不含原始 H。本次在指定 experiment 的有界文件名检查与命名 cache 中没有发现可与整个结构 V 逐行配对的原始 H；这是本次访问范围内的发现，不是断言所有存储上不存在。

## 可比较的固定规则

可复用已冻结的 D 合格池 15,666 个 feature、组大小 14、同频与混频各 1,119 组，各 feature 在每种方案恰用一次。旧 186 个 phi 关系组大小不相同，不能把“关系组”写成“同频组”，也不能将其未经大小匹配混入该主比较。

建议将每组命中定义固定为“CSR 中至少有一名组内成员出现”。分别从每组命中位置无放回抽相同 N 个原始 H，固定种子、位置抽样方式与层，再按位置减组均值，计算样本协方差。位置可在不同组间重复，各组不是独立重复；相邻位置也不是独立文档。

支持计数独立复核结果见 `rawhidden_support_only.json`：同频组最少 240 个命中位置，混频组最少 49,566 个。全部组都支持 N=128；N=256 会有 1 个同频组不够，N=512 会有 18 个同频组不够。若目标保留整个 D 池，N=128 是无需剔组的共同预算，但它不是估计充分性的证明，也不是最优样本数。选择必须在看 raw H 谱前冻结。

## 对象与解释边界

该谱回答：“被某组成员命中的文本位置，其完整模型原始 hidden 在多少方向上变化？”它不同于贡献谱的“固定位置集上，该组 feature 的重建贡献如何变化”。raw H 也包含其他 feature、未被该 CrossCoder 重建的残差以及共享上下文信息。

虽然两种方案使用同一 hit rule，但混频组中一个高频成员即可让很多位置命中，而同频低频组只能覆盖少量位置。这种输入集合选择本身就是两种规则的部分差别。因此观察到的谱差异不是该组固有维数，也不是频率异质性的单变量效应。应报告命中总数、抽样后不同 context 数、最大单 context 占比，以及原始的组平均 D 频率分布；不得只展示一个均值而省掉支持差异。

N=128 下位置中心化的样本协方差秩最多 127，这个上限由样本数带来，不是模型真实维数或容量。可用位置 Gram 的特征值与 1024 维协方差的非零谱严格等价，但不能拿 decoder Gram 或参数谱冒充。全零总方差仍记不可估计；两种方案相同 N 可消除直接秩预算差异，不能消除相关样本、来源选择和有限样本偏差。

无论方向如何，最强许可结论是固定模型、层、命中规则、分组及该缓存出处下的输入条件统计差异。它不证明“同频更适合共同学习”，也不补足已有配对训练的缺失收益。若结果与贡献谱不同，应保留对象区别，不把其中一项解释成另一项失败的修正。
