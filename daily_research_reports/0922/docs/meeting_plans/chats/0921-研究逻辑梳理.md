## 一、我们想怎样研究这个问题

我们现在研究的是：**把 SAE 引入模型训练，作为一个与任务损失共同优化的约束，它究竟会怎样改变模型的表征空间。**

Growing SAE 是实现这一目标的一种方式：可以增加字典容量，也可以增加旁支。但我们首先需要理解 SAE 约束本身做了什么，再讨论如何增长，而不是默认字典更大、重构更好，就意味着模型更好。

我们希望得到类似理解 L1、L2 正则项时的清晰直觉：L1 偏好稀疏解，L2 惩罚较大的范数；那么，**有限字典、Top-K 激活和重构损失共同引入了什么偏好？这个偏好遇到真实模型的数据与表征，会产生什么变化？**

研究应当沿着下面这条逻辑展开：

[
\text{任务与数据的性质}
;\rightarrow;
\text{当前表征如何编码这些性质}
;\rightarrow;
\text{SAE 目标施加什么约束}
;\rightarrow;
\text{编码方式发生什么变化}
;\rightarrow;
\text{这种变化如何影响任务}.
]

这里有几个明确的要求。

\*\*首先，要从可解释的假设推出观察，而不是先堆指标。\*\*聚类、分类准确率、可分性、梯度夹角，都只是测量工具。必须先说明它们测的是什么，以及什么结果支持或反对我们的机制假设。

\*\*其次，要区分“把信息看出来”和“把表征改好了”。\*\*在冻结表征上训练 SAE，发现了一些语义相关 feature，只说明 SAE 提供了一种读取已有信息的方式；不能直接推出，让 SAE 参与模型训练就会改善表征。

\*\*第三，不预设变化一定是有益的。\*\*我们首先问“它怎么改变”，然后才问“这种改变是否有利”。重构误差变小，可能来自更一致的编码，也可能来自字典适应能力增强，甚至可能来自有用差异被压缩。这些情况需要分开。

\*\*第四，不把某一个语义任务当成全部问题。\*\*我们过去观察过：原始表征不容易按 domain 聚类，但某些 SAE features 有明显的 domain 选择性。这是动机和线索，不是所有分析必须围绕的结论。我们真正关心的是更一般的编码结构。

因此，当前的目标不是先证明“SAE 让语义更可分”，而是建立一个足够具体的解释：

> **在什么数据条件下，SAE 约束会让模型以怎样不同的方式表达任务信息；这种改变何时有益、何时无效、何时可能有害。**

## 二、我们当前做了哪些假设和思考

### 1. 起点：信息存在，但整体距离不一定能体现它

我们考虑的现象是：

- 原始表征不容易通过直接聚类得到我们关心的类别；
- 但给定标签后，可以学到区分这些类别的线性读出；
- SAE 中则可能存在少量与这些类别明显相关的 features。

这里的“线性可读出”指存在合适的线性分类器，不是任意线性方法都能成功。

为解释这一现象，我们提出一个候选模型：

[
h\_i=Uc\_i+Vs\_i.
]

其中 (c\_i) 表示跨类别共享的变化，例如表达方式、上下文等；(s\_i) 表示与目标语义有关的变化。两类方向不必正交。

如果共享变化的幅度更大，整体距离就可能主要反映共享变化，而不是目标语义；有标签的分类器则可以学会减弱前者、读取后者。

这里的 common 不是所有样本完全相同的固定偏置，而是**各类别都会使用、但在样本之间变化的成分**。固定偏置不会改变样本之间的距离。

因此，我们目前的假设不是“语义不存在”，而是：

> **语义差异与其他变化叠加在一起，整体距离没有自动赋予目标语义更高的重要性。**

这只是能解释现象的一种假设，还不是已经证实的数据生成机制。

### 2. 理想 SAE：把叠加的变化分别记录

进一步假设：这些成分能在数据中以不同组合出现，而且每个样本只需要少量成分。

在稀疏分解成功的理想情况下，可以有：

[
D\approx[U\ V],
\qquad
z\_i\approx
$$\begin{bmatrix}
c\_i\\
s\_i
\end{bmatrix}$$,
\qquad
h\_i\approx Dz\_i.
]

这表示：**原来相加在同一个表征向量里的变化，现在由不同激活坐标分别记录。**

它不是消除 common，也不是必然把不同类别推得更远，更不要求每个语义恰好对应一个 feature。

这个结果依赖假设。如果两个成分总是共同出现，SAE 可能直接学出一个捆绑成分，而不是把它们拆开。因此，Top-K 和重构目标本身不保证发现真正的语义原子。

### 3. “挑出语义 feature”实际上引入了选择规则

假设 SAE 已经把不同成分分别记录，挑出语义相关坐标意味着：

[
z\_i\longmapsto P\_{\mathrm{semantic}}z\_i.
]

这一步是在决定：哪些变化参与比较，哪些变化暂时忽略。

因此，可能出现的好处不是增加了信息，而是：

> **原来需要组合许多原始坐标才能读取的信息，现在可以通过少数 SAE 坐标读取。**

但 SAE 不会自动知道我们关心哪种语义。如果依靠标签选择 features，应当明确区分：分解是无监督的，选择是有监督的。完整 SAE 编码里仍有 common 成分，所以也不保证直接聚类就能成功。

### 4. 联合训练：表征和字典相互适配

我们讨论的核心目标可以写成：

[
\mathcal L(\theta,\phi)
=======================

\mathcal L\_{\mathrm{task}}(\theta)
\+
\lambda,
\mathbb E\_i
\left|
h\_\theta(x\_i)
---------------

D\_\phi z\_\phi(h\_\theta(x\_i))
\right|^2,
\qquad
|z\_\phi(h\_i)|\_0\le K.
]

前提是重构梯度确实传回模型，而不是只更新 SAE。

这个过程中，同时存在两个动作：

- \*\*字典适应表征：\*\*寻找适合整批数据的共享方向。
- \*\*表征适应字典：\*\*调整编码，使样本更容易由少量字典方向组合出来。

所以不能把它简单描述成“表征靠近固定的基”。基也在移动，而任务损失同时约束模型必须保留什么信息。

目前最清晰、最不依赖语义假设的理解是：

> **SAE 正则偏好：整批任务表征能够用一套有限的共享字典，每个样本只使用少量方向来准确表达。**

这是“稀疏可表示性”的偏好，不自动等于语义可分性、正交性或组合性的增强。

### 5. 在当前假设下，我们关心的具体改变

假设同一种任务相关成分，在不同上下文中使用的方向还有一定差异。联合训练可能让这些表达方式更一致：

> **同一种成分更多地沿着共享方向表达，样本之间的差别更多体现为“使用哪些成分、使用多少”，而不是每个样本都改变成分的表达方向。**

这是我们当前提出的一个具体机制假设，而不是已经得到的实验结论。

它也有明确的其他可能：

- SAE 主要通过调整自身适应表征，模型编码变化很小；
- 原本已经能准确稀疏重构，重构项几乎没有进一步改变表征的动力；
- 模型缩小了难重构的变化，但其中可能包含任务需要的信息。

因此，**重构变好不足以区分这些情况**。我们接下来真正需要判断的是：变化来自字典、来自表征，还是来自两者；如果来自表征，它是在重新组织信息，还是在削弱信息。

### 6. Growing 的位置

在固定 (K) 的理想优化问题里，增加字典容量，会扩大可用的稀疏表达方式，使最优重构误差不增。但这意味着约束更宽松，**不等于表征一定更有结构，也不等于组合性一定增强**。

所以 growing 的问题应当接在机制之后：新增容量是在容纳必要的表达差异，还是让字典更容易适应现有表征、从而减弱对模型的约束？

我们目前已经明确的是研究问题和候选机制。尚未确定的是：**真实模型中主要发生哪一种相互适配，以及它是否改善了任务所需要的信息编码。**

这里才是**机制假设**。

“我们希望领域更容易读出”是研究目标；“SAE 要求少量字典方向能够重构表征”是方法性质。二者之间，并没有天然的等号。

> SAE 的目标究竟偏好什么？这种偏好在什么数据条件下，才可能带来我们希望的结果？

导师在会议中反复要求“用了什么手段—这个手段具有什么能力—得到什么结果”，指向的正是这个缺口。

## 二、学长给你的长篇思路，可以压成一个清楚的知识框架

### 第一层：我们实际做了什么？

当前旁路方案中，SAE 读取注意力输出投影后、残差相加前的向量。这里统一记为 $a$。

SAE 输出稀疏系数 $z$，并得到重构 $\hat a$。**正常语言模型继续使用的是原始 $a$，不是 $\hat a$**；旁路通过重构损失影响训练。这一点在仓库报告中写得很明确。

因此，必须分开：

> **原生表征 $a$ 有没有变化；SAE 系数 $z$ 怎样记录它；重构 $\hat a$ 保留了什么。**

不能把“重构更容易分类”，直接算作“正常模型使用的表征更容易分类”。

### 第二层：这个目标直接偏好什么？

只写与当前讨论有关的部分：


$$L=L_{\mathrm{LM}}+\lambda\,\mathbb E\|a-Dz(a)\|^2,
\qquad \|z(a)\|_0\leq K.$$


它最直接的偏好是：

> **整批表征能够共用一套有限字典，并且每个样本只需要少量字典方向，就能较准确地表达。**

这叫“稀疏可表示性”的偏好。

它没有直接规定：哪些是领域信息、哪些是表达风格；没有规定不同领域必须分开；也没有规定同一种语义必须永远使用同一个方向。

所以，学长长文中最应该保留的一句话，就是：

> **先理解 SAE 约束在偏好什么，再研究这种偏好是否有利。**

### 第三层：为什么“重构变好”仍然有多种解释？

联合训练中，字典和主干都在动。

重构误差下降，可能是字典更会适应现有表征；可能是表征变得更容易被共享方向表达；也可能是模型削弱了原来难以重构的变化。

这些情况的研究意义完全不同。

尤其要注意：

> **“更容易重构”只说明重构任务更容易了，并没有告诉我们，容易的原因是信息组织更好了，还是某些差异不见了。**

你们当前真正值得研究的，是这几个过程如何区分，而不是先给所有变化贴上“改善”的标签。

### 你原来的 $h=Uc+Vs$ 模型，应该放在哪里？

它适合解释一个起始现象：目标语义 $s$ 可能已经存在，但样本距离被其他变化 $c$ 主导，因此直接聚类不明显，有标签的分类器却仍能读出类别。

这里的 $c$ 是**各类别都会出现、但样本之间会变化的成分**，不是所有样本相同的固定偏置。

不过，这个模型只能说明“存在这种可能”，不能证明真实表征就是这样产生的，更不能直接推出 SAE 会优先保留 $s$、压缩 $c$。

**模型的价值在于产生可检验的区别，不在于写出来以后就把它当成事实。**

Growing 也应放在这之后：在固定 $K$、且扩容后仍能保留原方案的理想优化问题中，增加字典容量不会使最优重构误差变大；但它也可能让字典更容易适应原表征，从而减弱主干重新组织编码的必要性。这不是自动的机制进步。

## 三、你昨天的具体说法，应该怎样修改？

### 先把“梯度正交”这条逻辑彻底理清

我们用一个**简化数学推导**，而不是再增加一个实验指标。

令 $g$ 为语言损失对共享主干参数的梯度，$r$ 为已经乘上正则系数的重构梯度。固定同一个参数点、同一个批次和学习率，比较一次普通梯度下降：


$$L_{\mathrm{LM}}\bigl(\theta-\eta(g+r)\bigr)
-
L_{\mathrm{LM}}\bigl(\theta-\eta g\bigr)
=
-\eta\,g^\top r+O(\eta^2).$$


它说明：

**在这个局部、一阶、普通梯度下降的近似下，正交意味着辅助梯度没有提供额外的一阶语言损失下降项。**

这不等于长期没有作用；但它显然不能直接推出“下降更快”或“数据效率更高”。

而你们测到的是**原始梯度**，不是 AdamW 作用后的实际参数更新；报告还指出，方向符号随训练点和批次改变。因此，不能把某个平均夹角解释成长期稳定的优化机制。

所以，梯度分析应该先有一个目的，例如：

> **我要检验：低 loss 能否用“重构梯度持续沿语言损失下降方向提供额外推动”解释。**

对应当前结果，合理的结论是：

> **现有梯度结果没有建立这种持续同向推动的解释；低 loss 的成因仍未确定。**

这就是完整的“目的—假设—证据—判断”。梯度不需要删掉，但需要重新摆正它的职责。

### 其余几句话，也需要把对象和边界写出来

| 原来的说法 | 建议改成的说法 |
|---|---|
| “旁支 SAE 并不能让 domain 信息更容易读出。” | **在本轮 N8 面板和主要读点上，没有确认稳定的领域读出改善。**不能扩大成所有 SAE、所有数据上的否定。 |
| “强 SAE 正则让空间更加奇异。” | **本轮 S7 版本在该读点的方差更集中于少数方向；SALL 则更分散。**不要把有效方差维数下降直接叫作数学意义上的“更奇异”。 |
| “强 SAE 正则让 feature 更稀疏。” | **S7 的截断前正得分更集中，固定面板使用的原子种类更少。**这与每个词元最终保留多少个非零系数，是不同统计对象。 |
| “前32个原子与第33个及以后差异很大。” | **S7 的头部整体更集中，但没有发现第32名处的自然断崖。**头部质量集中不等于恰好在32处突然截断。 |
| “减小正则，优化阻力变小，所以训练效率提高。” | **在图示运行和训练窗口内，较小系数的训练语言损失更低；造成这一差异的机制尚未建立。** |
| “CKA 较低说明表征变好了。” | **CKA 较低说明当前测量下样本关系结构的一致性较低；它不负责判断哪个空间更好。** |

这些不是单纯的措辞润色。例如，N8 第8层的 Top-32 正得分占比，SALL/S7 是 **11.37%/86.80%**；但第32/33名相对差的中位数只有 **0.68%/3.61%**。因此，“头部更集中”有证据，“天然在32处截断”没有证据。

### 还有一个比说话顺序更重要的问题：你混用了不同实验身份

**21B 表征分析中的 S7，不是始终使用系数1的 S7，而是约15.466B之后从1改为0.1的重加权续训版本。**仓库报告明确提醒，不能把它与 SALL 的差异归因于“系数”或“旁路层数”这一个因素。

因此，你截图中的“注意 S7 的正则项系数为1”，用于这组21B分析时需要修改。

同时，10B 的梯度测量、21B 的表征审计、另一组系数消融训练曲线，也不能因为都叫“S7”，就拼接成同一个机制的连续证据。

**以后每张主图下面至少固定：模型版本、训练词元数、系数历史、测量位置、数据与汇聚方式。**这不是增加形式负担，而是避免在不同对象之间无意跳跃。

## 五、昨天的报告，建议怎样重写？

你的截图目前“目的”主要讨论领域组织，“结论”却先讲 loss 和梯度。听众刚接受了一个问题，马上被带到了另一个问题，所以很难跟住。

我建议本次把标题改成：

### **SAE旁路改变了表征，但领域组织改善尚未建立：本轮假设修正**

下面仍然保留你们要求的四段式。这里是对已有研究的**回顾性梳理**，不是声称这些机制条件当时已经全部预注册。

### 目的

> 理解 SAE 作为训练约束时，改变的是表征的哪些性质，以及这些变化是否使任务相关信息更容易使用。本轮先以领域组织为具体检验对象，区分几何变化与领域可读性的变化。

这个目的比“证明语义更可分”开放，但又没有宽泛到什么都能往里放。

### 假设

> 我们原来的候选解释是：SAE 的稀疏重构压力可能减少与领域无关的类内波动，同时保留领域间差异。若这一解释成立，则类间/类内比值应提高。另用固定形式的线性分类器，检查领域信息是否更容易读出。

这里需要主动说一句：

> **线性读出和 $B/W$ 是两个不同检验，不要求它们在所有情况下同步变化。**

这样就不会把“Fisher 高，所以分类一定更好”作为隐藏前提。

### 分析方法

> 在相同输入、相同读点上，比较 Dense、SALL 和明确标注谱系的 S7。先分析正常模型实际使用的原始注意力输出，而不是 SAE 重构。用领域分类检验可读性，用 $B,W,B/W$ 检验类中心与类内散布；再用方差谱和 CKA 定位几何变化。激活排序用于检查 SAE 的编码方式，不作为领域改善的替代证据。

### 结论

> 在主要读点上，SALL 的领域读出仅有小幅正差，而 $B/W$ 下降；其类间差异减小、类内散布增加，未支持原来“类内压缩、类间保留”的解释。S7 的表征和激活更集中，但领域读出更差。因此，当前证据支持把“几何发生变化”与“领域组织改善”分开，尚未建立二者之间的有益机制链。

随后另起一句，而不是接“因此”：

## 六、没有好假设的时候，怎样训练？拿你们自己的机制做一个例子

你不需要一开始就提出一个很深刻、很正确的理论。

一个有用的初步假设，需要做到的是：

> **它解释一个重要现象；它与至少一个竞争解释不同；有某种结果会迫使你修改它。**

“假设简单”不是问题。“无论结果怎样都能解释，而且不会改变下一步”才是问题。

### 第一个练习：尝试反驳一句看起来很合理的话

拿学长给你的候选机制：

> SAE 会促使同一种任务成分，在不同上下文中使用更一致的表达方向。

先不要立即安排大实验。问：

> **能否构造一个满足 SAE 目标、任务也完成得很好，但不同上下文仍使用不同方向的例子？**

可以。下面是一个**用于检验推导的玩具反例，不是真实模型结果**。

设同一个非负任务因素为 $s$，上下文有两种。模型分别这样编码：


$$a(s,0)=(s,0),\qquad a(s,1)=(0,s).$$


字典就用水平、竖直两个方向，每个样本只激活一个原子，即 $K=1$。

这样，两个上下文都能被精确重构；下游只要把两个坐标相加，就能恢复 $s$。任务信息完整，重构误差也为零。

但是，**同一个因素在两个上下文中使用的方向仍然完全不同。**

这个反例让我们得到一个非常明确的认识更新：

> **稀疏重构本身，不足以强迫同一种因素跨上下文统一方向。**

这并没有否定学长的研究方向，而是告诉我们，这个机制还需要额外条件。例如：字典容量是否不足以容纳所有上下文特定方向？复用方向是否能节省某种实际受限的资源？数据组合是否让捆绑编码难以维持？

注意，这些现在是**新的待研究条件**，不是已经证明的答案。

### 这就是你所说的“数学建模”应该怎样落地

不是先写一个很大的模型，而是：

> 把一句直觉变成明确条件 → 构造满足条件的例子 → 看结论是否必然成立 → 用反例找到缺失条件。

你们下一轮很适合先研究这个更具体的问题：

> **什么条件下，跨语境复用同一个方向，比为不同语境各存一个方向更有优势？**

我的建议是先完成这一轮纸面建模，再决定是否做小型受控实验。暂时不需要因此重训现有语言模型，更不需要立即展开 Growing。

### 怎样判断自己是不是又在钻牛角尖？

在继续一个细节之前，问自己：

> **如果这个问题得到相反答案，我会改变哪一个研究判断或下一步选择？**

例如，“32处有没有自然断点”的不同答案，会改变你能否把32解释成数据的自然尺度，因此值得检验。

但已经知道没有自然断点之后，如果继续反复更换排序图样式，却仍然回答不了预算是否足够、信息是否保留，那么这个细节就不再是当前主问题。

另外，**每轮都有当前假设，不等于每轮必须创造一个新假设。**一个假设可以经过多轮核对、推导和检验。每轮也不必强行证伪：保留、缩小适用范围、排除一个竞争解释，或承认当前检验没有区分力，都可以是诚实的更新。

## 七、怎样把它变成每天能执行的习惯？

你们 Research System 的 `research-progress-core` 已经要求：

> 判断 → 竞争解释 → 最小检验 → 直接结果 → 边界 → 决策。

它还明确区分观察、解释、主张、猜测和下一步，并允许未知保持未知。你不缺另一套更复杂的系统，缺的是让这套已有规则进入每轮工作。 

### 每轮结束，用六句话关闭这一轮

直接放进现有的 Focus 或迭代记录，不必再造一个平行文档体系：

```text
1. 本轮问题：我现在要减少哪一个不确定性？

2. 当前判断：我认为在什么条件下，什么过程会导致什么结果？

3. 区分办法：我的解释和竞争解释，分别预期看到什么？

4. 本轮所得：实际观察到了什么，或推导出了什么？没有做什么？

5. 认识更新：因此保留、削弱或排除哪个判断？仍然不能推出什么？

6. 唯一下一步：下一轮只解决什么？什么结果会让我停止或换方向？
```

一次纸面反例推导，也可以填满这六行。**推进不是必须新增一张实验图。**

### 日常表达练习：每天约15分钟，练同一个内容

**前5分钟：不看材料，写四句话。**  
只写“问题、当前解释、关键证据、认识更新”。写不出来的位置，就是需要澄清的思路缺口，不要立即让 AI 替你补上。

**中间5分钟：检查所有“因为、所以”。**  
对每一处问：“前面的条件能否真的推出后面的结论？有没有前者成立、后者不成立的反例？”昨天的“正交→效率”和刚才的“稀疏重构→方向统一”，都可以用这个办法检查。

**最后5分钟：录一遍一分钟发言。**  
回听时只检查三件事：听众是否知道你在回答什么；每个“它”是否有明确指代；你是否把解释当成了结果。不要一轮同时修正十种表达习惯。

Status: DRAFT_AWAITING_PRIMARY_METRIC_CONFIRMATION

Parent anchor:
`15_17_three_model_sae_representation_trajectory_anchor.md`

Problem key:
`sae_shared_direction_reuse`

## 1. Problem Definition

The parent A15_17 question asks how a sidecar sparse autoencoder (SAE)
constraint changes the language model's native attention-write
representation, rather than merely changing the SAE reconstruction.

The current local observation is narrower. In the existing 21B frozen audit,
the layer-8 N8 mean representation had reported variance effective dimensions:

- Dense: 15.45
- original SALL: 18.63
- reweighted S7: 13.72

The same audit also found a much more concentrated SAE atom usage pattern in
S7. On the fixed N8 observer panel, SALL layer 8 used 17,060 distinct atoms,
while S7 layer 8 used 142.

These measurements do not yet form a mechanism claim because they were not
registered as one aligned sample-level comparison. They also do not establish
a causal effect of regularization strength: S7 and SALL differ in sidecar
placement and training history in addition to coefficient history.

The local decision question is:

> On exactly the same examples and token mask, is S7's lower native
> attention-write effective dimension accompanied by stronger cross-sample
> reuse of the same SAE atom identities than SALL?

This is the smallest current mechanism question because Top-K sparsity is only
a per-token constraint. It does not mathematically imply that different
examples share the same small set of directions.

A positive result keeps shared-direction reuse alive as a candidate mechanism.
A negative result stops this explanation and redirects the investigation to
dictionary geometry or coefficient covariance.

This anchor does not decide whether lower effective dimension is beneficial,
semantic, causal for language-model loss, or caused specifically by a larger
or smaller SAE coefficient.

## 2. Physical Priors

The relevant representational prior is:

> If global low-dimensionality is produced by reuse of a common sparse
> dictionary support, then different examples must repeatedly use overlapping
> atom identities.

Per-token sparsity alone is insufficient. Two examples can each use only
32 atoms while using disjoint sets of 32 atoms, yielding sparse local codes
without a low-dimensional global support.

Therefore, observing low native effective dimension without increased
cross-sample atom reuse falsifies shared-support reuse as the main explanation
for this local observation.

## 3. Falsifiable Hypotheses

### H1: shared-atom reuse mechanism

S7's lower effective dimension is accompanied by stronger reuse of the same
SAE atoms across different examples.

Prediction:

- sample-level SAE usage profiles are more similar in S7 than in SALL;
- global SAE usage is concentrated on fewer atom identities;
- the lower native effective dimension reproduces on the same examples.

### H2: geometry/covariance rival

Low effective dimension does not require increased reuse of identical atom
IDs. Different examples may continue to use different atoms while:

- the corresponding decoder directions become geometrically aligned; or
- the coefficient covariance occupies only a small number of joint directions.

Prediction:

S7 can retain lower native effective dimension without showing higher
cross-sample same-ID reuse.

The current experiment tests the necessary prediction of H1. It does not yet
fully separate decoder collinearity from coefficient covariance if H1 passes.

## 4. Mathematical Model

For example $i$, valid token $t$, and SAE atom $j$, let


$$I_{itj}
=
\mathbf 1
\left[
j \text{ is selected in the token's Top-K SAE support}
\right].$$


Let $T_i$ be the number of valid body tokens and $K=32$. Define the
sample-level atom-usage distribution


$$u_{ij}
=
\frac{1}{T_iK}
\sum_{t=1}^{T_i} I_{itj}.$$


Thus $u_i$ describes how one example distributes its Top-K selections across
the SAE dictionary.

**AI_PROPOSAL — primary reuse metric pending researcher confirmation**

Define cross-sample reuse as the mean pairwise cosine similarity


$$R
=
\frac{2}{n(n-1)}
\sum_{i<k}
\frac{u_i^\top u_k}
{\|u_i\|_2\|u_k\|_2}.$$


Higher $R$ means different examples repeatedly select more similar atom
identities.

For the native pooled attention-write vectors $a_i$, the aligned analysis
will use covariance participation-ratio effective dimension,


$$d_{\mathrm{eff}}
=
\frac{(\operatorname{tr}\Sigma_a)^2}
{\operatorname{tr}(\Sigma_a^2)}.$$


This exact implementation must be checked against the existing A15_17
effective-dimension computation before Protocol promotion.

The mechanism predicts


$$R_{\mathrm{S7}} > R_{\mathrm{SALL}}$$


together with


$$d_{\mathrm{eff,S7}}
<
d_{\mathrm{eff,SALL}}$$


on the same examples.

These inequalities are necessary observations for H1; they do not establish
that reuse causally produced the effective-dimension difference.

- the same N8 examples;
- the same valid body-token mask;
- layer 8;
- each model's own 30,000-atom online SAE;
- Top-K = 32.

S7 is not assumed to correspond to atom 123 in SALL. The experiment compares
within-model reuse statistics and then compares those scalar statistics across
models.

For each example:

1. read the Top-K atom IDs for every valid token;
2. form the sample-level usage vector $u_i$;
3. compute cross-sample reuse within each model.

Separately, compute the native attention-write effective dimension using
exactly the same examples and pooling rule.

N8 domain labels are not used anywhere in this mechanism audit.

## 6. Minimal Falsification Tests

The decisive comparison is


$$\Delta R
=
R_{\mathrm{S7}}-R_{\mathrm{SALL}}.$$


**AI_PROPOSAL — statistical rule pending confirmation**

Use paired resampling of example IDs and recompute the complete statistic for
each resample.

Proposed verdict rule:

- **Pass:** the 95% interval for $\Delta R$ lies above zero, and the same
  aligned panel reproduces lower S7 native effective dimension.
- **Fail:** S7 reproduces lower native effective dimension, but the 95%

The remaining uncertainty is whether these measurements align at the
