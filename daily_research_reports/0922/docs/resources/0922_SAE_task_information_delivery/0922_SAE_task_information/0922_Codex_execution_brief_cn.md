## 六、分析顺序与停止条件

### 1. 先做 dev 读出资格

低强度历史模型的 a 按注册规则做同容量线性读出，四家族全保留。

- a 通过：进入下述主诊断。
- a 不通过而 r_out 通过：局部读点基线不足；可报告较完整表征诊断，不裁定“局部信息被删掉”。
- 二者都不通过：报告任务/读法资格不足；几何统计仍可交付，不继续调模型或扩大探针直到成功。

### 2. 核心读数只保留三类

**同面板集中：** 在本轮任务面板、相同读点/池化计算中心化有效维数、总方差、均值向量范数。旧192条自然文本的均值谱不能代替当前短句末词元的谱。若当前面板没有更集中，标明现象的输入/读点依赖性。

**任务读出：** fit-only中心化、整体RMS归一化；固定形式L2逻辑回归，dev按CE选α，两个模型对称。目标为平均CE+α||w||²/2，必须核对库参数与样本数的映射。保存收敛状态和逐样本概率、预测、标签。

主差值 ΔBA=高强度历史−低强度历史。只有95%区间下界高于−0.02，才按建议容忍度称不劣。区间宽不是相同；不得把未显著下降称信息保留。输出各家族结果，不用平均掩盖局部退化。

**相对表达变化：** 使用完整配对结构，按实体组、家族等权，计算正文第7.3节的 T、V、Q=V/T 与 ΔlogQ。T为同模板关系反转的平方距离；V为同事实不同表达的平方距离。必须输出T、V原值和fit-only总方差归一化值。Q更低不单独证明有益，也不能说所有表达变化都是LM噪声。

### 3. 必要解释控制，避免扩成扫描

对主读点 a 做两模型对称的 fit-only岭白化全维探针，规则见正文。若 r_out 也下降、且需要据此讨论更完整表征受损，再按同一预登记规则补 r_out 的白化控制；不能只给某一个模型换读法。

原始读出下降而白化恢复，优先报告尺度/条件数解释。都不恢复，也只说明指定线性读法的可读性下降，不是互信息删除。

PCA读出只作**条件性附加**：主任务通过资格后，利用同一缓存在fit无标签拟合，固定r=4/8/16/32/64，保留full参考，不能按test挑最好秩。不要让它阻塞三项核心结果。它是离线读出，不是模型内因果消融。

### 4. NLL 护栏

复用17B审计的192条自然文本。正常主干前向，固定input与预测mask，保存每记录的NLL总和与有效目标数；正确causal shift与padding。按有效目标token全局加权，比两个谱系的差值。

没有预先确定实用等价边界时，不把跨零区间说成语言性能相同。这个小面板也不能代替完整验证集或证明关系任务会被模型使用。

## 七、统计与实现底线

以独立实体组为单位，组内方向/模板/家族整体保留；两个模型共用bootstrap索引。BA、CE和Q从已冻结预测/配对距离重算，不在每次bootstrap重训探针。区间条件于现有fit/dev和训练种子；不是跨训练种子的因果平均效应。

若多个实体对共享实体，核查原设计要求，必要时按实体连接分量分组；仅更换pair ID不等于新实体。明确记录每个视图实际独立组数；旧“40组”来自旧联合留出，不能默认本轮相同，更不能默认足以排除2pp下降。

距离/协方差汇总使用足够精度。零总方差、T≈0、缺配对、超出可拟合PCA秩或探针不收敛，写不可裁决原因，不用填零或任意epsilon产生好看的分数。

最少代码检查：整体缩放不改变Q和有效维数；标签随机化不应产生跨组真实泛化；所有拟合变换只从fit学习；自检结果与真实模型结果分开。
