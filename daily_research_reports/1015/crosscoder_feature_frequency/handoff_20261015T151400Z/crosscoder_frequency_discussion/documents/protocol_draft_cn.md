## 1. 对象、计数与科学问题

一个输入是固定原上下文中的一个有效 token 位置 x。feature i 是固定 CrossCoder 的一个潜在坐标；同一位置的所有选定模型层共同产生一份 z_i(x)，不是每层独立样本。解码范数是重建方向的大小，不是命中概率。

现有缓存已应用原编码器的固定 TRAIN 阈值。以缓存中严格正的门控后 z 定义事件：

\[
a_i(x)=\mathbf{1}[z_i(x)>0],\quad n_i=\sum_x a_i(x),\quad n_{ij}=\sum_x a_i(x)a_j(x),\quad p_i=n_i/N.
\]

N 是该分析侧的有效位置数。p_i 是出现频率；不是词频、平均幅度、解码层占比或概率分布的一个互斥类别，所以各 p_i 之和不必为 1。共同出现仅指同一位置，不混用窗口/文档共现。原始计数必须先保存，派生量不能取代它们。

group 是由正向共同出现关系形成的候选 feature 集合。它不是专家、因果模块或已确认语义。主分组互不重叠；同一输入可以命中多个组。common 指相对于多个组对应输入都常出现的 feature，不能直接把全局 Top10 当全部 common。

H1a 的最强竞争解释是边际频率、位置激活预算及少量来源/文本重复足以产生结构。H1b 的最强竞争解释是关系指标、筛边和分组算法本身偏好同频。H2 还面临容量、曝光、样本难度、学习目标和分配冲突等竞争解释，本轮不解决。

## 3. 数据划分与独立性：先限定能回答什么

真正的文档级设计应先找回 original_document_id 和 near_duplicate_group，再按文档/重复组整体分配发现侧与未接触确认侧。划分不得依据激活、频率或希望得到的组。来源字段保留；先报告来源内结果和来源混合结果，再讨论来源效应，不能把所有来源差异当噪声消除。

当前可复用 D/V 是旧 split_manifest.json 中 128 个连续 context 一块的分配，N_D=5,238,097、N_V=5,247,663，共 81 块。两侧均已接触；context 不是原始文档，连续块也不保证不同文档。故主建议保留这些集合做缓存内探索，不重新包装成未接触确认集。

文档映射、近重复隔离和来源分层映射当前不齐备。此缺口不阻止频率描述和条件于缓存的结构检查，但阻止“在独立文本上复现”这一完整 H1 判定。本轮不自动建立新数据或全量编码。若研究者要求文档级结论，先选择已有可映射替代数据并确认范围，另行记录所需编码授权。

统计观测单位为位置；不确定性单位应为文档/重复组。无原文档时，最低仅按完整 context 或既有连续块重采样，并明确其独立假设尚未核实；不能使用 token 独立二项检验或 token bootstrap 获得过窄区间。原验证窗口已暴露这一事实不因重新划分而消失。

特殊 token、padding 与有效位置遵从原 index/excluded_ids，不为本轮改变分母。缺失、重复 key、无穷值、负 z、CSR 重复 feature ID、层/哈希/split 不匹配均为测量阻断；不静默剔除或补值。

## 4. 单项分析的四个环节

### 4.1 频率分布与稳定性：哪些 feature 在本窗口可靠可测？

输入为完整 D/V 边际、81 块边际和 CSR/context 索引。复用 feature_frequency.npz 做频率排名与 D/V 对照；如需 context 覆盖数则从 CSR 定义统计，不能把 81 块命中数当文档数。幅度均值单独列，不混入频率。

发现侧定义候选池 P，随后冻结。主建议使用命中计数和覆盖独立单元数作为可靠性条件，排除 p_D=0 或 1 的 phi 不适用项；所有其余 feature 仍保留在总体频率表中。n_min、最少覆盖文档/context 数和可接受区间宽度为待定，不能照搬旧 n≥200 视作新问题已验证标准。选择规则是：先查看已有计数与覆盖，再在获批的校准样本上按目标精度/可估计覆盖选择，记录完整可靠性曲线后冻结，不按同频结果调参。

零命中只表示该侧窗口未见。V 中零命中/支持不足不用于回删 P，也不任加 epsilon；相应 log 频率或组读数不可估计，报告覆盖并进入证据不足分支。

输出：全 F 的 n/p/侧别/覆盖/幅度诊断/可靠性标记，发现侧固定 rank，按文档或条件性块重采样的频率区间及秩稳定性。Spearman 仅辅助，须展示低频和零命中。稳定性好只支持测量范围内可重复；不建立天然层级。若区间宽或覆盖少，后续将此类 feature 标为未裁定，不能认定无关系。

### 4.2 关系：是否超出高频背景和激活数量约束？

先从完整共同计数分块派生下列量，定义域 0<p_i,p_j<1：

\[
p_{ij}=n_{ij}/N,\quad P(j\mid i)=p_{ij}/p_i,\quad \mathrm{lift}_{ij}=p_{ij}/(p_i p_j),
\]

\[
\phi_{ij}=\frac{p_{ij}-p_i p_j}{\sqrt{p_i(1-p_i)p_j(1-p_j)}}.
\]

AI 建议 phi 作主关系量：对称、有符号、扣除独立边际背景。必要敏感性读数为 log2(lift)，同时显示原始支持和覆盖；罕见事件的高 lift 不能单独选边。负关系另存诊断，不用于本次正向共同出现组。

phi 不消除频率偏好。若 0<p_i≤p_j<1，则即使 i 完全包含于 j，其正向上界也仅为：

\[
\phi_{\max}=\sqrt{\frac{p_i(1-p_j)}{p_j(1-p_i)}}.
\]

同频上界可为 1，频率相差大时上界较低。因此“不把频率距离放进聚类目标”仍不足以避免同频循环。

AI 建议主图：只在发现侧可靠池 P 内计算；保留有足够共同支持、phi>0 的每个节点前 q=10 个邻居，仅互选者连无向边，权重=phi。并列按稳定 feature ID。q 是控制图规模的工程提案，不是显著性阈值；共同支持阈值待定，随可靠性规则冻结。q=20 只作一项必要敏感性，不据其 H1/H1b 结果挑赢家。候选池不能先按相近频率分箱后分别建图。

度数最多 q，因此边数至多 Fq/2=81,920；完整 pair 读数仍可保存磁盘分块表。边只叫筛选关系，不声称数百万条边分别显著。若未来要逐边检验，须另定 family、有效检验和 FDR；当前用两个全局端点校准，避免少量随机样本伪装逐边 p 值。

### 4.3 分组及同频：指标之外是否仍有结构？

唯一主分组为正权无向图上的贪心加权模块度合并，建议 resolution γ=1；不指定专家数或预期组数。目标比较组内实际边权和同强度节点的期望边权，不包含组内频率距离。复用已存在的 NetworkX 环境；具体版本、稳定 ID 顺序和并列行为在获批实现时冻结，未合格则停止，不临时换算法。没有边、仅 singleton、一个大团或对 q 敏感，都如实报告。不得强迫得到漂亮分组。

在 D 上固定候选池、图规则和组 G_D。V 使用同一 P 与规则独立构图分组 G_V，不按 V 调参数。若某固定成员在 V 中 p=0 或 1，保留其候选身份并标记 phi 不可估计，不计算 0/0、不把未定义关系填成 0；该节点无可估计边，相关组的复现及覆盖损失明确记录，不回删候选池。H1a 全局复现端点 T_a：D 的非 singleton 组与 V 非 singleton 组按成员 Jaccard 做一对一最大总权匹配，除以 D 非 singleton 组数；未匹配组贡献 0。D 没有非 singleton 组时 T_a=0 并报告结构未形成。额外 V 组不直接扣分，此为有向复现读数。

同时必须报告非平凡组数、覆盖、最大组占比和冻结 D 组在 V 的组内平均 phi。只有一个大团时高匹配不能证明有用分组；非平凡组数/覆盖/效应的最低实际意义标准待研究者确认，不能事后定线。

H1b 用 V 频率评价已冻结 D 组。对所有固定成员均可估计的组 g，定义以十进制频率数量级为单位的离散度：

\[
\ell_i=\log_{10}p_i^V,\quad \bar\ell_g=|g|^{-1}\sum_{i\in g}\ell_i,\quad D_g=\sqrt{|g|^{-1}\sum_{i\in g}(\ell_i-\bar\ell_g)^2}.
\]

越小表示组内频率越接近。主汇总对组等权，feature 等权的汇总另列；singleton 不参加。缺失成员导致该组不可估计，不靠删成员改善 D_g。缺失组的数目、成员数和覆盖必须进入总体判定；总体有效覆盖的最低要求待定，未确认/未达到则证据不足。

最低充分对照有三项，各回答不同问题：

1. 同候选池、同组大小的随机分组：检验是否比任意装组更同频。保持整套组大小序列，随机排列成员后顺序分箱；不逐成员匹配频率。
2. 组平均 log 频率匹配对照：按同样组大小从 P 抽候选组，用 D 的组平均 log 频率匹配真实 D 组均值；不使用 V 匹配或筛选。建议容差从 D 频率动态范围和可获得候选数定，待定；容差、最大尝试数及不足处理在 V 读数前冻结。报告逐组匹配误差，不能强行用坏匹配。V 只用于评价。候选组可跨随机重复复用，重复数与随机种子固定。
3. 保留行列边际的全流程 null：保留每个 feature 的命中总数和每个位置的激活数，在相同有界样本上重新做支持筛选、建图、分组、匹配对照及全部端点。它检查指标和算法偏好，前两项不能替代。

主频率效应 T_b 是各有效组的 D_g 减其均值匹配随机组在 V 上 D_g 的平均，再组等权；负值支持更同频。效应量同时给 dex、相对对照差异和区间，不仅给 p。简单随机组与匹配组结论冲突时完整报告，不选择有利一个。

### 4.4 组到输入：能否把候选结构变成可检查的分配对象？

对每个非平凡组定义 score_g(x)=命中的组成员数/组大小。主建议在 D 上确定每组命中阈值，并至少有两个成员同时命中；阈值依据固定的参考命中率上限/随机基线，而非 V 例子是否漂亮。具体参考率和阈值待定，先保存分数分布和不能达到规则的组。冻结后在 V 对所有有效位置独立判断每组是否命中。

报告未命中、恰一组命中、多组命中比例（分母均为全部 V 有效位置，三者和为 1），另给各组覆盖与组间命中 Jaccard。不得强制 top-1 隐藏多组冲突。组 ID 不是专家 ID，也不是语义标签。

文本定位复用旧 index/tokenizer/inspection 逻辑。每组建议随机 5 条与高 score 5 条，随机 seed 待冻结，按不同 context 去重，不按文本意义筛选；保存抽样母体、位置、可见完整前文、目标 token、激活成员及原 z、其他组命中。高 score 内按 score、激活幅度、位置 ID 预定顺序；截断只用于表面展示，完整可见上下文留执行侧。右侧文本若展示须标“仅供阅读、模型此位置不可见”。

主社区互不重叠，“跨组 common”因此定义为 feature 在多个组对应输入上的命中率 c_ig=P(a_i=1 | g 命中)，而非声称它属于多个主社区。若 i 本身参与组命中，诊断时用排除 i 的 score 计算，防止自包含。common/区分性阈值待定，此项只作诊断，不将全局高频直接删掉；不从真实模型表征移除共同成分。

输入大量多组命中会削弱“一组对应一个 top-1 专家”的直接映射，但不自动否定结构或所有路由方案。文本表不能替代总体统计，也不能独自证明语义纯度或学习收益。

## 5. 可承担的随机基线、统计与停止规则

### 5.1 最小主问题版本与校准子样本

全量缓存负责描述与候选发现，避免再编码；其旧 D/V 是 exposed review。为使保边际基线的成本有界，AI 建议另固定 S_D、S_V：各从对应侧按 context 位置 key 的带 seed hash 取 128 个完整原 context，再在每个 context 内按位置 key 固定取 32 个有效位置，最多各 4096 个位置。抽样只依原始位置身份，不依 z、频率、组或文本意义；不足 32 时保留实际数，显式记录。保留原模型可见上下文，不对抽到的位置重新编码。

在 S_D/S_V 上从头走相同分析，包括独立用 S_D 定 P、组及匹配参数，用 S_V 评价。不能把全量发现的组直接当子样本内无选择偏差的发现。子样本支持不足的低频 feature 是未覆盖总体，不能外推。子样本 null 的 p 值只校准这个子样本流程，不用于给旧全量图、全量边或原文档 H1 签发显著性。

### 5.2 保边际交换的适用范围

每侧单独把稀疏事件矩阵的合法 2×2 子矩阵 [1,0;0,1] 与 [0,1;1,0] 互换，禁止重复边。提案需对称，拒绝保留为自环；确切提案分布和实现待资格测试冻结。每次随机化保持全部行度 k_x 与列命中 n_i，记录 seed、提案/接受数和边际完全一致性。它控制激活数量约束，但不能完整模拟 Base/CrossCoder 的连续机制、文档相关或数值阈值几何。

至少两条独立 seed 链，按 accepted swaps/nnz 的预定递增检查点监测与原事件重叠、phi 分位数、组数/大小及 T_a/T_b。检查点、burn-in、间隔和可接受链间差异尚待小资格检查的时间/混合记录，不编造“交换几次就已充分混合”。诊断平稳只是必要条件。若链仍漂移、系统差异、拒绝率很高或预算内不能合格，则 null 失败，停止推断，不自动加长。

AI 建议正式目标 B=99 个近似合格随机化对，每个包含独立随机化的 D/V 两矩阵；两条链提供的有效样本数与自相关必须报告。B 不是 99 个独立文档。Monte Carlo 分辨率最低 1/(B+1)=0.01。若有效 B 太小，不给精细 p 值；不得声称逐边 FDR。相关 MCMC draws 不等于独立可交换的 null；ESS 只作诊断，不能直接替代秩公式分母来制造有效 p 值。

每个 null 都执行同样的候选筛选、正 phi/支持筛边、互选邻居、同一分组算法、D 均值匹配随机组和 V 评价。不得保留真实组不变然后声称已消除算法同频偏好。若某次 null 没有非 singleton 组，T_a 按既定规则为 0；T_b 若无可估计组则未定义。不得丢掉此类 draw 重抽凑足 B，也不得填 0/epsilon。正式前必须固定对真实/null 共同适用的可估计覆盖标准；任何一方不满足，记录失败比例并将 H1b 校准标为证据不足，不计算选择性秩 p 值。source-stratified null 仅在获得可靠来源标识后作为必要定位；当前只能标缺口，不能凭 context ID 冒充来源。

### 5.3 端点、区间和多重比较

T_a 越大支持复现，T_b 越负支持同频。用 (1+至少同样极端的 null 数)/(B+1) 给单侧近似 Monte Carlo 校准，并对这两个预定义全局端点做 Holm 校正，建议 familywise α=0.05。原 H1 的两个子判断都需成立；Holm 只是这两个端点的保守控制，不是逐边或逐组发现许可。Holm 对有效 p 值才有其通常错误率含义；这里相关链产生的是近似条件校准，不能声称已经保证名义 FWER。null 混合或依赖假设不合格时不得使用“显著”措辞。

冻结组后用文档/重复组整体 bootstrap 估计频率效应及输入覆盖区间；现有缓存只能给条件于 context/连续块假设的区间，建议 1000 重复。每次保留完整组及缺失标记，不能在重采样中删失低频成员。T_a 的成员稳定性另报，不能把固定组 bootstrap 称为重新发现稳定性。若需 T_a 区间须重新构图分组的整块重采样并单独预算，当前不列最低必需运行。

n_min、覆盖阈值、实际重要性 δ_a/δ_b、最小组/总体覆盖要求、匹配容差、输入阈值、null 资格参数与资源上限均为待定。建议由 D 上精度与可行性校准后确认并冻结；不能用 V 效果或最终 p 选阈值。无实际意义界限时，只报告效应，不把未显著等同于“不存在”。

## 7. 规模、时间、峰值内存与资格阶段

以下推导只用已保存尺寸和历史运行收据，未启动新计数/计时。硬件方案仅是预算提案，不是资源申请；当前不新连接设备。

完整 CSR 的逻辑 payload 约 16.10 GB，D/V 两份 int64 全 pair 矩阵共约 4.295 GB。按流式 chunk 和 mmap 读取，不必整体驻留。禁止 N×F×F（约 2.81×10^15 单元）和无约束 N×F 稠密事件矩阵。

对第 x 行 k_x 个命中，稀疏枚举成本是 Σ_x k_x(k_x−1)/2；用平均 L0 254.54 代入仅得到约 3.38×10^11 的粗略下界尺度，真实成本还取决于行度方差/高尾。已有全计数直接复用。F×F 输出允许受控磁盘/mmap，并非禁止一切二维矩阵。

子样本每侧最多 4096 行，以平均 L0 估算 nnz 约 1.04×10^6、unordered pair 约 1.32×10^8。B=99 的 D/V 全流程 null 约 2.62×10^10 pair 更新，另有交换、计数实现与分组开销；不得把 198 个矩阵当一次计算。交换成本按实际提案/接受数另计。保留输出摘要和种子，随机矩阵串行处理，不保存 198 份全 F×F 矩阵。

历史实测：旧 phase1 在 4 H100 环境 active compute 629.63 秒；编码约 127 秒、全共同计数约 87.5 秒、merge 约 121.5 秒，最高记录进程 RSS 约 12.25 GB。该工作不含本轮 swap/null/分组；不作为本轮耗时或单机峰值承诺。

| 环节 | 当前建议成本（仅估算） | 主机峰值预算提案与前提 |
|---|---|---|
| 1 频率/稳定性 | 边际表 1–5 分钟；扫描 CSR 补 context 覆盖 2–15 分钟 | 4–8 GiB，流式；不缓存全部 z；条件性 bootstrap 用块边际 |

不是“全问题 10 分钟即可完成”的承诺。推荐批准后先做资格阶段，资源上限与总时限在 decisions_needed 中由研究者确认：不超过上述子样本，≤4 个 null 及两链短检查点，建议 CPU 30 分钟、RAM 32 GiB 硬上限；统计量仅用于实现/成本/混合资格，不作 H1 结果。若超限、null 不合格或成员覆盖严重不足，保存失败收据并停止，不自动扩样、增设备或去掉对照。资格后若总预算不够，报告本问题当前证据不足，不能删掉关键 null 后宣布支持。

## 10. 第二步 H2：只保留必要规划，不激活实验
