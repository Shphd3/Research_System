## 1. 一分钟理解本任务

**总目的：在固定参数量和计算预算下，提高 MoE 对不同内容的有效学习容量。**

我们希望用频率和 feature 关系指导专家分工。但 feature 是分组对象，真正进入专家的却是包含多个 feature 的完整 token 表征。因此，名单上的同频分组，不一定能变成专家实际接触的同频内容。

**本轮只回答：现有分组和路由在真实输入上落实了怎样的分工？低频目标未到达负责专家，主要暴露了评分问题、分组与输入共现的冲突，还是两者尚不能区分？**

先把问题定位到具体 feature、输入位置和评分项，再决定下一轮改什么。学习收益和容量提升不由本轮直接判定。

## 4. 术语与不可混淆的对象

- **feature**：固定 CrossCoder 的一个坐标；激活事件沿用缓存的原定义
- **频率组 A**：直接按全局频率区间形成的名单；不是 φ 关系组
- **φ 关系组**：按二元共现相关性建图形成的候选组；φ 不是因果贡献，也不是解码方向共线性
- **负责专家**：实验预先指定该 feature 名单对应的专家编号；不意味着它已经学会该 feature
- **实际接收**：完整输入被路由到专家，未按 feature 拆分后分别送入
- **common**：本轮按训练侧出现频率预先定义的伴随高频集合；不自动等于语法、第一主成分、已掌握知识
- **全局频率 p**：全部位置中的出现比例；**专家内频率 q**：送到某专家的位置中的出现比例
- **学习机会代理**：接收率和曝光次数；不等于梯度大小、任务价值或已经学会

允许低频专家同时处理 common。不以平均负载、相等组人数或删除 common 为目的。

## 5. 分析判断与竞争解释

这是看过初步结果后的诊断研究，不能包装成完全未知结果上的预注册验证。

### 判断 J1：名单没有落实为选择性接收
检验逐 feature 的负责专家接收率、专家内频率和富集；区分“收了大部分输入所以什么都见过”与“更集中地接收特定内容”。

### 判断 J2：当前固定评分主要受伴随高频成分影响
检验赢家得分与胜出差额由哪些评分项构成；固定字典、名单和分母，仅做评分项消融，观察分发是否变化。该消融定位的是评分计算路径，不能直接证明自然输入因果关系或学习损害。

### 竞争解释 J3：部分接收要求与输入共现结构不兼容
若不同组的目标总是共现，top-1 不能把同一个输入同时送给多个负责专家。检查具体冲突，不把任何零接收都归咎于评分，也不把一个反例推广到全部组。

其他解释必须保留：计数口径错误、幅度尺度、组大小与频率耦合、样本不足、字典重构不充分。既有工程检查可复用，不重复全套训练准备。

## 6. 本轮要形成的认识更新

| 证据 | 允许更新的判断 | 下一步 |
|---|---|---|
| 目标输入存在；仅改评分项后目标接收改善，且不是零分并列驱动，同时报告对其他目标的代价 | 支持当前评分对低接收有可定位贡献；尚未排除共现约束等其他原因 | 提出一个新评分方案，另行登记并检验 |
| 跨组共现给出明确的接收率不可行界 | 某些要求与现分组/top-1 预算冲突 | 讨论改分组或接受接收率取舍 |
| 高频组接收很多输入但逐 feature 富集接近1 | 高接收量不代表明确的内容分工 | 不再只按专家负载评价分发 |
| 部分 feature 确有选择性接收 | 并集统计掩盖了差异 | 定位哪些输入/feature 能实现分工 |
| 样本、文本对齐或反事实不足 | 尚不能区分解释 | 报告缺口，不伪造确定根因 |

**不承诺一定得到正向结果。可靠的失败定位或可行性边界也是更新；“没有显著性”不能自动写成“无效果”。**
