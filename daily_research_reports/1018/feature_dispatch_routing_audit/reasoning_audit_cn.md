## 1. 目的与可回答的范围

父问题是分工能否改善学习；本轮的子问题是：低频 feature 已在输入中出现，为何完整输入没有到达名单指定的专家？负责专家只是预先指定的名单编号，不表示已经学习该 feature。实际接收是完整 token 表征进入一个专家，并未把各 feature 拆开分发。

本轮检查“冻结 feature 命中和幅度 → 原分组平均分数 → hard top-1 去向 → 逐 feature 接收与专家内频率”这条链。学习损失、梯度效用、知识难度和容量收益不在这条链的实测范围。旧正式 A/B、C/D 学习仍为 `NOT RUN`；本轮没有将其补写成阴性或阳性学习结果。

## 2. 量的定义和分母是否合格

全局激活频率 p 是全部有效预测位置中 feature 出现的比例；接收率 a 是含该 feature 的位置中进入某专家的比例；负载 l 是全部位置中进入该专家的比例；专家内频率 q 是进入该专家的位置中含该 feature 的比例。分子、分母和整数守恒见 `metrics/core/core_checks.json` 及逐 feature 表。

- TRAIN 为130,712个位置、128个切块上下文；EVAL 为65,402个位置、64个上下文。原 token mask、下一 token shift 和位置映射已核对。它们是不重叠文件上的留出位置；CrossCoder 训练见过所属语料，EVAL 也已被查看。不能称全新独立确认，文档级去重与近重复独立性未知。
- 可靠 feature 池9,615项、原低频 L 为964项、原高频 C 为962项。C 复用原 TRAIN 上10%高频名单，阈值约4.5861%，**不是本轮新取 p≥0.5，也不表示每个 C 成员都普遍存在**。common 不是语义类别、第一主成分或已掌握知识的同义词。
- A的964个低频 feature 在两侧负责专家接收率全部为0。它们的负责专家 A0 完全无输入，故负责专家内 q 与富集为 NA，而不是0。a=0与q不可估计必须同时保留。
- B1/B2必须使用各自名单和自身实际去向。EVAL低频 feature 等权平均接收率为4.4358%和10.2956%；仍分别有122、48项零接收。不能把同号专家跨规则解释成同一语义角色，不能把B有正接收或非空负载说成已改善学习。
- 低频并集覆盖 TRAIN 95,544个位置，只说明“至少一个低频 feature 出现”。最高频专家覆盖这个并集，不能代替964个 feature 各自的接收、q或富集。病例、特征和位置也不是三份相互独立的证据。

## 3. 评分路径证据支持什么

原评分是每组所有成员的 decoder 范数加权激活均值，未激活成员贡献0，分母保持原成员数。原 FP64稀疏累加后保存FP32的分数及原哈希 tie/fallback 已精确复现；这排除了此次解释依赖分数实现不一致的疑虑。活跃比例×事件加权平均幅度的恒等式是算术核验，不是两个独立因果机制。

对含低频 feature 的位置，原赢家减A0的平均分数差：

|范围|位置数|总差额|C项差额|非C项差额|
|---|---:|---:|---:|---:|
|TRAIN|95,544|0.567492|0.569428|−0.001935|
|EVAL|49,291|0.550900|0.552779|−0.001879|

非C项在这些位置上支持A0，但不足以抵消C项差额。A的原赢家与次名来自完全属于C的组，因此原冠亚军差额的非C分量恒为0。这定位了当前评分计算由哪些项决定；并不证明高频伴随项对原模型预测无用，也不能区分名单构成、频率和幅度哪个应独立承担根因。

仅将C在评分中的项置零，原字典激活、输入表征、名单、分母和tie/fallback全部不变。这是**虚拟评分路径干预**，不是模型表征消融，也不是新训练。A两侧全部位置转到专家0，零分和并列均为0。

但这个结果有决定性的非识别边界：A组1–7的全部362个成员都属于C；组0另有600个C成员和8,653个非C成员。因此去C会机械地使其他七组永远得0分。组0的9,253项负责专家接收率变为1，同时原本有正接收的其他组**25个 feature**变为0；另30个组3成员原先就零接收。55是名单负责专家原本非空的feature数，不能误写成55项受损。

这里不存在有效的已有逐组匹配消融对照，未另行搜索。不能把“低频接收提升且没有并列”单独宣布成新路由成功，不能归因于common语义，也不能建议把C当噪声删除。B在去C后也大量改派，说明该操作足以改变评分，不提供上述独立归因。

## 4. 共现约束没有解释掉零接收

有限检查只从TRAIN固定三个案例目标，各规则取跨负责专家的高重叠伙伴，每个案例每规则最多3对；共27个固定对，再读取EVAL复核。没有构造全字典最优分配，也没有扫描全部跨组对。

对两个负责专家不同的目标，若要求它们各自至少有相同比例τ的命中到达负责专家，top-1必要条件为：τ≤1−共同命中数／两者命中数之和。交集位置不能同时送到两个专家，这个推导成立；它是特定接收条件的必要条件，不是学习能力上界。

A选中对的τ上界在TRAIN为0.99181–0.99613，EVAL为0.98837–0.99718。它们会排除部分接近100%的同时覆盖要求，但**不能迫使低频目标接收率为0**。例如9297→负责A0与16240→负责A1：TRAIN命中304、19,588，共现163，τ上界0.99181。原A0零接收不是这条界的数学必然。

同样，界接近1不证明所有目标可同时满足，也不排除更高阶、多目标或未检查对的冲突。B有部分更紧的局部界而仍出现非零接收，说明“存在top-1取舍”与“必须完全饿死某组”不是同一命题。不能从有限搜索没找到严重冲突，改写成“分组结构没有问题”。

## 5. 文本能核查需求—去向，不能给出功能命名

案例9297、1133、2704仅由TRAIN规则冻结，原负责专家均为A0，全部候选的接收率都为0。因此这三个案例没有好／中／坏差别；选择按上下文支持和ID破并列，没有伪造接收率梯度。

每个feature有EVAL三个固定种子随机命中和一个高激活、优先未展示上下文的命中，共12张卡片。高激活样本并非必然是全局最大值，取样规则与全局最大值另记。卡片核对了当前token、可见前缀、下一token标签与输入去向；截短展示不等于模型只看了这100个token。

12张卡片×3条规则中，移除目标U自己的评分项均未改变赢家。这只说明这36个位置—规则组合对该评分项的局部选择敏感性；不说明U对原模型预测、其他输入或后续学习无用。各例可见词汇模式只能作为候选解释；不凭12条文本赋予单义标签。表中组号−1表示未进入可靠评分池，但feature仍存在于原始输入表征，并未从模型输入删除。

## 6. 有界认识更新与唯一优先下一决策

昨天的判断是“低频 feature 出现，却没收到输入，可能是评分或分组冲突”。本轮证据把其中一条计算路径明确了：原始组平均评分中，C项胜出差额压过A0的非C项，低频出现并未取得路由选择权；这比只看到负载失衡更具体。有限冲突对没有迫使零接收，但删除C也没有提供可用解决方案。

**AI建议：下一阶段优先讨论并冻结一次评分校准比较，先决定路由应比较原始幅度还是相对组自身常态的响应。** 保留现分组与top-1作为首个有限比较对象，同时检查逐feature接收、其他频段代价和空专家，不以全部送给A0为成功。具体校准公式、接收要求、阈值、冻结验证和预算仍需下一阶段定义；本轮未选择新公式，也未执行。

该优先级适用于当前固定字典、这9,615项名单、均值评分与已观察窗口；不是“只需修评分”的普遍结论。若将来明确的接收要求被具体共现界排除，应先处理该取舍；若评分校准仍无法获得合理覆盖，则分组冲突继续保留为竞争解释。学习改善、容量提升和机制有效性仍为 `NOT TESTED`；研究者对科学解释与下一阶段的正式判断保持 `Unknown`。
