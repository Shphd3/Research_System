## 1. 冻结对象与基本量

位置 t 是有合法下一 token 标签的有效预测位置。沿用既有 mask，不把 padding、无效末位混入分母。上下文只用于分块和文本解释，不额外视为独立证据。

令：
- b_ti = 1 表示缓存中 feature i 在位置 t 激活，否则0；不得把 decoder 范数当作输入激活
- e_R(t) 为规则 R 的既有 hard top-1 分配结果；下式在分别计算某条规则时简写为 e(t)，不能让 A/B 共用一份去向
- g_R(i) 为规则 R 下 feature i 名单指定的专家；R 分别为 A、B1、B2
- N 为有效位置数；N_e 为送到 e 的位置数
- n_i = Σ_t b_ti；n_ei = Σ_t 1[e(t)=e] b_ti

计算：

    p_i = n_i / N
    a_ei = n_ei / n_i              # 含 i 的输入到 e 的比例
    l_e = N_e / N
    q_ei = n_ei / N_e              # e 的输入中含 i 的比例
    enrichment_ei = q_ei / p_i

检查恒等式 q_ei = p_i a_ei / l_e。实现误差应仅为浮点精度。

同时核对 Σ_e N_e=N、Σ_e n_ei=n_i、n_ei≤min(N_e,n_i)。这些等式针对本轮完整 top-1 分发；若旧记录含丢弃或特殊通道，先单列去向，不能偷偷归入普通专家。

### 零值必须按含义保留

- n_i=0：p=0，a 与 enrichment 不可估计；不能声称永久死亡
- N_e=0：l=0，q 与 enrichment 是 NA，不是0；n_i>0 时该专家的 a=0
- N_e>0、n_i>0、n_ei=0：q=0、a=0、enrichment=0；不能从统计表删掉
- 所有比率均同时给出整数分子/分母，不用大平滑常数遮掩零接收

全局稀有不等于单个输入稀有，也不等于知识困难。多个低频 feature 的并集可能很常见。

### 集合定义

G_e 沿用原 A 八组；B 使用各自冻结名单。低频集合 L 必须优先复用原协议定义；若无法找回，标记旧低频并集无法复核，不自行换定义来复现旧数字。

共同高频集合 C：优先使用原协议的明确高频列表及其定义；若原来只有模糊标签，没有 feature 列表，本轮采用 TRAIN 上 p_i≥0.5 的可靠 feature 作为**新增诊断定义**，记录人数、ID、选择时间。C 可以与 G_e 重叠，计算时去重。阈值不因 EVAL 结果调整；若 C 为空，报告空集，不临时改阈值。

C 只表示高频伴随成分。检查 P(c激活 | i激活)，不能仅凭 φ 筛 C：p_c=1 时 φ 没有定义，却可能与所有目标一起出现。

## 2. 第一阶段：逐 feature 与组层面实际分发

### 2.1 核心表

对 A、已有 B1/B2，分别在 TRAIN/EVAL 输出：

- `expert_summary.csv`：规则、split、expert、名单人数、N_e、l_e、命中名单的输入量、上下文数
- `feature_expert_metrics.csv`：规则、split、feature_id、g_R(i)、p_i、n_i、expert、N_e、n_ei、a_ei、q_ei、enrichment、命中上下文数、NA 原因
- `feature_owner_summary.csv`：每个 feature 在其负责专家的指标，并列出实际接收最多的专家及其指标
- `common_companions.csv`：目标 feature 与 C 成员的共现数、P(c|i)、全局频率、负责专家内 q_i/q_c 和有效分母

只计算现有可靠 feature 池及有需要的 C，利用稀疏命中表聚合，不做所有 feature 对的稠密扫描。

### 2.2 汇总方式

同时报告 feature 等权的中位数/四分位范围，以及按出现次数加权的汇总。不能只让极高频成员决定总均值。

分开报告：
1. 名单内目标的实际频率分布
2. 伴随 common 的实际频率分布
3. 零接收目标比例及原始命中数
4. 完全无输入专家的数量

这轮**不优化一个新的复合总分**。若画正 q 的 log 分布，必须在旁边标出零项和 NA 项数量；不能把丢掉零项后的离散度当作全组成绩。

目标—common 对可报告 `log10(q_c/q_i)`：正值表示 common 更常见，负值表示目标更常见；q_i=0 标注“目标未接收”，q_c=0 单列“该伴随项未出现”。不强迫把本来未出现的 common 加回来凑同频。

### 2.3 B 的比较边界

B 保留组人数，但成员不同。因此按相同 feature 比较其**各规则自身负责专家**的接收与富集，不能把 B 的同号 expert 叫成与 A 同义的“低频专家”。B 是已有分组对照，不是所有混杂都匹配的最优或理论上界。A 两种子的相同路由只算一个确定性分配结果。

配对前核对同一 split 的输入位置 ID、有效 mask、feature 矩阵及评分权重一致。若不能对齐，只分别描述，不能直接作同 feature 的配对差值。每条规则独立使用自己的 e_R(t)。

### 2.4 不确定性

所有图给出样本数。需要区间时，使用既有上下文 ID 的成块重采样（固定种子，200次）估计描述性区间；不把 token 独立自助法当文档独立证据。计算昂贵时优先核心表，区间不是第一阶段交付的阻塞项。没有足够精度就写描述性结果，不以“没显著”判无效。

## 3. 第二阶段：真实文本的需求—去向对照

### 3.1 选择案例 feature

只在 TRAIN 选 ID，冻结后去 EVAL 取例子。原低频集合内，TRAIN 至少30次命中、至少5个上下文的成员可进入**案例候选池**；这些门槛仅保护案例可读性，不从核心表删除其余成员。上下文按原缓存 ID 定义并去重，注明它是切块窗口还是原文档；窗口 ID 不保证文档独立。

优先选择3个：负责专家接收率最低、中位、最高，各取一例；并列按命中上下文数降序、feature ID 升序。若全部接收率相同，不伪造好/坏对比，改为三个不同 ID，并明确该池无此差异；必要时用一个中频成员作标明频段的参照。候选不足则据实减少。

每个 ID 展示：EVAL 3个固定种子随机命中位置，另加1个高激活位置；优先不同上下文。无 EVAL 支持时展示 TRAIN 并标注。不要只展示最高激活文本。

### 3.2 文本卡片字段

- 原始文件/上下文/位置/token ID；当前 token 及其前缀
- 正确下一 token 单独展示，注明仅用于解释，不参与路由
- U 的全局频率、名单专家、该位置激活幅度（可用才写）
- 同位置主要伴随 feature、其频率、所属组
- 各组原始分数、赢家/次名、差额、实际专家
- U 的存在是否改变其组分数及赢家；不能把“没有改变赢家”叫作 U 对模型无用

可给直观语义描述，但标为候选解释；不凭单句命名 feature，不把被截断的未来文本当作编码器看到的输入。

零接收专家没有“它收到的自然文本”。此时展示该组本应对应的命中输入及其真实去向，禁止编造收样。

## 4. 第三阶段：评分路径与共现约束

### 4.1 原评分的算术分解

先按代码确认评分式。若原式确为：

    s_e(t) = [Σ_i∈G_e z_ti w_i] / |G_e|

其中 w_i 为既有跨层 decoder 范数权重，则沿用同一权重，不另换范数定义。

先核验 z 的非负性及原 score 定义；若存在负项，不能仅用 z>0 的命中数解释完整带符号得分，单独报告并沿用实际评分式。

将 s 分成 C 与非 C 两部分，分母始终为原 |G_e|。对赢家与次名比较两部分对胜出差额的贡献；若某项为负，保留符号。非负评分下，令 H_e 为组内全部激活事件数，则：整体活跃比例为 H_e/(N|G_e|)，事件加权平均幅度为 Σ_tΣ_i∈G_e z_ti w_i/H_e，两者乘积等于组分数的总体均值。H_e=0 时事件均幅为 NA，组均分为0。不要改成两个逐 token 普通均值的乘积，也不把两项当独立因果效应。

### 4.2 有限评分反事实

只在原缓存上将 C 对**路由评分**的项置零，保留原 z、组名单、分母、tie/fallback 规则和专家输入；重算 top-1。

报告：改派率、每专家接收量、逐目标 a/q、零分与并列数量。若改变来自大量零分并列，不能叫作残差学会了区分。

这一步是虚拟评分诊断，不是新训练、不是真实模型表征消融，也不代表该策略可上线。删除高频项自然会改变幅度；即使结果变好，也不能单凭它断言 common 语义是根因。

若已有合适的匹配消融对照，可复用：优先匹配每个组被删除的 feature 数，再检查 TRAIN 频率、支持数与幅度可比性，并解释匹配范围。只匹配全局删除数不足以控制各组分母的差异。若 C 几乎占满某组或不存在可比替代，报告“无有效匹配对照”，不为此开展大规模搜索；明确该反事实没有识别频率、幅度和语义各自的独立因果作用。

进一步可对案例 U 单独移除其评分项，保持同样分母，回答它对路由选择的局部作用。只处理案例，不全字典穷举。

### 4.3 共现导致的不可行性证据

先用已有跨组共现记录或案例候选寻找高重叠目标对，不新建全字典二次方矩阵。对属于不同负责专家的 i、j，令命中数为 n_i、n_j，共同命中 n_ij。

top-1 且每个目标至少有 τ 比例到达各自负责专家时，必要条件为：

    τ(n_i+n_j) ≤ n_i+n_j−n_ij

即相同覆盖要求的上界：

    τ ≤ 1−n_ij/(n_i+n_j)

这来自相交位置不能同时给两个专家。若完全同现，上界为0.5；k组目标完全同现时共同要求至少满足 kτ≤1。

只报告找到的冲突与适用样本范围。必要条件满足不证明整体可行；没有搜到冲突不证明不存在。不要把这一上界叫作学习能力上界。

本轮不求完整最优分配，不偷偷降低覆盖要求，不调整名单。若怀疑需要重分组，将具体冲突对作为后续证据。

## 7. 逻辑审计与验收

作者已检查本协议的以下边界；执行 Agent 还须结合实际文件复核：

1. A 频率组与旧 φ 图没有混称；B 专家编号没有当语义对齐

8. 共现不可行界只是特定覆盖条件的必要条件，不冒充全局最优或理论容量
9. 每条最终结论可追到 CSV 行、图及文本位置；没有文件支持的描述标为假设
10. 过完备、满秩、稀疏可重构、专家能预测没有混为一谈

指定 reasoning skill 若可读取则执行；不可读取时记录“未加载该 skill，采用上述显式逻辑检查”，不要声称已调用。不要输出私有推理过程，交付可审核的定义、证据、反例和结论边界。
