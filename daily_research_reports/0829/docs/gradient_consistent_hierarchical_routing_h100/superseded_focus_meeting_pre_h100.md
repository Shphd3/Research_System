**本次术语：**混合专家模型（MoE）是由路由器选择少量专家计算的模型；路由器（Router）是专家打分与选择机制；冻结真实模型（Qwen3-30B-A3B）是本轮只读取而不更新的被审计模型；原生门控层（Gate）是该模型把隐藏状态投成 128 个专家分数的真实模块；功能公共成分（common）是本合成任务四个教师函数共享的秩一算子；对齐条件（work）表示父分组与功能分解一致，错配条件（fail）只重新配对同一组教师函数；前八名稀疏选择（top-8）是原生 Router 只保留八位专家的部署操作。

## 1. 本次组会主题与核心问题

**主题：**什么样的专家效用信号，才可能被递进残差 MoE 稳定学成可路由结构？

**核心问题：**先学习并冻结共同函数，再对剩余功能做 $1\rightarrow2\rightarrow4$ 递进专家训练，是否同时解决了“表征不可分”和“专家效用监督难学”两个问题？

## 2. 当前认识更新

目前证据只支持前半句，而且条件很强：当第一层分组与真实功能分解一致时，递进残差树确实能把全局交互改写成分支内简单功能；分组错时，它受到精确的容量下界。它没有证明树比通用非线性路由更高效。更关键的是，精确计算出的逐样本反事实专家效用也不自动成为好监督：若“当前最佳专家”还依赖 Router 看不到的样本内容和不断变化的专家参数，监督标签就不是 Router 输入的稳定函数，硬标签会造成赢家自增强和专家饿死。

因此本轮唯一认识更新是：

> **要做专家效用驱动的 MoE，先决条件不是把效用算得更精确，而是让监督目标成为 Router 可见表征上的稳定条件统计量。正确的层级分组可以降低功能复杂度，但不能修复一个对 Router 不可观测、随专家共同演化的效用标签。**

这段表述由 AI 根据已核验证据草拟，仍等待研究者确认。

## 3. 递进回答

### 3.1 Qwen 隐藏表征里是否缺少可分的父类信息？

不是。八类父语义在隐藏输入中几乎可被完美跨模板读出，经过 128 维原生 Gate 投影后仍保持 0.942--0.998 的平衡准确率；主要损失发生在 top-8 稀疏选择，选择后的读出降至 0.405--0.564。四个固定深度在 C4/C5 同时满足“投影保留、选择损失显著、路由关联高于空参照”。

这个答案只到“信息在哪里损失”。它不能说明父类标签就是专家效用，也不能说明改变 Router 会改善语言模型。因此必须继续问：给定一个真的知道专家功能的受控任务，导师的结构机制是否成立？

### 3.2 导师的 common→冻结→残差→1→2→4 机制是否成立？

作为条件机制成立，作为相对优势不成立。正确分组下，任务损失驱动的树把终点误差降到 $2.30\times10^{-5}$；只把同样四个教师函数重新配到错误父类后，终点保持在 0.33698，与解析 $1/3$ 下界一致。可是平坦非线性 Router 在两种配对中都到近零，而且正确分组下与任务树的学习曲线面积没有显著差异。

所以我们得到的是“正确树可实现、错误树有结构地板”，不是“树比非线性更高效”。这使最后一个问题变得必要：直接把反事实效用告诉 Router，能否形成额外收益？

### 3.3 为什么精确的反事实专家效用监督反而失败？

直接结果是否定的。效用树在 work 的中位终点误差为 0.41693，7/8 种子未到近零；至少一个叶专家的中位负载为零，原生 Gate 与冻结隐藏探针的效用目标平衡准确率都只有 0.625，低尾分类间隔均为负。任务树则负载完全均衡、效用目标可读率为 1、误差近零。效用监督在平坦模型中也没有建立学习曲线收益。

AI 的底层解释是：当前效用标签取决于样本内容 $z$、当前残差和正在变化的专家，而树 Router 只看 $p$ 或条件 $q$。同一个 Router 输入可以暂时对应不同“最佳专家”，硬标签便把专家初始化造成的偶然差异反馈放大。这个解释与负载、间隔和探针证据一致，但还没有由一次目标聚合干预独立证明。

## 4. 边界与唯一下一决策

- **已经理解：**正确功能分组使递进秩一树可表示；错误分组产生精确容量下界；当前逐样本硬效用监督不稳定且没有收益；静态语义可读不能替代效用可学。
- **仍不能说：**层级 MoE 普遍无效、反事实效用普遍有害、自然语言没有层级、或真实 Qwen 训练会出现同样塌缩。

**唯一下一决策：**是否批准一个最小后继问题——把瞬时逐样本硬效用改成“给定 Router 可见状态的软条件期望效用”，其余专家、树、任务损失、候选计算和预算全部不变，检验效用目标可观测性是否是塌缩原因。
**完成标准：**相对无辅助损失和瞬时硬效用两个对照，条件期望效用在八个配对种子中不恶化终点，显著降低学习曲线面积，同时所有必需功能都有非零负载和正低尾间隔；否则停止效用驱动残差树的真实模型推广。
**恢复动作：**研究者先确认或修正本页唯一认识更新与下一决策；确认后才新建后继 Focus/Protocol，不直接启动 Qwen 训练。
