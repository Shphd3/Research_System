# 组会主线：正确层级能实现残差分解，但未建立额外训练优势

## 先说结论

本轮把“导师的机制直觉是否可实现”和“这个架构是否比匹配基线更好”分开了。结果是：

> **给定正确父类分组时，$1\rightarrow2\rightarrow4$ 的秩一残差树确实能按共同、父级、叶级三阶段把函数学完；错误分组也确实留下约 $1/3$ 的解析误差下界。但匹配的平坦非线性 Router 同样学到近零误差，本次注册比较没有建立层级的额外样本效率；当前在线反事实效用监督降低了训练表现，并伴随逐种子的专家饥饿模式。因此，导师 intuition 成立的是有条件的函数分解与容量边界，不是“层级架构必然更优”。**

冻结 Qwen3-30B-A3B 的结果补充了接口位置：父类标签在隐藏状态和 128 维 Gate 分数中几乎都可读，但原生 top-8 稀疏选择丢失了大量线性访问性，同时仍保留高于空参照的父类关联。这个结果只说明访问性损失位置，不能说明所选专家有正确功能。

## 1. 唯一问题

先学习并冻结一个共同的秩一函数，再只对它未解释的功能残差进行 $1\rightarrow2\rightarrow4$ 递进专家训练，是否仅在给定父类分组与专家功能一致时把全局非线性决策化为分支内简单决策，并相对匹配的平坦非线性混合专家模型提高训练效率；直接监督“哪个候选专家最能降低当前损失”，是否还有额外收益？

这里的五层对象不能互换：外部语义标签、隐藏表征可访问性、原生 Gate 可访问性、反事实专家效用和实际功能误差。

## 2. 四要素实验版本

### 2.1 核心问题

正确的条件分解是否不仅**可实现**，而且比同参数、同样本、同候选前向计算的平坦非线性 Router **更高效**；在线反事实效用监督是否进一步改善训练？

### 2.2 实验目的、子问题与完成标准

1. 理论上区分固定线性映射、可学习非线性映射、条件化映射、语义可分和功能可分。
2. 在冻结 Qwen 中定位父类标签从隐藏状态 $H$ 到 Gate 分数 $Z$、再到 top-8 稀疏路由 $Q$ 的访问性损失。
3. 在同一组四个教师函数上只改变它们与具名父类的配对，检验正确树的可实现性、错误树的秩一容量下界，以及“树/平坦”乘以“任务损失/效用监督”的 $2\times2$ 比较。

完成标准分两条核验：Qwen 链通过冻结输入、检查点与 Gate 哈希、模板划分、探针、bootstrap、标签置换、行数、四卡资源和产物哈希审计；合成链通过生成器、解析 oracle、秩、冻结、掩码、配对、负载、算力、八个种子和产物哈希审计。两条链分别给出冻结判决，不共用科学护栏。

### 2.3 分析方法

1. 证明固定线性映射不能创造线性可分性，并用 $b=pq$ 的异或构造说明非线性或条件化何时能暴露新决策；再证明错误父分组为何把两个双正交秩一残差压入一个秩一叶，产生 $1/3$ 下界。
2. 对 Qwen 的同一批隐藏状态做完全相同的跨模板探针，只比较 $H\rightarrow Z\rightarrow Q$，并用完整模板族自举和标签置换空参照裁定。
3. 对合成任务运行八个配对优化种子，以无噪声归一化均方误差学习曲线面积和固定预算端点为功能裁定，以效用遗憾、低尾间隔、负载和逐次投影账本定位失败。

### 2.4 实际结论

- **Qwen 访问链：**五个确认层中有 4/5 在 C4、C5 同时满足 Gate 投影基本保留、top-8 选择造成实质损失、稀疏路由仍有高于空参照的父类关联；5/5 有实质选择损失，0/5 近乎完全保留。BF16 与 FP32 判决一致。
- **解析与训练机制：**任务损失树 `H_task` 的 work 端点归一化误差中位数为 $1.94\times10^{-5}$，fail 为 $0.336926$；fail-minus-work 学习曲线面积差为 $0.053155$，95% 区间 $[0.050140,0.054230]$，机制通过。
- **层级收益：**work 中配对面积差 $A_T=-8.21\times10^{-5}$，95% 区间 $[-0.004211,0.002458]$；区间跨零，因此本次注册检验**没有建立正的层级收益**，也不能把统计未区分加强成普遍等价。
- **效用监督：**树内效用对比 $S_H=-0.012057$，95% 区间 $[-0.067979,-0.007610]$；平坦模型 $S_F=-0.005792$，95% 区间 $[-0.007309,-0.000315]$。正值才代表效用监督更好，因此两者均不支持，且当前监督减慢训练。

## 3. 逐步回答：为什么这个闭环不等于三个散题

### Q1. 我们原来把什么混在了一起？

父类覆盖更广只会增加一项类间协方差，不保证它支配总协方差的最大特征值。训练出现得更频繁也只会增加梯度采样次数；只有跨细类平均梯度不抵消时，才会形成稳定父类方向。最大方差、线性判别、Router 选择和专家效用因此不是同一个对象。

**边界：**这纠正了 PCA 假设，但没有证明标准下一词元训练会主动生成目标语义间隔。

### Q2. 冻结 Qwen 的父类信息在哪里丢失？

隐藏状态 $H$ 的八类父标签平衡准确率为 0.9948--1.0000，Gate 分数 $Z$ 为 0.9417--0.9984，top-8 稀疏路由 $Q$ 为 0.4047--0.5635。投影通常保留，稀疏选择损失大；但所有确认单元的路由关联仍高于匹配空参照。

**边界：**这不是“Qwen 用父类路由”的因果证据，更不是“这些专家有用”的效用证据，所以必须进入一个能定义专家功能的受控任务。

### Q3. 导师的递进残差机制本身对不对？

在 work 中，三个双正交秩一算子给出 $C\rightarrow pA\rightarrow bB$ 的精确分解；在 fail 中，先按错误的 $p$ 分支后，一个叶必须拟合 $b(pA+B)$，而 $A+B$ 有两个非零奇异值，秩一叶至少遗漏一个单位能量，故总能量三中的 $1/3$ 无法消除。训练结果复现了 work 近零、fail 约 $1/3$。

**边界：**精确 $1/3$ 只属于四状态等权、各向同性高斯算子期望、精确共同祖先、双正交残差、给定树、逐阶段冻结和秩至多一叶的解析 oracle；float32 训练端点 $0.336926$ 只通过 $1/3-10^{-4}$ 的容差护栏。这不是所有层级 MoE 的普遍定理。

### Q4. 可实现为什么没有变成方法优势？

平坦 Router 看见完整 $s=(p,q)$，自身是非线性 MLP，而且每批都含完整四叶组合，因此也能直接学会异或交互。本次比较没有发现层级独有的可测样本效率缺口。work 的 `H_util` 同时出现 1 个近零、4 个约 $1/6$、3 个约 $2/3$ 的三模态种子结果。与全部账本相容的最窄解释是：尚未成熟的候选专家产生 stop-gradient 最优标签，hard top-1 又只把任务梯度送给已选专家，于是未选专家饥饿，早期选择被阶段冻结固化。但这不是唯一因果归因；本实验没有分别干预效用交叉熵、任务直通梯度、负载平衡、初始化与冻结。

**边界：**这否定当前在线效用合同，不否定经过另行注册的稳定化效用设计，也不外推到真实语言模型。

## 4. 唯一认识更新

> **语义层级不是方差层级；正确层级能提供一个可解释的条件函数分解，但“可分解”不自动等于“比通用非线性模型更高效”。本轮确定了导师机制的可实现边界，同时拒绝了当前层级增益和在线反事实效用增益。**

这次 H100 功能实验是用户本轮明确要求的下游、碰撞隔离后继实验。08:28 组会原文登记的顺序仍是先做未见模板低尾间隔的表示形成检验；不能改写成“组会已经指定要直接推广残差树”。

## 5. 五分钟汇报顺序

1. **0:00--0:40，纠正前提：**父类共同属性不要求父类方差最大，二维 PCA 不裁定高维可分，频率还需要非抵消的平均梯度。
2. **0:40--1:20，唯一问题：**正确父分组能否把全局非线性功能决策拆成局部简单决策，并超过匹配平坦 Router；效用监督是否另有收益？
3. **1:20--2:00，理论：**同一组四个教师函数只改变父类配对；work 有 $C+pA+bB$，fail 的错误叶留下 $1/3$ 秩一下界。
4. **2:00--2:40，Qwen：**$H$ 与 $Z$ 近乎保留父类访问，$Q$ 明显下降但仍高于空参照；马上说明“这不是专家效用”。
5. **2:40--4:20，决定性功能比较：**护栏全过，机制通过；平坦模型追平；效用监督为负并出现 $0,1/6,2/3$ 的专家饥饿模式。
6. **4:20--5:00，唯一更新和停止规则：**保留条件分解定理，停止推广当前树和在线效用监督，回到“频率是否必须通过跨细类梯度一致性才能形成父类方向”的表示形成问题。

## 6. Claim Boundary

### 可以说

- 在冻结数据、探针和层集合下，Qwen 的主要父类访问损失发生在 top-8 选择而非多数层的 Gate 投影；稀疏路由仍保留统计关联。
- 在本合成合同中，正确父分组的逐级秩一残差机制可实现，错误分组出现注册的容量下界。
- 在本次八个配对优化种子和固定预算中，平坦非线性 Router 与层级任务树匹配，当前效用监督没有收益并会诱发专家饥饿。

### 不能说

- Qwen 原生 Router 因果使用父类语义，或被选专家具有正确功能；
- 层级结构一般无效，或其他效用监督设计必然失败；
- 自然语言具有该四叶树，模型能无监督发现它，或真实语言模型损失会改善；
- 这条 H100 后继证据等于当前 8×RTX5090 Focus 已执行。

## 7. 唯一下一决策与已停放路线

研究者已接纳本轮直接结果、边界和 H100 证据归属：当前 8×RTX5090 Focus 继续拥有本周期；E01H/E03H 只作为碰撞隔离的 4×H100 敏感性证据被纳入，不改写成该 Focus 使用 H100 执行。三条候选后续路线中，研究者选择最上游的表示形成问题作为唯一下一决策：

> **在总 token、总目标位置、父细类样本数、词表、模板和标签熵匹配时，父类相关预测事件的高频是否足以形成未见模板上的父类判别方向，还是必须同时有跨细类不抵消的梯度一致性？**

最小后继设计是父类相关预测事件频率（高/低）乘以跨细类梯度一致性（高/低）的 $2\times2$ 下一词元预测实验。四格必须返回跨细类梯度一致性、父类类间能量、5% 低尾归一化间隔和父类判别子空间的谱位置；低频释放的目标位置用难度和词频匹配、但与父类无关的中性预测事件替代。若高频但低一致性不能形成稳定正间隔，而高一致性两格随频率呈可复核差异，才支持“频率通过不抵消的共享梯度起作用”；若四格都不能形成正间隔，结果只说明这个构造不足，随后才能讨论显式层级先验。
