# 三个认识：名单规模、关系分组与接收区域的学习收益

重绘结果：名单规模不能代替输入贡献；部分频率段有额外共现关系，但还不足以得到稳定的两个子组；旧T_S1的接收区域并非全部获益。

图1、图2a/2b来自**新分发分析** `20261019T025630Z`，未训练。图3来自**旧T_S1的epoch1训练检查点**，每模型168步、85548个答案监督位置，seed11/22；它没有训练本轮新分组。expert ID不能对应为新图中的频率段或子组。二者复用同一Tulu EVAL256问答、22446个答案预测位置；EVAL此前已查看，均按探索证据解释。

## 图1：名单规模能否代表输入贡献？

![成员数量与末层贡献份额，上下对齐](figures/figure1_feature_count_vs_contribution.png)

上面板为四个TRAIN频率段的feature成员数，下面板为EVAL逐位置末层贡献份额的平均值，两个面板共用频率段横轴，纵轴分别标注，不使用双纵轴。频率是TRAIN答案预测位置上feature被激活的比例；四段按正频率的log等宽划分，低→高。feature的末层贡献标量为其激活值乘末层decoder向量长度；段内相加，再除全部16384项贡献标量总和。它没有计算decoder向量抵消或重建残差。

|频率段（低→高）|成员数|EVAL平均末层贡献份额|
|---|---|---|
|1|1,694|0.108%|
|2|5,673|2.198%|
|3|7,013|31.275%|
|4|1,097|66.419%|

**观察。** 第三段有7013个feature、占平均末层贡献31.275%；第四段只有1097个、占66.419%。第一段1694个、占0.108%。907个TRAIN零频feature单列U，没有塞进最低频段；U的EVAL平均份额0.001185%仍保留在贡献分母内。这里使用EVAL份额，未误用成员源表中的TRAIN平均份额。

**允许的结论。** 频率段名单人数不能代表这些输入上的贡献标量份额。少数高频feature可占很大平均份额。该量描述当前激活与decoder尺度，不是知识量、信息量、梯度干扰、学习价值或容量。

**对设计的影响（AI建议）。** 分发设计应分别报告名单规模与实际输入贡献，并明确按总贡献、组均值还是TRAIN常态校准评分。仅按人数配平不足以判断输入贡献是否均衡；本图没有比较新训练收益。

来源：[绘图表](tables/figure1_feature_counts_contribution.csv)。平均以22446个EVAL位置等权，未给未计算的置信区间。

## 图2：额外关系是否足以形成稳定分组？

![留出组内φ与匹配随机](figures/figure2a_heldout_phi_vs_matched_random.png)

蓝色菱形为TRAIN构造的关系组在EVAL上的组内有符号φ，灰点为20个频率匹配随机组的均值，灰线为这20个结果的最小到最大范围，**不是置信区间**。每个随机名单保持子组人数，并在段内十个细频率档匹配。右侧单列关系组减随机均值的差值，以保留第一、二段很小的差别；没有按结果选择随机seed。

φ度量两个feature激活指示变量的相关：联合激活频率减边缘频率乘积，再除二者标准差乘积。构组时仅使用正φ；图中复核使用有符号φ，按两个子组内可估的无序feature对数量加权。常量feature对应的不可估对排除并保留数量；单成员子组没有feature对，φ为NA。

|频率段|关系组φ|匹配随机均值φ|差值|两子组大小|
|---|---|---|---|---|
|1|0.00033838|0.00029366|+4.471e-05|1,308 / 386|
|2|0.00072009|0.00071958|+5.099e-07|5,670 / 3|
|3|0.00511779|0.00240052|+2.717e-03|1,861 / 5,152|
|4|0.00998610|0.00998613|-2.554e-08|1,096 / 1|

**图2a观察。** 第一、三段关系φ高于全部20个匹配随机结果，第三段差值为0.00271726；第二、四段差别很小。第四段小组φ为**NA**，不是0；其段级φ仅由可估大组贡献。

**图2a允许的结论。** 部分频率段的共现关系超出了已匹配的频率统计。第二、四段可交换成员比例仅18.97%/1.09%，匹配随机与原名单很接近，对照区分能力有限。仅凭平均φ无法判断成员名单是否稳定，也无法推导更新相容、学习价值或容量。

**图2a对设计的影响（AI建议）。** 保留关系组和频率匹配随机的并列对照，并继续单独检查成员稳定性；平均关系增量不直接决定可训练的专家名单。

来源：[组内φ绘图表](tables/figure2a_heldout_phi.csv)。

## 图2b：成员名单是否稳定？

![成员稳定性小图与两子组大小](figures/figure2b_membership_stability.png)

稳定性图单独显示：全TRAIN与两半各自重构名单、两半之间的平均匹配Jaccard。对两个子组交换编号后取较佳匹配，再对两组的交并比平均；1表示名单一致。行标签给全TRAIN两子组人数。分半按对话哈希，两个半样本45637/39911个位置；频率段保持全TRAIN定义，因此只检查固定频率段条件下的成员稳定性。

|频率段|全TRAIN子组人数|half0子组人数|half1子组人数|
|---|---|---|---|
|1|1,308 / 386|1,693 / 1|1,691 / 3|
|2|5,670 / 3|5,666 / 7|5,671 / 2|
|3|1,861 / 5,152|7,010 / 3|4,587 / 2,426|
|4|1,096 / 1|1,096 / 1|1,096 / 1|

**观察。** 第三段名单由全TRAIN的1861/5152变为两半的7010/3与4587/2426，半间Jaccard仅0.327。第一段全样本与两半的Jaccard均约0.385。第二段全名单5670/3，第四段1096/1；第四段虽Jaccard为1，仍是一个大组加一个单成员组。所有源表缺失量保留NA。

**允许的结论。** 这些证据尚不足以支持稳定的两个实质子组。平均共现关系可复现与成员名单稳定是两个不同检验。Jaccard及组大小都不能推导共同更新是否相容、学习价值或容量。

**对设计的影响（AI建议）。** 暂将这次二分视为候选组织；频率段、组内关系和成员稳定性分别检查，避免把固定切成两组直接当作两个可用专家。关系组与匹配随机仍应并列保留；不据此冻结新训练名单。

来源：[稳定性绘图表](tables/figure2b_membership_stability.csv)。缺失量保留NA，真实的零Jaccard仍是0。

## 图3：各接收区域是否都获得收益？

![旧T_S1逐expert的EVAL损失差，两种子及现有区间](figures/figure3_old_T_S1_epoch1_expert_DeltaNLL.png)

仅展示旧T_S1，圆点seed11、方点seed22；每个expert ID旁两种子错开。纵轴是该expert自然接收的EVAL答案位置上，开启epoch1残差分支相对关闭分支的平均ΔNLL，单位nats/答案位置；负值是损失下降，零线是不变。误差线直接复用既有1000次按对话重采样的95%描述区间，没有重新采样或重算loss。固定T_S1路由使每expert两种子接收同一区域，区间分别报告，没有把expert当独立重复。

|1|-0.05751 [-0.07675, -0.04026]|-0.06260 [-0.08324, -0.04572]|

**观察。** expert1、3在两个seed的区间均低于0；expert0只在seed11的区间完全低于0。expert7在两个seed的ΔNLL为+0.01309/+0.01128，区间分别[+0.00338,+0.02235]和[+0.00128,+0.02086]，都高于0。其余多项区间跨0。

**允许的结论。** 在旧T_S1 epoch1和这份已查看EVAL上，各接收区域并非全部获益；区域7有两个seed一致的损失上升描述。跨0区间表示当前证据不足以确定方向，不证明零效应。本图不能解释哪个feature导致这些差异，也不能检验新末层贡献分发或新关系子组的训练效果。

**对设计的影响（AI建议）。** 后续分发与训练比较需要保留逐区域损失及不确定性，用新方法自身的训练结果检验收益。接收率上升、更多共现或激活项增多均不能代替这项检验；本图也未识别梯度干扰的原因。
