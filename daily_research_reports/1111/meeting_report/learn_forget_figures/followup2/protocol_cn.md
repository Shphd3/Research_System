1. 损失差按左侧模型减右侧模型，统一使用文档配对 95% 区间。R04 已有 1000/1500/2000 步；500 步若原表缺失，则以既有逐位置 loss、同一文档 ID 做 2000 次配对 bootstrap（seed 20261111），不做新前向。0–10B 主图使用对称对数轴容纳原点；0–1B 放大使用线性轴。原生 MoE–A5 的 1B 点用原生基准横坐标 1B，A5 实际为 1.000341504B。1B 改接正式 baseline，不把它与早期 A0 当成同一条 checkpoint lineage；间隔仅以虚线提示比较次序。0 点未列为指定对照，不造数据点。
2. 任务 F 既有左上面板：自有表征、真实 Top2、八个 expert 中位数和 10%–90% 分位。Dense 的 1 是全局除以全局的定义参照，阴影是 expert 间分布，不是置信区间。
3. 同任务 F 的固定 DEV 序列号（128×2048 = 262144 位置），使用各模型 FFN 前 norm2 输出，按各 checkpoint 当时的实际硬 Top2 分组。兼容 F 的 BF16 autocast 与 FP16 表征记录精度，协方差按各组各自去均值、FP64 计算，熵有效秩为归一化谱熵取指数；分母始终是该 checkpoint 该层全部位置的全局秩。逐层以 8 个 expert 中位数为主，层段 0–3 / 4–7 分别取四层算术平均。Dense 只算全局。优先 A0 500 → 正式原生 10B → A0 1000，其余按可得性依序；能复用 F 的同 DEV 缓存就不重复前向。先验：原生分发对专家输入的方向筛选早于较晚训练。判据：原生两个层段的均值在 500 和 1000 步都低于 0.90，且此后至 10B 的已测节点均未高于 0.95，则记“输入方向的减少在早期形成并保持”；逐层及逐层段同时报告，若只一个层段满足，不写成全模型成立。33B 独立观察。稀疏快照不识别两个节点间的路径。
4. 对任务 B 冻结的 3169 个交集 feature，各选一个代表上下文：优先第一个 Dense、MoE 均有逐位置 loss 上升的正激活位置，否则取第一个正激活位置；同一序列内左右各 20 token。只匹配用户列出的词组，不区分大小写、折叠空白，按词边界匹配：Take the tour、EditText of this page、PingBack、Categories、Leave a Reply、permalink、Your Answer。命中即“网页模板文字”，其余为“其他（未命中）”。位置同时报告每类 EVAL 正激活支持的去重并集、两个集合重叠、以及 feature×位置次数。分类是代表窗口的关键词粗分；整组 feature 的支持位置并非每个都含该关键词。不给未运行的人工语义标注。
