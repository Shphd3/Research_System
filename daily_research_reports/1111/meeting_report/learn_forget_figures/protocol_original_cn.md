## 图 1：MoE 比 Dense 好，是学得快，还是忘得少？低频差在哪一项？

**量**
- 参照：$\ell^*_x$ 取 MoE 33B 检查点的逐位置损失；可学位置 $\mathcal P=\{x:\ell^*_x\le\ln2\}$。另用 Dense 最晚检查点当参照重做一遍作敏感性检查。
- 状态（带迟滞）：$\ell_x(T)\le\ln2$ 为"会"，$\ge2\ln2$ 为"不会"，之间沿用上一个检查点的状态。
- 掌握率 $K(T)$：可学位置里"会"的比例。相邻检查点 $T_a\to T_b$ 之间：
$$K(T_b)-K(T_a)=\underbrace{a\cdot\big(1-K(T_a)\big)}_{\text{新学会}}-\underbrace{f\cdot K(T_a)}_{\text{忘掉}}$$
  $a$ 是"不会→会"的比例，$f$ 是"会→不会"的比例。这是恒等式，核对它数值上成立。

**分层**（各算一遍）
- 位置上低频 feature 的占比高（32 个里 bin0–2 的个数在全体位置的上四分之一）与占比低（下四分之一）；
- 用 DEV 统计一个平滑的 bigram 模型：它给正确答案的概率 ≥0.5 的位置记为"认出当前 token 就会"，其余记为"要靠上下文"。

**图**：横轴累计 token。上排两条掌握率曲线（Dense、MoE）；下排两组柱子，每个区间画"新学会"和"忘掉"两项，Dense 和 MoE 并排。四个分层各一小幅。

**读法**
- 把 MoE 与 Dense 的掌握率之差拆成"新学会之差"和"忘掉之差"，对所有区间累加。忘掉这一项占差距的 60% 以上，记为"MoE 的优势主要来自忘得少"；新学会占 60% 以上，记为"主要来自学得快"；之间记为"两者都有"。
- 对低频占比高的位置单独给出同样的判断。
- 给出文档自助法区间；区间跨 0 的项写"分不出"。

## 图 2：哪些 feature 互相帮助，哪些互相干扰？

用只读梯度量"在 a 类内容上走一步，对 b 类内容是帮助还是伤害"。

**分组**：A5 的 8 个 feature 分组 × {低频, 高频}，共 16 组。位置 $x$ 对组 $a$ 的权重 $w^a_x$ 等于它的 32 个 feature 里属于组 $a$ 的比例；组损失 $L_a=\sum_xw^a_x\ell_x/\sum_xw^a_x$。

**做法**
- 检查点：MoE baseline 和 Dense 各取两个，最接近 1B 的共同点，和 10B 以内最晚的共同点。
- 每组取 $R=4$ 份互不重叠的 DEV 序列批（不同组、不同份之间不共用序列），各算一次梯度 $g^{(r)}_a$。
- 参数块分开统计：Dense 的 FFN；MoE 的 expert；两者的注意力层。梯度太大就用固定的随机投影（例如投到 $2^{20}$ 维）后再算内积，或流式算点积，不保存完整梯度。
- 帮助系数（用不同份之间的内积，避免噪声偏差）：
$$T_{ab}=\frac{\operatorname{mean}_{r\ne s}\ \langle g^{(r)}_a,g^{(s)}_b\rangle}{\sqrt{\operatorname{mean}_{r\ne s}\langle g^{(r)}_a,g^{(s)}_a\rangle\cdot\operatorname{mean}_{r\ne s}\langle g^{(r)}_b,g^{(s)}_b\rangle}}$$
  正值表示学 a 对 b 有帮助，负值表示伤害，接近 0 表示互不相干。分母里任一项不为正的组标"信号不足"。
- 先测一次耗时。总预算 90 分钟；超出就先只做 4 组（最大的两个分组 × 低频、高频），再视时间补全。

**图**：16×16 的热力图，每个模型、每个参数块一幅。旁边一幅散点：$T_{ab}$ 对两组的共现程度（同一位置上两组都出现的位置比例，除以独立时的期望）。

**读法**
- $T_{ab}<0$ 的组对占比低于 5%，记为"几乎不存在需要隔离的冲突"。
- 同一分组内"低频对高频"的 $T$，减去"低频对其他分组"的 $T$ 的均值，差值明显大于 0（按 4 份批次的波动估计区间），记为"低频从与它共现的高频内容借力"。
- $T_{ab}$ 与共现程度的秩相关 ≥0.3，记为"共现可以当作互相帮助的代理"。
- 比较 MoE 的 expert 块和 Dense 的 FFN 块上述三个量有无差别。

## 图 3：一个位置上有 32 个 feature，最多能集中到什么程度？低频和高频能同时集中吗？

集中度 $\bar M_j=2\sum_e q_j(e)^3/u(e)$ 的理论上限是 4，但一个位置的 32 个 feature 分属多组，上限达不到。这张图把"达得到的上限"算出来。

**做法**（离线优化，不涉及任何模型）
- 待求的是一张 feature 到 expert 的打分表 $A\in\mathbb R^{30000\times8}$。位置的打分 $s_x=\sum_{j\in A_x}A_j$，选 Top-2；加一个偏置使各 expert 的负载最大值与均值之比 ≤1.2。A5 是 $A$ 每行只有一个非零的特例。
- 目标：$J_\lambda=\lambda\cdot\operatorname{mean}_{j\in\text{低频}}\log\bar M_j+(1-\lambda)\cdot\operatorname{mean}_{j\in\text{高频}}\log\bar M_j$，另取一个"全部 feature 等权"的目标。
- 求解：交替迭代 30 轮。固定分法算 $q_j(e)$、$u(e)$；再令 $A_{j,e}\leftarrow\omega_j\log\big(q_j(e)/u(e)\big)$（$\omega_j$ 是目标里 $j$ 的权重），重新分。起点用 A5 的分组和 3 个随机起点，取目标最高的。
- 在 DEV 上求 $A$，在 EVAL 上报告集中度。$\lambda\in\{0,0.25,0.5,0.75,1\}$。
- 另给一个解释上限的简单统计：每个位置的 32 个 feature 覆盖了几个 A5 分组；质量最大的两个分组占该位置的比例（均值和分布）。

**图**：横轴高频 feature 的集中度中位数，纵轴低频 feature 的集中度中位数。画出各 $\lambda$ 的解连成的曲线，再标上随机分发、原生 A0、A5、A8、A9d 的位置，以及理论值 4。

**读法**
- 等权目标下 EVAL 上的集中度中位数，就是"可达上限"的一个下界估计，直接报告数值。
- 曲线上 $\lambda=1$ 相对 $\lambda=0$，高频集中度下降超过 20%，记为"低频和高频的集中存在明显取舍"；否则记为"可以同时集中"。
- 写明：这是启发式求解，真实最优不低于它；坐标是 teacher 的 feature。
