## 0. 术语约定

本文使用以下中文概念，首次出现后保留必要缩写。

| 术语 | 本文含义 | 不等于什么 |
|---|---|---|
| 下一词元预测（NTP） | 用已有前缀预测下一个 token 的标准语言建模目标 | 不自动等于学习了所有潜在语义因素 |
| 公共信息（common information） | 在大量样本、分支或任务中重复使用的共享预测因素 | 不是所有样本相同的常数均值 |
| 专属信息（specialized information） | 只在某个条件、分支或子任务下决定目标的因素 | 不是简单的低频 token 身份 |
| 公共子空间 $C$ | 当前祖先模块稳定使用或能够解释的低维方向集合 | 不必等于 PCA 前几个方向 |
| 表示残差 $r$ | 从当前状态中删除公共子空间后的剩余表示 | 不等于功能误差或模型输出误差 |
| 功能残差 | 祖先函数尚未完成的目标部分 | 不等于表示向量差 |
| 线性可读性 | 某个线性读出器能获得高于机会水平的预测性能 | 不等于全部样本具有正间隔 |
| 正低尾间隔 | 至少约 $95\%$ 样本的归一化分类间隔为正 | 不等于真实专家已经获得效用 |
| 功能收益 | 条件专家降低留出预测损失或功能误差 | 不等于标签分类准确率提高 |
| oracle 分支 | 实验中直接使用生成数据时的真实分支变量 | 不解决无标签分支发现问题 |
| 层次化残差学习 | 沿路径不断固定已解释函数，并学习条件剩余 | 不要求各层参数严格正交 |

## 1. 摘要

本文研究一个表征空间层面的宏观问题：

> **语言模型如何将低维的共享信息与条件专属信息，组织成高维隐藏状态中的稳定可分结构？**

现有证据不能支持“高维隐藏状态完全没有类别信息”。相反，Qwen3-30B-A3B 的原生 Router 输入在受控八类任务上具有较高的跨模板线性准确率；但其 $5\%$ 低尾间隔仍为负，说明“平均可读”与“稳定正间隔”是不同属性。更新残差 $R_U$ 还表现为：相对旧状态有条件增量信息，但不能独立形成稳健路由几何。因此当前瓶颈不是简单寻找更好的随机投影，而是解释和生成**任务对齐的可分表示**。

本文给出以下理论链：

1. 满列秩线性升维保持线性函数族，只能按奇异值缩放已有几何间隔，不能创造新的线性可分性；
2. 任务对齐的非线性交互特征可以把原本不可线性分的数据展开为可线性分；
3. 在简化 NTP 二次模型中，高频公共事件产生更大的有效曲率，从而使公共方向在有限时间内更快收敛；
4. 删除公共子空间不会创造新信息，但在公共变化与标签独立时，可以降低有限样本方向估计误差；
5. 条件专家是否必要取决于两个分支的目标函数是否冲突，而不是单个 expert 的 rank 是否“不够大”；
6. 真正推动 margin 转正的是分支条件的表示更新，而不是线性 residualization 本身；
7. 沿树路径不断学习“子树共享函数 + 条件增量”可以得到严格的望远镜分解；
8. 无标签 PCA 分裂只有在分支信号是 residual covariance 中最大可识别 spike 时才成立。

据此，本文只注册一个最小核心实验：在一层 causal Transformer 上构造高频公共任务与低频条件任务，先观察 common-first 是否出现，再在同一冻结 checkpoint 上比较：

- 读取完整状态的 oracle 子专家；
- 读取去 common residual 的 oracle 子专家；
- 不分支的参数量匹配 residual shared adapter。

主裁定要求 residual tree 在冲突任务中同时获得：

- 正的 OOD 低尾归一化 margin；
- 相对 full-state tree 的显著 margin 改善；
- 更低的专属目标 NLL；
- 对公共任务零干扰；
- 在无功能冲突条件下不产生虚假的“树结构收益”。

若这些条件不同时成立，则不能推进到无标签分裂、深树或硬件实现。

## 2. 宏观研究路线与唯一问题

### 2.1 宏观研究路线

当前研究按以下依赖关系推进：

$$
\boxed{
\text{低维任务因素}
\rightarrow
\text{高维表示映射规律}
\rightarrow
\text{NTP 表示形成动力学}
\rightarrow
\text{common residual}
\rightarrow
\text{条件表示更新}
\rightarrow
\text{正 margin 与功能收益}
\rightarrow
\text{无标签分支发现}
\rightarrow
\text{深树与工程实现}
}
$$

每一步的角色不同：

1. **映射规律**回答哪些变换只保持结构，哪些变换能生成结构；
2. **NTP 动力学**回答为什么模型可能先形成 common-dominated 表示；
3. **去 common**回答如何删除与当前分支无关的已解释变化；
4. **条件专家**回答如何学习祖先没有完成的条件函数；
5. **无标签分裂**回答如何在没有真实分支变量时发现 child；
6. **工程实现**只在机制成立后讨论。

### 2.2 下一次组会的唯一宏观问题

> ## 语言模型如何将低维的共享信息与条件专属信息，组织成高维表征中的可分结构？

本轮不是要证明所有真实语言知识都来自一个固定低维向量，也不是要设计最终可部署 MoE。当前只裁定一个候选机制：

> **候选机制 $H_{\mathrm{CR}}$：** 在公共预测模式更频繁的 NTP 数据上，模型会在有限训练时间内优先形成 common-dominated 子空间；冻结该公共函数并从后续表示中删除其已占用子空间，再使用分支条件低秩更新学习功能残差，可以比直接读取完整状态更容易形成稳定 OOD 正间隔和功能收益。

### 2.3 最强竞争解释

- **竞争解释 R1：** 负低尾 margin 与 common 无关；模型只是训练不足或任务本身困难，删除 common 不会改善。
- **竞争解释 R2：** 所有收益来自 oracle 分支或额外参数，而不是 residualization。
- **竞争解释 R3：** 两个分支根本没有功能冲突；多个 experts 只是冗余容量。
- **竞争解释 R4：** common 子空间估计删除了真正有用的分支信号。
- **竞争解释 R5：** margin 改善只是分类几何现象，没有降低真实预测损失。

核心实验必须同时区分这些解释。

## 3. 为什么这个问题容易混淆

### 3.1 低秩不推出不可分

若所有类别都位于一个二维平面内，只要它们沿该平面中的一条方向分开，就可以具有很大的正 margin。因此：

$$
\text{低有效秩}
\not\Rightarrow
\text{线性不可分}.
$$

反之，一个高秩表示可以包含大量与标签无关的变化，仍然具有负低尾 margin。

### 3.2 高平均准确率不推出正低尾 margin

一个线性分类器可以在大多数样本上正确，但在每个类别边缘存在一批负 margin 样本。因此：

$$
\text{高 balanced accuracy}
\not\Rightarrow
\Gamma_{0.05}>0.
$$

现有原生 Router 输入实验正表现为这一现象：跨模板准确率较高，但低尾 margin 仍为负。

### 3.3 表示 residual 不等于功能 residual

表示 residual：

$$
r=(I-P_C)(h-\mu)
$$

删除的是状态空间中的方向。

功能 residual：

$$
e=t-\widehat t_{\mathrm{ancestor}}
$$

描述祖先函数尚未完成的目标。二者需要分别定义，不能因为祖先预测得好，就自动把其输出列空间当成唯一正确的 common 空间。

### 3.4 删除 common 不会创造信息

$r$ 是 $h$ 的确定性线性函数。若 $r$ 上存在一个线性分类器，则与投影复合后，$h$ 上也存在一个线性分类器。因此去 common 的合理作用是：

- 删除与标签无关的高方差变化；
- 降低有限样本估计难度；
- 提高分支方向的相对可识别性；
- 限制 child 不重复读取祖先方向。

它本身不能把真正线性不可分的数据“变成”线性可分。

### 3.5 语义分层不自动等于专家分层

即使标签有“界—门—纲—目”层级，如果不同叶子需要完全相同的预测函数，就没有必要使用多个 specialized experts。专家分裂必须由**条件函数冲突**而不是标签树本身支持。

## 4. 当前证据与会议认识

### 4.1 已完成的 Qwen 证据

已有冻结表征实验建立了三层边界：

1. Qwen3-30B-A3B 的更新残差 $R_U$ 在 31/48 层中对旧状态 $X$ 有显著正的受控条件增量效用；
2. 独立 $R_U$ 没有形成跨模板、正低尾 margin 的线性 Router 空间；
3. 原生 Router 输入 $G_\ell$ 与相邻层差分 $\Delta G_\ell$ 都包含较强跨模板线性类别信息，但低尾 margin 仍然为负。

因此当前最安全的知识更新是：

> **类别相关信息可以存在并被线性读取，但尚未自然组织成覆盖低尾样本的稳定正间隔；“信息存在”“平均可读”“正 margin”“真实专家效用”必须分开。**

### 4.2 组会中固定下来的导师直觉

会议中最重要的修正是把下一层 gating 对象从

$$
E_{\mathrm{parent}}(h)
$$

改为

$$
(I-P_C)(h-\mu).
$$

导师的推理是：

1. 第一个 expert 更可能先学习所有分支共同需要的功能；
2. 直接使用它的输出，只会强调已经相同的部分；
3. 增加 specialized experts 的原因不是简单增加 rank，而是剩余条件函数不能由一个低秩映射兼容；
4. 后续 expert 应学习祖先没有完成的部分，而不是重复 common；
5. 该机制必须在一层 Transformer 合成数据上同时构造 work case 与 non-work case。

会议中关于 NTP 的 common-first 解释仍是猜想，不是已完成证明。本文的理论只在简化二次模型中建立有限时间结论，实验证据由后续一层 Transformer 提供。

## 5. 具体数据与训练布局

本节先定义实验，再给出定理，避免数学对象与实证对象脱节。

### 5.1 潜在变量

每条合成序列由以下变量生成：

- 公共风格变量：$c\in\{0,\ldots,7\}$；
- payload：$q\in\{0,\ldots,7\}$；
- 分支：$b\in\{0,1\}$；
- 两个表面 nuisance：$u,v\in\{0,\ldots,31\}$；
- 任务类型：$t\in\{\mathrm C,\mathrm S\}$，分别表示公共任务和专属任务。

### 5.2 词表

词表由以下 token 组成：

- 结构 token：`<BOS>`, `<TASK_C>`, `<TASK_S>`, `<BR_NULL>`, `<BR_0>`, `<BR_1>`, `<QUERY>`, `<ANSWER>`, `<EOS>`；
- 风格 token：`<STYLE_0>` 到 `<STYLE_7>`；
- payload token：`<PAYLOAD_0>` 到 `<PAYLOAD_7>`；
- nuisance token：两组 `<N1_0>` 到 `<N1_31>`、`<N2_0>` 到 `<N2_31>`；
- 输出 token：`<OUT_0>` 到 `<OUT_7>`。

总词表大小为 $97$。

### 5.3 序列形式

所有序列长度相同。公共任务序列为：

```text
<BOS> <TASK_C> <STYLE_c> <PAYLOAD_q> <BR_NULL>
<N1_u> <N2_v> <QUERY> <ANSWER> <OUT_{rho(c)}> <EOS>
```

专属任务序列为：

```text
<BOS> <TASK_S> <STYLE_c> <PAYLOAD_q> <BR_b>
<N1_u> <N2_v> <QUERY> <ANSWER> <OUT_{pi_b(q)}> <EOS>
```

其中

$$
\rho(c)=c.
$$

公共任务要求模型根据 style 预测输出；payload、branch 和 nuisance 对公共目标无关。


四种表面模板只改变前缀 token 的顺序，不改变可用信息或目标函数：

```text
T0: TASK STYLE PAYLOAD BRANCH N1 N2 QUERY ANSWER
T1: TASK N1 STYLE PAYLOAD N2 BRANCH QUERY ANSWER
T2: STYLE TASK N2 PAYLOAD BRANCH N1 QUERY ANSWER
T3: N2 TASK PAYLOAD STYLE N1 BRANCH QUERY ANSWER
```

四种模板在 TRAIN、DEV、TEST-ID 和 TEST-OOD 中都出现且严格平衡。OOD 不依赖未见 token 或未见模板，只改变 style 与 payload 的统计关系。

### 5.4 Work case：存在功能冲突

定义：

$$
\pi_0(q)=q,
\qquad
\pi_1(q)=(q+4)\bmod 8.
$$

对于同一个 payload，不同分支要求不同输出。因此单一、无条件共享函数无法同时实现两个映射。

### 5.5 Non-work case：不存在功能冲突

定义：

$$
\pi_0(q)=\pi_1(q)=q.
$$

分支标签仍然存在，但目标函数相同。该条件用于检验多 experts 的收益是否只是额外参数或 oracle 分支造成。

### 5.6 高频 common 条件与平衡对照

Stage 1 使用两种数据频率：

- common-heavy：
  $$
  p_{\mathrm C}=0.9,\qquad p_{\mathrm S}=0.1;
  $$
- balanced control：
  $$
  p_{\mathrm C}=p_{\mathrm S}=0.5.
  $$

两种条件具有相同总 episode 数、相同模型、相同优化步数和相同随机种子。它们只改变公共任务与专属任务的出现概率。

### 5.7 训练—开发—确认划分

| 划分 | 数量 | 用途 | 是否可用于选择 |
|---|---:|---|---|
| TRAIN-1 | 64,000 | Stage 1 联合 NTP 训练 | 是 |
| DEV-1 | 8,000 | common-first checkpoint 判定 | 是 |
| TRAIN-2 | 16,384 个专属 episode | Stage 2 child 训练 | 是 |
| DEV-2 | 4,096 个专属 episode | Stage 2 checkpoint 选择 | 是 |
| TEST-ID | 8,192 个专属 episode | 同分布确认 | 否 |
| TEST-OOD | 8,192 个专属 episode | nuisance 关系反转确认 | 否 |
| TEST-COMMON | 8,192 个公共 episode | common 保持性确认 | 否 |

所有 split 在完整 tuple

$$
(t,c,q,b,u,v,\text{template id})
$$

上互斥。

### 5.8 OOD 构造

定义二元组：

$$
g(c)=\mathbf 1[c\ge4],
\qquad
g(q)=\mathbf 1[q\ge4].
$$

在 TRAIN-2、DEV-2 与 TEST-ID 中：

$$
\Pr[g(c)=g(q)]=0.9.
$$

在 TEST-OOD 中反转为：

$$
\Pr[g(c)=g(q)]=0.1.
$$

专属目标始终只由 $(b,q)$ 决定，与 $c$ 无关。这样 style 是训练分布中的高频伪相关因素，OOD 时失效。该构造直接检验删除 common/style 子空间是否提高稳健性。

### 5.9 模型架构

使用一层 pre-norm causal Transformer：

- 隐藏维数 $d=64$；
- 注意力头数 $4$；
- 每头维数 $16$；
- dropout $0$；
- RoPE 位置编码；
- tied token embedding / LM head；
- root 低秩 FFN：
  $$
  E_0(h)=B_0\,\operatorname{GELU}(A_0h),
  $$
  其中
  $$
  A_0\in\mathbb R^{8\times64},
  \qquad
  B_0\in\mathbb R^{64\times8}.
  $$

在 `<ANSWER>` 位置，Stage 1 状态记为 $h_0$。

root 已占用候选子空间定义为：

$$
C=\operatorname{col}(B_0).
$$

用 TRAIN-2 状态均值 $\mu$ 居中，并先定义完整居中输入：

$$
\bar h=h_0-\mu.
$$

然后定义：

$$
P_C=B_0(B_0^\top B_0)^\dagger B_0^\top,
$$

$$
r=(I-P_C)\bar h.
$$

### 5.10 Stage 2 候选结构

child rank 为 $r_e=4$。

#### 条件 A：Root-only

不添加 child，仅评估 Stage 1 checkpoint。

#### 条件 B：Full-state tree

使用 oracle 分支选择两个 child：

$$
h^+
=
h_0+
B_b\operatorname{GELU}(A_b\bar h).
$$

#### 条件 C：Residual tree

$$
h^+
=
h_0+
B_b\operatorname{GELU}(A_br).
$$

#### 条件 D：Residual shared

不使用 branch，训练一个 rank-$8$ 的共享 adapter：

$$
h^+
=
h_0+
B_{\mathrm{sh}}
\operatorname{GELU}(A_{\mathrm{sh}}r).
$$

rank-$8$ shared adapter 与两个 rank-$4$ children 具有近似相同总参数量，并拥有更高单样本活动 rank，因此它是偏向共享模型的保守对照。

### 5.11 冻结边界

进入 Stage 2 后冻结：

- token embedding；
- attention；
- root expert；
- normalization；
- LM head。

只训练新增 adapter。child 只在 `<TASK_S>` episode 上激活；公共任务完全旁路 child。因此 common 输出在参数和前向路径上都应逐样本不变。

## 6. 定义与主度量

### 6.1 线性可分性

对多类表示 $h_i$，若存在 affine scores

$$
s_k(h)=w_k^\top h+b_k
$$

使每个样本满足

$$
s_{y_i}(h_i)>s_k(h_i),
\qquad
\forall k\ne y_i,
$$

则该有限样本集线性可分。

### 6.2 归一化多类 margin

令最强错误类别为

$$
k_i^*
=
\arg\max_{k\ne y_i}s_k(h_i).
$$

归一化样本 margin 定义为：

$$
\widetilde\gamma_i
=
\frac{
s_{y_i}(h_i)-s_{k_i^*}(h_i)
}{
\|w_{y_i}-w_{k_i^*}\|_2
}.
$$

低尾 margin：

$$
\widetilde\Gamma_{0.05}
=
Q_{0.05}(\widetilde\gamma_i).
$$

该指标消除简单缩放分类权重带来的 logit margin 变化。

主分析中的错误类别集合是**完整词表中的所有错误 token**；另行报告只在八个 `<OUT_k>` 之间计算的 output-only margin 作为诊断，但它不承担主裁定。

### 6.3 专属目标 NLL

只在 `<ANSWER>` 后的真实专属输出 token 上计算：

$$
\mathcal L_{\mathrm S}
=
-\frac1N
\sum_i
\log p_\theta
\left(
\operatorname{OUT}_{\pi_{b_i}(q_i)}
\mid x_{i,<\mathrm{target}}
\right).
$$

### 6.4 common-first 诊断

定义：

- $t_C$：DEV-1 common target accuracy 首次达到 $98\%$ 且 NLL 不高于 $0.08$ 的 checkpoint；
- $t_S^+$：DEV-1 specialized $\widetilde\Gamma_{0.05}$ 首次严格大于 $0$ 的 checkpoint；
- 若在预算内未转正，则记为右删失。

common-first 延迟：

$$
D_{\mathrm{CF}}=t_S^+-t_C.
$$

主要诊断比较 common-heavy 与 balanced control 的 $D_{\mathrm{CF}}$。

### 6.5 表示保留诊断

在 TRAIN-2 上分别拟合线性 probes，并在 TEST-OOD 上评估：

- style 可读性：$c$；
- payload 可读性：$q$；
- branch 可读性：$b$。

候选 residual 应满足：

- style 可读性显著下降；
- payload 与 branch 可读性不发生灾难性下降。

这些是机制守卫，不是主结论指标。

## 7. 数学模型

### 7.1 潜在因素与高维表示

用

$$
z=(c,s)
$$

表示低维任务因素，其中：

- $c$ 是公共因素；
- $s$ 是条件专属因素。

训练映射为：

$$
h=F_\theta(z,\xi)\in\mathbb R^d,
$$

其中 $\xi$ 表示表面 nuisance。

研究重点不是 $d$ 是否“大”，而是：

1. $F_\theta$ 是否保留了 $s$；
2. $F_\theta$ 是否生成了目标对齐交互特征；
3. $s$ 的信号幅度是否足以形成稳定 margin；
4. 高维 nuisance 是否提高了有限样本估计难度。

### 7.2 common-first 的局部二次模型

令参数分成正交块：

$$
\theta=(\theta_C,\theta_S).
$$

局部期望损失为：

$$
\mathcal L(\theta)
=
\frac{\lambda_C}{2}
\|\theta_C-\theta_C^*\|_2^2
+
\frac{\lambda_S}{2}
\|\theta_S-\theta_S^*\|_2^2,
$$

其中：

$$
\lambda_C=p_Ca_C,
\qquad
\lambda_S=p_Sa_S.
$$

$p_C,p_S$ 是两类训练事件频率，$a_C,a_S$ 是单事件平均局部曲率。

### 7.3 common nuisance 模型

表示写成：

$$
h=y\mu+c+\varepsilon,
$$

其中：

- $y\in\{-1,+1\}$；
- $\mu$ 是判别方向；
- $c\sim\mathcal N(0,\tau_C^2P_C)$ 是标签无关的样本变化 common nuisance；
- $\varepsilon\sim\mathcal N(0,\sigma^2I_d)$；
- 理想条件下 $\mu\in C^\perp$。

### 7.4 层次条件函数

叶子路径为：

$$
b_{1:L}\in\{-1,+1\}^L.
$$

叶子目标函数为：

$$
f_{b_{1:L}}(q).
$$

层次专家的理想职责不是学习标签名称，而是分解该条件函数。

## 8. 定理、命题与证明

### 定理 1：满列秩线性升维保持 affine 线性可分性

设：

$$
h_i=Az_i+c,
\qquad
A\in\mathbb R^{d\times r},
\qquad
\operatorname{rank}(A)=r.
$$

则有限标记样本 $\{(z_i,y_i)\}$ 在潜在空间 affine 线性可分，当且仅当 $\{(h_i,y_i)\}$ 在高维空间 affine 线性可分。

#### 证明

若潜在空间存在：

$$
s_k(z)=u_k^\top z+\beta_k,
$$

定义：

$$
w_k=A(A^\top A)^{-1}u_k,
$$

$$
b_k=\beta_k-w_k^\top c.
$$

因为：

$$
A^\top w_k
=
A^\top A(A^\top A)^{-1}u_k
=
u_k,
$$

故：

$$
w_k^\top(Az+c)+b_k
=
u_k^\top z+\beta_k.
$$

潜在空间的每个 score 在高维像空间中被精确复现。

反之，若高维空间存在：

$$
s_k(h)=w_k^\top h+b_k,
$$

令：

$$
u_k=A^\top w_k,
\qquad
\beta_k=w_k^\top c+b_k.
$$

则：

$$
w_k^\top(Az+c)+b_k
=
u_k^\top z+\beta_k.
$$

因此高维分类器也可在潜在空间精确复现。证毕。

#### 结论

维数从 $r$ 增加到 $d$ 本身不会创造新的 affine 线性函数族。需要产生新可分结构时，必须依赖非线性或信息改变。

---

### 定理 2：线性升维对几何 margin 的奇异值界

设 $\sigma_{\min}(A)$、$\sigma_{\max}(A)$ 为 $A$ 的最小和最大非零奇异值。令 $\gamma_Z^*$ 与 $\gamma_H^*$ 分别为潜在空间与高维像空间的最优归一化多类几何 margin。若 $\gamma_Z^*>0$，则：

$$
\boxed{
\sigma_{\min}(A)\gamma_Z^*
\le
\gamma_H^*
\le
\sigma_{\max}(A)\gamma_Z^*
}.
$$

#### 证明

给定潜在分类器 $u_k,\beta_k$，使用定理 1 的构造：

$$
w_k=A(A^\top A)^{-1}u_k.
$$

对任意 pair difference $v=u_y-u_k$，SVD 给出：

$$
\|A(A^\top A)^{-1}v\|_2
\le
\frac{\|v\|_2}{\sigma_{\min}(A)}.
$$

score 差不变，因此高维归一化 margin 至少是潜在 margin 的 $\sigma_{\min}(A)$ 倍。对潜在最优分类器取上确界，得到左侧不等式。

对任意高维分类器，先把每个 $w_k$ 正交投影到 $\operatorname{col}(A)$。该操作不改变像空间样本上的 score，并且不会增大 pairwise weight norm，所以最优分类器可假设位于 $\operatorname{col}(A)$。定义：

$$
u_k=A^\top w_k.
$$

对任意 $w_y-w_k\in\operatorname{col}(A)$：

$$
\|A^\top(w_y-w_k)\|_2
\le
\sigma_{\max}(A)\|w_y-w_k\|_2.
$$

所以相应潜在 margin 至少为高维 margin 的 $1/\sigma_{\max}(A)$。对高维最优分类器取上确界，得到右侧不等式。证毕。

#### 特例

若：

$$
A^\top A=I_r,
$$

则：

$$
\gamma_H^*=\gamma_Z^*.
$$

因此 isometric 升维严格保持归一化 margin。

---

### 定理 3：固定线性映射不能创造线性可分性

若标签映射不能由原空间任意 affine 线性分类器实现，则对任意固定线性映射 $P$，投影空间中的 affine 线性分类器也不能实现该标签映射。

#### 证明

若投影后存在：

$$
s(h)=W'Ph+b',
$$

则复合：

$$
W'P
$$

本身就是原空间线性权重，与前提矛盾。证毕。

#### 边界

一次注册 probe 失败不能证明“不存在任何线性分类器”；它只说明在给定数据、probe 族和统计功效下没有发现稳定结构。

---

### 定理 4：任务对齐的非线性特征可以创造线性可分性

令：

$$
z=(z_1,z_2)\in\{-1,+1\}^2,
\qquad
y=z_1z_2.
$$

该 XOR 标签在原二维空间中不可线性分；但在特征映射：

$$
\phi(z)=(z_1,z_2,z_1z_2)
$$

下可由：

$$
y=\operatorname{sign}(e_3^\top\phi(z))
$$

精确线性分类。

#### 证明

XOR 的两个正样本为 $(1,1)$、$(-1,-1)$，两个负样本为 $(1,-1)$、$(-1,1)$。正负两类凸包都包含原点，因此不存在严格分离超平面。映射后第三坐标恰为 $y$，故用第三坐标即可分类。证毕。

#### 结论

“高维展开”的关键不是维数本身，而是是否加入目标对齐的交互特征。

---

### 定理 5：高频 common 事件导致更快的有限时间收敛

对局部二次损失：

$$
\mathcal L(\theta)
=
\frac{\lambda_C}{2}
\|\theta_C-\theta_C^*\|^2
+
\frac{\lambda_S}{2}
\|\theta_S-\theta_S^*\|^2,
$$

使用步长：

$$
0<\eta<\frac1{\max(\lambda_C,\lambda_S)}
$$

的梯度下降。若：

$$
\lambda_C>\lambda_S>0,
$$

则对任意 $t>0$：

$$
\frac{
\|\theta_C^{(t)}-\theta_C^*\|
}{
\|\theta_C^{(0)}-\theta_C^*\|
}
=
(1-\eta\lambda_C)^t
<
(1-\eta\lambda_S)^t
=
\frac{
\|\theta_S^{(t)}-\theta_S^*\|
}{
\|\theta_S^{(0)}-\theta_S^*\|
}.
$$

#### 证明

两个参数块的更新相互解耦：

$$
\theta_C^{(t+1)}-\theta_C^*
=
(1-\eta\lambda_C)
(\theta_C^{(t)}-\theta_C^*),
$$

$$
\theta_S^{(t+1)}-\theta_S^*
=
(1-\eta\lambda_S)
(\theta_S^{(t)}-\theta_S^*).
$$

递推即可。由于步长范围保证两个因子都在 $(0,1)$，且 $\lambda_C>\lambda_S$，公共误差收缩更快。证毕。

#### NTP 对应

在简化 mixture 中：

$$
\lambda_C=p_Ca_C,
\qquad
\lambda_S=p_Sa_S.
$$

所以 common-first 可能来自更高出现概率、更大单样本曲率，或二者共同作用。

#### 不能声称

该定理不是对真实 Transformer + AdamW 的全局证明，只说明导师直觉在局部正交二次模型中是自洽的。

### 定理 6：specialized margin 的有限时间转正阈值

假设专属方向幅度按：

$$
a_S(t)=1-(1-\eta\lambda_S)^t
$$

增长，表示沿单位方向 $u$ 满足：

$$
h_t=y\mu a_S(t)u+\varepsilon,
$$

其中：

$$
u^\top\varepsilon\sim\mathcal N(0,\sigma^2).
$$

使用 $u$ 作为归一化二分类读出方向，则：

$$
\Gamma_{0.05}(t)
=
\mu a_S(t)-1.64485\sigma.
$$

因此 margin 转正当且仅当：

$$
a_S(t)>
\frac{1.64485\sigma}{\mu}.
$$

#### 证明

signed margin 为：

$$
yu^\top h_t
=
\mu a_S(t)+yu^\top\varepsilon.
$$

由于高斯分布关于零对称，$yu^\top\varepsilon$ 仍服从 $\mathcal N(0,\sigma^2)$。其 $5\%$ 分位数为 $-1.64485\sigma$。证毕。

#### 解释

common-first 不必导致永久不可分，但会在有限训练时间内造成 specialized margin deficit。

### 定理 7：删除标签无关 common nuisance 降低有限样本估计误差

设：

$$
h_i=y_i\mu+c_i+\varepsilon_i,
$$

其中：

$$
c_i\sim\mathcal N(0,\tau_C^2P_C),
\qquad
\varepsilon_i\sim\mathcal N(0,\sigma^2I_d),
\qquad
\mu\in C^\perp.
$$

定义均值差估计器：

$$
\widehat\mu_h
=
\frac1n\sum_{i=1}^ny_ih_i.
$$

则：

$$
\mathbb E\widehat\mu_h=\mu,
$$

且：

$$
\boxed{
\mathbb E\|\widehat\mu_h-\mu\|_2^2
=
\frac{
\tau_C^2\dim(C)+\sigma^2d
}{n}
}.
$$

对 residual：

$$
r_i=(I-P_C)h_i,
$$

定义：

$$
\widehat\mu_r
=
\frac1n\sum_i y_ir_i.
$$

则：

$$
\boxed{
\mathbb E\|\widehat\mu_r-\mu\|_2^2
=
\frac{
\sigma^2(d-\dim C)
}{n}
}.
$$

#### 证明

因为 $y_i^2=1$，且 $c_i,\varepsilon_i$ 与 $y_i$ 独立、均值为零：

$$
\widehat\mu_h-\mu
=
\frac1n
\sum_i
y_i(c_i+\varepsilon_i).
$$

其协方差为：

$$
\frac1n
(\tau_C^2P_C+\sigma^2I_d).
$$

对协方差取 trace 即得第一式。

由于 $\mu\in C^\perp$：

$$
r_i
=
y_i\mu+(I-P_C)\varepsilon_i.
$$

同理，误差协方差为：

$$
\frac{\sigma^2}{n}(I-P_C),
$$

trace 为 $\sigma^2(d-\dim C)/n$。证毕。

#### 样本复杂度推论

由 Markov 不等式，若希望：

$$
\|\widehat\mu-\mu\|
\le
\epsilon\|\mu\|
$$

以至少 $1-\delta$ 的概率成立，一个保守充分条件是：

$$
n
\ge
\frac{
\operatorname{tr}(\Sigma)
}{
\delta\epsilon^2\|\mu\|^2
}.
$$

residualization 删除了：

$$
\tau_C^2\dim(C)
$$

这一标签无关项。

### 命题 8：当分支信号与 common 重叠时，删除 common 会丢失信息

若：

$$
\mu=\mu_C+\mu_\perp,
\qquad
\mu_C=P_C\mu\ne0,
$$

则：

$$
(I-P_C)h
$$

中的判别均值只剩：

$$
\mu_\perp.
$$

因此 residualization 损失的信号能量为：

$$
\|\mu_C\|_2^2.
$$

这是必须构造的失败条件，而不是实现 bug。

### 定理 9：层次条件函数的望远镜分解

对任意树节点 $v$，令 $\mathcal L(v)$ 为其后代叶集合，定义子树平均函数：

$$
f_v(q)
=
\frac1{|\mathcal L(v)|}
\sum_{\ell\in\mathcal L(v)}f_\ell(q).
$$

对 child $vs$ 定义：

$$
\Delta_{v,s}(q)
=
f_{vs}(q)-f_v(q).
$$

则任意叶路径 $b_{1:L}$ 满足：

$$
\boxed{
f_{b_{1:L}}(q)
=
f_{\varnothing}(q)
+
\sum_{j=1}^{L}
\Delta_{b_{1:j-1},b_j}(q)
}.
$$

#### 证明

右侧为：

$$
f_\varnothing
+
(f_{b_1}-f_\varnothing)
+
(f_{b_{1:2}}-f_{b_1})
+\cdots+
(f_{b_{1:L}}-f_{b_{1:L-1}}).
$$

中间项逐项抵消，只剩叶函数。证毕。

#### 解释

“不断减去 common”更严格的函数表述是：每个节点保存该子树共享函数，child 只学习相对 parent 的条件增量。该定理不要求不同层的参数子空间天然正交。

### 定理 10：功能冲突决定 specialized experts 是否必要

令 $b\in\{+,-\}$ 等概率，payload $q$ 满足：

$$
\mathbb E q=0,
\qquad
\operatorname{Cov}(q)=\Sigma_q.
$$

目标函数为：

$$
t=M_bq.
$$

单共享线性 expert $Mq$ 的风险：

$$
R_{\mathrm{shared}}(M)
=
\mathbb E\|Mq-M_bq\|_2^2.
$$

其最优解为：

$$
M^*=\frac12(M_++M_-),
$$

最小风险为：

$$
\boxed{
R_{\mathrm{shared}}^*
=
\frac14D
},
$$

其中：

$$
D
=
\operatorname{tr}
\left[
(M_+-M_-)\Sigma_q(M_+-M_-)^\top
\right].
$$

oracle 两专家风险为零。若错误路由概率为 $\eta$，且与 $q$ 独立，则：

$$
R_{\mathrm{tree}}=\eta D.
$$

所以 tree 优于最优共享 expert 的充分必要条件为：

$$
\eta<\frac14.
$$

#### 证明

将风险写成：

$$
\frac12
\|(M-M_+)\Sigma_q^{1/2}\|_F^2
+
\frac12
\|(M-M_-)\Sigma_q^{1/2}\|_F^2.
$$

完成平方可得最优解为平均矩阵，剩余项为 $D/4$。正确路由时误差为零；错误路由时输出差为 $(M_+-M_-)q$，其期望平方范数为 $D$。证毕。

#### 结论

若 $M_+=M_-$，则 $D=0$，多个 experts 没有功能必要性。

### 定理 11：受保护 child 的输入隔离与祖先线性读出保持

设祖先已用子空间为 $C$，祖先需要保护的线性读出堆叠为：

$$
W_A\in\mathbb R^{m\times d}.
$$

定义：

$$
P_K
=
I-
W_A^\top
(W_AW_A^\top)^\dagger
W_A.
$$

child 更新为：

$$
\delta(h)
=
P_KB\,
\phi\left(
A(I-P_C)(h-\mu)
\right).
$$

则：

1. 对任意 $c\in C$：
   $$
   \delta(h+c)=\delta(h);
   $$
2. 对任意 $h$：
   $$
   W_A\delta(h)=0.
   $$

#### 证明

因为：

$$
(I-P_C)c=0,
$$

第一式成立。

$P_K$ 是 $\ker(W_A)$ 的正交投影，因此：

$$
W_AP_K=0.
$$

故第二式成立。证毕。

#### 实验中的简化

本轮 child 只在专属任务 episode 上激活，公共任务完全旁路 child，因此公共输出获得更强的结构性零干扰。输出零空间保护保留为后续“同一 token 同时需要祖先与 child”时的扩展。

### 定理 12：正确分支条件更新可以使 margin 转正

设 residual：

$$
r=y\mu u+\varepsilon,
\qquad
\|u\|_2=1,
\qquad
u^\top\varepsilon\sim\mathcal N(0,\sigma^2).
$$

oracle child 添加：

$$
\delta_y=ayu,
\qquad a>0.
$$

则更新前后 $5\%$ signed margin 分别为：

$$
\Gamma_{0.05}^{\mathrm{before}}
=
\mu-1.64485\sigma,
$$

$$
\boxed{
\Gamma_{0.05}^{\mathrm{after}}
=
\mu+a-1.64485\sigma
}.
$$

当：

$$
a>1.64485\sigma-\mu
$$

时，更新后 margin 转正。

#### 证明

更新后：

$$
yu^\top(r+\delta_y)
=
\mu+a+yu^\top\varepsilon.
$$

取高斯 $5\%$ 分位数即得。证毕。

#### 结论

真正生成新 margin 的是分支条件更新；删除 common 只改变 child 看到的输入统计。

### 命题 13：PCA 分裂的成功条件与严格反例

设 residual：

$$
r=b\alpha u+\eta q+\varepsilon,
$$

其中 $u\perp q$，$b$ 平衡，$\eta$ 与 $b$ 独立，且：

$$
\operatorname{Var}(\eta)=\tau^2,
\qquad
\varepsilon\sim\mathcal N(0,\sigma^2I).
$$

则：

$$
\operatorname{Cov}(r)
=
\alpha^2uu^\top
+
\tau^2qq^\top
+
\sigma^2I.
$$

- 若 $\alpha^2>\tau^2$，第一主成分为 $u$；
- 若 $\tau^2>\alpha^2$，第一主成分为 $q$，与分支 $b$ 独立；
- 若相等，第一主方向不可识别。

因此 PCA 不是通用语义分裂器。无标签 split 只能在 oracle tree 机制成立后作为下一独立问题研究。

### 引理 14：common projector 估计误差的扰动界

若：

$$
\|\widehat P_C-P_C\|_2\le\delta,
\qquad
\|h-\mu\|_2\le R,
$$

则真实与估计 residual 满足：

$$
\|\widehat r-r\|_2
\le
\delta R.
$$

#### 证明

$$
\widehat r-r
=
(P_C-\widehat P_C)(h-\mu),
$$

直接应用算子范数界。证毕。

若归一化线性分离 margin 为 $\gamma$，则当：

$$
\delta R<\gamma
$$

时，单个二分类决策的符号不被该 residual 误差改变。

| common nuisance | full state 对比 residual | OOD margin、style probe | 去 common 不是当前瓶颈 |
| 功能冲突 | Work 对比 Non-work | tree 与 shared NLL gap | 多 experts 只提供容量 |
| 条件更新生成 margin | root-only 对比 residual tree | $\widetilde\Gamma_{0.05}$ | 机制核心失败 |
| common 保护 | child 仅专属 episode 激活 | common logits 漂移 | 实现未满足架构契约 |
| PCA 可识别性 | 暂不进入主实验 | 后续 oracle 与 PCA gap | 分支发现与专家机制分开 |

## 10. 唯一核心实验协议

### 10.1 Approval snapshot

**决策问题。**

> 在一层 NTP 模型中，高频公共任务是否导致有限时间的 specialized margin deficit；在同一个冻结 checkpoint 上，去除 root 已占用子空间后进行 oracle branch-conditioned low-rank learning，是否比读取完整状态更容易获得 OOD 正 margin 与功能收益？

**主假设。**

$$
H_{\mathrm{CR}}:
\quad
\text{common-heavy}
\Rightarrow
\text{common-first}
\Rightarrow
\text{residual tree 优于 full tree}.
$$

**最强竞争解释。** residual tree 的任何收益来自 oracle gate 或额外参数，而不是去 common；或任务不存在功能冲突。

**处理组。** Residual tree。

**核心对照。** Full-state tree、Residual shared、Root-only。

**只改变的变量。**

- Full vs Residual：child 输入是否经过 $I-P_C$；
- Tree vs Shared：是否按 oracle branch 选择 child；
- Work vs Non-work：两个分支目标函数是否不同；
- Common-heavy vs Balanced：公共任务频率。

**保持不变。**

数据规模、模型、Stage 1 checkpoint、child 初始化、总训练步数、优化器、LM head、分支信息、测试集和随机种子。

**主指标。**

$$
\Delta\Gamma_{\mathrm{OOD}}
=
\widetilde\Gamma_{0.05}^{\mathrm{ResidualTree}}
-
\widetilde\Gamma_{0.05}^{\mathrm{FullTree}}.
$$

**Pass。**

以下条件必须同时成立：

1. 五个种子中至少四个满足 common-heavy 的 specialized margin 转正时间比 balanced 晚至少 $500$ steps；若 balanced 在预算内转正而 common-heavy 未转正，也记为该 seed 支持延迟；若两者都未转正，则该 seed 为 `INSUFFICIENT`；
2. Work case 中 residual tree 的 OOD $\widetilde\Gamma_{0.05}$ 的 $95\%$ 下界 $>0$；
3. Work case 中 $\Delta\Gamma_{\mathrm{OOD}}$ 的 $95\%$ 下界 $>0$；
4. residual tree 相对 full tree 的 OOD specialized NLL 差的 $95\%$ 上界 $<-0.02$ nat/target-token；
5. residual tree 相对 parameter-matched residual shared 的 OOD NLL 差的 $95\%$ 上界 $<-0.02$ nat/target-token；
6. Non-work case 中 residual tree 与 residual shared 达成功能等价：二者 OOD NLL 差的 $95\%$ 区间完全落在 $[-0.01,0.01]$ nat/target-token；
7. TEST-COMMON 上逐样本 logits 最大绝对漂移 $\le10^{-6}$。

**Fail。**

Stage 1 premise 已实现，但上述主几何或功能条款不成立。

**Insufficient。**

发生以下任一情况：

- Stage 1 未出现“common 已学会、specialized margin 尚未转正”的合格 checkpoint；
- data guard、split guard、参数匹配或前向零漂移 guard 失败；
- 任何主条件未完成五个种子；
- TEST 在模型冻结前被打开。

**不能声称。**

即使 Pass，也不能声称真实语言 NTP 必然如此、PCA 能发现分支、真实 MoE 会获得收益、深树可部署或硬件高效。

**最小批准范围。**

先批准数据生成与单种子 smoke；smoke 通过后另行批准五种子正式运行。

### 10.2 Block A：问题与结论边界

状态：`PROPOSED`

- 一次只判断 common-first + residual conditional learning 这一条机制；

- 正 margin 与 NLL 改善必须同时出现；
- Qwen 证据只作为问题来源，不作为合成实验结果。

### 10.3 Block B：数据构造与来源

状态：`PROPOSED`

必须实现的生成检查：

1. Work case 中对每个 $q$：
   $$
   \pi_0(q)\ne\pi_1(q);
   $$
2. Non-work 中：
   $$
   \pi_0(q)=\pi_1(q);
   $$
3. 专属目标与 style 条件独立：
   $$
   Y_S\perp c\mid(b,q);
   $$

### 10.4 Block C：学习任务与监督

状态：`PROPOSED`

Stage 1：

- 输入：完整 causal prefix；
- 输出：下一个 token；
- 目标：标准 token-level cross entropy；
- 允许监督：序列中的真实 next token；
- 禁止：显式 margin loss、branch classification loss、TEST 信息。

Stage 2：

- 只在专属任务的指定答案位置优化 next-token cross entropy；更早的结构 token 不参与 Stage 2 loss；
- oracle $b$ 仅决定选哪个 child，不作为额外分类 loss；
- Full 与 Residual 使用完全相同的 oracle gate。

状态：`PROPOSED`

- weight decay $0.01$；

在实现 Transformer 前，运行一个确定性 NumPy/PyTorch 单元测试：

### 11.1 潜在维数与高维维数

$$
r\in\{2,4,8,16\},
$$

$$
d\in\{r,4r,16r\}.
$$

### 11.2 映射

1. Isometric：
   $$
   A^\top A=I;
   $$
2. Ill-conditioned：
   $$
   A=Q\operatorname{diag}(1,\ldots,\kappa^{-1})V^\top,
   \quad
   \kappa\in\{10,100\};
   $$
3. Rank-deficient：
   删除真实判别方向；
4. XOR feature：
   加入乘积特征。

### 11.3 必须复现实象

- isometric 时 normalized margin 数值误差内保持；
- ill-conditioned 时 margin 位于定理 2 上下界；
- rank-deficient 时可分性可能丢失；
- 纯线性映射不能使 XOR 可分；
- 加入 $z_1z_2$ 后 XOR 可分。

若这些检查失败，不进入 Transformer 实验。

## 12. 预期结果与研究决策

### 12.1 支持机制的结果

预期模式：

1. common-heavy 的 common NLL 更早收敛；
2. common-heavy 的 specialized margin 转正明显晚于 balanced；
3. full state 中 style probe 很高；
4. residual 后 style probe 下降，payload/branch 保留；
5. Work case residual tree 的 OOD margin 转正；
6. residual tree 同时优于 full tree 与 residual shared；
7. Non-work tree 不优于 residual shared；
8. common logits 精确不变。

允许结论：

> 在该受控一层 NTP 数据生成过程、有限训练预算和 oracle gate 下，高频 common 学习会形成可测的 specialized margin delay；删除 root 已占用子空间提高了条件 residual learning 的 OOD 几何与功能效率，而多个 experts 的必要性来自分支函数冲突。

### 12.2 common-first 不出现

若 common-heavy 与 balanced 没有稳定差异：

允许结论：

> 当前数据或模型没有支持“频率导致 common-first”这一具体机制。

下一步不是继续树结构，而是审查：

- common/specialized 单样本曲率是否不同；
- common 任务是否真的迫使 root 使用独立子空间；
- 标准 NTP 结构 token loss 是否稀释了目标。

### 12.3 oracle residual tree 失败

若 $t^*$ 已实现，但 residual tree 不改善：

允许结论：

> 仅依靠删除 root 输出列空间和 oracle child，并不足以生成正 margin。

这直接削弱当前中心机制。不得进入 PCA 或深树。

### 12.4 residual tree 只改善 margin，不改善 NLL

允许结论：

> 产生了标签几何变化，但没有证明专家功能收益。

下一步应审查 margin 指标是否与目标函数错位，而不是宣布 MoE 成功。

### 12.5 residual tree 与 full tree 相同

允许结论：

> common nuisance 在当前样本量和优化条件下不是决定性瓶颈；完整状态 child 能够自行忽略它。

这与定理 7 不矛盾，因为 residualization 的优势是有限样本统计优势，不是表达能力优势。

### 12.6 Work 成功但 Non-work 也成功

允许结论：

> 结果被额外参数、课程或实现差异混杂，不能归因于功能冲突。

必须先修复 shared control。

### 12.7 Oracle 成功后 PCA 失败

该结果尚不属于本轮，但其正确解释是：

> 条件专家机制可能成立，无标签分支识别尚未解决。

不能把它写成整个 residual tree 失败。

## 13. 结论边界

本文理论严格支持：

1. 满列秩线性升维保持 affine 线性函数族；
2. 线性映射不能创造原空间不存在的线性可分性；
3. 非线性交互可以创造新可分特征；
4. 简化二次模型中更大有效曲率导致更快有限时间学习；
5. 标签无关 high-variance common 会提高有限样本方向估计误差；
6. 分支函数冲突给出 specialized experts 的必要性；
7. 分支条件更新可以显式增加 margin；
8. 层次函数可以按子树 common 与条件增量望远镜分解；
9. PCA split 需要可识别 spike。

本文不能证明：

1. 真实语言语义具有固定的低维欧氏坐标；
2. 真实大模型的 NTP 全局动力学等价于二次模型；
3. Qwen 的负低尾 margin 由 common-first 唯一造成；
4. $\operatorname{col}(B_0)$ 是唯一正确 common 空间；
5. oracle gate 可以被无标签 PCA 稳定恢复；
6. 单层结果可直接递归到深树；
7. 该结构硬件友好或优于工业 MoE；
8. 正语义 margin 必然带来真实 expert utility。
