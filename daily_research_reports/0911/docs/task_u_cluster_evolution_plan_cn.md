## 1. 对象锁定

| 项 | 取值 | 理由 |
|---|---|---|
| 主对象 | \(h_i(t)\)：固定记录、答案前位置、最后前馈模块之前的 1024 维向量 | 路由器与专家共同读取的向量；0911 稿 §3 已锁定 |
| 轨迹 | `task_u__seed17 / 29 / 43` | 研究者指定：Task-only ＋ attention 开放 |
| 时刻 | 21 个检查点（0,1,4,8,16,32,…,512） | 呈现次数轴＝\(128\times\)update |
| 配套对象 | \(v_i(t)\)（最终表征）、\(e_i(t)\)（实际专家号） | 输出侧与路由侧；**不得替代**主对象 |
| 对照 | `task_f` 三条轨迹 | \(h\) 逐位不变 ⇒ 全套读数的"零变化"参照，也是实现自检 |

**必须先讲清的一件事**：按已有测量，U 档 \(D_{512}\approx0.067\)、\(R_{512}\approx0.045\)、\(h\) 净换组 1.55–1.85%。**"剧烈"在表征几何上可能并不存在**；已有证据显示真正的剧烈变化在路由分配（76.77% 改选）而不在输入几何。所以本实验的合格结果包括"**没有超出分辨率的剧烈变化**"——这不是失败，是答案。

## 3. 分析设计（四层表征 → 五类分析）

| 层 | 用什么 | 只读现有产物？ |
|---|---|---|
| L1 关系层 | 全维余弦矩阵 \(C_t(i,j)=u_i(t)^\top u_j(t)\)，\(u=h/\|h\|\) | 是 |
| L2 分组层 | 固定 K8 读出（dev 拟合 / test 分配）；成对同组关系；\(k{=}10\) 近邻保持 | 是 |
| L3 结构层 | 8 组的组间关系矩阵及其谱；来源分离 \(S\)；\(D/R\) | 是 |
| L4 成分层 | 固定 SAE 字典的稀疏码 \(A_t\)、原子激活率、共激活 \(\varphi\) | 是 |

**五类分析**

1. **时间×时间结构差异**：把只相对 t0 的 \(R\) 扩成 \(21\times21\) 的两两差异（记录对余弦差的加权均方根），逐轨迹一张，另出 3 种子平均。重点读 128–512 之间**等跨度**（相隔 32）的区间。
2. **成员流动**：相邻时刻换组率（匈牙利重匹配后，标为**下界**）＋**不依赖簇编号**的成对同组率与近邻保持率（后者在组号任意置换下必须不变——这是防伪检查）。
3. **求解噪声底**：在 0/32/64/256/512 五个时刻，对**同一份 \(H\)** 用 5 个分析随机种子重复原 K8 算法（保留 `n_init=20`），得到"同数据、不同求解"的差异分布。**这是整把尺子的刻度。**
4. **结构纵轴**：8 组组间关系矩阵随时间（余弦热图 + 最大特征值/谱隙/有效秩曲线），叠加噪声带。
5. **成分层（SAE）**：见 §4。

**主图六张**

| 图 | 内容 | 读法 |
|---|---|---|
| F1 | 时间×时间差异热图（\(21\times21\)，3 轨迹 + 平均） | 找"震中"：哪两个时刻之间差异最大 |
| F2 | 结构纵轴曲线 + 噪声带 | 纵轴＝谱量，横轴＝呈现次数；带内＝不可判定 |
| F3 | 成员流动曲线（相邻 + 相对起点）＋ 求解噪声带 | 后期是否仍在换组 |
| F4 | 点云演化（复用共同坐标投影，5 主时刻 + 21 时刻附件） | 只作直观入口，不作证据 |
| F5 | SAE：原子激活率热图 + \(\varphi\) 边集变化 + 重构误差/稀疏度 | 字典用法是否变 |
| F6 | "地震图"：F1 的相邻区间差异 与 NLL 区间降幅 叠画 | 结构变化是否与损失下降同时发生 |

## 4. SAE 具体怎么分析（人话版）

**先说 SAE 是什么**：它是一本 **3 万个词的词典**（原子）。给它一个 \(h\)，它只挑 **32 个词**来描述这个向量。这本词典在训练开始前就固定了，**训练期间它不学习**。

**我们要做的事**：拿这本固定词典，把**每个时刻**的 \(h\) 都翻译一遍，得到 \(\text{记录}\times\text{原子}\) 的稀疏表 \(A_t\)（1480 行、每行只有 32 个非零）。然后问三个问题：

1. **这本词典还被这样用吗？** 看每个原子的**激活率**（有多少条记录用到它）随时间的变化 → 图 F5 左。
2. **哪些词总是一起出现？** 用 phi 系数 \(\varphi_{ij}\) 量"一起出现的程度是否超出各自单独出现的预期"；把每个时刻的 \(\varphi\) 图画出来，比较**边集是否变化**（用边集 Jaccard 与 \(\varphi\) 的加权差）→ 图 F5 中。
3. **词典还读得动吗？** 看**重构误差**与**稀疏度**随时间。如果重构变差，说明 \(h\) 漂到了词典覆盖不到的地方——**这时"原子关系没变"不能解释成"结构没变"，只能解释成"这本词典读不出来"**。

**两个必须做的控制**：
- **噪声底**：把记录对半重抽，看 \(\varphi\) 与激活率自身抖动多大；变化必须超过它。
- **F 档自检**：`task_f` 的 \(h\) 逐位不变，在确定性编码器下 \(A_t\) 必须逐位相同；不一致就是实现问题。

**边界**：原子不是类别，也不是专家；一本固定词典读不出来 ≠ 没有结构；重拟合字典属于 0911 稿实验三，**本次不做**。

## 5. 实施步骤（含第一步）

**第一步（今天，零重训、纯 CPU，预计分钟级到十几分钟）**
把尺子造出来，并回答"有没有超出分辨率的差异"：

1. 读入 126 个 `task_u` 分片 + 63 个 `task_f` 分片（对照），固定记录顺序、取点、全维空间。
2. 算 L1 的 \(C_t\)，输出 F1（时间×时间差异热图）。
3. 在 5 个固定时刻做 5 个分析种子的重复 K8 → 求解噪声底；同时算成对同组率与近邻保持率。
4. 输出 F3，并把"时间差异"与"求解噪声"画在同一尺度上。
5. 自检：`task_f` 的 \(C_t\) 必须逐位相同。

**产物**：`audits/task_u-cluster-evolution-20260911/`（脚本 `step1_relations.py`、`step1_results.json`、`F1_*.png`、`F3_*.png`、`method.json` 记录源码摘要与输入摘要）。**不写 `analysis/`、不碰 `fm/`。**

**第二步（SAE 成分层）**：固定字典编码 21 个时刻的 \(h\) → F5；对半重抽噪声底；F 档自检。

**第三步（内容解释）**：稳定 / 反复换组 / 持续换组三类各取固定哈希 5 条，列原文、来源、长度、旧邻居、新邻居；研究者先盲于条件名描述共同内容。

**按结果选做**：离线重拟合字典（0911 稿实验三）——**只在固定字典不足以区分竞争解释时进入**。

## 6. 判据与结论分支

| 观察 | 允许结论 | 明令不能写 |
|---|---|---|
| 时间差异 ≤ 求解噪声 | 在当前工具分辨率下不可判定 | "没有变化" |
| 时间差异 > 噪声，且超出的部分集中在早期 | 这段后训练存在可复现的关系重组，且前 1/8 内完成大部分 | "类别形成""语义重组" |
| 差异只由统一缩放/整体旋转解释 | 报告为几何规范化，不称结构重组 | 用 \(D\) 上升代替 \(R\) 上升 |
| `task_u` 与 `task_f` 读法一致（F 档恒为 0 变化） | 变化来自 attention 开放，不是任务目标本身 | 用 F 档的"无变化"否定 U 档的变化 |
| SAE 读数变化只随重构误差/覆盖变化 | 测量失配，先校准再解释 | "原子关系重组" |

## 7. 目标评估：这份计划能不能"看到聚类随训练怎么变"？

**能，但只在"几何/分组结构"的意义上；"语义类别"这一层现在答不了。**

- **满足的部分**：F1 给"什么时候变"、F3 给"变多少、后期还变不变"、F2 给"结构量怎么走"、F5 给"成分层怎么走"——四条都直接是"指标随训练的变化 + 具象可视化"，正对研究者固定想看的东西。
- **不满足的部分（必须提前说）**：0911 稿的主假设"同类收缩、异类分离、后期稳定"需要一个**独立于来源和聚类算法的语义真值**；文档自己也承认当前没有。因此本计划只能回答"**关系是否变了**"，不能回答"**是否按语义重组**"。要跨越这一步，必须先建立一小批与簇无关的内容标签（0911 §6 实验二已写），这是**第二步之后**的事。
- **一个方法学提醒**：现有主读面的点云图是 2 维 PCA；\(D\approx7\%\) 时"看起来没变"是常态，所以**主图不能是二维散点**，必须是 F1/F2/F3 这类全维量。

## 8. 边界

- 本方案是 **AI 建议**，不是已确认的实验，也不构成执行授权；执行前需要研究者确认下面的三项。
- 全程不重训主模型、不产生新教师目标、不改 `fm/**`、不改任何规范产物与身份记录。
- 固定八簇只回答"这套读出怎样变"，不是自然类别计数；来源不是语义真值；原子图不是样本分组。
- 研究者的边界句逐字保留："这批模型适合观察'预训练模型局部微调中的结构变化'。固定八簇不能证明自然类别何时诞生，也不能替代语义解释。审计末尾采集仍未齐全，尚不能交完整表征结论。"

## 9. 需要研究者确认的三项（确认后即可开工）

1. **问题（stable key）**：是否登记为 `A15.sae_hierarchical_teacher_construction` 之下的独立问题（建议 key 形如 `A15.local_sft_representation_reorganization`，由研究者定名）。
2. **唯一下一决定**：建议写作——"**是否存在超出读出噪声、可跨训练种子复现的输入表征重组？若是，进入内容解释；若否，收窄到'路由/输出侧变化'并把几何主张撤回。**"
3. **四段式（Focus 用，需研究者确认或改写）**
   - 目的：判断 task-only＋attention 开放的局部后训练中，固定文本的输入表征关系是否发生可复现的重组，并把"真实重组"与"读出波动"分开。
   - 假设：预测早期变化大、后期趋于稳定；最强竞争解释是"变化不超过同一份 H 的重复分析波动，或只是整体缩放/旋转"；区分结果是时间差异与求解噪声的相对大小。
   - 分析方法：全维余弦关系的 21×21 两两差异、不依赖编号的成对同组率与近邻保持、8 组结构纵轴的谱量，三者都与同一份 H 重复分析的噪声底并列；SAE 作为固定字典的成分层读数。
   - 结论分支：超出噪声且跨种子复现 ⇒ 进入内容解释；不超出 ⇒ 报告分辨率不足，撤回几何重组主张；只在 task 出现 ⇒ 支持任务训练的伴随效应，不支持教师贡献。
