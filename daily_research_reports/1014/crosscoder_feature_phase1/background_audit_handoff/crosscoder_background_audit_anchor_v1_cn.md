# CrossCoder 阶段一后续：高组成列表重叠的背景解释审计

## 1. Problem Definition

**唯一裁定问题：固定阶段一的模型、数据和主图判据，所展示的高组成列表重叠主要反映普遍高频节点，还是仍有超出背景频率、在同 bin 发现／复核侧保留并能从文本检查的特征关系？**

上层方向是理解同一层中哪些内容适合共享学习或分配到不同专家。本轮只审计“组成列表重叠”这个统计代理，不能直接回答学习收益。用户已授权写本独立 anchor，并让原对话 `01a1343f-32aa-7500-9835-000956218089` 执行有限的缓存分析。本文件是新的派生审计设计；不替换原 Anchor、Protocol 或阶段一结论，也不代表研究者确认了新机制。新增指标与判断分支为 `AI_PROPOSAL`／探索性诊断，允许执行不等于科学认可。

支持：存在超出背景、保留于复核侧且文本可检查的有限对象，则继续讨论对象定义。削弱：展示的高 J 无额外区分力或只剩极少普遍项，则缩窄用 J 指导内容分组的解释。不足：对照不可比、剩余支持少或文本无法区分，则保留 Unknown。三者均不启动功能验证或训练。

## 2. Physical Priors

候选解释 P1：节点在绝大多数位置出现时，许多不同特征都容易满足“出现时它也出现”，因而获得相同的直接邻居列表。高 J 可能来自背景覆盖，而非共同内容。P1 是可检验解释，尚未确认为真实主因。

竞争解释：某些共同项虽常见，仍对候选有额外条件富集，且文本呈现具体格式、词汇或内容关系。共同项比例本身无法区分两者。仅从列表删项后 J 不变，也不能排除 P1；两张相同列表同步缩短仍可保持 J=1。

## 3. Falsifiable Hypotheses

H1（探索性）：高 J 候选具有超出共同背景的可检查关系。预期共同项对应边在复核侧有额外富集，且候选相对预先选定的频率／列表大小可比对照仍有区分。随机文本与高激活文本需分别展示，格式关系也按实报告。

最强竞争解释 H0：高 J 主要来自普遍节点及极端并列代表选择；同频率、同列表大小对象容易有相似列表，随机文本不支持更具体的共同内容。共同删除 Top10 后剩余一项相同，不能单凭 J=1支持 H1；若剩余项也普遍且没有额外富集，H1 仍受挫。没有验证因果或收益的方向性假设。

## 4. Mathematical Model

模型固定为冻结 Qwen3-0.6B Base 的14个偶数 residual-post 层联合编码 CrossCoder，16384个共享特征，训练999,997,440个配对位置。每个目标位置只有一个联合激活向量 z；各层有不同 decoder，不能当作14套层内独立激活。

阶段一使用冻结 TRAIN 阈值0.051281172782182693、固定归一化和原始推理。10,485,760个合格 VAL 位置分为发现侧 D=5,238,097、复核侧 V=5,247,663；81个连续上下文块，每块至多128个完整上下文。原文档和近重复独立性 Unknown，VAL 已用于训练评估。

原始边 A→u 的判据保持：两节点支持≥200、共同支持≥20、P(u|A)≥0.8、P(A|u)≤0.5、nu/nA≥2。先复核 D 的原始边，再约简通过的图；C(A) 是约简图直接出邻居。核心观测 J(A,B) 为两列表交集大小除以并集大小；空并集 NA，单侧空列表 J=0另标。

背景解释用同侧节点频率 p_u=nu/N 核查：边的 lift=P(u|A)/p_u，额外概率=P(u|A)−p_u。它们只描述关联，不是干预效应。Top10 按发现侧支持数递减选取（同分按 ID）；不是 decoder 范数、入度或 TRAIN 频率。

主判断来自“共同背景解释后是否还有可比且可检查的关系”，不设追求漂亮图的统一通过数值。lift>1只表示相对边缘背景富集，不自动认证语义；需要 D/V原始计数、对照和文本一起解释。多层几何仅使用既有 decoder 范数及幅度，逐特征层间幅度占比恒等于范数占比，不能补足功能证据。

## 5. Computational Realization

实际执行唯一责任人是原对话；本审计线程只读核查与报告。原对话先检查同题正在进行的工作，复用已有结果，不重复启动。

- 输入：`../reading_bundle/` 内正式记录、候选与文本；执行侧既有频率、原始边／复核表、D/V约简图、候选元数据、分块计数及 decoder 几何。资产缺失先记录，禁止重新全量推理或完整关系计数。
- 背景核查：读取固定候选共同项的既有边表，列 D/V的支持、p_u、条件概率、lift、额外概率；说明87.5%的对象与分母。
- 联合删除：固定候选、固定发现侧 Top10，分别从 D原始图与V已复核原始图同时移除10节点，再正确约简相关可达子图。另列“仅过滤旧组成列表”作为不同操作，不能混称重新约简。保留空列表、列表大小及剩余共同项；不重新排名全池。
- 有限对照：从现有合格节点元数据确定少量 D侧频率和列表大小可比对象，不按复核结果、文本或高 J挑选；读取其列表、现成共同计数及少量已缓存文本。无可靠匹配就报告不足，不扩大搜索。复用既有并列组统计以说明选择偏差。
- 输出：新派生表、至多2–3幅有裁定作用的图、中文 Summary／Detailed、文本核查意见、来源与缺项；不覆盖正式结果。CPU工程分块／并行／内存可以在既有配额内调整并记录。

## 6. Minimal Falsification Tests

以下至多三项是同一问题的诊断；原对话可依据缺项删减，不机械跑全方法。

1. **共同项是否有额外富集？** 固定4对，重点核查高 J 两对的8项及非 Top10 的14。把边条件概率与同侧背景放在一起；对实际计数和既有分块结果核对。若边只达到背景水平，背景解释加强；若有额外富集，只保留统计关联解释。读取既有表，预期秒至分钟 CPU量级；不新增GPU。
2. **多个背景节点是否共同支配？** 一次共同删除固定Top10，正确重约简，和仅过滤旧列表并列。主要读数为剩余共同项、两列表大小、J及各项背景富集；不以J不变单独判定稳健。空集或仅单项高J均警告，不能凑候选。相关可达子图CPU计算，具体耗时由原对话依据现有图大小给出。
3. **候选是否超出可比对象且文本能检查？** 先固定匹配规则、确定性种子及小样本上限（建议每个高 J 对≤32个对照，属于AI_PROPOSAL），再看结果。匹配D侧A/B频率及列表大小，保持V仅描述性复核；另报共享锚点限制与并列代表ID偏差。无法兼顾条件则报误差或不足。随机文本是主要核查材料，高激活作辅助；目标token、模型可见前文、同上下文重复须明确。既有图／表CPU读取，不扫描全池反复排名。

本轮主结果仍为原阈值。若确有工程选参数问题，仅调整工程实现。若科学测量参数确需调整（支持数、条件概率或背景过滤），在运行前记录原因、少量预定版本和什么结果会改变判断，独立标为探索性敏感性，完整保留原结果。禁止无目的全网格、追随结果调参或隐去阴性结果。重新提取激活、GPU或扩大资源依赖停下报告；不受影响的阅读和报告继续。
