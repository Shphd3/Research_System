# continuous_hmm_v5_30law 结果汇总（r20260407_v5full_si_fix）

## 实验概述

- **实验目的**：评估不同 router 在三类合成数据上的**分发性能**，侧重比较二阶分发 vs 一阶分发的能力差异
- **数据分发测试的含义**：给定不同类型的合成数据（Type1/2/3 代表不同的均值/协方差分离结构），测试 router 是否能将 token 分配到对应的专家，形成有意义的 domain/expert specialization
- **指标说明**：
  - **TaskLoss**：预测 MSE，越低越好
  - **NMI/ARI**：衡量路由分配与类别标签的对齐程度，越高越好
  - **H(E|C)**：条件熵，越低表示专家-类别相关性越强（但需结合 NMI 解释）
  - **SI**：子空间干扰（Subspace Interference），衡量同一专家在不同域上的协方差重叠程度，**越低越好**
- Runs: **45 / 45**（5 routers × 3 types × 3 seeds）
- 训练口径：epochs=12, batch_size=128, freeze_backbone=true, embedding_lr=3e-4, router_lr=3e-3, backbone_lr=2e-4, ortho_alpha=0.05

## 核心结论

### 1. 二阶分发 vs 一阶分发能力对比

| 场景 | 最优 Router | NMI↑ | SI | 主导机制 |
|------|-----------|------|----|---------|
| Type1（强均值分离） | linear_running_center | 0.1263 | 20.14 | 一阶中心化 |
| Type2（强协方差分离） | subspace_energy | 0.0257 | 11.69 | 二阶子空间 |
| Type3（混合分离） | hybrid_subspace_energy | 0.0250 | 12.51 | 混合一阶+二阶 |

### 2. SI 指标分析

- **SI 与 NMI 无明显负相关**：SI 最低不代表 NMI 最高
- `acp_lite` 在所有 type 中 SI 都较低（~10-11），但 NMI 不是最优
- `linear_running_center` 在 Type1 中 NMI 最高，但 SI 也最高（~20）
- **可能原因**：SI 衡量的是协方差重叠，而 NMI 衡量的是类别对齐——两者不是同一件事

### 3. H(E|C) 指标分析

- **低 H(E|C) ≠ 高专一性**：`linear_no_center` 的 H(E|C) 最低（~0.03-0.63），但 NMI/ARI 也最低
- **原因**：均匀随机分配会产生低条件熵，但不形成有意义的 specialization
- **结论**：H(E|C) 需要结合 NMI 或 purity 解释，不能单独使用

### 4. Gate-A 复判（Type2）

- 条件：NMI > acp_lite，TaskLoss < acp_lite，CV_load <= 1.2 × linear_running_center
- `subspace_energy`: **NMI=0.026 > acp_lite=0.008** ✅，**TaskLoss=2.233 > acp_lite=2.228** ❌
- Gate-A Overall: **仍未通过**（TaskLoss 未优于 acp_lite）

### 5. 下一步建议

1. **SI 指标需要重新思考**：当前 SI 与 NMI 无明显相关性，可能需要修改 SI 定义或结合其他指标
2. **探索更高正交约束强度**（ortho_alpha ∈ {0.2, 0.5, 1.0}）
3. **考虑 metric 组合**：NMI + SI 联合判断可能比单独判断更有意义
