- 理论解释：
  1. 对于二阶项（方差）反映的信息以及我们的方法在利用什么分发：
    1. 对于去中心化后的激活值$$X_c = X-1^T \mu$$进行SVD，奇异值平方$$\frac{\sigma_i^2}{N}$$反应的是在奇异方向上数据方差。离群的几个最大的奇异值意味着：在这几个特定方向上，Token之间的差异是最大的。
    2. 现在我们的按照方差分发是在利用什么信息：
      1. 我们的子空间能量路由 $$\ell_e = \|V_e x_c\|^2$$。这里的 $$V_e$$矩阵（包含 $$r$$ 个行向量）实际上我们的intuition就是在主动去对齐那些具有大奇异值的奇异方向。做一个假设，假如r=16，实际上就是强迫专家对齐$$V_e$$这个秩为的低秩子空间中的能量。专家 $$e$$ 应该去捕捉哪几个主轴（哪些 $$v_i$$）上的能量？当一个 Token 在这些主轴上的投影极长时，它就会被送入对应的专家。
        （这里有可行的下一步：那就是让低秩空间尽量不要重叠，这就可以用上尚老师觉得可行的，一个$$V_e$$更新，其他的$$V_{e'}$$可以朝着相反的方向更新，使得最终我们的可以使得每个空间$$V_e$$互不相交）
        1) 专家内部正交约束
        目标：让每个专家自己的r 个基向量彼此正交、范数受控（接近正交归一）。
        $$\mathcal{L}_{\text{internal}}
=
\sum_{e=1}^{K}
\left\|
V_e V_e^\top - I_r
\right\|_F^2$$
        - 若V_e的行向量完全正交归一，则该项为 0。
        2) 专家间重叠/相似约束
        目标：让不同专家的子空间互相分离，减少“学到同一套方向”。
        $$\mathcal{L}_{\text{cross}}
=
\sum_{\substack{i,j=1\\ i\neq j}}^{K}
\left\|
V_i V_j^\top
\right\|_F^2$$
        - 若专家i,j的子空间越正交，则$$\left\|
V_i V_j^\top
\right\|_F^2$$越小。
  2. 对于低秩和专家专一性的联系，加上我们的数据本身就是低秩的，能否根据公式锚定关系？
    $$\mathrm{Cov}(x) = \mathbb{E}_{e}\!\big[\mathrm{Cov}(x\mid E=e)\big] + \mathrm{Cov}_{e}(\mu_e)$$
    1. 这个式子即使$$x$$本身是低秩的，也确实不能够说：专家专一性越强，模型越低秩；但是，假如说我们能够做到，限制每个专家的秩比较平均的情况下，专家专一性越强，模型一定越低秩。在现在的二阶路由情况下，我们可以通过限制$$V_e$$为低秩的，力求达成这个条件

- 实验：方差与语义之间的关系
取去均值后的表征的前r个特征子空间，然后进行语义聚类，查看聚类的准确率。
  设中心化特征为：
  $$x_c = x - \mu$$
  设一阶 PCA 投影为 $$P_r$$，二阶 PCA 投影为 $$Q_r$$，其中 $$r\in\{32,64,128,256\}$$（也可自定义）。
  - first_order_raw
    $$z = x_c$$
  - first_order_pca
    $$z = P_r x_c$$
  - second_order_raw
    $$z = x_c \odot x_c$$
  - second_order_pca
    $$z = Q_r (x_c \odot x_c)$$
  - subspace_first_pca（与 first_order_pca 同定义）
    $$z = P_r x_c$$
  - subspace_second_pca
    $$z = (P_r x_c)\odot(P_r x_c)$$
  - energy_first_pca
    $$z = \|P_r x_c\|_2$$

  2. 结果分析
    1. $$z = x_c \odot x_c$$携带的语义信息并不多
    2. 低秩部分携带语义信息，但是低秩部分的语义信息不完全
    3. 二阶低秩能量部分携带的语义信息在低秩部分更加显著，秩升高会发生信息的混淆从而导致聚类性能下降。但值得注意的是$$z = \|P_r x_c\|_2$$分离度非常好，这也应证了我们对于大奇异值的奇异方向便于将特征分开的认知。只是这种分离性并没有和语义对应上。
