## 1. 组会记录语义校订稿

### 1.1 恢复边界

ASR 已经丢失部分词语，因此无法保证逐字恢复。下面是**语义恢复稿，而不是逐字稿**：保留讨论的论证顺序，删除无意义口误，并把明显错误的科学表述替换为其最可能想表达、且逻辑上成立的版本。

### 1.2 主要词语校正

| ASR/笔记中的词 | 校订 |
|---|---|
| 低质、高质、高职称 | 低秩、高秩 |
| comments、camp、tom | common / 共享成分 |
| 狼 sentence、狼 C 粉丝、science、nonsense | long sentence / long sequence / sequence |
| 根节点的 BN、这个字被控制 | 根节点的可达维数或秩上界受控 |
| 叶子节点低频 | 删除。概率树定理需要局部源低维，不要求叶子低频 |
| 高秩输出必然 deterministic | 删除。秩与确定性没有这种关系 |
| 不同短句之间没有关系 | 改为局部依赖与长程依赖并存，不是相互独立 |
| 自回归语言模型“就是 diffusion” | 改为粗到细的直觉类比，不是机制等价 |

### 1.3 校订后的完整语义记录

#### 00:10　汇报人

我这部分研究的是树状组合的低秩性。原先我们假设叶子表示都位于低维子空间，并试图由此证明整棵树也共享一个低维空间。现在发现这个推理不成立：即使叶子维数有限、树深有限，不同角色和不同层的组合算子仍可能不断产生新的独立方向，因此不能直接推出全局低秩。

#### 00:38　讨论

例如，“今天下雨”和“我不想被淋湿”可以分别看成局部、可复用的信息单元，但它们在一个完整句子中的特定组合可能很少出现。局部单元低维或高频，不保证完整组合也低维；具体组合仍可能需要额外方向。

#### 01:06　汇报人

因此，我们把静态树改成任务条件下的概率性稀疏激活树。叶子表示局部信息源；给定输入和任务，只激活部分边和部分源；根节点只接收活动路径的贡献。如果单次计算调用的源数量受控，那么给定激活模式时，根节点的可达空间维数也可以被上界控制。

#### 01:53　汇报人

更准确地说，完整潜在树可以具有很高的总体容量，但单个输入只调用其中一个较小的活动子树，因此单次条件计算可能位于较低维空间。

#### 02:05　导师

需要继续澄清你的对象。局部或 common 信息可以落在共享低维空间中；但是一条完全指定的句子还包含词汇选择、句法、语用和风格等细节，跨样本看可能需要更多方向。模型在当前任务中可能只保留与任务相关的部分，而不是无损保存整句话。你需要重新说明“低秩”究竟指根表示、活动路径，还是所有句子的拼接矩阵。

#### 02:51　汇报人

根节点可以理解为当前任务对整句话的摘要。核心任务语义可能由少数因素控制，但完整表面形式包含更多自由度。概率门控选择当前有用的信息源和计算路径，因此我们想声称的是“给定条件的活动计算维数较小”，而不是“整句话或整个语言系统全局低秩”。

#### 03:27　导师

接下来有一个核心问题：如果模型内部只保留了低维的任务相关因素，它为什么仍能输出一条词词合理、形式复杂的长 token 序列？例如，它能生成“因为今天下雨，所以我想带伞”。每个位置都要给出具体 token，低维内部信息如何产生这种表面复杂度？

#### 04:00　讨论

先暂时接受“模型学到了一些低维共享因素”这个假设。但模型的输入和输出是长 token 序列，不能仅用“句子里有几个关键词，其余是 common”回答，因为 common 规律本身仍必须生成具体词语和结构。

#### 04:37　导师

问题应当表述为：输出序列中可能包含共享、低维的控制因素，但输出本身有大量具体选择。模型如何把这些因素转化为逐 token 的条件分布？

#### 05:09　讨论

一个候选解释是：模型需要组合多个局部信息源，而不是由单个语义向量一次性生成整句话。但这仍需说明局部信息如何被组合并影响后续 token。

#### 05:42　导师

需要从不同切入点反复审查同一机制。不同人给出的解释应当产生可区分的预测，而不能只换一种流畅说法。

#### 06:16　导师

再次重述：我们暂时假设核心语义含有共享、低维的因素，但模型输出的是长序列。长序列的具体形式和多样性来自哪里？

#### 06:47　讨论者

一种更准确的解释是：低维语义因素并不直接等于 token。它们可以作为条件，通过非线性解码器和自回归条件分布，从大词表中选择具体 token。表面输出可以很复杂，但只有一部分变化由核心语义控制；其余变化来自句法、风格、词汇选择、上下文和采样等因素。

#### 07:25—08:40　讨论

第一，语言具有局部结构和层级组合。一个长序列可以被因子化为多个局部依赖及其长程组合，因此模型不必在一步中无损编码整个序列。第二，这些局部片段并非相互独立；远程因果、指代和语篇关系仍可能约束局部生成。树状结构只能作为依赖或计算图近似，不能自动推出低秩。

#### 08:40—10:12　导师与讨论者

相同意图可以有不同表面实现。例如问候可以表现为“早上好”“你昨天休息得怎么样”等。模型学习的是给定上下文的输出分布，而不是必须每次复现唯一 token 序列。因此，输出不唯一说明条件分布仍有词汇、风格或采样自由度；它既不证明内部表示低秩，也不说明模型没有学会所谓“高秩细节”。更安全的结论是：核心意图没有唯一决定完整表面序列。

#### 10:45—11:10　关于 diffusion 的讨论

有人把这个过程类比为由粗到细：先掌握共享、粗粒度结构，再逐渐掌握长尾细节，使表达更精确。这个类比可以作为优化直觉，但自回归语言模型并不是 diffusion model。扩散模型具有明确的加噪和迭代去噪过程；若只想表达“模型先学简单或高频结构、后学细节”，更准确的术语是学习动力学中的频率偏置或粗到细学习，而不是 diffusion 机制。

## 2. 必须重新固定的五个数学对象

| 对象 | 严格定义 | 能回答什么 | 不能回答什么 |
|---|---|---|---|
| 序列熵 | $H(X_{1:T})$ 或条件熵 $H(X_t\mid X_{<t})$ | token 不确定性、编码长度 | 线性空间维数 |
| 语义不确定性 | $H(Z\mid X_{1:T})$，$Z$ 为任务/意图变量 | 给定句子后语义还多不确定 | 表示矩阵秩 |
| 表示矩阵秩 | 对一批样本/位置堆叠 $H=[h_1,\ldots,h_n]$ 后的 $\operatorname{rank}(H)$ | 线性跨度维数 | 单个语义的“信息量” |
| 参数矩阵秩 | $\operatorname{rank}(W)$ 或其谱 | 某个线性算子的自由方向 | 整个模型或语言的秩 |
| 功能秩 | 达到指定任务损失容忍度所需的最小秩 | 哪些方向对任务真正必要 | 几何方向的天然语义 |

### 2.1 熵与秩不是同一个量

Shannon 熵衡量概率分布的不确定性：

$$
H(X)=-\sum_x p(x)\log p(x).
$$

高熵表示结果更不确定，不是“语义更确定”。语义更确定对应的是条件熵 $H(Z\mid X)$ 更低。

矩阵秩则是线性代数对象：

$$
\operatorname{rank}(H)=\dim \operatorname{Col}(H).
$$

它表示一批向量精确张成多少个线性方向。只有在“语义由线性基组合产生”这一额外假设下，才能把秩解释为最少线性基数；不能把它直接称为“最少语义概念数”。

### 2.2 为什么会出现“谱熵”一词

可把奇异值归一化为 $p_i$，再定义

$$
r_{eff}=\exp\left(-\sum_i p_i\log p_i\right).
$$

这叫有效秩。它把谱分布的 Shannon 熵转成一个“等效方向数”。但这里的熵是**奇异值分布的熵**，不是句子熵，也不是语义不确定性。必须明确奇异值、平方奇异值或协方差特征值采用哪一种归一化。

### 2.3 长句可以同时“总熵更高、语义歧义更低”

对 token 序列：

$$
H(X_{1:T})=\sum_{t=1}^{T}H(X_t\mid X_{<t}),
$$

总序列熵通常随长度增加，因为增加了新的随机变量。

但对潜在语义 $Z$，在平均意义上更多上下文可降低不确定性：

$$
H(Z\mid X_{1:T+1})\le H(Z\mid X_{1:T}).
$$

所以“句子越长，总信息量越大”和“句子越长，某个语义更明确”可以同时成立，不矛盾。它们讨论的是不同熵。

## 3. 对组会理解性问题的逐项回答

### 3.1 “导师说的高秩/低秩是不是其实是熵？”

**结论：不是。**

导师的口头表述很可能混合了三件事：

1. 完整表面序列具有较多自由度；
2. 核心任务语义可能由较少因素控制；
3. 模型未必能确定所有表面细节。

第一项接近“输出分布或描述复杂度”，第二项接近“任务条件内在维数”，第三项接近“条件熵”。它们都不能直接替换成矩阵秩。

### 3.2 “熵高是不是语义更确定，因此语义基底更低秩？”

**结论：方向反了，而且后半句不能推出。**

- 语义更确定：$H(Z\mid X)$ 低。
- 语义基底是否低维：需要定义表示矩阵和样本集合，再测秩或内在维数。
- 低条件熵不推出低秩。例如，一个确定映射可以把不同输入映到遍布高维空间的确定输出。

### 3.3 “long sequence 是高秩、低熵吗？”

**结论：这个句子本身没有数学意义。**

必须先说明：

- 是把一个序列各位置 hidden state 堆成 $T\times d$ 矩阵？
- 还是把很多句子的根表示堆叠？
- 还是参数矩阵？
- 还是删除参数谱方向后的任务损失？

若堆叠一个序列的各位置 hidden state，高秩只表示不同位置的表示线性多样性较高，不等于语义多，也不等于熵低。

### 3.4 “整句话高秩，但语义低秩，是否冲突？”

**结论：不必冲突，但当前说法仍不够严格。**

可以建立如下生成模型：

$$
Y=g(Z,U),
$$

其中 $Z$ 是核心任务语义，$U$ 包含句法、风格、词汇选择、语用、上下文细节和采样变量。即使 $Z$ 低维，$Y$ 的表面变化仍可很大，因为 $U$ 提供了额外自由度，$g$ 又是非线性、自回归的。

但如果声称“完整语义只有一个固定低维 $Z$，且没有其他变量”，那么高复杂度输出就不能被无条件解释。你们原先漏掉的正是 $U$。

### 3.5 “高秩输出是否意味着每次必须 deterministic？”

**结论：完全不成立。**

秩描述跨样本向量的线性跨度；deterministic 描述条件分布是否退化为单点。二者彼此独立：

- 确定映射可以在不同输入上产生高秩输出集合；
- 随机输出也可以始终落在一条直线上，秩很低。

组会中真正合理的意思应改为：**同一核心意图不足以唯一确定表面 token 序列。**

### 3.6 “为什么内部可能有低维因素，模型仍能说出一句人话？”

正确的最短解释链是：

1. 模型并没有把整句压在一个单独的“语义向量”里；每个位置都有状态，且状态依赖完整前缀。
2. 自回归分解把序列概率写成
   $$p(x_{1:T})=\prod_t p(x_t\mid x_{<t}).$$
   模型逐步解决局部条件决策，而非一次性输出整句。
3. 核心语义只是生成条件之一，句法、风格、词汇和上下文细节也在状态中。
4. 非线性解码器可以把共享因素与其他因素组合成离散 token 决策。
5. 因而“某个任务相关因素低维”不推出“所有 hidden state 或输出空间低维”。

### 3.7 “LLM 是否只能学习低秩内容，额外参数只是记忆高秩细节？”

**结论：不成立。**

低维微调、LoRA 或某些低内在维数结果只说明：对特定预训练模型和特定任务，存在低维参数更新可达到较好性能。它们不证明预训练模型本身、自然语言或所有任务全局低秩。过参数网络可以拟合随机标签，Transformer 也具有很强的函数表达能力。更合理的判断是：

> 模型具有高容量，但训练数据和优化产生结构性偏置，使高频、共享或简单模式往往先学、集中学；这是一种学习偏置，不是表达能力上只能低秩。

### 3.8 Diffusion 类比是否成立？

仅能保留为弱类比：

- 真正 diffusion model 定义了前向加噪和反向迭代去噪过程。
- 自回归 LM 没有这一过程。
- “先学 common，再学细节”更接近频率偏置或粗到细优化。
- Diffusion-LM 是另一类明确使用连续扩散过程的语言模型，不能用它反证普通 NTP 模型也是 diffusion。
