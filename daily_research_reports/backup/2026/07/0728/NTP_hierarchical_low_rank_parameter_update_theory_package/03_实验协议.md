# Protocol A14-PU-01：概率树—NTP—task spike—完整权重有效秩

**状态：**待研究者审批；未授权实现、smoke 或运行  
**实验角色：**结构实现与因果链 operationalization test  
**主模型：**Gaussian 初始化的 learned residual MLP，pure SGD  
**精确定理正对照：**固定概率树 features 的二类 contrast-NTP writer

# 0. Approval Snapshot

**Purpose：**判断共享概率树是否在 learned writer input 中实现 \(kr\) 维任务坐标，并通过 full-position NTP exposure 与 pure SGD 形成足够强的 task spike，使完整 \(W_T\) 而不仅是 \(\Delta W_T\) 达到低有效秩。

**Primary anchor：**A14 tree low-rank language structure；本轮不修改 anchor。

**Decision question：**

> shared-tree 相对 disjoint-tree，full-position NTP 相对 root-only，是否通过更高的 mapping effective exposure 和正梯度相干度，使 learned MLP 同时满足稳定 \(kr\) 维 activation envelope、低尾 \(\Delta W_T\)、task-spike energy dominance 与低尾 \(W_T\)？

**Strongest rival：**teacher 共享 mappings，但 student 使用 context-specific rotating coordinates；或 \(\Delta W_T\) 虽低秩，却尚不足以压过 Gaussian bulk，导致完整 \(W_T\) 仍高有效秩。

**Primary endpoint：**

$$
\tau_{kr}(W_T),
\qquad
r_{0.90}(W_T),
\qquad
k=4,\ r=2,\ q=kr=8.
$$

两者使用同一 90% energy criterion：\(\tau_8(W_T)\le0.10\iff r_{0.90}(W_T)\le8\)。

**Hard mechanism gates：**

1. held-out activation implementation capture；
2. mapping effective exposure；
3. gradient coherence；
4. \(\tau_8(\Delta W_T)\)；
5. task-spike/Gaussian-bulk ratio 与 proof ratios \(\rho_{\mathrm{op}},\rho_F\)；
6. frozen rank-8 functional replay。

**Minimal conditions：**

- shared-tree / disjoint-tree；
- full-position NTP / root-only loss；
- M0 fixed-feature writer / M1 learned residual MLP；
- M2 Transformer only after M1 support。

**Pass：**至少 4/5 confirmation seeds 通过 capability、causal-use、activation、coherence、update-tail、full-weight-tail 和 functional-replay gates；shared/full 的 exposure 与 task-spike growth 必须显著高于至少一个预注册 rival，并由中介链方向解释。

**Fail：**模型 capable 且 causal-use 成立，但 learned activation 不实现稳定 rank-8 coordinate，或 \(\Delta W_T\) 空间外尾部持续高，或 task spike 不增长/不主导 Gaussian bulk；4/5 seeds 落入预注册 refutation region。

**Insufficient：**M0 数值正对照失败、少于 4 个 eligible seeds、SGD 不稳定、separator/margin gate 失败、test 被用于选 rank/threshold，或指标落在支持与反驳阈值之间。

**Cannot claim：**自然语言普遍低有效秩；完整 Transformer 参数元组低有效秩；full-position 对任意 root-only objective 都更优；AdamW 与 pure SGD 等价；低有效秩带来 Router/MoE 收益。

**Approval decision：**

- [ ] 批准 Stage 0--3：generator、M0、M1
- [ ] M1 通过后批准 M2
- [ ] 修改后批准
- [ ] Park / 拒绝

# 2. Tested Hypothesis And Rivals

## H-PU

在 shared-tree、full-position NTP 和 pure SGD 下，capable M1 会在 \(W_2\) 输入 activation 中实现跨 contexts 稳定的 rank-8 causal mapping space；其 effective exposure 与 gradient coherence 形成增长 task spike，最终使

$$
\tau_8(\Delta W_{2,T})\le0.10
$$

且

$$
\tau_8(W_{2,T})\le0.10
$$

同时成立。

## R1：teacher shared，student rotating

预测：capability 通过，但 \(C_{\mathrm{act}}\) 和跨 checkpoint capture 失败。

## R2：低秩只来自单事件稀疏或 architecture bottleneck

预测：disjoint-tree 的 \(\tau_8\) 与 shared-tree 相同，或 random rank-8 replay 同样有效。

## R3：full-position 只是多了 loss terms

预测：匹配 effective exposure 或 prediction-event budget 后，full/root 的 spike growth 差异消失。

## R4：update 低秩但完整权重未低有效秩

预测：

$$
\tau_8(\Delta W_T)\ll1,
\qquad
\tau_8(W_T)\not\ll1,
\qquad
\rho_F\not\ll1.
$$

## R5：outlier 被误写为低有效秩

预测：\(\rho_{\mathrm{op}}<1/2\) 且有谱隙，但 \(\rho_F\) 和 \(\tau_8(W_T)\) 未通过。

## R6：背景产生系统性 tail

预测：\(R_T/S_T\) 不下降，conditional mean tail gradient 非零。

# 3. Data-Generating Process

## 3.1 Shared mapping library

冻结

$$
k=4,\qquad r=2,\qquad s=2,\qquad q=8.
$$

mapping \(j\) 接收

$$
c_j\in\{-1,+1\}^2
$$

并通过非退化 signed-permutation transform

$$
Q_j\in\mathbb R^{2\times2}
$$

作用。令 oracle writer-input ambient dimension 为 \(m_0=64\)，并取互相正交的 block injections

$$
E_j^{\mathrm{tree}}\in\mathbb R^{64\times2}.
$$

受控 task state 为

$$
s_e^\star
=
\sum_{j\in\mathcal J_e}
E_j^{\mathrm{tree}}Q_jc_{e,j}
\in\mathbb R^{64},
$$

并令 oracle writer input \(a_e^\star:=s_e^\star\)。所有 task states 的并空间维数至多为 \(8\)。保留 64 维 ambient space 是为了让 Gaussian \(W_0\) 具有非平凡的 rank-8 外 bulk，而不是让 \(\tau_8\) 因矩阵太小自动为零。

## 3.2 Registered next-token contrasts

冻结不超过 64 个 readout types \(\nu\)。每个 type 含：

- \(v_\nu\in U_{\mathrm{tree}}\)：shared-tree 时 \(U_{\mathrm{tree}}=U_\star\)，disjoint-tree 时为 family-specific spaces 的并；local type 只读取一个 mapping block，root type 在两个活动 blocks 上均有非零系数；
- \(\bar b_\nu=(e_{u_\nu}-e_{v_\nu})/\sqrt2\in\mathbb R^{128}\)：互不重叠 token pairs，因此各 \(\bar b_\nu\) 正交。

registry 必须覆盖全部 8 个 mapping coordinates，并为每个允许的双 mapping 组合至少保留一个 root readout。

事件 \(e\) 选择预注册 type \(\nu(e)\)，并令

$$
g_e=v_{\nu(e)}^\top a_e^\star,
\qquad
y_e=\operatorname{sign}(g_e).
$$

generator 只接受 \(|g_e|\ge\gamma_0>0\) 的事件；正确 token 与对照 token 的 contrast 为

$$
b_e=y_e\bar b_{\nu(e)}.
$$

定义

$$
Q_\star
=
\frac{1}{Z}
\sum_\nu \bar b_\nu v_\nu^\top,
\qquad
Z=
\left\|
\sum_\nu \bar b_\nu v_\nu^\top
\right\|_F.
$$

则 \(\|Q_\star\|_F=1\)、\(\operatorname{Row}(Q_\star)\subseteq U_\star\)，且每个注册事件严格满足

$$
\langle Q_\star,b_e(a_e^\star)^\top\rangle_F
=
\frac{|g_e|}{Z}
\ge
\frac{\gamma_0}{Z}.
$$

因此 M0 的 shared positive margin 不是拟合后假设，而是 generator 可直接验证的不变量。

## 3.3 Causal tree

每个 sequence 含两条相距至少 8 tokens 的 branches：

~~~text
branch A: [MAP_A] [COEF_A] ... [LOCAL_TARGET_A]
branch B: [MAP_B] [COEF_B] ... [LOCAL_TARGET_B]
                                  |
                              [ROOT] [ANSWER]
~~~

- LOCAL targets 分别依赖单个 mapping；
- ROOT answer 依赖两 mapping 的组合；
- distractor spans 不改变 teacher label；
- 每个 mapping/coefficient/token 都在 train 出现；
- held-out split 隔离 mapping/coefficient 组合、context IDs 与 intervention pairs。

该构造使 full-position 在 local 与 root positions 复用 mappings；root-only 只保留 ROOT answer。

## 3.4 Causal validity

对每个 mapping \(j\)，配对改变 \(c_j\) 而冻结其他外生变量。teacher 必须满足

$$
\operatorname{ACE}_j>0
$$

且 intervention 至少改变一个注册 local/root contrast。若 teacher effect 不成立，该 generator 无效。

## 3.5 Shared-tree

所有 context families 复用同一 \(\{Q_j,E_j^{\mathrm{tree}}\}_{j=1}^4\)。

## 3.6 Disjoint-tree

使用四个 context families；每个 family 使用 family-specific mapping injections。单事件仍为 \(s=2,r=2\)，但跨 family union budget 设为

$$
q_{\mathrm{disjoint}}=32.
$$

模型宽度、sequence length、answer entropy、样本数和单事件 activity 保持匹配。报告 \(\tau_8\) 与其自身预算 \(\tau_{32}\)。

## 3.7 Background conditions

主决策只使用 shared-only 和 balanced independent distractors。相关 tail mapping 作为边界控制：

- independent nuisance：给定 task state 不改变 teacher logits；
- label-dependent bad control：context 直接改变 teacher contrast；
- relevant tail：以 \(0.05\) 概率调用头部外 causal mapping。

相关 tail 不要求被平均掉。

# 4. Models And Training

## M0：fixed-feature contrast-NTP writer

$$
o_e=W a_e^{\mathrm{oracle}},
\qquad
W\in\mathbb R^{128\times64},
$$

$$
a_e^{\mathrm{oracle}}
=
\sum_{j\in\mathcal J_e}E_j^{\mathrm{tree}}Q_jc_{e,j}.
$$

使用第 3.2 节预注册的正确/对照 token contrast \(b_e\)，并令

$$
\ell_e(W)=\log\!\left(1+\exp[-b_e^\top o_e]\right).
$$

- \(E_j^{\mathrm{tree}}\) 与 \(Q_j\) 冻结；
- 128-token vocabulary 上的 registered binary next-token contrast；
- 只训练 \(W\)；
- 精确验证 T1--T6。

M0 任意显著 \(\tau_8(\Delta W_T)\) 都是实现或数值错误。

## M1：learned causal-prefix residual MLP

固定长度 causal prefix 编码为 \(\chi_e\)，Gaussian input map 给出

$$
h_e^0=W_{\mathrm{in}}\chi_e+b_{\mathrm{in}}.
$$

单 residual MLP：

$$
m_e=\operatorname{GELU}(W_1\operatorname{LN}(h_e^0)+b_1),
$$

$$
h_e^+=h_e^0+W_2m_e+b_2.
$$

next-token logits 与注册 contrast loss 为

$$
o_e=W_{\mathrm{out}}h_e^++b_{\mathrm{out}}\in\mathbb R^{128},
$$

$$
\ell_e
=
\log\!\left(1+\exp[-b_e^\top o_e]\right),
$$

宽度 64，FF width 128。主矩阵

$$
W=W_2\in\mathbb R^{64\times128}.
$$

\(W_{\mathrm{in}},W_1,W_2,W_{\mathrm{out}}\) 与 biases 共同训练，但结论只针对 \(W_2\)。若 margin 增长主要由其他参数承担，M1 对 T6 为失败或不足，而不是自动成功。

## M2：一层一头 Transformer

pre-norm causal attention + residual MLP，宽度 64、FF width 128，沿用 M1 的 128-token registered contrast head。只分析 \(W_O\) 与 \(W_2\)。M2 仅在 M1 主门通过后进入。

## Initialization

所有注册线性矩阵：

$$
W_{ab}\sim\mathcal N(0,1/d_{\mathrm{in}}).
$$

保存 step-0 state。bias 为 0，LayerNorm gain 为 1。初始化不得预先使用 mapping directions。

## Optimizer

~~~text
SGD(lr=frozen_after_development, momentum=0, weight_decay=0)
~~~

不使用 Adam、AdamW、momentum、逐坐标预条件或默认 gradient clipping。

development seed 100 只从

$$
\eta\in\{0.01,0.03,0.1\}
$$

选择第一个稳定并通过 capability 的学习率；冻结后不得读取 confirmation rank 指标调参。M0 另记录

$$
M_X=\max_e\|X_e\|_F
$$

并强制 \(\eta M_X^2\le1\)，作为 fixed-step smoothness 的保守门；违反者不属于精确定理正对照。

## Objectives

full-position：

$$
L_{\mathrm{full}}
=
\frac{1}{|\mathcal E_{\mathrm{full}}|}
\sum_{e\in\mathcal E_{\mathrm{full}}}\ell_e.
$$

root-only：

$$
L_{\mathrm{root}}
=
\frac{1}{|\mathcal E_{\mathrm{root}}|}
\sum_{e\in\mathcal E_{\mathrm{root}}}\ell_e.
$$

主比较匹配 sequences、steps、batch size 和 initialization。另做 prediction-event-budget guard，以区分 objective structure 与监督事件数量。

# 6. Seeds And Checkpoints

- development seed：100；
- confirmation seeds：0, 1, 2, 3, 4；
- M0：singleton random-reshuffling SGD，以匹配 T3；
- M1/M2：mini-batch size 256，属于 learned/mini-batch 条件检验而非 T3 精确定理；
- maximum steps：20,000；
- checkpoint interval：250。

checkpoint 只按 calibration capability 选择。eligible 条件：

- ROOT answer accuracy \(\ge0.95\)；
- ROOT CE \(\le0.10\) nat；
- unseen-combination accuracy \(\ge0.90\)；
- local-target accuracy \(\ge0.95\)（full-position）；
- causal intervention agreement \(\ge0.90\)。

capability-fail seed 不得以 \(\Delta W\approx0\) 计为低秩成功。

# 7. Learned Activation Implementation

## 7.1 Calibration subspace

对 mapping \(j\) 的配对干预：

$$
\Delta m_{j,x}^{\mathrm{int}}
=
m(x;\operatorname{do}(c_j))
-
m(x;\operatorname{do}(c_j^0)).
$$

每个 mapping 只用 calibration contexts 取 top-\(r\) 方向，再正交化并集：

$$
\widehat U_\star
=
\operatorname{orth}([U_1,\ldots,U_k]),
\qquad
\operatorname{rank}(\widehat P_\star)\le8.
$$

test 不参与拟合或 rank 选择。

## 7.2 Capture

$$
C_{\mathrm{act,test}}
=
\frac{
\sum_{j,x\in D_{\mathrm{test}}}
\|\widehat P_\star\Delta m_{j,x}^{\mathrm{int}}\|_2^2
}{
\sum_{j,x\in D_{\mathrm{test}}}
\|\Delta m_{j,x}^{\mathrm{int}}\|_2^2
}.
$$

hard support：

$$
C_{\mathrm{act,test}}\ge0.90.
$$

hard refutation：

$$
C_{\mathrm{act,test}}\le0.70.
$$

同时报告 per-mapping rank-2 tail、union dimension 和 checkpoint projector drift

$$
\delta_U(t)
=
\|\widehat P_\star(t)-\widehat P_\star(t-\Delta)\|_{\mathrm{op}}.
$$

# 8. Exposure And Gradient Coherence

## 8.1 Exposure

从 generator manifest 与训练轨迹计算

$$
\mathsf{Exp}^{\mathrm{raw}}_j(T)
=
\sum_{t,e}
\eta_t\omega_{e,t}
\mathbf1\{j\in\mathcal J_e\},
$$

$$
\mathsf{Exp}^{\mathrm{eff}}_j(T)
=
\sum_{t,e}
\eta_t\omega_{e,t}
\mathbf1\{j\in\mathcal J_e\}
r_e(W_t).
$$

报告每 mapping、local/root position 和 checkpoint window 的 exposure。不得只用 raw token frequency 代替 residual pressure。

## 8.2 Frozen separator

M0 使用 teacher separator \(Q_\star\)。M1 只用 calibration events 拟合 unit-Frobenius separator \(\widehat Q_\star\)，并冻结到 test。

## 8.3 Gradient coherence

令 \(g_{e,t}^{\parallel}=-\nabla_W\ell_{e,t}\widehat P_\star\)。定义

$$
C_{\mathrm{grad}}(T)
=
\frac{
\sum_{t,e}\eta_t\omega_{e,t}
\langle g_{e,t}^{\parallel},\widehat Q_\star\rangle_F
}{
\sum_{t,e}\eta_t\omega_{e,t}
\|g_{e,t}^{\parallel}\|_F
}.
$$

support：

$$
C_{\mathrm{grad}}\ge0.80
$$

且至少 \(95\%\) 的 weighted events 具有非负 separator projection。

若 full-position 相对 root-only 的 spike growth 更大，但 exposure/coherence 不增加，则 NTP 相干强化解释不成立。

# 9. Parameter Decomposition And Spectrum

## 9.1 Centered update

$$
\Delta W_T=W_T-W_0.
$$

对 M1：

$$
S_T=\Delta W_T\widehat P_\star,
$$

$$
R_T=\Delta W_T(I-\widehat P_\star).
$$

M0 使用已知 \(P_\star\)。

## 9.2 Update metrics

$$
\tau_8(\Delta W_T)
=
\frac{\sum_{j>8}\sigma_j(\Delta W_T)^2}{\|\Delta W_T\|_F^2}.
$$

结构捕获：

$$
C_{\mathrm{param}}
=
\frac{\|S_T\|_F^2}{\|\Delta W_T\|_F^2}.
$$

support：

$$
\tau_8(\Delta W_T)\le0.10,
\qquad
C_{\mathrm{param}}\ge0.90.
$$

refutation：

$$
\tau_8(\Delta W_T)\ge0.25
\quad\text{或}\quad
C_{\mathrm{param}}\le0.70.
$$

## 9.3 Complete weight metrics

$$
\tau_8(W_T),
\qquad
r_{0.90}(W_T),
\qquad
\frac{\sigma_8(W_T)}{\sigma_9(W_T)}.
$$

不得用可视化谱形替代 \(\tau_8\)。

## 9.4 Spike-to-bulk ratios

令

$$
N_T=W_0+R_T.
$$

首先直接报告 task-spike/Gaussian-bulk 比：

$$
\zeta_{\mathrm{G},F}(T)
=
\frac{\|S_T\|_F^2}{\|W_0\|_F^2},
\qquad
\zeta_{\mathrm{G},\mathrm{op}}(T)
=
\frac{\sigma_8(S_T)}{\|W_0\|_{\mathrm{op}}}.
$$

该比值隔离固定 Gaussian 初始化；完整证明门还必须把 learned leakage \(R_T\) 合入 \(N_T\)。定义

$$
\rho_F(T)
=
\frac{\|N_T\|_F}{\|S_T\|_F},
$$

$$
\rho_{\mathrm{op}}(T)
=
\frac{\|N_T\|_{\mathrm{op}}}{\sigma_8(S_T)}.
$$

若 \(\sigma_8(S_T)=0\)，规定 \(\rho_{\mathrm{op}}=+\infty\)。

- conservative outlier gate：
  $$
  \rho_{\mathrm{op}}<\frac12;
  $$
- \(\tau_8(W_T)\le0.10\) 的 sufficient Frobenius gate：
  $$
  \rho_F
  \le
  \frac{\sqrt{0.10}}{1+\sqrt{0.10}}
  \approx0.2403.
  $$

实际 \(\tau_8(W_T)\) 仍直接计算；\(\zeta_{\mathrm G}\) 诊断 task spike 是否越过 Gaussian bulk，\(\rho_F,\rho_{\mathrm{op}}\) 是含 leakage 的充分条件，均不替代主指标。

# 10. Functional Replay

best rank-8 update：

$$
W^{(8)}
=
W_0+(\Delta W_T)_8.
$$

structure-projected update：

$$
W^{(U)}
=
W_0+\Delta W_T\widehat P_\star.
$$

complement-only update：

$$
W^{(\perp U)}
=
W_0+\Delta W_T(I-\widehat P_\star).
$$

令 \((\Delta W_T)_8=U_8\Sigma_8V_8^\top\)。random equal-spectrum update 使用独立 Haar 正交基 \(U_{\mathrm{rand}},V_{\mathrm{rand}}\)：

$$
W^{(\mathrm{rand})}
=
W_0+U_{\mathrm{rand}}\Sigma_8V_{\mathrm{rand}}^\top.
$$

它与最佳 rank-8 update 具有相同 rank、奇异值和 Frobenius 能量，只改变方向。其余 final parameters 与 output head 冻结。support：

$$
\Delta CE_8\le0.02\ \text{nat},
\qquad
\Delta Acc_8\le0.02,
$$

且 random rank-8 的 CE cost 至少高 \(0.05\) nat 或 accuracy drop 至少高 \(0.05\)。

# 11. Three Spectrum Verdicts

## V1：update-only low effective rank

满足

$$
\tau_8(\Delta W_T)\le0.10
$$

但

$$
\tau_8(W_T)>0.10,
\qquad
\rho_F>0.2403.
$$

允许结论：任务更新低有效秩；完整 Gaussian 基座尚未被主导。

## V2：task outliers without global energy dominance

满足

$$
\rho_{\mathrm{op}}<\frac12
$$

或存在预注册严格谱隙，但 \(\tau_8(W_T)>0.10\)。

允许结论：完整权重出现 task outliers；不能称低有效秩。

## V3：complete-weight low effective rank

同时满足

$$
\tau_8(W_T)\le0.10,
\qquad
\rho_F\le0.2403,
\qquad
r_{0.90}(W_T)\le8.
$$

允许结论：在该受控模型与训练 horizon，完整注册 writer 达到结构预算内低有效秩。

# 12. Main Decision Rule

M1 shared/full 获得主支持，要求至少 4/5 eligible seeds 同时满足：

1. \(C_{\mathrm{act,test}}\ge0.90\)；
2. \(C_{\mathrm{grad}}\ge0.80\)；
3. \(\tau_8(\Delta W_T)\le0.10\)；
4. \(C_{\mathrm{param}}\ge0.90\)；
5. V3；
6. functional replay；
7. shared/full 相对 disjoint/full 的 paired \(\tau_8(W_T)\) 至少低 \(0.10\)；
8. full/root 的 spike-growth差异与 effective exposure 差异同方向，且 event-budget guard 不推翻解释。

若只达到 V1 或 V2，报告对应较弱结论，不升级为 V3。

paired comparisons 报告全部 seed points、median difference 与 paired bootstrap 95% interval。test 只读取一次。

# 14. Known Good, Bad And Confusing Cases

## Known good

- M0 shared/full：\(\operatorname{rank}(\Delta W)\le8\)，loss 趋零后 \(\tau_8(W_T)\) 下降；
- constructed rank-8 spike + fixed Gaussian bulk：满足 T5 数值不等式；
- disjoint-tree 在自身 \(q=32\) 预算下低尾。

## Known bad

- context-dependent coordinate rotations；
- label-dependent background；
- full-weight weight decay；
- diagonal preconditioning；
- test-fitted activation subspace。

## Known confusing

- capability 失败导致 \(\Delta W\approx0\)；
- 只有一个 outlier 但 Gaussian bulk 仍占总能量；
- root-only 已覆盖全部 mappings；
- full-position 因位置平均而没有更高 effective exposure；
- output head 而非 \(W_2\) 承担 margin growth。

# 17. Failure Classification

- teacher ACE/margin 失败：prior/generator failure；
- M0 exact theorem失败：implementation/numerical failure；
- M1 capability失败：model/capability failure；
- capability通过但 activation bridge失败：learned-realization failure；
- activation通过但 coherence失败：NTP mechanism failure；
- update低尾但 \(\rho_F\) 不下降：finite-horizon spike-strength failure；
- V2 但非 V3：outlier/energy-rank distinction，非完整失败；
- replay失败：geometric proxy failure；
- M1通过、M2失败：Transformer envelope/routing boundary。
