## A. 理论对象

- [ ] 主对象是任务参数增量 $\Delta\Theta$，不是完整参数矩阵。
- [ ] 主表示对象是 ROOT task component / fixed-readout functional rank。
- [ ] raw effective rank 只作为附加结论。
- [ ] 单输入 $s$ 与跨样本头部 $k$ 已区分。
- [ ] local innovation 与不可验证的“原子语义”已区分。
- [ ] relevant context 与 nuisance context 已区分。
- [ ] full-position NTP 背景梯度没有被忽略。

## B. 定理假设

- [ ] H1–H12 均可由定义、生成器、架构或实验守卫识别。
- [ ] shared Jacobian/path image 被标为开放桥接条件。
- [ ] Adam 不被假设自动保持 SGD 子空间。
- [ ] residual/base 不被假设低秩。
- [ ] lookup 不被假设必然高秩。
- [ ] 高频不被当作 common mapping 的定义。

## C. 证明

- [ ] T0 no-go 反例成立。
- [ ] T1 路径像维数核算无重复计数。
- [ ] T2 population nuisance gradient 使用了正确条件独立。
- [ ] T3 使用 $n_{\mathrm{eff}}$，不是 raw exposure。
- [ ] T4 只控制任务增量。
- [ ] T5 精确桥只用于固定路由一层模型。
- [ ] T6 对可训练 attention 使用显式 Jacobian 假设。
- [ ] T7 使用固定原输出头。
- [ ] T8 的每个误差项都有定义。
- [ ] T9 raw effective rank 具有相对能量条件。

## D. 导师奇异模式先验

- [ ] 保留 direction 与 gain 的区分。
- [ ] 原指数关系未被推广为真实矩阵普适定理。
- [ ] weight decay 与 optimizer metric 边界已写明。
- [ ] singular alignment 不被直接当作功能效用。

## E. Protocol

- [ ] generator output balance 通过。
- [ ] shared mapping 有 unseen-combination gate。
- [ ] nuisance 不泄漏 label。
- [ ] calibration/test 完全分离。
- [ ] checkpoint 不读取 test rank。
- [ ] continuous positive control 在 discrete variant 前运行。
- [ ] M0/M1 positive controls 在 M2 Jacobian 前运行。
- [ ] functional rank 使用 fixed readout。
- [ ] random equal-rank control 已注册。
- [ ] residual high-rank nuisance 反例已注册。
- [ ] 5 seeds 和 CI 规则冻结。
- [ ] Fail 与 Insufficient 明确区分。
