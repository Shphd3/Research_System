# 树状低秩理论：研究路线图

## 顺序

1. **叶子几何**：是否存在可泛化的共享低维空间？
2. **组合规律**：父节点是否由共享角色线性算子解释？
3. **可达空间**：角色像空间是否重叠，秩增长是否受控？
4. **公共空间**：所有层是否近似共享同一空间？
5. **噪声边界**：创新残差是否小到使有效秩上界非平凡？
6. **MoE 分支**：单一空间失败时，是否存在多个局部低维空间？

## 决策门

| 阶段 | 通过后 | 失败后 |
|---|---|---|
| Plan 01 | 检验共享组合 | 转向多个子空间或停止该理论 |
| Plan 02 | 估计可达空间 | 改研究非线性组合或停止线性解释 |
| Plan 03 | 检验全局低增长 | 仅保留最坏秩增长定理 |
| Plan 04 | 使用固定全局秩定理 | 保留层级低秩或缓慢增长结论 |
| Plan 05 | 声称理论对真实表示非平凡 | 只能声称条件定理正确 |
| Plan 06 | 进入低秩专家与稀疏路由 | 不以子空间几何解释 MoE |

## 第一阶段最小闭环

当前只需完成：

- 正式证明中的层级 0–5；
- Plan 01–03 的实验设计固定；
- 合成数据验证定理和反例。

在真实数据通过 Plan 01–03 之前，不进入世界知识、复杂 MoE 或扩散模型。
