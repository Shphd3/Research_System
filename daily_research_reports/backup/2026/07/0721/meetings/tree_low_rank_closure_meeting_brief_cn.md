# 概率性稀疏激活树：条件低维定理、真实边界与 Router 含义

> **组会展示终版。**本文从零定义问题，先收束静态树定理，再给出概率性条件模型，
> 最后说明它为何比全局共享模型更接近当前研究对象，以及它与 Router 之间还缺什么。

## 一、执行摘要

1. **原始命题不成立。**短序列叶子共享低维空间，不能单独推出整棵树共享一个固定
   低维空间；不同孩子角色可以把同一叶子空间送入新的独立方向。
2. **静态树的正确结论是维数核算。**全局维数由角色映射保留多少方向、同层角色复用
   多少方向、不同层复用多少历史方向共同决定，而不是由“树”自动决定。
3. **新的条件定理成立。**若一次输入或任务只激活至多 $s$ 个局部信息源，每个信息源
   的群体空间至多为 $r$ 维，且活动路径使用固定线性映射，则这次激活模式的根可达
   空间至多为 $sr$ 维。
4. **概率只控制该事件出现多频繁。**若“活动信息源不超过 $s$ 个”以至少
   $1-\delta$ 的概率成立，则“当前模式可达空间不超过 $sr$ 维”也至少以同样概率成立。
5. **条件低维不等于全局低维。**不同输入、任务或 Router 模式可以选择不同甚至正交
   的低维空间；每次计算都低维，跨条件合并后的总体空间仍可满维。
6. **低维不等于有用。**全部关闭分支可以得到零维表示，却可能丢失任务所需信息。
   因而必须另行要求：稀疏表示相对完整计算仍保留任务效用。
7. **条件模型是当前更合理的候选，而非既成事实。**它允许完整系统保留高容量，同时
   只为当前任务提取少量相关语义摘要；这与全局共享算子缺乏真实证据的现状相容。
8. **Router 是模式选择器，不是定理结论。**定理解释 Router 稀疏选择可能带来的几何
   后果；要得到功能 Router，还需证明模式可复用、可识别，并且匹配专家提高未见数据
   上的任务效用。

## 二、我们究竟在建模什么？

- **节点表示：**短语、子句或其他局部信息经过编码得到的 $d$ 维向量。
- **群体子空间：**许多同类节点向量跨样本共同占据的线性空间。单个非零向量的矩阵
  秩恒为 1，因此“一个节点低秩”不是有意义的命题。
- **树状组合：**孩子表示沿固定角色映射传给父节点。这里的角色可以是左孩子、右孩子
  或其他有序位置。
- **可达空间：**给定叶子空间、组合映射和激活模式后，机制理论上能够在根产生的全部
  方向。它描述机制容量，不等于有限样本实际观察到的矩阵秩。
- **激活模式：**当前输入或任务保留哪些边、哪些局部信息源的二值选择。
- **条件低维：**固定一个激活模式，或固定一个能控制少量模式的条件后，跨样本根表示
  主要位于小空间中。它不要求所有条件共享同一个空间。
- **任务充分性：**稀疏表示虽然舍弃信息，但相对完整计算只产生受控的任务损失增量。

## 三、第一阶段：静态树理论收束了什么？

### 1. 原始推理为什么失败？

设所有叶子只有一个共同方向。左角色可以把这个方向映到方向 1，右角色可以把它映到
独立的方向 2；一层后空间就从一维变成二维。继续组合时，新方向还可继续累积。

因此，以下三件事都不足以保证全局低维：

- 叶子低维；
- 所有样本共享同一套角色映射；
- 树深有限。

### 2. 正确的静态结论

整棵树的全局维数由两类机制共同控制：

- **角色压缩：**每个角色映射主动保留较少方向；
- **方向复用：**不同角色或不同层重复使用已有方向。

同层复用只能保证每层分别低维。只有新层持续复用历史方向，或每层真正新增的方向数
始终有界，所有层合并后才会保持低维。公共不变子空间是一个强充分条件，但不是唯一
条件，也不是树结构自动提供的性质。

### 3. E07 在这里说明什么？

- 在 950 条合成记录中，维数公式与独立奇异值分解测量的最大差为 **0 维**。
- 7/7 个故意错误的核算方法被负对照拒绝。
- 充分激活时 20/20 条记录达到可达维数；不足激活时 20/20 条记录的观测秩严格更小。
- 一个代表性结果是 `128/252 -> 4/24 -> 4/4`：只有压缩或同层复用时，单层可以保持
  4 维但全局累积到 24 维；再加入跨层复用，全局才固定在 4 维。

**允许结论：**静态可达维数的核算实现正确地区分压缩、同层复用、跨层复用和有限
样本激活。

**不能结论：**E07 没有文本、预训练模型或训练，不能证明语言使用这些机制，也没有
验证本文新增的概率性激活假设。

## 四、第二阶段：概率性稀疏激活树证明了什么？

### 1. 模型

完整系统可以包含很多潜在分支，但一次输入或任务只激活其中一部分。每个活动局部
信息源位于一个低维群体空间，并沿当前活动路径传到根。激活模式可以依赖输入和任务，
但路径上的线性映射在所研究样本间保持固定。

### 2. 核心定理

对任何已经实现的固定激活模式：

> 根表示是所有活动信息源沿活动路径传播后的贡献之和；若活动信息源不超过 $s$ 个，
> 每个信息源空间维数不超过 $r$，则根可达空间维数不超过 $sr$。

若“活动信息源不超过 $s$ 个”以至少 $1-\delta$ 的概率成立，则上述可达维数界也以至少
$1-\delta$ 的概率成立。路径映射发生降维、或多条路径复用方向时，实际维数会更小。

### 3. 定理依赖的必要前提

1. **固定有限计算拓扑：**样本间拓扑变化时，拓扑必须并入条件或模式。
2. **低维局部信息源：**每类活动源跨样本共享一个维数受控的空间。
3. **固定或受控的线性路径映射：**输入相关标量门值可以改变系数，但任意输入相关
   矩阵或任意非线性映射不受该定理控制。
4. **高概率稀疏：**需要控制活动源数量的尾概率；仅知道平均激活数量小，只能得到更弱
   的概率界。
5. **明确比较范围：**真正的矩阵秩结论针对共享同一模式的一批样本。若同一条件仍混合
   多个模式，还必须控制模式数或模式空间的重叠。

### 4. 该定理没有证明什么？

- 没有证明完整树或完整语言系统全局低维；
- 没有证明真实输入确实只激活少量任务相关路径；
- 没有证明现有 Transformer 使用固定线性路径映射；
- 没有证明激活模式有限、稳定或可被学习；
- 没有证明稀疏表示保留任务信息；
- 没有证明 MoE、Top-1、Top-$k$ 或低秩专家最优。

## 五、为什么条件模型比全局共享模型更符合当前问题？

这里的“更符合”是**建模依据**，不是已经验证的经验事实。

1. **研究目标是任务相关摘要，而非无损保存整棵树。**一句话含有大量与当前查询无关的
   信息；允许任务只读取部分局部源，比要求根在所有任务中保留全部细节更符合目标。
2. **它区分总体容量与单次计算复杂度。**所有条件合并后可以使用很多方向，从而保留
   丰富能力；单个输入只使用少量活动路径，因此当前计算仍可低维。
3. **它容纳表示异质性。**不同节点类型、组合角色或任务可以使用不同局部空间，不再
   强迫所有样本共享同一个全局子空间和组合器。
4. **它与当前真实负结果相容。**E06 在控制父节点内容和边界方向后，Qwen 的正确切分
   优势为 `+0.0064`，Pythia 约为 `-0.0001`，区间均跨 0；这不支持模型通用的全局共享
   线性句法组合器，但没有排除条件化、局部或非线性机制。
5. **它可作为更丰富结构的活动计算近似。**语言依赖可能形成有向无环图或一般关系图。
   对一次具体计算，可以把被使用的有限路径展开成活动树来分析；这只是计算轨迹近似，
   不表示语言本体或原图严格是一棵树。

### 仍需警惕的替代解释

局部低维可能来自样本不足、长度、位置、编码器各向异性或人为分组，而非任务相关
语义机制。若每个样本都允许拥有自己的模式或空间，条件模型会退化成不可证伪的拟合。
因此条件必须数量有限、跨样本复用，并在未见数据上接受检验。

## 六、条件低维如何与 Router 发生关系？

可以把逻辑链写成：

```text
输入或任务条件
-> Router 选择有限激活模式
-> 当前只保留少量局部信息源
-> 条件定理给出当前可达维数上界
-> 任务充分性检验判断该压缩是否有用
```

### 理论直接支持的部分

- Router 若产生稀疏活动子树，则可以控制单次计算的可达维数；
- 完整模型可以拥有高维总容量，而单次输入只使用其中一小部分；
- 条件空间不必对齐，因此该解释不重新要求全局低维。

### 从几何到功能 Router 仍缺的条件

1. **模式复用：**只有少量模式，并在不同样本中反复出现；
2. **条件可识别：**Router 能在未见输入上预测合适模式；
3. **函数异质性：**不同条件确实需要不同函数，而不只是落在不同几何空间；
4. **条件效用：**匹配专家相对替代专家稳定降低未见数据任务损失；
5. **任务充分：**稀疏激活相对完整计算的性能损失受控；
6. **样本级稀疏：**一个样本只需少量模式或专家。

因此，**几何接近不等于专家有用**。目前只能把树深、节点类型、组合角色和任务查询
视为候选条件变量，不能把它们直接指定为已证实的专家标签。

## 七、理论、实验与推测的状态表

| 状态 | 当前最强表述 |
|---|---|
| **已证明** | 固定模式的路径展开；活动源数量给出的可达维数上界；高概率稀疏推出高概率模式条件低维；条件低维可与全局高维共存；含噪时的有效秩误差界 |
| **实现审计通过** | E07 的静态可达维数核算与独立测量完全一致 |
| **真实边界证据** | E06 不支持跨模型稳定的全局共享线性金标准切分组合器；现有传播界仍为空泛 |
| **尚未验证的经验命题** | 真实任务只激活少量相关路径；条件模式有限且可复用；稀疏表示保持任务效用 |
| **推测** | 活动模式可能对应功能专家，并可能通过 Router 减少单次计算复杂度或参数干扰 |

## 八、三条非平凡认识更新

1. **研究对象从“整棵树是否低秩”改为“一个条件下实际激活了多少独立信息方向”。**
   全局高维与单次条件低维并不矛盾。
2. **稀疏性只给几何容量界，不能代替信息保真。**任何 Router 理论都必须同时包含
   “激活少”和“任务充分”两条独立约束。
3. **Router 的理论角色不是创造低秩，而是选择可复用的局部计算模式。**只有当模式
   对应不同的最优函数并产生条件效用时，局部几何才有资格升级为专家路由依据。

## 九、建议的组会讲述顺序

1. **原命题不成立：**叶子低维不推出整棵树全局低维。
2. **静态树的正结论：**全局维数由累计新增方向核算；E07 只审计这一实现。
3. **条件模型的正结论：**全局可以高维，但高概率稀疏激活可使单次计算局部低维；
   E06 说明这是对全局共享模型有依据的放松，而不是已经验证的语言机制。
4. **Router 的边界：**它可以选择活动模式，但功能价值还需要模式复用、函数差异、
   条件效用和任务充分性；最后只裁定是否提升这一新问题。

## 十、唯一下一决策

> 判断“任务条件下的低维活动子树，同时保持任务效用”是否值得提升为下一张正式
> Thinking Card；在此之前不进入 Router 架构设计。
