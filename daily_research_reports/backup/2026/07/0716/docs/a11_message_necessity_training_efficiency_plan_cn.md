# A11 主线转向简短 Plan：实际消息、结构必要性与训练效率

日期：2026-07-16
状态：探索计划；尚未形成 Protocol，不授权实现或运行。

## 归因修正

保留旧实验的直接结果：联合替换第二层 `U03` K/V 没有产生跨种子稳定的强答案控制。撤回更强归因：“标准主头没有利用 MTP 信息”。旧任务存在直接绕行路径，且 K/V 补丁同时混合信息形成、Q–K 检索、V 内容和输出饱和。

## 统一研究问题

> 当早期状态是答案形成的必要中介时，informative-MTP 是否更早建立一条实际被标准下一词元系统使用的 branch 消息？

实际消息定义为

$$
M_{A\leftarrow U03}=\alpha_{A,U03}W_OV_{U03}.
$$

## 初步路线

1. **结构必要性：** 构造 `relay-required` 任务，使 `U03` 能读取 `BR_z`，答案位置不能直接读取 `BR_z`，只能经过 `U03`；保留 `bypass-open` 作为对照。
2. **消息因果性：** 在能力匹配检查点，对 $M_{A\leftarrow U03}$ 做删除检验必要性、donor 替换检验充分性；不再把原始 K/V 当作主要语义对象。
3. **训练效率：** 比较 NTP、shared-aux、informative-MTP 在固定算力下达到同一标准头能力阈值的步数，并检验 MTP 的效率增量是否只在 `relay-required` 中出现。

最小条件矩阵：

| 任务结构 | NTP | shared-aux | informative-MTP |
|---|---:|---:|---:|
| bypass-open | ✓ | ✓ | ✓ |
| relay-required | ✓ | ✓ | ✓ |

## 顺序与停止条件

先只确认 `relay-required` 的可学习性和无绕行性。若 NTP 在合理深度与预算内不能学会，停止比较目标函数，不运行 MTP；若绕行仍存在，先修任务。能力门通过后，才冻结消息因果指标和训练效率指标。
