# 0403 阶段总结

## 1. 到目前为止我们明确了什么

1. `linear_running_center` 仍然是干净 baseline。
2. `acp_lite` 是当前最强的一阶 comparator，不能绕开它继续讲新路线。
3. `specialization`、`low-rankness`、`variance-aware routing` 是三层不同概念，不能混用。
4. token-level audit 已经说明 expert specialization 的确存在，而且是可读的。
5. 0403 的 clustering audit 削弱了旧 diagonal quadratic 的语义叙事：
   - raw first-order features 仍然最对齐 coarse semantic labels
   - pure energy 可以产生强几何分离，但不等于 semantic grouping
   - diagonal second-order features 没有展示稳定的语义优势

## 2. 这意味着什么

这轮最大的变化不是“我们又多了一个结果”，而是：

**主线被迫重塑了。**

我们不再适合继续围绕“旧 diagonal quadratic 是否成立”推进。
现在真正值得推进的问题是：

- 什么样的二阶结构真正与 MoE routing 相关？
- 这些结构应该怎样和一阶信息组合？
- 新的 route 为什么在理论上比旧 diagonal quadratic 更合理？

## 3. 当前新的主线

现在更合理的新目标是一个 hybrid route，而不是纯 quadratic branch：

$$
\ell_e(x)
=
a_e^\top x_{\parallel}
+
b_e^\top x_c
+
\|V_e x_c\|_2^2
+
c_e
$$

其中：

- $$x_{\parallel}$$ 保留 mean-related information
- $$x_c$$ 保留 centered first-order residual
- $$\|V_e x_c\|_2^2$$ 表示 expert-specific low-rank subspace energy

这个形式的核心含义是：

**真正想推进的 variance-aware routing，不应该丢掉有用的一阶信息，而应该在一阶信息之上叠加结构化的二阶能量项。**

## 4. 当前最重要的理论问题

接下来和 theory agent 继续讨论时，最该盯住的是三个问题：

1. 为什么新的 hybrid route 在理论上比旧 diagonal quadratic 更合理？
2. `specialization -> low-rankness` 这条桥梁在我们当前问题里如何写得更强、更严谨？
3. 下一步最小实验到底应该怎样设计，才能真正支持或削弱这条新主线？

## 5. 当前最重要的实验问题

接下来交给 experiment agent 的实验，不应该再是“继续给旧 diagonal quadratic 找证据”，而应该围绕新主线：

1. refined clustering / separation audit
2. hybrid-route training progress + geometry audit

实验要回答的不是“quadratic 有没有用”，而是：

**新的 hybrid route 是否真的学出了更合理的 routing structure。**

## 6. 当前不能过度宣称什么

现在还不能说：

- 旧 diagonal quadratic 已经实现了真正的 variance routing
- pure energy separation 就等于 semantic routing
- 新 hybrid route 已经被实验验证
- 当前结果已经足以推出 CL 层面的最终收益

## 7. 进入下一步时最推荐的顺序

1. 用当前状态文档和 theory agent 继续讨论
2. 等 theory 端收束后，明确写出本轮实验设计
3. 再把状态文档 + 实验设计 + 执行信息交给 experiment agent
4. 实验结束后，把结果直接写回状态文档

## 8. 一句话总结

进入 0403 之后，我们已经从“为旧 diagonal quadratic 辩护”切换到：

**围绕 `mean-aware + centered-linear + low-rank subspace-energy` 的 hybrid route，重新建立理论主线，并设计最小实验去验证这条新主线是否值得继续推进。**
