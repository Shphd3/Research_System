## 1. 一页速览

### 核心结论

我们现在的问题不是单纯“让专家负载均匀”，而是：**均匀出现的特征，能否进入一个不塌缩、可解释、训练后可保持、并有功能价值的专家分区。**

当前证据支持四件事：

1. **塌缩不是因为特征不存在。** 受控任务中，隐藏状态里能读出槽位信息；已知特征中心也能形成好分区。
2. **第 0 步塌缩有清楚机制。** 共同成分 `c` 通过 `w_e^T c` 变成专家的隐式偏置，压过特征剩余成分。
3. **真实文本瓶颈是早期保存。** 替代特征第 0 步可路由，但普通训练第 5/10 步会覆盖它。
4. **分区值得保存。** 07 的受控结果显示，共同成分控制不只是改善负载，还能降低稀有特征损失，并出现专家功能价值。

### 本次汇报的主张边界

可以说：共同成分和早期锁定是当前最强机制解释；真实文本主瓶颈是早期训练覆盖；受控 D07 支持专家分区有功能价值。

不能说：塌缩已经解决；负载均匀就是专家分工；真实文本已经有语义专家；共同成分控制已经是可部署方法。

## 2. 研究问题



特征级专家分工至少需要四个条件：

| 条件 | 含义 | 当前状态 |
|---|---|---|
| 同特征一致 | 同一特征进入同一组专家 | 受控环境可达；真实文本第 0 步可达 |
| 不塌缩 | 不是少数专家吸收大多数样本 | 仍需和特征一致性一起看 |
| 训练后保持 | 第 5/10 步后分区还在 | 真实文本当前失败 |
| 功能价值 | 被选专家真的降低对应样本损失 | 受控 D07 支持，真实模型未完成 |

## 3. 机制模型

把带有特征 `f` 的路由位置隐藏状态写成：

```text
h_f = c + r_f
```

其中：

- `c` 是所有特征共享的共同成分；
- `r_f` 是特征 `f` 自己的剩余成分。

门控器给专家 `e` 的分数是：

```text
z_{f,e} = w_e^T h_f = w_e^T c + w_e^T r_f
```

`w_e^T c` 对所有特征都相同，因此它相当于专家 `e` 的隐式共同偏置。即使门控器没有显式偏置项，也会因为随机行向量对共同成分投影不同而产生优势专家。

如果某个专家 `e*` 的共同成分优势大于特征剩余成分带来的修正：

```text
(w_e* - w_e)^T c > |(w_e* - w_e)^T r_f|
```

那么所有特征都会被送到 `e*`。这就是为什么“特征频率均匀”不自动带来“专家使用均匀”。

训练后塌缩还需要早期锁定解释：第 0 步优势专家收到更多样本，得到更多梯度，专家功能和门控分配共同适应，初始偏差被放大。

## 4. 证据链

| 结论 | 关键证据 | 解释 | 边界 |
|---|---|---|---|
| 塌缩不是特征缺失 | 受控任务中槽位探针可读；槽位初始化能形成高一致性分区 | 路由失败不是因为隐藏状态没有特征 | 不证明真实语义特征 |
| 第 0 步由共同成分主导 | 共同分数能预测优势专家；抵消共同分数能改善早期路由 | `w_e^T c` 是隐式专家偏置 | 不等于最终解决方案 |
| 早期训练会覆盖分区 | 真实文本替代特征第 0 步一致性高，第 5/10 步接近随机 | 第一失败点是训练保存 | 不能据此否定替代特征价值 |
| 全位置聚类会污染特征发现 | 只看路由相关位置能恢复特征，全位置会混入非路由状态 | 样本池选择是机制问题 | 还需无标签筛选器 |
| 分区有受控功能价值 | D07 中共同成分控制降低稀有特征损失；被选专家有消融价值 | 专家分区不只是负载好看 | 只限受控合成环境 |

## 5. 六分钟汇报稿

### 0:00-0:45 先定问题

我这次不是直接声称稀疏专家模型已经形成了专家分工，而是在拆它为什么连均匀特征都不能稳定进专家。当前核心问题是：特征频率均匀、门控器随机初始化时，为什么只选一个专家的门控器仍会塌缩；如果第 0 步能形成分区，为什么训练第 5/10 步又会覆盖它。

### 0:45-1:45 讲机制模型

我把路由位置的隐藏状态写成 `h_f = c + r_f`。`c` 是所有特征共享的共同成分，`r_f` 是特征自己的成分。门控分数是 `w_e^T h_f = w_e^T c + w_e^T r_f`。这里 `w_e^T c` 对所有特征都一样，所以它相当于专家 `e` 的隐式偏置。只要这个共同成分优势大于特征成分差异，所有特征就会被送到同一个专家。

### 1:45-2:45 讲 05 的机制证据

受控任务说明，塌缩不是因为特征不存在。隐藏状态里能读出槽位信息，已知槽位中心初始化也能得到好分区。但是随机初始化下，普通门控器会进入塌缩。共同分数 `w_e^T c` 能预测早期优势专家；抵消共同分数能改善早期路由。这说明第 0 步塌缩种子来自共同成分诱导的隐式专家偏置。

### 2:45-3:50 讲 06 的阶段合同

我把真实文本主线拆成三个合同：第一，是否存在稳定替代特征；第二，替代特征能否变成第 0 步门控初始化；第三，训练能否保持。结果是，前两步通过，第三步失败。真实文本中替代特征存在，第 0 步能被线性路由，但普通训练第 5/10 步会覆盖分区。所以现在第一瓶颈不是发现替代特征，也不是第 0 步桥接，而是早期训练保存。

### 3:50-4:40 讲 06_17 的边界修正

受控桥接里，全位置聚类失败不是因为路由特征几何不存在，而是因为样本池混入了太多非路由隐藏状态。只看路由相关位置或槽位末端位置时，可以恢复特征；全位置会把不该用于路由的状态混进去。这说明后续如果继续做无标签发现，需要路由相关状态筛选器，而不是把所有隐藏状态一起聚类。

### 4:40-5:30 讲 07 为什么进入主线

即使解决塌缩和保存，也还不能说专家分工有价值。07 的作用是回答：分区是否真的降低特征干扰。D07 受控结果支持这一点：共同成分控制在负载匹配下减少稀有特征损失，并且被选专家对对应组有消融价值。所以 07 不是换方向，而是证明为什么前面的分区值得保存。

### 5:30-6:00 请导师裁定

我的建议是，下一步优先做真实文本早期保存 / 反反馈协议。问题是：能否让第 0 步已经存在的替代特征分区穿过第 5/10 步窗口，同时不伤害语言建模损失。想请导师裁定：这个是否应作为下一轮主锚点，还是应先做无标签路由相关状态筛选器，或先把 07 的功能价值诊断迁移到真实模型。

## 7. 导师可能追问与回答

### 问：你现在到底要解决负载均匀，还是专家分工？

答：负载均匀只是入口护栏。真正目标是特征级专家分工。一个方法如果只改善负载、但特征一致性不高，不能算分工。

### 问：共同成分控制是不是已经解决问题？

答：没有。它支持共同成分是早期机制项，但真实文本普通训练仍会覆盖第 0 步分区。当前瓶颈是保存，不是单纯第 0 步初始化。

### 问：替代特征是不是语义特征？

答：不能这样说。替代特征只是稳定隐藏状态簇，用来让真实文本问题可评估。它是评估桥，不是语义声明。

### 问：07 和 05/06 是不是两条线？

答：不是。05/06 解决“能否形成并保持分区”的入口条件；07 解决“这个分区是否有功能价值”。没有 07，负载和一致性都可能只是表面结构。

### 问：下一步为什么不继续做无标签聚类？

答：如果目标是 受控桥接，路由相关状态筛选器很重要。但真实文本主线的第一坏点已经定位到早期保存；最快推进主线的是测试反反馈能否保存第 0 步已有分区。
