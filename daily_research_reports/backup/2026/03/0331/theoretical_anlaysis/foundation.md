# 路由机制的数学理论基础

## 一阶与二阶分发、去中心化与二次路由的统一理论框架

***

## 第零部分：背景与动机

### 0.1 大背景：Mixture-of-Experts（MoE）路由问题

在现代大语言模型（LLM）中，**Mixture-of-Experts（MoE）** 架构已成为扩展模型容量的关键技术。MoE 的核心思想是：

1. **稀疏激活**：模型包含多个"专家"（通常是 FFN 层），但对于每个输入 token，只激活其中少数专家
2. 路由机制：一个路由器（Router） 负责决定每个 token 应该被发送到哪个专家

这种架构的优势在于：可以在不显著增加计算成本的情况下，大幅增加模型参数量。

### 0.2 问题：为什么需要"按方差分发"？

在标准的 MoE 架构中，路由器通常是一个线性层，输出每个专家的得分，然后通过 softmax 选择 top-k 专家。然而，**实践发现简单的线性路由器 存在严重问题**：

1. **路由坍塌（Routing Collapse）**：路由器倾向于将大部分 token 发送到少数专家，导致负载严重不均衡
2. **专家利用率不足**：即使存在多个专家，大部分专家得不到有效利用

**为什么会出现这个问题？**

在 LLM 中，来自不同领域（domain）的 token（如代码、数学、文本、推理等）的激活向量，可能共享一个共同的"基线方向"。这个基线方向会主导线性路由器的决策，使得路由器实际上只是在学习"这个 token 是否远离基线"，而非"这个 token 属于哪个领域"。

### 0.3 核心问题

基于上述观察，我们提出并试图回答以下问题：

**问题 1（定义问题）**：什么是"按方差分发"？如何从数学上精确定义一阶分发和二阶分发？

**问题 2（必要性问题）**：在什么情况下，基于均值差异的一阶分发是充分的？什么情况下需要利用协方差/方差的二阶差异来分发？

**问题 3（可行性问题）**：如果需要利用二阶信息，路由器应该如何构造？现有的 Debiased Quadratic Router 是否足够？

**问题 4（去偏问题）**：为什么二阶去偏（Debiasing）是必要的？不去偏会导致什么后果？

## 第一部分：符号定义与基本框架

### 1.1 符号定义

设我们有：

- $K$ 个专家 (experts)，索引为 $k \in {1, 2, \ldots, K}$
- $D$ 个领域 (domains)，索引为 $d \in {1, 2, \ldots, D}$
- Token 激活矩阵：$X \in \mathbb{R}^{N \times d\_{model}}$，其中 $N$ 为 token 数量，$d\_{model}$ 为隐层维度

为简化 notation，本文档主要考虑二分类场景（$K=2$，或一个专家 vs 其他），但结论可推广到多分类。

### 1.2 领域条件分布

定义 token 激活值在领域 $d$ 下的条件分布：
$$p(x | D=d)$$

其样本均值为：
$$\mu\_d = \mathbb{E}\[x | D=d] = \frac{1}{N\_d} \sum\_{i \in \text{Domain } d} x\_i$$

其样本协方差为：
$$\Sigma\_d = \mathbb{E}\[(x - \mu\_d)(x - \mu\_d)^T | D=d]$$

### 1.3 路由评分函数

线性路由器对专家 $k$ 的评分定义为：
$$\ell\_k^{lin}(x) = w\_k^T x + b\_k$$

其中 $w\_k \in \mathbb{R}^{d\_{model}}$，$b\_k \in \mathbb{R}$。

### 1.4 Token 级别的一阶与二阶路由

上述定义都是从**领域统计量**（$\mu\_d$，$\Sigma\_d$）的角度给出的。对于实际路由决策，我们需要理解这些统计量在 **token 级别** 的对应形式。

**定义 1.4.1（Token 级别的一阶路由）**

对单个 token $x\_i$，线性路由器的评分为：
$$\ell^{lin}(x\_i) = w^T x\_i + b$$

**Token 级别的含义**：

- 每个 token 激活向量在方向 $w$ 上做投影
- 这个投影值 $w^T x\_i$ 反映的是：该 token 的激活向量**在 $w$ 方向上的"坐标"**
- 如果 $w$ 学到了领域差异方向（即 $\mu\_A - \mu\_B$ 的方向），那么领域 A 的 token 投影值偏正，领域 B 的 token 投影值偏负

**定义 1.4.2（Token 级别的二阶路由）**

对单个 token $x\_i$，Debiased Quadratic Router 的评分为：
$$\ell\_{quad\_deb}(x\_i) = w\_1^T x\_{c,i} + w\_2^T (x\_{c,i} \odot x\_{c,i} - \lambda)$$

其中 $x\_{c,i} = x\_i - \mu\_{global}$，$\odot$ 为 Hadamard 积（元素级乘法）。

**Token 级别的含义**：

- 第一项 $w\_1^T x\_{c,i}$：和线性路由一样，看的是激活向量的**方向**
- 第二项 $w\_2^T (x\_{c,i} \odot x\_{c,i})$：**每个维度自己跟自己的乘积**，即 $w\_2^T \cdot \[x\_{c,i,1}^2, x\_{c,i,2}^2, ..., x\_{c,i,d}^2]^T$

这问的是这个 token **在每个维度上波动的剧烈程度**，而不关心它的整体方向。

**一阶 vs 二阶的本质区别**：

| <br />      | 一阶路由        | 二阶路由                       |
| ----------- | ----------- | -------------------------- |
| **看什么**     | $w^T x\_i$  | $w\_2^T (x\_i \odot x\_i)$ |
| **物理含义**    | 激活向量的**方向** | 每个维度的**幅度**（方差/波动）         |
| **对单token** | 投影值         | 各维度平方的加权和                  |
| **决策依据**    | "你在哪个方向"    | "你波动大不大"                   |

## 第二部分：去中心化（Centering）的理论基础

### 2.1 核心问题：为什么路由需要去中心化？

**直观理解**：在 LLM 中，不同领域的 token 激活值可能共享一个共同的"基线"方向。这个基线方向会主导线性路由器的决策，使得路由器实际上只是在学习"这个 token 是否远离基线"，而非"这个 token 属于哪个领域"。

**形式化分析**：

设领域 $A$ 和 $B$ 的激活均值分别为 $\mu\_A$ 和 $\mu\_B$。考虑它们可以分解为：
$$\mu\_A = \alpha \mu\_{shared} + \beta\_A v\_A$$
$$\mu\_B = \alpha \mu\_{shared} + \beta\_B v\_B$$

其中：

- $\mu\_{shared}$ 是**共享方向**（所有领域共有的基线）
- $v\_A, v\_B$ 是各自领域特有的方向
- $\alpha$ 是共享方向的权重

如果 $\alpha \gg |\beta\_A|, |\beta\_B|$，那么 $\mu\_A \approx \mu\_B \approx \alpha \mu\_{shared}$，线性路由器难以区分。

**定理 2.1（线性路由失效条件）**

设线性路由器参数为 $(w, b)$，其对领域 $A$ 和 $B$ 的期望评分差为：
$$\Delta\_{AB} = \mathbb{E}\[\ell\_k^{lin}(x) | D=A] - \mathbb{E}\[\ell\_k^{lin}(x) | D=B] = w^T(\mu\_A - \mu\_B)$$

**证明**：
$$\mathbb{E}\[\ell\_k^{lin}(x) | D=A] = \mathbb{E}\[w^T x + b | D=A] = w^T \mu\_A + b$$
$$\mathbb{E}\[\ell\_k^{lin}(x) | D=B] = w^T \mu\_B + b$$
$$\Delta\_{AB} = (w^T \mu\_A + b) - (w^T \mu\_B + b) = w^T(\mu\_A - \mu\_B)$$

**证毕** □

**推论 2.1.1**：当且仅当 $\mu\_A = \mu\_B$ 时，对所有 $w \in \mathbb{R}^{d\_{model}}$ 都有 $\Delta\_{AB} = 0$，线性路由器完全失效。

**推论 2.1.2**：即使 $\mu\_A \neq \mu\_B$，如果 $\mu\_A - \mu\_B$ 与 $w$ 正交（即 $w^T(\mu\_A - \mu\_B) = 0$），该路由器参数也无法区分这两个领域。

### 2.2 去中心化的数学本质

**定义 2.2.1（全数据全局去中心化）**

给定全量数据 $X$（包含所有领域），全局均值为：
$$\mu\_{global} = \frac{1}{N\_{total}} \sum\_{i=1}^{N\_{total}} x\_i = \mathbb{E}\[x]$$

去中心化操作为：
$$x\_c = x - \mu\_{global}$$

**引理 2.2.1（去中心化后的均值性质）**

设领域 $A$ 和 $B$ 的 token 数量分别为 $N\_A$ 和 $N\_B$，则去中心化后的领域均值满足：
$$\mu\_{c,A} = \mu\_A - \mu\_{global}$$
$$\mu\_{c,B} = \mu\_B - \mu\_{global}$$

且当 $N\_A = N\_B$ 时：
$$\mu\_{c,B} = -\mu\_{c,A}$$

**证明**：

设全量数据由领域 $A$ 和 $B$ 组成（为简化，假设只有两个领域）：
$$N\_{total} = N\_A + N\_B$$
$$\mu\_{global} = \frac{N\_A \mu\_A + N\_B \mu\_B}{N\_A + N\_B}$$

当 $N\_A = N\_B = N$ 时：
$$\mu\_{global} = \frac{N \mu\_A + N \mu\_B}{2N} = \frac{\mu\_A + \mu\_B}{2}$$

因此：
$$\mu\_{c,A} = \mu\_A - \frac{\mu\_A + \mu\_B}{2} = \frac{\mu\_A - \mu\_B}{2}$$
$$\mu\_{c,B} = \mu\_B - \frac{\mu\_A + \mu\_B}{2} = \frac{\mu\_B - \mu\_A}{2} = -\mu\_{c,A}$$

**证毕** □

**定理 2.2.2（全数据去中心化后的余弦相似度）**

当两个领域 token 数量相同时，去中心化后的领域均值方向**必然**满足：
$$\cos(\mu\_{c,A}, \mu\_{c,B}) = -1$$

**证明**：

由引理 2.2.1，当 $N\_A = N\_B$ 时，$\mu\_{c,B} = -\mu\_{c,A}$。

余弦相似度定义为：
$$\cos(u, v) = \frac{u^T v}{|u| |v|}$$

代入 $v = -u$：
$$\cos(u, -u) = \frac{u^T (-u)}{|u| |u|} = \frac{-|u|^2}{|u|^2} = -1$$

**证毕** □

### 2.3 为什么中心化后专家仍然能均衡分发？

**问题**：中心化后不是没有一阶信息了吗？为什么专家分发反而更均衡了？

**回答**：这里存在一个关键误解。需要区分**两类"一阶信息"**：

| 一阶信息类型                                    | 数学定义       | 中心化后的命运          |
| ----------------------------------------- | ---------- | ---------------- |
| **类型 I**：全局基线方向 $\mu\_{global}$           | 所有领域的共同均值  | 被**移除**          |
| **类型 II**：领域特定方向 $\mu\_d - \mu\_{global}$ | 去中心化后的领域均值 | **保留**，且不同领域方向相反 |

**关键洞察**：当 $N\_A = N\_B$ 时，虽然 $\mu\_{c,A} = -\mu\_{c,B}$，但 $|\mu\_{c,A}| \neq 0$（除非 $\mu\_A = \mu\_B$）。

**定理 2.3.1（去中心化后领域均值的方向差异）**

即使 $\cos(\mu\_{c,A}, \mu\_{c,B}) = -1$，两个领域的去中心化均值向量**并不相同**，它们是**完美反向**的。

这意味着：

- 如果路由器依赖 $\mu\_{c,A}$ 和 $\mu\_{c,B}$ 的方向来决策，**两个领域的决策边界会相反**
- 这种"方向相反"恰恰实现了**均衡分发**：领域 A 被导向专家 1，领域 B 被导向专家 2

**数学解释**：

设线性路由器参数为 $w$，其对去中心化数据的评分差异为：
$$\Delta\_{AB}^c = w^T(\mu\_{c,A} - \mu\_{c,B}) = w^T(\mu\_{c,A} - (-\mu\_{c,A})) = 2 w^T \mu\_{c,A}$$

由于 $\mu\_{c,B} = -\mu\_{c,A}$：

- 若 $w^T \mu\_{c,A} > 0$，则领域 A 的评分高于领域 B
- 若 $w^T \mu\_{c,A} < 0$，则领域 A 的评分低于领域 B

**这实现了天然的领域分离**：不同的领域会被导向不同的专家！

### 2.4 定理 2.4.1（为什么必须取均值）

**核心论点**：在特征不去均值的时候，所有领域的数据都由同一个均值引导，线性路由必然失效。

**定理陈述**：设原始特征 $x$ 的全局均值为 $\mu\_{global}$。如果路由器仅使用一阶投影 $w^T x$，则在 $\mu\_A = \mu\_B = \mu\_{global}$ 的条件下，无论参数 $w$ 如何选择，都无法区分领域 $A$ 和 $B$。

**证明**：

路由器对领域 $d$ 的期望输出为：
$$\mathbb{E}\[w^T x | D=d] = w^T \mu\_d + b$$

如果 $\mu\_A = \mu\_B = \mu\_{global}$（即领域共享同一均值），则：
$$\mathbb{E}\[w^T x | D=A] = w^T \mu\_{global} + b = \mathbb{E}\[w^T x | D=B]$$

对所有 $w \in \mathbb{R}^{d\_{model}}$ 成立。因此线性路由器无法通过调整 $w$ 来区分两个领域。

**证毕** □

**推论 2.4.2（均值的必要性）**

去中心化操作（减均值）是**必要**的，因为它打破了"所有领域共享同一均值"的困境：

- 原始均值：$\mu\_A \approx \mu\_B \approx \mu\_{global}$ → 无法区分
- 去中心化后：$\mu\_{c,A} = \mu\_A - \mu\_{global}$，$\mu\_{c,B} = \mu\_B - \mu\_{global}$ → 当 $\mu\_A \neq \mu\_B$ 时，$\mu\_{c,A} \neq \mu\_{c,B}$

**这就是为什么激活值必须要进行取均值**：取均值后做减法（去中心化），才能让不同领域的方向产生差异！

## 第三部分：一阶与二阶统计量的理论分析

### 3.1 一阶统计量：均值

**定义 3.1.1（一阶统计量）**

随机向量 $x \in \mathbb{R}^d$ 的一阶统计量为其均值：
$$\mu = \mathbb{E}\[x]$$

样本估计为：
$$\hat{\mu} = \frac{1}{N} \sum\_{i=1}^N x\_i$$

### 3.2 二阶统计量：协方差

**定义 3.2.1（二阶统计量 - 协方差矩阵）**

随机向量 $x$ 的二阶统计量为协方差矩阵：
$$\Sigma = \mathbb{E}\[(x - \mu)(x - \mu)^T]$$

展开形式：
$$\Sigma = \mathbb{E}\[xx^T] - \mu\mu^T$$

**注意**：协方差是**二次型**的期望，涉及 $x$ 与自身的乘积（$xx^T$ 是 $d \times d$ 矩阵）。

### 3.3 线性变换能提取什么？

**定理 3.3.1（线性变换提取一阶统计量）**

设线性变换 $f(x) = Wx + b$，其中 $W \in \mathbb{R}^{p \times d}$，$b \in \mathbb{R}^p$。

变换后的期望为：
$$\mathbb{E}\[f(x) | D] = W \mu\_D + b$$

变换后的协方差为：
$$\text{Cov}\[f(x) | D] = W \Sigma\_D W^T$$

**关键观察**：

- **一阶输出** $W\mu\_D + b$ **仅依赖原始均值** $\mu\_D$
- **二阶输出** $W\Sigma\_D W^T$ **仅依赖原始协方差** $\Sigma\_D$

**证明**：

一阶部分：
$$\mathbb{E}\[Wx + b | D] = W \mathbb{E}\[x|D] + b = W\mu\_D + b$$

二阶部分：
$$\text{Cov}\[Wx + b | D] = \mathbb{E}\[(Wx - W\mu\_D)(Wx - W\mu\_D)^T | D] = W \mathbb{E}\[(x-\mu\_D)(x-\mu\_D)^T | D] W^T = W \Sigma\_D W^T$$

**证毕** □

### 3.4 线性路由器能利用什么信息？

**定理 3.4.1（线性路由器的信息论限制）**

线性路由器 $\ell^{lin}(x) = w^T x + b$ **只能**利用一阶统计量（均值差异），**无法**利用二阶统计量（协方差差异）。

**证明**：

线性路由器的输出为 $w^T x + b$，其期望为 $w^T \mu\_D + b$。

期望输出差异为：
$$\mathbb{E}\[\ell^{lin}(x)|D=A] - \mathbb{E}\[\ell^{lin}(x)|D=B] = w^T(\mu\_A - \mu\_B)$$

这个差异**仅依赖于均值差** $\mu\_A - \mu\_B$，与协方差无关。

**证毕** □

**推论 3.4.2（协方差差异需要非线性路由器）**

如果 $\mu\_A = \mu\_B$ 但 $\Sigma\_A \neq \Sigma\_B$，线性路由器**完全无法**区分领域 A 和 B，即使它们的二阶结构完全不同。

### 3.5 非线性路由器：二次型路由器

**定义 3.5.1（二次型路由器）**

设路由器评分为：
$$\ell^{quad}(x) = x^T Q x + w^T x + b$$

其中 $Q \in \mathbb{R}^{d \times d}$ 为对称矩阵（二次项系数），$w \in \mathbb{R}^d$（一次项系数）。

**定理 3.5.2（二次路由器可利用二阶统计量）**

二次路由器的期望输出为：
$$\mathbb{E}\[\ell^{quad}(x) | D] = \text{Tr}(Q \Sigma\_D) + \mu\_D^T Q \mu\_D + w^T \mu\_D + b$$

**证明**：

展开期望：
$$\mathbb{E}\[x^T Q x | D] = \mathbb{E}\[\text{Tr}(x^T Q x)] = \mathbb{E}\[\text{Tr}(Q x x^T)] = \text{Tr}(Q \mathbb{E}\[xx^T])$$

利用 $\mathbb{E}\[xx^T] = \Sigma\_D + \mu\_D \mu\_D^T$：
$$\mathbb{E}\[x^T Q x | D] = \text{Tr}(Q \Sigma\_D) + \text{Tr}(Q \mu\_D \mu\_D^T) = \text{Tr}(Q \Sigma\_D) + \mu\_D^T Q \mu\_D$$

加上线性项和常数项即得证。

**证毕** □

**推论 3.5.3（二次路由器可区分均值相同但协方差不同的领域）**

当 $\mu\_A = \mu\_B = \mu$ 但 $\Sigma\_A \neq \Sigma\_B$ 时：
$$\mathbb{E}\[\ell^{quad}(x)|D=A] - \mathbb{E}\[\ell^{quad}(x)|D=B] = \text{Tr}(Q (\Sigma\_A - \Sigma\_B))$$

只要 $\Sigma\_A \neq \Sigma\_B$，总存在 $Q$ 使得该差异非零。

## 第四部分：二次路由与二阶统计量的深入分析

### 4.1 Debiased Quadratic Router 的定义

**定义 4.1.1（元素级二阶均值）**

$$\lambda\_t = \mathbb{E}\[x\_c \odot x\_c]$$

其中 $\odot$ 表示 Hadamard 积（元素级乘法），$x\_c = x - \mu\_{global}$ 为去中心化后的激活值。

注意：$\lambda\_t \in \mathbb{R}^d$ 是**向量**（不是矩阵），每个维度存储该维度的二阶原点矩。

**定义 4.1.2（EMA 估计）**

$$\lambda\_t = (1-\gamma) \lambda\_{t-1} + \gamma \overline{(x\_c \odot x\_c)}\_t$$

这是对 $\mathbb{E}\[x\_c \odot x\_c]$ 的指数滑动平均估计。

**定义 4.1.3（去偏二阶特征）**

$$q\_{deb} = x\_c \odot x\_c - \lambda\_t$$

这相当于"去中心化的二阶矩"减去其二阶均值。

**定义 4.1.4（Debiased Quadratic Router Logits）**

$$\ell\_{quad\_deb}(x) = W\_1 x\_c + W\_2 q\_{deb}$$

其中 $W\_1 \in \mathbb{R}^{K \times d}$，$W\_2 \in \mathbb{R}^{K \times d}$。

### 4.2 Debiased Quadratic Router 真的能看二阶信息吗？

**分析**：

展开 $\ell\_{quad\_deb}(x)$ 的第 $k$ 个分量：
$$\ell\_{k, quad\_deb}(x) = w\_{1,k}^T x\_c + w\_{2,k}^T (x\_c \odot x\_c - \lambda\_t)$$
$$= w\_{1,k}^T x\_c + w\_{2,k}^T (x\_c \odot x\_c) - w\_{2,k}^T \lambda\_t$$

**定理 4.2.1（Debiased Quadratic Router 的信息提取能力）**

Debiased Quadratic Router **可以**提取二阶信息，但其二阶项是**元素级**的，而非矩阵形式的协方差。

**证明**：

传统协方差形式：$\Sigma = \mathbb{E}\[(x-\mu)(x-\mu)^T]$ 是 $d \times d$ 矩阵

Debiased QR 的二阶项：$q\_{deb} = x\_c \odot x\_c - \lambda\_t$ 是 $d$ 维向量

它们的区别在于：

- 协方差矩阵 $\Sigma$ 包含**不同维度之间的相关性**（$i \neq j$ 时 $\mathbb{E}\[x\_i x\_j]$）
- 元素级二阶 $q\_{deb}$ 只包含**每个维度自己的二阶信息**（对角线元素）

因此：

- 如果领域差异体现在**协方差矩阵的非对角线**（维度间相关），Debiased QR **无法**捕获
- 如果领域差异体现在**每个维度的方差**（对角线元素），Debiased QR **可以**捕获

**证毕** □

### 4.3 二次路由 vs 传统协方差路由

| 特征    | 二次协方差路由 $\ell = x^T Q x$ | Debiased QR $\ell = W\_1 x\_c + W\_2 (x\_c \odot x\_c)$ |
| ----- | ------------------------ | ------------------------------------------------------- |
| 形式    | 完整二次型 $d \times d$       | 元素级二次 $d$ 维向量                                           |
| 协方差捕获 | 全协方差 $\Sigma$            | 仅对角线 $\text{diag}(\Sigma)$                              |
| 维度间相关 | ✅ 能捕获                    | ❌ 不能捕获                                                  |
| 计算复杂度 | $O(d^2)$                 | $O(d)$                                                  |
| 可解释性  | 困难                       | 较易                                                      |

### 4.4 定理 4.4.1（二阶路由的有效性条件）

**定理陈述**：Debiased QR 能够有效区分两个领域，当且仅当这两个领域的二阶差异**存在于对角线元素**中。

**证明**：

设两个领域 $A$ 和 $B$，$\mu\_A = \mu\_B = \mu$（均值为零或已去中心化）。

Debiased QR 对领域 $A$ 的期望输出：
$$\mathbb{E}\[\ell\_{k, quad\_deb}|A] = w\_{1,k}^T \mu + w\_{2,k}^T (\mathbb{E}\[x\_c \odot x\_c | A] - \lambda\_t)$$

由于 $\mu = 0$（已去中心化）：
$$\mathbb{E}\[\ell\_{k, quad\_deb}|A] = w\_{2,k}^T (\mathbb{E}\[x\_c \odot x\_c | A] - \mathbb{E}\[x\_c \odot x\_c])$$

其中 $\mathbb{E}\[x\_c \odot x\_c | A] - \mathbb{E}\[x\_c \odot x\_c]$ 是领域 $A$ 的"二阶均值异常"向量。

两个领域的期望差为：
$$\Delta\_k = w\_{2,k}^T (\mathbb{E}\[x\_c \odot x\_c | A] - \mathbb{E}\[x\_c \odot x\_c | B])$$

这取决于**对角线二阶矩的差异**（每个维度独立），而非协方差矩阵的非对角线元素。

**证毕** □

## 第五部分：多类分类的路由分析

### 5.1 多专家场景的建模

现在我们将二分类的分析推广到 $K$ 个专家的场景。

设我们有 $K$ 个专家和 $D$ 个领域（通常 $D \geq K$）。路由器需要将每个 token 分配到 $K$ 个专家中的一个或多个。

**定义 5.1.1（多类线性路由器）**

对 $K$ 个专家，线性路由器的输出为：
$$\ell^{lin}(x) = W x + b$$

其中 $W \in \mathbb{R}^{K \times d}$，$b \in \mathbb{R}^K$。第 $k$ 个专家的分数为 $\ell\_k = w\_k^T x + b\_k$。

**定义 5.1.2（多类二次路由器）**

$$\ell^{quad}(x) = \text{diag}(X^T Q X) + W x + b$$

或使用 Debiased 形式：
$$\ell\_{quad\_deb}(x) = W\_1 x\_c + W\_2 (x\_c \odot x\_c - \lambda)$$

### 5.2 多类场景下的一阶分析

**定理 5.2.1（多类线性路由的判别力）**

对于 $K$ 个专家，线性路由器对专家 $k$ 的期望分数为：
$$\mathbb{E}\[\ell\_k^{lin} | D=d] = w\_k^T \mu\_d + b\_k$$

**证明**：

$$\mathbb{E}\[w\_k^T x + b\_k | D=d] = w\_k^T \mathbb{E}\[x | D=d] + b\_k = w\_k^T \mu\_d + b\_k$$

**证毕** □

**推论 5.2.2（多类线性路由的领域分离条件）**

线性路由器能够将不同领域分离到不同专家，当且仅当存在一组权重 ${w\_k}$ 使得：

$${w\_k^T \mu\_d + b\_k}\_{k=1}^K$$

对不同领域 $d$ 产生可区分的模式。

### 5.3 多类场景下的二阶分析

**定理 5.3.1（多类二次路由的期望输出）**

二次路由器对专家 $k$ 的期望输出为：
$$\mathbb{E}\[\ell\_k^{quad} | D=d] = \text{Tr}(Q\_k \Sigma\_d) + \mu\_d^T Q\_k \mu\_d + w\_k^T \mu\_d + b\_k$$

**证明**：

直接由定理 3.5.2 推广得到，对每个专家 $k$ 独立应用。

**证毕** □

**定理 5.3.2（多类 Debiased QR 的期望输出）**

对去中心化后的数据 $x\_c = x - \mu\_{global}$，Debiased QR 对专家 $k$ 的期望输出为：

当 $\mu\_d = \mu\_{global}$（即领域均值等于全局均值）时：
$$\mathbb{E}\[\ell\_{k, quad\_deb} | D=d] = w\_{2,k}^T (\mathbb{E}\[x\_c \odot x\_c | D=d] - \lambda)$$

**分析**：

这表明 Debiased QR 的第二项 $w\_2^T (x\_c \odot x\_c - \lambda)$ 捕捉的是每个维度的"二阶异常"。如果领域 $d$ 在第 $i$ 个维度的方差比全局均值大，则 $w\_{2,k,i}$ 可以被学习来区分这个领域。

### 5.4 多类场景下的负载均衡分析

**定义 5.4.1（专家利用率）**

专家 $k$ 的利用率为：
$$\rho\_k = \frac{1}{N} \sum\_{i=1}^N \mathbb{1}(\text{argmax}\_j \ell\_j(x\_i) = k)$$

**定理 5.4.2（多类路由的坍缩条件）**

如果所有领域的均值 $\mu\_d$ 都接近全局均值 $\mu\_{global}$，且二阶差异也不明显，则线性路由器会退化到为所有领域产生类似的输出，导致：
$$\text{argmax}\_k \ell\_k(x) \approx \text{const}$$

即所有 token 都被路由到同一个专家，造成**路由坍缩**。

## 第六部分：协方差信息的必要性分析

### 6.1 什么情况下需要协方差信息？

**定理 6.1.1（协方差信息必要条件）**

协方差信息（二阶统计量）对于路由是**必要**的，当且仅当：

1. **均值不可分**：$\mu\_A \approx \mu\_B$（不同领域的均值相同或非常接近）
2. **二阶可分**：$\Sigma\_A \neq \Sigma\_B$（协方差矩阵存在差异）

即：
$$(\mu\_A - \mu\_B) \approx 0 \quad \text{但} \quad \Sigma\_A - \Sigma\_B \neq 0$$

**实际场景**：

在 LLM 中，以下场景可能需要协方差信息：

1. **语义相似但表达方式不同**：两个领域含义相近，但一个领域用词集中、方差小，另一个领域用词分散、方差大
2. **推理类型不同**：数学推理（低方差，结构化）vs 创意写作（高方差，多样化）
3. **代码 vs 自然语言**：代码 token 激活可能更集中在特定维度，自然语言则更分散

### 6.2 需要完整协方差还是对角线协方差？

**定理 6.2.1（协方差结构与路由能力）**

1. **如果领域差异仅在对角线元素**（各维度独立方差不同）：
   - Debiased QR（$W\_2 (x\_c \odot x\_c - \lambda)$）**足够**
   - 计算复杂度 $O(d)$
2. **如果领域差异在非对角线元素**（维度间存在相关性差异）：
   - Debiased QR **不足以**捕获这些差异
   - 需要完整二次型 $x^T Q x$ 或等效结构
   - 计算复杂度 $O(d^2)$

**实践建议**：

由于 $d\_{model}$ 通常较大（如 4096、5120 等），完整协方差路由的计算成本可能过高。经验上，如果领域差异主要体现在各维度的独立波动上，Debiased QR 是一个合理的近似。

### 6.3 如何构造能利用协方差信息的路由器

**方案一：完整二次型路由器**

$$\ell^{full\_quad}(x) = x\_c^T Q x\_c + w^T x\_c + b$$

其中 $Q \in \mathbb{R}^{d \times d}$ 为对称矩阵。

**优点**：能捕获所有协方差信息
**缺点**：$O(d^2)$ 参数和计算复杂度

**方案二：低秩近似二次路由器**

$$\ell^{lowrank}(x) = (U x\_c) \odot (U x\_c) + w^T x\_c + b$$

其中 $U \in \mathbb{R}^{r \times d}$，$r \ll d$。

这相当于对协方差矩阵做低秩分解：
$$Q \approx U^T U$$

**优点**：降低到 $O(rd)$ 计算复杂度
**缺点**：只能捕获前 $r$ 个主成分方向的协方差

**方案三：元素级二次路由器（Debiased QR）**

$$\ell^{element}(x) = W\_1 x\_c + W\_2 (x\_c \odot x\_c - \lambda)$$

**优点**：$O(d)$ 计算复杂度，可解释性强
**缺点**：只能捕获对角线协方差

## 第七部分：二阶去偏的理论解释

### 7.1 什么是去偏？为什么不去偏会坍缩？

**问题陈述**：

实验观察发现，如果不进行二阶去偏（即直接使用 $x\_c \odot x\_c$ 而不减 $\lambda$），会导致严重的负载不均衡和路由坍缩。为什么？

**直觉解释**：

考虑 $x\_c \odot x\_c$ 的期望：
$$\mathbb{E}\[x\_c \odot x\_c] = \lambda$$

如果我们直接使用 $x\_c \odot x\_c$ 作为特征，路由器会学习将高"能量"的 token 路由到某个专家。但**全局二阶均值 $\lambda$ 包含了所有领域的共同信息**，这与一阶去中心的逻辑类似——我们需要移除领域无关的共享信息。

**定理 7.1.1（二阶坍缩机制）**

设不做去偏的二次路由器为：
$$\ell^{no\_deb}(x) = w\_1^T x\_c + w\_2^T (x\_c \odot x\_c)$$

对领域 $d$ 的期望输出：
$$\mathbb{E}\[\ell^{no\_deb} | D=d] = w\_1^T \mu\_{c,d} + w\_2^T \mathbb{E}\[x\_c \odot x\_c | D=d]$$

其中 $\mathbb{E}\[x\_c \odot x\_c | D=d]$ 包含了：

1. **领域特定方差**：$\mathbb{E}\[x\_c \odot x\_c | D=d] - \lambda$（我们想要的）
2. **全局二阶基线**：$\lambda$（所有领域共享，不需要）

**问题**：如果 $\lambda$ 在所有 token 上都是主导的（因为它是对所有 token 的平均），那么 $w\_2^T \lambda$ 会产生一个**常数偏置**，使得路由器难以区分不同领域的二阶差异。

### 7.2 去偏如何解决坍缩问题？

**定理 7.2.1（去偏后的可区分性）**

去偏后的二阶特征：
$$q\_{deb} = x\_c \odot x\_c - \lambda$$

对领域 $d$ 的期望：
$$\mathbb{E}\[q\_{deb} | D=d] = \mathbb{E}\[x\_c \odot x\_c | D=d] - \lambda$$

这恰好是**领域特定的二阶异常**——移除了全局共享的二阶基线，保留了领域间的差异信息。

**定理 7.2.2（去偏实现均衡分发的机制）**

考虑两个领域 A 和 B：

- 如果领域 A 的各维度方差**高于**全局均值：$\mathbb{E}\[x\_c \odot x\_c | A] - \lambda > 0$
- 如果领域 B 的各维度方差**低于**全局均值：$\mathbb{E}\[x\_c \odot x\_c | B] - \lambda < 0$

通过学习合适的 $w\_2$，路由器可以将：

- 高方差领域 A 导向某些专家
- 低方差领域 B 导向另一些专家

**这实现了一种基于"波动强度"的均衡分发！**

### 7.3 去偏与一阶去中心的对应关系

**类比分析**：

| <br />    | 一阶（均值）                           | 二阶（元素级方差）                                |
| --------- | -------------------------------- | ---------------------------------------- |
| **原始特征**  | $x$                              | $x\_c \odot x\_c$                        |
| **全局统计量** | $\mu\_{global} = \mathbb{E}\[x]$ | $\lambda = \mathbb{E}\[x\_c \odot x\_c]$ |
| **共享信息**  | 所有领域的共同基线                        | 所有领域的共同二阶基线                              |
| **去偏操作**  | $x\_c = x - \mu\_{global}$       | $q\_{deb} = x\_c \odot x\_c - \lambda$   |
| **去偏后含义** | 偏离全局均值的方向                        | 偏离全局方差的程度                                |

**核心洞见**：去偏操作在二阶上的作用与去中心化在一阶上的作用完全对应——都是为了**移除领域无关的共享信息，保留领域间的差异信息**。

### 7.4 为什么不去偏会造成严重负载不均衡？

**机制分析**：

1. **未去偏时**：$w\_2^T (x\_c \odot x\_c)$ 包含常数项 $w\_2^T \lambda$
2. **这个常数项对所有领域相同**，但其幅度可能很大
3. **路由器学习时会"追逐"这个常数项**，倾向于将所有 token 导向少数专家以最大化/最小化这个常数偏置
4. **结果**：所有 token 都产生类似的二阶分数，路由器退化

**去偏后**：$w\_2^T (x\_c \odot x\_c - \lambda)$ 是**零中心化**的，路由器必须通过学习 $w\_2$ 来产生领域差异，而不能简单"追逐"常数项。

## 第八部分：综合结论与理论总结

### 8.1 一阶 vs 二阶分发的精确定义

| 分发类型     | 数学形式                               | 线性路由器                | 二次路由器                |
| -------- | ---------------------------------- | -------------------- | -------------------- |
| **一阶分发** | 基于 $\mu\_D = \mathbb{E}\[x\|D]$    | ✅ 能利用 ($w^T \mu\_D$) | ✅ 能利用 ($w^T \mu\_D$) |
| **二阶分发** | 基于 $\Sigma\_D = \text{Cov}\[x\|D]$ | ❌ 不能利用               | ⚠️ 仅对角线（Debiased QR） |

### 8.2 去中心化的理论必要性

**核心定理**：为使线性路由器能够区分不同领域，必须对激活值进行去中心化（减均值）操作。

**原因**：

1. 如果不去中心化，所有领域的 $\mu\_d$ 接近共同均值 $\mu\_{global}$
2. 线性路由器输出 $w^T \mu\_d + b \approx w^T \mu\_{global} + b$ 对所有领域相同
3. 去中心化后 $\mu\_{c,d} = \mu\_d - \mu\_{global}$，打破了这个对称性

### 8.3 为什么中心化后专家能均衡分发

当 $N\_A = N\_B$ 时：

- $\mu\_{c,B} = -\mu\_{c,A}$
- 领域 A 和 B 的去中心化均值**方向相反**
- 线性路由器通过学习 $w$，自然地将 A 导向专家 1、B 导向专家 2
- **这实现了均衡分发**

### 8.4 二次路由器的真实能力

Debiased QR 的二阶项 $x\_c \odot x\_c$ 只能捕获**每个维度的独立方差**，无法捕获**维度间的相关性**。

如果领域差异主要体现在：

- **每个维度的独立波动** → Debiased QR **有效**
- **维度间的协方差结构** → 需要完整二次型 $x^T Q x$

### 8.5 协方差信息的必要性判断

协方差信息是**必要**的，当且仅当：

- 不同领域的**均值相同或非常接近**（一阶无法区分）
- 但**协方差矩阵存在差异**（二阶可区分）

在实际 LLM 场景中，如果观察到：

- 一阶分发导致不均衡
- 且不同领域确实存在方差/波动差异

则应考虑使用二阶路由。

### 8.6 二阶去偏的必要性

**去偏是必要**的，因为：

1. 未去偏的 $x\_c \odot x\_c$ 包含全局二阶基线 $\lambda$，这是所有领域共享的无关信息
2. 不去偏会导致路由器"追逐"常数项，造成路由坍缩
3. 去偏后的 $q\_{deb} = x\_c \odot x\_c - \lambda$ 零中心化，使路由器能学习领域间差异
