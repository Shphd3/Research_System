## 0.4 两分钟口头复述骨架

> 我们研究的不是“随机投影能否创造语义结构”，而是“它何时能低成本保持原空间已经存在的可路由结构”。已有结果表明，分类功能可以集中在低维子空间，但这些方向不等于最大方差方向，而且单个协方差谱轴通常没有强 domain 判别性。本文首先区分稠密高斯随机投影和随机谱坐标抽样：前者不需要语义在谱上均匀，后者需要判别结构相对于谱基低相干。随后证明，只要原空间具有正距离间隔或正线性 Router 间隔，足够维数的随机降维可以保持它；反之，如果原空间在线性 Router 函数族内不可分，任何线性投影都不能把它变得可分。实验的关键不是再次画谱，而是先直接测完整高维表征是否可路由，再测随机降维能否保留该能力。若原空间可分且可压缩，进入低维 Router；若原空间不可分，研究重点必须转向训练如何形成可分表征。

# 摘要

混合专家模型的路由器需要把高维 token 表征映射到少量专家。已有表征分析给出三个相互关联但不能混同的现象：第一，完整候选更新的协方差谱可以很宽，因而统计意义上并不低秩；第二，对固定语义分类任务，少量监督方向可以保留大部分分类功能，因而任务功能可能低维；第三，这些判别方向并不等于最大方差方向，而且多数单独的协方差谱方向上，类间变化并未明显大于类内变化。上述现象尚不能回答：完整高维表征是否已具有可被低成本 Router 使用的组合判别结构。

本文形式化“低维语义均匀嵌入高维谱空间”这一会议直觉，并区分两种随机降维。对于稠密高斯随机投影，保持有限样本距离或线性分类间隔并不要求判别信息在原谱坐标上均匀；对于随机选择谱坐标，必须要求相关差分向量或判别子空间相对于谱基低相干，即能量没有集中在极少数谱方向。本文证明：（1）高斯随机投影以对数级目标维数保持有限样本两两距离；（2）若类别原本具有正类内—类间距离间隔，则投影后仍保持可分性；（3）若数据位于若干低维仿射子空间，则所需维数主要依赖单类内在维数和类别数，而非原始维数；（4）在谱低相干条件下，随机谱坐标抽样也能保持相关距离；（5）若原空间已有正的多类线性 Router 间隔，则投影后可保持全部路由决策；（6）若原空间在线性 Router 函数族内不可分，则任何线性投影后接线性 Router 都不能创造可分性。

在理论之后，本文给出一套可复现的 Qwen3 表征审计协议。协议从数据构建、表征提取、候选更新定义、完整空间可路由性、谱分散度、随机降维维数扫描、合成对照和统计检验逐项规定。最终实验只允许产生两类决策：若完整空间具有稳定正间隔且随机低维表示能够保留该能力，则随机降维是已有路由结构的低成本保持器；若完整空间本身不具备稳定线性可分性，则继续寻找线性低维基没有理论依据，应转向训练过程如何形成可分表征。

# 1. 问题、动机与研究目的

## 1.1 Router 问题

设 Transformer 某一层为每个 token 产生表征

\[
x\in\mathbb R^d.
\]

一个具有 \(K\) 个候选专家的线性路由器计算

\[
s_k(x)=w_k^\top x+b_k,\qquad k=1,\ldots,K,
\]

并选择

\[
g(x)=\arg\max_{k\in[K]}s_k(x).
\]

当 \(d\) 很大时，直接使用完整表征进行路由会增加参数、计算和通信成本。自然问题是：能否先将表征压缩到

\[
z=Rx\in\mathbb R^m,\qquad m\ll d,
\]

再在 \(z\) 上完成路由。

## 1.2 已有观察及其边界

当前研究报告支持以下观察：

1. **完整候选更新可以统计高秩。** 其协方差谱下降较慢，需要大量主方向覆盖大部分方差。
2. **固定分类任务可以功能低维。** 一个可学习的低秩输入子空间能在较小秩下恢复大部分分类性能。
3. **多种语义共同使用时需要更宽的联合空间。** 单个领域内部的判别空间较小，不同领域的局部判别子空间重叠较低；共享投影需要覆盖多个不同局部空间。
4. **判别方向不等于最大方差方向。** 监督判别子空间更多落在全局协方差谱的中部，而不是最大方差头部。
5. **多数单谱轴不具备强判别性。** 在固定协方差特征向量上，绝大多数方向的类内变化不小于类间变化；少数较强方向主要位于中后部。

这些观察只说明：

\[
\text{协方差谱轴与 domain 判别结构没有自然对齐}.
\]

它们**不能单独推出**：

\[
\text{完整高维空间不存在多方向组合形成的线性分类器}.
\]

因此，完整空间是否可路由，必须由全空间线性 Router、距离型 Router 和留出集间隔直接检验。

## 1.3 唯一研究目的

本文的主目的为：

> **刻画一个已经具有正 domain 可分间隔的、任务功能低维的语义结构，在高维谱坐标中广泛分布时，随机降维在多小的目标维数下仍能保持其距离结构和线性 Router 决策；并用严格实验判断当前 Qwen3 表征是否满足这些前提。**

这一定义包含两个互补分支：

### 正分支：保持问题

若原空间已经存在可路由结构，证明随机降维可以低成本保持：

\[
\text{原空间可分}
\Longrightarrow
\text{低维空间仍可分}.
\]

### 负分支：结构生成问题

若原空间在线性 Router 函数族内不可分，证明线性随机降维不能创造结构：

\[
\text{原空间线性不可分}
\Longrightarrow
\text{任意线性降维后仍线性不可分}.
\]

## 1.4 本文不证明什么

本文不预设并不证明以下命题：

1. 低秩自动意味着可分；
2. 谱上均匀分布自动意味着可分；
3. 随机投影会创造新的 domain 语义；
4. 多数单谱轴判别性弱就意味着完整高维空间不可分；
5. 局部敏感哈希本身能够学习专家语义；
6. 当前 Qwen3 表征一定不适合 Router；
7. 距离保持自动带来语言模型损失下降或专家效用提升。

# 2. 形式化定义

## 2.1 模型中的分析表征

固定一个 decoder-only Transformer 和某个 block \(\ell\)。对样本 \(i\) 的指定 token，定义：

- \(h_{\ell,i}\in\mathbb R^d\)：进入本层 Attention 前的 residual stream；
- \(a_{\ell,i}\in\mathbb R^d\)：本层 Attention 模块写入 residual stream 的向量；
- \(N_\ell\)：模型实际使用的 post-Attention 归一化算子，例如 RMSNorm。

定义 Attention 写入前后的归一化状态：

\[
x_{\ell,i}=N_\ell(h_{\ell,i}),
\]

\[
z_{\ell,i}=N_\ell(h_{\ell,i}+a_{\ell,i}).
\]

定义精确归一化更新：

\[
u_{\ell,i}=z_{\ell,i}-x_{\ell,i}.
\]

为了去除旧状态能够线性预测的部分，只在训练集上拟合多输出岭回归：

\[
(B_\ell,b_\ell)
=
\arg\min_{B,b}
\sum_{i\in\mathcal I_{\mathrm{train}}}
\left\|u_{\ell,i}-B^\top x_{\ell,i}-b\right\|_2^2
+
\lambda\|B\|_F^2.
\]

定义候选非线性可预测更新：

\[
r_{\ell,i}
=
 u_{\ell,i}-B_\ell^\top x_{\ell,i}-b_\ell.
\]

后文将 \(r_{\ell,i}\) 简写为 \(r_i\)。必须注意：

> \(r_i\) 只是“不能由旧状态通过当前线性预测器解释的更新”，并不等于已经证明的“新语义信息”。

## 2.2 语义类别与离线路由标签

设每个样本具有一个仅用于分析的语义标签

\[
y_i\in[K]=\{1,\ldots,K\}.
\]

标签不输入模型，不参与预训练，也不出现在 prompt 中。它只用于：

- 计算类内与类间结构；
- 拟合离线线性 Router；
- 判断低维表示是否保留原空间的路由能力。

## 2.3 两种“低维”

### 2.3.1 几何低维

第 \(k\) 类的支持集位于一个低维仿射子空间：

\[
\mathcal M_k\subseteq a_k+S_k,
\qquad
\dim(S_k)\le r\ll d.
\]

这是关于数据几何本身的假设。

### 2.3.2 功能低维

对固定分类任务，若存在正交投影

\[
P\in\mathbb R^{d\times r},
\qquad P^\top P=I_r,
\]

使低维表示 \(P^\top r_i\) 的留出集分类性能接近完整表示，则称该任务功能低维。

定义容许性能损失 \(\eta>0\)，最小功能维数为

\[
r^*(\eta)
=
\min\left\{
 r:
 \exists P,
 \mathrm{Risk}(P^\top r)
 \le
 \mathrm{Risk}(r)+\eta
\right\}.
\]

功能低维不意味着 \(\operatorname{Cov}(r)\) 低秩。完整表示可以统计高秩，但完成一个具体判别任务只需少量方向。

## 2.4 谱空间中的“均匀分布”

在训练集上中心化候选更新：

\[
\widetilde r_i=r_i-\bar r,
\qquad
\bar r=\frac1n\sum_i r_i.
\]

定义协方差矩阵

\[
\Sigma
=
\frac1{n-1}
\sum_i \widetilde r_i\widetilde r_i^\top
=
U\Lambda U^\top,
\]

其中

\[
U=(u_1,\ldots,u_d)
\]

是按特征值从大到小排列的全局谱基。

设某个 \(r\) 维判别子空间的正交基为

\[
P\in\mathbb R^{d\times r}.
\]

定义该子空间在第 \(j\) 个谱方向上的投影能量：

\[
\ell_j
=
\|P^\top u_j\|_2^2.
\]

因为 \(P\) 与 \(U\) 都正交，

\[
\sum_{j=1}^d\ell_j=r.
\]

定义子空间相干度：

\[
\mu(P;U)
=
\frac d r
\max_{j\in[d]}\ell_j.
\]

其最小可能值为 \(1\)。

- \(\mu\approx1\)：判别子空间相对于谱基近似均匀；
- \(\mu\gg1\)：判别子空间集中在少数谱方向。

再定义归一化谱能量

\[
p_j=\frac{\ell_j}{r},
\qquad
\sum_jp_j=1,
\]

及归一化谱熵

\[
H(P;U)
=
-\frac{\sum_jp_j\log p_j}{\log d}.
\]

- \(H\approx1\)：谱分布平坦；
- \(H\ll1\)：谱分布集中。

因此，本文中的“低维语义均匀分布在高维谱空间”正式指：

\[
r\ll d,
\qquad
\mu(P;U)\text{ 较小},
\qquad
H(P;U)\text{ 较大}.
\]

它不是指样本在整个高维空间中均匀采样，也不是指所有协方差特征值相同。

## 2.5 两种随机降维

### 2.5.1 稠密高斯随机投影

令

\[
R\in\mathbb R^{m\times d},
\qquad
R_{ab}\overset{\mathrm{i.i.d.}}{\sim}\mathcal N(0,1/m).
\]

低维表示为

\[
\phi_G(x)=Rx.
\]

该映射混合全部原坐标。它保持固定有限点集的欧氏结构时，不要求信息在谱坐标中均匀。

### 2.5.2 随机谱坐标抽样

先将向量表示到全局谱基：

\[
q=U^\top x.
\]

独立均匀采样谱索引

\[
J_1,\ldots,J_m\sim\operatorname{Unif}\{1,\ldots,d\},
\]

并定义

\[
\phi_C(x)
=
\sqrt{\frac d m}
\left(q_{J_1},\ldots,q_{J_m}\right)^\top.
\]

该方法只观察少量谱坐标。若关键信息集中在极少数谱方向，抽样可能完全漏掉信号；因此它需要低相干或“谱上均匀”假设。

## 2.6 两种可分性

### 2.6.1 距离簇间隔

定义最大类内距离

\[
D_{\mathrm{in}}
=
\max_{y_i=y_j}\|r_i-r_j\|_2,
\]

以及最小类间距离

\[
D_{\mathrm{out}}
=
\min_{y_i\ne y_j}\|r_i-r_j\|_2.
\]

若

\[
D_{\mathrm{out}}>D_{\mathrm{in}},
\]

则所有同类样本对都比所有异类样本对更近。该条件很强，但适合分析距离型路由。

### 2.6.2 多类线性 Router 间隔

给定权重与偏置

\[
\{(w_k,b_k)\}_{k=1}^K,
\]

定义样本 \(i\) 相对错误类别 \(k\) 的 logit 间隔：

\[
\rho_{ik}
=
(w_{y_i}-w_k)^\top r_i
+(b_{y_i}-b_k).
\]

定义最小训练样本间隔

\[
\rho
=
\min_i\min_{k\ne y_i}\rho_{ik}.
\]

若 \(\rho>0\)，则该线性 Router 在全部样本上分类正确。

距离簇间隔与线性间隔不是同一个条件：距离簇间隔失败时，数据仍可能通过多个方向的线性组合被正确分类。

## 2.7 局部敏感哈希

局部敏感哈希（locality-sensitive hashing，LSH）是一类随机哈希方法。其基本要求是：距离近的点以更高概率产生相同哈希码，距离远的点以更低概率碰撞。LSH 通常服务于近似最近邻检索，输出离散桶或比特码；它不是本文的主证明对象，也不自动学习专家语义。

本文只把 LSH 视为一种可能的后续工程用途：若低维随机映射已经保持距离结构，就可以用哈希快速检索少量候选专家，再在候选集中计算精确路由分数。

# 3. 理论结果

## 3.1 引理一：高斯随机投影保持固定向量长度

### 引理 1

令

\[
R_{ab}\overset{\mathrm{i.i.d.}}{\sim}\mathcal N(0,1/m).
\]

对任意固定非零向量 \(v\in\mathbb R^d\) 和任意 \(0<\varepsilon<1\)，有

\[
\Pr\left[
\left|
\|Rv\|_2^2-\|v\|_2^2
\right|
\ge
\varepsilon\|v\|_2^2
\right]
\le
2\exp\left(-\frac{m\varepsilon^2}{12}\right).
\]

### 证明

矩阵 \(R\) 的每一行与 \(v\) 的内积独立服从

\[
\mathcal N\left(0,\frac{\|v\|_2^2}{m}\right).
\]

因此

\[
\frac{m\|Rv\|_2^2}{\|v\|_2^2}
\sim
\chi_m^2.
\]

对卡方变量 \(X\sim\chi_m^2\)，由矩母函数

\[
\mathbb E[e^{tX}]=(1-2t)^{-m/2},\qquad t<1/2,
\]

使用 Chernoff 方法可得，对 \(0<\varepsilon<1\)，

\[
\Pr\left[
\left|\frac Xm-1\right|\ge\varepsilon
\right]
\le
2\exp\left[-m\left(\frac{\varepsilon^2}{4}-\frac{\varepsilon^3}{6}\right)\right].
\]

因为

\[
\frac{\varepsilon^2}{4}-\frac{\varepsilon^3}{6}
\ge
\frac{\varepsilon^2}{12},
\qquad 0<\varepsilon<1,
\]

故结论成立。证毕。

## 3.2 定理一：有限样本两两距离保持

### 定理 1

给定有限点集

\[
\mathcal X=\{x_1,\ldots,x_n\}\subset\mathbb R^d.
\]

令 \(R\) 为高斯随机投影。若

\[
m
\ge
\frac{12}{\varepsilon^2}
\log\frac{n(n-1)}{\delta},
\]

则以至少 \(1-\delta\) 的概率，对所有 \(i\ne j\) 同时有

\[
(1-\varepsilon)\|x_i-x_j\|_2^2
\le
\|R(x_i-x_j)\|_2^2
\le
(1+\varepsilon)\|x_i-x_j\|_2^2.
\]

### 证明

非零差向量的数量至多为

\[
M=\frac{n(n-1)}2.
\]

对每个固定差向量，由引理 1，失败概率至多为

\[
2\exp\left(-\frac{m\varepsilon^2}{12}\right).
\]

对全部差向量使用并合界，总失败概率至多为

\[
2M\exp\left(-\frac{m\varepsilon^2}{12}\right)
=
n(n-1)\exp\left(-\frac{m\varepsilon^2}{12}\right).
\]

代入维数条件后，该概率不超过 \(\delta\)。证毕。

## 3.3 推论一：类内—类间距离间隔保持

### 推论 1

假设原空间满足

\[
D_{\mathrm{out}}>D_{\mathrm{in}}.
\]

若随机投影对全部样本对满足定理 1，并且

\[
(1+\varepsilon)D_{\mathrm{in}}^2
<
(1-\varepsilon)D_{\mathrm{out}}^2,
\]

则投影后仍有

\[
D'_{\mathrm{out}}>D'_{\mathrm{in}}.
\]

等价地，只要

\[
\varepsilon
<
\gamma_{\mathrm{dist}}
:=
\frac{D_{\mathrm{out}}^2-D_{\mathrm{in}}^2}
{D_{\mathrm{out}}^2+D_{\mathrm{in}}^2},
\]

距离簇间隔就会保持。

### 证明

由定理 1，

\[
(D'_{\mathrm{in}})^2
\le
(1+\varepsilon)D_{\mathrm{in}}^2,
\]

且

\[
(D'_{\mathrm{out}})^2
\ge
(1-\varepsilon)D_{\mathrm{out}}^2.
\]

给定条件保证后者严格大于前者。证毕。

### 含义

随机投影只是在保持原空间已有的距离间隔。若原空间满足

\[
D_{\mathrm{out}}\le D_{\mathrm{in}},
\]

该推论不提供任何可分性保证。

## 3.4 定理二：低维仿射子空间并集的统一嵌入

### 定理 2

设

\[
\mathcal X
\subseteq
\bigcup_{k=1}^K(a_k+S_k),
\qquad
\dim(S_k)\le r.
\]

对每一对类别 \((k,\ell)\)，定义

\[
L_{k\ell}
=
\operatorname{span}
\left(a_k-a_\ell,S_k,S_\ell\right).
\]

则

\[
\dim(L_{k\ell})\le 2r+1.
\]

若

\[
m
\ge
\frac{48}{\varepsilon^2}
\left[
(2r+1)\log 9
+
\log\frac{2K^2}{\delta}
\right],
\]

则以至少 \(1-\delta\) 的概率，对任意 \(x,y\in\mathcal X\) 同时有

\[
(1-\varepsilon)\|x-y\|_2^2
\le
\|R(x-y)\|_2^2
\le
(1+\varepsilon)\|x-y\|_2^2.
\]

### 证明

先考虑一个固定的 \(q\) 维线性子空间 \(L\)，其中 \(q\le2r+1\)。令 \(\mathbb S(L)\) 表示 \(L\) 中的单位球面。存在半径为 \(1/4\) 的有限网 \(\mathcal N\subset\mathbb S(L)\)，满足

\[
|\mathcal N|\le9^q.
\]

对每个 \(u\in\mathcal N\)，由引理 1，在误差参数 \(\varepsilon/2\) 下，

\[
\Pr\left[
\left|\|Ru\|_2^2-1\right|>\frac\varepsilon2
\right]
\le
2\exp\left(-\frac{m\varepsilon^2}{48}\right).
\]

对网中全部点使用并合界，失败概率至多为

\[
2\cdot9^q
\exp\left(-\frac{m\varepsilon^2}{48}\right).
\]

定义限制在 \(L\) 上的对称算子

\[
A=R^\top R-I.
\]

若对全部 \(u\in\mathcal N\) 有

\[
|u^\top Au|\le\frac\varepsilon2,
\]

则对任意单位向量 \(x\in L\)，取 \(u\in\mathcal N\) 使 \(\|x-u\|_2\le1/4\)。于是

\[
|x^\top Ax|
\le
|u^\top Au|
+|x^\top Ax-u^\top Au|.
\]

又有

\[
|x^\top Ax-u^\top Au|
\le
2\|A\|_{\mathrm{op}}\|x-u\|_2
\le
\frac12\|A\|_{\mathrm{op}}.
\]

因此

\[
\|A\|_{\mathrm{op}}
\le
\frac\varepsilon2+\frac12\|A\|_{\mathrm{op}},
\]

从而

\[
\|A\|_{\mathrm{op}}\le\varepsilon.
\]

所以 \(R\) 在固定子空间 \(L\) 上为 \(\varepsilon\)-近似等距映射。

现在对全部至多 \(K^2\) 个子空间 \(L_{k\ell}\) 使用并合界。给定定理中的维数条件后，总失败概率不超过 \(\delta\)。最后，若

\[
x\in a_k+S_k,
\qquad y\in a_\ell+S_\ell,
\]

则

\[
x-y\in L_{k\ell},
\]

故全部类内和类间差向量都被统一保持。证毕。

### 含义

当每类语义位于低维仿射子空间时，目标维数主要依赖单类内在维数 \(r\)、类别数 \(K\)、允许失真 \(\varepsilon\) 和失败概率 \(\delta\)，而不直接依赖原始维数 \(d\)。但该定理仍只保持已有结构，不保证不同类别本来就分开。

## 3.5 定理三：谱上均匀分布时，随机谱坐标抽样保持距离

稠密高斯随机投影不需要谱均匀性。会议中“低维语义均匀地藏在高维谱空间”这一假设，真正对应的是随机选择谱坐标。

### 定义：差分向量的谱相干度

对非零向量 \(v\)，令

\[
q=U^\top v.
\]

定义

\[
\mu(v;U)
=
d\frac{\|q\|_\infty^2}{\|v\|_2^2}.
\]

必有

\[
1\le\mu(v;U)\le d.
\]

- \(\mu(v;U)\approx1\)：该向量能量接近均匀分布在全部谱方向；
- \(\mu(v;U)\approx d\)：能量几乎集中在一个谱方向。

### 定理 3

给定有限非零向量集合

\[
\mathcal V=\{v_1,\ldots,v_M\},
\]

并假设

\[
\mu(v;U)\le\mu
\qquad
\forall v\in\mathcal V.
\]

使用带放回的随机谱坐标抽样 \(\phi_C\)。若

\[
m
\ge
\frac{8\mu}{3\varepsilon^2}
\log\frac{2M}{\delta},
\qquad 0<\varepsilon<1,
\]

则以至少 \(1-\delta\) 的概率，对全部 \(v\in\mathcal V\) 同时有

\[
(1-\varepsilon)\|v\|_2^2
\le
\|\phi_C(v)\|_2^2
\le
(1+\varepsilon)\|v\|_2^2.
\]

### 证明

固定 \(v\in\mathcal V\)，令 \(q=U^\top v\)。对每次随机索引 \(J_t\)，定义

\[
Y_t
=
d\frac{q_{J_t}^2}{\|v\|_2^2}.
\]

由于 \(J_t\) 均匀分布，

\[
\mathbb E[Y_t]=1.
\]

由相干度假设，

\[
0\le Y_t\le\mu,
\]

且

\[
\operatorname{Var}(Y_t)
\le
\mathbb E[Y_t^2]
\le
\mu\mathbb E[Y_t]
=
\mu.
\]

又因为

\[
\frac{\|\phi_C(v)\|_2^2}{\|v\|_2^2}
=
\frac1m\sum_{t=1}^mY_t,
\]

对独立有界随机变量使用 Bernstein 不等式，得到

\[
\Pr\left[
\left|
\frac1m\sum_{t=1}^mY_t-1
\right|\ge\varepsilon
\right]
\le
2\exp\left(
-\frac{m\varepsilon^2}{2\mu+2\mu\varepsilon/3}
\right).
\]

当 \(0<\varepsilon<1\) 时，分母不超过 \(8\mu/3\)，故

\[
\Pr\left[
\left|
\frac{\|\phi_C(v)\|_2^2}{\|v\|_2^2}-1
\right|\ge\varepsilon
\right]
\le
2\exp\left(-\frac{3m\varepsilon^2}{8\mu}\right).
\]

对全部 \(M\) 个向量使用并合界，即得结论。证毕。

### 推论：低维且谱低相干的子空间

若所有相关向量都位于 \(r\) 维子空间 \(S\)，定义子空间相干度

\[
\mu(S;U)
=
\frac d r
\max_j\|P_Su_j\|_2^2,
\]

则对任意 \(v\in S\)，

\[
|u_j^\top v|^2
\le
\|P_Su_j\|_2^2\|v\|_2^2
\le
\frac{\mu(S;U)r}{d}\|v\|_2^2.
\]

所以

\[
\mu(v;U)\le\mu(S;U)r.
\]

随机谱坐标抽样所需维数因此满足

\[
m
=
O\left(
\mu(S;U)r\varepsilon^{-2}
\log\frac{M}{\delta}
\right).
\]

这一定理准确表达了：低维本身不够；只有当低维结构相对于谱基不集中时，随机抽取少量谱方向才可靠。

## 3.6 定理四：高斯随机投影保持多类线性 Router 决策

### 定理 4

给定有限样本

\[
\{(r_i,y_i)\}_{i=1}^n,
\qquad y_i\in[K],
\]

以及原空间多类线性 Router

\[
s_k(r)=w_k^\top r+b_k.
\]

假设最小 logit 间隔为

\[
\rho
=
\min_i\min_{k\ne y_i}
\left[
(w_{y_i}-w_k)^\top r_i+b_{y_i}-b_k
\right]
>0.
\]

定义

\[
B_x=\max_i\|r_i\|_2,
\]

\[
B_w=
\max_i\max_{k\ne y_i}
\|w_{y_i}-w_k\|_2,
\]

以及

\[
\eta
=
\min\left\{
\frac12,
\frac{\rho}{2B_xB_w}
\right\}.
\]

若

\[
m
\ge
\frac{12}{\eta^2}
\log\frac{4n(K-1)}{\delta},
\]

则以至少 \(1-\delta\) 的概率，投影后的权重

\[
\widetilde w_k=Rw_k
\]

和原偏置 \(b_k\) 对全部样本保持原 argmax 决策，并且投影后的最小间隔至少为 \(\rho/2\)。

### 证明

对每个样本 \(i\) 和错误类别 \(k\ne y_i\)，定义

\[
v_{ik}=w_{y_i}-w_k,
\]

\[
a_i=\frac{r_i}{B_x},
\qquad
c_{ik}=\frac{v_{ik}}{B_w}.
\]

考虑有限向量集合

\[
\mathcal Q
=
\left\{
 a_i+c_{ik},
 a_i-c_{ik}
 :
 i\in[n],\ k\ne y_i
\right\}.
\]

其大小至多为 \(2n(K-1)\)。由引理 1 和并合界，在给定维数条件下，以至少 \(1-\delta\) 的概率，所有非零 \(q\in\mathcal Q\) 都满足

\[
\left|
\|Rq\|_2^2-\|q\|_2^2
\right|
\le
\eta\|q\|_2^2.
\]

零向量显然满足该关系。由极化恒等式，

\[
4\langle Ra_i,Rc_{ik}\rangle
=
\|R(a_i+c_{ik})\|_2^2
-
\|R(a_i-c_{ik})\|_2^2,
\]

并且

\[
4\langle a_i,c_{ik}\rangle
=
\|a_i+c_{ik}\|_2^2
-
\|a_i-c_{ik}\|_2^2.
\]

因此

\[
\begin{aligned}
4\left|
\langle Ra_i,Rc_{ik}\rangle
-
\langle a_i,c_{ik}\rangle
\right|
&\le
\eta\|a_i+c_{ik}\|_2^2
+
\eta\|a_i-c_{ik}\|_2^2\\
&=
2\eta\left(\|a_i\|_2^2+\|c_{ik}\|_2^2\right)\\
&\le4\eta.
\end{aligned}
\]

故

\[
\left|
\langle Rr_i,Rv_{ik}\rangle
-
\langle r_i,v_{ik}\rangle
\right|
\le
\eta B_xB_w.
\]

投影后的正确类别与类别 \(k\) 的 logit 差满足

\[
\begin{aligned}
&(Rw_{y_i}-Rw_k)^\top Rr_i
+(b_{y_i}-b_k)\\
&\ge
\rho-
\eta B_xB_w\\
&\ge
\frac\rho2.
\end{aligned}
\]

该不等式对所有错误类别同时成立，所以投影后的 argmax 决策完全保持。证毕。

### 含义

该定理证明的是：若完整空间已经存在具有正间隔的线性 Router，则随机投影后存在一个对应的低维线性 Router，并保持有限样本决策。它不保证低维 Router 从随机初始化一定能被优化找到，也不把有限样本结论自动推广到任意新分布。

---

## 3.7 定理五：线性投影不能创造线性可分性

### 定理 5

设标签映射不能由任何原空间多类线性 Router

\[
r\mapsto Wr+b
\]

正确实现。则对任意线性映射

\[
A\in\mathbb R^{m\times d},
\]

也不存在投影空间线性 Router

\[
z\mapsto W'z+b',
\qquad z=Ar,
\]

能够正确实现相同标签。

### 证明

反设存在 \(A,W',b'\)，使投影后的线性 Router 正确分类全部样本。则复合映射为

\[
W'(Ar)+b'=(W'A)r+b'.
\]

该复合映射本身就是原空间上的多类线性 Router，与假设矛盾。证毕。

### 含义与边界

该定理说明，更换正交基、使用非正交线性方向、线性降维或线性升维后接线性 Gate，都不能创造线性可分性。它不排除非线性分类器、核方法、重新训练表征生成网络，也不排除线性投影改善优化条件数或正则化。

---

## 3.8 理论结论的逻辑图

```text
低秩
  └─ 不保证可分

谱上均匀
  └─ 不保证可分

原空间正距离间隔
  └─ 高斯随机投影可保持

原空间正线性 Router 间隔
  └─ 高斯随机投影可保持决策

低维 + 谱低相干
  └─ 随机谱坐标抽样可保持

原空间线性不可分
  └─ 任意线性投影后仍线性不可分
```

最重要的区分是：

\[
\boxed{
\text{随机降维是结构保持器，不是结构生成器。}
}
\]

# 4. 实验协议

## 4.1 实验问题与可证伪假设

### 问题一：分类功能是否低维

**假设 H1**：存在 \(r\ll d\) 的监督输入子空间，使其在未见数据上保留完整表征至少 90% 的机会校正分类性能。

### 问题二：判别子空间是否谱上分散

**假设 H2**：监督判别子空间相对于全局协方差谱基具有较低相干度和较高谱熵，不集中在连续 PCA 头部。

### 问题三：完整高维表征是否本来可路由

**假设 H3**：完整高维候选更新在留出数据上存在稳定的多类线性 Router 准确率和正 margin。

### 问题四：随机降维是否保持已有路由结构

**假设 H4**：若 H3 成立，则在 \(m\ll d\) 时，稠密高斯随机投影能够保持大部分距离结构、Router 决策和分类性能。

### 问题五：谱均匀性是否决定随机谱坐标抽样

**假设 H5**：随机谱坐标抽样的稳定性随判别子空间相干度增大而下降；稠密高斯随机投影对这一相干度不敏感。

### 负分支

若 H3 不成立，则根据定理 5：

> 不应继续把“寻找另一组线性低维基”作为主路线，而应转向训练如何产生可分表征。

## 4.4 实验一：复现单谱方向的类内—类间结构

### 目的

验证以下现象是否可复现：

- 类内和类间绝对变化都随协方差特征值减小而下降；
- 大多数单谱轴的相对判别性较弱；
- 少量较强方向位于中后部，而非最大方差头部。

### 方法

在训练集上计算

\[
\Sigma=U\Lambda U^\top.
\]

对测试集投影：

\[
q_{i,j}=u_j^\top(r_i-\bar r).
\]

对第 \(j\) 个谱方向，定义全局均值 \(\mu_j\)、类别均值 \(\mu_{c,j}\)，类间散度

\[
B_j
=
\sum_{c=1}^K n_c(\mu_{c,j}-\mu_j)^2,
\]

以及类内散度

\[
W_j
=
\sum_{c=1}^K
\sum_{i:y_i=c}
(q_{i,j}-\mu_{c,j})^2.
\]

定义单轴判别比

\[
F_j=\frac{B_j}{W_j+10^{-12}}.
\]

### 输出

1. \(B_j,W_j,F_j\) 随归一化谱排名的曲线；
2. 每个 5% 谱段中 \(F_j>1\) 的比例；
3. \(F_j\) 最大的 20 个方向；
4. 每个方向投影最大和最小的各 50 个样本，进行盲法语义审查；
5. 1,000 次样本 bootstrap 的 95% 置信区间。

### 结论边界

即使绝大多数 \(F_j<1\)，也只能说明单独谱轴缺少强判别性，不能宣布完整空间线性不可分。

## 4.5 实验二：功能低维与谱分散度

### 4.5.1 完整空间分类基线

在训练集拟合带 \(L_2\) 正则的多类逻辑回归：

\[
\min_{W,b}
\frac1n\sum_i
\operatorname{CE}(W^\top r_i+b,y_i)
+
\lambda\|W\|_F^2.
\]

开发集选择 \(\lambda\)，测试集只评估一次。

### 4.5.2 监督低秩线性 Router

对

\[
r\in\{1,2,4,8,16,32,64,128,256,512\}
\]

学习

\[
P_r\in\mathbb R^{d\times r},
\qquad P_r^\top P_r=I_r,
\]

以及低维权重 \(A_r\in\mathbb R^{r\times K}\)：

\[
\min_{P_r,A_r,b}
\frac1n\sum_i
\operatorname{CE}(A_r^\top P_r^\top r_i+b,y_i)
+
\lambda\|A_r\|_F^2.
\]

实现时令自由矩阵 \(Q\) 每次前向通过 QR 分解得到 \(P_r\)，避免正交约束漂移。每个秩运行 5 个随机种子，开发集早停。

### 4.5.3 对照子空间

同一秩下比较：

1. PCA 头部方向；
2. PCA 中部连续谱段；
3. PCA 尾部方向；
4. Haar 随机正交子空间；
5. 高斯随机投影；
6. 随机谱坐标抽样；
7. 监督低秩子空间。

所有低维表示均重新训练相同形式的逻辑回归，避免分类器容量不同。

### 4.5.4 功能维数

若完整空间准确率 \(A_{\mathrm{full}}>1/K\)，定义机会校正准确率：

\[
A^*(r)
=
\frac{A(r)-1/K}{A_{\mathrm{full}}-1/K}.
\]

定义 90% 功能维数：

\[
r_{90}
=
\min\{r:A^*(r)\ge0.9\}.
\]

### 4.5.5 谱分散度

取 \(r_{90}\) 对应的监督子空间 \(P_{r_{90}}\)，计算

\[
\ell_j=\|P_{r_{90}}^\top u_j\|_2^2,
\]

\[
\mu(P_{r_{90}};U),
\qquad
H(P_{r_{90}};U).
\]

再生成 1,000 个同秩 Haar 随机子空间，得到相干度和谱熵的零分布。报告：

- 实际子空间相对 Haar 基线的 z-score；
- 前 1%、5%、10%、25% 谱方向覆盖的判别子空间能量；
- 八个领域局部判别子空间的两两主角度与投影重叠；
- 八个局部子空间并集的维数增长。

### 判定

- 若 \(r_{90}\ll d\)，支持功能低维；
- 若 \(\mu\) 接近 Haar 基线且 \(H\) 高，支持谱上近似均匀；
- 若只有“方向不连续”但 \(\mu\) 很大，则只能称为宽谱或非连续分布，不能称为均匀。

## 4.6 实验三：完整高维表征是否可路由

这是整个协议中最关键的经验门槛。

### 4.6.1 全空间线性 Router

使用实验二的完整空间多类逻辑回归，报告：

- 测试 accuracy；
- macro-F1；
- 同模板测试与新模板测试的差值；
- 五个训练随机种子的均值和标准差。

### 4.6.2 归一化 logit margin

对每个测试样本，定义

\[
\widehat\rho_i
=
\min_{k\ne y_i}
\frac{
(w_{y_i}-w_k)^\top r_i+b_{y_i}-b_k
}{
\|w_{y_i}-w_k\|_2\|r_i\|_2+10^{-12}
}.
\]

报告：

- 中位数；
- 5%、25%、75% 分位数；
- \(\widehat\rho_i>0\) 的样本比例；
- 新模板测试集上的相同统计量。

### 4.6.3 距离型 Router

在训练集计算类别中心

\[
\mu_c
=
\frac1{n_c}\sum_{i:y_i=c}r_i.
\]

测试时使用最近类中心：

\[
\widehat y_i
=
\arg\min_c\|r_i-\mu_c\|_2.
\]

同时报告：

- 最近类中心准确率；
- 类内与类间距离完整分布；
- 稳健距离间隔

  \[
  Q_{0.05}(D_{\mathrm{out}})
  -
  Q_{0.95}(D_{\mathrm{in}}).
  \]

最大类内与最小类间对异常值过于敏感，因此只用于对应理论，不作为唯一经验指标。

### 4.6.4 最优线性组合方向

计算类间和类内散度矩阵：

\[
S_B
=
\sum_c n_c(\mu_c-\mu)(\mu_c-\mu)^\top,
\]

\[
S_W
=
\sum_c\sum_{i:y_i=c}
(r_i-\mu_c)(r_i-\mu_c)^\top.
\]

求正则化广义特征值问题：

\[
S_Bv
=
\lambda(S_W+\tau I)v.
\]

开发集选择 \(\tau\)。报告前 1、2、4、8、16 个广义特征方向的留出集分类性能。该步骤直接检验：多个单谱轴都弱时，它们的线性组合是否仍可形成强判别方向。

### 路由门槛

只有同时满足以下条件，才进入“随机降维保持已有 Router”的正分支：

1. 完整空间线性 Router 在两个测试集上均显著高于机会水平；
2. 新模板测试性能没有发生灾难性下降；
3. 大多数正确样本具有正归一化 margin；
4. 结果在不同训练种子和 bootstrap 中稳定。

## 4.7 实验四：随机降维维数扫描

### 4.7.1 目标维数

\[
m\in\{8,16,32,64,128,256,512,1024\}.
\]

对每个 \(m\) 和每种随机映射运行 30 个独立随机种子。

### 4.7.2 映射方法

1. 稠密高斯随机投影；
2. 随机符号投影，元素取 \(\pm1/\sqrt m\)；
3. 随机谱坐标抽样；
4. PCA 头部；
5. 与监督子空间能量峰值匹配的 PCA 中部谱段；
6. 监督低秩子空间，作为性能上界而非无标签方案。

### 4.7.3 理论对齐评估：冻结原空间 Router

先在完整训练表征上学习 \(W,b\)。对高斯投影，直接使用

\[
\widetilde W=RW,
\qquad
\widetilde s(z)=\widetilde W^\top z+b,
\qquad z=Rr.
\]

对随机谱坐标抽样，使用相同抽取和缩放后的权重坐标。报告：

1. 与完整 Router 的决策一致率

   \[
   \Pr[g_{\mathrm{low}}(r)=g_{\mathrm{full}}(r)];
   \]

2. 正确类别 margin 保留比例；
3. 测试准确率；
4. 两个测试集上的最差种子结果。

该协议直接检验定理 4，而不把“重新训练后优化是否成功”混入保持性质。

### 4.7.4 实用评估：低维空间重新训练 Router

对每个低维表示重新训练相同逻辑回归。该实验回答：低维表示不仅存在对应分类器，而且能否被标准优化程序稳定学到。

### 4.7.5 距离保持

从测试集中分层抽取 100,000 个样本对，其中同类与异类各占一半。定义相对平方距离失真：

\[
e_{ij}
=
\frac{\|\phi(r_i-r_j)\|_2^2}{\|r_i-r_j\|_2^2}-1.
\]

报告：

- \(|e_{ij}|\) 中位数；
- 95% 与 99% 分位数；
- 最大值；
- 类内与类间分别统计。

### 4.7.6 通过标准

定义机会校正性能保留率：

\[
\operatorname{Ret}(m)
=
\frac{A_m-1/K}{A_{\mathrm{full}}-1/K}.
\]

若某个 \(m\ll d\) 满足：

1. 30 个随机种子中至少 95% 的种子有

   \[
   \operatorname{Ret}(m)\ge0.95;
   \]

2. 与完整 Router 决策一致率至少 95%；
3. 新模板测试集同样满足上述标准；
4. 距离失真 95% 分位数不超过预先设定的 \(\varepsilon\)；

则认为该维数能够稳定保持已有路由结构。

## 4.8 实验五：合成数据校验理论与代码

真实表征可能同时违反多个假设，因此必须先用合成数据验证代码能复现理论分支。

### 4.8.1 Case A：低维、可分、谱上均匀

设

\[
d=4096,
\qquad r=16,
\qquad K=8.
\]

在潜在空间中令类别中心

\[
\mu_k=4e_k,
\qquad k=1,\ldots,8,
\]

每个样本为

\[
z=\mu_k+\xi,
\qquad
\|\xi\|_2\le0.5.
\]

因此类内距离至多为 1，而类间距离至少为

\[
4\sqrt2-1>4.6.
\]

取 Haar 随机正交矩阵

\[
Q\in\mathbb R^{d\times r},
\qquad Q^\top Q=I_r,
\]

并令

\[
x=Qz.
\]

该数据低维、强可分，且相对于标准坐标近似均匀。

### 4.8.2 Case B：低维、可分、谱上集中

使用相同潜在数据，但令

\[
Q=
\begin{bmatrix}
I_r\\
0
\end{bmatrix}.
\]

全部信息集中在前 \(r\) 个坐标。

预期：

- 稠密高斯投影在 Case A 和 Case B 中都能保持；
- 随机坐标抽样在 Case A 中稳定；
- 随机坐标抽样在 Case B 中容易漏掉信息。

### 4.8.3 Case C：原空间线性不可分

构造二维 XOR：

\[
(1,1),(-1,-1)\mapsto1,
\]

\[
(1,-1),(-1,1)\mapsto2,
\]

再嵌入 \(\mathbb R^{4096}\)。预期：任意线性投影后重新训练线性分类器，仍不能实现零训练误差。该实验验证定理 5 的代码实现和评价流程。

### 4.8.4 样本量

每个可分 case 每类生成：训练 1,000 条、开发 200 条、测试 500 条。全部实验先在合成数据通过，再运行真实表征。

## 4.9 结果解释与唯一决策表

| 完整空间 | 随机低维 | 允许结论 | 下一步 |
|---|---|---|---|
| 线性 Router 稳定可分 | \(m\ll d\) 时稳定保持 | 当前表征已有可压缩路由结构 | 进入低维 Router 与专家效用实验 |

# 6. 证明与实验的边界

## 6.1 有限样本与分布泛化

定理 1 和定理 4 首先保证有限样本集合。对未知分布的新样本，需要额外的支持集覆盖、统一收敛或流形复杂度条件。本文通过独立测试集和新模板测试集经验评估泛化，但不把有限样本定理夸大为任意分布保证。

## 6.2 语义标签与真实专家效用

离线 domain 标签只是检验几何结构的代理。即使 domain 可分，也不等于按该标签分专家一定降低语言模型损失。进入后续阶段后，还需用专家反事实效用定义真正的路由目标。

## 6.3 监督低秩空间的解释

监督低秩子空间只证明低维判别空间的存在性。它使用了标签，不能直接作为无标签 Router 的实际求解方法。

## 6.4 “均匀”不是高斯随机投影的必要条件

稠密高斯投影对固定有限点集的保持不依赖谱均匀性。谱均匀性主要决定随机选择少量原谱坐标是否可靠。

## 6.5 逐轴判别比不是完整可分性的充分判据

多数谱轴上 \(B_j/W_j<1\) 不能推出完整空间不可分。多个弱方向可能组合成强判别方向，因此必须执行全空间 Router 和广义 Fisher 实验。

## 6.6 理论维数界是充分条件而非必要条件

本文通过集中不等式、有限网和并合界得到的目标维数，是保守的高概率充分上界，通常明显大于实践中维持准确率所需的维数。实验不应以“经验维数小于理论上界”作为理论失败；真正需要检查的是维数、原始 margin、相干度和失败概率之间的定性关系是否一致。

# 7. 结论

本文将会议中的随机投影直觉修正为一个严格的二分问题。

第一，若原始表征已经具有正的距离间隔或正的多类线性 Router 间隔，则随机降维可以在足够维数下保持这些结构。对于稠密高斯随机投影，所需维数主要由样本数、类别数、内在维数、允许失真和原始 margin 决定，而不要求判别信息在谱坐标上严格均匀。对于随机谱坐标抽样，低维还不够；判别结构必须相对于谱基低相干，才能避免关键方向被漏掉。

第二，随机降维不能创造原空间不存在的线性可分性。若完整高维表征在线性 Router 函数族内不可分，那么任何线性投影后接线性 Router 都仍然不可分。这一不可能性把研究问题从“寻找更好的线性低维基”转向“训练如何生成适合路由的表征几何”。

第三，已有研究结果只支持以下谨慎判断：候选更新可以统计高秩，但固定分类功能可能低维；判别方向不等于最大方差方向；多数单谱轴没有强 domain 判别性；不同领域的局部判别空间可能不同。它们尚未证明完整高维空间不可路由。因此，下一步最重要的实验不是继续解释单个谱方向，而是直接测量完整空间的线性 Router 性能、留出集 margin 和多方向组合能力，然后再进行随机降维维数扫描。

最终判据为：

\[
\boxed{
\begin{aligned}
&\text{完整空间可分且低维可保持}
&&\Rightarrow
&&\text{随机降维是可用的低成本保持器};\\
&\text{完整空间不可分}
&&\Rightarrow
&&\text{停止线性坐标搜索，转向表征形成训练}.
\end{aligned}
}
\]

# 8. 组会同步复述稿

## 8.1 三十秒版本

> 我们现在把问题分成“保持结构”和“生成结构”两部分。随机降维只有在原高维表征已经存在正距离间隔或正线性 Router margin 时，才能低成本保持可分性；如果原空间线性不可分，任何线性投影都不可能创造可分性。所谓低维语义均匀分布在谱空间，严格对应低相干条件，它主要保证随机抽取谱坐标不会漏掉信息，而不是高斯随机投影的必要条件。下一步先直接验证 Qwen3 完整高维表征是否可路由，再做随机维数扫描；由此决定继续低维 Router，还是转向训练产生可分表征。

## 8.2 两分钟版本

> 已有实验给出的核心现象是：完整候选更新的 covariance 可以很宽，但具体分类任务存在较低维的监督判别空间，而且这些方向不等于最大方差方向；同时，多数单独 covariance 谱轴的类间变化没有超过类内变化。这个结果只能说明谱轴和判别结构没有自然对齐，不能证明完整高维空间不可分。
>
> 我们因此形式化两个随机降维。第一种是稠密高斯随机投影，它混合全部坐标；只要原空间有正距离或正线性 Router margin，就能以高概率在低维保持。第二种是随机抽取谱坐标，它只有在低维判别结构相对于谱基低相干，也就是能量比较均匀时才可靠。我们分别给出了有限样本距离保持、低维仿射子空间并集保持、谱坐标抽样保持和多类线性 Router margin 保持定理。
>
> 同时有一个不可能性结论：若原空间在线性 Router 函数族内不可分，那么任意线性投影后再接线性 Router 仍然不可分。所以随机投影只能保持结构，不能创造结构。
>
> 实验上先构造八个粗领域、每个八个细类的受控数据，在固定 Qwen3 表征位置提取不能由旧状态线性预测的 Attention 更新。先复现逐谱轴的类内—类间现象，再直接训练完整空间线性 Router、测留出 margin 和广义 Fisher 组合方向。只有完整空间本来可分，才进入随机投影维数扫描。如果原空间可分且一百多维就能稳定保持，我们继续低维 Router；如果原空间本身不可分，就停止继续找线性基，转向训练如何产生层次化可分表征。

## 8.3 导师追问时必须能回答的五个问题

1. **“均匀分布的对象是什么？”**  
   是低维判别子空间相对于全局协方差谱基的投影能量，而不是样本在高维空间均匀采样。

2. **“均匀性为什么有用？”**  
   它保证随机抽取少量谱坐标时不容易漏掉全部判别信息；稠密高斯投影本身不要求该假设。

3. **“随机投影为什么能 route？”**  
   随机投影本身不 route；它只保持原空间已有的距离或 logit margin，之后仍需距离型或线性 Router。

4. **“已有实验是否证明 Qwen3 一锅粥？”**  
   没有。已有结果只证明多数单谱轴较弱；必须补完整空间线性 Router 和多方向组合实验。

5. **“证明完成后如何决定下一步？”**  
   完整空间可分且低维保持，就做低维 Router；完整空间不可分，就转向训练产生可分表征。
