# A15｜高铁至次日 12:00 的 MVP 推进计划

## 唯一思考锚点

> **父类条件化是否比全局去掉 coarse/PCA 子空间，更稳定地暴露低维细粒度判别结构？**

本轮不证明完整 MoE，不训练深树，不继续泛读。MVP 只要求：

- 一个问题；
- 一个冻结层；
- 一个已有数据集；
- 一张维数—性能主图；
- 一个子空间 overlap 表；
- 一段能用自己的话讲清楚的认识更新。

# 3. 今晚实验的最小契约

## 数据

- 冻结已有表征；
- 先用数学、物理两个父类；
- 每个父类 2–4 个细类；
- 第 24 层；
- 保持现有模板隔离的 TRAIN/DEV/TEST。

## 四个空间

1. 完整 \(h\)；
2. 粗粒度判别投影 \(P_{S_C}h\)；
3. 粗粒度 residual \((I-P_{S_C})h\)；
4. 父类特异细粒度空间 \(P_{S_{F|c}}h\)。

## 主指标

- held-out 细分类准确率；
- 5% 低尾归一化 margin；
- subspace overlap / principal angles。

## Rank

\[
r\in\{1,2,4,7,16,\text{full}\}.
\]

Rank 只用 DEV 选择，TEST 只开一次。

## 主图

一张图：四种空间的 rank–performance 曲线。

## 附表

- \(S_C\) 与每个 \(S_{F|c}\) 的 overlap；
- 两个 \(S_{F|c}\) 之间的 overlap；

# 4. 结果解释模板

## 结果 A：residual 最好

允许说：粗、细方向在当前任务中近似可分，去粗粒度是有效归纳偏置。

不能说：真实语言语义普遍正交；完整 residual tree 已成立。

## 结果 B：local conditional 最好，residual 下降

允许说：父类条件主要用于选择或解释局部坐标，粗、细信息存在重用或交互；全局删除 coarse 不合适。

下一步：设计父类条件 Router，而非继续全局 residual。

## 结果 C：local 低维且不同父类低重合

允许说：支持“条件低维、全局并集高秩”；共享 Router 的维数需求来自多个局部空间并集。

下一步：研究如何无标签选择 \(S_{F|c}\)。

## 结果 D：全部不稳定

允许说：当前层/数据没有提供稳定的层级几何证据。

下一步：检查数据定义、模板泄漏和表征位置，不进入 MoE 架构。

# 5. 11:00 对接时的 3 分钟结构

1. **问题：**我们原先把 common、coarse 和父 expert 子空间混为一体，导致“去 coarse”实验可能删错对象。
2. **事实：**PCA 头不区分粗类；学会粗类不自动学细类；正确父类条件却能改善细类训练；局部 7 维、共享 56 维、局部空间低重合。
3. **实验：**比较 full、coarse、coarse-residual、conditional-local 四种空间。
4. **结果：**只讲一张主图和一个 overlap 表。
5. **认识更新：**回答是 residual、纠缠还是局部并集。
6. **边界：**没有证明无标签 Router、专家收益或完整树。
7. **下一决策：**是否据此进入父类条件 Router 的最小训练实验。
