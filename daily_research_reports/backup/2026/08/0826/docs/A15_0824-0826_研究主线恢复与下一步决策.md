# A15｜0824–0826 研究主线恢复

## 从“去掉 common 后递归分发”转向“父类条件化下的局部判别子空间”

# 结论先行

1. **最新实验已经否定了三个强版本假设：**
   - 主成分分析（PCA）头部最大方差方向就是粗粒度语义方向；
   - 模型学会粗粒度“界”后，会自然获得细粒度“门”的区分能力；
   - 全局删去“界”或 PCA 头部后，细粒度结构会自动显现并可直接用于下一层路由。

2. **目前最坚实的表征事实是：**
   - 高方差头部主要承载跨领域共享的词法、功能词、标点和通用句法；
   - 语义判别方向多位于谱的中后部，而非 PCA 头部；
   - 单个已知父类内部的细分类功能可以由很低维的局部子空间保留，但不同父类依赖的局部子空间几乎不同，其并集使整体表征呈高秩。

3. **因此，`common`、`coarse` 与 `fine` 不能再视为同一个从大方差到小方差的正交分解：**
   - `common` 是跨样本共享且高频的统计因素；
   - `coarse` 是用于区分父类的任务相关信息；
   - `fine` 是在父类条件下区分子类的信息。
   三者可能位于相同谱段、部分重叠，且同一方向在不同父类中可具有不同功能含义。

4. **之前的 AI 理论—实验方案并非数学错误，而是主线选择偏早：**它把“公共因素、粗粒度语义、父专家已学函数”合并成同一个正交子空间，并直接进入一层 Transformer 的 common-first / residual-tree 训练机制。最新证据表明，当前首先缺少的不是一个更复杂的训练协议，而是对**粗粒度判别子空间与父类条件细粒度子空间之间关系**的审计。

5. **当前思考锚点：**

> 不再先问“应该删掉哪些 PCA 方向”，而先问：**固定父类以后，细粒度判别信息是否形成稳定的低维局部子空间；该子空间与粗粒度判别子空间是正交、重叠，还是父类特异地重用同一批方向？**

## 0.1 材料可信度排序

5. **AI 理论—实验协议：**是待审核方案，不是实验结果。

需要特别纠正两处：

- 0826 简略纪要称“高层级节点不具备可分性”，但 `feature (7).pdf` 第 2 页图表显示，**组合层级越高，domain 区分能力越强；叶子 feature 被各 domain 广泛使用，单看激活难以区分 domain**。前一句很可能发生了主客体颠倒。
- 0826 主会议转写同时出现“界必须持续更新”“要剔除界的梯度”“绝不能冻结界”等相互冲突表述。当前只能安全解释为：**细粒度训练不能丢失父类上下文，但需要限制新模块重复学习父模块的作用**；具体参数是否冻结，材料不足以确定。

## 0.2 证据标签

- **[事实]** 已由图表或数值实验支持。
- **[导师假设]** 导师根据现象提出、尚未验证的机制解释。
- **[分析推论]** 由多份材料合并得到的解释，需后续实验证伪。

## 0.3 核心术语

- **公共信息（common information）：**大量领域和样本反复使用的统计因素，例如功能词、通用句法与模板；不等于粗粒度语义。
- **粗粒度信息（coarse information）：**用于区分父类，例如数学与物理的信息。
- **细粒度信息（fine information）：**在已知父类后区分子类，例如数学内部的抽象代数与组合数学的信息。
- **条件子空间（conditional subspace）：**在固定父类条件后，为完成该父类内部细分类任务所需的判别子空间。
- **局部低维、整体高秩：**每个条件任务只需少量方向，但不同条件任务使用不同方向，其并集维数很高。
- **主成分分析（PCA）：**寻找总方差最大的正交方向；它优化重构方差，不优化类别区分。

# 1. 第一步：恢复真实研究主线

## 1.1 上一次组会真正的问题是什么

0824 组会将问题压缩为两条相互关联但不同的线：

### 线 A：层次化专家为什么失败

原候选机制是：

1. 先让一个低秩父 expert 学习公共或粗粒度部分；
2. 再增加子 experts；
3. 从后续表示中删去父 expert 已解释的部分；
4. 子路由器只根据剩余变化进行分发。

导师当时的新直觉是：新增 expert 的必要性不是“父 expert 的秩不够”，而是不同条件函数存在冲突；后续 expert 不应重复学习父 expert 已经学到的内容。候选路由输入被写为

\[
r=(I-P_C)h.
\]

但导师明确说，这只是由失败现象诱发的解释，不能直接当作结论。

### 线 B：为什么高维表示仍然不够可分

已有实验观察到：原始高维表示中虽然存在领域信息，但不同类别的低尾样本仍互相穿插；线性随机降维不能创造原空间不存在的线性可分性。因此真正问题从“如何降维”转为：

> 模型究竟怎样把低维语义因素组织成稳定、任务对齐的高维可分几何？

这条线是正确边界，但当时尚未确定粗、细语义在真实表示中的几何关系。

## 1.3 学长们最新实验分别说明了什么

## 1.3.1 ZX：全局“去界”不是层级条件化

### 实验事实

[事实] ZX 的二维反例表明，同一局部坐标在不同父类中可以对应不同叶节点。若直接删去父类坐标，组合数学与经典力学等不同父类样本可能因剩余坐标相同而被错误送到一起。

这个失败不是简单的“投影估计不准”，而是对象定义错误：

\[
\text{叶节点身份}=\text{父类条件}+\text{父类内部坐标}.
\]

删掉父类条件后，只剩“父类内部相对位置”，不足以确定叶节点。

### SAE 结果

[事实] `feature (7).pdf` 第 2 页显示：每个 token 仅激活约 32/30000 个 SAE feature，说明每个样本的表示具有稀疏局部支持；但不同 token 激活的 feature 集不同，整体覆盖范围很宽。

严格地说，这直接证明的是**稀疏性**，不是矩阵秩定理；但它与“局部低维、整体高秩”一致。

[事实] 叶子 feature 更靠近 PCA 头部、却被各 domain 广泛使用；组合节点越高，domain 区分能力越强。这说明：

> PCA 头部更像通用原子特征；领域语义可能来自多个原子 feature 的组合，而不是某个单独高方差轴。

---

## 1.3.2 HRJ：条件化有收益，但 PCA 不能提供条件

### 训练结果

[事实] `feature (7).pdf` 第 10 页的 loss/PPL 表：

- 普通 MoE：loss 2.6351，PPL 13.945；
- 去 PCA 头、去 FFN 大奇异方向或只留 PCA 头：均与基线接近，没有形成明确收益；
- **将粗粒度相同的数据强制分到同一 expert，再做细粒度分发：loss 2.5897，PPL 13.326。**

这不是“自动学出了层级 Router”的证据，因为父类分配是人工给定的；它支持的是：

> **先给出正确父类条件后，局部 expert 更容易学习父类内部的细粒度函数。**

### 表征与 gate 的差异

[事实] 第 12 页显示，父 expert 输出中细粒度线性准确率约为 53.7%–56.9%，但真实下一层 gating 约为 51.2%。即：

- 父 expert 表征中可能出现了一些细粒度可读信息；
- 训练得到的 gate 没有把这些信息转化为可靠分发。

因此必须继续区分：

\[
\text{信息存在}\neq\text{线性可读}\neq\text{路由器学会使用}\neq\text{专家功能收益}.
\]

---

## 1.3.3 CAR：粗粒度学习不会自动生成细粒度边界

[事实] `feature (7).pdf` 第 3 页显示：FFN 训练后，“界”的线性区分准确率约为 \(0.818\pm0.056\)，显著高于未训练 FFN 的 0.365 和随机水平 0.333；但在学会“界”以后，“门”的二分类准确率约为 \(0.510\pm0.002\)，仍接近随机 0.5。

因此被否定的是：

\[
\text{学会 coarse}\Longrightarrow\text{自动学会 fine}.
\]

CAR 的另一组方向语义分析还表明：

- 类间距离相对类内距离较大的方向主要在协方差谱中后部；
- 这些方向对应评价词、形式化运算、任务结构和数据模板等 domain-specific 信息；
- PCA 头部但判别比值小的方向主要对应标点、功能词与通用句法。

## 1.3.4 与 DXY 已有实验合并后的强事实

[事实] 单个已知父类内部的 8 分类任务，至多约 7 维的监督局部判别子空间即可保留完整功能；八个父类共用一个投影时需扩展到约 56 维；第 24、28 层不同父类局部子空间平均两两重合仅约 1.27% 和 1.79%。

[事实] 完整层间新增表示可以是高秩的，但分类功能可以由较低维子空间保留；该子空间与 PCA 最大方差方向不对齐，而更集中在约 12.5%–15.6% 的中部谱段。

[事实] 原生 Router/更新表征包含领域信息，但 5% 低尾 margin 为负，距离比约 0.20–0.33，小于 1，说明类别几何仍有严重交叠。

这些事实共同支持：

\[
\boxed{
\text{父类条件下功能低维}
+
\text{不同父类使用不同方向}
\Rightarrow
\text{全局并集高秩}
}
\]

但尚未支持“模型能无监督发现这些父类条件”。

## 1.4 与我们之前给定的理论和实验方案有什么联系

## 1.4.1 仍然正确、应保留的部分

| 旧方案内容 | 当前判断 | 保留方式 |
|---|---|---|
| 线性投影不能创造原空间不存在的线性可分性 | 正确且仍是边界定理 | 保留为下游降维前提，不作为当前主实验 |
| 表示高秩与任务功能低秩必须区分 | 被最新实验进一步支持 | 作为当前主线基础 |
| residualization 不会创造信息 | 正确 | 用来防止把“去 common”写成魔法 |
| full-state 必须作为 residual 基线 | 正确 | 后续任何 residual 实验都必须保留 |
| expert 必要性来自条件函数冲突，而非标签名称 | 正确但尚未实证 | 保留为后续功能层问题 |
| 小模型、work/fail 成对构造 | 方法论正确 | 在几何对象确定后再使用 |

## 1.4.2 与最新实验联系较弱、当前不应作为主线的部分

旧方案使用了模型

\[
h=c+z\mu+\varepsilon,\qquad \mu\in C^\perp,
\]

并把 \(C\) 同时解释为：

1. NTP 高频形成的 common 子空间；
2. “界”对应的粗粒度语义；
3. 父 expert 输出列空间；
4. 应从 child 输入中删除的 nuisance 子空间。

最新实验说明，这四者没有证据相等：

- PCA 头部 common 方向主要是通用语言因素，不是“数学/物理”粗类方向；
- 粗类判别方向本身位于中后谱；
- 细类方向可能与粗类方向共享谱段或存在条件交互；
- 删除父类信息可能让不同父类叶节点发生碰撞；
- \(\operatorname{col}(B_0)\) 是否等于真正的 common 子空间没有验证。

因此旧方案验证的是一个**正交可加的特殊世界**：若细粒度信号确实位于 \(C^\perp\)，residual tree 是否工作。它不能回答当前真实数据最关键的问题：真实粗细语义是否满足这种分解。

## 1.4.3 为什么我们之前会走偏

### 偏差 1：把导师的口头干预直接升级为数学对象

“去掉 common”尚未定义清楚时，方案直接选了正交投影 \(I-P_C\)，并进一步选 \(C=\operatorname{col}(B_0)\)。这绕过了最关键的识别问题：**什么才是 common，如何证明它不是 coarse 或 fine 的一部分。**

### 偏差 2：混淆三个层级

我们把“高频公共统计”“父类语义”“父 expert 已完成函数”合并了。它们在真实模型中可能分别对应不同方向、不同谱段和不同功能。

### 偏差 3：从静态几何直接跳到训练机制

当前已有实验仍在回答“信息在哪里、如何重叠”。旧方案却直接进入 common-heavy NTP、oracle branch、child adapter、OOD margin 等完整训练协议，跨过了必要的中间桥：

\[
\text{真实几何对象存在}
\rightarrow
\text{对象可被稳定识别}
\rightarrow
\text{再设计训练机制}.
\]

### 偏差 4：oracle 结构可能使合成实验只证明设计自洽

若数据生成时已显式放入 orthogonal common/fine、真实 branch 和冲突函数，再用 oracle branch 训练 residual children，实验成功主要说明机制在其自身假设下成立，不能解释真实表示为何呈当前结构。

### 偏差 5：没有设置“新团队结果否决设计”的检查点

以后进入实现前必须先完成：

1. 每个理论符号对应哪个已测量对象；
2. 最新组内实验是否支持其定义；
3. 若不支持，方案降级为对照，而不是继续扩写。

## 1.6 本次组会导师的新猜想是什么

根据与学长的逐字同步，导师的新猜想不是简单恢复“去 common”，而是：

> **粗粒度和细粒度判别信息可能共同位于谱的后部或同一局部子空间中；某些方向同时携带粗、细粒度变化。粗粒度变化幅度可能更大，因而在混合数据中占主导；当固定父类后，粗粒度变化消失，同一批方向中的细粒度变化才变得可见。**

该猜想包含三个仍需拆开的子命题：

1. **位置命题：**粗、细判别方向是否位于相近谱段；
2. **重叠命题：**它们的判别子空间是否有显著交叠；
3. **条件化命题：**固定父类是否比全局投影删除父类方向更能暴露细粒度结构。

其中只有第 3 个最直接对应现有正结果：人工按粗类分 expert 后，细粒度训练和 loss 更好。

---

## 1.7 当前仍不知道什么

最核心未知不是“树要分几层”，而是：

> **父类条件究竟通过什么几何机制降低细粒度学习难度？**

目前至少有三种竞争解释：

### H-A：正交残差

粗粒度子空间与细粒度子空间近似正交；去掉粗粒度后，细粒度间隔提高。旧 residual 方案对应此情形。

### H-B：条件重用/子空间纠缠

粗、细信息共享部分方向或存在父类依赖的坐标含义；必须保留父类条件，不能全局删掉粗粒度。

### H-C：局部子空间并集

每个父类内部都有独立低维细分类空间；父类条件的主要作用是选择正确的局部坐标系，而不是删除某个统一 coarse 子空间。

现有证据最接近 H-B/H-C，但尚未完成直接比较。

# 2. 第二步：帮助真正理解整条逻辑

## 2.1 HRJ、ZX、CAR 各自解决了什么问题

### ZX 解决的是“为什么全局去 coarse 会失败”

他给出的关键认识是：父类信息不仅是需要消除的大方差噪声，还可能是解释子类坐标含义所必需的上下文。全局删除父类后，不同父类的局部相对位置会发生碰撞。

### HRJ 解决的是“正确父类条件是否真的有功能价值”

他的结果表明，PCA 规则不能自动发现父类；但人工提供正确父类条件后，训练 loss/PPL 改善。这把问题从“删哪个方向”改成“如何识别并利用条件子空间”。

### CAR 解决的是“粗粒度学习是否自动包含细粒度学习”

答案是否定的。粗类边界形成，不代表细类边界也形成。因此树状模型不能只依赖学习顺序，必须有额外的细粒度目标、条件训练或新特征生成机制。

三者合起来得到：

\[
\boxed{
\text{粗类可学}
\not\Rightarrow
\text{细类可学};\quad
\text{删粗类}
\not\Rightarrow
\text{细类显现};\quad
\text{给出正确粗类条件}
\Rightarrow
\text{细类学习可能更容易}.
}
\]

---

## 2.2 对 common / coarse / fine 的认识更新

### 旧认识

\[
\text{PCA 头部/common/coarse}
\quad+
\quad
\text{PCA 尾部/fine residual}.
\]

### 新认识

更合理的结构至少包含三类对象：

\[
h
=
F_{\mathrm{common}}(u)
+
F_{\mathrm{coarse}}(c)
+
F_{\mathrm{fine}}(c,z)
+
\xi,
\]

其中 \(F_{\mathrm{fine}}\) 显式依赖父类 \(c\)。这意味着它不一定能写成全局统一的 \(z\mu\)，也不要求与 coarse 正交。

- **common：**高频、共享、常位于 PCA 头部，但区分性弱；
- **coarse：**用于区分父类，可能在中后谱；
- **fine：**父类条件下的局部函数，方向随父类变化。

最重要的更新是：

> **common 不等于 coarse；coarse 也不等于应该删除的 nuisance。**

---

## 2.3 对 PCA 方差方向的认识更新

PCA 只最大化

\[
\operatorname{Var}(v^\top h),
\]

而路由需要最大化与标签或 expert 效用相关的量，例如类间/类内比、分类 margin 或损失差。

一个方向可以具有极大方差但与标签独立；另一个方向方差很小却完全决定类别。因此：

\[
\text{方差排序}
\not\Rightarrow
\text{语义层级排序}.
\]

最新结果把这一点从一般常识变成了本项目的直接事实：判别方向集中在中后谱，PCA 头部更多是共享语言统计。

---

## 2.4 对“局部低维与整体高秩”的认识更新

设父类 \(c\) 的细粒度判别子空间为 \(S_c\)，维数约为 \(r\)。若不同父类的 \(S_c\) 重合很小，则共享空间至少需要覆盖

\[
S_{\mathrm{all}}
=
\operatorname{span}(S_1,\ldots,S_K),
\]

其维数接近

\[
\dim S_{\mathrm{all}}\approx\sum_{c=1}^{K}\dim S_c.
\]

这正对应实验中的约 7 维局部空间与约 56 维共享空间。

物理含义是：

- 每个 token/父类只需要少量“当前有用坐标”；
- 不同 token/父类使用不同坐标；
- 所有坐标合在一起看，整体自然高秩。

所以“整体高秩”不再是低维 Router 的反证，反而可能是条件路由存在的理由。

---

## 2.5 对条件子空间的认识更新

条件子空间不是“先删掉父类再做分类”，而是：

\[
\text{先确定父条件 }c
\quad\Longrightarrow\quad
\text{只在 }S_c\text{ 中解释子类差异}.
\]

父条件可以发挥三种作用：

1. **选择坐标系：**不同父类使用不同局部判别方向；
2. **消除无关类间变化：**只在父类内部估计 covariance/分类边界；
3. **保留语义上下文：**同一局部坐标在不同父类中含义不同，父类身份不能被删除。

这与全局 residualization 的根本区别是：

- residualization 是一个统一线性变换；
- 条件化是先分组，再使用父类特异的局部模型。

---

## 2.6 导师的新 intuition 是怎样从失败一步步产生的

1. **原始直觉：**粗语义差异更大、先学、方差也应更大，所以可用 PCA 头部先分粗类。
2. **第一次失败：**PCA 头部无法区分数学/物理，判别方向在中后谱。
3. **修正尝试：**删去所谓 coarse/common 方向，希望 fine residual 显现。
4. **第二次失败：**删除父类分量会使不同父类叶节点碰撞；PCA/大奇异方向分发也没有收益。
5. **关键正现象：**人工把同一粗类放入同一个 expert 后，细类表征与最终 loss 变好。
6. **新推理：**父类条件不是单纯噪声，而是在局部坐标中解释细类所需的条件；粗、细信息可能重用同一谱段或同一局部子空间。
7. **新假设：**混合数据中粗粒度变化主导；固定父类后，粗变化消失，局部细粒度变化在条件子空间中暴露。
8. **尚未完成的桥：**需要直接测量 coarse 与 fine 子空间的重叠、谱位置和条件化收益，不能仅凭 PCA 图推断。

---

## 2.7 你可以脱离原文复述的 90 秒版本

> 我们原来把高方差 common、粗粒度语义和父 expert 学到的东西当成一个子空间，认为先把它删掉，细粒度信息就会出现在 residual 里。最新实验不支持这个模型。CAR 证明学会粗类并不会自动学会细类；ZX 证明删掉父类坐标会让不同父类的叶节点发生碰撞；HRJ 证明 PCA 或简单去方向没有收益，但人工给出正确父类条件后，细粒度训练和语言模型 loss 会改善。同时，我们已有结果说明每个父类内部的细分类只需约 7 维，但不同父类使用的方向几乎不重合，八个父类共享时需要约 56 维。因此现在更合理的解释是：common 主要是高方差共享语言统计，coarse 与 fine 都是任务相关信息；fine 是父类条件下的局部低维子空间，不一定与 coarse 正交。下一步应先测 coarse 与各个 conditional fine 子空间之间的重叠和条件化收益，再决定是做 residual tree 还是父类特异的局部 Router。

# 3. 第三步：压缩下一步，但暂不替你冻结最终方案

## 3.1 当前最重要的一个未知问题

> **固定父类后出现的细粒度低维判别子空间，与粗粒度判别子空间究竟是什么关系：正交 residual、部分重叠，还是父类特异的不同局部坐标系？**

等价的可执行问法是：

> **父类条件化是否比“全局去掉 coarse/PCA 子空间”更稳定地暴露细粒度可分结构？**

---

## 3.2 为什么它最值得下一次组会解决

它直接决定三条互斥路线：

- 若近似正交，旧 residual-tree 值得继续；
- 若显著重叠，必须保留父类信息并建模交互；
- 若各父类子空间彼此不同，Router 的核心应是“选择局部坐标系”，而不是寻找一个全局低维投影。

这个问题可以用现有冻结表征完成，不需要先训练复杂 MoE；结果一旦明确，能立刻裁定之前 AI 方案是主线、特例还是反例对照。

---

## 3.3 最小需要证明什么

本轮不需要证明完整树结构，只需两个最小数学结果。

### 证明 A：全局删除父类信息可能必然失败

构造父类 \(c\) 与局部子类 \(z\)，表示为

\[
h(c,z)=b_c+s_{c,z}.
\]

若不同父类存在相同或相近的局部坐标

\[
s_{c_1,z_1}=s_{c_2,z_2},
\]

而叶节点 \((c_1,z_1)\neq(c_2,z_2)\)，则删除父类分量 \(b_c\) 后两叶完全碰撞，任何分类器都无法区分。该反例形式化 ZX 的失败。

### 证明 B：局部低维空间并集导致共享空间高维

设每个父类细分类判别空间为 \(S_c\)，任何共享线性投影若要保留所有局部任务，必须在每个 \(S_c\) 上保持判别方向，因此其维数至少受

\[
\dim\operatorname{span}(S_1,\ldots,S_K)
\]

约束。当 \(S_c\) 近似正交或重叠很小时，该下界接近 \(\sum_c\dim S_c\)。这解释 7 维局部、56 维共享，而不需要先引入 NTP 动力学。

### 暂时不证明

- NTP 是否 common-first；
- residual tree 的训练收敛；
- 1→2→4 深树；
- 无标签 gate 如何发现父类；
- 专家硬件效率。

## 3.4 最小需要实验验证什么

## 实验名称

**父类条件化—子空间关系审计（Conditional Subspace Audit）**

## 唯一问题

在现有粗细粒度数据和冻结表征中，父类条件化得到的细类判别子空间是否低维、父类特异，并且不能由简单全局 coarse-removal 替代？

## 最小数据范围

- 先只取 2 个父类：数学、物理；
- 每个父类取 2–4 个细类；
- 先只用一个已有稳定层，例如第 24 层；
- 结果清晰后再用第 28 层作确认，不扩大模型或数据。

## 四个比较

1. **完整表征 + 父类内探针：**固定父类，在完整 \(h\) 上学细分类；
2. **粗粒度投影：**在 \(P_{S_C}h\) 上学父类内细分类；
3. **粗粒度残差：**在 \((I-P_{S_C})h\) 上学父类内细分类；
4. **父类特异低秩空间：**在每个 \(S_{F|c}\) 上学细分类。

其中：

- \(S_C\)：由训练集学习的粗粒度判别子空间；
- \(S_{F|c}\)：固定父类 \(c\) 后学习的细粒度判别子空间。

## 三类测量

1. **维数—性能曲线：**\(r\in\{1,2,4,7,16,\text{full}\}\) 的留出细分类准确率与 margin；
2. **子空间关系：**
   \[
   \operatorname{overlap}(S,T)
   =\frac{\operatorname{tr}(P_SP_T)}{\min(\dim S,\dim T)},
   \]
   并报告 principal angles；
3. **谱位置：**各判别子空间在 PCA 轴上的投影能量分布，判断粗、细是否占据相同谱段。

## 一个主图

横轴为投影维数，纵轴为 held-out 细分类性能；四条曲线对应 full、coarse、coarse-residual、local conditional。旁边只放一个 overlap 小表。

## 支持不同 intuition 的结果

### 支持“正交 residual”

- \(S_C\) 与 \(S_{F|c}\) 重叠接近零；
- 去 coarse 后细类性能提高或不降；
- 不同父类的 \(S_{F|c}\) 较共享。

### 支持“条件重用/纠缠”

- \(S_C\) 与部分 \(S_{F|c}\) 有显著重叠，或位于相同谱段；
- 去 coarse 会损失细类性能；
- 保留父类条件的 local probe 明显优于全局 residual。

### 支持“局部并集高秩”

- 每个 \(S_{F|c}\) 低维即可达到接近 full 的性能；
- 不同父类的 \(S_{F|c}\) 两两重叠很低；
- 共享空间需要接近局部维数之和。

### 否定当前层级 intuition

- 父类内细分类本身没有稳定留出性能；
- 局部低秩空间不能跨模板泛化；
- 条件化、residual 与完整表征无稳定差异；
- 子空间关系对 seed/split 极不稳定。

## 停止规则

- 第一层、第一个 split 已给出明确结构时，不追加新模型训练；
- 只在结论不稳定时增加第 28 层或第二个 seed；
- 不在本轮实现 learned hierarchical gate；
- 不用 TEST 选择 rank 或方向。

# 4. 防止再次走偏的执行规则

1. **先定义对象，再写机制。** 每个“common/coarse/fine/subspace”都必须有可计算定义。
2. **先审计已有表示，再训练新模型。** 若静态几何不支持正交 residual，不进入 residual tree。
3. **一个问题只出一张主图。** 其他结果只能作为 guard 或 appendix。
4. **每个结论写清层级：**信息存在、线性可读、正 margin、路由学会、功能收益不能互换。
5. **每次新实验前做三行检查：**
   - 它裁定哪个未知？
   - 哪个结果会让我放弃当前解释？
   - 是否已有更小的冻结表征实验能回答？
6. **AI 方案默认是候选，不是主线。** 只有与最新团队事实一致后才授权实现。
