## 1. 最重要的结论：我们的核心目的是什么？

### 1.1 最终目的

我们的最终目的不是“找到一张好看的 PCA 图”，也不是“证明越深层方差越靠后”，而是：

> **对每一层，找到一个紧凑子空间；这个子空间对该层相对旧状态新暴露的、与任务有关的区分最敏感，并最终把这些区分变成 Router 的分发特征。**

可以把研究路线写成：

```text
定义某层到底写入了什么
→ 证明其中存在旧状态之外的任务相关区分
→ 找到保留该区分的最小充分子空间
→ 验证该子空间在新数据上稳定
→ 最后检验它能否改善专家分发
```

### 1.2 dxy 当前理解是否正确？

dxy 的方向是正确的，但还需要补上“新增”和“敏感”的可检验定义。

以“数学”为例：

- 旧状态已经能表达较粗的共同信息：这是“数学”；
- 当前层的写入使 token 对更细的差别变得敏感，例如“组合数学与线性代数”的区别；
- 理想子空间不应只对两者共有的“数学”成分响应很大，而应突出两者之间的差别；
- 这些差别坐标随后才可能用于把 token 分给不同专家。

因此，“对新信息敏感”至少包含四层含义：

1. **增量性：**该区分不是旧状态已经同样可读的重复编码；
2. **选择性：**子空间响应的是具名差别，而不是任意大幅度变化；
3. **紧凑性：**少量方向能够保留完整更新中大部分有用增益；
4. **可迁移性：**在未参与选方向的新 token、模板或任务实例上仍成立。

只有再通过专家效用或 Router regret 的功能检验，才能增加第五层含义：**可分发性**。

### 1.3 从会议出发的第一道逻辑关卡

在寻找 PCA 方向或聚类之前，逻辑上首先应回答：

> **对于一个预先指定的细粒度目标，某层的精确更新中，是否存在旧状态之外、能在未见数据上提高该目标可访问性的成分？**

例如，先固定“组合数学 vs 线性代数”这个差别，再问当前层更新是否让这个差别比仅用旧状态时更容易被留出读出器识别。若这一步不成立，后续得到的低维、高方差或聚类结构都不能称为“新增信息敏感子空间”。当前项目已在一个受控层上取得局部正证据；逐层判据为何仍未解决，见第 5 节。

### 本节解析

会议中“每层肯定学了新的东西”是推动分析的**工作假设**，不是会议已经证明的事实。我们的最终目标没有改变；改变的是证据顺序：先证明“新增且有用”，再寻找“低维位置”，最后谈 Router。

## 2. 合并后的会议记录

## 2.1 起点：公共基上的逐方向方差没有出现预期规律

### 清晰版记录

汇报者首先说明，研究原本希望利用不同层表征之间的差别，提取有助于分发的低维信号。此前因为每层使用的坐标不统一，跨层方差比较不可靠。本轮因此尝试先构造所有层共用的基，再把每层表征或 Attention 输出投影到同一组方向上。

会议中明确讨论了至少两种激活侧公共基：

1. 对最后一层的 token 表征矩阵做 SVD，取前约 500 个方向；
2. 把多层 token 表征汇总后做 SVD，取一组跨层共享方向。

对每一层，汇报者把约一百万个 token 投影到这 500 个方向，分别计算每个方向上的方差，再比较不同层的 500 条方差坐标。

观察结果是：

- 不同层当然存在差别；
- 但没有出现稳定、单调的“越深层，方差越向公共基后部移动”；
- residual 表征的方差往往整体大于 Attention 输出的方差；
- 因此，现有图不能支持预期的“层深—谱位置”叙事。

### 解析

这组结果否定的是一种具体方法假设：

> 只要找到一组跨层公共基，对各层逐方向方差作比较，层新增信息就会以稳定后移的方式出现。

它没有证明“层间没有新信息”，也没有证明“公共坐标完全无用”。公共基解决的是**不同层如何用同一把尺子描述**，却没有回答：

- 比较对象是否真的是当前层写入；
- 大方差是否对应任务相关差别；
- 某个方向上的变化是否已经存在于旧状态；
- 这些方向是否能改善分发。

这一失败促使会议回到更基础的问题：我们究竟在比较什么？

## 2.2 老师的第一次重构：先盯住同一个 token，再谈统计

### 清晰版记录

老师把问题简化为两个层、同一批 token 的两个矩阵，并反复追问：

> 如果我们相信两层之间有区别，那么这个区别本身是什么？应该先对什么量做差？

原方法是：每层先在每个公共方向上对所有 token 求方差，再比较两层的方差曲线。老师指出，这样首先得到的是“这一层中不同 token 彼此有多不一样”，而不是“同一个 token 经过这一层后增加了什么”。

会议随后提出，应保持 token 一一对应：对同一个 token 在前后状态中的 500 维投影先作差，再研究全部 token 的差分向量分布。Attention 被解释为同一 token 从上下文其他位置汇入信息的过程，因此研究单元应优先是“同一 token 的变化”。

### 解析

这里修正了统计顺序：

```text
旧顺序：每层分别聚合 token → 得到两条边际方差曲线 → 比较曲线
新顺序：先配对同一 token → 得到每个 token 的更新向量 → 再统计更新点云
```

两条边际分布不同，并不能告诉我们哪个 token 如何改变；两条边际分布相似，也不意味着对应 token 没有发生系统性置换或旋转。

数学上，设同一 token 在相邻状态中的投影为 $z_{\ell,i}$ 和 $z_{\ell+1,i}$。真正的配对差分为

$$
d_{\ell,i}=z_{\ell+1,i}-z_{\ell,i}.
$$

而且通常有

$$
\operatorname{Cov}(z_{\ell+1}-z_\ell)
\neq
\operatorname{Cov}(z_{\ell+1})-\operatorname{Cov}(z_\ell).
$$

更完整地说：

$$
\operatorname{Cov}(z_{\ell+1}-z_\ell)
=C_{\ell+1}+C_\ell
-\operatorname{Cov}(z_{\ell+1},z_\ell)
-\operatorname{Cov}(z_\ell,z_{\ell+1}).
$$

原来的逐层方差曲线丢掉了两个状态之间的 token 配对与交叉协方差，这就是老师要求“先对应 token 做差”的直接原因。

但这里仍需再修正一步：**相邻完整层状态之差会同时混入 Attention、MLP、残差累积和归一化变化。**它可以作描述，却不应自动被命名为某个具体操作的“新增信息”。

## 2.3 直觉模型：一层是在同一 token 上整合上下文信息

### 清晰版记录

老师用多人交流作类比：把每个人看成一个 token。浅层时，一个 token 主要保留自身信息；随着 Attention 作用，它逐步汇入邻近或远处 token 的信息。因此，若要判断某一层给当前 token 增加了什么，就应比较该 token 在写入前后的变化，而不是只比较这一层所有人的总体离散程度。

会议进一步用学科类别作直觉例子：不同 token 可能都带有“数学”这一共同成分，但分别对应更细的子类。若只看原始表征之间的距离，共同的“数学”成分可能掩盖细粒度差别；若能隔离当前层带来的区分，就更可能看见子类差别。

### 解析

这个类比提供了研究对象的物理解释：Attention 的作用不是凭空创造外部事实，而是让上下文中的某些区分在当前 token 位置变得更可访问。

因此，我们应避免把“新信息”说成信息论意义上的凭空创造。当前更准确的术语是：

> **旧状态之外的新增可访问性。**

它表示在指定目标和指定读出器族内，加入当前层更新后，未见样本上的目标预测是否优于只用旧状态。

## 2.4 目标收束：找对层新增区分敏感的低维子空间，用于分发

### 清晰版记录

会议把假设向前推进了一步：如果每层确实引入了可复现的变化，那么希望找到一个低维子空间，使该层新产生的特征在这个子空间中最明显。最终，这些低维坐标可作为 gating 特征，决定 token 应被分发到哪个专家。

老师还强调：

- 子空间不能只适用于几个人工挑选的 token；
- 每层可能需要自己的低维子空间；
- 该空间必须能应用于该层面对的广泛 token；
- 每一步都要说明基于什么假设、计算什么量、结果如何证伪假设。

### 解析

这段是整场会议的最终目标定义，也是 dxy 当前理解的来源。但是需要区分三层对象：

| 层级 | 要回答的问题 | 需要的证据 |
|---|---|---|
| 更新对象 | 当前层到底改变了什么？ | 同 token、同 hook、同归一化映射下的精确更新 |
| 敏感子空间 | 哪些少量方向保留任务相关新增区分？ | 留出增益、同秩随机对照、压缩充分性 |
| Router | 这些方向是否真的有助于分配专家？ | 匹配负载下的专家效用或 Router regret |

会议主要提出了第一层到第二层之间的几何探索，还没有完成第三层的功能验证。

## 2.5 dxy 的最后汇报：MLP 参数公共方向上的 Attention 方差

### 清晰版记录

dxy 最后汇报的方法是：把各层 MLP 输入侧参数矩阵汇总，寻找跨层共同方向；再把每层 Attention 输出投影到这些方向上，比较各层投影方差。

老师认为这一路径的出发点可以理解：它试图用一套具有参数含义的共同坐标，观察 Attention 写入在 MLP 相关方向上的变化。但会议也发现，实际计算仍主要把 500 个投影坐标逐个分开，只得到 500 个独立方差，没有研究它们怎样联合变化。

由此引出问题：对每个 token 已经得到一个 500 维向量，怎样用一个统一统计对象概括一百万个 500 维向量的形状？

### 解析

dxy 的方法解决的是**坐标对齐与参数解释**：不同层被放到同一组 MLP 相关方向上。它尚未解决：

- 500 个方向之间是否协同变化；
- 当前研究的是原始状态、Attention 写入，还是旧状态之外的更新；
- 高方差是否对应目标差别；
- 这个公共方向集是否比同维随机子空间更有效。

因此，会议提出协方差并不是完全换了一条研究路线，而是在修补“把一个 500 维 token 向量拆成 500 个互不相关标量”的信息损失。

## 2.6 为什么在会议中提出协方差矩阵？

### 清晰版记录

会议把一百万个 token 投影到 500 维参考子空间，得到一个 $500\times N$ 或 $N\times500$ 的坐标矩阵。老师最初把矩阵乘积混称为 NTK、feature information matrix 等；随后通过语音助手核对，明确了正确做法：

1. 先对投影坐标中心化；
2. 再计算 $500\times500$ 的样本协方差；
3. 对角线是每个方向的方差；
4. 非对角线是两个方向如何共同变化。

### 解析

协方差被提出，是因为原分析只保留了完整协方差的对角线。

设每个 token 的候选更新为 $u_i\in\mathbb R^d$，把它们按行堆成

$$
U=
\begin{bmatrix}
u_1^\top\\
\vdots\\
u_N^\top
\end{bmatrix}
\in\mathbb R^{N\times d}.
$$

参考子空间的正交基为

$$
B\in\mathbb R^{d\times k},\qquad B^\top B=I,
$$

则所有 token 的投影坐标为

$$
A=UB\in\mathbb R^{N\times k},
$$

其中第 $i$ 行对应列坐标 $a_i=B^\top u_i\in\mathbb R^k$ 的转置。先计算均值并中心化：

$$
\bar a=\frac1N\sum_{i=1}^Na_i,
\qquad
\widetilde A=A-\mathbf 1\bar a^\top.
$$

样本协方差是

$$
C=\frac1{N-1}\widetilde A^\top\widetilde A
\in\mathbb R^{k\times k}.
$$

若不中心化，$A^\top A/N$ 是**未中心化二阶矩**，不是通常意义上的协方差。

协方差回答的是：

> 在选定子空间内，token 更新点云主要沿哪些方向扩展？哪些原坐标经常一起增减？

它比 500 个独立方差多保留了方向间的联合变化，也把百万个点的二阶几何压缩成 $k\times k$ 的摘要。但它不保留全部点云结构；不同分组的点云可能有相同协方差。

## 2.7 为什么继续提出 PCA？

### 清晰版记录

得到中心化协方差后，会议提出对它做特征分解或 SVD，保留最大的若干主成分，再在降维空间中分析 token。

### 解析

对协方差作特征分解：

$$
C=Q\Lambda Q^\top,
\qquad
\lambda_1\ge\lambda_2\ge\cdots\ge0.
$$

前 $m$ 个特征向量 $Q_m$ 给出原 500 个参考坐标的线性组合。token 的 PCA 坐标为

$$
S=\widetilde A Q_m\in\mathbb R^{N\times m}.
$$

PCA 在这里有四个目的：

1. 找到多个原坐标共同形成的主要变化方向；
2. 检查变化能量是否集中在少量维度；
3. 在聚类前去掉部分冗余和低方差噪声；
4. 把一百万个高维点压到可计算、可视化的空间。

但 PCA 优化的是**总方差最大**，不是“任务区分最大”，更不是“旧状态之外的新增信息最大”。模板、位置、向量尺度或粗粒度共同成分都可能占据前几个主成分。

所以，若目标是专门寻找“组合数学 vs 线性代数”的差别，普通 PCA 只能作为无监督候选发现或压缩工具；是否真正保留该差别，必须由独立标签或功能目标在留出数据上检验。

## 2.8 为什么继续提出聚类？

### 清晰版记录

老师随后追问：如果希望利用这个子空间把一百万个 token 分成若干组，应该怎样做？语音助手说明，协方差只能给出重要方向，不能直接给每个 token 分组；常见流程是中心化、PCA 降维，再对每个 token 的低维坐标做 mini-batch k-means，或在需要软归属时使用高斯混合模型。

### 解析

聚类回答的是：

> 在候选更新空间中，哪些 token 的变化模式彼此接近？

需要聚类的是 $S$ 的每一行，即每个 token 的低维坐标，而不是协方差矩阵 $C$ 本身。

若“组合数学”和“线性代数”的更新在这个空间里稳定分开，可以说候选空间包含与该差别相关的 token 级几何结构。但即使聚类稳定，也仍不能直接推出：

- 群组就是新增知识；
- 群组天然对应专家；
- 聚类边界能降低 Router regret；
- 该结构会跨数据、模板和模型复现。

还必须比较同维随机子空间、重采样稳定性和未见数据上的语义富集。聚类是几何证据，不是最终功能证据。

## 2.9 会议末尾的层级结构提议与方法论要求

### 清晰版记录

有同学提出：由于深层表征包含浅层信息，可以尝试在每层构建层级结构，把叶子节点理解为旧信息、较高层节点理解为新的组合信息。

老师认为这一说法仍停留在概念层面，要求进一步回答：输入是什么、计算步骤是什么、在哪个空间完成、如何适用于所有 token、最后怎样服务 gating。会议最终强调，研究应当是逐步收紧的思辨过程：每一步明确假设，再给出能够支持或否定它的计算。

### 解析

“层级结构”可以是未来竞争方案，但本次没有形成可执行定义，不能与已经写出矩阵对象的协方差—PCA 路线并列为会议结论。它应留在 Parking Lot，除非先明确：

- 节点和边分别由什么量定义；
- “旧”与“新”怎样被独立验证；
- 层级结构怎样超过平面低维对照；
- 怎样产生可用于分发的固定特征。

## 3. 从会议原话到当前更严格的数学对象

会议提出“同 token 先做差”是关键进步，但“相邻完整层状态相减”仍不是最干净的层操作定义。当前 A15_08 对它作了如下收紧。

在第 $\ell$ 层，令：

- $h_\ell$：Attention 写入前的 residual；
- $a_\ell$：Attention 输出投影后、将加回 residual 的写入；
- $N_\ell$：同一个 post-Attention normalization。

定义

$$
X_\ell=N_\ell(h_\ell),
\qquad
Z_\ell=N_\ell(h_\ell+a_\ell),
$$

以及同层、同 token、同一归一化映射下的精确更新：

$$
U_\ell=Z_\ell-X_\ell.
$$

三种常被混淆的对象应明确分开：

| 对象 | 能说明什么 | 主要混淆 |
|---|---|---|
| $H_{\ell+1}-H_\ell$ | 两个完整层状态之间的累计变化 | 混入 Attention、MLP、残差与归一化变化 |
| 原始 $a_\ell$ | Attention 向 residual 坐标写入什么 | 没包含归一化对实际 MLP 输入的影响 |
| $U_\ell$ | 当前 Attention 写入对本层 MLP 输入造成的精确变化 | 非零仍不等于任务相关新信息 |

即使 $U_\ell$ 是精确更新，也不能直接称为“新知识”。进一步要从 $X_\ell$ 预测 $U_\ell$，把旧状态已经能线性解释的部分去掉：

$$
R_{U,\ell}
=U_\ell-\widehat{\mathbb E}_{lin}[U_\ell\mid X_\ell].
$$

然后才问：在冻结旧状态读出器以后，加入 $R_{U,\ell}$ 是否降低未见数据上的目标损失，并超过目标无关、同预算的匹配对照。

### 本节解析

这不是否定会议提出的协方差/PCA，而是给它们放回正确位置：

- 协方差与 PCA 可以描述 $U_\ell$ 或 $R_{U,\ell}$ 的几何；
- 条件留出增益判断其中是否存在“旧状态之外的目标相关新增可访问性”；
- 低秩充分性判断少量方向能否保留这种增益；
- Router 检验判断这种增益是否能转化为分发收益。

公共基因此是一把**描述尺子**，不是“新增信息”的定义。

## 4. 协方差、PCA、聚类分别为了什么？

| 方法 | 输入 | 真正回答的问题 | 不能单独回答的问题 |
|---|---|---|---|
| 子空间投影 | 每个 token 的候选更新与参考基 | 在我们关心的坐标中，token 怎样变化？ | 参考基是否正确；变化是否新增或有用 |
| 中心化协方差 | 所有 token 的投影坐标 | 哪些方向变化大，哪些方向联合变化？ | 单个 token 属于哪组；高方差是否语义相关 |
| PCA | 协方差及所有 token 坐标 | 主要联合变化能否由少量线性组合概括？ | 主成分是否是新增信息或任务最重要方向 |
| 聚类 | 每个 token 的 PCA 坐标 | token 更新是否形成稳定群组？ | 群组是否对应专家、是否改善 Router |
| 条件留出增益 | 旧状态、精确更新、具名目标 | 更新是否带来旧状态之外的任务相关可访问性？ | 该信息是否低维、是否被模型原生使用 |
| 路由功能检验 | 冻结特征、专家与匹配负载 | 特征是否真的改善专家选择？ | 更广泛任务和模型上的普适性 |

### 一句话回答“为什么要用这套方法”

> 因为配对后的每个 token 都是一个多维更新向量：协方差保留这些维度怎样联合变化，PCA 找到最主要的联合变化并压缩维度，聚类再检查 token 更新是否形成群组；但要把群组称为“层新增信息”或 Router 信号，还必须补上旧状态条件下的留出功能检验。

### 从会议过程看，提出顺序为什么是这样？

```text
公共基上的逐方向方差没有稳定后移
→ 发现原来比较的是各层边际统计，不是同 token 更新
→ 改为先获得一百万个 token 的配对更新向量
→ 发现每个更新有 500 个坐标，逐坐标方差丢掉联合变化
→ 引入中心化协方差
→ 用 PCA 找主要联合变化并降维
→ 为了把 token 分组，再引入聚类
```

所以，这套方法是由原方法的两个具体缺口自然推出的：**没有先保留 token 配对**，以及**把多维向量拆成了互不相关的标量**。

## 5. 为实现最终目的，需要依次验证哪些假设？

| 顺序 | 可证伪假设 | 最小需要检查的证据 | 若失败，说明什么 |
|---|---|---|---|
| H0 对象有效 | $U_\ell$ 确实是同 token、同层、同 normalization 下的精确更新 | hook/token 身份与 $Z_\ell=X_\ell+U_\ell$ 重建 | 连“这一层的更新”都没有定义干净 |
| H1 新增且相关 | $R_{U,\ell}$ 在旧状态之外提高具名目标的留出可访问性 | old-only vs old-plus-update；目标无关同预算 null | 变化可能只是旧信息重编码、尺度或容量效应 |
| H2 低维充分 | 一个冻结的 $m$ 维子空间保留完整更新的大部分增益 | 与 full update、同秩随机、标签置乱方向比较 | 高方差或漂亮 PCA 不等于有用信息低维 |
| H3 稳定泛化 | 同一冻结子空间在新 token、模板和数据划分上复现 | untouched held-out、重采样稳定性、方向匹配 | 当前结构可能是样本或选择偏差 |
| H4 可用于分发 | 子空间坐标改善专家选择 | 匹配负载与预算下的专家效用/Router regret | 几何或可读性不等于 Router 功能 |

这些假设不能颠倒。尤其不能用 H2 的“低维”或聚类图去挽救 H1 的“并非新增”。

### 逻辑第一关与当前研究位置不是同一件事

从 0813 会议问题出发，逻辑第一关是 H1：

> **对一个预先命名的细粒度区分 $Y$，某层 $R_{U,\ell}$ 是否在旧状态 $X_\ell$ 之外，为未见样本上的 $Y$ 提供超过目标无关同预算对照的新增可访问性？**

但当前 A15 路线已经比 0813 向前走了一步：A15_08 在第 25 层的受控任务上建立了一个局部新增可访问性实例，同时注册的两个方向没有保留足够的完整增益；A15_08_01 又显示，跨层差中差交互可以增强，而目标条件自身的绝对增益反而下降。因此，正交交互不能替代我们真正关心的绝对目标量。

### 当前只应冻结的一个研究问题

现在不应同时展开新的 PCA、聚类和 Router，而应只把下面的问题定义清楚：

> **怎样定义一个不会被控制条件恶化、旧状态 headroom 或读出容量制造假阳性的“逐层目标条件绝对新增可访问性”主判据？**

可把每层的目标量写成

$$
G_{\ell,Y}
=CE_{heldout}\!\left(f_{X,\ell}(X_\ell)\right)
-CE_{heldout}\!\left(f_{X,\ell}(X_\ell)+g_\ell(R_{U,\ell})\right).
$$

它必须与目标无关、同预算的匹配修正比较；其他条件构成的差中差只承担机制对照，不承担目标量本身。

在不执行实验的前提下，下一份研究定义只需写清四件事：

1. $Y$ 到底是哪一个具体差别，而不是泛泛的“语义”；
2. 旧状态、层更新、token 位置和逐层聚合分别如何固定；
3. 哪个匹配 null 排除“旧状态更差、读出容量更大或重复编码”的竞争解释；
4. 什么结果分别记为 Pass、Fail 与 Insufficient。

逐层绝对判据成立后，才进入 H2：检验 PCA 或其他方法冻结的前 $m$ 个方向能否保留大部分完整增益。

## 6. 会议已经形成的共识、尚未形成的结论

### 已形成的共识

- 研究最终面向逐层 Router，需要寻找适用于大量 token 的紧凑层特征；
- 跨层比较需要明确共同坐标或明确的同层物理坐标；
- 同一个 token 的变化应在总体聚合之前被保留；
- 对多维 token 坐标，应研究中心化后的完整协方差，而不只看每个方向的独立方差；
- PCA 负责寻找主要联合变化，聚类负责给 token 级点云分组；
- 每一步都必须对应一个明确、可否定的假设。

### 尚未形成、不能从会议直接推出的结论

- “每一层都产生新的任务相关信息”尚未被证明；
- 相邻完整层状态之差不自动等于当前 Attention 的新增信息；
- 最大方差主成分不自动是最有语义或最适合路由的方向；
- 稳定聚类不自动等于专家分区；
- 公共 MLP 参数基不自动是每层新增信息的共同基；
- 本次会议没有批准直接训练 Router，也没有完成低秩充分性检验。

---

## 7. dxy 的清晰口头复述

> 我们的最终目标没有变：希望对每一层找到一个低维空间，它不是简单承载这一层最大的变化，而是对这一层相对旧状态新暴露的任务区分最敏感，最后把这些坐标用于 Router。0813 我最后汇报的是，用各层 MLP 参数构造公共方向，再看各层 Attention 写入在这些方向上的方差。会议指出了两个问题：第一，应该先保留同一个 token 在写入前后的变化，而不是先分别汇总每层；第二，每个 token 在子空间里是一个多维向量，只看逐方向方差会丢掉方向间共同变化，所以才提出中心化协方差、PCA 和聚类。但这套方法最多发现低维、稳定的更新几何，不能单独证明它是新增信息。现在最先要验证的是：对一个具体目标，精确层更新能否在旧状态之外提供留出增益。这个问题通过后，我们才找保留该增益的最小子空间，再讨论 Router。

## 8. 思考自检

1. 我所说的“这层新增信息”，具体对应哪个 token、哪个 hook、哪个层操作？
2. 我关心的“差别”能否写成一个预先固定的目标，而不是看图后命名？
3. 旧状态已经能表达多少该差别？新增量怎样超过旧状态和匹配 null？
4. 协方差中的大方向是任务相关信号，还是位置、模板、尺度和粗粒度共同成分？
5. PCA 的前几个方向是否在新数据上保留完整更新的功能增益？
6. 聚类是否超过同维随机子空间，并在重采样后稳定？
7. 即使几何和读出成立，它是否真的改善专家效用，而不只是让离线分类器更容易读？

如果第 1—3 问尚未回答，就不应进入第 4—7 问。
