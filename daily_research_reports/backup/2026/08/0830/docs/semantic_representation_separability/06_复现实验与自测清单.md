# 复现实验与自测清单：怎样完整理解这轮工作

本文件中，线性探针（probe）是冻结 Qwen 表征后拟合的离线线性
分类器；原生门控层（Gate）是模型内部给专家打分的路由器；模型块
（Block）是 Qwen 的深度编号。E01/E02/E03 分别是单库迁移、双库
覆盖和 TAX-C4A 联合偏移实验。

## 先按这个顺序读

1. 先读 `01_结论先行_唯一问题与结果.md`，复述唯一问题和三层结论；
2. 再读 `02_实验四段式_数据探针与指标.md`，确认一条数据、token、层和 margin；
3. 对照 `03_图表逐张阅读_失败定位与旧实验对照.md`，手工读出两张 E02 主图；
4. 读 `04_理论认识更新_语义可分与映射.md`，解释为什么固定线性映射不能创造可分性；
5. 最后看规范 `summary.md` 和 `detailed.md`，核对聊天解释没有加强正式证据。

## 六、你能否回答这十个自测题

1. 为什么 C4E-B 与 C5E 不是“新事实”和“旧事实”的区别？
2. 为什么八个父类条件细类头不能替代全局 64 类头？
3. 第五百分位间隔大于零为什么不等于所有样本严格可分？
4. 为什么 E01 只能说 C4 边界跨 C5 失败，不能直接说 C5 不可分？
5. E02 哪三层明确区分了“边界迁移失败”和“C5 内部不可读”？
6. 为什么 Block 28 的 0.015 正间隔仍不能称为稳健？
7. 为什么不同训练条件的归一化间隔不能直接相减？
8. 为什么完整双库训练的改善不能只归因于表达覆盖？
9. 当前实验为什么不能证明 top-k 截断导致本轮的可分性损失？
10. TAX-C4A 失败后，为什么还不能只归因于“事实语义没有泛化”？

### 标准答案关键词

1. 同一六事实包、不同表达；2. 条件头提前知道父类；3. 只保护约 95% 位置；4. 可能存在另一条 C5 边界；5. Block 4、12、44；6. 同时下界、留一族和固定正则均不稳；7. 尺度不同；8. 同时多了数据；9. 取样位置在 Gate/top-k 之前；10. 长度和生成措辞也变化。

## 七、你最后应该能够用自己的话说出

> 我们没有发现“Qwen 没有语义”。我们发现的是：固定事实的语义在各表达库内部高度线性可读，但一套从单个表达库学到的线性边界不能稳定服务另一个库。首尾层以及 Block 12 最明确地表现出这种库条件边界；完整双库训练能在四层形成共同边界。下一步要用冻结探针测试另一组事实包，才能知道当前读出有多少是语义、多少是固定事实和生成器签名。
