# 结论先行：我们现在究竟知道表征有多可分

本文件中，混合专家模型（MoE）指由路由机制选择多个专家模块的模型；
路由器（Router）指给专家打分或选择专家的机制；模型块（Block）指
Qwen 的深度编号。E01 是单库边界迁移审查，E02 是表达库边界覆盖
对照，E03 是 TAX-C4A 新于探针事实包的联合偏移压力测试。

## 唯一问题

> 在 Qwen3-30B-A3B 的真实混合专家入口中，父类、父类内部细类和完整 64 个语义叶类，是否由一套不随表达方式改变的线性边界稳定读出？如果同一套边界失败，原因是目标表达库本身没有线性语义结构，还是两个表达库需要不同的线性边界？

这不是在问“2,048 维够不够高”，也不是在问“专家是否有用”。它只问：冻结表示以后，一个全空间线性读出究竟能访问多少语义，以及这套读出是否跨表达稳定。

## 一句话结果

> **当前表征明显包含语义，但语义的线性坐标与表达库发生了纠缠。库内几乎都能读，单库学得的边界跨库不稳；看过两个表达库并增加训练覆盖后，部分层能学到共同边界。**

最确定的层是 Block 4、12、44：C4 和 C5 各自在自己的训练—测试划分上都有同时校正后的正低尾下界，但 C4→C5 和 C5→C4 两个方向都未获得正下界。因此这三层可以明确称为“语义库内稳健可读，但线性边界受表达库条件影响”。

Block 20、28、36 的结论弱一层：C5 库内平均准确率仍约 99%，观测第五百分位间隔也为正，但同时下界跨过零。因此这些层既有跨库边界问题，也不能排除 C5 自己的困难样本低尾不够稳。

## 四个最重要的数字

| 证据 | 结果 | 它回答什么 |
|---|---:|---|
| E01 标签关联 | 120/120 单元通过 | 表征不是完全没有标签信息 |
| E01 C4 学、C5 测 | 6/6 层的最差任务观测间隔为负 | 一套 C4 边界不具备全层跨表达低尾稳健性 |
| E02 C5 学、C5 测 | 六层观测瓶颈全为正；同时下界 3/6 为正 | C5 内部高度可读，但中层低尾证据不够稳 |
| E02 四条件总表 | 22/48 个单元同时下界为正 | 这是跨四训练条件、两测试库、六层的总体证书数，不是“22/48 准确率” |

## 两次实验分别做了什么

### E01：一套边界能否直接跨库

只在 C4E-A 的 15 个完整模板族上训练 60 个探针，然后冻结，在 C4E-B 和 C5E 上测试。

- C4E-B：原注册判据下六层低尾下界均为正；
- C5E：六层都至少有一个任务的观测第五百分位间隔为负；
- 失败主要来自某个父类内部的细类，不是 64 类联合头独有的额外障碍。

E01 能说“C4 边界不跨 C5 稳定”，但当时不能说 C5 自己是否能被另一条线性边界读出。

### E02：C5 自己是否可读，两个库能否共享边界

E02 加入四种训练条件：只看 C4、只看 C5、双库但没有训练量优势、双库完整覆盖。两个测试面板固定为各自未参加训练的 B 半边。

| 训练条件 | C4B 正同时下界 | C5B 正同时下界 | 两边同时通过的层 |
|---|---:|---:|---|
| 只看 C4 | 5/6 | 0/6 | 0/6 |
| 只看 C5 | 0/6 | 3/6 | 0/6 |
| 双库匹配训练量 | 2/6 | 2/6 | Block 4、44 |
| 双库完整覆盖 | 5/6 | 5/6 | Block 4、12、20、44 |

“双库匹配训练量”有 896 条训练文本，略少于单库的 960 条，因此它没有样本量优势。它在 C5B 六层都比 C4 边界好，却在 C4B 多数层变差，说明模型学到的是一个折中边界，不是免费获得了全局不变性。

“双库完整覆盖”有 1,920 条训练文本。它恢复了更多共同边界，但同时改变了表达覆盖和训练量，所以不能把改善单独归因于“看过两个库”。

## 现在能不能说表征空间已经足够线性可分

不能给一个脱离条件的“能”或“不能”。正确答案要分三层：

1. **同库平均可读：能。**两个表达库自己训练、自己测试时，多数层和任务接近完美准确率。
2. **同库低尾稳健：部分能。**C4 很强；C5 的 Block 4、12、44 获得同时正下界，Block 20、28、36 只有正点估计而未获同时证书。
3. **一套线性 Router 跨表达稳定：当前不能。**任一单库训练的边界在另一个库六层都未获正同时下界。完整双库训练也只在四层同时通过。

因此，“表征有语义”和“表征已经足够供真实 Router 稳健使用”之间仍有逻辑断层。前者已被离线读出支持；后者还要求未见事实、Router 容量、原生 Gate 使用、专家效用和语言模型收益。

## 语义空间与表征空间的关系现在刻画到哪一步

### 已核验证据

- 相同父类、细类和联合标签能在冻结表示中被全空间线性函数高精度读出；
- 表达库变化会系统地改变哪一条线性边界最适合数据；
- 用数量相同但来自不同表达库的 960 条训练文本分别学习 C4 与 C5
  边界；从 C4 边界换成 C5 边界后，C5B 六层的原始单位瓶颈都显著
  提高，同时 C4B 六层都显著下降；
- 原子顺序重合排除不改变任何主符号，所以少数完全相同顺序不能解释结果。

### 最保守解释

语义不是缺失，而是和表达组织共同编码。我们目前观察到的是“库条件边界不兼容”，还没有直接测得一个几何旋转矩阵，也没有证明表达风格是唯一原因。

### 尚未知

- 换掉具体六条事实后，冻结边界是否仍能读出同一语义标签；
- 自然文本而非当前合成生成器是否复现；
- 低秩或有限参数 Router 是否能实现全空间探针；
- 原生 Gate 是否使用这些方向；
- 使用这些方向是否把 token 送到反事实上更有用的专家。

## 唯一下一步

E03 不再训练新探针，而是把 E01 的 60 个 C4 探针冻结，直接用于 TAX-C4A：每个语义叶类换成另一组六条事实。这样可以检查当前边界是否只是识别固定事实签名。

TAX-C4A 同时更长、措辞更不自然，因此：

- 通过：支持迁移到这一组新的事实包，但不能称为 Qwen 预训练未见事实的普遍泛化；
- 失败：只说明“新事实包 + 长度 + 措辞”的联合变化没有建立迁移，不能把原因只归于事实身份。

在 E03 完成前，不应直接进入核 Router 或表示塑形架构比较。

## 你需要记住的唯一认识更新

> **线性可分不是表征自己的单一属性，而是标签、事实、表达分布、表示位置、读出函数和稳健范围的联合关系。当前 Qwen 表征的语义在库内高度线性可读，但尚未形成一套对表达变化普遍稳定的线性坐标。**
