# 文献定位：这项表征审查与 X-MoE 有何不同，做到哪里才值得发表

本文件中，混合专家模型（MoE）指由路由机制选择多个专家模块的模型；
路由器（Router）指给专家打分或选择专家的机制；原生门控层（Gate）
指模型内部实际产生专家分数的 Router；线性探针（probe）指冻结表示后
拟合的离线线性分类器。E01/E02/E03 分别是单库迁移、双库覆盖和
TAX-C4A 联合偏移实验。

## 先给判断

> **E01/E02 本身是一项必要、方法上比二维可视化或单一准确率更严格的审计，但还不是一篇完整的 MoE 方法论文。真正值得发表的主张应是：发现“语义可读但跨表达边界不稳”的可复现瓶颈，并证明一个受控训练干预能够在未见事实和表达上改善低尾边界，继而改善原生路由的专家效用或语言模型目标。**

## 1. 与 X-MoE 的准确关系

[X-MoE](https://proceedings.neurips.cc/paper_files/paper/2022/hash/df4f371f1f89ec8ba5014b3310578048-Abstract.html) 研究送入稀疏混合专家路由器的 token 隐藏表示。其严格梯度事实是：普通点积 Gate 对隐藏表示的一部分反向梯度位于专家嵌入的线性张成空间；作者据此解释低维路由方向可能牵引表示。

X-MoE 的经验“表示塌缩比”使用

$$
\operatorname{Tr}(\Sigma_W\Sigma_B^\dagger),
$$

即类内协方差相对于类间协方差的比值。但论文没有在该公式附近明确给出定量计算时的 `class` 操作定义；图中按专家着色并不能替代严格定义。因此本轮没有直接复现这个数，也没有把“数越小越塌缩”的叙述搬到外部语义标签上。

如果类别是我们定义的语义类，较小的类内/类间散布比通常反而表示同语义更紧。E01 使用成对类距离归一化方差，只把它当失败定位，不让它裁定线性可分性。该指标的直接来源是 [Galanti 等人的类距离归一化方差](https://openreview.net/forum?id=SwIp410B6aQ)。

## 2. 为什么冻结线性读出仍是当前主工具

[Alain 与 Bengio 的线性探针](https://arxiv.org/abs/1610.01644) 冻结底层网络，只训练隐藏表征上的线性分类器。它最直接回答“该函数族能不能访问标签信息”，但不回答模型是否原生使用。

E01 比普通探针多了三层约束：

1. 训练模板族与评估模板族完整隔离；
2. 学得的头冻结后跨表达库迁移；
3. 除平均准确率外，要求最差任务的第五百分位几何间隔有正的同时下界。

在本文件列明并核验的一手来源中，本次检索未发现一项工作同时采用
“固定事实、表达库隔离、A 库拟合后 B/C 库不重拟合、全部层级任务、
低尾间隔”这一整套判据。这是候选方法学差异，不是穷尽性的新颖性
证明；它仍需系统综述、自然数据和不同事实包复制。

## 3. 当前结果最容易被什么替代解释

[Hewitt 与 Liang 的探针选择性控制](https://aclanthology.org/D19-1275/) 指出，高容量探针可能通过识别输入身份再记住任意标签映射。映射到本实验：每个细类只对应一组固定的六条事实，探针可能跨模板识别“事实或词汇签名”，再把它映射到标签。

当前固定预测标签置换只证明预测与真实标签关联，不等价于重新训练随机“事实身份→标签”控制。因此：

- 父类和局部细类以后可以增加事实身份选择性控制；
- 64 类联合任务本来就是 64 个固定事实叶的身份识别，随机双射只是重命名，不能构成干净控制；
- 最直接的补充不是再加一个几何指标，而是提取 `TAX-C4A` 的新事实表征。

## 4. 与原生 MoE 路由文献的关系

- [OLMoE](https://openreview.net/forum?id=xXTkbTBmqq) 统计专家被不同域或词项选中的频率。它测路由关联，受词频、域组成和负载约束影响，不等于专家功能。
- [Probing Semantic Routing in Large Mixture-of-Expert Models](https://aclanthology.org/2025.findings-emnlp.991/) 比较语义保持或改变时 top-$k$ 专家集合的重叠，最接近“同义表达是否走相似专家”；但它不测隐藏状态能否由一套冻结线性边界跨表达读出，也不测专家效用。
- [MoE-Embedding](https://proceedings.iclr.cc/paper_files/paper/2025/hash/aed2049f68827943dda5a63b7c4ba0a2-Abstract-Conference.html) 把多层路由权重连接成句向量，说明 Gate 输出含有可用语义信号；它没有固定事实和严格表达库隔离。
- [Tight Clusters Make Specialized Experts](https://proceedings.iclr.cc/paper_files/paper/2025/hash/854a9ab0f323b841955e70ca383b27d1-Abstract-Conference.html) 主动重加权特征空间以制造更紧的路由簇。它是一个路由干预，不是被动可分性指标。
- [Dikkala 等人的稀疏 MoE 理论](https://aclanthology.org/2023.emnlp-main.583/) 在分离高斯簇等假设下分析线性路由器与专家联合训练；这些分离条件是理论前提，不能反向证明冻结 Qwen 已满足。
- [KERN](https://www.microsoft.com/en-us/research/publication/understanding-the-mixture-of-experts-with-nadaraya-watson-kernel/)
  把 MoE 解释为 Nadaraya--Watson 核回归，并提出带归一化的核启发式
  Router。它已经占据“核函数式 Router”这一直接方向，因此只把线性
  Gate 换成核打分不足以构成本研究的新颖性。
- [Self-Routing](https://arxiv.org/abs/2604.00421) 直接把隐藏状态的指定
  子空间当作专家 logits，说明“让表征自己承担路由坐标”已有明确先例；
  但它不检查这些坐标的跨事实、跨表达低尾不变性。
- [Task-Conditioned Routing Signatures](https://arxiv.org/abs/2603.11114)
  从多层专家激活模式读出任务类别，属于路由关联和遥测证据，不是专家
  效用或隐藏表征边界证据。
- [RARE](https://arxiv.org/abs/2608.21236) 发现直接干预隐藏表征会引起
  路由漂移，并把行为扰动投影到 Router 矩阵零空间。它与“表示塑形如何
  保持或改变路由”直接相邻，因此未来干预不能只报告 probe margin，
  还要报告路由漂移和功能结果。

这些工作共同支持一个边界：隐藏表示可读、原生 Gate 路由一致、专家形成专门功能、反事实专家效用和最终语言模型收益是五个不同问题。

### 4.1 与“专家效用监督”最接近的工作

截至本次 2026-08-30 的检索，“显式探索替代专家路径”已经不是空白
方向。以下工作直接压缩了我们未来方法的新颖性空间：

- [Exploration-Driven Reinforcement Learning](https://aclanthology.org/2025.findings-emnlp.1282/)
  随机扰动一部分路由决策，以原路径和扰动路径的性能差作为强化学习
  优势信号。它已经建立“探索替代路径来训练 Router”这一方法类别。
- [When Are Experts Misrouted?](https://arxiv.org/abs/2605.07260)
  在相同计算量下采样替代 top-$k$ 路径，用真实下一 token 的损失比较
  路径效用，并只更新最后一层 Router。它与我们所说的“反事实专家效用
  监督”最直接重合；因此仅仅提出“比较替代专家，再监督 Router”已经
  不是足够的新颖点。
- [Coupling Experts and Routers via an Auxiliary Loss](https://openreview.net/pdf/f35d79e4a919763a2377dddb70c73ffb1617a468.pdf)
  用 Router 向量构造代理 token，再约束对应专家对自身代理的激活高于
  其他专家。它在 ICLR 2026 已发表，属于低开销的 Router—expert 能力
  耦合，但代理激活不等同于逐 token 的反事实语言模型效用。
- [Awakening Dormant Experts](https://arxiv.org/abs/2604.14246)
  用虚拟消融定义反事实专家影响，并在固定激活预算下进行训练外推理
  重路由；它更接近“因果专家作用”，但目标集中在长尾事实幻觉。
- [Beyond Routing](https://arxiv.org/abs/2608.08853)
  固定已选专家集合，只改变集合内聚合，发现 Router 分数与已选专家的
  反事实效用几乎不对齐。这说明“选谁”和“如何给已选专家加权”是两个
  可以独立失败的对象。

这些论文的共同启示不是“本方向已经做完”，而是我们必须把贡献收窄并
做强：**新颖性不能只来自效用标签，而要来自被本轮审计明确识别的
“表征边界不变性—有限预算访问—反事实效用”闭环。**本研究仍可形成
差异化贡献的地方，是检验跨事实、跨表达稳定的语义坐标是否会提高
效用监督的样本效率、低尾可靠性和分布外迁移；上述工作没有替我们建立
这条因果链。

## 5. 哪些额外指标值得用，哪些不应喧宾夺主

| 指标 | 当前角色 | 原因 |
| --- | --- | --- |
| 冻结跨库线性探针 + 低尾几何间隔 | 主判据 | 直接检查同一边界的跨表达可访问性 |
| 成对类距离归一化方差 | 失败定位 | 描述类内散布相对类中心距离，不寻找最优判别方向 |
| 权重奇异谱 | 描述 | 没有注册 Router 秩预算，不能证明低秩充分 |
| X-MoE 协方差比 | 暂不加入 | 类定义与语义标签解释不同，全局伪逆不利于定位 |
| Fisher 判别比 | 当前不加入 | 2,048 维远大于局部训练样本，类内协方差奇异，结果依赖未注册正则化 |
| 在线最短描述长度 | 未来样本效率诊断 | 测学会读出需要多少标签，不替代跨表达边界 |
| 表征流形容量 | 低优先级 | 测随机二分总体容量，不直接测注册的 8/64 类语义划分 |

## 6. 发表价值的三道门

### 门一：现象必须脱离固定事实和单一生成器

至少完成：

- `TAX-C4A` 新于探针的事实包联合偏移面板，并继续拆出事实、长度和措辞对照；
- 一个自然语义层级数据集；
- 至少一个第二模型或更多层复制；
- 事实身份随机控制。

若现象只存在于 64 个固定合成事实上，它适合作为内部机制诊断，不足以承载强语义主张。

### 门二：提出能被证伪的机制，不只是指标大全

最有潜力的机制是：

> 语义标签在各表达库内都可线性读出，但表达组织方式给隐藏状态加入了沿判别方向的系统偏移；训练覆盖不足导致 Router 学到库条件边界，而不是稳定语义边界。

它的最小预测是：库内探针成功、双向迁移受限、合并库训练能改善共同边界。E02 已支持前两项，但只部分支持第三项：没有样本量优势的双库训练只在 Block 4、44 同时稳健，并且表现为改善 C5、牺牲 C4 的折中；完整双库训练在 Block 4、12、20、44 形成共同证书，但同时增加了训练量。因此当前机制只能收紧为“训练库组成会改变匹配哪一侧的边界，而完整双库联合条件在部分层建立共同证书”；表达覆盖、样本量及其交互的贡献尚未拆开。

### 门三：干预必须进入功能结果

可发表的 MoE 方法最终至少需要一个匹配比较：

$$
\text{标准线性 Router}
\quad\text{vs.}\quad
\text{表达不变表示塑形 + 同容量 Router}.
$$

两者固定模型规模、活动专家数、候选前向、token 预算和训练算力。先检查未见事实/表达的低尾间隔，再检查原生路由的负载、专家反事实效用和验证集语言模型损失。只有几何变好而功能不变，仍不能称为更好的 MoE。

## 7. 推荐的唯一下一步

E02 已结束，仍不立即设计核 Router。先为 `TAX-C4A` 提取同一 Qwen3-30B 六层真实 Gate 输入，把 E01 已冻结的 C4E-A 探针原样应用到新事实面板：

- C4E-B 通过、TAX-C4A 失败：只建立该联合偏移上的迁移失败；事实包、
  长度和措辞仍需继续拆分，不能直接判为固定事实/词汇签名；
- TAX-C4A 通过、C5E 失败：支持冻结边界迁移到这一项事实包、长度和
  措辞联合面板，却不迁移到 C5E；它提示不同偏移的影响不同，不能干净
  归因于事实或表达中的单一因素；
- 两者通过：才支持更强的事实—表达双重语义不变性。

这一步改变核心判断，且不需要先引入新的 Router 容量，因此优先级高于核函数、更多聚类指标或大规模架构训练。

## 理解检查

如果一个新方法让语义探针的低尾间隔变正，但原生路由的专家反事实效用和验证损失都没有改善，它最多建立了哪一层证据，为什么还不能称为更好的 MoE？
