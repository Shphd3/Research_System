# 实验二：跨层新增信息的参数谱位置、表征低秩性与 token 几何

本文先解释实验二的方法，再在第十节给出 2026-08-16 已完成的全层结果。

## 一、先确定我们到底想回答什么

实验一回答：

> 哪些层的 $R_{U,\ell}$ 在同一个旧状态 $X_\ell$ 之外，确实增加了 conditional-fine 的留出可访问性？

实验二的核心不是单独证明某一层低秩，而是比较不同层的新增信息。它接着回答：

> 不同层的 $R_{U,\ell}$ 增加了多少 conditional-fine 可访问性，它在本层 MLP 参数谱和冻结公共参数谱的什么位置激活，以及其 token 更新点云是否由稳定低维表征承载？

这句话有两个不能混淆的部分：

1. **表征低秩：**所有 token 的更新点云是否主要分布在少量方向上。
2. **功能保留：**这些少量方向是否保留了实验一验证的细类功能增益。

因此要把同一个 $R_{U,\ell}$ 放进三种分析坐标，并与一条功能曲线并列：

- **功能曲线 $T_\ell$：**不同层到底增加了多少目标相关可访问性；这是“新增信息”的主判据。
- **本层 MLP 参数谱：**更新在该层自身的强响应到弱响应参数方向中，哪个等秩能量带最大、谱质心在哪里。
- **冻结公共参数谱：**所有层用同一组参数方向和同一排序，检验更新能量位置是否随深度后移。
- **token-level 协方差空间：**用 $r_{80,\ell}^{rep}$、effective rank、CKA 和聚类比较点云紧凑性、跨层几何和群组结构。

原假设必须拆成两个可分别失败的陈述：

1. 随层加深，功能净收益 $T_\ell$ 整体增大；
2. 随层加深，$R_{U,\ell}$ 在冻结公共参数谱中的归一化能量位置整体后移。

只有两者同时成立，才支持“新增细类可访问性随深度增强，并在参数响应谱上后移”。只看到后移不能证明新增信息增加；只看到功能增强也不能证明其由更后参数谱承载。

我们不预设越深越好，也不只挑最好的一层。正式产物必须保留所有合格层的完整曲线和层—层矩阵。

一个空间可以很低维，却只承载模板、长度或尺度变化；它也可以保留分类功能，但只是受八分类标签自由度限制的任务方向。因此实验二必须同时报告表征几何和功能保留，但不能把两者合并成一个未经解释的“低秩”。

## 二、为什么组会会提出协方差、PCA和聚类

组会之前的方法是：把每层 Attention write 投到约 500 个参考方向，然后分别计算 500 个方向上的方差。

这个方法丢掉了两类信息：

1. 没有先看同一个 token 在本层写入前后发生了什么；
2. 把一个 token 的多维更新拆成了很多互不相关的标量，没有保留方向之间怎样一起变化。

因此组会给出的修正顺序是：

```text
同一个 token 的精确更新
→ 把所有 token 的更新放在一起
→ 中心化并计算完整协方差
→ PCA 找主要联合变化方向
→ 在 PCA 坐标中分析或聚类每个 token
```

这里：

- 协方差解决“多个方向是否一起变化”；
- PCA解决“联合变化能否由少量方向概括”；
- 聚类解决“低维空间里的 token 是否形成群组”。

它们都不能单独证明这些变化是旧状态之外的新增信息。新增性仍由实验一的同一 $X$ 留出功能增益裁定。

### 组会汇报原路线对实验二的具体启发

组会汇报中其实有两条相关分析线：

1. **公共参数基上的逐方向方差与 rank centroid。**它给不同层一把共同坐标尺，并观察 coarse/fine 方差在谱位置上的差别；但它主要保留逐方向方差，没有保留方向之间的完整联合变化，而且“平均更靠后”不等于每层新增信息更强。
2. **CCA 的 common predictable / common update / attention private 分解。**它尝试把 layer input 与 Attention output 的相关部分分开，并检查这些成分的 domain 可读性；这帮助我们意识到“输入可预测部分”和“Attention 额外写入部分”必须区分。但 domain 可读性很高仍不等于旧状态之外的 conditional-fine 新增增益，也不等于表征低秩。

当前实验二继承的是这两条线的核心问题，而不是直接继承其结论：

- 用 $R_U$ 代替没有严格功能门的“common update”；
- 保留本层 MLP 谱和冻结公共参数谱，专门描述候选新增更新落在参数几何的哪里；
- 再用完整 covariance/PCA 补上逐方向谱能量没有保留的跨方向联合变化；
- 用 CKA 比较不同层 token 几何，不把公共参数基中的同 rank 误当成同一语义；
- 最后用同一 $X$ 的功能保留检查给几何加上任务边界。

## 三、实验对象：每层同一个 token 的 $R_U$

对第 $\ell$ 层同一个 decision token：

$$
X_\ell=N_\ell(h_\ell),
\qquad
Z_\ell=N_\ell(h_\ell+a_\ell),
$$

$$
U_\ell=Z_\ell-X_\ell,
\qquad
R_{U,\ell}=U_\ell-\widehat{\mathbb E}_{lin}[U_\ell\mid X_\ell].
$$

白话解释：

- $X_\ell$：本层 Attention 还没写入时，这个 token 交给 MLP 的反事实旧状态。
- $Z_\ell$：本层 Attention 写入以后，模型实际交给 MLP 的状态。
- $U_\ell$：本层 Attention 对 MLP 输入造成的精确变化。
- $R_{U,\ell}$：把旧状态在线性意义下已经能够预测的更新去掉以后，剩下的候选更新。

实验二分析的不是完整层状态，也不是 $H_{\ell+1}-H_\ell$，而是每层、每个 token 的 $R_{U,\ell}$。

## 四、为什么要在父类内部中心化

我们关心的是已知 mathematics 后，combinatorics 与 linear algebra 等 child 之间的差别。

如果直接把所有父类混在一起做 PCA，最大的方向可能只是 mathematics 与 medicine 的粗类差别。于是对父类 $p$ 的 token，减去该父类的 TRAIN 均值：

$$
\widetilde R_{\ell,i}
=R_{U,\ell,i}-\mu^{tr}_{\ell,p(i)}.
$$

白话说：

> 先把“它们都属于数学”这一共同平移去掉，再看数学内部不同 token 怎样变化。

只减父类均值，不减 child 均值。因为 child 中心之间的差别正是我们需要保留的 conditional-fine 对象。

## 五、同一个 $R_U$ 的三种分析空间

### 1. 本层 MLP 参数谱：看“本层自己最响应哪里”

每层用自己的 MLP gate/up 输入侧参数构造

$$
K_\ell=W_{gate,\ell}^{\top}W_{gate,\ell}
+W_{up,\ell}^{\top}W_{up,\ell}
=B_\ell\Gamma_\ell B_\ell^\top,
$$

并按特征值从大到小排列方向。前 rank 表示本层 MLP 参数响应强，后 rank 表示响应弱。将 $\widetilde R_{\ell,i}$ 投到 $B_\ell$，把 4096 个方向预先分成 16 个等秩带，计算每带更新能量：

$$
E^{local}_{\ell,b}
=\sum_{j\in b}\operatorname{Var}_i
\left(b_{\ell,j}^{\top}\widetilde R_{\ell,i}\right).
$$

最大谱能量带 $b^{max}_\ell=\arg\max_b E^{local}_{\ell,b}$ 的白话含义是：

> 在这层自己的 MLP 参数尺子上，token 更新变化最集中地落在哪一段。

但每层 $B_\ell$ 都不同，所以“第 10 带”只能比较相对谱位置，不能说两层使用同一组方向。

### 2. 冻结公共参数谱：看“用同一把尺子是否后移”

主公共尺子沿用既有 Mean Response 定义：先对各层 $K_\ell$ 做 trace 归一化并平均，再特征分解：

$$
\overline K=\frac1L\sum_{\ell=1}^{L}
\frac{K_\ell}{\operatorname{tr}(K_\ell)}
=B^{MR}\Lambda^{MR}(B^{MR})^\top.
$$

所有层都投到同一个 $B^{MR}$，因此可以比较相同参数方向与相同 rank。既有 Rank Consensus 公共基作为敏感性对照：若只有 Mean Response 后移，就只能说结果依赖这把公共尺子，不能说存在基不变的公共谱后移。

对 local 或 common 视角，原始总能量另行保留；再把方向能量归一化为 $p_{\ell,j}$，计算谱质心：

$$
C_\ell=\sum_j p_{\ell,j}\rho_j,
\qquad \rho_j\in[0,1].
$$

$C_\ell$ 越大，表示相对能量位置越靠后。“最大能量带”用于直观展示；谱质心和预注册后段能量份额用于正式判断，因为相邻两带能量接近时，argmax 会因很小噪声突然跳带。原始总能量可以说更新幅度变大或变小，但仍不能替代 $T_\ell$ 的功能新增判据。

### 3. token-level 协方差空间：看“点云自身怎样组织”

这一空间不按 MLP 参数响应排序，而直接从 token 更新点云的完整协方差中学习 PCA 方向。它回答低秩、跨层几何和聚类问题。参数谱视角与 token 视角不能互相替代：前者说更新落在参数几何哪里，后者说更新本身由多少联合变化方向组织。

### 4. 原深度假设怎样正式比较

`AI_PROPOSAL`：在 Protocol 中预先冻结浅层集合 $\mathcal E$ 和深层集合 $\mathcal D$，并同时计算

$$
\Delta_T=\operatorname{median}_{\ell\in\mathcal D}T_\ell
-\operatorname{median}_{\ell\in\mathcal E}T_\ell,
$$

$$
\Delta_C^{common}
=\operatorname{median}_{\ell\in\mathcal D}C_\ell^{common}
-\operatorname{median}_{\ell\in\mathcal E}C_\ell^{common}.
$$

完整逐层曲线仍是主展示，窗口差只把“随深度增强/后移”变成一个不靠肉眼挑层的总体统计。$\Delta_T>0$ 检验功能增强，$\Delta_C^{common}>0$ 检验公共谱后移；二者使用同一重采样单位和同时区间，但分别给 verdict。本层 MLP 最大能量带与质心作为机制侧支持，不作为跨层同方向身份证明。

## 六、关键名词的白话解释

### 1. token 更新点云

每个 token 的 $\widetilde R_{\ell,i}$ 是一个 4096 维点。把同一层全部 token 放在一起，就形成一个高维点云。

“表征低秩”可以想成：

> 虽然每个点写成4096个数字，但所有点实际主要躺在一张很薄的低维纸面上，而不是占满整个4096维空间。

### 2. 协方差矩阵

把所有 token 行堆成矩阵 $M_\ell$：

$$
M_\ell=
\begin{bmatrix}
\widetilde R_{\ell,1}^\top\\
\vdots\\
\widetilde R_{\ell,n}^\top
\end{bmatrix}.
$$

协方差为

$$
C_\ell=\frac{1}{n-P}M_\ell^\top M_\ell.
$$

协方差的对角线是每个坐标自己变化多大；非对角线是两个坐标是否经常一起增大或一起减小。

白话说：

> 逐方向方差只看每个乐手声音多大，完整协方差还看哪些乐手经常同时演奏。

### 3. PCA

PCA把原来的4096个坐标重新组合成一组新的正交方向，并按照 token 点云在这些方向上的变化量从大到小排序。

$$
C_\ell=V_\ell\Lambda_\ell V_\ell^\top,
\qquad
\lambda_{\ell,1}\ge\lambda_{\ell,2}\ge\cdots.
$$

- $V_\ell$：新的方向。
- $\lambda_{\ell,j}$：第 $j$ 个方向承载多少更新方差。

PCA的目的不是直接寻找语义，而是回答：

> 这层 token 更新最主要的联合变化能否被少量方向概括？

PCA只优化总方差。最大的主成分可能是模板、位置或尺度，所以还要做留出稳定性与功能保留检查。

### 4. 80%方差秩 $r_{80}^{rep}$

$$
r_{80,\ell}^{rep}
=\min\left\{r:
\frac{\sum_{j=1}^{r}\lambda_{\ell,j}}
{\sum_j\lambda_{\ell,j}}
\ge0.8
\right\}.
$$

白话说：

> 至少需要多少个 PCA 方向，才能装下这层 token 更新总变化的80%？

$r_{80}^{rep}$ 越小，点云能量越集中。但因为样本只有 $n$ 个，即使隐藏维度为4096，样本协方差最多也只能识别约 $n-P$ 个方向，所以必须报告

$$
\frac{r_{80}^{rep}}{n-P},
$$

不能因为 $n<4096$ 就把天然不满秩误叫成模型低秩。

### 5. effective rank

effective rank 不只问达到80%需要多少维，还综合整条特征值分布：

$$
r_{eff,\ell}^{rep}
=\exp\left(-\sum_jp_{\ell,j}\log p_{\ell,j}\right),
\qquad
p_{\ell,j}=\frac{\lambda_{\ell,j}}{\sum_k\lambda_{\ell,k}}.
$$

白话说：

> 如果把方差当作财富，effective rank 衡量这些财富相当于平均分给了多少个有效方向。

一个方向几乎拿走全部方差时，effective rank 接近1；很多方向比较平均时，它会变大。

### 6. 冻结的 PCA 子空间

只用 TRAIN 求出 PCA 方向并确定前 $r$ 维，然后原样应用到 DEVELOPMENT 和 CONFIRMATION。

不能在每个 split 上重新做 PCA，因为那相当于考试时重新寻找最有利的方向。

冻结 TRAIN projector：

$$
P_{\ell,r}=V_{\ell,r}V_{\ell,r}^\top.
$$

在留出 split $s$ 上的方差保留率为

$$
V_{\ell,r}^{s}
=\frac{\operatorname{tr}(P_{\ell,r}C_\ell^{s})}
{\operatorname{tr}(C_\ell^{s})}.
$$

白话说：

> TRAIN 找到的这张“低维纸面”，换一批不同措辞的 token 后，它们是否仍然大体躺在同一张纸面上？

### 7. CKA

CKA 是 Centered Kernel Alignment，可译为“中心化相似结构对齐”。它用来比较两个层的 token 几何是否相似。

CKA不是逐方向比较。它先在每层问：

> token A 与 token B 有多相似？token A 与 token C 有多相似？

对同一批、同一顺序的 token，构造 token—token Gram 矩阵 $G_\ell$（字母 $K_\ell$ 已专门表示 MLP 参数算子）：

$$
G_\ell=M_\ell M_\ell^\top.
$$

然后比较两层中心化后的 Gram 矩阵：

$$
CKA(\ell,m)
=\frac{\langle HG_\ell H,HG_mH\rangle_F}
{\|HG_\ell H\|_F\,\|HG_mH\|_F}.
$$

白话例子：

> 假设两位老师用不同坐标给同一批学生画像。第一位用“代数—几何”，第二位把坐标旋转成“抽象—计算”。虽然坐标轴名字不同，但如果两位老师都认为学生甲和乙相似、甲和丙差异大，那么两套学生关系图仍然相似，CKA就高。

CKA高表示两层对 token 之间相对关系的判断相近；CKA低表示 token 几何发生明显变化。

在线性、中心化且数值正常的设置下，CKA通常位于0到1之间：接近1表示两层的整体 token 相似关系高度一致，接近0表示两套关系图几乎不对齐。它没有一个通用的“超过多少就算同一阶段”阈值，因此正式分析应报告完整热力图、重采样区间和相邻层变化，而不是事后画一条任意分界线。

CKA的作用：

- 不需要公共参数基；
- 不需要把第 $j$ 个 PCA 方向与另一层第 $j$ 个方向硬配对；
- 可以画36×36热力图，观察哪些层形成相似阶段；
- 可以看相邻层 CKA 是否突然下降，定位表征几何转折。

CKA不能说明：

- 这一层是不是低秩；
- 哪个具体方向负责某个 child；
- 是否存在新增功能；
- Router是否有效。

此外，CKA必须使用完全相同、完全同序的 token，并先完成同样的父类内中心化，否则样本错位或粗类结构会制造假差异。

### 8. CCA与CKA不是同一个方法

组会汇报图中出现的是 **CCA（Canonical Correlation Analysis，典型相关分析）**。CCA输入两组变量，例如 layer input 和 Attention output，分别寻找一组线性组合，使两组组合后的相关性最大。它适合回答：

> Attention output 中哪些成分与 layer input 高度相关，哪些成分相对更“private”？

本实验补充的 **CKA（Centered Kernel Alignment）** 不去学习两组最佳线性组合，而是直接比较两层在同一批 token 上形成的相似关系矩阵。它适合回答：

> 第 $\ell$ 层和第 $m$ 层是否以相似方式区分这些 token？

简单区分：

- CCA：在两个表征之间找“最相关的方向”；
- CKA：比较两个表征的“整体 token 关系图”是否相似。

因此，CCA更接近组会汇报中的输入—Attention 成分分解；CKA则服务我们现在的核心目标——比较不同层新增更新的整体几何。

### 9. Haar 同秩随机空间

Haar 空间可以理解为：在4096维空间中随机抽一张同样维数的、方向没有任务偏好的正交子空间。

它回答：

> PCA 前 $r$ 维真的比任意 $r$ 维空间更能保留功能，还是只要给读出器 $r$ 个维度就够了？

### 10. 坐标独立置乱 null

对每个坐标分别打乱 token 行，保留每个坐标自己的数值分布，但破坏不同坐标在同一个 token 上共同变化的关系。

它回答：

> 真实点云的低秩集中是否来自跨坐标联合结构，还是有限样本与各坐标边际方差本身就会产生相似谱？

### 11. k-means、ARI和NMI

k-means 在 PCA 坐标中把 token 分到距离最近的中心。当前按父类分别设 $k=8$，因为每个父类有8个 child。

- ARI：聚类分组与真实 child 分组的一致程度，并校正随机一致。
- NMI：聚类身份与 child 身份共享多少归一化信息。

聚类中心只用 TRAIN 拟合，然后冻结并分配 DEVELOPMENT/CONFIRMATION token。

聚类回答“token 更新是否自然成组”，不回答这些组是不是专家，也不进入低秩主 verdict。

## 七、完整分析步骤及每一步目的

| 步骤 | 做什么 | 直接目的 | 防止什么误解 | 主要输出 |
|---|---|---|---|---|
| 1. 固定对象 | 复用实验一全部层的 $X,Z,U,R_U$，验证同 token、同 hook、同 normalization | 确保分析的是本层精确更新 | 把完整层差或错误 hook 当作新增量 | 每层身份与重建 guard |
| 2. 固定数据 | 三个 split 讲同一 child 概念，但表达、模板和内容组合互斥 | 检验跨措辞泛化 | 读出器或 PCA 记住模板 | split manifest 与重复检查 |
| 3. 父类内中心化 | 每个 token 减去 TRAIN 父类均值 | 聚焦父类内部 child 差别 | PCA主要反映 mathematics 与 medicine 等粗类差别 | $M_\ell^{tr/dev/conf}$ |
| 4. 本层 MLP 谱投影 | 每层用自身 $K_\ell$ 特征向量投影 $R_U$，计算16带能量、最大带和质心 | 看本层更新主要激活该层参数响应谱的哪一段 | 把本层 rank 当成跨层同一方向 | local 能量图、$b_\ell^{max}$、$C_\ell^{local}$ |
| 5. 公共参数谱投影 | 所有层投到冻结 Mean Response；Rank Consensus 作敏感性对照 | 用同一把参数尺子检验谱位置是否随深度后移 | 用单一基的后移冒充基不变规律 | common 能量图、$C_\ell^{common}$、$\Delta_C$ |
| 6. 功能—谱联合趋势 | 将全层 $T_\ell$ 与公共谱质心曲线并列，预注册浅深对比 | 分别检验新增功能增强和参数谱后移 | 用谱后移替代功能新增 | $\Delta_T$、$\Delta_C$ 及类型化 verdict |
| 7. 计算完整协方差/SVD | 保留方向间联合变化 | 描述每层 token 更新点云形状 | 只看逐方向方差、丢掉非对角信息 | 特征值谱与 PCA 方向 |
| 8. 测表征秩 | 算 effective rank、$r_{80}^{rep}$、stable rank并按 $n-P$ 归一化 | 判断更新能量是否集中 | 把有限样本天然不满秩叫低秩 | 全层秩轨迹 |
| 9. 做几何 null | 与逐坐标独立置乱谱比较 | 检查联合结构是否超出有限样本基线 | 任意小样本矩阵都看起来低秩 | null 分布与真实差值 |
| 10. 检验跨表达稳定 | TRAIN 冻结 PCA，直接投影 DEV/CONF | 判断低维空间是否可复现 | TRAIN 模板或抽样偶然性 | 留出方差保留率 |
| 11. 用 CKA 跨层比较 | 比较同序 token Gram 矩阵 | 直接比较不同层新增更新的 token 几何、识别相似阶段和转折 | 强行用公共参数基配准主成分 | CKA热力图与相邻层曲线 |
| 12. 检验功能保留 | 对所有层、所有注册秩投影 $R_U$，重新计算同一 $X$ 增益 | 判断低维空间是否保留实验一功能 | 把高方差误当作细类功能 | rank—gain retention曲线 |
| 13. 同秩随机对照 | PCA子空间与同秩 Haar 比较 | 排除“只要给 $r$ 维就行” | 维数容量冒充方向选择 | PCA超过Haar的增益 |
| 14. token 聚类 | 在冻结 PCA 坐标中按父类做 $k=8$ 聚类 | 检查更新是否形成稳定细类群组 | 把协方差或PCA直接当作分组结果 | ARI、NMI、重采样稳定性 |
| 15. 联合解释 | 分开报告功能、参数谱位置、低秩与功能保留，再做交叉判定 | 得到具名层的完整新增信息画像 | 用任意单张好看的图决定结论 | 全层四维画像与类型化结论 |

## 八、怎样把表征低秩和功能保留联系起来

对每层、每个预注册秩 $r$，将更新投影到 TRAIN PCA 子空间：

$$
R_{U,\ell}^{(r)}=P_{\ell,r}R_{U,\ell}.
$$

使用实验一完全相同的旧状态 base，计算投影更新带来的增益：

$$
G_{\ell,r}^{PCA}.
$$

与完整更新比较：

$$
D_{\ell,r}^{func}
=G_{\ell,r}^{PCA}-0.8G_{\ell,full}.
$$

白话说：

> 如果完整更新值100分，前 $r$ 个 PCA 方向至少能否保留80分？

必须对所有层和候选秩提前计算，不能先看实验一哪些层为正，再只为这些层挑最有利的秩。最后只有同时满足以下条件的层才能被称为“任务相关低维候选层”：

1. 完整 $R_U$ 在实验一中超过同一 $X$ 的匹配对照；
2. 更新点云的表征秩相对可识别上限足够小；
3. TRAIN PCA 在表达互斥的两个留出 split 上稳定；
4. 少量 PCA 方向保留至少80%完整增益；
5. 该功能保留超过同秩 Haar。

## 九、结果出现后怎样解释

先对原“随深度增强并谱后移”假设作独立判定：

| $\Delta_T$：功能随深度增强 | $\Delta_C^{common}$：公共谱后移 | 允许结论 |
|---|---|---|
| 是 | 是 | 支持“conditional-fine 新增可访问性整体增强，并在该冻结公共参数谱中后移” |
| 是 | 否 | 功能增强，但没有证据表明由更后参数谱承载 |
| 否 | 是 | 发生参数谱能量重分配，但不能称为新增信息随深度增加 |
| 否 | 否 | 当前对象和尺度下不支持原深度—谱后移假设 |

若 Mean Response 为正而 Rank Consensus 没有通过同一个正向判据，结论必须加上“basis-sensitive”；本层谱只显示相对位置趋势，不能修复公共谱不一致。

| 功能新增 | 表征低秩且稳定 | 低维功能保留 | 允许结论 |
|---|---|---|---|
| 是 | 是 | 是 | 存在具名层，其新增细类可访问性由稳定低维表征保留，可进入后续 Router 候选验证 |
| 是 | 否 | 否或不确定 | 新增细类可访问性存在，但表征较分散；不应强行压缩成低秩空间 |
| 是 | 是 | 否 | 更新几何低秩，但主要 PCA 方向没有保留新增细类功能；低秩可能由 nuisance 主导 |
| 否 | 是 | 不具备解释资格 | 存在低秩更新几何，但不能称为新增细类信息 |
| 否 | 否 | 否 | 当前对象、任务和线性方法下，没有得到功能或低秩证据 |
| 任意 | TRAIN是、留出否 | 任意 | 表面低秩可能是模板或有限样本过拟合，判为证据不足 |

CKA与聚类只帮助解释结构：

- CKA出现分块：可以描述模型层之间存在若干 token 几何阶段；不能直接说深层学会了新知识。
- 相邻层 CKA突然下降：说明 token 更新关系在此处发生转折；需要结合功能曲线判断是否与新增细类可访问性一致。
- 聚类稳定且child富集：说明低维点云包含细类分组结构；仍不能称为专家分区。
- 聚类不稳定：不否定连续低维空间，只说明它未形成清晰离散群组。

## 十、按照汇报模板写出的实验二

### 实验二：

**实验目的：**

比较不同层同一个 token 的候选新增更新 $R_{U,\ell}$：先检验 conditional-fine 功能净收益是否随深度增强，再分别观察它在本层 MLP 参数谱和冻结公共参数谱中的能量位置是否后移，最后分析 token 更新点云的表征秩、跨层几何和低维功能保留。实验二区分“功能新增”“参数谱位置”和“token 表征低秩”，任何一种几何现象都不能替代功能 verdict。

**实验对象：**

对每层 $\ell=1,\ldots,36$，使用实验一同一 decision token 的

$$
R_{U,\ell}=U_\ell-\widehat{\mathbb E}_{lin}[U_\ell\mid X_\ell].
$$

对每个 token 减去其 TRAIN 父类均值：

$$
\widetilde R_{\ell,i}=R_{U,\ell,i}-\mu^{tr}_{\ell,p(i)}.
$$

$\widetilde R_{\ell,i}$ 表示去掉父类共同平移以后，该 token 在本层的候选更新。每层所有 token 的 $\widetilde R_{\ell,i}$ 共同构成要分析的更新点云。

**实验数据：**

复用实验一的父类—子类数量平衡 conditional-fine taxonomy。TRAIN、DEVELOPMENT、CONFIRMATION 表达互斥：三个 split 讲同一父类—child 概念，但具体措辞、模板家族和内容组合不同。所有 split 保持相同的8个父类、每父类8个 child和同一个 decision token；同一批样本在所有层中保持完全一致的顺序。

**实验过程：**

1. 复用实验一提取的全层 $R_{U,\ell}$，验证样本、token、hook和层身份一致。目的：保证比较的是同一个 token 的本层更新，而不是两个完整层状态的混合差。
2. 在每层按父类减去 TRAIN 父类均值。目的：去掉父类共同成分，只分析父类内部 child 相关及其他 token 变化。
3. 将每层更新投到该层 $K_\ell$ 的本地参数谱，计算16个等秩带的能量、最大能量带和谱质心。目的：判断更新相对本层 MLP 强—弱响应方向主要落在哪里；不同层本地 rank 只比较相对位置，不解释为同一方向。
4. 将所有层投到冻结 Mean Response 公共参数谱，并用 Rank Consensus 检查基敏感性；报告全 rank 能量曲线、最大能量带、谱质心和预注册后段份额。目的：用同一把参数尺子检验更新能量位置是否随深度后移。
5. 将公共谱质心曲线与实验一全层 $T_\ell$ 并列，并计算预注册浅层—深层差。目的：分别判定“新增功能增强”和“参数谱后移”，只有二者同时成立才支持原联合假设。
6. 只用 TRAIN 对每层的父类内中心化更新计算完整协方差或等价 SVD，并得到 PCA 特征值和方向。目的：保留多个坐标怎样联合变化，而不是只看逐方向方差。
7. 计算每层 effective rank、80%方差秩和归一化秩，画出全层表征秩曲线；同时与逐坐标独立置乱 null 比较。目的：比较各层候选新增更新的紧凑程度，并判断低秩集中是否超过有限样本基线。
8. 冻结 TRAIN PCA 子空间，直接投影 DEVELOPMENT 和 CONFIRMATION，计算留出方差保留率。目的：判断低维结构能否跨不同表达复现。
9. 对同一批 token 的每两层更新计算 linear CKA，绘制36×36热力图和相邻层曲线。目的：不依赖参数基，直接比较不同层新增更新的 token—token 几何是否相似，并定位层级阶段和转折层。
10. 对所有层和预注册秩，将 $R_U$ 投到 TRAIN PCA 前 $r$ 维，并沿用实验一同一 $X_\ell$ base 重新计算交叉熵增益；与 full-$R_U$ 和同秩 Haar 比较。目的：检查少量 PCA 方向是否保留至少80%的完整功能增益。
11. 在冻结 PCA 坐标中按父类分别做 $k=8$ 聚类，并在留出 split 上报告稳定性、ARI和NMI。目的：辅助判断 token 更新是否形成稳定的细类群组；聚类不进入低秩主 verdict。
12. 分别报告功能正收益、参数谱位置、稳定表征低秩和低维功能保留，再作联合判断。目的：不给任意一个几何指标越权，最后得到每个具名层的完整画像。

**实验结果：**

- 实验一的功能准入层为 block 24、28；block 25 同时区间跨零，不准入。
- 早层 2–12 与深层 25–35 的 $\Delta T=-0.0046$，同时区间跨零，不支持整体深层功能增强。
- Mean Response 公共谱后移 $\Delta C=0.0285$，但 Rank Consensus 为 $-0.0397$；结论为 `INSUFFICIENT_BASIS_SENSITIVE`。
- 没有一层通过严格表征低秩四项合取。block 24/28 的 $r_{80}$ 为 149/106，确认方差保留为 42.1%/54.6%。
- block 24、28 的最小功能保留通过秩均为 256；1–128 维均未通过全层×秩同时下界和 Haar 对照。
- 完整 35×35 CKA 与 2,000 次相邻层区间已计算；功能准入层不对应统一的 CKA 断点。
- CKA 区间另有校准警告：有放回重采样复制同一 token 后会抬高高维 Gram 相似度，点估计落在 percentile 区间外的相邻对为 TRAIN/DEVELOPMENT/CONFIRMATION=34/1/1。因此只把完整点矩阵作为描述，不用这些区间认定层间断点。
- block 24/28 PCA 聚类 ARI 高于标签置换，却未超过等秩 Haar ARI q95，聚类证据不稳健。

**实验结论：**

更新云有联合结构，但不满足稳定表征低秩；已确认的新增功能可以压缩到 256 维。公共谱后移对基定义敏感，不能写成稳健的“随层后移”。PCA、CKA和聚类均不能替代实验一的 same-$X$ 功能判据。

## 十一、一段可以直接在组会上说的话

> 我们的核心目的是比较不同层新增信息。实验一先给每层一条同一 $X$ 下的净功能收益 $T_\ell$。实验二对同一个 $R_U$ 再用三种坐标看：第一，用各层自己的 MLP 参数谱看本层更新的最大能量带和相对位置；第二，用冻结公共参数谱给所有层同一把尺子，检验谱质心是否随深度后移，并用另一种公共基检查这个结论是否依赖坐标；第三，直接对 token 更新点云做完整协方差、PCA和CKA，比较表征秩与跨层几何。原假设只有在 $T_\ell$ 随深度增强和公共谱位置后移同时成立时才得到支持，单独谱后移不能叫新信息增加。最后再检验少量 PCA 方向能否在未见表达上保留大部分 full-$R_U$ 功能增益；聚类只辅助观察 token 是否成组，不直接等于专家或 Router。

## 十二、汇报时最容易说错的五句话

不要说：“最大谱能量带越靠后，说明深层新增信息越多。”

应该说：“最大能量带只描述更新能量落在参数谱的哪段；新增多少必须看同一 $X$ 下的 $T_\ell$。正式后移判断还要看完整谱质心，而不能只看会跳带的 argmax。”

不要说：“PCA前几个方向就是新增信息。”

应该说：“PCA前几个方向承载最大的更新联合方差，是否保留新增功能需要独立检验。”

不要说：“CKA高说明两层学到同样知识。”

应该说：“CKA高只说明两层在同一批 token 上形成了相似的更新几何关系。”

不要把 CCA 和 CKA 混用。

应该说：“CCA用于找输入与Attention输出之间最相关的线性方向；CKA用于比较不同层的整体 token 关系图。”

不要说：“协方差低秩说明语义低秩。”

应该说：“协方差谱集中说明更新表征几何紧凑；只有通过同一 $X$ 功能门后，才能增加任务相关解释。”

不要说：“聚类得到8组，所以正好对应8个专家。”

应该说：“父类内 $k=8$ 只是检查 token 更新是否与8个 child 形成稳定富集；专家身份与 Router 效益仍需后续验证。”
