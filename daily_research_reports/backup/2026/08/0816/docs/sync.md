# 0816 研究汇报

## 汇报概要

本次要解决的核心问题：

> 对同一个 token，不同层究竟新增了多少旧状态之外的细粒度可访问信息；这些新增信息是否随深度整体增强、是否向参数谱后部移动，以及能否由低维子空间保留？

核心假设：

1. 模型较深层的累计表征更能区分同一粗类内部的细粒度语义，但“每层新增量”不一定单调增加；
2. 新增更新具有低秩结构：既要检验更新云本身是否稳定低秩，也要单独检验功能是否能由低维投影保留。

整体思路：

1. 对每一层定义同一个 decision token 的 Attention 写入前后状态：

$$
X_\ell=N_\ell(h_\ell),\qquad
Z_\ell=N_\ell(h_\ell+a_\ell),\qquad
U_\ell=Z_\ell-X_\ell.
$$

其中，$X_\ell$ 是无本层 Attention 写入时的归一化旧状态，$Z_\ell$ 是模型实际送入本层 MLP 的状态。再去除旧状态能够线性预测的更新：

$$
R_{U,\ell}=U_\ell-\widehat{\mathbb E}_{lin}[U_\ell\mid X_\ell].
$$

2. 先做功能裁定：在已知父类的条件下，检验真实 $R_U$ 是否比 duplicate-$X$ 容量对照和 64 个样本级错配 $R_U$ 更能提升子类预测；只有通过这一关的层才能称为“新增细粒度可访问性”。
3. 再做表征分析：对所有层分别观察本层 MLP 参数谱、两个冻结公共参数谱、token 协方差/PCA、跨层 CKA、聚类和低维功能保留。几何分析不反向替代功能裁定。

结论：

1. 实验一通过：全层同时校正后，只有 block 24、28 确认增加了旧状态之外的细粒度可访问性；block 25 点估计为正但证据不足。新增信息是局部层现象，不支持“越深每层新增越多”。
2. 实验二给出分裂结论：更新云明显不是独立坐标噪声，但没有一层通过“稳定表征低秩”四项合取；block 24、28 的功能可压缩到最小注册秩 256。Mean Response 公共谱显示后移，Rank Consensus 却显示反向移动，因此“谱后移”是 basis-sensitive，不能视为稳健事实。

## 具体实验

## 实验一：逐层条件细粒度新增可访问性

实验目的：

确定哪些 block 的精确更新，在旧状态已经提供的粗/细粒度线索之外，仍增加了已知父类条件下的子类可访问性。

实验对象：

对 block 1–36 构造 $X_\ell$、$Z_\ell$、$U_\ell$ 和 $R_{U,\ell}$。$R_U$ 只是旧状态线性不可预测的候选更新，最终必须由新确认集功能增益裁定。

实验数据：

- TRAIN、DEVELOPMENT、CONFIRMATION 各 640 条；
- 8 个父类 × 每父类 8 个子类 × 每单元 10 条；
- 已知父类后预测其内部子类，例如 mathematics→combinatorics、mathematics→linear algebra；
- CONFIRMATION 使用 10 个新模板与 5 个拟合集未出现的事实子集；重复文本、标签泄漏和 decision-token 端点错误均为 0。

实验过程：

1. 冻结 Qwen3-8B 和最后一个 `Classification:` token，提取 36 层的 $h,a,X,Z,U,H_{36}$；验证模型实际 MLP 输入就是公式中的 $Z$。
2. 只用 TRAIN 拟合 $U\sim X$ 和 old-only 基线，只用 DEVELOPMENT 选择正则；block 1 因相同 token 的 $X_1$ 恒定，按预注册规则记为结构性 N/A。
3. 所有分支复用 bit-identical old-only logits：
   - true：真实 $R_U$；
   - duplicate-$X$：再次给同一 $X$ 一个校正头，用来度量纯容量收益；
   - mismatch：64 个父类内、无自映射、样本级双射的错配 $R_U$。
4. 在每次分层 bootstrap 内重新计算：

$$
T_\ell=G_\ell^{true}-\max\left(G_\ell^{dupX},q_{.95,b}G_\ell^{mis,b}\right),
$$

并对 block 2–36 做 2,000 次父类—语义族重采样和全层 max-statistic 同时 95% 区间。

实验结果：

| Block | true gain | duplicate-$X$ gain | mismatch q95 | $T_\ell$ | 同时 95% 区间 | 判定 |
| ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 24 | 0.1091 | -0.0027 | 0.0003 | 0.1087 | [0.0526, 0.1649] | 通过 |
| 25 | 0.0959 | 0.0266 | 0.0017 | 0.0693 | [-0.0073, 0.1460] | 未决，不通过 |
| 28 | 0.0803 | 0.0150 | 0.0011 | 0.0653 | [0.0239, 0.1067] | 通过 |

全层正集合为：

$$
\mathcal L^+=\{24,28\}.
$$

能力与构造守卫：

- $Z_{24}$、$Z_{25}$、$Z_{28}$ 的确认细类准确率分别为 56.09%、78.44%、94.69%；
- $H_{36}$ 确认准确率为 99.22%，全局能力门通过；
- 同批重复前向、$Z-X-U$、原生 MLP 输入和 o_proj 身份检查的最大误差均为 0。

实验结论：

模型确实会在局部层产生旧状态之外的细粒度可访问性，但当前只支持 block 24、28。block 25 不能因为最初被关注就算作通过：它的 duplicate-$X$ 对照也获得明显收益，全层同时下界仍跨零。实验不支持“越深，每一层新增越多”。

## 实验二：新增更新的参数谱位置、表征秩与 token 几何

实验目的：

在实验一功能锚点之上，比较不同层 $R_U$ 的五类性质：

1. 在本层 MLP 参数谱的哪一段能量最大；
2. 在冻结公共参数谱上是否随深度后移；
3. token 更新云是否稳定低秩；
4. 不同层的 token–token 关系是否相似；
5. 功能新增是否能由低维子空间保留。

实验对象：

先减去每个父类的 TRAIN 均值，但不减子类均值：

$$
\widetilde R_{\ell,i}=R_{U,\ell,i}-\mu^{train}_{\ell,p(i)}.
$$

这保留同一父类内部的细粒度差异，避免父类均值主导协方差。

实验方法与每一步目的：

1. 本层 MLP 参数谱：分解

$$
K_\ell=W_{gate,\ell}^{\top}W_{gate,\ell}+W_{up,\ell}^{\top}W_{up,\ell},
$$

把 4,096 个方向固定分成 F1–F16。目的是回答“本层更新主要落在本层 MLP 哪一段参数谱”，而不是证明 MLP 实际使用了这些方向。
2. 公共参数谱：复用冻结的 Mean Response 和 Rank Consensus 两套公共基。目的是在共同坐标中比较跨层相对谱位置，并用两套基检查结论是否依赖公共基构造。
3. 协方差/PCA：对 TRAIN token 更新矩阵做 SVD，报告 $r_{80}$、有效秩和稳定秩，并把 TRAIN 投影器原样用于 DEVELOPMENT/CONFIRMATION。目的是寻找 token 共同变化的低维方向，而不是直接定义语义功能。
4. CKA：比较每两层 token Gram 矩阵的相似度。白话说，它检查“同一批 token 在两层里谁和谁更像”的关系是否相同；CKA 高不等于两层信息相同，也不等于低秩。
5. 低维功能保留：将 $R_U$ 投影到注册秩 1–512 的 TRAIN PCA 子空间，继续复用实验一的相同 base logits，并与 64 个等秩 Haar 随机子空间比较。目的是区分“方差可压缩”和“功能可压缩”。
6. 聚类：在 $r_{80}$ PCA 坐标中做父类内 $k=8$ 聚类，比较真实子类、标签置换和等秩 Haar。它只作 token 几何诊断。

实验结果：

### 1. 深层功能新增不是整体趋势

预注册早层 2–12 与深层 25–35 的中位差：

$$
\Delta T=-0.0046,\qquad 95\%\ \text{sim CI}=[-0.0260,0.0169].
$$

因此不能说深层每一层新增更多；通过的是局部 block 24、28。

### 2. 参数谱后移依赖公共基

- Mean Response：$\Delta C=0.0285$，同时区间 [0.0218, 0.0352]，显示后移；
- Rank Consensus：$\Delta C=-0.0397$，同时区间 [-0.0471, -0.0322]，显示反向移动；
- 联合 typed outcome：`INSUFFICIENT_BASIS_SENSITIVE`。

本层 MLP 谱也不是平滑后移：TRAIN 中 block 2–25 基本由 F1 主导，block 26 首次跳到 F16，block 32–36 多由 F15/F16 主导；功能准入的 block 24、28 在 TRAIN 中仍由 F1 主导。CONFIRMATION 的 block 25 已变为 F16，说明最大能量带还具有切分敏感性。

### 3. 更新云有结构，但“稳定表征低秩”不通过

- 真实 $r_{80}$ 在所有层都低于坐标独立打乱的 q05，说明维度之间存在联合结构；
- 但没有一层同时满足：$r_{80}/632\le10\%$、低于打乱 q05、以及在 DEVELOPMENT/CONFIRMATION 均保留至少 75% 方差；
- block 24：$r_{80}=149$，确认保留 42.1%；
- block 28：$r_{80}=106$，确认保留 54.6%。

所以不能把“TRAIN 上比打乱更集中”写成“稳定低秩表征”。

### 4. 功能可以压缩到 256 维，但不是 1–128 维

- block 24：最小注册通过秩为 256；rank 256 的 PCA gain 为 0.3145，超过 80% full gain、Haar q95=0.2081，并且全层×秩同时下界大于 0；
- block 28：最小注册通过秩为 256；rank 256 的 PCA gain 为 0.3890，超过 Haar q95=0.3707，同时下界大于 0；
- 两层在 rank 1–128 均未通过完整判据。

256 维是隐藏宽度 4,096 的 6.25%，但也是可识别上限 632 的 40.5%。准确说法是“功能可压缩到 256 维”，不是“新增信息是极低秩的”。

### 5. CKA 与聚类只提供辅助几何

- CONFIRMATION 相邻层 CKA 中位数约 0.861；23→24 为 0.926，27→28 为 0.739，28→29 为 0.682；功能新增层不一定对应 CKA 突变。
- CKA 区间质量复核发现，有放回重采样复制同一 token 后会系统性抬高高维 Gram 相似度（点估计落在 percentile 区间外的相邻对：TRAIN/DEVELOPMENT/CONFIRMATION=34/1/1）。因此保留完整点矩阵作描述，但不用这些区间认定层间断点。
- block 24/28 的确认 PCA 聚类 ARI 为 0.184/0.251，虽高于标签置换 q95，但没有超过相应 Haar ARI q95（0.190/0.264），而且聚类稳定性较低。

实验结论：

实验二不支持统一的“深层新增更多、谱稳定后移、表征整体低秩”叙事。更准确的结论是：

1. 功能新增发生在 block 24、28；
2. 公共谱后移对基构造敏感；
3. 更新云有协方差结构，但跨模板不满足稳定表征低秩；
4. 已确认的功能新增可以由 256 维 PCA 子空间保留；
5. CKA 和聚类不能替代功能对照。

## 最终认识更新

我们最初希望找到“一个对每层新信息敏感、并能用于分发的低秩空间”。这次结果将问题清理为两步：

1. 先问哪一层真的增加了目标信息：当前答案是 24、28；
2. 再问这些已准入层能否被低维空间抓取：当前答案是可以压缩到 256 维，但尚未证明该空间能做 Router、能跨任务稳定，或被模型原生 MLP 因果使用。

因此下一步若继续，应围绕 block 24、28 的 rank-256 子空间做冻结干预/路由效用检验，而不是继续从所有层的漂亮谱形状中挑方向。
