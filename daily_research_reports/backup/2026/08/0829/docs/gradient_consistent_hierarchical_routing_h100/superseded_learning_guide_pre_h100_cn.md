## 本次术语

- **混合专家模型（MoE）：**由路由器选择或组合多个专家模块的模型；它不自动具有有效专家分工。
- **路由器（Router）：**根据可见输入为专家打分并选择专家的机制；它不是专家，也不是离线线性探针。
- **功能公共成分（common）：**本任务四个教师函数都需要的同一个秩一算子 $C$；不是表示均值或高频方向。
- **功能剩余项：**冻结路径尚未解释的目标输出；不是从 Router 输入中减去某个向量。
- **线性探针（probe）：**在冻结表征上拟合的受限读出器，只检查某个标签是否可访问。
- **归一化均方误差（NMSE）：**预测算子与教师算子的平方误差除以教师总能量；本实验中 0 表示精确拟合，$1/3$ 是错误树的解析下界。
- **学习曲线面积（AULC）：**在累计训练样本数的对数坐标上对 NMSE 积分并归一化；越小表示固定训练过程中更早降低误差。
- **反事实专家效用：**同一样本交给一个等计算候选专家后，相对当前残差减少了多少平方误差；它不是语义标签。
- **冻结真实模型（Qwen3-30B-A3B）：**本轮只读取其隐藏状态和真实门控权重、不更新参数的被审计模型。
- **原生门控层（Gate）：**Qwen 中把隐藏状态线性映射为 128 个专家未归一化分数的真实模块；它是 Router 的一部分。
- **前八名稀疏选择（top-8）：**只保留分数最高的八位专家并重新归一化权重的部署操作。
- **对齐条件（work）与错配条件（fail）：**前者让给定父分组与功能分解一致，后者保持四个教师函数不变、只把它们重新配到错误父分组。
- **双表达面板（C4/C5）：**两组使用相同语义原子、不同受控自然语言表达的数据；它们分别报告，不称为独立总体复现。
- **脑浮点 16 位与单精度 32 位（BF16/FP32）：**真实 Gate 主路径和数值敏感性路径使用的两种浮点精度。
- **异或关系：**两个二值量的乘积式交互；单个全局仿射超平面不能恢复，但给定其中一个量后可变成分支内线性关系。
- **低维余弦路由方法（X-MoE）：**把 token 和专家投到低维球面后按余弦分数选择的已有方法；本轮只借用它的 Router 行空间问题。

## 第一遍：只掌握一条主线

这项研究问：如果先让一个专家学共同函数并冻结，再让后续专家只学未解释功能，能否让专家效用变得容易路由？

现在的答案是：**正确分组使这个机制可实现，但没有带来相对平坦非线性 Router 的效率优势；逐样本瞬时效用监督反而破坏了树的专门化。** 关键不是“效用算得不准”，而是“效用标签在训练早期不一定由 Router 看见的输入唯一决定”。

一条完整推理链是：

```text
语义标签可从隐藏状态读出
-> 不代表原生稀疏 Router 保留它
-> 更不代表该标签等于最佳专家
-> 正确条件树能把 XOR 功能变成分支内简单功能
-> 但逐样本最佳专家还依赖 Router 看不到的 z 和正在变化的专家
-> 硬效用标签发生冲突并造成赢家自增强
-> 因此下一步应检验 Router 条件期望效用，而不是直接推广当前层级硬效用条件
```

## 1. 理论节点：哪些认识是确定的？

### 1.1 在所列假设下已证明：固定线性映射不能创造线性可分性

若 $z=Ax+c$ 在新空间里可被 $w^\top z+b$ 分开，代回去便得到

$$
w^\top(Ax+c)+b=(A^\top w)^\top x+(w^\top c+b),
$$

它已经是原空间的线性分类器。线性投影可以丢失方向，也可以通过降维正则化改善有限样本探针，但不能创造原本不存在的线性判别函数。

最近的错误说法是：“投影后准确率更高，所以投影创造了语义信息。”正确说法只能是：在指定训练样本、正则化和读出算法下，投影后的估计更稳定。

### 1.2 在所列假设下已证明：余弦 top-$k$ 仍是线性选择边界

对 X-MoE 式分数

$$
s_e(h)=\frac{(Wh)^\top e_e}{\|Wh\|\|e_e\|},
$$

同一个输入的 $\|Wh\|$ 对所有专家相同。比较专家 $i,j$ 时只剩

$$
h^\top W^\top
\left(\frac{e_i}{\|e_i\|}-\frac{e_j}{\|e_j\|}\right),
$$

边界仍是超平面。X-MoE 的贡献是改变 Router 可见行空间、范数竞争和优化几何，而不是把选择器变成非线性核机器。

### 1.3 在所列假设下已证明：正确树有零误差，错误树有 $1/3$ 下界

定义

$$
\Theta^{work}_{p,b}=C+pA+bB,
\qquad
\Theta^{fail}_{p,b}=C+qA+bB,
\quad q=pb.
$$

两种条件拥有同样的四个函数。work 可按 $C\rightarrow pA\rightarrow bB$ 分解。fail 固定先按 $p$ 分组后，一个秩一叶必须拟合 $b(pA+B)$；因为 $A,B$ 是正交单位秩一算子，$A+B$ 有两个相同非零奇异值。最佳秩一近似必丢一个单位能量，总能量为三，所以 NMSE 至少 $1/3$。

这个定理只证明给定树的表示容量。它没有证明训练能找到正确树，也没有证明树比通用非线性网络更省样本。

## 2. Qwen 审计：表征信息在哪里丢失？

### 为什么要做

如果隐藏状态本身没有父类可访问信息，后续 Router 失败可能只是上游表征问题；若 Gate 投影保留而稀疏选择丢失，则问题位于选择接口。

### 比较对象

- $H$：Qwen3-30B-A3B 原生 MoE 输入；
- $Z$：128 维真实 Gate logits；
- $Q$：只保留 top-8 专家并重新归一化的稀疏权重。

同一八类父标签、同一跨模板划分、同一线性探针算法依次读取三者。C4/C5 必须分别成立；Block 44 只作可见先导，不参与裁定。

### 已核验证据

五个确认深度中，$H$ 的平衡准确率为 0.9948--1.0000，$Z$ 为 0.9417--0.9984，$Q$ 为 0.4047--0.5635。Blocks 4/12/20/28 在两面板都满足“投影保留、top-8 损失显著、剩余路由关联高于置换空参照”。BF16 与 FP32 给出同一裁定。

允许结论：主要父类访问损失发生在 top-8 选择。
禁止结论：父类对应专家有用、Qwen 原生因果使用父类、改变 Router 会降低语言模型损失。

## 3. 合成实验：导师直觉到底通过了哪一部分？

### 四个条件

1. 条件树 + 任务损失；
2. 条件树 + 逐样本硬效用监督；
3. 平坦非线性 Router + 任务损失；
4. 平坦非线性 Router + 逐样本硬效用监督。

七个专家、初始化、数据顺序、三阶段步数、候选专家前向、参数量和推理活动专家数全部匹配。八个随机种子是配对统计单元。

### 已核验证据

- 条件树 + 任务损失：work 终点 NMSE $2.30\times10^{-5}$；fail 为 0.33698。
- 条件树 + 硬效用：work 为 0.41693，7/8 种子失败。
- 两个平坦模型：work 中位终点约 $2\times10^{-5}$ 到 $3\times10^{-5}$；fail 中位也接近零。
- utility 对树的 AULC 对比是 -0.03860，95% 区间完全小于零；对平坦模型的区间跨零。

所以，导师直觉中“正确递进功能分解可训练”通过；“它比通用非线性更高效”和“直接效用监督会加速”没有通过。

## 4. 为什么硬效用监督失败？

### 来源公式

效用可展开为

$$
U_{ie}=2r_i^\top W_ez_i-\|W_ez_i\|^2.
$$

它显式依赖样本内容 $z_i$、当前残差 $r_i$ 和正在变化的专家 $W_e$。但树的第一层 Router 只看 $p$，第二层只在父掩码内看 $q$。

### AI 推断

训练早期，同一个 $p$ 或条件 $q$ 可能因为不同 $z_i$ 和随机专家状态而得到不同最佳专家标签。硬交叉熵要求 Router 对相同可见输入输出互相矛盾的类别；一个偶然占优专家又会获得更多任务梯度，进一步扩大优势。

证据与此一致：硬效用树的中位最小叶负载为零；原生 Gate 和冻结隐藏探针对效用标签的平衡准确率同为 0.625；两者低尾归一化间隔均为负。因为隐藏探针也失败，问题不是简单换一个更好的线性输出头就能解决。

这仍不是因果证明。实验没有直接比较瞬时效用和条件期望效用，因此“不可观测移动标签导致塌缩”保持为待检验解释。

## 5. 下一最小问题怎样定义？

**AI 建议：**只问一个问题：把效用目标改成 Router 可见状态上的条件期望，能否消除塌缩？

$$
\bar U_e(r)=\mathbb E[U_e\mid r],
$$

其中 $r$ 是 Router 实际看见的父/子分支状态。比较三组：无辅助损失、瞬时硬效用、软条件期望效用。其余对象全部冻结。正结果必须同时满足：AULC 下降、终点不劣于任务基线、每个必要功能非零负载、低尾间隔为正。否则停止将效用驱动残差树推广到真实模型。

它比“给 Router 看更多特征”更小，因为后者同时改变可观测信息和函数类，无法判断问题来自标签定义还是 Router 表征。

## 6. 文献位置与发表边界

已有工作分别覆盖了低维余弦路由与表示坍缩（[X-MoE](https://proceedings.neurips.cc/paper_files/paper/2022/hash/df4f371f1f89ec8ba5014b3310578048-Abstract.html)）、共享/细分专家结构（[DeepSeekMoE](https://aclanthology.org/2024.acl-long.70/)）、残差专家组合（[Residual Mixture of Experts](https://arxiv.org/abs/2204.09636)）、专家选择式分配（[Expert Choice](https://proceedings.neurips.cc/paper_files/paper/2022/hash/2f00ecd787b432c1d36f3de9800728eb-Abstract-Conference.html)）以及路由学习（[Learning to Route](https://aclanthology.org/2023.emnlp-main.583/)）。更接近的近期方向已经直接研究反事实或专家能力驱动的路由，例如 [Expert Policy Optimization](https://arxiv.org/abs/2605.07260)；这意味着“使用专家效用监督 Router”本身不能作为新颖性主张。

当前最可防守的新意是：把**效用可分性相对于 Router 可见表征**定义为必要条件，并用函数多重集相同的 work/fail 定理与层级/平坦 × 任务/效用 $2\times2$ 严格拆开结构、监督和通用非线性。

目前证据适合形成研讨会或分析型预印本，但还不足以支持主会方法论文：核心方法臂没有增益，真实 Qwen 只做了静态语义审计。主会级推进至少需要在真实单层 MoE 上执行等计算候选专家，证明 Router 可测的条件期望效用能稳定改善留出语言模型损失，并在多个任务或检查点复现；否则应把贡献定位为负结果与方法学警告，而不是新 MoE 架构。

## 理解检查

请不用数字回答：**为什么“我们能精确算出当前哪个专家最有用”仍不足以说明“Router 能学会选择它”？**

合格答案必须同时说出两点：效用标签可能依赖 Router 不可见的 $z$；专家参数变化会使标签本身随训练移动。
