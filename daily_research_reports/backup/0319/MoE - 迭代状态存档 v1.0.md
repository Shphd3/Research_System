# [调研]MoE - 迭代状态存档 v2.0 (Mid-term Update)

## 1. 当前主线目标 (North Star)
基于多头表征的谱分层理论，探索去均值后的 Spike（主空间）作为 MoE 路由分发核心的充分必要性。旨在证明：摒弃深层高维噪声、依赖低维 Spike 进行的“正确语义分发”，是实现自然负载均衡（无需强制辅助损失）以及促进下游专家网络局部低秩性（Local Low-Rankness）的根本数学途径。

## 2. 背景与理论基石 (Background & Math Foundation)
- **空间三段论**：大模型的表征空间经过去均值 SVD 后，可严密划分为：
  - `Spike` (宏观共性语义核，高信息密度)
  - `Middle Tail` (微观/特异性语言学差异，低信息密度)
  - `Deep Tail` (各向同性噪声，无泛化能力)
- **均值的物理意义**：均值 $\mu$ 代表全局常数偏移（如语言基础语法/锥形效应），对判别性路由毫无贡献。Spike 代表跨 Token 的宏观语义坐标轴。
- **隐式降噪路由**：摒弃显式 SVD 切分，采用低秩矩阵分解 $W_g = A B^T$ 作为 Router，强制网络在 Spike 流形上进行拓扑聚类与分发。

## 3. 当前假说 (Current Hypotheses)
- **H1 (正确分发驱动均衡与低秩)**：
  - **分发机制**：如果 Router 的决策空间被严格约束在 Spike 子空间（通过低秩瓶颈），它将对齐数据固有的宏观语义分布。
  - **负载均衡**：只要预训练数据的宏观域先验分布相对均匀，基于 Spike 的纯粹语义分发就能涌现出自然负载均衡，极大降低对 Auxiliary Loss 的依赖。
  - **专家低秩性**：纯净的语义分发使得输入单一专家的激活矩阵内在秩极低，从而允许专家采用低秩网络结构（促进高效推理与参数共享）。
- **H2 (语义降级与噪声，已通过 Probe 验证)**：多头表征深部的 Deep Tail 在宏观领域分类上等同于随机猜测，不仅对路由无益，反而会引入虚假相关性导致路由坍塌。必须在路由前被截断或过滤。
- **H3 (多头一致性演化)**：层数越深，不同 Head 提取到的 Spike 空间重叠度（共识）越高，而 Tail 越趋近于纯随机空间。

## 4. 预想的实验结构：第二阶段 (Experiment Design: Round 4)
- **目标**：验证 H1 中“低秩约束（Spike代理）-> 自然负载均衡 -> 专家特征低秩”的传递链条。
- **实验设置**：
  1. **构建低秩 Router Proxy**：不仅使用传统的 Linear Router $W_g \in \mathbb{R}^{d \times E}$，构建 Low-Rank Router $W_g = A B^T$ (例如秩 $r=16$)。
  2. **端到端微小模拟/或冻结特征训练**：给定冻结的大模型中间层特征，仅训练 Router 预测伪标签（或进行自编码聚类）。
- **观测指标**：
  - `Routing Entropy / CV`：观察低秩 Router 是否在没有辅助 Loss 的情况下，比全秩 Router 表现出更好的负载均衡度。
  - `Expert Input Rank`：计算被分发到同一专家的 Token 特征矩阵的有效秩（Effective Dimension），对比随机分发、全秩分发和低秩分发下的专家内聚程度。

## 5. 预期结果与更新准则 (Expected Results & Update Rule)
- **预期**：Low-Rank Router 分发出的簇群，其内部特征的奇异值衰减极其陡峭（专家低秩性被证实）；且在缺乏辅助 Loss 惩罚时，Low-Rank Router 表现出的负载不均衡度远小于全秩 Router。
- **警戒线**：如果低秩 Router 依然出现严重饿死现象，说明宏观分布本身不均，必须引入数据重采样，或承认 Spike 路由无法单枪匹马解决负载均衡。
