## Scope

This package contains the curated 05_01 result materials for AI audit. The key question is whether router-center separation alone provides a reliable specialization mechanism, and how the result boundary changed after H0604a/H0604b.

## Audit Focus

Ask the AI auditor to check:

1. whether the documents consistently define `geometric inhibition` as router-center separation only;
2. whether C2/C5 supervised token-margin evidence is clearly separated from center-only evidence;
3. whether high same-feature consistency is protected by collapse guards;
4. whether `slot`, $B_i$, and `(slot,B_i)` are kept distinct;
5. whether any claim incorrectly upgrades routing structure into expert utility specialization.
