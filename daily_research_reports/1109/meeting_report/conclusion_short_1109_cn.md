# 1109 结论（精简版）

## 问题 1：共享参数学长尾信息时，限制学习的是更新方向冲突，还是随机梯度噪声？

**结论 1：一组数据的一步更新对另一组的影响，平均方向没有冲突，但帮助很小；随机梯度噪声总是伤害，学习率稍大时就占主导。**

用 SAE feature 的共同出现关系把 token 分组。6 个不同组对之间，平均更新的方向项全是帮助（3 对显著），没有一对是伤害。minibatch 噪声的伤害随 $\eta^2$ 增长、随 $1/n$ 下降；在 $n=32$、$\eta=1/4$ 时，它约为平均方向帮助的 17 倍。

| 量 | 跨簇 A→B | 同簇 B′→B |
|---|---|---|
| 噪声项对 $\log\eta$ 的斜率（$n$=32/64/128；理论 2） | 2.06 / 2.04 / 1.95 | 2.17 / 2.01 / 2.02 |
| 噪声项对 $\log n$ 的斜率（$\eta=1$；理论 −1） | −1.18 | −0.99 |
| 方向项 $g_B^\top\bar g$（z） | $5.7\times10^{-5}$（1.28） | $2.7\times10^{-3}$（5.2） |

**由此得到分发的设计目标。** 长尾 feature 在一次更新里出现的 token 很少，它的信号会被其余 token 带来的噪声淹没。分发要做两件事：

- 把同一条长尾信号的 token 集中到少数 expert，即覆盖率 $c_i$ 高；
- 把无关 token 挡在外面，即纯度 $\pi_i$ 高。

这样做相当于增大了这条信号的有效 batch。在二阶近似下可以推出，可用的学习率也随之变大（待验证）。两者合成一个指标，即集中度 $\bar M_i$（dense 为 1，随机 Top-2/8 为 1/4）。

## 问题 2：按 teacher feature 分发，能否让长尾学得快？

**结论 2：目前的 teacher 没有完成好的 feature 分组。它比随机分发更集中，但比原生 router 更分散。五个模型的 NLL 与集中度 $\bar M$ 同趋势变化。**

| 模型 | 分发方式 | 总体 NLL | $\bar M$ 中位数 | 最低频 bin0 NLL |
|---|---|---:|---:|---:|
| A0 | 原生可学习 router | 4.083 | 1.010 | 3.795 |
| A1-deep | 前 4 层原生，后 4 层 teacher | 4.085 | 0.871 | 3.790 |
| A4 | 原生 router + teacher 蒸馏 | 4.129 | 0.811 | 3.867 |
| A1 | 8 层固定 teacher 分发 | 4.158 | 0.586 | 3.901 |
| A2 | 8 层固定随机分发 | 4.286 | 0.257 | 4.188 |

**teacher 为什么不够集中**（离线诊断，探索性）：

1. **分组目标不对。** teacher 对每个 token 的整组编码做 8 类 K-means，相似度主要由常见 feature 决定。结果是：它把高频 feature 聚得比原生 router 紧，把低频 feature 聚得比原生 router 松，与设计目标相反。
2. **分组不均衡，被负载均衡改写。** 一个 expert 分到 32% 的 token（均衡应为 12.5%），load bias 只能大量改派。改派后 $\bar M$ 从 0.697 降到 0.586。
3. **8 层共用同一个固定划分。** 原生 router 的每一层集中的是不同的 feature，八层平均后达到 1.01；A1 每一层都是 0.586。把前 4 层换回原生 router（A1-deep）后，$\bar M$ 升到 0.871，NLL 几乎追平 A0。

**下一步：** 按设计目标重新构造 teacher，要求它以低频 feature 的共同出现为依据、与负载均衡相容、逐层划分。先离线用 $\bar M$ 筛选候选方案，再训练检验 NLL 是否跟着 $\bar M$ 走。

> 边界：单种子，0.52B token；五个模型中，只有 A1 对 A2 的集中度是我们从外部设定的，其余模型的路由是学出来的，集中度与 NLL 之间可能互为因果。
