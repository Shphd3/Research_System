# 后续实验阅读副本

返回[统一阅读入口](../../00_reading_guide_cn.md)。

这个位置用于收录在其他位置已有正式来源的后续实验副本。本轮新实验的唯一正式记录已按研究者要求放在[experiments/20260926_direction_conflict](../../experiments/20260926_direction_conflict/anchor.md)，无需再复制一套；其执行与结果见该目录的Summary和Detailed。初建时讨论稿见[上一版机制分析](../../01_mechanism_analysis_cn.md)。

正式材料维护在所属问题的原始位置。其阅读副本放在本目录同级的 `<日期_实验名>/` 中，按实际存在情况收录 Anchor、Protocol、Summary、中文Summary及Detailed；不创建虚假的批准状态或结果占位文件。每次收录需记录来源路径、复制时间、源文件与副本摘要值，并更新统一入口。

副本只为集中阅读，不作为另一套可独立修改的实验设计。图片链接当天 `figures/` 的阅读副本，原始数据、模型和执行日志留在执行工作区。
