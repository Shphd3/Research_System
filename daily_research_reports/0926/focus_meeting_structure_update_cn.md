# 组会图稿：不同数据的表征结构，怎样连接到共享学习后果？

[本轮结果摘要](docs/structure_update/summary_cn.md) · [完整证据](docs/structure_update/detailed.md) · [思路审计与聊天计划](01_思路纠偏与聊天计划_cn.md)

这是研究者要求的图稿与解析，认识措辞为AI分析；不是新建科学问题卡，也不改变现有问题的状态。导师附件与黑板原图未取得，图的需求依据可见引用会话中的说明。

## 1. 本次主问题与知识更新

**不同领域在表征空间中有不同分布，这种不同是否足以意味着它们在共享参数更新时互相伤害？**

本次回答是：**不足以。** 同一自然文本面板上已经同时观察到领域结构差异和平均正向迁移。这里的正向迁移指：只用一组数据计算小步更新，另一组独立记录的平均预测损失也下降。它不是长期共享收益，更不是隔离效果的证明。

本轮的价值是把对象对齐并测出箭头的方向。不能把完成8个分支本身当作机制成立；真正的认识更新是，当前数据没有支持“可分就会互害”这一直接连接。

## 2. 先交结构图：每一点是什么，分布沿什么方向变化

### 问题一：稀疏自编码器看到的原始表征是什么样？

稀疏自编码器（本次简称SAE）是把注意力输出表示成少量字典特征的旁支观察工具；其重构不进入当前模型的语言预测主路径。本轮首先画它看到的原始向量，不从特征编号猜语义。

![原始注意力输出共同坐标图](figures/a_common_axes_and_spectrum.png)

每个点是一段256词元自然文本的末块注意力输出平均向量；颜色表示其来源领域。第一批四领域合起来拟合一套方向，第二批所有记录都投到这套方向上。没有给每个领域单独选一套坐标，也没有用展示批次挑最分开的轴。

“主成分分析（PCA）”在这里指按第一批样本方差寻找共同的正交方向。第一、第二主轴只按方差大小排序，没有经过语义命名。图上数学在第一轴明显偏移，物理在第二轴有位置差异，计算机与生物有较多重叠；这是分布结构，不能解释为四个互不重叠的语义模块。二维平面只覆盖第二批约29.4%的中心化能量，未显示的方向不能被视为没有信息。

左下图必须讲清楚：未去均值的原始能量第一方向占92.3%；去掉均值后，90%的样本差异仍需108个方向。前者很大程度来自所有样本共有的平均向量。**大均值、低方差有效维数、语义概念少，是三个不同主张。** 单位长度归一化后分布仍有差异，只能削弱“差异完全来自每段向量长度”的解释。

### 问题二：这些向量就是被更新参数接收的输入吗？

不是同一个对象。注意力输出先与原有状态相加，再经过归一化及门控计算，才成为末层下投影的输入。这里的下投影是把3072维中间向量映回1024维模型状态的矩阵。

![下投影输入共同坐标图](figures/u_common_axes_and_spectrum.png)

这张图仍使用同一批记录，在实际输入空间重新拟合共同轴；前两轴覆盖第二批约32.6%的中心化能量，90%方差需要95个方向。它把观察位置与参数作用位置接上，但仍不能只凭散点间距判定更新冲突。不同图的坐标、归一化前后坐标均分别拟合，轴的符号和绝对数值不能跨图直接比较。

## 3. 为什么表征不同仍可能相互帮助

先考虑某一个词元。令 $u$ 为下投影接收的3072维输入，$W$ 为1024行、3072列的权重矩阵，矩阵输出为 $y=Wu$。令 $e=\partial\ell/\partial y$ 为损失对这个输出的导数：它表示为了减少预测错误，当前输出往哪个方向变化会使损失上升或下降。下降更新取其反方向。$e$ 已包含输出之后的残差、最终归一化与词表预测的反向作用。

链式法则给出权重梯度：

$$G=\frac{\partial\ell}{\partial W}=e u^\top.$$

因此，一个更新要求包含两项：**输入是什么，以及模型对这个输入还错在哪里。** 只看输入分布，缺少第二项。

两个单词元梯度在矩阵坐标中的内积为：

$$\langle G_A,G_B\rangle_F=(e_A^\top e_B)(u_A^\top u_B).$$

下标A、B仅表示两个例子；$\langle\cdot,\cdot\rangle_F$ 是把矩阵对应元素相乘后求和。这个等式是对单词元线性矩阵的代数分解，不是本轮已经测出的完整因果机制。对整组数据应先平均每个词元的外积；不能用“平均误差乘平均输入”代替，也不能把正文均值散点直接带入此式当作组梯度。

一个一维例子足以看出缺口：两个输入都为1，如果两者的输出导数分别为+1和−1，梯度就相反；如果输出导数都是+1，梯度就同向。**相同输入既可以对应相容更新，也可以对应冲突更新。** 相反，输入方向不相似，也不自动决定两个梯度的内积为负。

若从同一权重出发用A作小步下降，步长为正数 $\eta$，则B的损失一阶变化为：

$$L_B(W-\eta G_A)-L_B(W)\approx-\eta\langle\nabla_W L_B,G_A\rangle_F.$$

内积为正意味着局部一阶上帮助B，为负意味着伤害B；有限步长还受曲率和数值误差影响，所以本轮直接测更新后的损失并检查半步。训练批的梯度内积也不等于独立记录的实际损失变化；图中两者分别报告。

这就是从“表征关系”到“学习后果”中间缺失的连接：**输入结构与预测误差信号共同形成参数更新，参数更新才产生可测的跨组后果。** 本轮没有进一步分解哪部分误差信号造成帮助，不能把上述公式写成已识别的具体语义机制。

## 4. 再看同数据更新图：实测方向是什么

![同数据更新后果](figures/same_panel_update_consequences.png)

上排两张矩阵都从同一个冻结模型出发。行是计算更新的领域，列是测量更新后果的另一批文本。正数、蓝色意味着损失下降；对角线是自身改善，其余12格是跨组后果。所有数值放大1,000倍显示，完整数值在[结果表](/data/250010109/MoE_Router/experiments/20260926_structure_update_bridge/update_summary.csv)。

两个步长的12个跨组平均方向均为帮助，完整步长约为每预测词元0.00053—0.00201自然对数损失下降。不是每条记录都改善，也不能由这些边际区间推出一个经过多重比较校正的普遍规律。完整步长的计算机自身改善区间略跨零，故还要保留这一来源资格的不确定性。

左下显示六对来源梯度余弦均为正，与本次帮助方向相容。右下把同一四领域的激活分布距离与双向帮助放在一起：六个点全部展示，不筛“最好看”的组对；四个来源共享，六个组对并非六个独立实验。当前点数与数据角色不足以检验通用预测能力，更不能声称SAE超越词频参照。

这张图补的是局部更新后果。既有9月25日选择题实验则测了另一载体的训练与隔离结果，不能把两者拼成同一数据上的完整因果实验。旧实验的固定总参数比较为远组共享1.427814、隔离1.430959；隔离没有优于共享，而24.44%的准确率又限制了知识学习的解释。详见[旧实验摘要](../0925/docs/human_semantic_updates/summary_cn.md)。

## 5. 完整逻辑链现在到哪里

| 连接 | 当前证据与状态 |
| --- | --- |
| 不同来源 → 表征分布不同 | 同一检查点、共同轴及既有完整字典分布支持这一描述；词汇与文体解释仍在 |
| 表征 → 被更新矩阵的实际输入 | 真实源码与同次前向取点已核对；中间有残差、归一化和门控，不能视为同一个向量 |
| 参数输入与误差信号 → 参数梯度 | 单词元关系由链式法则确定；本轮取得组平均完整矩阵梯度，未分解误差信号的具体语义来源 |
| 一组更新 → 另一组独立文本损失变化 | 本轮直接测量完成；两个幅度下12个跨组均值都是帮助，未出现平均伤害 |
| 局部帮助／伤害 → 长期共享是否落后 | 本轮未检验；单步结果不能代替完整训练比较 |
| 共享落后 → 隔离能否恢复 | 需要预算对照；既有其它载体的固定总参数结果未支持隔离优势 |
| 稀疏特征 → 可部署的划分规则 | 尚未建立独立预测价值或实际分配收益，不由前面的可分性补足 |

**逻辑分析已闭合，正向机制证明并未闭合。** 闭合的含义是每一箭头都有对象、证据或明确缺口，并且实际结果已经改变允许的结论；不是要求每一箭头都被证明为支持预期。

## 6. 可直接讲的三分钟版本

> 我这次先把老师要求的结构图画出来了。同一模型、同一层，不同领域都投到同一组方向上，能看到数学、物理与其它来源的分布位置不同。但图的原始能量集中和样本差异集中不是同一件事：第一原始方向占92.3%，去均值后覆盖90%差异仍需108个方向。
>
> 接下来我检查这些向量怎样影响参数。稀疏自编码器看到的是注意力输出，被适配的下投影接收的是经过残差、归一化和门控后的输入。更新方向还取决于模型的预测误差，所以只看表征相似或不同，不能判断是否冲突。
>
> 我用同一批自然文本补了独立的一步更新检查。两种步长下，12个跨组方向的平均损失都下降。完整步长的计算机自身改善区间略跨零，因此我保留这一不确定性。当前结论是：领域可分与局部帮助可以同时存在；我还没有得到可以据此隔离参数的证据。下一步先选定一个有实测依据的学习后果及竞争解释，再决定如何区分；不把找到伤害作为成功条件，也不直接由可分性设计划分规则。

## 7. 唯一下一决策与停止条件

**AI建议：选择哪个有实测依据的学习后果及最强竞争解释，作为下一次区分检验的对象？** 本轮的平均帮助可以成为待解释现象；若仍研究共享落后或隔离收益，先说明那个后果在哪个载体、状态和预算下已成立，不能把本轮自然文本单步结果与另一载体的训练曲线拼成同一因果实验。

本次讨论的完成标准是：用一句话固定后果、范围与对照，写出两种解释会在哪个观察上分歧，以及支持、未支持、证据不足各改变什么决定。若选择局部伤害假说，其来源自改善与独立目标受害须同时合格；若结果继续为帮助或不足，就停止用该条件支撑隔离，不事后挑层、挑步、挑样本挽救。表征信号的独立预测价值是后续问题。该讨论决定尚待研究者确认，不自动启动新实验。
