## 当前判断

E04 的问题不只是任务难，而是完整双射补全和答案相关拒绝采样使载体包含目标推理之外的捷径。下一步先重构一个更小、更对称的短程载体；暂不增加序列距离，也不解释 MTP/NTP 机制。

实验角色：载体操作化与有效性审计。

## 简短 Plan

1. **构造载体：**设计短序列、稀疏、对称的三链数据，移除完整双射补全和答案相关拒绝采样。
2. **审核生成规则：**检查隐藏查询、必要边删除、答案分布、节点命名和事实顺序等守卫，判断载体能否识别单步与两步能力。
3. **冻结实验定义：**审核通过后，才把数据算法、自变量、控制变量、能力门槛和停止条件写入新的 Protocol。
4. **分阶段推进：**Protocol 经用户批准后才实现生成器；生成器审计通过后才做 NTP 能力校准；当前不运行 MTP/NTP 正式比较。

## 给主对话的 Prompt

```text
我们现在只推进 A12/12_0 的新数据载体设计，不启动实验。

目标：构造一个短序列、稀疏、对称的多链任务，用于后续判断标准 K=2 MTP 是否改变标准 NTP 主头学习单步与两步组合的训练动力学。

请基于以下原则草拟数据构造：

1. 每个样本现场生成三条结构完全对称的候选链：

   U1 --r1--> V1 --r2--> W1
   U2 --r1--> V2 --r2--> W2
   U3 --r1--> V3 --r2--> W3

2. 每个样本重新随机命名九个节点，六条事实随机排序。
3. 先生成完整图，再独立、均匀选择查询链；禁止根据 A、B、Y 或答案性质拒绝样本。
4. 单步查询 Ui 的答案为 Vi；两步查询相同 Ui 的答案为 Wi。
5. 单步与两步必须匹配输入长度、事实数量、节点词表、查询位置、答案位置、输出格式，以及查询相关与无关事实数量。
6. 只输出最终答案，不显式输出中间状态。
7. 训练集和测试集使用独立生成的图实例。
8. 暂时保持短序列，不增加距离变量。
9. 当前只设计和审核数据，不实现、不训练、不提交远程任务。

请输出：

一、逐步的数据生成算法；
二、一个完整的单步样例和对应两步样例；
三、单步与两步的严格匹配表；
四、隐藏查询、删除目标第一条边、删除目标第二条边、随机重命名、随机调整事实顺序、答案与查询链边际分布等守卫的预期结果；
五、该载体能够识别什么、不能证明什么；
六、仍需我决定的设计项。

请重点自我审计：

- 是否仍存在节点频率、答案频率、位置或格式捷径；
- 三条链是否真正可交换；
- 删除必要边后是否可能通过排除法恢复答案；
- 单步与两步是否只相差组合深度；
- 是否无意混入距离或任务格式差异。

所有不能由当前原则唯一确定的设计都标记为“待我决定”，不要自行写入最终 Protocol。输出草稿后停止，等待我审核。
```

## 当前结论边界

这一步只决定新载体是否值得进入 Protocol。即使载体通过生成器审计，也不能据此声称 MTP 有组合优势、长程优势、中间状态因果使用或自然语言迁移价值。

## 唯一下一决定

审核主对话给出的数据生成草案：批准、修改或拒绝。批准前不实现和运行。
