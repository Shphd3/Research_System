# 从检索命中到功能效用

## 状态

这是为 2026-07-17 组会准备的工作主题，由 AI 提议、等待研究者确认。
它不是正式锚点或实验协议，也不授权新实验。

## 建议的组会主题

**从检索命中到功能效用：长上下文 Router 到底应该优化什么？**

一句话判断：

> 能放入一百万词元，不等于能使用一百万词元；只有在固定计算预算下，
> 被 Router 选中的信息能够维持标准预测头的正确决策，长上下文才真正可用。

长上下文是工作负载，功能效用才是研究对象。我们不再把“信息位于上下文中”、
“隐状态中可读”或“按特征分桶”当作使用证据，而要问：选中这部分信息后，
下游损失是否真的改善或被保留。

## 为什么现在值得做

当前系统已普遍宣传百万级上下文，但简单的 needle retrieval 不等同于多跳使用、
聚合或非字面检索。外部证据只说明工作负载重要，不证明我们的机制：

- [Gemini 长上下文文档](https://ai.google.dev/gemini-api/docs/long-context)
- [OpenAI GPT-4.1 公告](https://openai.com/index/gpt-4-1/)
- [RULER](https://arxiv.org/abs/2404.06654)
- [NoLiMa](https://arxiv.org/abs/2502.05167)

用户已给出的现象：

> Agent 密集工作负载能够塞入极长上下文，但真正能稳定使用其中必要证据的模型很少。

## 目标审计

| 层次 | 问题 | 当前边界 |
|---|---|---|
| 工作负载 | 模型能否使用分散在长上下文中的必要证据？ | 长度本身不定义难度。 |
| 表征 | 证据是否被编码并传递到可用状态？ | 可读不等于被使用。 |
| 预测 | 标准头是否因果依赖该证据？ | A11 的更早信号不保证这一点。 |
| 检索 | 固定预算下，选择器是否维持预测质量？ | recall 或 attention mass 不是功能效用。 |
| MoE | Router 能否预测当前查询需要哪个专家或记忆项？ | 特征身份与负载均衡都不充分。 |
| 训练方法 | MTP、扩散或其他目标能否改善所需状态？ | 方法是干预手段，不是研究终点。 |

因此，终点不是“证明 MTP 有效”或“让特征可分”，而是：

> 学到一个随查询变化的 Router，在固定计算预算下预测 held-out 功能效用。

## 根据导师录音必须联合考虑的点

1. **有价值的工作负载：** 必须需要困难的长程结构，而不是只有词元距离。
2. **明确的计算结构：** 局部步骤、耦合、顺序、中间状态和最终读取要分别建模。
3. **先分清目标机制：** next-one 与 next-two 的监督差异不能等同于长上下文收益。
4. **形成不等于使用：** 状态中信息更多，不能证明标准头真正使用它。
5. **功能专门化：** 特征可分只有在改变专家或记忆效用时才有价值。
6. **能力与载体有效性：** 载体学不会时，不能解释为 MTP 或组合机制失败。
7. **每日闭环：** 每天只回答一个子问题，写明边界，并留下一个下一决策。

## 最小决定性问题

### Q0：已有证据可以确切回答

**在当前受控设置中，完美特征专门化是否足以产生有效稀疏检索？**

答案：**否。** R3/R4 表明，完美特征分桶在功能性稀疏输出指标上仍弱于
同数量局部基线。这是一个受控负结果，不能外推为所有长上下文 Router 都失败。

### Q1：今天建议审计

**在现有受控检查点上，检索代理分数能否在固定 top-$k$ 预算下预测记忆项的
因果损失效用？**

令 $q$ 为查询，$C_q$ 为可用记忆，$S_s^k(q)$ 为分数 $s$ 选出的 $k$ 个记忆项。
主要功能损失差定义为：

$$
\Delta_s(k)
=
\mathbb E_q\left[
\ell\!\left(q;S_s^k(q)\right)-\ell(q;C_q)
\right].
$$

$\Delta_s(k)=0$ 表示稀疏选择与完整记忆的损失相同；越小越好。它度量固定预算下
是否维持预测，不证明长上下文尺度、记忆项之间的因果独立性或 MoE 专家价值。

仅用于诊断的单项移除效用为：

$$
u(q,i)
=
\ell\!\left(q;C_q\setminus\{i\}\right)-\ell(q;C_q).
$$

$u(q,i)>0$ 表示移除记忆项 $i$ 会损害标准头。记忆项可能相互作用，因此单项效用
不能相加，也不能被称为精确 top-$k$ oracle。

最小同预算对照：

1. 随机同数量；
2. 局部同数量；
3. 特征对齐分桶；
4. dense attention mass 排序；
5. 若计算允许，用因果效用排序作诊断上界。

主指标是 held-out 查询上的 $\Delta_s(k)$；与 $u(q,i)$ 的排序一致性只是次指标。

决策规则：

- attention mass 能预测效用而特征身份不能：研究随查询变化的 attention-like 索引；
- attention mass 也不能预测：直接学习输出或损失效用，而不是模仿 attention；
- 所有选择器主要随距离失效：先研究位置或信息传递，不急于研究 Router 语义。
