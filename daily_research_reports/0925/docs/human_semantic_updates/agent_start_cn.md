4. 冻结协议科学正文、代码、数据角色、人工标签、矩阵、分析及资源估算。计划包括720逻辑轨迹，同硬件Solo复用基础630条，当前混合机型分片为640物理轨迹，不是720个独立模型证据；使用明确获批的资源，先核吞吐是否满足阶段与总预算。
