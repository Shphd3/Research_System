# 更新兼容性是否比来源可分性更能提示参数隔离收益

> 日期：2026-09-25；问题设计仍 `DRAFT_FOR_REVIEW`；新实验完成数据资格与 SCREEN，正式训练 `NOT RUN`。研究者已要求按原协议停止，不把筛选不足解释为机制否定。
> 本轮曾获四卡 5090 Spot smoke 后条件式 full 的执行授权；SCREEN 未构造出合格对照，故 full 授权未触发。D16 容量对照仍为未执行设计，不存在结果。
> 唯一实验契约：[protocol.md](protocol.md)；执行 agent 入口：[agent_start_cn.md](agent_start_cn.md)。正式 problem_key／父 Anchor／Focus 归属未确认，暂留本日期草案目录；旧 0924 注册文档及结果保持原样。

## 1. Problem Definition

**在输入表示同样容易区分的两对任务中，训练前更新方向更相反的一对，是否在独立样本上出现更强的局部互损，以及更大的固定参数预算隔离收益？**

父问题仍是“哪些数据适合共用有限参数，为什么”。研究者希望从主题类别转向学习要求。这里把“学习要求”收窄为：在同一冻结模型、同一个待适配权重上，答案预测损失要求怎样改变权重。不能把文本差异、所需计算、表示距离、梯度方向混成一个未定义原因。

旧实验已经观察到两组各自可学，不能说它因为“模型已学会”而失效；开发集上隔离也未胜过同总参数共享。未知的是：是否需要比来源名称更接近实际更新的信号，才能找到隔离值得的情形。旧数据是有噪声的两个 M2D2 配置，并非纯数学／生物语义干预，也没有证明其分布相同。

**修正引用对话最后一条的两处逻辑：**筛选“差异大且冲突强”的一对再报告同一筛选分数，不能构成验证；只训练一对，即使成功，也不能说明更新兼容性比来源差异更有区分力。因此，AI 建议筛选最多八来源，正式只留一对候选及一对参照：两对表示均可分，兼容性分别低／高，并尽量在严格规则下共享一个来源。筛选、训练、开发、诊断、确认分开，筛选结论不作结果证据。

不以本轮证明“分布差异导致冲突”的因果链，也不证明所有任务上哪种因素最重要。通过可形成两个选定任务对上的独立预测案例；失败停止该筛选信号的强叙事；样本或对照不足时报告未知。

## 2. Physical Priors

**候选先验：**当可训练自由度有限时，一个任务要求的更新可能帮助另一任务，也可能让它的预测变差。任务来源容易区分并不决定是哪一种；更新方向的关系可能提供额外信息。

一阶近似下，沿 A 的负梯度走一小步，对 B 损失的影响约为两者梯度内积的负值。这只是同一坐标、同一状态、足够小步长下的局部关系；实际低秩适配（LoRA，用两个小矩阵乘积表示权重变化）、Adam 动量、曲率及后续轨迹都可能让它失效。故方向分数只筛候选，必须在独立样本与真实适配状态上测更新后果和长期收益。

最强竞争解释是：所测方向只反映模板／答案统计或冻结起点的瞬时几何，不能预测后续适配；分开即使有用，也可能来自条件化容量和优化器统计，而非该方向关系。另一竞争解释是容量不足：D8 每个任务只能使用秩 8，隔离的潜在收益可能被减小的分支容量抵消；S16 同时学习两任务也可能受总容量限制。两种情况不能仅凭 D8 与 S16 的胜负区分。

## 3. Falsifiable Hypotheses

**H_update（本轮、AI 具体化）：**对两个预先锁定、表征都可分的任务对，筛选方向不兼容的任务对 P−，相对方向兼容的 P+，在新样本上呈现更大的固定预算隔离收益；P− 自身还应有正收益，并在预设训练状态出现“源任务改善、另一任务受损”的局部证据。

**H_rival：**高来源可分性可以和有效共享并存；筛选阶段的方向差异不能稳定外推到独立更新后果或隔离收益。它允许某一个任务对分开有益，但不要求 P− 相对 P+ 更有益。

区分性预测：两对都具备来源可分性，仅 P− 具备筛选负方向关系；若新样本上的隔离收益差及局部损害均沿预测方向，支持一个有限的预测案例。若只有来源可分、没有局部损害或隔离收益，则反对把筛选信号直接当隔离依据。若 P− 的差分优势仅因为 P+ 隔离更差，而 P− 自身无正收益，也不支持“值得隔离”。

**尚不测试：**稀疏自编码器（SAE）的特征能否预测兼容性；自动路由；专门修改冲突过程以识别其长期因果作用。它们不因本轮正结果自动成立。

## 4. Mathematical Model

主干与 SAE 冻结，最后块下投影为 $W\in\mathbb R^{1024\times3072}$，其实际输入为门控后的向量 $u$。给 W 加 $B_eA_e$，只有 A、B 训练。外部任务来源标签或固定混合组号选择分支 e，不是学到的路由。

任务是给定问题／代码提示，预测参考答案的下一词元；只计答案目标，不计提示、填充和结束标记。对任务 d：$L_d=\sum_{t\in V_d}\ell_t/|V_d|$；正式混学每步两组各有同数有效答案目标，因此目标为 $(L_A+L_B)/2$。

筛选时，以每条记录答案预测位置的平均 u 作来源判别，得到独立筛选半区上的平衡准确率 $D_{ij}$。它测来源是否可读，不是完整分布距离或语义距离。

同一冻结起点上，$G_d=\partial L_d/\partial W$ 是完整有效权重坐标的梯度，只读取、从不更新 W。定义

$$C_{ij}=\frac{\langle G_i,G_j\rangle_F}{\|G_i\|_F\|G_j\|_F}.$$

C 是方向兼容性代理，不是 LoRA／Adam 实際一步的损失后果。使用完整 W 坐标避免零初始化 LoRA 中一侧因子梯度为零、随机低秩基改变筛选排名的问题；代价是它没有证明秩 16 真能实现该更新。独立诊断正是检查这条桥梁。

任务对 p 内主对照是共享秩 16（S16）与按任务隔离的两个秩 8（D8），两者总可训练参数都是 65,536。令 $\Delta_p=\bar L_{S16,p}-\bar L_{D8,p}$，其中 $\bar L$ 为两任务等权平均；正值表示隔离更好。本轮唯一主要比较量为

$$\Gamma=\Delta_{P-}-\Delta_{P+}.$$

Γ 单位为 nats/有效答案词元。其正值只说明两个选定任务对的隔离收益排序符合预测；还须 P− 自身有正收益、胜过混合分组且通过局部互损检查，才形成完整有限支持。不同答案分布仍有熵和难度差异；共同单位和共享来源不能消除这些混杂。

**容量诊断 D16：**增加按任务隔离的两个秩 16 分支，每个词元只使用其中一个。其总可训练参数为 131,072，每词元活跃参数为 65,536；S16 为 65,536／65,536，D8 为 65,536／32,768。比较 D16 与 D8，检查固定隔离方式下增大分支容量是否改善（秩变化也会改变优化过程，并非纯容量测量）；比较 D16 与 S16，检查每任务活跃秩相同后隔离的表现，但总参数已翻倍。定义 $Q_p=\bar L_{D8,p}-\bar L_{D16,p}$ 和 $E_p=\bar L_{S16,p}-\bar L_{D16,p}$，正值分别表示增大隔离分支有益、D16 优于 S16。二者是次要容量诊断，不能替代或挽救主要 Γ。

局部检查 $H_{A\to B}=L_B(\phi+u_A)-L_B(\phi)$：φ 是同一 S16 参数／优化器状态，u_A 为只加入 A 新梯度的可回滚 Adam 更新。独立 A 必须改善；另与保留动量但零新梯度分支比较，并缩小步长。它识别这次干预的局部影响，不单独识别 Γ 的长期因果来源。

## 5. Computational Realization

模型沿用已执行旧实验的**从头训练 S7、重构系数 0.1、精确 21B 词元**检查点，不回退到最初草稿的重加权续训 S7。具体路径与哈希在 Protocol。旧六条件增量参数化、身份校验和回滚结构可复用；旧正文数据循环不可直接复用答案任务。

候选来源为本地已有 MMLU、MMLU-Pro、BBH、GSM8K、MATH、GPQA、HumanEval、MBPP。先恢复原题、参考答案、原始来源版本和题目家族，统一外层输入模板；代码保留空格换行，选择题保留选项及正确字母对应关系。剔除无答案、歧义标签或上下文容不下完整题答的记录，不截断成看似能训练的题。数据资格先按库存／来源／去重确定，不以最终效果筛选。

每来源的信息角色：SCREEN 两半只用于 D/C 和选对；TRAIN 用于适配；DEV 用于单任务可学性；DIAG_UPDATE／READOUT 分别用于虚拟更新和独立读损失；CONFIRM 留到训练和分析冻结后。先按原题／近重复家族分组，再划分，不能先切 token。

旧官方题库含历史研究使用，不能宣称全新基准或基座未见。优先从旧 train 保留本轮独立确认题；任何曾用于旧结果选择或本模型评估的题族从新 CONFIRM 排除。历史来源证据不够时标记身份问题并停止确认资格；旧 test 可作探索参考，不能改名为新证据。八来源不代表八个来源都够用；尤其短选择题的监督词元可能比样本条数暗示的少。

选对算法在 Protocol 冻结：最多 28 对只做筛选，正式最多两对；P− 和 P+ 都高 D、共享一个来源、D 相近，C 分别负／正。不存在这样的组合时停止，不强行挑所谓“最远”的一对，不降低门槛。MMLU×MBPP、MMLU×MATH只是待测候选，不预先指定赢家。

正式每对保留 A-only16、B-only16、S16、S8、D8、R8，并加入 D16，共七条件；R8 的每个专家混学两任务，控制参数数目、活跃秩和负载。D16 与 S16 使用数值相同的秩 16 初始化，各分支参数及优化器状态独立；它与其余混学条件共用目标流、损失分母和日程。所有种子使用相同硬件型号，减少旧种子／设备混杂。两对采用同样每源答案词元预算、损失分母和日程；单任务与共享按本任务曝光对齐，仍明确其全局批量不同，不能把 Solo 差值当作纯因果效应。

方法来源：采用 [LoRA](https://arxiv.org/abs/2106.09685) 的参数化；适配 [任务分组研究](https://arxiv.org/abs/2109.04617) 的跨任务更新后果读数。该研究不保证本实验有效；[梯度干预研究](https://arxiv.org/abs/2001.06782)也不能被简化为“夹角负就必然长期有害”。本轮不加入梯度手术，避免同时改变处理变量。

## 6. Minimal Falsification Tests

**一个实验、两个任务对，三个依次检验的环节。**

1. 筛选阶段是否构造出可分度相近、方向关系不同且库存合格的两对？失败意味着所定义载体未构造出，不是已经证伪所有更新干扰。
2. 各任务 Solo 是否在 DEV 有独立改善？未通过则相应任务对不具备完整机制检验资格，不能用“分开更差”掩盖学不动。
3. 独立 CONFIRM 上 Γ 是否达到预设大小，P− 是否自身获益、胜 R8；独立回滚是否支持局部互损且强于 P+？所有判断使用预定终点／状态，不能看曲线挑最冲突时刻。

提案主要门槛为 Γ 的 95% 配对区间下界 >0.01，三个固定训练种子方向一致。完整支持还要求 P− 的 Δ 区间下界 >0.01、R8−D8 下界 >0，以及预定局部损害规则。区间上界 ≤0.01 为未支持预设大小的 Γ；跨门槛为不足。局部与功能结果允许不同状态，不压成一个笼统 PASS。

单对成功但两对排序不成立，只保留该对的分开收益；排序成立而局部检查失败，只支持有限功能排序，机制保持未知。即使全部通过，也没有测过足够多独立任务对来建立普遍预测规律。

容量结果另读：若 D8 较差、D16 明确改善并优于 S16，说明原比较对隔离分支容量敏感，但改善仍可能来自总容量增加，不能宣布纯干扰机制成立。若 D16 改善 D8 却仍较差，只支持增大分支有益、尚未建立隔离优势。若 D16 没有明确改善，容量解释保持未决；区间足以排除预定有意义改善时，才可排除“从秩 8 增至 16 会带来该大小改善”这一窄预测。未显著不等于相等；不从有限秩范围推出容量充足。Protocol 单列容量状态，不改主假设判据。

## 7. Current Evidence

[旧 DEV／rollback 报告](../../../0924/docs/analysis/dev_rollback_reading_cn.md)及其 JSON 本次已核对：18 条训练与三套诊断完成；单学末端 A/B 改善约 0.086/0.065 nats/token；S16−D8 为 −0.00900，95% DEV 区间 [−0.01012,−0.00787]；早期预定回滚平均为跨组改善。确认分析清单仍标未解封，不能写成正式确认的零效应。

安全解释：该载体可学，却未展示固定总参数的隔离优势；它不支持原先希望的完整案例。不能从中推出数据分布相同，也不能说“仅主题语义差异”已被纯净控制，因为来源审计记录有非主题文本。

研究者引用对话 `6ab5208f-fc14-83e8-844d-91bfe1329d0b` 的最后回复（本次已读取）提出了八来源 D/C 筛选和一对压力测试。本稿继承问题方向，新增独立验证和兼容参照；该回复本身不是结果证据、数据清单或执行授权。

新任务的[筛选与执行记录](detailed.md)显示：8 个候选来源中 6 个通过角色库存；这 6 个来源形成的 15 对都达到可分度门槛 $D\geq0.75$，但没有一对在两半 SCREEN 都满足预定 $C\leq-0.05$。最接近的 MATH–MMLU 为 $-0.06350/-0.04815$，第二半仍未过线。因此没有预定 P−／P+，只能判 `SCREEN_NO_ELIGIBLE_CONTRAST`；这是载体构造失败，不是训练效应为零。七条件四卡 5090 工程 smoke 已通过，但不产生主要科学结果；Solo、混学、回滚与 CONFIRM 未运行。

## 8. Claim Boundary And Next Decision

支持范围最多是：一个固定 21B 基座、一个低秩插入位置、固定答案监督和两个预先选择任务对上的兼容性信号／功能后果对应。不能称“更新要求比人类语义普遍更重要”“分布差异造成了冲突”“筛选最负就一定适合分专家”，更不能推广到 SAE 路由或从头 MoE。D16 也不能单独排除共享模型总容量不足：D16 若胜 S16，两者总参数不相等；若后续要拆开总容量与隔离作用，需另行设计如 S32 的同总参数共享对照，本轮不自动扩充。

**当前决定（研究者已确认）：本轮按原协议停止**；没有合格 P−／P+ 时不提交正式训练，也不事后放宽 $C$ 门槛。**唯一后续决策（AI 建议，尚未由研究者采纳）：是否另立问题与预登记方案来检验新的兼容性代理。**完成标准是明确新代理为何能分离“局部方向”与“后续实际互损”，在读取新验证数据前锁定对照和停止规则；若不重开，则本问题保持 `Unknown`，不从当前筛选推论共享或隔离的普遍优劣。
