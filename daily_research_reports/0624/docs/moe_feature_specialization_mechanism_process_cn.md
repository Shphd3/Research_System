# 稀疏专家模型特征分工：研究过程与机制解释文档

## 微型总结

当前问题不是“让负载看起来均匀”本身，而是：**均匀出现的特征，能否进入一个不塌缩、可解释、训练后可保持、并且有功能价值的专家分区。**

现在最强的机制线索是：隐藏状态里存在跨特征共享的共同成分 `c`。只选一个专家的线性门控器会计算 `w_e^T h`。即使门控器没有显式偏置，`w_e^T c` 也会变成“专家 e 的隐式偏置”。早期被这个隐式偏置选中的专家会收到更多样本和梯度，形成早期锁定。真实文本上，替代特征在第 0 步可以被线性路由，但第 5/10 步会被普通训练覆盖，所以当前主瓶颈是**早期训练保存**，不是单纯的第 0 步初始化。

---

## 0. 裁定

**裁定：** 研究主线应从“均匀负载”改写为“反共同成分、反早期锁定、保存特征分区、证明功能价值”。

**阻塞问题：** 真实文本训练中，已经可路由的替代特征会在早期训练窗口被覆盖。也就是第 0 步有结构，第 5/10 步结构消失。

**保留：** 共同成分导致早期塌缩的机制解释；已知特征中心和伪特征中心能形成分区的正控；07 线中“分区能降低稀有特征干扰，并有专家功能价值”的受控证据。

**不清楚：** 真实文本中的共同成分来源；如何无标签筛出真正和路由有关的隐藏状态；如何让训练保存分区而不伤害语言建模损失。

**最小下一步：** 写并执行一个真实文本早期保存协议：检验门控器共同成分控制或反早期锁定，能否让替代特征分区穿过第 5/10 步窗口。

## 1. 研究问题应该怎么说

### 1.1 父问题

**稀疏专家模型的门控器，能否让专家形成稳定、可解释、可复用的特征级分工？**

这里“特征级分工”至少包含四层含义：

1. **同特征一致：** 同一个特征的样本倾向于进同一组专家。
2. **不塌缩：** 不是大多数样本都进少数专家。
3. **特征身份清楚：** 路由分组能对应到可操作的特征轴。当前受控设置中，特征轴优先使用“槽位”；如果常量词元 `B_i` 也变化，则最小一致性键应是 `(槽位, B_i)`。
4. **有功能价值：** 被选中的专家不只是标签上对齐，还真的对该组样本的损失或消融有贡献。

### 1.2 当前子问题

当前最小子问题是：

**为什么特征频率已经均匀、门控器也是随机初始化，普通只选一个专家的门控器仍会在初始化或早期训练中塌缩？如何构造一个不塌缩、特征对齐、且训练后能保持的初始分区？**

这比“如何把特征均匀分到专家”更准确。原因是：

- 负载均匀只是排除单专家塌缩；
- 负载均匀不等于同特征一致；
- 同特征一致不等于专家有功能价值；
- 因此 07 线必须进入主线，用来证明分区确实降低特征干扰。

### 1.3 会议中最安全的一句话

**我现在不是直接声称稀疏专家模型已经形成了语义专家，而是在拆解：为什么均匀特征也不能稳定进入专家分区；什么机制能让这个分区在早期训练中保存；以及这个分区是否真的降低特征干扰。**

## 2. 机制模型：为什么特征均匀也会塌缩

### 2.1 变量定义

- `f`：一个特征身份，例如受控任务中的槽位。
- `e`：一个专家编号。
- `h_f`：带有特征 `f` 的样本在路由位置的平均隐藏状态。
- `c`：所有特征共享的共同成分。
- `r_f`：特征 `f` 自己的剩余成分。
- `w_e`：门控器中专家 `e` 的打分向量。
- `z_{f,e}`：特征 `f` 被专家 `e` 接收前的门控分数。

核心分解是：

```text
h_f = c + r_f
```

门控分数是：

```text
z_{f,e} = w_e^T h_f = w_e^T c + w_e^T r_f
```

定义：

```text
a_e = w_e^T c
```

`a_e` 对所有特征都相同，所以它不是特征信号，而是专家 `e` 的隐式共同偏置。

### 2.2 第 0 步塌缩的充分条件

令 `e*` 是共同偏置最大的专家：

```text
e* = argmax_e w_e^T c
```

比较专家 `e*` 和任意其他专家 `e`：

```text
z_{f,e*} - z_{f,e}
= (w_e* - w_e)^T c + (w_e* - w_e)^T r_f
```

第一项是共同成分带来的优势，第二项是特征剩余成分带来的修正。

如果对所有特征 `f` 和所有其他专家 `e` 都有：

```text
(w_e* - w_e)^T c > |(w_e* - w_e)^T r_f|
```

那么：

```text
z_{f,e*} > z_{f,e}
```

也就是说，所有特征都会被送到同一个专家 `e*`。这说明：**特征频率均匀并不能保证专家负载均匀。只要共同成分在门控分数中压过特征成分，就会塌缩。**

### 2.3 早期锁定

第 0 步的共同偏置只解释“塌缩种子”。最终塌缩还需要训练动态解释。

直觉是：

1. 第 0 步某个专家因为 `w_e^T c` 获胜。
2. 只选一个专家的门控器会让获胜专家接收更多样本。
3. 接收更多样本的专家得到更多梯度，变得更适合当前样本。
4. 门控器和专家一起适应早期分配。
5. 于是初始小偏差被放大成稳定分配。

一个极简动态可以写成：

```text
δ_{t+1} ≈ (1 + ρ) δ_t + noise,  ρ > 0
```

这里 `δ_t` 是第 `t` 步的专家优势。如果 `ρ > 0`，早期优势会放大；如果没有反锁定机制，门控器很容易进入共同成分主导的盆地。

### 2.4 负载不均不等于特征分工

导师最近的一个重要更新是：负载误差至少有三类来源，不能混在一起。

```text
观测到的负载误差
= 真实决策区域不均衡
+ 有限样本抽样噪声
+ 门控器行范数或隐藏共同成分造成的几何偏差
```

因此，随机路由和负载不均只是机制审计线，不是最终特征分工证据。高维归一化方向会降低随机地板；高斯初始化的门控行如果范数不同，也会制造额外不均衡。判断特征分工时必须同时看：特征一致性、负载、任务损失、共同成分分数和功能价值。

## 3. 导师新路线对本问题的启发

导师的尺度无关表示路线提出了一个更大的图景：语言中的组合结构会复用早先学到的结构，而交叉熵优化会偏向高增益方向。高增益方向是指某个矩阵的奇异值很大，因此隐藏状态沿这个方向的小变化，会在输出或注意力分数上产生更大变化。

对输出矩阵 `W`，若 `W = UΣV^T`，沿隐藏侧奇异方向 `v_i` 的梯度步贡献近似为：

```text
损失下降_i ≈ -学习率 × σ_i^2 × <u_i, p - y>^2
```

这句话的含义是：**一个方向被优化选择，不是因为它几何上好看，而是因为它同时有大增益 `σ_i`，并且和当前预测误差对齐。**

这给稀疏专家模型路线一个清楚位置：专家分区不是小工程技巧，而是避免所有特征挤进同一个高增益子空间的一种结构方案。理想情况是，不同特征进入不同专家，每个专家形成局部子空间，从而降低常见特征对稀有特征的干扰。

但这也暴露出当前瓶颈：**如果门控器先塌缩，专家分区就不会发生。** 所以我们现在先研究门控器为何塌缩、如何保持分区，然后再用 07 线证明分区有价值。

## 5. 当前可以讲的主张边界

### 可以讲

1. 在受控均匀特征设置中，塌缩不是因为特征缺失，也不是因为特征分区不可达。
2. 共同成分通过 `w_e^T c` 形成隐式专家偏置，是第 0 步优势专家的强机制解释。
3. 只选一个专家的训练会放大早期优势，形成早期锁定。
4. 真实文本中可以发现稳定替代特征，并且第 0 步能被线性门控路由。
5. 普通真实文本训练会覆盖这个替代特征分区，因此保存机制是当前瓶颈。
6. 受控 D07 结果说明：好的分区不只是负载更均匀，还能减少稀有特征干扰，并出现专家功能价值。

### 不能讲

1. 不能说塌缩已经解决。
2. 不能说负载均匀就是专家分工。
3. 不能说替代特征就是自然语言语义。
4. 不能说共同成分唯一来源已经确定。
5. 不能说共同成分控制已经是可部署架构。
6. 不能把受控 D07 直接外推到真实大模型。

## 6. 结果应该怎么呈现

### 6.1 主指标

| 指标 | 它回答的问题 | 不能误读成什么 |
|---|---|---|
| 特征一致性或替代特征一致性 | 同一特征是否稳定进同一专家？ | 不能单独证明专家有功能价值。 |
| 最大负载或负载不均 | 是否出现少数专家吸收大多数样本？ | 负载均匀不等于特征对齐。 |
| 任务损失或准确率 | 模型是否仍学会任务？ | 学会任务不等于门控形成分工。 |
| 共同成分优势 | 第 0 步是否被 `w_e^T c` 主导？ | 只能解释机制项，不是最终性能。 |
| 第 0/5/10 步轨迹 | 分区是否穿过早期训练窗口？ | 只看最终点会错过第一次失败位置。 |
| 专家功能消融 | 被选专家是否真的有用？ | 没有保存路由时不应做此测试。 |

### 6.2 建议图

1. **机制图：** `h_f = c + r_f`，然后画出 `w_e^T c` 如何变成隐式专家偏置。
2. **阶段合同图：** 特征是否存在 → 能否第 0 步路由 → 能否第 5/10 步保存 → 是否有功能价值。
3. **早期轨迹图：** 第 0、5、10 步的特征一致性、最大负载、共同成分优势。
4. **价值图：** 稀有特征损失：密集模型、负载匹配模型、共同成分控制模型、正控专家模型。

## 7. 下一步机制推进

### 7.1 主线优先级

当前最快推进主线的一步是：

**真实文本早期保存 / 反反馈协议。**

它的问题不是“再找一个让负载更均匀的方法”，而是：

**能否让第 0 步已经存在的替代特征分区，穿过第 5/10 步训练覆盖窗口，同时不伤害语言建模损失？**

### 7.2 这个协议区分的竞争解释

| 竞争解释 | 如果它是真的，会看到什么 | 需要的裁定 |
|---|---|---|
| 替代特征本身不稳定 | 聚类稳定性低，第 0 步线性路由也弱。 | 已有证据不支持它是第一失败点。 |
| 第 0 步线性桥接不够 | 第 0 步替代特征一致性低。 | 已有证据显示第 0 步桥接通过。 |
| 普通训练反馈覆盖分区 | 第 0 步强，第 5/10 步崩溃，损失仍正常下降。 | 这是当前主解释。 |
| 只需要负载均衡 | 负载改善后，替代特征一致性也保持。 | 如果负载好但一致性低，此解释失败。 |
| 共同成分是主要驱动 | 控制共同成分后，第 5/10 步一致性保存更好。 | 若损失不坏且一致性提高，则支持。 |

### 7.3 最小实验协议草案

固定：真实文本数据、小型稀疏专家模型、只选一个专家、第 0 步替代特征中心、相同训练预算。

候选变体不应被当成“方法竞赛”，而是机制干预：

1. **普通训练基线：** 复现第 0 步强、第 5/10 步崩溃。
2. **门控器共同成分抵消：** 专家仍看完整隐藏状态，门控分数减去共同成分诱导的偏置。
3. **门控器输入去共同成分：** 专家看完整隐藏状态，门控器只看共同成分受控后的表示。
4. **早期反锁定：** 只在第 0 到第 10 步窗口使用软化门控或负载约束，之后回到普通训练。
5. **正控保存：** 用固定或慢更新的替代特征中心作为上界，不作为可部署方法。

### 7.4 成功和失败标准

成功不是“负载更好看”。成功至少需要：

```text
第 10 步替代特征一致性显著高于随机基线；
最大负载不过度集中；
语言建模损失不明显恶化；
早期共同成分优势下降或被解释；
同一随机种子下结果可复现。
```

失败也有信息：

- 如果负载改善但替代特征一致性不改善，说明只是负载控制，不是特征保存。
- 如果一致性改善但损失恶化，说明方法破坏了预测学习。
- 如果第 5 步改善但第 10 步消失，说明反锁定窗口还不够，或专家功能共同适应仍在覆盖分区。
- 如果正控也失败，说明替代特征本身可能和真实训练目标不兼容。

## 8. 如何像导师一样提炼机制

每次看到一个结果，先不要问“下一个方法是什么”。先填五行：

```text
观测：实际观测到了什么？只写数值和图，不解释。
解释：这个观测支持哪个机制项？
竞争解释：它排除了哪个竞争解释？没有排除什么？
主张边界：因此主张边界向前移动了多少？
下一裁定：下一步只需要裁定哪一个问题？
```

例子：

```text
观测：真实文本替代特征第 0 步一致性约 0.75，第 5/10 步接近随机，损失没有崩。
解释：替代特征发现和第 0 步线性路由不是第一失败点；训练反馈覆盖是瓶颈。
竞争解释：排除“根本没有可路由替代特征”的一阶解释；没有排除“替代特征没有功能价值”。
主张边界：可以说当前管线坏在保存阶段，不能说真实专家分工不可能。
下一裁定：测试早期反反馈是否能保存替代特征分区。
```

这个模板能防止两个常见错误：

1. 把调试图当成核心证据；
2. 把负载改善当成专家分工。

## 9. 汇报时的核心句

**共同成分解释为什么均匀特征也会在第 0 步产生优势专家；早期锁定解释为什么这个优势会被训练放大；阶段合同解释为什么真实文本瓶颈不是发现替代特征，而是保存它；07 线解释为什么分区值得保存，因为它能在受控环境中减少稀有特征干扰并产生专家功能价值。**
