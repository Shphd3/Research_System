## 一句话问题

同一个 SAE 中，利用高层组合节点及其真实连接，是否比不区分层级的分组更能组织稳定、有用的输入类别？

最强竞争解释：高层节点只是更少见、覆盖更窄；看起来语义更纯，不代表连接本身有用，更不代表适合做粗粒度父类。

## 2. 学长怎样得到高层节点？参数有哪些？

### 方法不是另训练一个高层 SAE

组合节点仍是同一个 SAE 已有的原子。若一个较少见原子出现时，几个较常见原子几乎总一起出现，就把它标成候选组合节点。如果组成原子本身又是组合节点，就出现多级结构。

记较少见组合原子为 C，组成原子为 B。学长可查材料的核心规则是：

\[P(B\text{ 激活}\mid C\text{ 激活})\geq0.98.\]

白话：看到 C 时，几乎一定也看到 B；看到 B 时却未必看到 C。这是激活集合的包含关系，不是自动得到的人类语义父子关系。源码边方向是“组合 → 组成”。图上更高的 C 通常更少见，可能是更具体的条件组合；不能直接称它为语义粗父类。

| 可查代码的构图参数 | 值 | 白话作用 |
|---|---:|---|
| 组合原子最少出现次数 | 100 | 避免极少样本的偶然关系 |
| 组成原子候选池 | 最高频4096个 | 限定搜索范围 |
| 组成原子在组合出现时也出现 | ≥0.98 | 近乎包含 |
| 反方向包含概率 | <0.98 | 排除近乎相同的原子 |
| 组成／组合出现次数比例 | ≥1.5 | 组成原子更普遍 |
| 每个组合包含的组成原子数 | 2–8 | 不是一对一复制 |
| 所选组成原子同时出现的概率 | ≥0.90 | 要求联合共现 |
| 独立复现、联合预测增益 | 只作诊断 | 学长这套宽松图不以它们筛掉候选 |

来源：[学长方法说明](/data/250010109/Research_System/Projects/Ruijun_Separable_Gating/MTP/feature—composition0730/EXPERIMENT_SUMMARY.md:34)、[可查代码默认值](/data/250010109/Research_System/Projects/Ruijun_Separable_Gating/MTP/feature—composition0730/code/run_feature_composition_spectrum.py:133)。默认值不等于截图那次运行的完整实参。

### 截图中的“0.5”不能和这套0.98混用

学长[旧图说明](/data/250010109/Research_System/Projects/Ruijun_Separable_Gating/MTP/feature—composition0730/DAILY_SUMMARY_VARIANCE_AND_COMPOSITION_20260805.md:114)明确写“关系阈值0.5”，共有六层（深度0–5）、1047个节点；它不是“最大深度6”。目前查到的材料未给出该0.5关系分数的精确公式及完整运行配置，不能说它就是原子激活值阈值，更不能承诺把本代码的0.98改成0.5就能复现。

我们自己的原子激活规则是保留前32个正响应，没有额外的0.5激活阈值。不同版本的学长 SAE、训练数据和分析数据也不能仅凭截图认定一致。精确对齐旧图仍缺：生成脚本版本、实际参数清单、SAE检查点及分析数据身份；这是待补来源，不是本轮自主索取或外部同步任务。

## 3. 已有分析告诉我们什么？

[E18完整结果](/data/250010109/Research_System/Projects/from-attention-to-search/main/experiments/A15/15_13_semantic_supervision_middle_layer_formation/A15_13_E18_dataset_conditioned_sae_semantic_hierarchy/summary.md)已经检查过深度与语义，不能把下一步说成首次探索：

- 某些分析语料上，更深节点对标签更专一；但粗类、细类的专一性常一起上升，没有可靠的粗—细职责交接。
- 原DCLM图在三粗类、九细类的标签数据上，仅两条边通过语义检验，覆盖一个粗类、两个细类；不能当完整路由教师。
- 原图深度2节点在语义确认中支持不足；跨分析语料，原激活关系保留较少。稀有性和数据条件是必须面对的原因。

所以最值得补的不是另一张“深度越高纯度越高”的曲线，而是：**控制节点频率和覆盖后，高层节点是否仍有用；真实连接是否比随意配对多提供信息。**

## 4. 两阶段离线实验：执行顺序

方法、指标、匹配规则、文件清单及实现顺序统一维护在[两阶段离线分析与初步实现计划](/data/250010109/Research_System/daily_research_reports/0909/sae_offline_two_stage_implementation_plan_cn.md)。本页保留概念和历史参数，不再维护另一套独立计划。

### 阶段一：选哪些原子？

- [ ] 先标出图内叶节点、中间／高层组合节点及背景原子，并检查实际激活文本。
- [ ] 用相同分组算法和8组预算，比较叶节点与高层节点；当前完整映射只作历史参考。
- [ ] 双方按发现频率与数量匹配，比较内容一致性、覆盖和稳定性；未覆盖不能删除。
- [ ] 输出组×内容分布图、纯度×覆盖率图、匹配清单与逐记录指标。

要回答：高层节点是否比叶节点提供更合适的分组对象，还是只因为稀有而显得更纯？

### 阶段二：真实连接有用吗？

- [ ] 固定同一公共叶节点集合和8个终端组，比较直接单层分组与高层锚点引导的嵌套分组。
- [ ] 初步建议2个父组、各4个细组；父归属可以重叠但每叶总权重为1。该默认尚待确认，不按任务标签选父组数。
- [ ] 加入保留节点连接数和频率分层的打乱连接比较，先验证对照确实改变父归属。
- [ ] 检查真实连接是否在同等覆盖下提供额外区分，并出现稳定的宽父组／细分工。

要回答：有效的是节点本身，还是节点之间的真实组织关系？阶段一没有胜出不自动阻止阶段二；只有支持、隔离或构造不可行才停止。

### 本轮不做什么？

不重新训练SAE，不训练路由，不增加专家，不执行远程全量评测。离线结果只能决定是否值得进一步训练；不能直接确定何时需要扩容。
