## 1. 窄专家训练：学选路改善长尾，整体仍落后 A0

[观察] 在 10 亿有效 token 处，三条 S4 轨迹均有完成回执。5090 上学习选路与哈希选路的对照显示，学习选路让长尾 CE 低 **0.03181 nat**，总体只低 **0.01168 nat**。Reserved S4 相对 A0 的总体差距为 **+0.07761 nat**。L4 最近的共同评估点是 2.62 亿 token，S4 与 L4 的长尾差约 0.0023 nat，共享与独立子空间的长期优劣仍为 Unknown。

| 模型 | 总体 CE | 高频 | 中频 | 长尾 |
| --- | ---: | ---: | ---: | ---: |
| 原生 MoE（A0） | 3.77943 | 2.58976 | 5.13487 | 6.72434 |

## 2. 输出尺度对照：总体追回 12.2%，长尾变差

[观察] 第 1,000 步，同为 262,144,000 个训练 token，在同一批 2,097,152 个 EVAL 位置上对齐。A0、原 Reserved S4、S4-scale 总 CE 分别为 **4.62878、4.69730、4.68896**。

| 频段 | 原 S4 − A0 | 原 S4 − S4-scale [95% 区间] | S4-scale − A0 |
| --- | ---: | ---: | ---: |
| 总体 | +0.06853 | +0.00835 [0.00762, 0.00903] | +0.06018 |
| 高频 | +0.05545 | +0.01875 [0.01798, 0.01957] | +0.03670 |
| 中频 | +0.11603 | +0.00837 [0.00685, 0.00983] | +0.10766 |
| 长尾 | +0.01884 | −0.04729 [−0.04969, −0.04503] | +0.06613 |

[AI 分析] 只校准混合输出的幅度，高频受益最多。总体改善小于事先设定的 0.02 nat 门槛，长尾反而变差。区间来自评估位置配对自助法，种子方差 Unknown。

[AI 建议] 下一条训练对照可把一部分激活计算预算划给每个 token 都经过的全宽共享 FFN，同时用已有检查点评估扩大候选集的收益。宽分支目前是待测设计，性能 Unknown。

## 3. 冻结 Qwen：选组还有空间，频率差异来自恢复幅度不同

| 测量 | 结果 |
| --- | --- |
| 单层 MLP 的压缩易损位置 | 能量选组的 ΔCE 为 0.426 nat，只看原模型分布选组可降至 0.294，蒸馏小 MLP 路由为 0.440。 |
| 联合拟合子空间和路由 | 全词表 KL 从 0.301 降到 0.276，目标词 ΔCE 从 0.440 升到 0.488 nat。 |
| 输出层降到 256 维 | 相比随机投影，学习投影使常见词 ΔCE 从 20.374 降到 0.478 nat，罕见词从 19.975 降到 2.332 nat。剩余损伤比从 0.98× 升至 4.88×。 |
| 随机投影 KL 二阶校准 | 四种宽度均未通过分档校准。256 维总体预测均值与实测相差约 2%，十个分档仍有六档偏离预设区间。 |

[AI 分析] 学习投影帮助了两类词，常见词恢复更多。小路由没有追回这一轮无答案选组的差距。单层冻结结果到整模预训练的可迁移性仍为 Unknown。
