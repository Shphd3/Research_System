# 图表逐张阅读：怎样看出“可读但不够不变”

## 先说读图原则

本文件中，E01 是单库边界迁移审查，E02 是表达库边界覆盖对照；
模型块（Block）是 Qwen 的深度编号，分类间隔（margin）是样本到最近
错误类边界的有符号几何距离。类距离归一化方差（CDNV）只描述类内
散布相对类中心距离，不是线性可分证书。

本轮图不是用二维投影“看簇分没分开”。真正裁决结果的是高维线性头在未参与拟合的完整模板族上的预测和几何间隔。图只负责把已经注册的统计量展示出来。

每次读图都按四个问题：

1. 横轴和纵轴具体是什么对象；
2. 点表示观测值，误差线表示哪一种不确定性；
3. 零线以上允许说什么；
4. 哪些因果或功能结论不在图中。

## 图一：E01 六层平均可读性与低尾间隔

![E01 六层可读性与间隔](../../../../Projects/from-attention-to-search/main/experiments/A15/15_12_semantic_representation_separability/A15_12_E01_qwen3_30b_fixed_fact_expression_separability/figures/layerwise_readability_and_margin.png)

### 怎么读

- 横轴是 Qwen Block 4、12、20、28、36、44；
- 面板或曲线区分父类、64 类联合和父类条件细类；
- 准确率回答平均样本有多少被读对；
- 第五百分位间隔回答困难约 5% 样本是否仍在正确边界一侧。

最重要的现象不是“C5 还有不错的准确率”，而是 C4 训练得到的头到了 C5 后，中间层准确率下降并且多个细类低尾进入负值。它说明信息没有完全消失，但困难样本不再被同一条边界稳定保护。

### 不能说

- 准确率 90% 不能等于“线性可分”；
- 高维里某条线性边界失败，不能等于不存在任何另一条线性边界；
- 这一图不涉及原生专家选择。

## 图二：E01 每层最差任务瓶颈

![E01 最差任务低尾](../../../../Projects/from-attention-to-search/main/experiments/A15/15_12_semantic_representation_separability/A15_12_E01_qwen3_30b_fixed_fact_expression_separability/figures/all_task_bottleneck_margin_one_sided.png)

### 为什么要看“最差任务”

一个真实全粒度语义分发系统不能因为七个父类内部细分得好，就忽略第八个父类完全失败。因此每层先计算十个任务的第五百分位，再取最小值。

E01 的 C4E-B 六层最差任务下界为正；冻结边界移到 C5E 后六层最差任务观测值为负。最差任务依次集中在数学、物理等父类内部的细分，不是联合 64 类头独有的失败。

图中的误差线是从观测值向下的单侧下界，不是对称标准差。原始运行图曾把单侧下界画成对称误差条，数值没有错但视觉语义错误；规范图已经更正为只向下延伸。

## 图三：E01 C5 联合类别的距离归一化类内散布

![E01 C5 类距离归一化方差](../../../../Projects/from-attention-to-search/main/experiments/A15/15_12_semantic_representation_separability/A15_12_E01_qwen3_30b_fixed_fact_expression_separability/figures/c5_joint_cdnv_heatmaps.png)

### 怎么读

每个格子比较两个联合类别：分子是两个类别内部的平均散布，分母是两个类别中心的平方距离。值大表示类内散布相对中心距离大。

它只能帮助找到“哪些类别对几何上更挤”，不能裁决线性可分性。实际结果中，它与分类混淆的相关性很弱。因此不要寻找最亮格子后直接说“这就是失败原因”；真正的直接错误要看混淆表。

### 最重要的实际混淆

- Block 4 的 C5 物理细类，21 个错误全部来自 `mechanics`，其中 16 个被判为 `relativity`；
- Block 20 的物理细类，`mechanics` 大量流向 `electromagnetism`；
- Block 36 的数学细类，`probability`、`geometry`、`analysis` 大量流向 `algebra`；
- Block 36 的联合任务中，多个经济学细类流向 `public economics`。

这些是“哪个局部语义边界失效”的直接定位，不证明类别本身没有语义。

## 图四：E02 四种训练条件的同时低尾

![E02 四训练条件低尾](../../../../Projects/from-attention-to-search/main/experiments/A15/15_12_semantic_representation_separability/A15_12_E02_expression_bank_boundary_coverage_controls/figures/simultaneous_bottleneck_comparison.png)

### 图的组成

- 左面板在 C4B 测试，右面板在 C5B 测试；
- 紫色只看 C4，橙色只看 C5，绿色看两个库但没有样本量优势，蓝色看两个库的完整 A 半；
- 圆点是十个任务中最差的观测第五百分位；
- 向下误差条是一个同时保护全部 48 单元的下界；
- 虚线零轴是证书门槛。

### 第一眼应该看什么

在左图，紫色 C4 边界强、橙色 C5 边界弱；右图恰好反过来。这不是“一个库更难”的简单故事，而是同一训练量下，边界对自己库有利、对另一个库有害。

蓝色完整双库边界在两边都靠上，说明表征中并非不存在共同线性分法；只要训练覆盖足够，Block 4、12、20、44 可以同时得到正下界。但 Block 28 的 C5B 和 Block 36 的 C4B 仍未获证。

绿色匹配训练量条件只在 Block 4、44 两边同时通过。它告诉我们：仅仅见过两个库并不自动解决中层问题；完整双库的更好结果同时包含更多数据。

### 为什么 E01 写 C4B 6/6，E02 却写 5/6

两者的观测 C4A→C4B 数值相同，差别只在事先注册的不确定性范围：

- E01 的单侧下界保护本实验的 12 个“面板×层”瓶颈，Block 36 下界为
  0.111，因此按 E01 判据是 6/6；
- E02 为了同时比较四训练条件、两测试库和六层，用一条更严格的 48
  单元同时带，Block 36 下界变为 -0.326，因此在 E02 比较中是 5/6。

这不是重跑结果相反，也不能用 E02 事后推翻 E01 的注册判定；它说明
证书强弱取决于同时保护了多少个比较。

## 图五：训练边界切换带来的成对变化

![E02 原始单位成对差值](../../../../Projects/from-attention-to-search/main/experiments/A15/15_12_semantic_representation_separability/A15_12_E02_expression_bank_boundary_coverage_controls/figures/paired_raw_margin_differences.png)

### 为什么这里不用归一化间隔相减

四个训练条件各自有不同的训练侧均方根尺度。直接拿各自归一化后的数相减，会把不同尺子的数字当成同一单位。图五先把间隔还原成原始激活距离，再在同一测试面板和同一层内做处理条件减 C4 的差值。

### 怎么读

- 左图小于零：替换 C4 边界后，C4B 变差；
- 右图大于零：替换 C4 边界后，C5B 变好；
- 置信区间不跨零才支持差异非零。

橙线“C5 减 C4”在 C4B 六层全部小于零，在 C5B 六层全部大于零，而且区间都不跨零。这是表达库条件边界不兼容最直接的对照。

绿色双库匹配条件在 C5B 六层都改善，却在 C4B 前五层显著变差，说明它是折中，不是统一修复。蓝色完整双库在 C5B 六层全部改善，对 C4B 多数层与原 C4 边界没有显著差异，但这同时使用了更多训练数据。

## Block 28 为什么要特别小心

C5 自己训练、自己测试时，Block 28 的观测瓶颈只有 0.015：

- 去掉一个模板族，最差可到 -0.019；
- 固定正则 (C=10,100,1000) 时依次为 -0.016、0.015、0.057；
- 48 单元同时下界为 -3.262。

所以不能因为点估计略大于零就说它稳健。这是本轮唯一同时对“留一模板族”和“固定正则”发生符号变化的单元。

## 与旧的线性 probe 实验到底差在哪里

旧实验和本轮不是同一流程，数字不能直接比较。

| 项目 | 旧 `native_router_representation_controls` | 本轮 E01/E02 |
|---|---|---|
| 数据 | BIND-TAX-V2，19,200 行 | C4E/C5E，各 1,920 行，64 个固定事实叶 |
| 标签 | 仅父类八分类 | 父类、八个父类条件细类、全局 64 类 |
| token | 最终 `Answer:` 位置 | 最终 `Classification:` 冒号位置 |
| 表征 | 原生 Gate 输入 (G) 与相邻层变化 (Delta G) | 六层实际 `block.mlp`/Gate 输入 |
| 层选择 | 先筛全层，再冻结 Block 41/42 | 预先固定 Block 4/12/20/28/36/44，全部报告 |
| 测试 | 同模板与新模板，多随机种子 | 完整模板族隔离、跨表达库、反向与双库覆盖 |
| 间隔 | 未归一化真实类减最强错误类分数 | 训练均方根尺度下的几何边界距离 |

旧实验报告父类平均准确率约 0.71--0.78，但第五百分位分数间隔为负。本轮在更小、固定事实的合成数据上得到接近完美的库内读出，却发现跨表达边界不稳。它们可以同时为真：旧实验更广、更难、对象更粗；本轮更严格地拆了粗类、局部细类和联合类，但事实集合固定。

## 这轮有没有证明“top-k 截断造成线性可分性损失”

没有。当前六层探针取的是 Gate 和 top-k 之前的实际 `block.mlp` 输入。E01/E02 的失败发生在前截断表征与冻结线性边界之间，不能归因于 top-k。

另一项旧审计曾分别读出：

- (H)：Gate 前隐藏表示；
- (Z)：全部专家 Gate 分数；
- (Q)：只保留 top-8 后的离散/稀疏选择。

那项结果显示父类可访问性从 (H/Z) 的高水平降到 (Q) 的约 0.40--0.56，因此支持“top-8 是额外可访问性瓶颈”。但它使用另一流程，只涉及父类关联，也没有证明专家效用。这项结论不能替代本轮跨表达表征审计。

## 父类—专家负载热图应该怎样读

虽然它不是本轮主图，但以后读 MoE 热图时要先问归一化方向：

- 横轴通常是专家，纵轴是父类；
- 若每一行归一化为 1，格子表示“这个父类的 token 有多少比例流向该专家”；
- 若每一列归一化为 1，格子表示“进入该专家的 token 由哪些父类组成”；
- 原始计数热图还会受父类样本量影响，不能直接比较颜色。

正确阅读顺序：先看每个父类内部是否集中，再看不同父类是否使用不同专家，最后与总体专家负载基线比较。一个格子很亮只说明路由关联，不说明专家对该父类更有用；还必须用反事实替换、专家损失差或其他效用指标验证。

## 最后一条读图纪律

> 点在零以上是观测；误差线下端也在零以上才是注册证书。准确率高表示平均可读；同一边界跨库仍有正低尾，才表示表达不变。热图关联、线性可读和专家效用永远分开。
