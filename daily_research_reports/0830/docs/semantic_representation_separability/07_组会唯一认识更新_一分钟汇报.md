# 组会唯一认识更新：一分钟汇报版本

本文件中，混合专家模型（MoE）指由路由机制选择多个专家模块的模型；
原生门控层（Gate）是模型内部给专家打分的路由器；模型块（Block）是
Qwen 的深度编号。E01/E02/E03 分别是单库迁移、双库覆盖和 TAX-C4A
联合偏移实验。

## 唯一一句话

> **Qwen 的真实 MoE 入口并不是没有语义，而是语义在每个表达库内高度线性可读，却没有普遍形成一套跨表达稳定的线性坐标；因此当前首先要补的是语义边界的不变性证据，而不是直接把 Router 变复杂。**

## 一分钟口述

我们这次固定 Qwen3-30B-A3B，在 Block 4、12、20、28、36、44 的真实 Gate 输入上，分别检查父类、八个父类条件细类和全局 64 类线性读出。

E01 只在 C4 表达库训练。它在 C4 的未见模板上六层都很强，但同一边界移到使用相同事实、不同组织方式的 C5 后，六层最差细类低尾都为负。所以第一步说明：有语义信息，但一套 C4 边界不跨 C5 稳定。

E02 再让 C5 自己训练。C5 自己测试时六层观测低尾都为正，平均任务准确率约 99% 以上；其中 Block 4、12、44 经过保护全部 48 个比较的同时校正后仍为正。反向 C5→C4 又全部未获证。因此这三层可以明确说：不是 C5 没有线性语义，而是两个表达库最适合的边界不兼容。

让训练同时看两个表达库以后，匹配训练量条件只在 Block 4、44 两边同时稳健；完整双库条件在 Block 4、12、20、44 同时稳健。这说明共同线性边界可以存在，但完整条件同时改变表达覆盖和训练量，当前不能断言二者各自多重要；中层仍是瓶颈。

所以我们的更新不是“高维表征不可分”，而是“库内可读不等于跨表达不变”。下一步只做一件事：冻结原来的 60 个探针，测试 TAX-C4A 的另一组事实包联合偏移是否仍能迁移；若失败，还要继续拆分事实、长度和措辞，不能直接判为固定事实签名。

## 与两次会议记录怎样接上

### 接 0828：语义结构不等于 PCA 方差结构

0828 纠正了“二维图没分开就是高维不可分”和“线性映射可以创造可分性”两个错误。本轮用完整 2,048 维线性头验证了这条判断：库内可以接近完美读出，而跨库仍失败；二维簇形状根本不足以描述这一差别。

新的确定认识是：**表征可分性必须写明标签、事实、表达分布、读出函数和稳健范围。**脱离这些条件说“空间可分”没有完整含义。

### 接 0829：可访问性不等于专家效用

0829 的 H→Z→Q 审计指出 top-8 会进一步压缩父类可访问性，反事实专家训练又没有建立层级优势和效用收益。本轮取的是 top-8 之前的 Gate 输入，所以发现的是更上游的问题：语义边界在进入截断以前就可能随表达库变化。

因此证据链应按顺序走：

```text
跨事实与表达稳定的表征读出
→ 有限预算 Gate 能访问
→ top-k 仍保留
→ 被选专家反事实上更有用
→ 语言模型目标改善
```

本轮只走到第一步的一半，不能跳到专家效用。

## 如果导师追问“现在到底证明多少”

### 已建立

- 固定事实下，两个表达库都含有强线性语义读出；
- Block 4、12、44 明确存在表达库条件边界不兼容；
- 完整双库训练在 Block 4、12、20、44 学到两个测试库共同的正低尾边界；
- 失败主要由个别父类内部细类承担，不是全局 64 类组合独有问题。

### 不能说

- 语义对新事实普遍可分；
- 模型学到了唯一或低维的语义子空间；
- top-k 是本轮失败原因；
- 原生 Gate 使用了探针方向；
- 专家更有用或语言模型更好。

### 唯一下一决策

确认当前已审计的 4×RTX5090 入口后提取 TAX-C4A，同位置、同六层，冻结 E01 探针不重拟合；若改选 8 卡，必须先补并审计 8 卡入口。它通过以后才值得另开表示塑形问题；它失败则先拆事实、长度和生成措辞三个联合变化。
