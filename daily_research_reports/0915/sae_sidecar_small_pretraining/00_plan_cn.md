## 1. 本轮问题与归属

研究者的问题：语言模型从随机初始化开始预训练时，语义组织结构是否在表征中逐步形成？在线 SAE 重构梯度能否使领域信息更容易被读取？SAE 能否读出形成过程，并最终支持文本/模型的议题、立场与论证框架画像？

可检验的最小版本：在相同数据、初始化和优化条件下，最后层 MLP 输入的**八类领域宏平均 F1**（每类等权的分类综合分数）是否在 T 中改善，改善何时出现，以及留出语言模型损失代价是多少。宏 F1 与谱、聚类、重构诊断均不能单独证明模型“关注”或功能性使用这些概念。

最强竞争解释：① SAE 自己学会了读出，主干没有变好；② 主干丢掉细节、更容易压缩；③ 只学到主题关键词、文风或来源；④ 读出器换基或特征编号变化，被误读成结构出生/消失。分别用独立 raw-h 读出、LM/方差检查、词袋与跨表达核验、固定文本上的特征响应对齐加以分离。

已核对 [PROJECTS](../../../PROJECTS.md)：相关 SAE 路由条目所指 [0907 Focus](../../0907/focus_sae_flat_router_functional_training.md) 当前拥有的是结构路由/局部增量学习，不能直接承接本问题。0914 串联 50B 的 [Protocol](../../0914/sae_mediated_pretraining/protocol.md) 拥有已有执行，不拥有新旁路比较。候选归属为 `Projects/from-attention-to-search/` 的 A15 相关方向；候选稳定键 `sae_sidecar_pretraining_structure_formation` **未确认**，科学状态 Unknown。本文不创建或重置任何 Focus/Anchor。新探索先完成可审阅实现与证据；科学归属与正式执行范围一起由研究者确认。

## 2. 两组模型与梯度合同

| 项 | 候选冻结值 |
|---|---|
| 主干 | 随机初始化的 Qwen3-style Dense，4 层、hidden 512、FFN 1536 |
| 注意力 | 8 个 Q 头、4 个 KV 头、head_dim 64；RoPE theta 1000000，RMS epsilon 1e-6 |
| 输入 | 2048 token 上下文；原 Qwen3 tokenizer；vocab 151936；共享输入 embedding/output head |
| SAE | 一套在线训练字典；宽 10000，最多 20 个正激活；列归一化解码器 |
| 挂接点 | **最后块 attention residual 经 norm2 后、进入 MLP 前的 h**；原生 MLP 使用 h，不能使用 SAE 重构 |
| C | 每次都训练 SAE，但重构编码输入 `h.detach()`；LM 梯度不经过 SAE |
| T | 同样训练 SAE，重构编码输入 h 保留梯度；LM 梯度仍不经过 SAE |
| 重构权重 | 两组 lambda_R=1；目标 h 和能量分母均 detach |
| AuxK | 两组同样 SAE-only：k_aux=256，系数 1/32；死特征窗口 10000000 个训练抽样位置，活动阈值 1e-3 |
| 初始化 | seed 17，一份初始主干与 SAE 完整状态复制到 C/T；不得加载 tokenizer 目录中的预训练权重 |
| 参数 | 主干 90379264；SAE 10250512；总计 100629776；由当前源模型 meta-device 形状计数验证，不代表新旁路已实现 |

每个抽样位置的重构误差：

\[R(h)=\frac{\operatorname{mean}_d[(A_\phi(g(h))-\operatorname{sg}(h))^2]}{\max(\operatorname{mean}_d[\operatorname{sg}(h)^2],10^{-4})},\quad g_C(h)=\operatorname{sg}(h),\quad g_T(h)=h. \]

总目标：有效预测位置平均的 LM 交叉熵 + 抽样位置平均的 R + 1/32 × 抽样位置平均的 AuxK。LM 与 SAE 使用各自的全局分母。本文的“正则”就是稀疏重构反馈，不是额外领域监督，不另加 L1、聚类标签或多尺度损失。

T 的辅助梯度直接进入挂接点上游；最后块 MLP 参数、其后的 final norm 没有该损失的直接梯度。共享 embedding 在上游，不能把它的梯度误判成独立输出头受辅助监督。C 的主干只能得到 LM 梯度。AuxK 的输入与残差目标停止梯度；不强迫主干为了复活字典特征而改变表示。

本轮仍保留目标侧 detach，因此没有宣称消除辅助路径的 TopK 梯度限制。若要改成完整距离梯度，属于后续新比较，不能混进本轮。

## 4. 优化、批量与精确预算

- 推荐双5090方案：每条件独立一个双卡节点，world_size=2、每卡microbatch=2、梯度累积32、seq_len=2048，完整更新262144个有效目标。两个独立任务分别跑C/T，不跨节点通信。H100单卡选项改为world_size=1、累积64，保持同一全局批量；正式配对两组固定同一拓扑。
- AdamW：LM lr=3e-4，betas=(0.9,0.95)，矩阵参数 weight_decay=0.1、norm无decay；SAE lr=3e-4，betas=(0.9,0.999)，无weight_decay；epsilon=1e-8。LM/SAE分别裁剪梯度范数至1。
- LM预热262144000个目标（1000完整更新），SAE预热2621440个目标（10完整更新），之后恒定；不新加余弦。第零步lr沿原实现可能为0，验收梯度和第一次非零lr参数更新要分开。
- BF16 autocast；分块交叉熵 ce_chunk_tokens=128、checkpoint_ce=true；主干gradient_checkpointing=false为候选。显存不足时两组一致修改微批/累积且重做匹配验收，不能无记录降序列长度。
- SAE随机抽样1/8有效位置，使用独立可恢复RNG；每完整更新32768位置。按输入位置选择，不能因 C/T 表征不同而改变抽样。
- 5B含19073次完整更新和1次127488目标的部分更新，总19074次。部分更新按实际全局目标数归一化；两组同一位置、同一边界。不得把5B raw tokens直接当5B预测目标。
- 双rank末更新需要63个真实序列（最后一个仅512有效目标），补1个全mask虚拟序列形成64序列，即每rank16个microbatch；虚拟序列不贡献LM目标/SAE样本。原sampler直接均分可能丢掉末序列，P0必须修复并验收，不能因DDP整除把5B终点静默截短。单rank也可采用相同padding规则维持微批形状。
- 科学快照目标0/0.1/0.3/0.5/1/3/5B，以及阶段端点1024更新；除5B终点外在首个达到目标的完整更新后保存，不为快照拆批。计划和实际token同时记录。

1. 任意非有限损失/梯度、token/digest错配、断点恢复失败、挂接错误、存储不足：立即停止受影响任务，不能把失败轨迹混作完整配对。

### 6.2 LM代价、形成轨迹与功能边界

固定DCLM验证流前512个2048目标窗口，共1048576目标，每个共同checkpoint都使用相同内容、分母及顺序；不使用仅4批的健康指标代替这一代价。该流曾用于历史评估，仍称开发验证。

绘制raw-h宏F1、独立读出SAE分数、LM损失三条token曲线，完整报告每个注册点，不选择事后最佳点。“更早形成”先用全轨迹描述；若需阈值到达时间，必须在看新结果前额外固定阈值，不能事后选择最有利定义。

画像探索从发现集提名最多20个概念/概念组。每个候选保存代表片段、近邻反例与不确定性，在另选的去重文本上盲核验“议题/立场/论证框架”；领域标签不能替代立场。初始人工核验预算200段、每候选5个高响应与5个对照，评审不看条件。它是小规模解释验证，不是全面政治测量。

若要声称模型在预测中使用这些概念，另做小范围h方向消融与同范数随机方向对照，观察目标/非目标文本损失；此分支只在概念语义和主读出稳定后设计，不是当前开小试的前置条件。

## 7. 读出器检验与两篇论文的使用

本轮online训练先用现有TopK，减少实现与算力变量。普通SAE未读到的结构不能直接判不存在：[MP-SAE](https://arxiv.org/abs/2506.03093)用残差驱动的迭代选择，能在其研究设置中恢复某些相关、层次与非线性可访问特征；[Matryoshka SAE](https://arxiv.org/abs/2503.17547)用嵌套字典重构缓解特征吸收。两者都不直接确立“在线重构梯度促进从零语义形成”。

最低成本读出核验：先在D2的C/T checkpoint固定h上，离线训练普通TopK和MP-SAE。每checkpoint用同一DCLM验证流中与LM验证不重叠的窗口[512,1536)抽取200000个固定位置；80% fit /20%验证，以窗口为单位拆分。cache存FP16 h、样本/位置ID、token坐标和模型hash，两个checkpoint约0.38GiB纯h。

两种读出器同宽10000、目标平均实际L0约20；MP限制最多20次迭代，记录实际非零数，不能把迭代次数等同活跃数。候选共同Adam lr3e-4、batch512、最多2000更新/每个读出器最多30GPU分钟；若预算内未收敛，记不足，不强称性能排序。在线字典在同一面板另报；离线读出仅使用其checkpoint表征，不能从较晚checkpoint取教师反馈较早LM。

只有出现一般概念被具体概念吸收的明确案例，才加Matryoshka离线读出；只有独立语义评价显示多尺度约束有价值，才另设计在线多尺度反馈。每次增加读出器应报告实际稀疏度、fit预算和耗时，不能让复杂读出器多训很多后归因于结构。

跨时间特征对齐用固定发现文本上的激活响应与代表片段；保留出生、消失、拆分/合并和无法对齐，不按latent编号强行追踪。raw-h读出是主干变化的主参照，在线SAE的改进不能独占结论。

## 8. 已有远程T与Dense如何利用

已有T的输入重构梯度和SAE-only AuxK由0914正式Protocol及真实源码支持；它仍是**串联**，不能作为新旁路T。已有Dense与T有相同初始主干和token边界的对齐审计，但架构与AuxK等差异未被单独控制。

只读已完整保存的共同token checkpoint，建议优先0/0.5/1/3/5B，实际以manifest为准。提取相同M2D2面板的最后块post-norm2、pre-SAE原始h；两模型内部h维数都是1024，独立拟合相同容量的读出规则。不与小模型512维结果直接做模型规模无关的效果差。远程模型无需等50B结束才开始读现有完整checkpoint，也不需要修改或暂停远程训练。

用途：确定语言结构随训练变化的现象、发现候选概念、识别读出器盲点。不能用旧T−Dense取代新C/T对辅助梯度开关的隔离。

- 推荐长训练放两个独立双5090 ACP Spot任务，并行C/T；若选择单H100 Spot则C/T依次执行。若本地单H100能持续运行且环境数值资格一致，也可本地C、H100 Spot T并行。环境不同不能以“同卡型”代替torch/kernel/数据契约验证。
- 原envelope提到交互容器可能约4小时回收；不能假设当前或迁移容器长期存活。短阶段≤3小时到边界checkpoint退出，长阶段交给批任务。不是每次迁移都从零重训。
- 使用envelope当前镜像键 `shphd-lite-0911` 与其提交模板。规格查询只证明单卡worker规格存在，不能证明Spot当前有空闲、排队时长或抢占概率。
- 完整恢复状态每100更新原子保存、保留最近2份；本计划吞吐情景约每3–9分钟一次。信号能捕捉则补存，但不依赖平台提供优雅退出通知。科学里程碑保存模型+配置/来源；恢复checkpoint保存模型、优化器、scheduler、各rank sampler/cursor与所有RNG、同步SAE活动计数、token坐标和contract hash。
- 回收后从最近**完整**checkpoint恢复，保留run root与contract；不得从最后metrics行猜状态。未提交更新的重复计算计入物理算力，不重复计入已提交训练轨迹的token。Spot预算/排队由durable receipt记录。
- 候选单次运行segment≤3小时；每条件累计运行墙时预算36小时含恢复与checkpoint，不含未获卡排队。单卡对应每条件36 GPU小时/配对72 GPU小时；双卡对应每条件72 GPU小时/配对144 GPU小时。这是候选预算上限而非预计消耗或执行批准。到限保存并报告，不能自动扩预算。100次间隔checkpoint耗时若超过训练时间5%，先报告成本再统一修改恢复策略。
- 总新实验磁盘预算40GiB，两组可恢复状态与里程碑约10–20GiB量级，cache/日志另计；以完整状态实测为准，剩余不足两个完整checkpoint加2GiB余量时停。数据视图复用软链，不复制20GB前缀。

详细估算在 [compute_estimate.json](compute_estimate.json)，公式与重算程序在 [compute_estimate.py](compute_estimate.py)。H100以60k/90k/120k有效目标每秒情景，5B纯训练约23.15/15.43/11.57小时；额外15%评估/存盘预算后约26.62/17.75/13.31小时。5090每卡50k/70k/90k情景分别约31.94/22.82/17.75小时含同样额外预算，两组并行墙时取较慢一组，GPU小时相加。**此15%是规划假设，不含昂贵离线读出、排队或抢占。** 若额外损失的计算占比为p，则运行时再除以(1-p)，再加排队Q；p=10%或30%仅做情景，不是概率预测。

| 可用资源 | 配对方式 | 两组各5B规划墙时（不含Spot中断/排队） |
|---|---|---|
| 本地1×H100或1×H100 Spot | 串行C/T | 约28–54小时 |
| 本地2×H100 | 每卡一组 | 约14–27小时；仅当容器能持续存活 |

不同卡型不要用于C/T两个不同条件的正式配对；从H100改成5090时先做跨平台恢复资格，无法证明一致性则在同一平台从共同0点重开独立比较，不拼接成严格同轨迹。

上述5090每卡估算先得到50k/70k/90k目标每秒，再按双卡效率0.75/0.85/0.90乘以2，形成每个双卡条件75k/119k/162k的情景；含15%额外时间对应21.30/13.42/9.86小时。成对运行墙时取较慢任务，合计GPU小时约4倍墙时（40–88量级），不是双任务墙时相加。

P0/S关键验收：

1. 相同初态/输入下C/T前向LM logits相同；与相同Dense主干也相同。仅LM backward时SAE无梯度，参数不受weight decay或另一分组误更新。
2. 单独R backward：C主干无梯度，T的h及上游有有限非零梯度；目标/分母不传。最后MLP独有参数无R梯度；共享embedding单独解释。
3. 单独forced-AuxK backward：SAE有非零梯度、主干无；关闭forced后自然计数一致恢复。不能用nan_to_num掩盖非有限raw AuxK分支，记录归一化前后的finite检查。
4. 不同lambda的R梯度在同输入、同参数且裁剪前按系数缩放；total/raw/weighted日志相符。
5. 全局有效目标、SAE抽样数、数据digest、mask/RNG在C/T匹配；最后512有效目标与末更新127488目标的CPU小型类比用例正确。
6. 完整恢复后下一更新的loss、计数、参数及SAE活动buffer匹配；Spot/本地跨环境若不能达到同环境容差，则记录差异并用同环境完成成对比较。
7. TensorBoard遵循 [observability contract](../../../docs/training_observability_contract.md)：LM/total、R/AuxK raw/weighted、LM/SAE lr及梯度范数、有效token、update、tokens/update、吞吐、活动计数。不只画total loss。
