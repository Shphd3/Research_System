# 06｜在线SAE架构：插入位置、梯度与候选干预

**首选是最后层的旁路在线观察器：SAE随主模型更新，但重构损失不反传到主模型。它最接近导师“先看动态形成，再考虑反向正则”的顺序。后续反馈分支保留为显式开关，而不是把两种科学问题混成一条训练。**

## 1. 精确位置与前向过程

第l个解码块包含注意力、门控前馈层与两次残差相加。令最后一个完整块的残差输出为rᵢ，最终均方根归一化后的状态为hᵢ：

$$r_i=\mathrm{Block}_{10}(\cdots\mathrm{Block}_{1}(\mathrm{Embed}(p))\cdots)_i,$$
$$h_i=\mathrm{RMSNorm}_{final}(r_i),\quad \ell_i=W_Uh_i.$$

W_U是输出词表映射，与输入嵌入共享权重。hᵢ预测下一个词元xᵢ₊₁。SAE读取hᵢ，不读取采样生成的词元嵌入，不读取整个答案的平均状态，也不把当前token的目标错放成xᵢ。

前向关系如下，箭头只表示计算关系：

```text
输入前缀 → 词嵌入 → 10个完整解码块 → r → 最终归一化 → h → 词表映射 → 下一词元损失
                                                    |
                                                    └→ 停止主干梯度 → SAE → h_hat → 重构损失
```

**选择归一化之后的理由：**它就是模型实际用于预测的表示，量纲较稳定，容易将后续特征干预作用直接送入同一个词表映射。**同时保存r的理由：**归一化会改变尺度，不能只凭归一化后的距离判断模型原始状态是否变得紧凑。

“最后一层加SAE”来自导师；“最终归一化之后”是本方案的精确化选择，不是导师已经指定的细节。[M，12:19]

## 2. 四种候选方案，不混为“在线”

| 方案 | 模型预测是否经过SAE | SAE参数是否更新 | SAE损失是否更新主干 | 科学含义与本轮位置 |
|---|---|---|---|---|
| 冻结模型后的离线SAE | 否 | 是 | 否 | 独立拟合的读法对照，不能单独追踪自然在线过程 |
| 旁路在线观察器 | 否 | 是 | 否 | **主方案**，同步记录形成过程，主干仍只由语言任务学习 |
| 旁路辅助重构反馈 | 否 | 是 | 是 | 观察＋干预，检查“更可稀疏重构”是否改变轨迹；不等同语义监督 |
| 串联重构瓶颈 | 是 | 是 | 是，任务损失也经过SAE | 强结构干预，可能改变容量和优化；本轮仅实现开关与无作用测试，不优先做主实验 |

还有第五类：教师给定关系的语义反馈。它必须先规定关系来源、泄漏控制与负对照；本轮不自动用自生成标签启动。端到端SAE文献也有把重构状态对后续输出的影响用作目标的工作，但“端到端训练SAE”本身不说明原始语言模型参数也在更新，阅读时必须检查冻结边界。[S4]

## 3. 梯度的精确契约

用θ表示主干参数，φ表示SAE参数，sg表示停止梯度。本包SAE重构目标为：

$$L_{SAE}=\frac1{|I|}\sum_{i\in I}\frac{\|D_\phi E_\phi(u_i)+b_\phi-\mathrm{sg}(h_i)\|_2^2/d}
{\max(\mathrm{sg}(\|h_i\|_2^2/d),10^{-4})}.$$

I是本次抽样的有效位置。分母与目标都停止梯度；这是本包的定义，并不声称所有SAE文献如此。

**观察器：uᵢ=sg(hᵢ)。** 主干梯度为∇θL_LM；SAE梯度为λ∇φL_SAE。即使训练时把两个损失相加，也不会把重构损失传给主干。λ=1只是SAE训练的尺度，不是结构塑形强度。

**辅助反馈：uᵢ=hᵢ。** 主干额外收到通过编码—解码路径返回的重构梯度。目标支路仍被停止，因此这里不是把误差对“重构减原输入”的两个支路全部求导；代码、公式和解释保持一致。

忽略归一化分母常数时，若J是编码—解码对h的雅可比矩阵，则本包重构反馈约为2Jᵀ(ĥ−sg(h))。若另一实现没有停止目标，才会多出−2(ĥ−h)这一项。两种目标不可在日志中使用同一个未经注明的名称。

**串联瓶颈：**h̃=(1−α)h+αĥ，预测使用h̃。α=0时主干预测应与无SAE完全一致；α>0之后，任务目标也训练SAE。这并非“只多一个观察器”，必须匹配参数、计算和容量解释。

## 4. 为什么不从第0步就加“语义组监督”

随机初始化时，字典、激活与分组都没有获得你关心的语义资格。把当前分组立刻当目标，可能形成自我强化：随机分组→把表示推向分组→图更清楚。这样的清晰是人为目标的结果，不能证明模型自然发现了有意义类别。

因此第一阶段只更新SAE以跟踪表示；分组在预先约定的检查点上离线计算，不参与梯度。这样“在线SAE”与“在线刷新图分组”可以分别追踪，而不会把不可微的聚类刷新当作正常梯度反传。

实际使用的反向链要通过单元测试确认，而不是凭`model.train()`或“在线”这个词判断。本包已有观察器主干梯度等价、辅助反馈非零主干梯度以及α=0完全一致性测试。

## 5. SAE训练多久，什么时候反过来监督

这里没有一个由导师指定的“400步后就语义成立”。旧实验每次刷新400步是历史实现，不是跨模型可用的成熟标准。[R1]

本轮建议从第0步开始轻量在线更新观察器，每个主模型更新只使用独立抽样的约1/8有效位置；为避免同一批量重复更新过度拟合，首版1次SAE更新对应1次主干更新。保存每次累计实际SAE样本数，不把SAE步数与LM词元数混用。

当主干变化太快时，在线SAE可能滞后。于是对预先指定的早、中、晚检查点，冻结h，再独立拟合一份SAE作为“充分适应当前状态”的读法对照。建议相同数据顺序、相同样本预算、最多400更新，每次1024位置；另留20%记录监控重构，连续五次评估相对改善低于0.5%可停。这个停止规则只判断重构优化，不判断语义成熟；因时间不足没达平台应明确记录。

**反向监督的资格门槛不是训练步数，而是三项信息：**当前任务有相关学习信号；工具在留出记录上稳定重构并有足够覆盖；分组或特征对外部关系的表现能与格式/随机解释区分。未达到时继续观察，不强制开启语义损失。

## 6. 允许反馈时最小可比较的分支

从同一个θ*、φ*、优化器状态、数据游标分出两条短轨迹：

A保持旁路观察器；B仅打开辅助重构对主干的梯度。两者看到相同词元，SAE抽样相同，学习率相同。B的目的先是检验“可稀疏重构的压力会怎样改变轨迹”，还不是证明“语义分组监督有效”。

反馈系数不能照搬观察器的1。先在校准批量计算主干任务梯度范数g_L与单位重构反馈范数g_R，取λ=0.05×g_L/max(g_R,ε)，固定后再跑分支。0.05是首版保守干预强度建议，不是有效性阈值或最优超参数；需登记为设计选择。校准用独立小批量，测试集不参与选λ。

若B改变了结构且行为有收益，下一轮再用宽度匹配但无稀疏约束的自编码器、固定随机字典或打乱关系等对照区分“稀疏成分机制”与“一般额外损失”。不做这些对照时，结论只到“重构反馈有效/无效”，不能宣称SAE独有优势。

## 7. 真正的关系反馈应怎样定义——只给接口，不替你选假设

假设你之后确认了某种外部关系或已经冻结的滞后教师关系yᵢⱼ。可以用它约束学生关系s(hᵢ,hⱼ)，例如平方差或对比损失。这时必须有：

- 教师关系不使用确认集标签、不读未来答案；教师分支停止梯度。
- 正例和负例经过含义与格式的交叉检查；不把“同组=同专家最优”当先验事实。
- 明确损失究竟施加在h、z、路由概率p还是实际功能上，不能四者轮流替换。
- 保留打乱关系但组大小/采样分布匹配的对照，检查是否只是额外训练信号。

本轮**没有把这个尚未定义的语义损失写入默认模型**。这不是漏写训练，而是避免把你的科学判断默认为代码。`auxiliary`只实现重构反馈，配置名称不会冒充语义监督。

## 8. 如何做特征干预而不把重构误差当效果

将选择的特征组系数置零得到z′，使用：

$$h'=h+D(z'-z).$$

这样保留原始重构残差h−ĥ。直接使用Dz′+b会同时删除原有重构误差，两种作用混在一起。代码`patch_feature_group`采用前一种。

基线必须包括不干预、系数不变的自替换、等扰动范数的随机特征组，以及任务无关组；选组只能用发现集。最后层干预可通过同一个词表映射测正确下一词元损失和行为，跨多步生成需要完整解码流程，本包没有声称实现。

这种干预可能把状态推离正常分布，故行为变化只能证明此干预影响该输出，不自动证明该特征对应唯一真实概念。更强功能结论需要语义选择性、随机干预对照和恢复实验共同支持。[S3、S4]

## 9. 实现状态与未实现边界

已实现并本地测试：纯PyTorch因果主干、最终层SAE、四种模式、梯度隔离、分块交叉熵、可选块重计算、掩码、模型权重保存/加载、状态采集、关系与覆盖分析、残差保留干预、蒸馏损失参考。

未实现/未运行：你的集群训练入口、完整断点恢复训练器、分布式数据游标、正式训练任务、多步生成缓存、专家路由层、动态专家增长、未经你定义的语义反馈目标、Qwen3.5混合注意力移植、与官方模型逐层数值等价验证。

因此它是可测试的预训练研究组件包，不是冒称已在H100验证的生产训练栈。Agent应优先复用现有训练基础设施，接入这些有明确边界的模块。
