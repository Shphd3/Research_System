## 2. Agent严格执行顺序

### 步骤A：接入Research_System，不覆盖已有科学状态

先读根`AGENTS.md`和`PROJECTS.md`，再定位你本次批准的问题。把本包当新的设计讨论资料，不用它覆盖旧后训练S0—S6的已批准协议。候选问题键可暂记为`DRAFT.sae_pretraining_formation`，必须由你确认后再注册；本交付物没有创建新的正式Focus或Anchor。

在现有执行工作区建立独立目录，记录代码版本与所有文件哈希。实验代码与原始日志进入执行工作区；经过确认的设计和证据摘要按系统规则放回研究仓库。不要上传大数据、模型权重或所有日志到研究文档仓库。

### 步骤B：先跑本包测试，再接官方或现有主干

```bash
cd code
PYTHONPATH=. OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 pytest -q
PYTHONPATH=. python -m scripts.inspect_parameter_budget
```

本包提供原生PyTorch参考主干，因此不依赖在线下载模型权重才能进行架构测试。它不直接加载官方检查点。若Agent改用官方Qwen3类以复用成熟训练栈，必须核对输入输出维度、查询/键归一化、每头128维、最终归一化、共享词嵌入，并在小配置上补官方/参考实现逐层及梯度对齐；不能只比张量形状。

代码源码已通过GitHub连接读取和参考；完整上游仓库未克隆。`scripts/fetch_upstream.py`用于你有网络的执行环境下载固定版本文件与许可、登记哈希；该下载动作本次没有成功在沙箱完成。不要声称交付的是官方原文件的完整副本。

### 步骤C：补接数据和训练基础设施

复用已有分布式启动、数据并行和作业提交方式，不为了新项目重写平台。训练循环需要实现：主干与SAE参数组；单独梯度裁剪；BF16；有效词元归一化；梯度累积；独立采样随机流；完整状态保存与恢复；主干/SAE成对检查点；只读验证；定时退出与异常日志。

特别注意梯度累积：`normalized_objective`的全局计数应覆盖本次更新所有设备与所有累积微批量。若每个微批量各自取平均再简单相加，会因为有效位置数不同而改变权重。两种正确做法：预先累计分母，或对同一更新内分子的梯度按严格等价方式缩放。

首次真实数据资格跑先100—200次更新，不能一上来申请20B正式长跑。检查初始验证损失、短跑下降、随机/未来泄漏测试、SAE覆盖、四卡吞吐和完整恢复后下一步一致性。

### 步骤D：补面板与分析驱动，不改测量定义

按你填写的关系卡构造JSONL。先人工检查20—30个正负对，确认它们真的控制了格式与语义变量；不盲目让生成模型把标签词直接写进题面。

用已有数据清洗工具排除同源改写泄漏。固定每条前缀的位置、ID、语义和格式元数据；离线分组只使用校准集。为每个保存时刻生成r/h/z。复用本包分析函数，加一个读取检查点清单的薄驱动即可，不在循环里改聚类统计单位。

独立SAE拟合训练器、本包未实现的成对功能评估和组层q的批处理入口由Agent补接；它们的数学定义和输入接口在06、07中已给出。完整主模型训练脚本按你的要求暂未生成。

### 步骤E：训练、监测与到点停机

通过05资格后，按实际吞吐锁2B或4B首段；进度横轴用有效预测词元，壁钟另计。T=21小时必须准备做主要对照，T=25小时不再开始新的主训练。你的学习与解释时间不被作业监控挤掉。

异常时先保留失败证据。损失反转、SAE全失活、某个分片重复、语义确认集泄漏，都有不同含义；不通过换种子、换面板或事后删点修成积极结果。

## 4. 组会前的理解检查

不看文档，用两分钟讲完以下内容：我为什么要从头训练；旁路SAE为什么不改变自然主干；同一个h为什么能被重新分类；一个我关心的关系如何与格式区分；什么结果会让我停止当前解释。

如果你只能解释“我们用了Top-K、谱聚类、四卡H100”，说明你还在工具层。如果能说“我的原解释与最强竞争解释，在这一组对照中预测不同”，才进入本轮要练的研究判断。

## 5. 组会稿的固定空框

**问题与预期：**我想回答________。过去我以为________，纸笔示意图中横轴是________、纵轴是________。

**真实结果：**在________模型、________词元、________固定面板上，实际观察到________。固定与更新读法的差别是________。

**差异与区分：**这个结果与预期不同的地方是________。最强竞争解释是________，我们用________保持不变、替换________进行区分，发现________。

**认识更新与边界：**现在支持________，尚不能说________。下一步只决定________，不同时打开所有架构方案。

标题不要写“成功训完313M＋SAE”，而写你实际获得的认识。没有显著积极结果时，同样可以完整回答测量分辨率、读法偏差或机制链断在哪里。
