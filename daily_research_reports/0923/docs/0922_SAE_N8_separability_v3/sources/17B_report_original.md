# 17B 末层 SAE 旁路训练历史对照：用户提供的结果报告

来源：研究者在本对话中粘贴的报告。下文保留报告的目的、假设、方法、数值、边界与下一步；原消息中错位的表格仅重新排版。报告所称“独立复算通过、核验22份产物哈希”是来源报告的记载，本交接文件不代表另一次独立复算。

**结果已完成，独立复算通过：重加权模型的跨样本原子复用更强，原生表征有效维数也更低。这个差异在不改变末层旁路结构、当前正则系数和初始参数的对比中仍然存在。**

## 一、目的

此前比较“末层旁路模型”和“全层旁路模型”，混合了结构与训练历史差异。
本轮比较两个**同为末层旁路结构、当前重构系数均为0.1、训练到17B的模型**：

- **从零训练模型：** 从开始就使用0.1。
- **重加权模型：** 前期使用1，约15.47B时改为0.1。

要回答：**控制旁路结构和当前系数后，两种训练历史是否仍对应不同的原子使用方式和原生表征空间？**

## 二、假设

- **训练历史相关解释：** 即使当前结构和系数相同，不同历史仍可能留下不同的原子复用与表征几何状态。
- **另一种可能：** 两个模型在这些指标上已经接近，原先的差距主要出现在不同结构之间。

本轮没有预设哪个模型一定更集中，也不把“没有检测到差异”解释为两者等价。

## 三、分析方法

1. **保证对应比较。** 两个精确17B检查点使用相同192条记录，每条256个正文词元；观察第8层，字典均为30,000个原子，每个词元选32个。记录的初始完整参数哈希一致；本轮不训练、不使用领域标签。
2. **测跨样本原子复用。** 为每条记录统计各原子的入选频率，再计算不同记录间频率分布的平均余弦相似度。数值越高，表示不同样本越倾向于使用同一批原子；**不等于语义越相似**。以记录为单位进行2,000次配对重采样，估计“重加权减从零训练”的差值区间。
3. **测同面板原生几何。** 对同一批输入的原生注意力输出取正文均值，计算有效维数，即方差相当于分布在多少个等权方向上。它不是语义概念数量。独立复算了主指标、区间与有效维数，并核验22份产物哈希。

## 四、结论

### 1. 控制结构后，差异仍然存在，而且方向明确

| 指标 | 从零训练0.1 | 重加权至0.1 |
|---|---:|---:|
| 跨样本原子使用平均相似度 | 0.40498 | **0.62530** |
| 原生表征有效维数 | 19.98208 | **8.41849** |
| 全面板选中过的不同原子数 | 8,893 | **134** |
| 按使用频率折算的等效原子数 | 292.18 | **67.17** |

主指标差值为：**+0.22032，95%区间为 [0.20678, 0.23224]，完全大于零。**
因此，重加权模型确实表现出更强的跨样本同编号原子复用；同一面板的原生有效维数也更低。后者是点估计比较，本轮没有计算维数差的置信区间。

### 2. 这次最重要的认识更新：不能只用“当前结构和当前系数”解释表征状态

**解释：** 同为末层旁路、当前系数同为0.1，并不意味着形成相同的表征状态。此前的集中现象不能简单归结为“末层旁路与全层旁路结构不同”。

**候选解释：** 重加权模型可能保留了前期较强重构压力下形成的集中状态。这个解释与结果相容，但目前还只是候选；我们没有直接测量这种状态何时形成、调整系数后如何变化。

### 3. 原子数量悬殊不是每个词元激活数量不同，也不是已发现的提取错误

两模型仍然都是**每个词元选32个原子**。134与8,893描述的是整个面板累计使用过多少个不同编号，反映跨词元、跨样本的使用多样性。
本轮原生前32项与“前128项中的前32项”在两个模型上均没有支持集合不一致，不能用此前担心的提取差异解释这次现象。

### 4. 边界与下一步

**仍不能说：** 前期强正则单独导致了集中；原子复用导致低维；低维就是塌缩；领域分离或模型性能更好。两条训练路径仍存在微批划分、交叉熵分块及潜在采样随机过程差异。

**AI建议：下一步优先定位差异形成的时间。** 在共同训练进度上，比较重加权前后的同面板复用与有效维数：如果差距在改系数前已存在、之后持续，才更符合“早期形成并保留”的解释；如果并非如此，就应修正这一解释。该轨迹分析仍不能代替严格匹配训练条件的因果消融。
