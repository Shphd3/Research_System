# Minimal 2x2 Router Feature Specialization

This folder is a hand-written minimal simulation task for thinking through the
research workflow before promoting anything into a project anchor.

Fill the files in this order:

1. `00_handwrite_anchor.md`
2. `01_theory_derivation.md`
3. `02_minimal_experiment_plan.md`
4. `03_after_result_update.md`
5. `04_judgment_cheatsheet.md`

Rule: the user writes the research judgment first. AI may ask questions,
challenge assumptions, and check whether the next step follows from evidence,
but should not replace the user's hypothesis, claim boundary, or final decision.
