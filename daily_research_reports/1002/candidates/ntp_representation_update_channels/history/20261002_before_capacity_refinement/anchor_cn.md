# Anchor 候选：S7 表征能否解释自然文本的共享更新响应？

2026-10-02，Asia/Shanghai。`CANDIDATE_FOR_REVIEW`。本轮研究者确认：机制研究必须结合确切自然文本的表征空间分析；以 S7 和已有 SAE 旁支为工具；候选文件保留在当日备选目录。下文新比较与操作化为 **AI_PROPOSAL**，不改变正式 Focus 或旧实验裁决。[English](anchor.md)。

## 1. Problem Definition

**固定 S7 与一批来源文本的更新后，仅凭另一条自然文本在更新前的表征，能否解释它受到的作用，并定位承载该作用的输出方向？**“受到的作用”指真实下一词交叉熵的增减；“解释”在本候选主检验中指对未参与拟合的记录提高预测准确性，不等同于纯语义或因果解释。

上位问题是哪些数据适合共享参数，什么时候分开才有净收益。已有领域均值掩盖事件差异，SAE 激活与方向敏感性又不提供损失作用的正负。因此本轮把对象放在实际自然文本、固定来源更新与读出文本的表征响应上。来源领域仅用于构造可审阅的更新，不把领域标签当成未来 Router 的答案。

若更新前表征在独立记录上增加可读出的响应信息，可推进表征定义的学习关系；若精确无增益，则限制本次工具、读出器和尺度；若精度或数值资格不足，则保留未知。长期隔离收益不由本轮裁决。

## 2. Physical Priors

1. **候选自然语言先验：**上下文和续写具有结构，当前模型的误差、下游敏感性与表征共同产生更新需求。Zipf 词频或各向异性单独不足以给出作用符号。
2. **数学条件：**仅改变末块注意力输出矩阵，保持其输入、前置残差和下游参数不变。该处之后没有跨位置注意力，因此每个读出位置可用原模型的下游计算精确重放有限矩阵变化。
3. **测量条件：**来源、读出器拟合与结果读出使用不同记录；数据来自同一个已说明的来源总体。记录不重复不保证论文独立，更不保证训练未见。当前历史面板已经曝光，只能用于探索。

## 3. Falsifiable Hypotheses

**主候选 H：**固定来源更新后，更新前 S7 输出及冻结 SAE 系数包含超出当前／前一 token、前16 token词袋、位置和表征尺度等已登记基线的响应信息。它预测：在新的读出记录上，加入表征后对有限损失响应的平方误差下降。候选主分支固定为SAE320，普通输出投影是工具对照；SAE无需胜过它们，失败也不代表完整原生表征无信息。

**最强竞争解释：**可读出变化主要由词面组成、实际下一词身份和共同更新方向决定；SAE 的领域画像只重复这些组成信息。目标身份可以进入独立的解释性对照，不能进入声称更新前可用的主读出器。

**机制诊断：**一个输出子空间可承载帮助或不利分量，完整更新可能仍净帮助。子空间对预测分布敏感、在文本中经常激活、承载实际位移及承载带符号作用，是四种不同读数。它们不构成四项互相替代的成功标准。

## 4. Mathematical Model

一条事件由可见前文 \(x\) 与真实下一词 \(y\) 构成。\(c\in\mathbb R^{2048}\) 是矩阵输入，\(W\in\mathbb R^{1024\times2048}\)，\(a=Wc\) 是原生注意力输出；\(r\) 是相加前残差。固定下游映射产生 logits \(z=g(a,r)\)、概率 \(p\) 和损失 \(\ell=-\log p_y\)。令 \(J=\partial z/\partial a\)，\(u_y\) 为真实词的 one-hot 向量，则

\[
e=\nabla_a\ell=J^\top(p-u_y),\qquad G=\nabla_W\ell=ec^\top.
\]

来源集合 \(A\) 的 token 等权平均梯度为 \(M_A=N_A^{-1}\sum_{i\in A}G_i\)。只作 \(W\mapsto W-\eta M_A\) 时，读出事件 \(j\) 的位移和损失响应分别是

\[
v_{Aj}=-M_Ac_j,\qquad
a_j'=a_j+\eta v_{Aj},\qquad
I_{Aj}(\eta)=\ell_j(a_j+\eta v_{Aj},r_j)-\ell_j(a_j,r_j).
\]

位移式在限定参数块下精确成立，\(I\) 由原生下游网络直接计算。它的一阶导数为

\[
h_{Aj}=e_j^\top v_{Aj}=-\langle G_j,M_A\rangle_F,\qquad
I_{Aj}(\eta)=\eta h_{Aj}+O(\eta^2).
\]

所以表征相似只决定耦合的一部分，作用符号还依赖损失方向。研究者关心的是这条真实学习链，而不是将 SAE 重构代替模型前向。

冻结 SAE 给出 \(a=b+D\alpha+\varepsilon\)。对于一个预先选定的正交输出基 \(Q\)，定义 \(P=QQ^\top\)。分解 \(v=Pv+(I-P)v\) 后，两项一阶作用精确相加；\(PM_A\) 和 \((I-P)M_A\) 也是可实现的共享矩阵更新。有限损失一般不相加，必须直接比较完整、只保留和移除该分量三个分支。非正交 atom 的单项内积不能相加为独立贡献。

主预测比较使用 \(x\) 的词面基线 \(B(x)\) 与加入更新前表征的 \(F(x)\)，目标是实际 \(I_{Aj}\)。在独立记录上定义

\[
Q_A=1-
\frac{\sum_j(I_{Aj}-\widehat I^{F}_{Aj})^2}
{\sum_j(I_{Aj}-\widehat I^{B}_{Aj})^2},\qquad
Q_{\rm macro}=\frac14\sum_AQ_A.
\]

这是每个来源内的相对预测误差改善，再对四来源等权；不是受害比例、分开训练收益或原子因果性。当前探索的pooled-SSE比值作为次要读数保留，未来候选主判据不据曝光结果再改。历史缓存的 \(h\) 读出用于探索该操作化；不能以它冒充有限步 \(I\) 的未曝光确认。

## 5. Computational Realization

**先确定要解释的作用。**复用精确 33B 训练词元 S7 检查点、末块 `attn.o.weight` 与原生尾部计算。33B 指训练词元量。来源记录只用于构造纯 NTP 平均梯度；SAE不进入任务损失；这个纯NTP普通梯度方向不是S7训练器AdamW／SAE联合目标的重放。为何必要：保证来源更新与读出误差来自同一个模型状态。

**再检查表征中有什么可读出信息。**冻结已有字典与 F 选出的原子集合；用另批记录拟合词面基线、基线加 SAE，以及原生输出投影对照。真实下一词只进入损失标签和独立组成诊断。为何必要：把更新前信息与事后标签解释分开。

**最后定位实际作用。**在固定读出文本上并列显示激活、真实位移、带符号一阶项及有限矩阵变化结果；同时保留正交补、SAE 重构残差和负例。为何必要：即便一个方向可读、敏感，也可能未承载该次更新，或者局部不利被其他方向的帮助抵消。

[既有工具源码审计](../../../../Projects/from-attention-to-search/main/experiments/shared_updates/ntp_statistics_local_compatibility/20260930/sae_tool_source_audit.json)已经明确 SAE 编码原生输出而非矩阵输入。本轮复用其对象与接口，适配本地缓存分析和有限响应读出；不复用旧合成二元目标或把历史 R 重新称为盲确认。

## 6. Minimal Falsification Tests

候选主检验只裁决更新前表征是否增加响应信息：新记录、固定来源更新与冻结模型下，配对记录区间下界大于零支持该读出关系，上界不大于零限制该操作化，其余为不足。科学上多大的增量足以支持后续设计尚为 **Unknown**；检出非零改善不等于工程效用。

数值资格须分别验证零变化、外积恒等式、全模型矩阵更新与尾部重放一致、一阶项随步长缩小的误差，以及投影加正交补的线性闭合。已知混淆例包括总体帮助而部分事件受损、敏感但未移动、共同激活但更新需求相反、单个方向不利而总作用有利，以及非正交 atom 重复计算。

候选主推断固定来源矩阵，须冻结新读出记录、独立群单位、拟合选择和次要比较规则；若要外推到重新抽取的来源，另需登记来源重抽样，当前不包含。具体合同见本目录 Protocol；当前候选尚未获得新确认实验执行批准。

## 7. Current Evidence

[旧自然语言统计结果](../../../../Projects/from-attention-to-search/main/experiments/shared_updates/ntp_statistics_local_compatibility/20260930/summary_cn.md)的主均值检验为 INSUFFICIENT：\(T=0.006637\)，95% 区间 \([-0.003738,0.017012]\)，同时允许低于或高于候选 1% 尺度。SAE 激活／Fisher 画像是另一个描述分支，不能替它完成裁决。

[21B 自然方向干预](../../../../Projects/from-attention-to-search/main/experiments/shared_updates/atom_mechanism/20260926/summary_cn.md)已定位局部帮助通道；[33B 受控结果](../../../../Projects/from-attention-to-search/main/experiments/shared_updates/shared_update_conditional_interference/20260927_controlled/summary_cn.md)也显示局部不利可被更大帮助抵消。两者不能直接移植为当前自然文本的结果。

本轮完成实际有限读出：四来源更新都降低与来源构造不重叠的验证记录的平均损失；16个来源—R领域均值均负，点值−0.001953至−0.000182 nat；以1e-5 nat分辨带计，单事件不利比例43.97%—52.81%。这些是固定来源、已曝光旧R上的探索。

初始SAE读出器对实际有限响应的pooled误差改善1.41%，PCA2.26%，random2.53%。加入更强前文基线并交换F两半后，一阶响应SAE改善1.11%／1.21%，等权来源平均约0.76%／0.89%；真实目标诊断约21%—24%。不支持SAE独有信息或纯语义解释。

64条R记录的动态工具审计显示，静态相对平方重构误差6.51%不保证编码差忠实：稳定TopK集合的动态残差平方比约0.979—1.000；全步7.6%—11.8%事件切换集合，整体动态残差比约48—82。局部映射公式已与S7端点核对。结果、分母、条件区间与具体自然文本例子由[研究报告](research_report_cn.md)及其证据表持有。

换用F另一半构造来源后，实际有限R均值仍都为帮助，但两次均可分辨事件的同号率只有63.64%—79.13%。来源矩阵cosine为0.100—0.422。这进一步限制“固定来源预测增益”向“稳定数据属性”的外推；该两集合敏感性不是来源总体的稳定性估计。

续研证据：同域A/B来源批次的冻结迁移保留小幅增益，当前改善主要来自同域两批响应的平均部分；这不排除跨领域差异。新增[领域响应结构分析](domain_response_structure_cn.md)显示部分跨域复现、严格较早前文读出的有限增量及当前输出的输入通道边界。[来源迁移续研](source_transfer_addendum_cn.md)保留原数字。两轮都是旧面板探索，不自动替换下节问题或确认设计。
