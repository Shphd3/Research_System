## 1. 整个故事：每一步只补一个缺失环节

我们的初始想法是：无监督分组能给路由器一个有用的结构先验。但这个想法至少包含五个不能相互替代的判断。

| 递进问题 | 需要的证据 | 完成后的认识更新 |
|---|---|---|
| 正则化是否有任务收益？ | 相同训练预算和配对种子下的答案 NLL / 学习曲线 | 知道“值得解释的效果”是否存在，而不先编机制 |
| 正则化是否改变了实际分发？ | 教师关系、路由概率、离散选择分别比较 | 区分“概率形状改变”和“计算路径改变” |
| 不同路径是否执行了不可随意互换的计算？ | 固定输入、固定输出系数，替换专家后测任务损失 | 从分发相关性推进到当前专家函数的局部作用 |
| 两类样本能否继续共享学习？ | 从同一检查点学习一组，再测另一组的留出损失 | 区分当前表现和未来更新的兼容性 |
| 出现困难时是否值得增长？ | 修路由、更新旧专家、增加容量、条件化新增的对照 | 判断局部增长是否优于已测试的替代方案 |

**关键主线不是“不断多算指标”，而是：输入结构是否对应学习结构。**“输入看起来不同”只提出候选分组；“学其中一组会怎样影响另一组”才开始触及分工的形成。

本计划采用一条主干加局部分支，不展开所有条件组合的笛卡尔积。便宜诊断先覆盖五个条件；昂贵短更新只针对预先选定的少量候选，避免挑出一个好故事后无限追加实验。

```text

├─ 不可比/缺失 → 输出准确缺口；停止受影响的跨条件结论
└─ 可比

   ├─ 反转/变化很小 → 无稳定排序或收益很小；不能选赢家讲故事
   └─ 同向变差 → 正则化可能限制学习；只做有针对性的失败定位
      ↓ 上述三类均可进入便宜的 S2
   S2 结构是否改变路由概率及实际分发？
   ├─ 概率和选择均未明显变 → 本配置的结构作用弱；暂停机制扩张
   ├─ 概率变、选择不变 → 优先解释专家输出系数，不叫路径分离
   ├─ 选择受负载偏置主导 → 区分结构信号与负载控制的覆盖
   └─ 实际分发关系变化 → 进入 S3
      S3 冻结专家是否有功能差异，是否已有能力未被选中？
      ├─ 专门分支无可检出作用 → 检查共享分支/系数；不直接增长
      ├─ 替换专家影响小 → 当前候选群未显示不可替换的专家功能
      ├─ 其他旧专家更好 → 标记“修路由候选”，S5 优先测试 R
      └─ 路径有功能且存在待改善群 → S4
         S4 学一组，会帮助还是伤害另一组？
         ├─ 自己的留出组也学不会 → 优化/容量/数据仍未区分；不得宣布冲突
         ├─ 自己改善，另一组也改善 → 支持共享学习；优先更新旧专家
         ├─ 自己改善，另一组近零/不确定 → 不强行拆分；保留独立/弱效应分支
         └─ 自己改善，另一组持续受损 → 独立更新空间的候选
            S5 哪种处理更好兼顾待改善组和保留组？
            ├─ R 修路由足够 → 不增长
            ├─ U 更新旧专家足够 → 不增长
            ├─ C 无细分地增加容量已足够 → 支持容量增加，不支持细粒度门控必要性
            ├─ G 条件化新增优于 U/C → 支持此处的局部条件增量
            └─ 均无效/证据不清 → 停止增长主张，报告未解决的竞争解释
               ↓ 只有需要研究持续学习时进入新实验
            S6 真正的新任务按顺序到来
            ├─ 少样本收益不成立 → 不声称快速学习
            ├─ 新任务改善但旧任务损伤过大 → 保留机制不足
            ├─ 只在已知任务边界增长有效 → 还不是自动增量
            └─ 未知边界下触发可靠且新旧兼顾 → 支持所测数据流上的自适应增量
```

**两条例外通路必须保留。**第一，即使 S1 没有收益，S2–S3 仍可能定位失败，但不因此无限推进昂贵实验。第二，即使 S4 未出现可测冲突，也不能证明永远不需要增长；如果待改善组持续存在且旧模型学习无效，可进入一次有明确预算的 S5 容量比较，检验的是容量假设，而非“已证明冲突”。

### 3.2 因果位置与三种掩码

在位置 $t$ 使用 $h_t$ 预测位置 $t+1$ 的答案词元。不能用 $h_{t+1}$ 给该答案词元构造教师标签。[S1 §4]

- **任务掩码**：所有原始答案预测位置。S1 全部任务损失沿用它。
- **结构掩码**：任务掩码中，SAE 保留组激活总量非零的位置；四个正则化条件使用相同掩码。
- **负载掩码**：所有非填充提示/答案位置。只在分析训练负载与偏置时使用。

另外把任务位置分为“第一个答案词元的预测位置”和“已有前面答案的后续预测位置”。后者的上下文包含先前真实答案，不能被描述为“只看题目就识别了全部任务”。

### 3.3 路由中的三个量必须分开

$$
 z_t=Wh_t+c,\qquad p_t=\operatorname{softmax}(z_t),\qquad
 k_t=\arg\max_e(z_{te}+b_e).
$$

其中 $b_e$ 是负载调整缓冲量，评估和本计划短更新时默认冻结。实际专家贡献为 $p_{t,k_t}E_{k_t}(h_t)$；不能把该系数改成 1。[S1 §3]

因此分别记录：**概率 $p$、选择 $k$、所选系数 $a_t=p_{t,k_t}$**。只画一个路由准确率不能同时回答三个问题。

### 3.4 数值差异、实际大小和不确定性

S1 严格保留 A6 原规则：三个种子的配对差同向才叫“本配置方向一致”；反转则无稳定排序。这不是显著性检验，也不因挑了四个条件中的最好一个就升级为方法优越性。[S1 §9]

S3–S5 的新干预建议预先固定：

- 以记录/家族为重采样单位，按任务分层做 1,000 次配对自助重采样；每次重新用“损失总和/词元总数”计算差值，不能把词元当作独立样本。
- 每个训练种子单独报告点估计和区间；重复抽样不是新训练种子。
- 单个预指定对比显示 95% 区间。S4 对一个预先固定的双组矩阵同时判断四个格子时，建议用每格 98.75% 区间保护这四格的联合判定；仍不声称覆盖所有探索过的候选。
- 把不改变参数或计算路径的重复检查称为 no-op，其数值误差记为 $\epsilon_{num}$。只有超过它的变化才解释；若重构误差接近待测效应，先修复或使用原始完整前向。
- **实用阈值建议**：新诊断中 $\delta=0.001$ nat/词元作为“值得进一步关注”的默认大小。它不是已有实验结论，也不是普遍标准。执行前可改为研究者指定值，冻结后不可因为结果小而改低。S1 的原定规则不受影响。

对收益 $D=L_{before}-L_{after}$：区间全高于 $\delta$ 才称“达到预设大小的改善”；全低于 $-\delta$ 称“达到预设大小的损伤”；区间完整落在 $[-\delta,\delta]$ 内称“该容差内近零”；其余一律不确定。不要把“未显著”写成“没有影响”。若只做单种子探索，明确写“候选现象”，不要求为赶汇报补齐确认结论。

### 可以显著降低成本的尾部缓存

由于主干和最后一层注入前状态固定，可以尝试缓存每个选定位置的 $h_t$、冻结路径残差 $r^0_t$、目标词元和掩码，重建：

$$
\text{logits}_t = \operatorname{Head}\!\left(\operatorname{Norm}\left[
 r^0_t+S(h_t)+p_{t,k_t}E_{k_t}(h_t)
\right]\right).
$$

这里 $r^0_t$ 必须是**按实际源码定义、已包含原冻结残差与原 MLP 输出，但不含共享/专门适配器**的张量。$S,E$ 已包含原协议的缩放，不能重复乘 1/8。最终归一化和语言输出头不能省略，不能直接把专家输出当作 logits。

这是由 S1 架构推出的缓存方案，不是已验证实现。Agent 必须检查注入点后是否还有位置间相互作用、随机操作、精度转换或其他可变模块，并在至少两条件、两个检查点的少量记录上对齐完整前向。缓存通过后，S3 的八专家比较和 S4 的短更新可以只重复尾部运算，无须每次重跑主干。缓存键绑定数据、词元位置、冻结主干和接口版本；$p,S,E$ 随检查点变化，不能作为跨模型固定缓存。

### 输出、分支与汇报

输出 `eligibility.json`、`input_manifest.json`、`tail_cache_parity.json`。分支：

| 结果 | 允许说什么 | 下一步 |
|---|---|---|
| 五条件均合格 | 后续差异可归属于已记录的训练配置差别 | S1 |
| 某条件缺失或不匹配 | 完整比较未完成；其余合格配对可作部分比较 | 列明缺口，不自行补训 |
| 仅缓存不对齐 | 缓存接口不可用，不是模型机制失败 | 用原完整前向继续 |

**本步汇报句：**“我们比较的是同一起点的在线路由训练；旧冻结路由结果没有混入。”只有核验后才能写这句话。

## S1. 先看任务效果，决定后面要解释什么

### 要回答什么

结构正则化究竟带来改善、伤害，还是种子不稳定？先给效果定性，再讨论机制。

### Agent 操作与指标

1. 复用/完成最终更新 512 的完整内部测试评估。每模型、每种子：

   $$L=\frac{\sum_r \text{answer\_loss\_sum}_r}{\sum_r\text{answer\_token\_count}_r}.$$

2. 对每个正则化条件 $c$ 计算 $\Delta L_{c,s}=L_{c,s}-L_{task\_only,s}$；负值代表改善。报告三个种子原值、配对差、种子等权均值与样本标准差。
3. 展示逐任务差值，避免总 NLL 掩盖某个任务的损伤。整体 NLL 仍按词元加权；逐任务表和任务等权摘要不能替代主指标。
4. 保留 SAE-A/GMM-A、SAE-B/GMM-B、同一教师 A/B 的配对比较。不把教师构造差异解释为只替换一种聚类算法；不把相同 $\lambda=0.1$ 解释为相同梯度压力。
5. 在开发曲线上计算可选的归一化曲线面积：

   $$AUC=\frac{1}{512}\sum_{m=1}^{4}
      (t_m-t_{m-1})\frac{L(t_m)+L(t_{m-1})}{2},\quad t=(0,128,256,384,512).$$

   越低表示这段相同数据/更新预算内的平均损失更低。另报实际累计训练时间与设备/实现路径；旧基线运行环境不可比时，时间只作各自记录，不能直接排序计算效率。只有“更新步更少”不能自动写成“计算更省”。不从这五个稀疏点编造精确收敛时间。

### 输出

`final_nll.csv`、`per_task_nll.csv`、`paired_contrasts.csv`、`learning_curves.csv`；一张配对任务差值图、一张开发曲线图。缺失项写缺失，不插值补最终成绩。

### 分支与认识更新

| 观察 | 本步认识更新 | 下一步 |
|---|---|---|
| 三种子同向降低 NLL | 此设置出现方向一致的任务改善，机制未定 | S2–S3 找改变发生在哪里 |
| 方向反转 | 没有稳定排序，平均值不能掩盖反转 | S2 比较各种子路由作用是否也反转 |
| 三种子同向变差 | 结构约束在当前强度下可能妨碍学习 | S2 看约束与任务分发的冲突；不立即扩大训练 |
| 差异很小 | 即使同向，实际收益也很小 | 优先便宜诊断，暂不投入完整增量矩阵 |
| 早期较好、最终接近 | 可能改变了有限预算内的学习轨迹 | 保留“轨迹差异”，不声称一次样本学习 |

**本步汇报句模板：**“在相同起点和样本序列下，___ 的任务差值为 ___，三个种子方向 ___。这只确定了效果，还没有确定专家为什么不同。”

## S2. 分开检查：教师结构、路由概率和实际计算路径

### 要回答什么

正则项有没有产生它所要求的关系？这些关系是否真正改变了词元分发，而不只是改变输出权重？

### Agent 操作

在同一个 D/F 诊断面板、相同位置上，对五条件保存教师 $q^S,q^G$、有效掩码、$p$、$k$、$a=p_k$、无负载偏置选择 $k^0=\arg\max z$。教师向量可复用；每个模型的 $p,k,a$ 重新算。最先做最终检查点，只有发现需要解释的变化时才补 128/256/384。

**第一层：教师是否给出了可用区别。**记录结构掩码覆盖率、$q$ 的最大值与熵，以及跨记录样本对的教师相似度

$$s_{ij}=\frac{q_i^\top q_j}{\|q_i\|\|q_j\|}.$$

如果几乎所有 $q$ 相同，B 本来就缺少分离信号。不要增加人为负样本来“修好”当前实验，也不要把被排除位置从任务损失中删除。

**第二层：正则化是否改变概率关系。**A 报告原始相对熵 $KL(q\|p)$，即教师与路由概率的分布差异；B 报告原公式的吸引与排斥两项，继续分别按权重和归一化。为跨 A/B 比较，统一再算：

$$
 C_{same}=\frac{\sum s_{ij}\mathbf1[k_i=k_j]}{\sum s_{ij}},\qquad
 C_{diff}=\frac{\sum(1-s_{ij})\mathbf1[k_i=k_j]}{\sum(1-s_{ij})},\qquad
 C_{rel}=C_{same}-C_{diff}.
$$

对 $p$ 计算对应的加权距离摘要。样本对从固定的跨记录位置中抽取，五模型使用相同 ID 对；分母为零时写未定义，不用零替代。可固定抽取最多 20,000 对，避免构造全量平方矩阵。

$C_{rel}$ 高表示教师相近的样本相对更常共用专家，**不是专家功能或语义正确性**。同时报告各专家负载和教师权重分布，避免把所有样本挤进同一专家误读成同组一致。

**第三层：概率变化是否到达实际分发。**记录

$$B_{override}=\Pr(k\ne k^0),$$

并比较使用 $k$ 和 $k^0$ 的 $C_{rel}$。再看所选系数 $a$ 的分布。偏置很常改变选择说明路径包含强负载控制作用，不自动说明负载机制有害。

**额外但便宜的一项：实际负载不等于学习曝光。**A6 在全部非填充位置统计负载，但任务监督在答案预测位置。分别统计每专家收到的全部位置数、答案预测位置数、结构有效位置数，以及答案位置平均所选系数。全部位置均衡而答案位置极不均衡时，不能说每位专家获得了相同学习机会。位置数和系数仍只是学习曝光的代理，不等于真实梯度；缺少历史梯度日志时不能从终点推回整个训练过程。若需要追踪早期曝光，只读已有逐步计数或在保存的检查点上做固定面板描述，明确不是重建原训练历史。

**不能做的比较：**B 对专家编号的全局置换不敏感，因此不能用原始“第 e 组等于第 e 专家”的准确率判 B 失败。若需要画组—专家矩阵，原始矩阵可以画；若做编号匹配，必须只在 D 上固定映射、在 F 上评估。不同模型的“专家 3”也不能直接当成同一个功能实体。上述 $C_{rel}$ 不依赖专家编号，可优先使用。

### 一个便宜但重要的分层

对首个答案预测位置与后续位置分别报告教师覆盖和 $C_{rel}$。另外，已有数据中同词元编号跨上下文出现足够多时，比较其路由变化；以及同任务内不同词元的路由一致性。它只是词面/上下文依赖的描述，不自动证明语义识别。若缺少受控同义改写和上下文替换，标记“当前材料不能分离词面和处理需求”，不要现场生成几例后当作确认实验。

### 输出与分支

输出 `routing_relations.csv`、`route_bias_and_coefficients.csv`、`teacher_coverage.csv`。最多两张主图：教师关系到实际选择的对比；概率与离散选择的差异。

| 观察 | 认识更新 | 下一步 |
|---|---|---|
| 教师本身几乎不给区别 | 输入先验在当前位置/分组下信息不足 | 停止“该先验已引导分工”的说法 |
| 概率关系改善，实际分发基本不变 | 正则化主要改变了系数或未跨越选择边界 | S3 用固定系数的专家替换排查 |
| 无偏置选择有结构，实际选择弱 | 负载控制改变了结构信号到路径的传递 | 记录边界，不在本轮擅改偏置规则 |
| 实际分发关系更清晰，NLL 未改善 | 分得开不是任务收益的充分条件 | S3 看专家功能是否形成 |
| 分发和 NLL 均改善 | 存在相容的关联链，但因果环节仍缺 | S3 |
| 指标跨种子也反转 | 不稳定可能首先出现在分发形成 | 补中间检查点定位起始时间；不编最终机制 |

**本步汇报句：**“变化发生在 ___，而非所有层面；目前能确认的是分发关系 ___，还不能确认这些关系对应不同计算。”

## S3. 不更新参数，检验专家函数与尚未利用的旧能力

### 要回答什么

第一，专门分支是否真的影响答案预测？第二，不同专家能否随意互换？第三，表现差是不是仅因为选错了已有专家？这三问分开做，避免把一个“专家效用”数字承担所有解释。

### S3.1 先做两个删除干预

在同一检查点、同一 F 面板上分别运行：原模型；只将专门分支输出置零；只将共享分支输出置零。路由、系数、其他模块全部保持原值。

$$
D_E=L_{\text{去专门分支}}-L_{\text{原模型}},\qquad
D_S=L_{\text{去共享分支}}-L_{\text{原模型}}.
$$

正值说明删除在当前上下文中造成损伤。删除后的模型没有重新训练，所以这是**当前配置下的依赖性**，不是该架构有无适配器时的最优性能差。

- $D_E$ 达到预设大小：专门分支有可检出的整体作用，继续 S3.2。
- $D_E$ 近零而 $D_S$ 明显为正：当前提升主要依赖共享分支，不能讲成专家分工成功。再看逐组 $D_E$，避免平均抵消。
- $D_E<0$ 且超过容差：当前专门分支总体有害；先定位受损组，不通过增加专家来掩盖它。
- 两者均不确定：记录功效与效应大小，不把不确定写成“模型什么都没学”。

### S3.2 固定输出系数，逐个替换专家

对每个位置先保存原选择 $k_t$ 和原系数 $a_t=p_{t,k_t}$。依次把所选专家函数换成 $E_j$，$j=1,\dots,8$：

$$
\tilde y_{t,j}=y^0_t+S(h_t)+a_tE_j(h_t).
$$

再通过原来的残差后处理、最终归一化和语言头计算该目标词元的损失 $\ell_{t,j}$。这里 $y^0$ 是实际注入位置的冻结部分，具体实现必须与 S0 的完整前向对齐。

**为什么固定 $a_t$？**否则换专家的同时也换了输出幅度，无法区分“专家做的运算不同”和“路由给它的权重不同”。$j=k_t$ 是必需的自替换对照，必须复现原损失。测试只替换已指定位置，其余位置保持原状；不能用真实目标来改变输入前缀。

输出每个位置的八个反事实损失。按固定教师组 $g$ 汇总：

$$F_{g,j}=\operatorname{mean}_{t\in g}\ell_{t,j}.$$

更关键的是同一对专家 $j,j'$ 在不同组上的相对优势：

$$A_{g;j,j'}=\operatorname{mean}_{t\in g}(\ell_{t,j'}-\ell_{t,j}).$$

若在一个组 $j$ 更好、另一个组 $j'$ 更好，且在 F 上重复，才出现了**相对功能优势随输入组改变**的证据。某个专家在所有组都更好，更像整体质量差异，不能单凭此称为分工。

这里教师组只是固定诊断分组，不是已证实的语义类别。专家对和准备检验的组在 D 上选定，F 上只评估，不挑最漂亮的热图格子。

### S3.3 估计当前旧专家中的选择余地

固定系数的局部选择差距定义为：

$$G_{fixed}=\operatorname{mean}_t\left[\ell_{t,k_t}-\min_j\ell_{t,j}\right].$$

它表示：如果只换专家函数、不改幅度，已存在多少位置级改善空间。按任务、教师组、首个/后续答案位置拆开报告。

需要进一步解释幅度时，才补一个“使用替代专家自身原概率”的版本：

$$\tilde y^{nat}_{t,j}=y^0_t+S(h_t)+p_{t,j}E_j(h_t).$$

两种差距的意义不同，不能混成一个数：固定系数版本隔离函数替换；自身系数版本更接近当前路由参数提供的替代路径。八专家中的最小损失使用了目标答案，**只能作为诊断下界，不能当作推理时可实现的路由器成绩**。可学习的线性路由器是否能识别这些位置，要在 S5 的路由修复对照中验证。

### Agent 实现顺序与成本控制

1. 先做原模型与自替换一致性，再做删除；不得直接跑八专家表后才发现接口错了。
2. 尾部缓存合格时，批量计算八个低秩专家输出，但语言头按位置/专家分块计算，立即保留目标损失，不保存全部词表 logits。
3. 输出同时包含记录 ID、位置、原专家、替代专家、原系数、替代系数、损失和掩码。
4. 先在固定诊断面板做全部五条件；没有必要把八专家替换扩成全部 8,481 条完整测试。
5. 不使用自由生成来冒充本测试；当前是固定前缀下的答案预测干预。自由生成有额外路径变化，应单独定义。

### 输出、分支与认识更新

输出 `branch_ablation.csv`、`counterfactual_losses`、`functional_contrasts.csv`、`choice_gap.csv`。主汇报只保留一张功能对比图和一个选择差距表。

| 观察 | 允许结论 | 下一步 |
|---|---|---|
| 专家可替换、无选择差距 | 当前面板上没有显示不可互换的分工 | 不直接增长；S1 若有收益，优先解释共享分支/系数 |
| 相对优势随组改变，但原路由没选到 | 已有专家有异质功能，路由未充分使用 | S5 先做 R 路由修复 |
| 路由已较好利用旧专家，仍有待改善组 | 简单换旧专家的余地有限，但原因未定 | S4 看是否存在学习干扰或学习无效 |
| S2 分发更清晰，S3 功能对比无增强 | 几何分离未转化为更清晰的功能分工 | 暂停把分离指标当成功标准 |
| S2/S3 均改善，S1 不改善 | 局部分工不保证整体任务收益 | 检查组间抵消、共享贡献和收益大小；不扩大主张 |
| 自替换不一致 | 干预实现不可信 | 修复接口，废弃受影响的干预结论 |

**本步汇报句：**“我们不只看到分发不同；在保持同一输入与输出系数后，替换专家会使 ___ 组改善而 ___ 组受损。但这仍是当前函数作用，尚未回答它们应该怎样继续学习。”

## S4. 核心机制测试：学习一组，对另一组造成什么影响？

### 为什么这一步不需要知道最优专家参数

我们不猜专家最终应该长成什么样，而问一个局部、可测的问题：**从当前同一状态出发，给它一小段同样的学习机会，哪些留出样本受益，哪些受损？**

这得到的是当前检查点、指定优化器、指定预算下的学习关系，不是全局最优性证明，也不是“梯度一冲突就必须新增专家”。

### S4.1 先冻结候选群，避免事后挑冲突

1. 用 $c^*$ 对应的教师定义诊断组；若 $c^*$ 为 SAE 条件，采用冻结 $q^S$，GMM 条件采用 $q^G$。这些同一组定义也用于 task-only，不能给每模型另造一套有利标签。
2. 建议高置信诊断组定义为：最大归属概率至少 0.6，且最大与次大差至少 0.2，再按最大分量归组。**这只用于选干净的诊断子集，不改变 A6 的软目标。**阈值为新建议；低覆盖只说明该诊断不适用，不说明低置信样本没有价值。
3. 在 task-only、seed 17 的 D 中找“同一实际专家接收的多个教师组”，把它作为候选发现参照，避免正则化模型已将两组分开后反而找不到可比较对象。先按各组共同占用的记录数排序，最多保留两对候选；并列按教师组 ID 排序。每组在 U 和 D 中需各至少 16 条独立记录；组选择冻结后，再核对本阶段 F 中是否也有至少 16 条。允许按已冻结规则从整个对应子集中补取记录，不因结果不理想调低置信度；F 记录不足时报告不可判定，不改选另一个在 F 上更有利的组。
4. 在上述 task-only 参照的 D 上做下面定义的短更新探索，固定其中一对 $(i,j)$ 作为主探针。主时点为更新 8：先保留两个自组改善均超过 $\delta$ 的候选，再按 $-\min(T_{i\to j},T_{j\to i})$ 从大到小排序，并列按组 ID 排序。没有达到损伤阈值的候选，就记录未找到干扰候选；可以报告已有矩阵，但不能改用 F 筛出一个。其他候选仅保留为探索。
5. 保存 `candidate_lock.json`：教师版本、组规则、候选排序、组 ID、记录 ID、选择依据、被更新参数集合、模型、种子、检查点、优化器和步数。之后才查看 F。

如果教师八组已被严格分配到不同专家，不存在同专家双组，本层级的混学现象就不存在或不可测；不要随意重新聚类来制造一个冲突。进一步寻找组内细分需要读取原始稀疏特征或重新定义候选，属于后续设计，而不是本测试自动追加。

### S4.2 采用同样的数据，比较两种模型的“学习迁移矩阵”

对固定组 $i,j$，为每个待测模型定义：

$$
T_{i\rightarrow j}^{(u)}
= L(F_j;\theta)-L(F_j;\theta+\Delta\theta_i^{(u)}).
$$

其中 $\Delta\theta_i^{(u)}$ 是只用训练支持组 $U_i$ 做 $u$ 次更新后，实际得到的参数变化；$F_j$ 未参与该更新。正值表示学习 $i$ 帮助了 $j$，负值表示损伤。

**主比较保持同一组输入，不强行保持同一个专家编号。**同一组在 task-only 和正则化模型中可能路由到不同专家，这正是需要观察的分工差异。默认允许八个专门专家作为可更新集合，但只有支持样本实际选中的专家获得梯度；共享分支、路由器、负载偏置和主干全部冻结。

同时记录两组的实际专家重合率。如果要声称“同一个专家内部发生冲突”，需在预先固定的单专家子集上另外显示该现象；跨模型的主矩阵仍使用相同组输入，不能拿两个不同条件的不同子集作配对效果比较。

### S4.3 可以逐条实现的副本更新过程

对每个模型、每个种子、每个源组 $i$，独立执行：

1. 从同一个原检查点复制**全部**模型可变状态，保存原始损失。不同源组都重新从原点开始，不把“先学 i 再学 j”混入本矩阵。
2. 固定原路由概率、选择与负载偏置；禁用随机丢弃等随机行为，但保留专家梯度。加载主干后不更新它。
3. 从原训练集中取 $U_i$，最多 32 条记录、每条最多 8 个符合组规则的答案预测位置；样本 ID 和位置在两模型间相同。不能把同条记录中属于别组的答案也作为本次更新目标。
4. 使用新建的 AdamW 优化器，专家学习率固定 $2\times10^{-4}$，权重衰减设为 0，裁剪阈值 1.0；其他优化器参数从实际 A6 配置继承并记录。每步至多八条记录，按本步被选中的目标词元总数归一化。源组有限时使用固定顺序循环，并报告重复次数。
5. 只使用任务损失，无 SAE/GMM 正则；在更新 0、1、8 处评估，以更新 8 为主判定，更新 1 只解释小步方向。两者方向不同就报告时点依赖，不能挑其中较有利的一点。**这是新的短学习诊断，不是恢复 A6 原训练。**新优化器、零权重衰减、固定学习率和短批量均是为隔离学习影响而提出的设置。
6. 在 $F_i,F_j$ 及固定背景组上测损失。用同一检查点但无参数更新的副本作为 no-op 对照。记录实际更新范数、是否有限、每个专家是否真的改变。
7. 丢弃该源组的临时模型，再从原检查点测试另一个源组。原参数哈希、冻结分支哈希和路由选择均应不变。

**两个容易出错的地方。**第一，最终余弦学习率可能很小，不能把终点学习率直接拿来短更新，再据此说“专家学不会”。第二，AdamW 实际更新不是负梯度的简单倍数；本矩阵以实际损失变化为准，不能拿一个梯度余弦替代它。

### S4.4 先证明“学会了自己”，才解释对别人的影响

对双组矩阵

$$
\begin{pmatrix}
T_{i\to i} & T_{i\to j}\\
T_{j\to i} & T_{j\to j}
\end{pmatrix},
$$

对角线代表组内泛化，非对角线代表跨组迁移。按第 3.4 节的大小和区间规则判断。

| 矩阵现象 | 认识更新 | 下一步 |
|---|---|---|
| 两个对角线为正、两个交叉项为负 | 存在双向局部学习干扰 | S5 检验独立更新是否优于修路由/复用容量 |
| 对角线为正，仅一个交叉项为负 | 不对称干扰，不是完美二分结构 | S5 优先保护受损方向，不先画对称树 |
| 对角线与交叉项均为正 | 当前更新具有共享收益 | 优先 U 更新旧专家；增长动机减弱 |
| 对角线为正、交叉项在容差内近零 | 当前预算下近似独立学习 | 不把“独立”自动升级为“需要新增参数” |
| 对角线为正、交叉项区间不清 | 交叉作用未定 | 保持不确定，不为赶汇报追加任意步数 |
| 支持集改善、自己留出组不改善 | 只显示训练样本拟合或当前步数泛化不足 | 不得称已识别可泛化的新能力 |
| 连支持集也不改善 | 更新太弱、优化/接口/容量等仍未区分 | 先查实际参数与损失响应；必要时一次 S5 容量探针 |
| 无合格双组或记录不足 | 本候选构造无法回答冲突问题 | 不报告“没有冲突”；保留细分/数据不足结论 |

### S4.5 如何对比 task-only 和正则化模型

先报告两模型各组的初始损失，再看同一 $(i,j)$ 的对角改善和交叉损伤是否同时变化。初始剩余误差不同也会改变短期学习幅度；本比较识别的是已训练系统的局部学习行为差异，尚未独立分离路由变化与专家权重变化各自造成的作用。**交叉损伤变小但对角改善也消失，可能只是模型变得不愿意学习，不能称为更好的专门化。**

可以报告有自组改善前提下的损伤比例：

$$
I_{i\to j}=\frac{\max(0,-T_{i\to j})}{T_{i\to i}},\qquad T_{i\to i}>\delta.
$$

分母不满足条件时不计算。主结论仍看四格原值和区间，不只比较一个比例。若不同模型实际更新量差异大，补报按自组改善匹配的只读插值描述，或提出一个新预算匹配实验；不能偷偷增减更新步数以获取更漂亮的损伤比例。

先在最终检查点做 seed 17 探索；只有出现值得保留的候选，才在 F 上补足同一方案的 17/29/43。需要形成过程信息时，再以相同组规则补 128 或 256，不能只凭终点关系宣称冲突在整个训练中如何演化。

### 输出与汇报

输出 `support_probe_manifest.json`、`transfer_matrix.csv`、`parameter_and_route_invariance.json`、`temporary_update_costs.csv`。每个模型一张矩阵；另用表列出自组收益和交叉损伤。

**本步汇报句：**“在固定路由、共享分支和相同支持样本后，学习 i 对自身留出损失的改善是 ___，对 j 的影响是 ___；正则化模型相对 task-only 的变化是 ___。这说明 ___，还不能证明增加容量优于继续利用旧容量。”

## S5. 用最小对照决定：修路由、更新旧专家，还是局部增长？

### 本阶段的准确定位

使用 A6 已见任务做本阶段，只能叫**受控局部再适配**。其中的 i 是“待改善组”，不是从未见过的新任务；j 和背景组是“需要保留的组”。本阶段检验增长机制的局部价值，不直接证明持续学习。

### 进入条件

符合下列任一情形即可提出本阶段，不要求一定检测到梯度冲突：

- S3 显示有未利用的旧专家能力，需判断可学习路由能否调用；
- S4 显示可泛化的自组学习会损伤保留组；
- 存在持续待改善组，旧分支在指定短预算内学习不足，需区分容量增加与优化问题。

若只是教师分布陌生、置信度低、重构误差高，尚不足以进入“应该增长”的结论；这些只能提出候选。

### S5.1 先固定共同条件

先在 $c^*$ 的一个检查点、一个种子进行有上限的探索；有明确结果再配对比较 task-only 和三个种子。所有处理从同一原始参数起点出发。

支持样本来自训练集：待改善组最多 32 条；保留池包括冲突组 j 最多 32 条及其余任务最多 32 条。探针使用此前未用于 S3/S4 新干预的 `F_growth`，固定相同 ID；不能继续复用 `F_transfer` 来选择增长赢家。

每次更新取四条待改善记录与四条保留记录，用

$$L_{adapt}=\tfrac12 L_{\text{待改善词元}}+\tfrac12 L_{\text{保留词元}}$$

训练；两项分别按各自目标词元数归一化。共 16 次更新，在 0、1、4、8、16 次记录指标，以更新 16 为主判定，其余点展示轨迹，不在探针集上选择最佳早停点。两类样本有重复时如实报告唯一记录数与总曝光数。所有处理有同样的重放数据；不能只给增长分支旧样本保护。

负载偏置、主干和共享分支默认冻结。优化器按 S4 的新短更新规则，路由学习率用 $5\times10^{-4}$；新增加的门控也是路由参数。这里不继承 A/B 正则，避免把基础模型已有分工与后续额外结构目标混在一起。

### S5.2 按证据开启四种处理，不要求盲跑全部

| 处理 | 哪些参数变化 | 要排除的竞争解释 |
|---|---|---|
| K：原模型不变 | 无 | 短更新是否真的改善，而非评估噪声 |
| R：修路由 | 仅旧线性路由器；旧专家和共享分支冻结 | 已有能力存在，只是没调用 |
| U：复用旧专家 | 仅当前涉及的旧专家；路由/共享分支冻结 | 旧容量接受同样学习就足够 |
| C：无进一步细分地增加修正容量 | 旧系统冻结，在父专家分支内始终加一个小修正模块 | 收益是否仅来自更多可用容量/保护旧参数 |
| G：条件化增加修正容量 | 同 C 的修正模块，另学习何时启用它的门控 | 局部条件化是否优于不细分的容量增加 |

R 优先在 S3 有选择余地时开启；U 总是增长对照；只有 U 不足或问题本身是容量假设时才加入 C/G。C/G 不是新增 Dense 基线重训，而是区分增长原因的局部对照；它们属于本后续提案，不是偷偷加入 A6 五条件矩阵。

### S5.3 R：不能把“知道最佳旧专家”当成已经修好路由

先尝试只更新旧路由的任务损失。如果选择余地未被利用，需注意离散选择本身不可微，不能直接据此宣布“路由无法学习”。

可开启一次明确记录的辅助诊断：在**训练支持集**上，用冻结旧专家及原快照系数构造八专家损失，取最小损失专家作为固定监督目标，对现有线性路由做短时分类拟合；不使用 F 的最优专家标签。辅助拟合目标为固定专家标签的交叉熵；之后在 F 上用真实模型路径与实际系数评估。

这样得到的结论仍有边界：若分类拟合失败，可能是当前线性接口难以读出该选择，也可能是优化和样本不足；不是证明旧专家整体不可用。若拟合标签准确但实际任务不改善，应检查概率系数变化及“固定系数最优”与真实路径的差异。固定标签拟合与任务损失路由修复分别记录，不混成一条训练策略成绩。八专家标签构造的计算开销计入 R。

### S5.4 C/G：保留旧计算，添加零初始化的局部修正

令 $e$ 为候选父专家，旧模型对应位置输出为 $y_{old}$，原选择与系数为 $k,a$。定义：

$$
 y_C=y_{old}+\mathbf1[k=e]a\,g_C\,\Delta E(h),\qquad g_C=\operatorname{sigmoid}(c_C),
$$

$$
 y_G=y_{old}+\mathbf1[k=e]a\,g(h)\Delta E(h),\qquad
 g(h)=\operatorname{sigmoid}(w^Th+c).
$$

修正模块 $\Delta E$ 使用与旧专家相同的 rank-16 低秩接口和缩放；A 矩阵按原规则初始化、B 矩阵为零。C/G 使用同一新增模块初始参数。C 的标量 $c_C=0$，G 的 $w=0,c=0$，两者门控初值均为 0.5；因此新增瞬间严格不改变函数。C 也允许学习整体修正幅度，但它不依赖输入，用来排除“只是统一调大/调小新分支”的解释。先验证 $u=0$ 与 K 一致。

不把旧的八路 softmax 改成九路；不重新归一化旧专家系数。这样避免“只是新增一个输出选项，就改变旧路由权重”的混淆。G 第一次任务反向时门控梯度可能为零，因为新模块输出为零；应在新模块已有非零更新后检查。

C/G 都保留父专家计算，区别只在父分支内是否对输入条件化。**它们不是与 U 完全相同的计算量**：多一条低秩前向，G 还多门控参数。必须报告新增参数、实际活跃算量、显存和测得运行时间，不能把同样更新步数写成等计算比较。G 对 C 的门控收益也受新增门控参数影响，只能形成当前局部设计下的证据。

若 G 优于 C，补一个不训练的门控干预：将已训练 G 的 $g(h)$ 固定为 D 上父分支内的平均值，保持其余参数不变，在 F 上重新评估。若效果不变，不声称输入条件化已经产生可检出贡献；若被破坏，才支持“当前 G 的效果依赖门控随输入变化”，仍不是所有层级模型的优势证明。均值不能在 F 上调优。

门控作用域若只能覆盖父分支，父路由把样本送错分支时 G 无法补救。这正是先检查 R 的原因。若 i 与 j 在推理时可见的输入上无法区分，新增专家也不能凭空补出缺失信息。

### S5.5 需要报告的不是单一新组收益，而是一组权衡

$$
\text{Gain}=L_{i,0}-L_{i,after},\qquad
\text{Damage}=L_{retain,after}-L_{retain,0}.
$$

保留集至少分别显示冲突组 j 和其余背景任务，不能用八任务平均值掩盖 j 的损伤。报告每个处理在各更新数处的 Gain、Damage、唯一支持样本数、累计曝光数、新增参数和实际计算成本。

建议保留容差 $\epsilon_{ret}=0.001$ nat/词元，为本提案的工程判据，不是已知“可接受遗忘”标准。符合保留约束需损伤区间上界不超过该容差；仅点估计较小不够。收益也按第 3.4 节预设大小判断。

若没有处理在收益和损伤上全面占优，报告权衡曲线，不自动把“新增多一点内存换更少损伤”判成优越。何种代价值得由研究者决定。

### S5.6 分支与最终允许结论

| 结果 | 允许结论 | 不能声称 / 下一步 |
|---|---|---|
| R 达到收益且满足保留容差 | 当前困难可以由已测试的路由修复解决 | 不需要以增长作为首选 |
| U 达到收益且满足保留容差 | 当前旧容量在指定学习预算下可复用 | 不必长新专家 |
| C 和 G 相近，均优于 U | 新增修正容量/冻结旧参数有局部价值 | 未证明进一步细粒度门控必要 |
| G 相对 C/U 改善新旧权衡、门控干预支持条件化作用且成本可接受 | 支持该候选群、预算、接口下的条件增量 | 还不是普遍层级优势或持续学习结果 |
| G 组内改善、保留损伤也大 | 门控误触发或新计算干扰旧输出 | 先修保留机制；冻结旧参数不等于无遗忘 |
| G 只在训练支持样本改善 | 只显示拟合，不是学到可泛化新规则 | 不声称快速学习 |
| R/U/C/G 都弱或不确定 | 数据、接口、优化或容量解释尚未分开 | 不追加“更大专家”作为默认答案 |
| G 有效，但未测试其他旧模块联合更新 | 只胜过本计划测试的旧专家更新策略 | 不能说整个旧模型已无学习容量 |

最后一条很重要：本计划冻结共享分支以隔离问题，因此 U 的失败不能证明“如果允许更新所有旧参数，也一定失败”。若要作更强的容量必要性主张，需要额外的旧模块联合续训对照，另行计入预算。

输出 `adaptation_learning_curves.csv`、`gain_damage_cost.csv`、`growth_gate_activation.csv`、`growth_initialization_parity.json`。主图用 Gain–Damage 曲线，旁边列出计算/参数代价。

**本步汇报句：**“我们比较的不是新增专家与什么都不做，而是它相对修路由、复用旧容量、无条件增加容量的作用。目前证据支持 ___；仍不能排除 ___。”

## S6. 把局部增量推进到真正的持续学习与少样本学习

### 为什么必须另开这一步

A6 的八任务已经参与训练，教师构造也使用了训练分布。直接拿现成检查点，把其中一类再训练一次，不能说明“后来出现的知识如何学习”。S5 的局部优势只有通过时间顺序控制，才能与持续学习连接。

本节是后续实验规格，不是本轮训练后分析必须完成的工作。若时间有限，停在 S4 或 S5 已能形成完整、有边界的汇报。

### S6.1 最小的任务到达顺序

一个可复用现有材料的建议是：从原始适配器初始化重新开始；把八个真实 `task_id` 按 `SHA256("continual-v1|task_id")` 排序，前六个作为早期任务，后两个依次到达。不根据已有成绩挑最有利的新任务。

- 阶段 0：只用早期六任务训练路由和适配器，保存阶段结束状态。
- 阶段 1：第七任务到达，同时保留固定旧任务重放池。
- 阶段 2：第八任务到达，同时回测前面七任务。

**两个数据限制必须核对。**第一，GMM 拟合与 SAE 分组构造不得提前使用后来两任务；GMM 可按 A6 同样算法只在早期数据上重拟合，SAE 分组必须按实际原分组实现仅用早期数据构造。上传协议没有完整 SAE 分组算法，Agent 必须读取实际源实现；找不到就标记该步骤缺失，不能用常识自行补成一种谱聚类。第二，Qwen 预训练可能已含相关能力，因此这个设计严格测的是“后训练阶段未暴露的任务”，不是保证主干从未见过对应知识。

若要声称新增规则本身从未见过，需要独立生成、在初始模型冻结之后确定的符号—规则关系，并分离规则学习与表面改写；这是另一个数据设计，不能在本计划中假装现有八任务已满足。

### S6.2 “一个样本”与“学得更快”分别报告

从同一个阶段起点出发，对每个新任务使用嵌套的 1、4、16、64 条唯一支持记录。每个样本量单独恢复起点，不把先用 64 条训练的模型当作 1 条样本模型。

每个支持集做固定 16 次更新，并在 0、1、4、8、16 次评估；旧任务重放预算在各方法间一致。报告：

- 唯一新样本数；一条长答案可包含多个监督词元，不能称成一个监督信号；
- 总更新次数、总词元曝光量与实际计算成本；
- 新任务独立记录及不同表达上的效果；
- 旧任务相对到达前检查点的损失变化。

只有一条新样本训练后，在独立输入上有稳定收益，才能讨论该设定下的一次样本适配。新任务 NLL 学习曲线更低，不等于已经证明一次样本学习。重复使用同一条样本允许计入训练，但必须如实报告重复曝光。

### S6.3 自动增长触发器，不能借用任务边界答案

第一版可以只在已知任务边界调用 S5，回答“增长动作是否有效”；下一版再研究“模型能否自己发现何时调用增长”。不要把二者合并为一个成功指标。

建议最小自动版本：

1. 在仅含旧任务的控制流上，固定按 32 条记录组成检测窗口；计算窗口答案 NLL 的参考分布。用其 99% 分位数作为预警阈值，再要求连续两个窗口超过阈值。窗口大小和分位数是候选工程默认值，不是已验证最优触发器。
2. 超阈只触发**检查**，不直接增长。教师重构差、归属不确定或分布似然变化可以作为附加记录，但不作为单独的永久扩容依据。
3. 将触发缓冲中的训练数据划分为支持与临时验证两部分，调用有预算限制的 R/U/C/G 局部比较；验证位置不得同时用于短更新。所有候选的试验计算都计入策略成本。
4. 只有 G 或 C 在预设新旧收益约束下优于已测试的复用方式，才提交新增模块。否则修路由、复用旧容量或维持现状。即使 G 通过，仍需在后续未用于该决策的数据上测效应。
5. 新增后回测旧任务；记录门控在旧样本上的触发率与造成的损伤。旧参数不变，不等于旧输出不变。

这个触发器使用训练时已观察到的真实目标来计算损失，不能被描述为无标签推理时检测。模型路由输入仍只使用可见前缀；用于审计真实任务边界的 `task_id` 不提供给自动触发器。

GMM 归属概率很高也不能证明输入熟悉，因为它只表示相对于八个已有成分更像哪一个；需要考察绝对拟合或任务表现时必须另行记录，而不混淆归属与覆盖。

### S6.4 必须有“无需增长”的控制段

数据流至少含三种窗口：重复旧任务；仅改变表达/任务混合比例但不增加待学规则；真正引入后到任务。前两类用来估计不必要增长，不能只测有变化时能否触发。

比较至少三种策略：固定容量但允许旧参数适配；按上述规则检查后增长；已知真实任务到达时间才启动同一增长过程的边界已知参考。最后一种只作为诊断参考，不是可部署方法。预算允许时再加固定频率增长，检验“是否只是多加参数就行”。

首版每个数据流最多允许两个永久增长事件。达到上限后继续记录需求但不再增加；避免用无限扩容获得不可比结果。

输出指标：旧任务控制段每百窗口的不必要增长次数；从真实到达到预警/提交的记录数；试验候选与永久模块的总成本；每阶段新旧 NLL；累计新增参数。不能把没有“最优扩容真值”的每次预警都判为错，需区分预警、检查和永久增长三件事。

## 4. 你的参数差与梯度想法，怎样成为有价值的辅助分析？

### 4.1 参数起点—终点差，保留，但不作为主要分工证据

$$\Delta\theta=\theta_T-\theta_0=\sum_{t=0}^{T-1}(\theta_{t+1}-\theta_t).$$

它是净位移，中途相反的更新会抵消。于是“净变化很小”既可能表示没学，也可能表示有大量相互抵消；仅凭端点无法区分。如果保存了中间检查点，可以比较分段变化，但仍不能复原没保存的逐步轨迹。

低秩适配器（LoRA）的有效线性更新是 $W_{adapt}=sBA$。因为 $(B Q^{-1})(QA)=BA$，分别比较 A/B 因子的方向可能只是参数化差异。更合适的是：

$$\Delta W_{eff}=s(B_TA_T-B_0A_0).$$

比较它的范数、奇异值或不同专家之间的方向，只能叫参数几何，不能直接叫语义专门化。两个专家权重不同，仍可能在实际输入上输出近似相同；反之，小的参数变化也可能影响高敏感的输入。

### 4.2 优先比较固定输入上的函数变化

在同一组参考 $h$ 上计算

$$\Delta E_e(h)=E_{e,T}(h)-E_{e,0}(h).$$

分别报告不带路由系数的 $\Delta E$ 和实际加权贡献 $p_kE_k$。前者看专家函数，后者看模型真正使用的贡献；两者不要混在一起。

输出幅度/相关性可解释“专家是否写出了相似修正”，但最终还需接回 S3 的目标损失变化。初始化 B 为零时专家输出可能全零，余弦和相对变化率未定义；写未定义，不用一个极小分母制造巨大差异。

### 4.3 梯度为何比输入距离更接近学习需求，但仍不是最终答案

对简化的完整线性专家 $E(h)=Wh$，令 $\delta_i$ 为损失对专家输出的梯度，则

$$\nabla_W\ell_i=\delta_i h_i^T,$$

$$\langle\nabla_W\ell_i,\nabla_W\ell_j\rangle
=(h_i^Th_j)(\delta_i^T\delta_j).$$

这是一条直接代数恒等式，适用对象是完整线性 W；不能不加修改地套到 LoRA 因子、门控参数或 AdamW 实际步长上。它传达的直觉是：**输入像不像之外，还要看任务希望输出朝哪个方向改。**

可选的廉价筛查：在同一检查点、同一参数集合上，计算每组任务梯度，比较组间夹角；或用真实短更新 $\Delta\theta_i$ 预测对另组的局部变化：

$$L_j(\theta+\Delta\theta_i)-L_j(\theta)
\approx \nabla L_j(\theta)^T\Delta\theta_i.$$

必须用同一位置的梯度与更新，不能拿终点总位移与任意时刻的梯度随意配对。小步近似还受曲率影响，最终由 S4 的实际留出损失验证。

**禁止的捷径：**不同专家参数天然放在不同坐标块，完整参数梯度可能自动正交。这只能说明更新位置不重叠，不能单独证明专家学得好；必须同时显示对本组的留出改善和对其他组的影响。

### 此辅助分支的停止规则

如果参数谱或梯度相似性与 S3/S4 的函数、学习变化不一致，优先保留函数与干预证据，把几何指标降为不充分代理。不要为维护参数几何故事而改掉主实验问题。

## 5. 在何处检查“上下文身份”和动态 SAE？

本节只在主链暴露对应缺口时使用，不默认新增一整轮实验。

### 5.1 上下文身份缺口：S2 有结构，但可能只是词面规则

最小受控配对由两种变化构成：保持当前词元编号不变、改变前缀要求的操作；保持操作不变、只改写表达。必须先明确正确输出规则，准备独立模板，固定因果位置。

依次比较 $h$、教师 $q$、概率 $p$、选择 $k$、S3 的相对专家作用。分支：

- $h$ 已无可检出的区分：当前读取位置/信息接口不足，路由器无法凭空恢复；不先改聚类。
- $h$ 有区别而 $q$ 丢失：教师压缩/分组可能是瓶颈；需重新验证候选教师，而非把它当真标签。
- $q$ 有区别而 $p/k$ 丢失：路由学习或离散/负载接口可能是瓶颈。
- 路径有区别但功能无区别：回到 S3–S4 的学习内容，而不是继续拉开距离。

“$h$ 有区别”必须由预先规定的可读性或成对判别检测支持；单看二维图不能作此判决。现有附件没有这样的配对数据，若需正式实施，应单独给出生成规则，不冒充已有分析。

### 5.2 动态 SAE 缺口：只有被读取的分布确实变化时才讨论

当前 A6 的读取位置不随适配器训练变化，因此动态重训该处 SAE 不能解释由主干漂移引起的问题。[S1 §4.3]

未来若上游参数可训练，或真正新数据造成覆盖变化，可以先固定一批参考输入，比较旧词典的重构、有效覆盖及组关系稳定性；超过预先固定的容差再考虑抽样、低频更新词典。重新训练 SAE 后必须检查旧特征的对应与拆分，不能把编号变化当作新能力。

若改为分析专家注入后的状态，那是不同的输入分布，需要重新校准分析器。输入处 SAE 的标签不能未经验证直接拿来给专家输出命名。

本分支的认识更新是：**分析器更新、路由器更新、专家参数增长是三个不同决策，不应绑成“训练每一步都同步做”。**

## 7. 每轮汇报怎样形成完整而不过度的证据链？

### 7.1 指标必须回答一个问题，而不是堆在同一页

| 汇报层次 | 首要指标 | 最小图/表 | 这一步不能替代什么 |
|---|---|---|---|
| 任务效果 | 配对 $\Delta$NLL、逐任务差值 | 三种子配对差表 | 不能替代机制 |
| 实际分发 | $C_{rel}$、偏置覆盖率、答案位置负载 | 概率关系与选择关系对照 | 不能替代专家功能 |
| 当前功能 | 固定系数专家对比、删除损伤 | 预指定组的专家相对优势 | 不能替代学习兼容性 |
| 学习兼容性 | 自组收益与交叉迁移四格 | 两模型学习迁移矩阵 | 不能替代增长必要性 |

### 7.2 可填写的汇报叙事

**大问题：**模型如何形成既能共享已有计算、又能对新需求局部学习的专家分工？

**本轮唯一问题：**填写本次最高完成阶段真正回答的问题。例如只到 S2，就问“结构正则是否改变了实际分发”；完成 S4 后，才问“分发变化是否改变了不同样本之间的学习干扰”。

**原先的解释：**无监督分组可能把处理需求相近的样本送到一起，因此帮助专家学习。

**最强竞争解释：**分组只改变概率、输出系数或负载；即使有不同路径，也未对应不同计算，或者并不改善学习兼容性。

**直接证据：**填入已完成阶段的数值、模型/种子范围、对照和区间，链接原始表。

**本次认识更新：**“当前证据把解释推进到 ___；否定或削弱了 ___；仍无法区分 ___。”

**下一步唯一决策：**从本阶段分支选择一个动作。例如“先修路由”，而不是同时宣布重训 SAE、构造树、增大专家和换数据。

### 7.3 不同完成程度都可以结束一轮汇报

- 只到 S1：任务效果的边界已清楚，机制尚未测。不因没有机制就把平均提升包装成专门化。
- 到 S2：能定位先验到实际分发的传递是否成立；这已经可以否定“概率变好就代表分发变好”。
- 到 S3：能判断当前函数是否可互换，以及已有能力是否未被调用；下一步是学习关系，而非再做更多同类效用表。
- 到 S4：能把分工解释推进到局部学习兼容性；这是最直接连接增量学习的一步，但仍不等于应该扩容。
- 到 S5：能在指定预算与替代方案中作局部增长决策；持续学习验证仍独立。

## 8. 从你的提问看，当前认识已经到哪里，还需要跨过什么？

以下只是基于本轮提问及材料的判断，不是对你整体科研水平的评价。

### 8.1 已经明确的部分

你已经不满足于“聚类分开、路由均衡、任务分数提升”这几个表面结果，而在追问：专家内部究竟学了什么，参数更新是否反映这种学习，以及分析怎样决定后续动作。你还主动要求把正结果、负结果和不确定结果都接进验证链。这说明当前问题已经从“寻找一个可用模块”推进到“如何建立能支持研究决策的证据链”。

目前最需要补上的，不是再学一种聚类算法，而是给以下三件事划定清楚的位置：**训练后的描述、训练后的干预、下一轮学习的决策。**

### 8.2 第一个深化：专家的“职责”有两个时间尺度

**当前职责**是：现在把这个输入给哪位专家更好？S3 回答它。

**学习职责**是：以后继续学习这个输入群时，哪些参数应该一起变化，哪些最好保持独立？S4 回答它。

两者可能不同。一个专家现在在两组上都表现不错，但继续学习一组会伤害另一组；另两个专家现在输出不同，却可能在新样本上需要同方向的更新。只做终点效用表看不到这种区别，只看总参数差也看不到。

因此，值得作为下一研究问题的不是“专家是否已经不同”，而是：

> **无监督分组能否预测，哪些样本应该共享未来的学习更新？**

这把 SAE/GMM 从“真标签生成器”降回可检验的候选先验，同时赋予它更明确的研究作用。

### 8.3 第二个深化：分工不是把所有东西推远，而是选择性共享

理想现象不是所有交叉迁移都变小。若学习 i 本来有助于 j，把它们完全隔离反而可能浪费共享机会。

更有价值的目标是：**有用的正迁移保留，确实伤害别人的更新得到隔离，并且每一组仍学得动。**所以 S4 同时要求看自组改善、正迁移和负迁移，不能只汇报“梯度冲突下降”。

这里也出现一个重要反例：模型什么都不学，当然不会伤害旧任务；这不是好的持续学习。因此“遗忘少”永远需要与“新内容确实学会”成对报告。

### 8.4 第三个深化：语义层级可以提出树，但不保证学习关系是一棵树

导师的粗到细直觉可以转成一个更可测的含义：**保留多个情境都需要的共同计算，只有未被共同计算解决的差异才增加局部修正。**这不要求先获得完美的生物分类式语义树。

但 S4 的学习迁移可能是非对称的：i 帮助 j，j 却伤害 i；也可能三组之间没有一个统一的父子顺序。这样的证据可能更像带方向的关系图，而不是一棵干净的树。此时应让结果约束结构，不为了画层级而重新命名组。

**本文件的树是决策树，不是预先断言模型必须采用树架构。**这是验证逻辑与模型结构之间必须保留的区别。

### 8.5 第四个深化：快学习和永久扩容，不必是同一次决策

一次样本适配追求“少量新观察能立即产生有用变化”；永久增加专家则还要承担参数、路由和旧能力风险。一次观察有时足以尝试一个小修正，却未必足以证明应该永久增加一条分支。

可以将“临时、可撤销的快速写入”与“经过后续证据确认的结构增长”分开。这只是值得研究的候选策略，不是本文已经验证的结论；它也解释了为何 S6 的持续预警不能被直接宣传成一次样本增长判据。

### 8.6 最小的理解输出

在让 Agent 实现昂贵阶段之前，你只需能独立讲清三句话：

1. 同一教师分组可以改变路由概率，却未必改变所选专家。
2. 专家当前能做什么，与在它里面继续学习会伤害谁，是两个问题。
3. 学习冲突提出“分开更新”的候选；与修路由、复用旧容量比较后，才能决定是否值得新增参数。

如果三句话能够用 S2、S3、S4–S5 的具体操作解释出来，主线就已经清楚，不需要再通过堆更多术语来证明理解。

## 9. 文末实验建议：时间有限时，具体先做什么？

### 优先级 0：先交付一个完整的便宜结论

### 优先级 1：补上最小的函数干预

**做 S3 的自替换、两种删除，以及固定系数的八专家小面板。**先验证尾部缓存，再用相同输入覆盖五条件。目的不是把效用分析当终点，而是为 S4 排除“专门分支根本没起作用”和“已有旧专家就能解决”的解释。

若时间只能容纳一张新增功能图，选预先固定双组的专家相对优势，而不是再画一次路由分布。

### 优先级 2：最值得投入的一次机制推进

**只选一个候选双组，比较 task-only 与 $c^*$ 的 2×2 学习迁移矩阵。**先 seed 17 探索，更新 1 和 8 次，固定共享分支与路由。首要看自组是否泛化，再看交叉伤害。

这一步是你从“专家效用”走向“专家为什么需要分工”的最短实质推进。

### 优先级 3：只在已有候选时比较增长

**先 R 或 U，再按需要 C/G。**只研究一个局部候选，16 次短更新，保留集与待改善集都测。必须纳入 C，才能区分“更多修正容量”和“更细门控”的作用；不能只比较 G 与什么都不做。

若 R/U 已足够，停止增长主张就是一个有效结论。若 G 与 C 相近，汇报容量作用，不强讲层级结构。
