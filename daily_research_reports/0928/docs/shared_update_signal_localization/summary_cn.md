# 结果摘要：定位被总体帮助抵消的任务信号作用

方案：[本轮事后分析 Protocol](protocol.md)  
完整证据：[detailed.md](detailed.md)  
原注册结果：[0927 Summary](../../../0927/docs/shared_update_research_pack/summary_cn.md)  
状态：**分析已完成；事后探索；研究者科学判断待确认**。

## 1. 目的

定位 A 的有效更新对 B 造成的任务信号相关不利作用，找出压过它的较大帮助，并检查冻结 SAE 共同原子及其他几何／读出空间能否定位这种带符号作用。原注册实验得到“规则调节帮助、没有 B 净伤害”；本轮只分析同一批已保存的 192 次虚拟更新，不能改写原裁决。

## 2. 假设

在无关变量匹配的 \(t=\pm1\) 样本内，随任务信号翻转的位移可能在 B 翻转规则下增损，而更大的不随信号翻转的位移为 B 减损。更强的共同空间解释要求这项增损主要集中在共享表征空间。竞争解释是：共同激活、较大静态方差或容易解码任务标签，都不代表实际更新及其损失作用走这些空间。

## 3. 分析方法

逐逻辑样本对将 \(\Delta a_t=b+t s\)，其中 \(b=(\Delta a_++\Delta a_-)/2\)，\(s=(\Delta a_+-\Delta a_-)/2\)。把两项分别投影到冻结 SAE-full、原始 SVD、中心化 PCA、SAE 内 PCA、岭回归 probe 空间和三组同秩随机空间；这些空间只在独立结构集拟合，不用 B 损失选轴。利用已保存的 B 损失导数求带符号作用，逐条核对 \(I=C_{P,sig}+C_{P,even}+C_{\perp,sig}+C_{\perp,even}+R\)。沿用原来的 2000 组 family／repeat／pair 配对 bootstrap 索引求条件 95% 区间。probe 只用结构集的任务标签拟合，在独立读出集评价。12 个方向族都已被看过，且 bootstrap 不重新拟合空间。

## 4. 结论

**在这批已查看的构造数据中，预设的原生任务信号符号模式成立，但其局部不利项只占总体有益更新的一小部分。**步长 \(10^{-4}\) 时，高重合／B 翻转的 \(C_{sig}=+8.3126\times10^{-5}\) nat／目标，95% 区间 \([8.2860,8.3411]\times10^{-5}\)；不随信号翻转的作用加余项为 \(-0.0067480\)，所以实际 \(I=-0.0066649\)，区间 \([-0.0066800,-0.0066492]\)。高重合 A 和 B 保持规则的任务信号项分别为 \(-1.0335\times10^{-4}\) 与 \(-8.2701\times10^{-5}\)。任务信号交互 \(M_{sig}=+1.4510\times10^{-4}\)，区间 \([1.4458,1.4571]\times10^{-4}\)，占原注册 \(M=+1.5206\times10^{-4}\) 的大部分。半步长也满足相同符号。这里使用目标损失导数作局部归因，尚无表征干预的因果证据。

**所测静态空间都没有接住大部分不利作用。**高重合／B 翻转／步长 \(10^{-4}\) 时，SAE 完整空间中的 \(C_{P,sig}=+2.6766\times10^{-6}\)，空间外还有 \(+8.0449\times10^{-5}\)；它相对三组同秩随机空间的超额贡献区间为 \([-0.066,0.305]\times10^{-6}\)，跨过零。中心化 PCA-8 接住 \(+0.9040\times10^{-6}\)，相对随机秩 8 有很小的正超额 \([0.153,0.319]\times10^{-6}\)，但空间外仍有 \(+8.2222\times10^{-5}\)。原始 SVD-8 也有很小的正超额，两者都不支持“主要位于该空间”。秩 3 probe 在同组独立样本上准确率为 1.000、相同重合度跨组为 0.875，但它的带符号贡献仅 \(+0.1984\times10^{-6}\)，同秩超额区间跨零。半步长的定性读法相同。冻结 SAE 的任务信号重构护栏仍失败；投影捕获率不能修复这个资格问题。

必须分开看静态表征与更新位移：原始 SVD 首轴几乎接住全部均值能量，却只接住 B 中心化方差的 3.4%；中心化 PCA-8 接住 B 方差的 96.8% 和几乎全部**静态**任务差，却仅接住实际任务相关**更新位移**能量的 1.09%。SAE 完整空间接住该位移的 3.22%；较大的减损 even 项也主要在 SAE 外（外部 \(-0.0067065\)，内部 \(-0.0002232\)）。因此，标签能读出、静态空间有变化、实际更新经过该空间，是三种不同读数。
