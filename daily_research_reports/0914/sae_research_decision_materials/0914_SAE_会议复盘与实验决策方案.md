# 3．你的考虑对不对：把三个不同问题分开

## 3.1 直接回答

**你的考虑在“同一个 SAE 连续训练、追踪固定参数槽位”这个前提下成立；在“每个检查点独立拟合 SAE、把同编号当成同一特征”时不成立。无论哪一种，同编号都不自动保证同语义。**

| 你想说的结论 | 是否必须先匹配特征？ | 必要前提 |
|---|---|---|
| 第 j 个参数槽位的激活偏好如何变化 | 不需要语义匹配 | 同一训练轨迹，编号继承可审计，无未记录重置 |
| 当前所有特征整体是否更有领域选择性 | 可以不做逐特征匹配 | 使用对编号置换不敏感的总体指标、相同数据和规则 |
| 某个稳定概念从早期发展到后期更纯净 | 需要额外行为与语义证据 | 跨表达正例、语义反例、稳定响应；不能只靠编号 |
| 独立 SAE 的第 j 个特征是同一个对象 | 不能直接这样说 | 需额外建立对应，或改问不依赖编号的问题 |

“编号固定”是记录规则，不是研究结论。真正可检验的问题应写成：**预先固定的一组连续参数槽位，对同一批领域文本的激活偏好，在训练过程中怎样变化？**

## 3.2 统一符号：位置相同究竟意味着什么

设训练时刻为 t，固定输入文本为 x。主干给出的表示为 hₜ(x)∈Rᵈ。SAE 使用 m 个字典特征：

    zₜ(x) = TopK(ReLU(Wₑ,ₜ(hₜ(x) − bₜ) + aₜ))
    ĥₜ(x) = Dₜ zₜ(x) + bₜ

编码器 Wₑ,ₜ 的形状为 m×d；它的第 j 行计算第 j 个特征的激活。解码器 Dₜ 的形状为 d×m；它的第 j 列是该激活写回原空间的方向。zₜ,j 是这个位置在当前输入上的激活值。

你的“第 j 个位置”对应编码器第 j 行、编码器偏置第 j 项和解码器第 j 列的配对关系。连续更新时可以追踪这个位置；但这些参数和主干 hₜ 都会变化，因此它最终响应什么内容，必须实际测量。

这里有三种身份：参数身份是同一条更新路径上的槽位；响应身份是对固定输入的行为是否接近；语义身份是对同一概念的不同表达是否稳定响应。第一种不自动推出后两种。

## 3.3 为什么独立训练的同编号不可靠：一个严格反例

取任意特征置换矩阵 P，同时重排编码器与解码器：

    W′ₑ = P Wₑ，a′ = P a，D′ = D Pᵀ。
    z′ = Pz；于是 D′z′ = DPᵀPz = Dz。

在没有排名并列歧义时，保留最大若干激活的操作也与该置换相容。重构结果、重构损失、非零激活数量都可以保持不变，但特征编号已经改变。

最简单的例子：原来的特征1只响应输入类别A，特征2只响应类别B；把两个位置对调，模型重构能力完全一样，新的特征1却只响应B。因此，独立训练后同编号发生变化，不足以证明同一语义发生了演化。

相同随机种子或相同初始化，也不能保证在不同表示分布上优化后得到同一语义分配。可以比较共同初始化下两个训练分支的参数，但不能把它们说成一条未经中断的时间轨迹。

## 3.4 连续训练也不保证语义不变

让同一编号的方向从 (1,0) 连续转到 (0,1)。它一开始响应第一类输入，后来响应第二类输入；整个过程没有重编号。因此，连续性建立的是“这个位置怎么变”的研究对象，不是“它始终代表同一个概念”的保证。

还要注意，主干的表示坐标自身也会演化。解码方向夹角小，不足以证明语义稳定；夹角大，也不足以证明语义一定改变。对固定输入的整体响应 zₜ(x) 比单独看参数夹角更接近你当前的问题。

# 4．下一轮的研究决策：先做哪个比较

## 4.1 主问题与不能混在一起的三个结果

**主问题：在初始化、训练数据、训练长度和前向结构相同的条件下，让稀疏重构辅助目标更新上游主干，是否使最后一层 MLP 输入更容易区分未参与训练调参的领域，同时不明显损害语言建模？**

# 5．训练目标、梯度、稳定性与训练预算

## 5.1 第一轮只使用一个可解释的结构目标

设 h 是选定位置的主干表示，z是稀疏编码，ĥ是重构。`sg` 表示前向值不变、反向传播停止。对每个抽样位置定义：

    R(h) = ||ĥ − sg(h)||² / max(||sg(h)||², d×10⁻⁴)
    L = L语言模型 + λ × mean(R)

这与已读草稿按维度取均方后再归一化的口径一致。初始提案固定 λ=0.1；它是需要小试检验的设计值，不是论文或本项目已经验证的最优值。

B1把 `sg(h)` 送进SAE；M1把 h 送进SAE。**两组使用同样的 λ、SAE初始化、更新次数、抽样位置和优化器。** 这样B1与M1的直接区别是辅助目标是否能更新上游主干，而不是有没有训练观察器。

目标端 `sg(h)` 和归一化分母中的停止梯度保留：我们定义的是“通过编码—重构路径给主干增加梯度”。把目标端也开通是另一种优化向量场，必须另立条件，不能笼统地删除所有 `detach` 并宣称只改了梯度开关。

## 5.2 稀疏度不等于一个可以直接反传的计数项

第一轮建议沿用已有30,000个字典位置，每个输入只保留最大的32个非负激活（TopK）；正激活实际数量可能少于32。字典宽度、k和归一化方式在两组完全一致。[项2—项3]

此时“最多32个激活”由前向选择实现，而不是通过把非零个数加到损失中实现。不要把近乎固定、不可按普通方式求导的非零计数当成正在塑造主干的有效梯度。主干收到的是经过这个稀疏编码瓶颈的重构梯度。它可能促进可压缩性，但没有数学保证会自动形成领域分离。

## 5.3 防死机制的明确方案

主试验两组都加入同一防死辅助训练：如果某个槽位在最近10,000,000个“实际送入SAE的有效位置”中从未正激活，记为不活跃；不足这个窗口时，报告“尚未具备完整窗口”，不把所有未用位置提前判死。统计必须汇总所有数据并行进程，不能用语言模型总token数代替SAE采样数。[外1；本节在线口径为提案]

用不活跃槽位中最大的至多512个激活拟合停止梯度的重构残差，归一化为均方残差比例；辅助系数固定1/32，分母至少10⁻⁸。若无不活跃槽位或残差为零，该项记0。主编码器按解码器转置初始化，解码方向每次前向按列归一化。

为不混淆主问题，防死项在第一轮**只更新SAE**，不额外更新主干：输入与残差目标均停止主干梯度。导师要求影响主干的结构目标由5.1的重构项实现；防死项被定义为单独的训练稳定化操作。这是具体设计选择，不把它冒称为会议中已经确定的唯一实现。

暂不使用特征重采样；若运行必须引入重置，需同时改两组、增加代际编号并形成新版本。不能静默重置后继续画同一槽位的完整轨迹。

确认主面板后，再使用M2D2的百科来源检查现象是否局限于学术文本。预先固定四个父类、各两个子类；每类开发100份、确认200份文档。它不参与主方案调参，不与学术领域标签一对一硬对齐。

| 父类 | 两个精确子配置 |
|---|---|
| 文化艺术 | `Culture_and_the_arts__Sports_and_Recreation`；`Culture_and_the_arts__Visual_arts` |
| 健康 | `Health_and_fitness__Human_medicine`；`Health_and_fitness__Nutrition` |
| 自然科学 | `Natural_and_physical_sciences__Biology`；`Natural_and_physical_sciences__Earth_sciences` |
| 应用技术 | `Technology_and_applied_sciences__Computing`；`Technology_and_applied_sciences__Engineering` |

这里报告不拟合分类器的表示关系指标、领域响应分布和损失，不把开发100份偷偷改作模型训练。若要评测该面板的监督读出能力，另建同样明确的训练划分，不能用确认文档拟合分类器。

数据卡当前使用旧式加载脚本接口；先审查下载／加载脚本，再转换为本地固定格式并锁定版本，不盲目执行远程代码。研究使用时保留其公开许可和来源说明。[外5]

## 6.5 从“领域”走向“语义”的最小控制面板

**八领域分得更开，仍可能只是在识别术语、格式或话题来源。** 因此，第一轮主结论只写“领域可读性／选择性”。只有需要升级为“语义结构变好”时，才启用下面的独立控制面板。

新增一个明确标为“自建、待人工审核”的关系面板，不把它伪装成已有公开基准。使用四类可人工核验关系：国家—首都、作者—作品、化学元素—符号、整数—算术关系。每类20条事实，共80条；每条使用8种预先写好的英文表达模板，共640条正确文本。每条再构造1条词汇高度重叠但关系错误的反例，共640条反例。输入语言与现有预训练分词资产一致。

每类20条事实按10／5／5分为训练、开发、确认；模板按4／2／2划分。关系／正确性轻量读出器仅在训练事实×训练模板上拟合，在开发事实×开发模板上选参数；确认只使用确认事实×确认模板。确认中的“同一事实的两种表达”用于相似度比较，“更换关系对象的反例”控制词汇相似。全部事实、反例和模板必须人工审核并记录来源；未经审核不能进入确认面板。

四类任务分别报告，不把事实记忆、算术正确性和领域分类混成一个准确率。小模型未读出某种关系，只能说明本模型和当前读法下没有证据，不能直接宣称模型完全没有语义。

## 6.6 实际下游能力：与领域探针严格分开

统一使用语言模型评测框架（lm-evaluation-harness），固定安装提交、任务配置、提示模板和数据版本。所有任务采用零样本设置，即不给示范题；使用候选答案条件似然，不使用自由生成和人工裁判。每个任务使用对应有标签的完整评测划分。[外6]

|---|---|---|---|
| 情境续写常识 | `hellaswag` | validation | 长度归一化准确率，同时留存普通准确率 |
| 物理常识 | `piqa` | validation | 长度归一化准确率，同时留存普通准确率 |
| 基础科学问答 | `arc_easy` | test | 长度归一化准确率，同时留存普通准确率 |
| 较难科学问答 | `arc_challenge` | test | 长度归一化准确率，同时留存普通准确率 |
| 阅读判断 | `boolq` | validation | 准确率 |
| 指代消解 | `winogrande` | validation | 准确率 |

这些是本轮协议选择；正式使用前必须从锁定版本的任务配置导出数据集标识、可用标签、样本数与指标字段。若新版本任务名或目录变化，应显式映射并记录；不能静默换数据或照抄另一版本分数。目前已直接核验HellaSwag配置的划分与指标，其余任务需在执行环境完成同一项配置验收。[外6]

主干是项目自定义模型，不能假设模型权重可以直接交给标准Hugging Face接口。评测前要实现对应的似然计算适配器，用同一批短句对比训练器与评测器的分词、移位、候选续写位置和逐token对数概率；误差门槛先以float32实现对照确定。旁路方法评测时只运行主干，不调用SAE；串联方法则必须保留串联SAE，两种部署路径分别报告。

下游正式结果只在设计冻结的最终检查点计算；开发小试只做接口检查，不用这些公开评测分数反复选λ和特征。模型规模较小时，难题接近随机水平并不罕见，因此下游不是第一轮结构假设的唯一裁判，但所有负向结果必须保留。

# 7．完整评测流程：每一步得到什么认识

## 7.1 先验证干预真的存在，再看图

对固定批次分别求语言模型损失和辅助重构损失的梯度。B1的辅助梯度对上游主干应为0；M1应在连接到h的上游参数中可测到非零分量。记录每层梯度范数，以及辅助梯度与语言模型梯度的夹角余弦；这只解释更新方向关系，不等于已经证明语义机制。

B0与B1使用相同初始主干、输入、随机数和独立裁剪时，比较一次及多次更新的主干梯度和参数增量。CPU确定性测试比较完整张量；GPU可设数值容差，但必须记录比较范围，不能把抽样参数一致写成全模型逐位一致。

恢复检查必须验证下一批输入、SAE抽样位置、优化器状态和下一步损失，而不仅仅是“权重能加载”。这一步不通过，后续曲线不进入科学解释。

## 7.2 主指标：原始表征是否更容易读出领域

对固定的M2D2文档和固定位置导出原始h，不先用SAE替代。主分析对象是同一文档256个位置的平均表示；辅助对象是最后一个有效位置的表示。两者分别报告：窗口平均适合看整篇领域，不能据此宣称当前token的路由已经可用。

使用多类别线性逻辑回归，在600份／类训练文档上拟合，200份／类开发文档上从正则化参数C∈{0.01,0.1,1,10}选择；平分时取较小C。训练集拟合中心化与标准化统计，不能使用确认集。最大迭代数5000，容差10⁻⁶；未收敛就标记失败，不用未收敛分数下结论。

主指标是八类宏平均F1，粗四类结果辅助报告。分别比较原始表示与单位范数表示，以识别是否仅靠范数变化；所有主对比在同一表示口径内进行。额外记录全空间方差、表示范数分布与平均成对余弦，防止把表示塌缩误认为压缩或解耦。

第二来源面板的关系指标固定为：对文档平均表示做单位范数化，计算同一细领域文档对的平均余弦，减去同父类、不同细领域文档对的平均余弦；每个领域等权。粗粒度指标则比较同父类与不同父类文档对。这些量无需特征匹配或分类器训练，但仍只是领域组织指标。

词袋竞争基线：用相同文本、划分训练词频—逆文档频率（TF-IDF）线性分类器；特征仅由训练集拟合，词元1—2元组、最多50,000维、最小文档频率2，C选择与上面相同。这不是SAE方法的架构基线，而是用来判断领域任务是否主要靠词汇捷径。

## 7.3 SAE行为：避免只挑一张漂亮热图

对每个领域d、特征j，分别统计激活概率 p(d,j)=P(zⱼ>0｜d)，平均激活值，以及正激活条件下的平均幅度。三个量不能混用，因为“更常激活”和“偶尔激活得更强”是不同现象。每篇文档权重相同，不能让长文或大类压倒其他类。

使用平衡领域先验，定义 q(d｜j)=p(d,j)/Σₐp(a,j)，以及领域选择性 Sⱼ=1−H(q)/log(8)。它衡量领域偏好，不叫语义纯度。对所有有效特征报告分布、中位数和覆盖率；至少在确认集20篇不同文档上激活才进入稳定选择性汇总，其他列为低支持，不把单次激活的高分当成高质量特征。

同时报告每输入非零数、完整窗口不活跃率、覆盖不同文档的比例、重复／高度相关特征比例。重构指标使用均值预测基线归一化：总重构平方误差除以相对于训练／开发拟合均值的总平方误差。这个“评价归一化误差”与训练时逐token能量归一化不是同一指标，必须分开命名。

热图选择规则：在最终开发检查点上，每个领域选8个满足支持阈值的高选择性槽位，去重后最多64个；不足则减少并记录。同时固定随机抽128个槽位作选择偏差对照。选择只用开发集，回看历史时固定同一组编号和同一顺序。注明这是“按晚期开发响应选出的回溯面板”，不能拿它证明随机特征或整个字典都单调变好。

导师的前1%建议作为敏感性：在开发集按全局激活频率选出300个位置，冻结该名单，分别报告全部30,000个位置与去掉该名单的结果。不能每个时刻重选删除名单后仍声称使用同一把尺子。对公共特征做内容检查，不预设其一定无语义。

## 7.4 区分“主干变化”和“SAE读法变化”

先使用第7.2节原始表示探针作为不依赖SAE编号的主证据。再选更新4096与19200两个时刻，把两个连续SAE读到两份表示上，形成四种读法：E早(h早)、E早(h晚)、E晚(h早)、E晚(h晚)。同一批文本、同一位置、同一统计方式，不能同时改特征分组规则。

每个交叉读法先报告归一化重构误差。若交叉读法的误差比对应时刻的原配读法高20%以上，预注册为“读出分布失配警告”；该阈值是诊断规则，不是理论界限。失配时仍展示数值，但不能用某个固定SAE读不出早期信息证明早期信息不存在。

若M1仅在线SAE指标变好，而原始表示无变化，优先做独立读出器复核：在冻结的B1、M1最终主干上，用相同数据池、相同宽度和k，分别从头拟合新的SAE；各用种子911、927。数据池2²²个固定位置，训练4遍，批量8192，即2048次更新、共16,777,216次位置暴露；验证使用6.2中独立的读出器验证池。它只作为必要分支，不预先给所有检查点重训SAE。

独立SAE比较总体指标，不比较同编号。这个检查回答“新表征是否更容易被同样资源的读出器解释”，不是证明语义特征拥有唯一身份。

## 7.5 何时才需要进一步语义对应

只有当结论需要写成“同一个概念在训练中变得更明确”时，才增加匹配。优先用固定文本上的响应向量比较，匹配名单只在开发集建立，再在确认集验证跨表达一致性；允许不匹配、一个特征分成多个特征、多个特征合并，不能强制一一配对。

解码方向余弦、最高激活文本重合率、领域分布相似度可以辅助，但任何单一指标都不能独自定义语义身份。当前核心干预实验不以解决这件事为前提。

## 7.6 语言建模与下游效果

所有损失先按有效预测目标数汇总，再计算平均负对数似然；困惑度是该均值的指数。不能先算每批困惑度再平均。DCLM确认面板和M2D2各领域分别报告，后者另外给领域等权平均。

旁路方法以原始主干输出评测。另做诊断时，才把h替换成ĥ测任务损失变化；这个替换损失衡量SAE保真度，不是新模型超过原模型的收益。串联模型由于原前向就含SAE，应单列其完整模型表现和部署成本。

六个下游任务分别报告准确率差、各种子分数和等权平均差，不以一个总平均遮蔽特定任务退化。验证相似任务或多个领域的收益，不能自动推出路由收益或专家专门化，后者需要新的干预实验。

# 8．判定分支、交付物与行动清单

## 8.1 预先写下什么算支持、反对或证据不足

以下阈值是为了让这轮决策可执行而提出的工程／科学门槛，不声称适用于所有模型。应在读取确认结果前固定。

正式实验以三个训练种子的“方法减基线”配对差为统计单位；主指标只设一个：M2D2学术面板的原始窗口表示八类宏平均F1。每个种子另外以文档为单位做2000次分层配对重抽样，展示面板抽样敏感性；不能把文档或token数量当成独立训练重复。

跨种子报告全部三组差值、均值和使用t分布自由度2计算的配对均值95%区间。三个种子仍然很少，区间不稳定；不得把文档级极小的显著性当作跨训练稳定性已经成立。

| 分支 | 预注册判据 | 能说什么／下一步 |
|---|---|---|
| 支持主干可读性改善 | 三种子F1差同号为正、均值至少+2个百分点、配对均值95%区间下界大于0 | 支持该设置下的领域可读性改善；仍需语言质量不劣与竞争解释检查 |
| 语言质量不劣 | DCLM确认NLL差的配对均值95%区间上界小于0.02 nat／token | 在预定容忍度内未见明显语言建模损害；不是证明完全零退化 |
| 只有SAE指标改善 | 原始表示主指标不支持改善，SAE重构／选择性改善 | 暂归为读出侧效果，执行独立读出器分支，不宣称主干语义变好 |
| 结构改善但语言损失明显恶化 | F1改善，但NLL差区间下界超过0.02 | 当前权衡不满足目标；检查梯度与缩放，再决定新版本较小λ |
| 差异落在阈值以内 | F1差95%区间完全落在−2至+2个百分点内 | 当前预算与指标下，排除了预设量级的显著可读性收益；不泛化为所有正则无效 |
| 其余不确定情形 | 区间跨越阈值、种子分歧、支持不足或审计未通过 | 证据不足；解释限制，不改口称“没有区别”或“已经成功” |

“方法在下游有收益”另行判定：六任务等权准确率平均差至少+1个百分点、三种子同号、配对区间下界大于0；同时完整披露每任务差。达不到就不写下游提升。它不替代上面的主干结构结论，也不是所有结构实验继续推进的必要条件。

所有图同时给效应量和可见不确定性；二维投影、精选特征图及参数夹角都只是辅助证据。探索后新增的分析清楚标注，不回写成原先就确定的主检验。

## 8.2 逐步执行与每步认识更新

**步骤一：审计原实验。** 读取实际配置、运行源码、SAE初始化／恢复记录和导出器。输出：模型层数与维度、准确取点、前向路径、每项损失的梯度路径、检查点继承图。认识更新：之前的图究竟是连续槽位轨迹、独立读出器快照，还是证据不足。

**步骤二：冻结数据与梯度合同。** 生成训练和评测清单，完成B0／B1一致性、B1／M1辅助梯度差异、分布式计数与恢复测试。认识更新：我们是否真的实现了想研究的干预，而不是同时改变多个未知因素。

**步骤三：单种子开发小试。** 执行B1和M1至4096更新，只读开发面板，检查活跃率、表示范数、原始表示可读性和语言损失。认识更新：目标能否稳定运行，测量是否有分辨率；这不是正式的多种子结论。

**步骤四：固定方案后做三种子确认。** 按19,200更新预算完成配对，打开确认面板。先读原始表示结果，再读SAE诊断，最后读下游和计算成本。认识更新：在这个模型、数据与预算中，额外梯度究竟改变了什么，改善与代价是否同时存在。

**步骤五：按分支补一个最有价值的实验。** 只有读出改善则做独立SAE；结构改善但机制未分离则做非稀疏自编码器对照；词汇捷径解释很强则做跨表达控制；旁路无效但串联有明确动机才进入B2／M2。不要同时开启全部分支。
