## 2. 当前模型实际改变了什么

本次术语：稀疏自编码器（SAE）把输入向量表示成少量字典方向的加权组合；稀疏特征（feature）指其中一个字典坐标，不能未经验证称为语义原子。SAE-mediated 指 SAE 重构实际进入模型前向计算的训练臂；普通基线（baseline）指同规模主干直接使用原生表示的训练臂。B 表示十亿个累计有效预测词元，不是模型参数量。

最后一块的实际计算是：

$$r=x+\operatorname{Attn}(\operatorname{norm1}(x)),\quad h=\operatorname{norm2}(r),$$
$$z=E(h),\quad \hat h=b+Dz,\quad x_{out}=r+\operatorname{MLP}(\hat h).$$

普通基线对应 $x_{out}=r+\operatorname{MLP}(h)$。本轮的 $h$ 是**最后块 norm2 之后、MLP 之前**的输入；不是最终输出 RMSNorm 后的 `final_h`。保留 $r$ 的残差旁路意味着信息可以绕过 SAE 到达后续输出，不能说所有模型信息或所有语义都被压进了 32 个 feature。

| 训练因素 | 普通基线 | SAE-mediated |
|---|---|---|
| 主干 | 8 层、d=1024、281,431,040 参数 | 同一主干配置；初始 90 个非 SAE 张量逐一相同有既有资格记录 |
| 新参数 | 0 | SAE 61,471,024；总量 342,902,064，约多 21.84% |
| SAE | 无 | 宽度 30,000；ReLU 后取最大 32 项；解码列前向单位归一化 |
| 主任务梯度 | 下一词元损失更新主干 | 下一词元损失穿过 SAE，更新主干与 SAE |
| SAE 重构梯度 | 不适用 | 另一次对抽样输入及目标 detach 的重构损失，只更新 SAE；抽样率 1/8 |
| 外部语义标签监督 | 无 | 无；类别/命题标签只用于本次分析，不送回预训练 |

参数算式为 $2\times1024\times30000+30000+1024=61,471,024$。宽度约为输入维度的 29.3 倍。这里增加的是前向稀疏重构结构、额外参数/计算、额外重构目标，以及二者和主任务的联合适应；目前没有额外语义分类监督。30,000 不是 30,000 个已经证实的独立语义。

已核对两臂主干 AdamW、学习率 3e-4、betas=(0.9,0.95)、矩阵权重衰减 0.1、独立主干梯度裁剪和全局批量 262,144。4 卡累积 16 次与 8 卡累积 8 次吸收了卡数变化。实际主干学习率是 **1,000 更新线性 warmup 后恒定**，不是默认余弦衰减；不同终止预算没有自动造成 10B 内的不同衰减曲线。SAE 自有 betas=(0.9,0.999)、10 更新 warmup、零权重衰减。边界更新按 mask 截断到精确词元里程碑，不能用更新数乘 262,144 代替累计数。

两臂硬件/数值栈不同（H100 旧资格路径与 RTX5090 的 PyTorch 2.8/CUDA12.8 路径），额外参数和计算也不同。因此先报告**这两个配置在匹配数据与优化条件下的整体方法差异**；不称为等参数/等 FLOPs 对照，也不把差异唯一归因为“稀疏性”。本轮不主动补新的预训练消融臂。

## 3. 把直觉写成可支持、可推翻的假设

### 3.1 建议研究者确认的主假设

> 对独立标注且固定的一组命题、忠实改写与语义不同的匹配反例，在同一读取位置和固定分析规则下，随着当前语言模型预训练，同命题异表达的 SAE 稀疏组合重合度上升，而且这种重合相对于反例的优势增大。该优势不能主要由词面、模板、长度或全局常用 feature 的集中化解释。在可比的 SAE 读取质量下，检查这一趋势是否也出现在原始表示及普通基线中。

这是“语义相关的稀疏组合复用”假设，不预先保证抽象语义已经形成。不同命题可以共享大量真实语义成分，所以不要求所有异语义样本完全分离。

拆成四个可以分别失败的判断：

1. **跨表达复用**：同一时间点，同命题对比匹配反例更相似；随训练，同命题重合本身提高。
2. **选择性分化**：同命题相对于反例的优势扩大。更强版本才要求反例重合绝对下降，必须单列结果。
3. **表示与读法区分**：优势不仅存在于共同训练的 SAE 坐标；原始 $h$ 或同规则重新拟合的读法也提供相容证据。
4. **两臂差异**：在共同词元点，SAE-mediated 与普通基线的上述指标不同。差异方向目前为 Unknown，不能预定 SAE 更优。

**不要合并三种“稳定”：**同 checkpoint 换表达后的不变性；固定样本关系随训练的稳定性；同一个 feature 编号跨训练时期仍表达同一概念。对确定性模型重复输入同一句并不能测到第一种不稳定。第三种还涉及字典旋转、拆分/合并和 feature 身份，不是第一轮必须证明的条件。

### 3.2 时间窗口与反驳规则

建议正式确认主窗口固定为 **0.5B→10B**，延续原时间范围但使用新的确认数据与组合主指标。现在可先完成共同 **0/0.5/1/3B** 的早期结果；0.5→3B 标为预设阶段读数，不能因为旧结果在 3B 达峰，就把它换成最终主要终点。5/10B 只在两边完整保存后进入配对结果；15B 仅属于第一轨扩展，不参加当前 baseline 对照。

0B 必须补读以检验初始结构，但线上随机 SAE 的读取质量与训练后不同，0B 主要作为初始化参照。即使 0.5B 已有关系，也不能断言关系在 0.5B 才产生；现存永久快照不足以定位 0–0.5B 内具体出现时刻。不可从一张粗疏时间图推出瞬时形成速度。

在开发集上先评估噪声与所需精度，再由研究者确认最小关注差异 $\delta_+$、$\delta_G$、两臂差异 $\delta_D$ 及允许的重构质量差。没有普适的 0.02/95% 阈值。尚未确认时只给估计与区间，不强行签发支持结论。主终点同时要求：同义重合提高、选择性优势提高、末端优势为正，并通过测量有效性检查。若只满足其中一项，报告部分支持；若精度足够却与预期相反，报告不支持；区间太宽、标签/读取资格失败则为证据不足。中间下降点全部保留，不强求单调，也不把端点差叫作形成速度。

## 4. 指标从易到难：具体量、理由与不能证明的事

### 第一级：直接看“用的是不是相似的配方”

固定锚句 $a$、同命题改写 $p$、匹配反例 $n$。每句真正激活的集合为 $A_t(x)=\{j:z_{t,j}(x)>0\}$，排除 Top-K 中值为零的占位项。

**集合重合度**：
$$J_t(x,y)=\frac{|A_t(x)\cap A_t(y)|}{|A_t(x)\cup A_t(y)|}.$$

例如 $A(a)=\{1,2,3\}$、$A(p)=\{1,2,4\}$、$A(n)=\{1,5,6\}$，两个重合度是 0.5 和 0.2，选择性优势是 0.3。它直观地回答“用了多少相同坐标”，但不区分一项激活 0.001 还是 10。

**幅度加权重合度，建议作为组合主相似度**：令 $c_j=z_j\|D_j\|$，再按每句总幅度归一化 $u_j=c_j/\sum_lc_l$，
$$W_t(x,y)=\frac{\sum_j\min(u_{t,j}(x),u_{t,j}(y))}{\sum_j\max(u_{t,j}(x),u_{t,j}(y))}.$$

现有有效解码列范数为 1，因此 $c\approx z$；不得使用未归一化的原始参数列范数来重新加权。本量表示激活配方相似度，不是可加的独立语义信息量，非正交字典仍有表示不唯一性。

同时输出三条核心曲线：
$$S_t^+=\mathbb E[W_t(a,p)],\quad S_t^-=\mathbb E[W_t(a,n)],\quad G_t=S_t^+-S_t^-.$$

每个命题/独立源组等权；组内多种表达先平均。报告 $\Delta S^+$、$\Delta S^-$、$\Delta G$，因为 $\Delta G>0$ 可能只来自反例变远，并不意味着同义复用增强。二值 $J$ 用同一方式报告为敏感性结果。三元组正确率 $P(W(a,p)>W(a,n))+0.5P(=)$ 帮助直观阅读，不能替代效应幅度。

全零 code 是读取失败，不是“两个零向量语义相同”；主结果在共同可读样本上配对并报告覆盖率、各臂各时刻失败数。不得悄悄丢弃难样本；覆盖率不同需给缺失敏感性或降低结论资格。

防止全局常用坐标制造复用：若所有句都使用同一组 feature，$S^+$ 与 $S^-$ 会同时很高而 $G\approx0$。在长度、词面重合、来源等预设分层内打乱语义配对，保持原始 code 和样本频率，得到标签置换参照。不要只用均匀随机选择 32/30,000 的理论期望，因为真实 firing 频率不均匀。最常用 feature 的移除仅作开发集固定的敏感性诊断，不能事后删除不符合预期的坐标。

### 第二级：对照原始表示，确认变化发生在哪一层对象上

对 $v\in\{h,\hat h\}$ 计算原空间余弦关系优势：
$$M_t^v=\mathbb E[\cos(v_t(a),v_t(p))-\cos(v_t(a),v_t(n))].$$

仍分别输出正例和反例相似度、原始向量能量，不仅输出差值。稀疏系数余弦作为与 analysis1 的桥接指标；不要拿它替代一级直接组合重合度。每个时刻不独立做列标准化后称为同一种几何距离。

同时看 $M^h$、$G^{z}$、$M^{\hat h}$：它们分别回答“输入关系是否改变”“这把 SAE 如何组织它”“重构后关系是否保留”。$h$ 也由 SAE-mediated 联合训练影响，不能把它称为无 SAE 的自然预训练。$M^{\hat h}-M^h$ 是指定关系的几何保留差，不等于信息总量差。

### 第三级：少量 feature 能否在新表达上读取外部标签

保留粗类/子类和选定内容属性作为分开的辅助任务。训练集只用于选坐标及拟合线性读法，开发集选正则强度，确认集只评估。输出宏平均准确率/每类平衡准确率及配对区间，避免类别不平衡制造变化。

做每个二元概念使用 $K\in\{1,4,16,64\}$ 个坐标的容量曲线，主容量建议 K=16；同规则比较 $h$ 坐标、离线 SAE 坐标与随机选坐标。特征选择必须嵌入训练划分；全 30k 输入分类器不是这个稀疏容量测试。30k 与 1024 的搜索空间不同，即使 K 相同仍有选择机会差异，需随机标签/随机坐标和正则路径参照；不要声称已经严格匹配所有探针容量。

冻结在 $h$ 上拟合的读法后应用到 $\hat h$，与在 $\hat h$ 重新拟合的读法同时报告。冻结读法下降、适配后恢复，支持“坐标读法变了”；不能直接断言语义消失。新拟合的标签探针是分析监督，不能被描述为预训练新增了语义监督。该层用于补充解释，不让更复杂的分类器掩盖一级指标失败。

### 第四级：在不把 feature 编号当语义身份的前提下看时间稳定性

优先保存固定样本顺序的关系矩阵 $K_t(i,j)=W_t(i,j)$ 以及 $h$ 余弦矩阵，按外部命题/类别排序，跨时间固定色标。每个 checkpoint 内共同重命名 feature 不会改变这个矩阵，因此能观察关系组织的演变，不依赖跨时刻编号相等。

可补充相邻时刻固定语义组内的关系变化 $V_{s,t}=\operatorname{mean}_{(i,j)}|K_t(i,j)-K_s(i,j)|$ 和语义近邻保留率。必须注明实际词元间隔；不同间隔的数值不能直接当作“晚期更稳定”。当前稀疏永久快照只支持粗粒度漂移描述。矩阵不变也可能是一直没有语义关系，必须与 $G_t$ 联读。

若研究者坚持“相同的一组 feature 跨时间保留”，再做单独扩展：在独立无标签校准样本上建立每个 feature 的响应指纹，允许未匹配、拆分和合并，冻结匹配后在确认语义上检验选择性是否保留；输出可匹配比例和未匹配质量。字典向量余弦、同编号响应或强制一一配对都不够。固定 reader 只在输入适配良好时能作辅助尺子；现有严重跨期重构失配不满足这个前提。

### 并行必做：SAE 自身质量轴

以下量与语义指标并列，不能混成一个总分：

| 质量维度 | 计算与保存 | 审查问题 |
|---|---|---|
| 重构误差 | 每样本 $\|h-\hat h\|^2/\max(\|h\|^2,d\cdot10^{-4})$ 后平均；另报 raw MSE、$\|h\|^2/d$、重构余弦；可补中心化解释方差，分母为零时不适用 | 归一化误差下降是否仅伴随输入能量增长？不要混用全局比值与平均比值 |
| 实际稀疏度 | 正激活 L0 的均值、分位数；正激活总幅度；全零比例 | 32 是机制约束，不是已经获得语义稀疏性的证据 |
| 字典使用 | 固定 N 个 token 的 firing 频率、覆盖、零激活数、频率熵及其指数 | 是否集中在少数常用坐标？不同 N 的 coverage 不可直接比较 |
| 目标关系保留 | $M^{\hat h}-M^h$，冻结及适配读出差 | SAE 是否丢掉本次关心的区分，而不只是总体 MSE 好看？ |
| 拟合不确定性 | 同预算离线 SAE 的 seed 分歧、训练/验证误差和收敛记录 | 曲线是否主要反映 SAE 没训好或读法不唯一？ |

健康统计使用两臂相同位置的固定无标签 token 面板；句末语义面板另算同一套质量量。两者不是同一分布，不把 864 句的 coverage 与 115M token 的 coverage 放在同一尺度上。新一轮小规模质量/LM-loss面板建议固定131,072个有效预测位置及其上下文，先冻结清单；它与离线SAE拟合、拟合验证储备和语义确认样本不重合。原115M-token审计直接引用，不因换指标而默认全量重跑。这个小面板上的零激活特征只能称“该窗口未出现”，不能称全语料死亡。

## 5. 数据怎样选才公平

**公平首先是两臂面对同一份独立标签和固定测试，不是选一个 SAE 表现更好的数据集。** 不要求“Qwen 必须通过”或“TF-IDF 必须输给模型”才准入；这样的筛选会把模型表现写进试题。准入首先由标注、独立性和可审计构造决定，外部模型与词面基线用于检查测量响应和竞争解释。

### 5.1 旧层级数据：保留，但不要误作命题等价数据

本次核对的具体版本为：

`/data/250010109/MoE_Router/experiments/20260819_a15_08_06_e03_aligned_hierarchical_taxonomy_replication/data_v3/`

其 metadata 哈希与 manifest 相符；8 父类×8 子类、1920 行、train/validation/test 各 640；三份划分的 `template_family_id` 集合不交。样本有 `fact_indices`、`fact_subset_id`、`class_name`、模板家族和文字，具备复用基础。这里核实的是结构/身份，不是重新完成人工语义审核，也不代表所有历史层级版本都如此。

它的优势是类别平衡、领域层级明确、模板家族和事实子集有记录。局限是同一类的两句可能分别包含三条不同描述，测试又有两条/四条事实组合，**同子类并非同一命题**；旧提示还含分类指令和 `Classification:`。它可以测粗/细可读性、给定事实子集的内容检出、未见子类的父类泛化。要测忠实改写，须对完全相同内容集合补等价表达，不能把 class_id 直接复制成 fact_id。`formal_test_gate` 的旧封存文字是历史状态，不意味着今天仍未见过；本轮复用视为历史辅助数据。

### 5.3 独立标签如何表达“变化过程的监督”

监督是固定裁判，不是让训练去迎合预期曲线。每个样本记录命题身份 F、父类 C、子类 L、必要时的内容属性向量 A；另记录词面/模板/长度/来源等干扰变量 U。每对样本记录是否等价，以及角色交换、否定、数量/实体变化等反例类型。这里只把关键关系变更作为等价标签反例，不扩展为模型推理训练。

两类关系分开：$Y^{eq}_{ij}=1$ 表示忠实等价；$Y^{class}_{ij}$ 表示同子类、同父类或不同父类。每个时刻使用**同一张**标签矩阵、同一组样本和配对，在其上叠加 $W_t$ 或余弦矩阵。图中改变的是实测关系，不是标签或排序。监督表达可直接画为四格：同义/异义 × 高/低词面重合；主结果在各格及固定权重平均上同时报告。

新面板由人审核等价性、事实正确性和自然度；分析 AI 可以提出候选，但不得自己生成后自己签署“人工已确认”。对 PAWS 使用已有人工标注，先盲审一份固定抽样检查适用性。所有剔除和重标在查看目标模型结果前完成。若标注有争议，保存争议和排除理由。

开发与确认按命题家庭/源句连通分量划分；同一原句的派生表达不跨划分。PAWS 不凭 pair_id 就认定独立，源映射缺失时使用标准化句子的连通分量，并声明不能排除更远的共同来源。词面相似度用固定词/字符规则，匹配和分箱阈值只在开发集确定；不按 SAE 得分挑低词面样本。公开语料的预训练污染无法仅靠本轮短检查完全排除，需登记检索范围，不能声称全面去污染。

## 6. 两轨如何执行，以及 baseline 是否需要 SAE

### 第一轨：当前 SAE-mediated 模型的时间演化

固定样本和读取位置，沿 0/0.5/1/3/5/10B 缓存 $h_t,z_t,\hat h_t$，先输出 $S^+,S^-,G$ 与 $M^h,M^{\hat h}$，并与 SAE 质量和固定词面参照并排。15B 是只属于这一臂的后续描述。

验证逻辑依次是：标签是否真表达目标关系 → 同词不同义反例能否被区分 → 同义组合本身是否更一致 → 选择性是否上升 → 这种上升是否也能在原始表示或统一读法下观察 → 尚有哪些解释未排除。普通分类准确率提高只解决其中一个弱问题。

线上 SAE 是模型的一部分，所以它随主干共同变化本身是研究对象。可以描述“联合系统的 code 越来越体现指定关系”；仅凭这一轨不把变化全部归给主干，也不把重构越来越好当成语义越来越好。

### 第二轨 A：先比较主干，不需要先训练 baseline SAE

在共同词元点对同一批文本提取两臂 $h$，计算完全相同的 $M^h$、类别/属性读出、固定 held-out 下一词元平均损失。冻结提取模型，不更新任何权重。

令 $Q$ 是预先固定的一项指标，输出每个共同词元点的水平差：
$$D_Q(t)=Q_{mediated}(t)-Q_{baseline}(t),$$
以及相对起点的增长差：
$$I_Q(t;t_0)=[Q_m(t)-Q_m(t_0)]-[Q_b(t)-Q_b(t_0)].$$

这是配对的变化量对比，**不是自动成立的因果双重差分识别，也不等于形成速度**。时间曲线可以非单调；若要说更早达到某个能力，需先在开发阶段固定能力阈值，再仅在现有观测点给达到阈值的区间，未达到时记右删失，不插值得出精确形成时刻。

0B 的两臂 $h$ 理论上应一致，因为首次 SAE 位于这个提取点之后；可作为加载、层位和输入一致性的强检查。两臂最终输出和初始语言损失可以不同，因为 SAE 已改变最后 MLP 前向，不能把这两件事混淆。

### 第二轨 B：若要比较稀疏组织，就需要给 baseline 训练离线 SAE

**建议训练，但两边都重新训练一套同规则的离线 SAE。** 只给 baseline 训练离线 SAE，再与 mediated 的线上 SAE 比较，会同时混入读法训练年龄、目标函数和分布适应的差别。

三个结果栏分开：mediated 线上 code（真实训练系统）、mediated 冻结 $h$ 上的离线 code、baseline 冻结 $h$ 上的离线 code。两臂离线结果用于统一读法的主比较；线上与离线差异用于说明任务共同训练的读法有什么特殊性。

建议先以 **0.5B 与 3B 两端×两臂=4 个离线 SAE** 做预算资格阶段；这是当前可用早期窗口，不替代最终 0.5→10B 主窗口。先用一个固定 SAE seed 检查拟合和接口；最终主要两臂稀疏差异至少用第二个 SAE seed 复核。两个 reader seed 只估计读法不确定性，仍不是两个 LM 训练 seed。

离线拟合候选合同：

- LM 完全冻结、eval，激活输入 detach；只更新离线 SAE；不把重构送回 LM 前向。
- 复用现有 TopKSAE：d=1024，M=30,000，k=32，非负激活、前向单位解码列；同一标准化重构目标，不新增 AuxK、L1、router 或其他模块。
- 从独立无标签 DCLM 分析储备抽取相同文本、相同 token 索引；固定上下文、顺序、位置分布。拟合 token 面板与语义确认样本分开；fit/dev/quality 分开，已有常用验证集使用历史应登记。
- 建议先冻结 **1,048,576 个拟合激活位置 + 131,072 个验证位置** 为工程试拟合；每个输入1024维、一个位置算一个 SAE 样本。四格合计 4,194,304 次位置曝光/每 seed，并非语言模型预训练词元预算。相同位置储备可分片，fp32 缓存每格拟合输入约 4 GiB。
- 同一 seed 对两臂初始化相同、同一输入位置次序、同一有效位置/更新、AdamW 3e-4、betas=(0.9,0.999)、零衰减、同 warmup 和裁剪；全局 batch 候选4096激活位置，工程试拟合256更新。精确设置经试拟合预算批准前不启动。
- 离线SAE日志以累计激活位置及SAE更新为坐标，记录原始/加权重构损失、总损失、学习率、有效位置/更新与恢复连续性；LM未训练，LM训练损失标 `NOT_APPLICABLE` 并注明原因，不能伪造为0。验证质量与语义分数分别保存，后者不参与拟合选步。
- 这个小预算仅检验接口和拟合曲线，不保证 30k 字典充分拟合。批准试拟合后，用共同的无标签验证质量规则决定是否把所有比较格统一扩到更大预算；不为表现差的一臂单独延长，也不按语义确认分数早停。若预算不足，稀疏方法差异保留“读法未充分校准”。
- 固定预算比较与近似匹配重构误差的敏感性比较分开报告。不能为了匹配误差悄悄改变 k/M 并继续称为同一读法；无法匹配时报告质量—语义二维结果。

最终 10B 点就绪后，补两臂同合同的 10B 离线 SAE（及预定第二 seed），而不是重新训练整套语言模型。统一读法仍不能完全分离表示的几何和读法归纳偏置，但比线上/离线混比有更明确的解释。

### 7.2 主缓存

每个 arm×checkpoint×reader×panel 写一个 manifest 和分片 npz；避免 object dtype，允许用 parquet 单独存字符串元数据。

| 字段 | 形状/类型 | 用途 |
|---|---|---|
| sample_ids、token offsets、token_ids、attention mask | 固定顺序；整数；可用扁平数组+offsets | 确定两臂同样本文本、分词和位置 |

| h_hat_online | [N,1024] fp32，仅 mediated | 实际送入最后 MLP 的重构 |
| z_indices / z_values | [N,32] int32/fp32 | 真实正激活组合；按值筛除零；不存 N×30k 稠密 z |

| h_hat_offline、离线 z | 同上，离线拟合后另存 | 两臂统一读法比较 |

## 8. 统计与公平性验收

1. **样本资格**：语义标签独立于模型；确认集未被本轮选参数；命题家庭、原始句、派生模板及近重复不跨划分；两臂严格同样本顺序、文本、位置和统计权重。
2. **训练资格**：核对初始主干逐张量等价的既有收据；实际 requires_grad/优化器分组/参数变化；数据 manifest、每次全局有效 batch 的输入位置和 mask、LR/裁剪/归一化规则。baseline 已有4→8卡等价测试是工程证据，执行者仍需核对正式配置和公共里程碑边界；各 rank 的局部 digest 不可直接跨卡数比较。
3. **词元坐标**：独立累加权威 metrics 的 lm_tokens 并与 checkpoint tokens_seen 对齐；SAE 续训回滚段位于 recovery_history，不要重复计入被丢弃的 64,001–64,345 旧记录。不得合并物理 replay 为逻辑训练量。
4. **训练曲线资格**：按项目 observability contract 审计 TensorBoard。SAE 运行缺少对应事件与 total-loss 记录时，不直接称曲线合规；只读核验 JSONL 后如能明确重建，另存 `DERIVED_POST_HOC` 曲线与计算证明，不冒称原生事件，也不修改运行环境。若合同不满足，跨运行训练曲线仍标不具备正式比较资格。相同文本重新算的 checkpoint held-out loss 和表示比较分别审核，不因历史事件缺失全盘作废。两臂日志里的 total loss 目标不同，主要比较 LM loss，不能比较两个 total loss 数字来判断好坏。
5. **有效验证数据**：两臂 validation_batches=4/2 反映卡数差异，是否对应相同全局验证样本须核对索引；重新评估时显式冻结样本/目标 mask，以有效预测数全局归一化。
6. **区间**：先按命题家庭/源句组聚合，再配对 bootstrap，建议2000次固定seed；同一重抽样索引用于所有时间和两臂。PAWS 若共享源句，按连通源组抽样而不是把800对当800个独立观测。旧分析48个事实块的区间只覆盖给定参考库下的查询事实不确定性，不覆盖训练seed和领域总体。
7. **多重读取**：一个组合主指标W，J/余弦/分类和位置变化为明确标记的辅助；不在结果后换主指标。两主变化联合满足再称支持，不靠多个显著辅助指标“投票”。外部数据为复核，冲突时报告分布差异，不事后择一。
8. **初始化/读取单元检查**：同臂批大小改变不改变 eval 结果；0B两臂h一致；npz 重构等于有效字典解码；feature整体置换不改变 J/W；同码全部出现时 G=0；零码不产生伪等价；变更命题/角色的反例标签不丢失。这些是计划中的最小验证，不是本轮已运行的测试。
9. **有限泛化**：一个LM seed只支持这两条轨迹。样本bootstrap或增加SAE seed不能变成多预训练seed证据。公平比较可报告整体方法差，不足以因果识别额外参数、稀疏门和重构目标各自的贡献。

## 11. 给分析 AI 的执行顺序、文件职责与预算

执行须由研究者另行发出明确指令；本计划不继承 analysis1 已用完的 GPU 分析授权。可先实施只读审计和独立本地代码/小检查，再提交可审阅的精确分析配置。离线 SAE 是新增训练，必须把它和 checkpoint-only 推理分别列预算，不藏在分析命令里。

| 阶段 | 具体交付 | 出口/停止条件 |
|---|---|---|
| P0 来源与测量学习 | 读本计划、旧报告§3–7、实际tap/SAE代码；研究者用一组正反例解释W、G、h/h_hat。分析AI写输入资格表 | 完成位置/梯度/数据/日志核对；缺checkpoint不自动补训 |
| P1 冻结裁判 | 旧数据schema审计；新候选320句、PAWS抽样方案、人工审核记录、分层和固定split；开发集定精度及阈值 | 未获人工等价确认不生成确认结论；不得用模型表现挑题 |
| P2 旧缓存诊断 | 在独立目录实现J/W/零码/配对bootstrap；在analysis1缓存上检查结果和接口 | 明确标记探索/开发，不把旧事实升成新确认 |
| P3 两轨首轮提取 | 同一新面板，mediated线上0–10B可用点；两臂h先0/0.5/1/3B，补统一无标签质量与固定LM损失 | 推理模型/输入只读；完整manifest+无修改校验；共同点以外不做配对 |
| P4 统一读法试拟合 | 4格×1 SAE seed的精确预算、数据和资源配置，经批准后跑；合格后第二seed与最终10B点 | 质量未校准则只报告主干/线上轨迹；不硬解释两臂稀疏优劣 |
| P5 统计与反例 | S+/S−/G、h/h_hat、两臂差、质量轴、固定案例；补5/10B公共点 | 多指标一致/冲突均记录；不删峰后下降，不重定义同语义 |
| P6 汇报与交接 | 结果读取面、完整证据记录、六张以内主图、Unknown和一个下一决策；更新执行任务自己的memory | 有效测量后无效应也可完成汇报；不足明确结束，不能用更多投影补足资格 |

建议保护每天至少30分钟的阅读与独立解释时间，先完成“一个真实正反例+三个量含义”的小输出，再安排实现，不让训练监控吞掉这部分工作。

建议新增文件全部位于独立执行目录：

| 文件 | 职责/复用边界 |
|---|---|
| `audit_inputs.py` | 读取run合同、检查完整输入、词元/恢复历史/可观测性；不写训练run |
| `build_panel.py`、`configs/panel_spec.json` | 适配PAWS和历史层级；生成候选、审核字段、分组划分与配对；不自动签人工审核 |
| `collect_representations.py` | 改编旧semantic_evolution提取接口，区分原生/mediated tap及线上/离线reader；固定有效位置 |
| `feature_reuse_metrics.py` | 新增稀疏J/W、三条曲线、置换参照及分组配对区间；复用原余弦计算而非重写整框架 |
| `fit_offline_sae.py`、`configs/offline_sae.json` | 复用经哈希定位的TopKSAE和优化器语义；新写冻结LM的激活拟合循环及预算/质量记录 |
| `compare_tracks.py` | 统一读入long-table，计算共同点水平差/增长差；拒绝混合reader_origin或不同样本 |
| `render_report.py` | 固定样本排序/色标、真实词元间距、正反与质量图；输出全部负面结果 |
| `tests/test_reuse_metrics.py`、`tests/test_extraction_contract.py` | 小型手工稀疏码、零码/置换不变、配对统计、0B同tap和无参数修改检查 |
| `configs/analysis.json`、`schemas/`、`README.md` | 冻结主指标/时点/阈值状态、接口和复现入口；源码/hash版本化 |

**复用：**旧checkpoint加载、tokenizer身份、有效位置采集、h/h_hat/稀疏npz、关系余弦与绘图读表。**改编：**数据适配、native分支、质量校验、来源分组与bootstrap。**新写：**直接组合W/J与三曲线、两臂离线读法预算、共同点比较。**不复用：**当前未审核864句作为确认集、强制固定reader、按SAE结果选择的标签、旧router/MoE或复杂loss、历史提交命令默认配置。

成本预估分开：旧缓存CPU指标通常远小于模型提取，但未跑不报实测时长；既有864句×五时刻+Qwen+跨reader作业平台运行约7分24秒，只能作为小面板推理可行的历史参考，不能直接外推离线SAE。新执行先对32句和一个激活分片实测，报告加载、推理、写盘、拟合分别耗时，再给全规模墙钟和GPU时预算。两边不共享不同硬件吞吐来宣称方法计算效率。没有资源时，P0/P1/P2及主干缓存后的CPU统计可推进，不自动抢占现有训练。

## 12. 测完之后，能完成怎样的一次组会问题

**可以完成一个有边界的知识更新：**在这两条从随机初始化出发的轨迹、指定读取点和两种经过审核的关系数据上，命题改写的稀疏组合复用是否增强；它与原始表示的变化是否相容；统一读法后 SAE-mediated 相比普通基线有什么可测差异，最强竞争解释还剩什么。

建议汇报顺序：原假设与正反例 → 固定监督标签怎样变成三个指标 → 单轨真实变化与质量 → 共同词元点的两臂差异 → 失败/矛盾案例 → 已排除什么、仍无法区分什么、下一决策。预期曲线只能是标明“非实测”的示意，不用它补真实结果。

| 实际观测组合 | 可以得出的差异分析 | 仍不能声称 |
|---|---|---|
| 两臂h/统一离线code都改善，臂间差接近0且区间足够窄 | 当前关系随预训练变得更可读取；未发现SAE-mediated额外收益达到关注量级 | SAE无任何作用、所有阶段都等价 |
| 只有mediated线上code改善，h和统一离线code不支持 | 共同训练的读法适应仍是主要候选解释 | 主干新形成更多语义、机制已定位 |
| mediated在h及统一离线code均更好，质量相当、外部数据复核一致 | 整体SAE-mediated配置与更强的指定关系可读性相关，匹配条件下有稳定描述差 | 稀疏性单独导致、等算力优势、跨seed普遍规律 |
| 同义重合升高，但反例同样升高或标签置换也相同 | 全局集中/词面依赖可解释“复用”，主选择性假设不支持 | 语义分化成功 |
| h改善而h_hat/code不改善 | 本位置原始关系增强，但这套SAE读法未保留/未表达同等区分 | 模型完全没有语义、SAE一般都无效 |
| 数据有效且高精度指标不支持预期 | 这一具体假设受到反证；这是有效组会结果 | 因为结果不正就说实验未完成 |
| 数据/reader资格失败或区间太宽 | 当前只能报告测量不足，并指出最小补充 | 用漂亮聚类或更多指标宣布完整机制结论 |

仅完成现在0–3B窗口可支持一次**早期阶段**汇报；完成共同0.5–10B、确认数据和统一读法复核，才能对本计划完整时间窗口作答。即使全做完，也不能自动证明 feature 是语义原子、模型已拥有系统组合推理、原生预测实际依赖这些feature，或额外参数/稀疏性/重构loss各自的因果贡献。功能使用需要另行授权的定向干预；更强因果分解需要研究者选择额外对照，本轮不主动添加。

**等待研究者确认的一个主决策：是否将“同命题异表达的选择性组合复用”设为主问题，采用W及S+/S−/G为主测量，并按本计划分开批准checkpoint-only分析与两臂同规则离线SAE预算。** 同时确认新面板的领域/反例构成与最小关注差异；在此之前这些均保持提案状态。
