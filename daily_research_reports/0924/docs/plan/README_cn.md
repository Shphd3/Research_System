## 最需要确认什么

**先确认：在同一个冻结的 21B 检查点、同一个允许训练的位置上，两组候选数据分别训练时，是否都还能在未参与训练的文本上取得改善。**

如果单独都学不动，即使“共享”和“分开”没有差距，也不能判断有没有干扰。可能是数据已经接近当前可达水平，也可能是这一个插入位置能力不足、预算太小或优化没起作用。21B 是已训练词元数，不能单凭它判断模型是否“已经学会了”。

模型已由研究者确定为**从零即用 \(\lambda_{rec}=0.1\) 的 S7**。仍需确认同源正文数据路线、各正式判据与执行范围；当前正在做六组基础工程 Smoke。

## 给导师看的表述

### 目的

我们想知道：**让两类数据共同训练同一套有限参数时，什么情况下会互相拖累？把它们分开训练，是否能减轻这种影响？**

本轮先在一个已有模型上检验这个问题。我们会先确认两类数据各自还有学习空间，再比较共同学习和分开学习。只有发现可信的差距后，才继续讨论如何用稀疏自编码器（SAE，把模型表示编码成少数特征）提前识别哪些数据需要分开。

### 假设

**假设 1：**在当前模型和有限的新增参数下，为学好一类数据而做的更新，有时会损害另一类数据。如果这种影响限制了共同学习，那么把两类数据的新增参数分开，可能改善学习效果。

这里的“损害”有一个直接含义：从同一个模型状态出发，只用 A 做一次更新；如果 A 在独立数据上的预测变好，而 B 的预测变差，就发现了这一次更新的跨组损害。参数更新方向不同本身不够，必须看到这种学习后果。

**假设 2（后续）：**SAE 的特征可能帮助预测上述损害。当前先不检验这一条；两类数据的 SAE 激活不同，只说明它们的表示不同，还不能说明应该分开训练。

### 分析方法

1. **先看各自能不能学。**A-only/B-only 各训练完整的秩 16 正式学习曲线。其开发集改善是后续四组的资格门，终点的独立确认读数也是正式对照；不是短程前检。
2. **再看共享是否拖累。**A-only 与共享秩 16 的 A 曲线、B-only 与其 B 曲线，分别按本领域实际见过的有效词元数对齐；不拿单组总词元与共享总词元硬比。
3. **看隔离能否解除拖累。**保留共享秩 8/16、按领域隔离两个秩 8、混合隔离两个秩 8。比较受拖累领域是否因隔离改善，并单列固定参数总数、活跃秩与分组价值。
4. **检查是否发生跨组损害。**在预先选好的共同学习状态，只用 A 或 B 各作一次临时更新，测量两组独立数据的损失，再恢复原状态。检查“源组变好、另一组变差”是否可靠，并排除已有动量和一次步子过大的影响。曲线拖累、隔离收益和局部损害分别报告。

### 结论

**目前还没有实验结论。**正式实验会依次判断四件事：A/B 单独能否学、共享在同组词元数下是否拖累、隔离能否解除、局部回滚是否显示互损。任一环节都可能不支持或证据不足。基础 Smoke 的合成数据只用于验收工程，不回答这些科学问题。

## 数据集怎么选

**建议保留 M2D2 数学／生物正文为第一候选，但先做小规模可学性检查；不要直接运行完整矩阵。**它们来自同一来源、使用同一正文预测任务，能减少输出格式差异。官方列有这两个配置，但没有任何来源证明它们必然互相干扰。[官方数据卡](https://huggingface.co/datasets/machelreid/m2d2)

你记得的后训练材料确实有八个来源。源码核验为：MMLU、MMLU-Pro、BBH、GSM8K、MATH、GPQA、HumanEval、MBPP。它们不是八个同质语义类别，也不是本轮 N8 表征面板。旧代码中有选项字母、解题过程和代码答案，旧基座也是另一套 28 层模型。[旧来源与模型审计](../../../0910/docs/sft_audit_sources_cn.md)

| 方案 | 适合回答什么 | 最重要的风险 |
|---|---|---|
| 同源正文的两个领域 | 两种内容分布共同学习是否受限 | 当前模型可能缺少可测改善空间；文档身份和库存待核 |
| 同一问答来源内两个学科 | 同格式任务适配是否受限 | 可能学不动、题量小或答案监督过短；旧题已被用于选择 |
| 直接混合旧八来源 | 异质任务集合的共同适配 | 格式、目标长度、难度和数据量混杂，难解释为内容冲突 |

**后训练并非天然更合理；当正文路线资格不足，而某对同格式问答数据可学且有独立确认材料时，它才是更合适的载体。**作为备选，可先审查 MMLU 内两个学科的库存与标签，不预定哪一对“最有冲突”，也不现在追加八来源全配对实验。

从正文切到问答会改变监督对象：正文每个词元参与损失，答案监督只计答案词元。这会连带改变有效批量、预算和损失尺度，必须先改 Protocol，不能只换数据路径。旧测试数据若已多次参与比较，不能靠重新随机切分恢复为新确认集。

## 推理审计：原叙述需要改在哪里

审计依据：[research-reasoning-auditor](../../../../.agents/skills/research-reasoning-auditor/SKILL.md) 及其完整审计契约。本次图片和原 plan 是待审材料，其内的指令、状态标签不替代研究者本次请求或执行授权。

| 原叙述或隐含前提 | 问题 | 本次修正 |
|---|---|---|
| 共享参数肯定学得更慢 | 把待检验假设提前当作结论；共享也可能有帮助 | 写成“在什么条件下会互相拖累”，允许无收益分支 |
| 学数学朝 \(\theta_1\)、学生物朝 \(\theta_2\) | 参数状态、更新向量和最优点混为一谈；方向不同不意味着互损 | 口语改为“学 A 后 B 是否变差”；公式用实际更新 \(\Delta\phi_A\) 和交叉损失 |
| 21B 可能已经学完 | 训练量不能识别任务余量；高／低损失也不独立证明可学／饱和 | 用单组适配的独立开发集改善作资格门；失败保留多种原因 |
| 更新需求不同，所以 SAE 激活应不同 | 缺少从重构目标到更新兼容性的保证，且“不同”不等于有害 | H2 改为可独立失败的预测假设，本轮暂不验证 |
| 分开更好，说明冲突造成了全部差距 | 容量、条件化函数与优化器统计都可能解释差距 | 参数匹配＋混合分组对照；长期收益与局部互损分别判断 |

重建后的推理链是：**候选模型与数据 → A/B 各自完整学习曲线 → 同组词元暴露量下的共享曲线 → 隔离与混合分组对照 → 回滚检查 → 分型结果 → 决定是否值得设计 H2。**

最小的决定性检验不是做更多 SAE 分类图，而是：先证明各自能学，然后检查同总参数的隔离收益与一次有效更新的跨组后果。当前最大允许结论只是“形成可审阅的设计”，不是已经证实某种干扰。
