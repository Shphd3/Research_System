我当前直觉：常见组成要素形成低频组合时，可能主要需要学习如何组合使用已有处理。但这必须检验，不得当成已知事实。
保留已有功能的含义是：基础处理仍正确，并被后续实际使用；不是所有细分任务的最终答案必须不变。
