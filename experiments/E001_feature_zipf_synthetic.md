# E001 Feature-Zipf Synthetic Hierarchical MoE

Source report: `daily_research_reports/0507/feature_zipf_synthetic_brief_report_0505.md`

## Question

Can Hierarchical MoE recover hierarchical sparse mechanisms better than flat MoE when Zipfian structure acts on sparse features rather than on semantic labels directly?

## Hypothesis

If data are generated by hierarchical sparse Zipfian mechanisms, Hierarchical MoE should align experts with fine-grained features and true output mechanisms better than flat MoE controls.

## Why Synthetic?

Real language hidden states do not provide ground-truth mechanisms. Synthetic data allows controlled testing of recoverability, routing alignment, feature selectivity, and function alignment.

This version is more realistic than leaf-Zipf synthetic data because Zipf acts on sparse feature occurrence:

- common features: high-frequency general features
- group features: mid-frequency coarse context
- unique features: low-frequency fine semantics

Labels are induced by activated features rather than sampled directly.

## Data Construction

Representation:

$$
h=\frac{1}{\sqrt{|S(x)|}}\sum_{j\in S(x)}a_je_j+\epsilon
$$

Sample types:

| Type | Probability | Activated content | Used in router NMI |
|---|---:|---|---|
| common-only | 0.40 | common | no |
| group-only | 0.35 | common + group | yes |
| group+unique | 0.25 | common + group + unique | yes |

Variable-A output:

$$
y=(A_{\text{common}}+\mathbf 1[c]A_c+\mathbf 1[f]A_{c,f}^{tail})h+\eta
$$

Fixed-A output:

$$
y=A_{\text{common}}h+\eta
$$

Fixed-A is a control. It tests whether input features alone induce routing differentiation; it does not prove experts learned different output mechanisms.

## Experimental Design

Shared setup:

- hidden dimension: 1024
- coarse groups: 10
- fine mechanisms per group: 10
- leaf paths: 100
- train / valid / test: 20000 / 5000 / 5000
- epochs: 30
- batch: 256
- learning rate: 0.003
- seeds: 0, 1, 2
- learned flat and hierarchical main models use matched parameter count: 5,427,200

## Compared Models

- Random flat
- Flat $Wh$ + common + LB
- Flat middle spectral + common
- Hier full_input
- Hier conditional_input
- Oracle flat
- Oracle Hier conditional_input

## Metrics

- Loss
- Leaf NMI
- Feature selectivity
- Function cos
- Sparse dictionary atom selectivity
- Sparse dictionary atom diversity
- Sparse dictionary top atom overlap

## Results

Variable-A:

- Oracle models prove the mechanism is recoverable.
- Learned models clearly beat random flat on loss.
- Hierarchical models have slightly stronger function cos than flat learned models.
- Hierarchical models do not clearly beat flat middle spectral + common on Leaf NMI or feature selectivity.

Fixed-A:

- Learned routing still shows weak feature selectivity over random.
- Function cos is essentially identical across models because the output function is shared.
- This supports input-feature-induced weak routing differentiation, not functional specialization.

Sparse dictionary diagnostics:

- Flat middle spectral + common has the strongest learned sparse feature division metrics.
- Hierarchical models beat random but do not stably beat flat MoE.
- Oracle is much stronger, so the sparse dictionary metrics can detect the true-path upper bound.

## Interpretation

The experiment suggests specialization has at least two separable components:

1. feature-level specialization: routing or experts separate sparse input features;
2. function-level specialization: expert functions align with true output mechanisms.

Current Hierarchical MoE has a stronger signal on function-level recovery than on feature-level sparse division. The strongest feature-division phenomenon is currently flat middle spectral routing.

## Claim Strength

- Feature-Zipf data construction is more reasonable than leaf-Zipf: supported.
- Synthetic mechanism is recoverable: supported.
- Learned routers exploit sparse feature signal: weakly supported.
- Hierarchical MoE is better than flat MoE at sparse feature specialization: unsupported.
- Hierarchical MoE helps function-level mechanism recovery: weakly supported.
- Middle spectral routing helps sparse feature division: supported by current synthetic diagnostics.

## Limitations

- This is still synthetic data and does not prove transfer to real language hidden states.
- Learned Leaf NMI remains far below oracle.
- Function recovery and feature division are not yet unified by one architecture.
- Fixed-A cannot support claims about output-mechanism specialization.

2. Separate function-level specialization from feature-level specialization in the architecture and metrics.
3. Explain why middle spectral routing improves sparse feature division.
