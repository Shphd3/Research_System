# Experiment Protocol And Result Writer

The Anchor owns question, model and scientific choices; Protocol owns exact
execution/approval; Summary owns the complete four-part result; Detailed owns
setup, provenance, deviations, full rounds and artifact lineage. Do not invent
missing scientific choices or create a parallel implementation plan.

## Read For The Requested Output

Start with the named Anchor/folder. Protocol also uses Focus; results use the
frozen Protocol, actual evidence and researcher judgment.

| Output | Required reading |

Reuse confirmations and unchanged rules. Do not load authoring guides just to
read a frozen result contract. Preserve existing valid layouts and language roles.

## Mechanism And Evidence Checks

Map each decisive model term to actual computation, changed/held-fixed quantities,
observable, identification strategy and remaining confound. Do not say independently
manipulated when several factors move together. Test a few known good/bad/confusing
cases before costly sweeps; distinguish implementation calibration from confirmation.
Retain stage-local evidence and finite-step/component error where material.

Draft one `DRAFT_NOT_EXECUTABLE` Protocol, fill grounded fields and expose only
critical proposed/blocked choices with the A-G ledger. Promotion/amendment follows
its owner contract; design confirmation alone is not execution authorization.

For results, eligibility and source lineage precede interpretation. Preserve
`NOT RUN`, `UNKNOWN`, `MISSING`, `INELIGIBLE` and failed predictions. Complete
factual records while missing human judgment stays unknown; do not fabricate a
verdict or next decision. Four-part bilingual Summary and complete Detailed must
agree with frozen scope and actual evidence. Never rewrite source results to fit
an explanation.

With Summary link it first; deliver the decisive result, necessary figure/reading
sentence, boundary and next uncertainty. Unconfirmed proposals are `AI 建议`.
Verify chosen contracts, links and repeated fields. Execution, publication and
scientific transitions remain within explicit authority, without redundant gates.
