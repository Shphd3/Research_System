# Research Mainline

Map approved research state onto stable repository paths. This Skill does not
define a scientific question, method, result, or claim.

## Route By Requested Operation

- For choosing or changing project paths, filenames, Anchor folders,
  experiment locations, story locations, or Focus locations, read
  [layout_and_naming.md](references/layout_and_naming.md).
- For deciding which artifact owns a statement, whether the mainline changed,
  or which canonical and derived surfaces need updates, read
  [artifact_lifecycle.md](references/artifact_lifecycle.md).
- Before creating or reorganizing a research-line `README.md`, also read
  [line_direction_contract.md](references/line_direction_contract.md).
- For archive work or an explicitly requested root Anchor publication, read
  [publication_and_archive.md](references/publication_and_archive.md).

Do not load references for operations outside the request.

## Stable Boundaries

- The project Anchor is the sole canonical current research design. Do not
  create a parallel `design.md`.
- Root sync, graph edits, publication, external collaborator sync, handoff,
  commit, and push require an explicit request.
- External sync and handoff packaging belong to `research-communication`
  handoff mode. Graph structure belongs to `research-graph-sop`.
- Move canonical files when reorganizing; do not leave duplicate canonical
  versions. Update all in-scope references and verify the old path is gone.
- Do not promote raw logs, checkpoints, datasets, full run directories, or
  unfiltered outputs into mainline paths.
- Never strengthen a claim while moving, indexing, archiving, or publishing an
  artifact.

Completion requires correct placement, valid in-scope links, no duplicate
canonical source, unchanged scientific meaning, and any explicitly requested
derived view regenerated from its source.
