# Research Communication

Create one requested communication artifact from canonical scientific sources
without changing their claim boundary.

## Select One Mode

Read exactly one mode reference for the requested deliverable:

- Meeting brief, meeting synthesis, or speaking outline: read
  [references/meeting.md](references/meeting.md).
- Research-line story or paper-like stage synthesis: read
  [references/story.md](references/story.md).
- Curated package, copy, handoff, or external sync: read
  [references/handoff.md](references/handoff.md).

Do not load the other mode references unless the user explicitly requests a
second deliverable. Packaging already-written meeting material is handoff mode,
not a reason to reload the meeting workflow.

## Shared Contract

- Use the user-selected scope and the smallest canonical sources that establish
  the result. Do not treat chat as evidence.
- Lead with the question, knowledge update, result, or bounded conclusion.
- Define indispensable terms before using them as evidence.
- Separate direct result, interpretation, claim, limitation, and next decision.
- Preserve negative, failed, and insufficient evidence without optimistic
  reframing.
- Never strengthen a Focus, Anchor, Summary, or Detailed conclusion.
- Keep commands, full tables, raw logs, and run chronology in their owning
  artifacts.
- Create only the requested output. Graph edits, root Sync, external copying,
  commit, and push require their own explicit user request.

If the needed source scope or human scientific judgment is missing, report the
specific missing input. Do not manufacture a joint conclusion to complete the
document.
