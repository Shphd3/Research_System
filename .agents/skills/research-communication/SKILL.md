# Research Communication

组会结论默认按一分钟准备。每条先讲对研究问题的认识更新，再用一句比较说明依据。以导师接下来需要判断的取舍收尾。具体写法见 [一分钟组会](references/meeting.md#一分钟组会)。

Choose the requested mode; do not run a serial skill chain:
- Meeting or speaking: [meeting](references/meeting.md).
- Research-line synthesis: [story](references/story.md).
- Curated copy or external sync: [handoff](references/handoff.md).

Use canonical evidence and the shared [Markdown writing rules](../../../docs/report_writing.md).
Separate derivation, measurement, interpretation and decision. Inspect existing
work before calling it missing. Preserve negative results and source disagreements.

Use the current project's question record and dated evidence. Build the talk
around the conclusion that changes what the team would do next, and the
reason for that choice. Place the requested reading format in the dated meeting
folder. Detailed tables and history stay with the experiment.
Create only the requested output; execution and publication require their own scope.
