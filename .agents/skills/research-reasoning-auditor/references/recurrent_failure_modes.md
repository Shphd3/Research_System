# Recurrent Reasoning Failures

Diagnostic aids, not labels for the researcher or mandatory reply sections.

| Pattern | Repair question |
|---|---|
| Desired result becomes purpose | What remains unknown if the preferred outcome never occurs? |
| Observation becomes mechanism | What other mechanism predicts the same observation? |
| Proxy replaces the scientific object | What is actually measured, and what stronger claim is still untested? |
| Convenient metric retrofits the question | Would the question survive without this metric? |
| Only the favored hypothesis is considered | What is the strongest live alternative at the same explanatory level? |
| Confirmation is mistaken for discrimination | On which observable do the explanations disagree? |
| Correlated metrics are stacked | Are these independent evidence or repeated views of one property? |
| Mathematics precedes a defined question | What distinction must the formula resolve? |
| History or structure confounds the effect | What changed besides the proposed cause? |
| A smooth story substitutes for identification | Which arrow is actually tested? |
| A schematic curve substitutes for derivation | Which stated model produces that curve? Is it illustration or data? |
| A local effect becomes a design recommendation | Where is the matched objective/resource/time-horizon comparison? |
| Missing exposition is called missing research | Did we inspect the existing derivation and relevant result records? |
| Total approximation accuracy validates a small component | Is the remainder small relative to the claimed component itself? |
| Operational failure becomes scientific refutation | Did the measurement and implementation pass before interpreting the model? |

## Sparse-Representation Example

Lower effective rank and increased sparse-feature reuse do not establish selective
retention of useful information. Global compression predicts both. A separating
comparison must inspect task-relevant information or function; better linear
readout still shows accessibility rather than causal use. Likewise static common
activation, update displacement and signed loss contribution are different objects.

For the existing-derivation and local-to-decision cases apply
[mechanism closure](mathematical_mechanism_closure.md) before prescribing another toy
model. An open downstream decision does not erase a valid local derivation.
