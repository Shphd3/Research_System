# Evidence And Claim-Boundary Update

Use with the complete Anchor self-containment contract when updating sections
7–8 from completed evidence. This does not authorize a new experiment.

## Result Update

```text
human closed-book summary
-> AI evidence and boundary audit
-> summary.md / summary_cn.md / detailed.md update
-> anchor sections 7 and 8 update
-> researcher completes the actual result in the already-active
   daily_research_reports/MMDD/focus_<problem>.md
-> `research-final-report` writes <anchor_stem>_final_report.md once the question
   reaches a stable bounded conclusion
```

An explicit researcher account already supplied in the current session or
active Focus satisfies the human-summary prerequisite; do not ask for a duplicate.
If it is absent, audit the measurements and identify the missing judgment without
writing an AI interpretation as human-owned. The human summary states the question, direct result, confirmed and weakened
beliefs, current mechanism, cannot-claim boundary, and one next decision. AI
may improve expression only after that draft exists.
