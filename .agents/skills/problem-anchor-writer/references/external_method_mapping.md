# External Workflow Mapping

The [method kernel and coverage](../../../../docs/methodology/research_exploration_mapping.md)
adapt pinned research-exploration semantics without installing a second skill.
Keep the local eight-section Anchor; no parallel `design.md` or research map.

| External responsibility | Local owner |
|---|---|
| Problem, importance, root/child relation | Anchor 1; Focus activation through progress |
| Falsifiable world/workload priors | Anchor 2 |
| Candidate explanations and discriminator | Anchor 3 |
| Mathematical objective, variables, information and constraints | Anchor 4 |
| Prior-art mechanism decisions and constructible computation | Anchor 5 |
| Smallest falsifier and evidence boundary | Anchor 6 |
| Current bounded evidence | Anchor 7, derived from Summary/Detailed |
| Claim, upward answer and next decision | Anchor 8 and researcher-owned Focus |
| Exact run contract and complete round history | Protocol and Detailed, not duplicated in Anchor |
| Stable synthesis | Existing final-report or requested Story owner |

Preserve logical `refines`, `depends-on` and `coupled-with` distinctions without
forcing external directory layouts. Sibling dependency is not child ownership.
An active child inherits a parent clause and owes it a bounded answer; inactive
questions are not automatically given models or experiment folders.

The mapping documents intentional exclusions and retained contracts. Coverage
means obligations have local owners, not that an AI has proved all future work
correct. External tools, viewer services and publication remain optional and scoped.
