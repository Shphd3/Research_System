# Problem Anchor Writer

Maintain one canonical Anchor, never a parallel `design.md`. The researcher owns
question, prior, model and scientific decisions; AI audits and formalizes confirmed
meaning, keeping unresolved choices `Unknown`, `BLOCKED` or `AI_PROPOSAL`.

## Route By Change

Read the current Anchor and only decision-bearing parent clauses/evidence.
Reuse explicit confirmations; ask only for genuinely missing judgment.

| Request | Required contract |
|---|---|
| New/reopened scientific core | [Judgment review](references/judgment_review.md) |
| Formal Anchor write or audit | [Self-containment](references/anchor_self_containment.md) |
| Result/boundary update | Self-containment plus [result update](references/result_update.md) and owning evidence |
| Parameterized model fitted from data | Also [learnable design](references/learnable_research_design.md) |
| Equation-based mechanism or missing-model diagnosis | Also [closure](../research-reasoning-auditor/references/mathematical_mechanism_closure.md) |
| Prior work changes mechanism choice | Also [prior-art decision](references/prior_art_mechanism_decision.md) |
| External workflow integration | [Mapping](references/external_method_mapping.md) |

The [method kernel](../../../docs/methodology/research_exploration_kernel.md)
supplies stage logic, not another artifact schema or required call sequence.

## Write And Verify

Keep the existing eight sections, one scoped decision, core model, falsifier and
next decision. Section 4 states variables/state, exact objective or observable,
constraints, allowed information, assumptions and derived/empirical relations.
Section 5 maps each consequential item to constructible computation beside its
Goal, How and Why; engineering choices are not invented physical priors.

Use existing self-containment, grounding and parent/child rules. Clarity takes
priority over unchanged length or subsection order; retain the eight content
owners, allow necessary modest growth, and put full derivations in linked detail.
Explain the shortest derivation needed before linking fuller proof; local closure
does not settle a larger design decision. Links audit meaning, not replace it.
Preserve language companions and mathematical meaning.

An audit is read-only unless revision is requested. Passing checks is not human
approval or a scientific state transition. Complete authorized independent checks
and factual edits; name the exact blocked judgment rather than inventing it.
