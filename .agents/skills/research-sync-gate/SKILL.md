# 判断一个问题是否适合导师讨论

研究者要求评估组会准备度或下一问题时使用。从点名的讲稿、探索日志或 Anchor 开始，只追溯会改变判断的来源。

检查第一次听的人能否听懂研究目的、竞争解释、两者会产生不同预测的比较，以及实测值或仍待验证的预测。明确区分缺推导、缺实测、缺研究者取舍和讲稿没讲清。可靠的负结果、反例或能指导下一步的预测都可以成为讨论重点。

直接回答哪些内容可以讲，哪一处影响判断，并给出最小修订。需要结构化交接时可使用 `READY_FOR_SYNC`、`READY_FOR_PROTOCOL`、`NEEDS_HUMAN_JUDGMENT` 或 `NOT_READY_OBJECT_OR_LOGIC`。研究者已有的选择继续适用。写组会稿由 research-communication 处理；创建或批准正式实验依照其 Anchor 和 Protocol。
