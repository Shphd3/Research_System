# Project Instructions

Reusable prompts for recurring project-level work.

Current examples:

- `research_progress_project_prompt.md`: ChatGPT Project prompt for web-side research reasoning, meeting transcript debrief, experiment planning, result sync, and pre-meeting convergence.
- `group_meeting_project_prompt.md`: guidance for converting research progress into group-meeting / PRISM-style material.

When a prompt becomes stable and frequently reused, convert it into a Codex skill under `codex_skills/` and install it into `C:\Users\250010109\.codex\skills\`.
