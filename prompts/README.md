# Prompts

This folder stores the active reusable prompts for the research system.

Use root-level files (`AGENTS.md`, `PROJECTS.md`) as the active research
system. Prompts here are supporting material, not the primary source of
research memory.

For web-side theory AI that cannot see `Projects/`, use `AGENTS.md`,
`PROJECTS.md`, root `sync/` summaries, and user-provided anchor/result snippets.
Ask the user or Codex to expose project-local graph, anchor, `summary.md`, or
`detailed.md` files when needed.

## Folders

- `project_instructions/`: active reusable prompts for web-side research
  discussion, mainline audit, handoff preparation, and meeting closure.

Older prompt ideas have been folded into the active prompts. Do not maintain a
second prompt system.
