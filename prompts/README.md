# Prompts

This folder stores reusable prompts and historical workflow instructions.

Use root-level files (`CURRENT.md`, `PROJECT_INDEX.md`, `AGENTS.md`) as the active research system. Prompts here are supporting material, not the primary source of research memory.

## Folders

- `project_instructions/`: active reusable prompts for specific work modes, such as group meeting or PRISM preparation.
- `legacy/`: older large workflow prompts kept for reference. Do not treat them as the current workflow unless a task explicitly asks for them.
