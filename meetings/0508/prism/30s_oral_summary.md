# 30s Oral Summary

The purpose of this experiment is to test whether a Hierarchical MoE can recover a structured computation mechanism, not just split input features. I changed the synthetic setting so that Zipfian long-tail behavior is attached to sparse features, which is closer to language. The key result is: if all samples share the same output function, experts have little reason to specialize. But if common, group, and unique features require different transformations, the hierarchical model fits the mechanism slightly better. Its function cosine is 0.796, above the flat baseline's 0.780, but still far below the oracle hierarchical value 0.973. So my current claim is limited: hierarchy partially helps function-level mechanism recovery, but it has not yet proven stronger sparse feature division.
