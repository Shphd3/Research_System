# Future-me note

The important conceptual decision is:

```text
Do not call the problem solved when only equal mass works.
```

V2.1 is about the next step:

```text
equal mass + feature coherence + training preservation
```

If experiments show that only expert-guided variants work, the conclusion should say:

```text
Good dispatch needs an alignment prior.
```

If even expert-guided variants fail, the conclusion should say:

```text
The current assumptions are still insufficient; the missing ingredient is feature-identifiable geometry or stronger training preservation.
```
