# Result Writing Rules

When experimental results are available:

1. Do not overwrite theory statements.
2. Insert result paragraphs only in the Experiments section.
3. Preserve negative results.
4. For each result, state which claim it supports or refutes.
5. Do not use terms like “solves good routing” unless mass, coherence, and preservation all improve.
6. If only equal mass improves, say exactly that.
7. If expert-guided geometry helps only in aligned settings, say exactly that.
8. If margin-aware updates fail, report the failure.
