# Result Table Index

The current synthetic suite writes paper-facing aggregate tables under
`results/tables/`. These files are generated by `run_synthetic.py` and should be
treated as the source for numbers copied into `latex/paper.tex`.

## Current Tables

| Experiment | Table file | Main reading |
|---|---|---|
| E1 | `e1_uniform_sphere.md` | Prototype geometry controls load under uniform spherical features. |
| E2 | `e2_high_dim_geometry_floor.md` | More routed examples reduce sampling noise, not the fixed prototype-cell floor. |
| E3 | `e3_spectral_prototypes.md` | Expert spectral directions are useful centers, not a balance guarantee. |
| E4 | `e4_covariance_counterexample.md` | Covariance isotropy does not imply directional uniformity or uniform load. |
| E5 | `e5_anisotropy_whitening.md` | Whitening repairs the elliptical toy representation under the stated assumption. |
| E6 | `e6_balanced_assignment.md` | Capacity assignment forces counts but is not a representation-geometric explanation. |

## Regeneration

```bash
python papers/uniform_feature_moe_initialization/exp/run_synthetic.py \
  --outdir papers/uniform_feature_moe_initialization/exp/results --full
```

After regeneration, verify `results/summary.md` before copying any number into
the paper.
