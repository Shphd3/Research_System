# Experiment Registry

This file fixes the mapping between V1 experiment IDs, runner entrypoints,
result tables, paper figures, and paper labels. Use this registry when
regenerating results or updating `latex/paper.tex`.

The full suite can still be run through:

```bash
python papers/uniform_feature_moe_initialization/exp/run_synthetic.py \
  --outdir papers/uniform_feature_moe_initialization/exp/results --full
```

Individual experiments can be run with `--experiments`, or through the wrapper
scripts listed below.

## Wrapper Behavior

Each wrapper calls `run_synthetic.py` with a single experiment ID and writes to a
single-experiment result directory under `results/by_experiment/`. The canonical
paper-facing aggregate remains `results/`, generated by the full-suite command.
