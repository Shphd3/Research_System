# V2.2 Audit: Method, Paper, and Experiments

Date: 2026-07-06

## 1. Concrete method statement

The method in V2.2 is **BFSR: Balanced Feature-Specializing Routing**.

BFSR is a static calibration-time router:

```text
Input: unlabeled calibration features X_cal, number of feature families K, number of experts E.

1. Fit spectral normalization on X_cal.
2. Cluster normalized calibration features into K recovered feature families.
3. Estimate each recovered family's mass.
4. Assign recovered families to experts under an equal-number or mass-aware balance constraint.
5. Route holdout / future examples by recovered family identity.
```

The causal map is:

```text
spectral isotropy / whitening -> clean routing metric
local feature recoverability -> family recovery
uniform feature frequency -> equal-number family assignment gives mass balance
mass-aware assignment -> repair when frequency uniformity is removed
```

Quantile-SPR is not the main method.  It is a mass-only baseline that can balance counts while splitting feature families.

## 2. Paper statement audit

### Correct claims

The paper can claim:

```text
Under globally spectrally isotropic, frequency-uniform, locally recoverable feature-family distributions, BFSR constructs a balanced and feature-consistent static dispatch.
```

The paper can also claim:

```text
Spectral isotropy alone is insufficient.
Local recoverability is necessary for feature-family dispatch.
Uniform frequency is the clean-case mass mechanism.
Spectral normalization acts as metric repair under anisotropic distortion.
```

### Claims that must not be made

The paper must not claim:

```text
spectral isotropy alone gives useful routing
BFSR proves downstream learning improvement
BFSR solves learned-router MoE training
BFSR solves route preservation under drift
BFSR works on real language-model hidden states without further audit
K can be selected automatically
expert identity is semantic
```

### Wording fixes applied

The main paper has been revised to replace informal language such as `non-cheating` with:

```text
label-free
calibration-time
batch-independent
admissible under the calibration protocol
```

## 4. Reliability judgment

The results are reliable for the narrow static-dispatch claim.

They are not reliable evidence for:

```text
downstream task learning
real hidden-state routing
learned-router dynamics
training-time preservation
semantic expert specialization
automatic K estimation
```

The main technical limitation is that the current suite is synthetic and uses known K.  E5 also shows that when frequency uniformity is removed, family recovery and mass balance become more difficult; mass-aware assignment repairs LoadCV but does not fully solve all possible specialization issues.
