# Papers

This folder stores paper-writing workspaces.

Each paper workspace may contain:

- venue templates copied from official sources;
- LaTeX or Markdown drafts;
- paper-specific experiment plans;
- source maps back to project-local anchors, summaries, detailed records, and
  daily notes.

The source of research truth remains the project-local artifacts under
`Projects/` and the explicit root sync entries under `sync/`. Paper drafts
must not strengthen claims beyond those source artifacts.
