# 研究地图阅读副本

[English](README.md) · [项目列表](../../PROJECTS.md)

[11月4日当前地图与科研结果](from-attention-to-search/README.md)：166个正式问题，85个父问题、81个局部子问题；七组阅读入口覆盖谱、训练动态、特征组合、局部干预与训练效用。

项目保留可编辑的研究原件。本目录是有来源哈希的派生阅读副本：`sources/`保留原件字节，`documents/`提供可移植链接。`manifest.json`记录选择及省略引用，`selection.json`记录项目提交版本。省略引用不表示原件不存在；完整设计、结果与复现代码在原项目。

本轮获准提交并推送，最终发布状态由Git历史及远端回执确定。交互网页位于执行侧，由项目`main/research_map.json`和`scripts/render_research_map.py`重建。ZIP、原始权重、激活与缓存不在阅读包。
