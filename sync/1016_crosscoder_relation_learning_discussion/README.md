## Bounded knowledge update

A feature is a fixed CrossCoder latent coordinate, not a confirmed semantic concept. We measure which coordinates activate together at a text position, how those relationships repeat across data subsets, and how they compare with frequency controls.

- Some local co-activation relationships replicate, but hard community boundaries are sensitive:86.60% edge retention versus0.322 member-weighted community agreement. The 186 groups are not established natural experts.
- Under the current K=4 terminal-adapter contract, relation routing does not meet the learning-benefit criterion against frequency and matched-random routing. All three harm the zero-adapter reference. Low-feature frequency is not equivalent to difficult knowledge.
- With expert token counts preserved and per-expert parameter-displacement L2 matched, all 9 local-intervention mean point estimates fail to show an actual-routing compatibility advantage; some intervals cross zero. This does not identify the complete Adam trajectory cause.
- Removing the adapter TRAIN-mean response preserves most harm, refuting dominance by that constant response. The full training cause remains unidentified.

The sole AI-proposed next readout compares frozen checkpoints on adapter-unused contexts from the same source file and the existing other-file evaluation, with a fixed feature list and common estimable support. Source association is not transfer causation. This proposal has not been executed.
