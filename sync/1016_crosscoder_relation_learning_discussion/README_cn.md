## 本轮认识更新

这里的feature是固定CrossCoder的潜变量坐标，尚不是已确认的语义概念。我们测量同一文本位置哪些feature同时激活，并比较这些搭配在两份数据中的重复性及相对于频率对照的差异。

- 部分局部共同激活关系可复核，但完整社区边界较敏感：86.60%的局部连接保留，社区成员加权一致度为0.322。不能将186组直接认定为天然专家。
- 当前K=4末端适配器设置下，关系分配未达到优于频率分配和匹配随机分配的学习收益标准。三种分配均劣于零适配器；固定低频条件不等同于困难知识。
- 在保持每专家token数并匹配每专家参数位移L2范数后，9组局部干预平均点估计均未显示实际路由的更新相容性优势，部分区间跨0。不能据此解释完整Adam训练轨迹。
- 移除适配器的TRAIN均值响应后，主要损害仍存在，反驳这一常量响应主导损害的解释；完整训练根因尚未识别。
