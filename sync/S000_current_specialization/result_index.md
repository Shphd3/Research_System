## Current Claim Boundary

Completed evidence supports a small value for the correct semantic path and
stronger semantic interpretability. It does not yet show that a learned or
pseudo-label Router closes the task-loss or selective expert-function gap to
Oracle. E14 is the registered test of that remaining question.
