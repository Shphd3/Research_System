# A11_16 预训练共享梯度传递实验协议

保持 A11_15 的任务、Qwen3-0.6B、K=2、两个 loss、seed 和 300 步训练完全不变，只增加梯度诊断。

主指标是：

$$
\widehat U_D^E=-\frac{\langle \nabla_{\theta_S}M_E,\nabla_{\theta_S}L_D\rangle}{\|\nabla_{\theta_S}M_E\|\|\nabla_{\theta_S}L_D\|}.
$$

它回答：如果只沿额外 H2 loss 在共享 Qwen 参数上的梯度下降，共同 H1 在未见改写上的正确答案 margin 会增还是减。正值表示局部有帮助，负值表示方向相反。

在 `0,20,100,200,300` 分别测 NTP 与 MTP 轨迹。诊断 batch 固定覆盖五个领域与两个状态，答案标签和同义版本严格 `5/5`；由于标签由状态和选项顺序共同决定，选项顺序采用可行的最接近平衡 `4/6`。用 float32、相对参数范数 `1e-6` 的正负双向扰动做中心差分，验证一阶公式并消去主要曲率误差；单边下降变化单独记录，测量后精确恢复参数。

判定顺序：

1. 有限差分、参数恢复、配对与诊断平衡必须先通过；
2. step 0 和 NTP `0-200` 轨迹的方向稳定为正，才说明原始共享传递存在；
3. 如果 NTP 为正而 MTP 后期变为非正，说明共同适应削弱传递；
4. 如果有效测量下方向稳定非正，则把“正的共同接口传递”加入 MTP 效率理论的必要条件；
5. 如果方向混合，只报告条件性结论，不调新 loss，也不扩 K。

该实验只解释局部共享参数方向，不证明全程效率、FLOPs、纯预训练收益或外部下游提升。
