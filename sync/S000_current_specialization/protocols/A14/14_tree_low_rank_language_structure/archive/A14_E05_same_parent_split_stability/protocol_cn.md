# 实验协议：A14_E05 同父同 token 切分特异性与稳定性前沿

## 0. 审批摘要

审批状态：研究者已在 2026-07-18 明确授权解压理论包，并无需再次审批直接执行；本文件固定执行前合同。

目的：固定父文本、token 集合及顺序，只改变孩子切分边界，判断有序低维共享算子是否真正偏好金标准树切分，并判断是否存在预测有效且理论界非空泛的算子。

主锚点：[A14 语言树低秩](/Projects/from-attention-to-search/main/problem_anchors/14_tree_low_rank_language_structure/14_00_tree_low_rank_language_structure/14_00_tree_low_rank_language_structure_anchor_cn.md)

实验角色：修复 E03 内容混杂的操作化与根因审计。

核心模型：

$$
z_p=B_Lz_L+B_Rz_R+b+\xi_p.
$$

主要指标：分别在真实切分和替代切分上训练、由验证集选正则强度后，测试父节点归一化误差的相对差：

$$
Adv_{split}=\frac{CE_{alt}-CE_{gold}}{CE_{alt}}.
$$

最小设置：Penn Treebank 自然二叉父节点；父文本完全相同；替代内部边界；每个跨度独立编码；最终层 EOS 读出；叶子训练集单独选择 95% 能量子空间；有序岭回归。

模型：Qwen2.5-0.5B 预训练与同架构随机初始化为主；Pythia-410m 为方向性复现。文件级划分，seed 1405，句子簇 bootstrap 1,000 次。

通过：Qwen 预训练真实切分优势至少 5%，95% 区间下界大于 0；比初始化至少高 5 个百分点；真实切分预测误差小于 0.90；并至少存在一个验证集合格点的通用理论界比小于 1。

失败：预测能力有效，但真实切分优势不为正，且置信区间上界不为正。

证据不足：切分优势为正但所有界空泛；初始化已有同等优势；两个模型不一致；或数据/拟合 guard 失败。

不能声称：Transformer 内部真的执行该树、低维方向被行为使用、语言整体低秩，或 MoE、扩散模型与世界知识结论。

审批决定：直接执行冻结协议。

## 1. 关键定义

- **真实切分**：Penn Treebank 中父节点的直接左右孩子边界。
- **替代切分**：同一父节点内部的另一条边界；父文本、所有 token 及顺序完全不变，并选择 tokenizer 子词长度最接近真实左右孩子的候选。
- **叶子基 $U$**：只用训练叶子选出的 95% 能量正交子空间；父节点拟合前冻结。
- **有序算子**：左右孩子使用不同矩阵 $B_L,B_R$。
- **平均算子**：先平均孩子再映射，是不区分左右角色的对照。
- **通用界比**：原谱范数递推界除以父表示范数；小于 1 才非空泛。
- **不变空间证书**：严格输出瓶颈下测试残差范数除以父表示范数；它不能代替原无约束传播定理。

## 2. 可证伪假设

1. **H1 共享空间近似**：真实切分有序模型测试误差低于 0.90。
2. **H2 切分特异性**：真实切分相对替代切分优势至少 5%，bootstrap 下界大于 0。
3. **H3 角色特异性**：有序模型相对平均模型至少改善 5%。这是次要假设。
4. **H4 预测与稳定兼容**：存在真实切分优势至少 5%、同时通用界比小于 1 的验证集合格点。
5. **H5 学习增量**：Qwen 预训练切分优势比随机初始化至少高 0.05；Pythia 只限制普遍性。

“验证集合格”严格定义为：该岭回归系数对应的真实切分有序模型验证误差，不超过注册系数网格中最小验证误差的 $1.05$ 倍。这个容差在查看测试结果前固定。

smoke run 在原上界 $10^2$ 取到最优点，因此在正式运行前将网格一次性扩展为 $\{10^{-6},\ldots,10^2,10^3,10^4,10^5\}$。若正式运行的真实或替代切分最优点仍落在任一端点，则岭回归内部点守卫失败，H2 只能判为证据不足，且不再扩网格。

## 3. 数据与对照

沿用 E03 的 Penn Treebank 文件划分、独立跨度 EOS 表示和冻结模型版本。保留长度 3--16 词的自然二叉父节点。替代边界在所有非真实内部边界中，最小化左右 tokenizer 子词长度差；并以词边界距离和边界编号打破并列。父节点及 token 不变化。

最多使用 8,192 个训练粗叶子，以及 4,096/1,024/1,024 个训练/验证/测试父节点。smoke 使用 Qwen、256 个叶子和 128/64/64 个父节点。

每个 checkpoint 只用训练叶子选择 $k$ 和 $U$。真实与替代切分分别拟合完全相同的有序模型，分别由验证集选择岭回归系数，再在相同测试父节点上比较。平均孩子模型作为角色对照；随机初始化作为架构对照。

## 4. 结果如何更新假设

- H1、H2、H4 同时通过：增强“稳定共享低维组合”解释。
- H1、H2 通过但 H4 失败：只增强树条件几何，不增强稳定传播机制。
- H1 通过但 H2 失败：父节点可由内容预测，树切分没有额外解释力。
- H2 在初始化同样强：优势主要是架构或读出先验，而非训练所得。
- 有序不优于平均：当前数据未支持左右角色矩阵的必要性。
- Pythia 方向相反：结论必须保持模型特异。

## 5. Claim Boundary

通过最多说明：在该树库与该表示中，真实切分更符合一个可泛化的低维有序组合代理，而且存在非空泛稳定点。

它仍不能说明：该代理是 Transformer 的因果内部计算、金标准树唯一正确、低维方向对任务必要，或该机制可以直接推广到 MoE、扩散模型和世界知识。
