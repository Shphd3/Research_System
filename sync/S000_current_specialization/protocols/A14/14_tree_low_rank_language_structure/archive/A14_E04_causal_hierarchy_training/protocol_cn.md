# 协议：A14_E04 层次训练的受控因果干预

## 0. 目标

研究者已于 2026-07-18 授权直接执行。本实验在成对数据上只改变叶子 token
的组织方式，检验这种改变是否导致相同因果 Transformer 学到不同的树对齐
低秩几何。

## 1. 成对生成数据

生成深度 5、32 个叶子的满二叉潜变量树。根状态在 $k_\star$ 个状态上均匀，
子状态由共享模变换与 15% 噪声产生，叶子从对应状态的 token 集合发射。
取 $k_\star\in\{4,8,16,32\}$，3 个随机种子。

每条样本产生两种严格成对条件：

1. hierarchy：保持深度优先叶序；
2. shuffled：在该样本内部独立打乱 32 个叶子。

二者的长度、token 多重集、根状态、unigram 和样本数完全相同。训练/验证/
测试各为 20000/2000/2000 对。

## 2. 模型与能力防护

相同初始化训练 4 层、宽 128、4 头、FFN 512 的因果 Transformer。每个文档
是 `[BOS]+32 leaves+[EOS]`，训练时再追加下一文档的 BOS 目标，使 EOS 本身
也进入输入并获得梯度。batch 128，共 800 步，保存 0/200/400/800 步。NLL 是干预结果，不用于能力匹配，
因为打乱本来就改变条件熵。

能力防护改为：从完整序列 EOS 状态线性预测已知根状态。两模型准确率都至少
0.50 且相差不超过 0.05 时，该配对才进入主几何比较。

## 3. 几何与组合指标

独立编码长度 2/4/8/16/32 的金标准连续跨度，以 EOS 状态为节点向量。在
验证集长度 2 节点上固定 $k=r_{0.05}$，跨层报告测试尾能量与有效秩。

长度 2/4/8/16 的控制跨度向右移动半个跨度，使其跨越真实边界。逐层比较真实
跨度与移位跨度投影误差并平均，得到 $Adv_{tree}$。

逐层用验证集拟合

$$
h_p=W(h_l+h_r)/2+b+e,
$$

测试真实孩子与跨父节点置换孩子的残差优势，四层平均得到 $Adv_{comp}$；同时
报告一步理论界及其非空泛比例。

## 4. 预注册判定

令 hierarchy 减 shuffled 的成对效应为 $D_{tree}$ 和 $D_{comp}$。获得支持
必须同时满足：

1. 12 个最终配对中至少 10 个通过能力防护；
2. 两个平均效应都至少 0.05，cluster bootstrap 95% 下界都大于 0；
3. step 0 效应绝对值小于 0.02，最终超过 0.05；
4. $k_\star$ 与 hierarchy 长度 2 有效秩中位数的 Spearman 相关至少 0.8；
5. hierarchy 最终层间转移至少一半具有 $B/\|H_p\|_F<1$ 的非空泛界。

若至少 10 对通过能力防护但两个最终效应都不大于 0 且置信下界不大于 0，判
失败；其他混合结果判证据不足。

## 5. 边界

通过只建立一个受控合成因果例子，不能外推为真实语言生成机制，不能证明预训练
大模型由同一路径形成，也不能证明这些低秩方向在行为上必需。

正式运行前的实现说明：第一次 smoke 未追加 next-BOS，导致 EOS 没有进入模型
输入；该问题在任何注册完整运行前修复，未根据效应大小改变条件、指标或阈值。
