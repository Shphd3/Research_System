# 实验协议草案：首次越界后的表征恢复路径

## 0. 审核摘要

**审核状态：** 待用户确认。确认前不实现、不提交任务、不运行实验。

**目的：** 从完全相同的首次越界状态出发，判断表征训练是直接移动特征中心，还是通过改变未来路由器更新间接帮助恢复。

**主锚点：** `../../../../problem_anchors/06_geometry_proxy_preservation/06_02_partition_preservation_dynamics/subanchors/06_02_04_representation_router_optimizer_codynamics_anchor.md`

**唯一决策问题：** 越界后继续训练表征，是否是临界“特征—竞争专家”边界重新变正所必需的？如果必要，作用是否经由未来路由器更新传递？

**物理先验：** 对固定边界，后续间隔变化只能分解为实际路由器运动 $R$ 与直接表征运动 $C$。若 $C\le0$ 而表征训练仍是恢复所必需的，则其保护作用必须进入未来路由器更新路径。

**实验角色：** 根因审计，不是方法构造。

**主指标：** 越界后冻结表征的配对恢复必要性比例

$$
N_{repr}(re)
=\Pr\left(re_{joint}=1,re_{freeze\_repr}=0\mid re_{joint}=1\right).
$$

该指标直接回答：联合训练本来能恢复的事件中，有多少在删除越界后的表征更新后不再恢复。

**最小设置：** 复用上一轮的一层 Transformer 与一层加权最高分稀疏 MoE；使用全序列语言建模损失、固定功能专家、无位置嵌入、完整范数原始梯度路由更新；32 个随机种子、两个事件背景条件、每个事件继续 50 步。

**三个因果分支：**

1. 联合继续：表征和路由器都继续更新。
2. 冻结表征：只继续路由器更新。
3. 冻结路由器：只继续表征更新。

**机制诊断：** 额外运行“冻结表征并重放联合路由更新”，只用于判断联合路由轨迹能否在没有直接中心运动时恢复，不参与主指标。

**支持间接机制：** $N_{repr}(re)\ge0.75$，冻结路由器同样删除至少 75% 的联合恢复，至少 75% 的联合恢复事件满足 $C\le0$，且联合分支的累计路由器纠偏显著强于冻结表征分支。

**支持表征只在越界前重要：** 越界后冻结表征使恢复率下降不超过 0.10，且配对恢复时间中位数延迟不超过 2 步。

**证据不足：** 少于 32 个随机种子、少于 48 个合格事件、克隆复现失败、预算或梯度来源闭合误差超过 $10^{-5}$、或出现非有限数值。

**不能声称：** 已设计出可部署路由器、已迁移到真实大语言模型、已形成可学习专家专门化、已证明多词元预测收益或真实下游价值。

**审核决定：**

- [ ] 唯一问题与主线一致。
- [ ] “事件单元”和重新进入定义合理。
- [ ] 三个因果分支足以裁定必要性。
- [ ] 中介重放诊断可以保留。
- [ ] 支持、替代与证据不足规则合理。
- [ ] 批准生成英文正式协议、实现、烟雾测试和远程四卡完整运行。

## 2. 锚点对齐

**父结论：** 路由器更新尺度控制早期越界是否可达；仅路由器压力的固定阈值漏掉表征预算；重新进入时直接表征项仍然有害。

**本轮只减少一个不确定性：** 表征训练的总体恢复作用发生在越界前，还是越界后通过未来路由器更新继续发挥作用。

**主线影响：**

- 影响当前假设：是。
- 影响结论边界：是。
- 影响下一方法选择：是。
- 建议：推进。

若支持越界后间接作用，下一方法不能只看路由器本地压力；若表征只在越界前重要，第一种方法可以把越界后控制保持为路由器局部。

## 3. 被检验假设

### H1：越界后的表征训练具有必要性

判据：

- 联合分支临界特征对重新进入率至少为 0.25；
- $N_{repr}(re)\ge0.75$；
- 按种子聚类的 95% 置信区间下界大于 0.50。

### H2：越界后的路由器更新具有必要性

判据：

- $N_{router}(re)\ge0.75$；
- 按种子聚类的 95% 置信区间下界大于 0.50。

### H3：表征通过未来路由器更新间接帮助恢复

H1、H2 均成立，并同时满足：

1. 至少 75% 的联合恢复事件在重新进入时累计直接表征贡献 $C\le0$；
2. 在联合重新进入时间 $T_{re}^{joint}$ 上，至少 75% 的配对事件满足

$$
D_R
=\frac{R_{joint}(T_{re}^{joint})-R_{freeze\_repr}(T_{re}^{joint})}
{m_{f,b_c}(0)}>0;
$$

3. $D_R$ 的种子级中位数为正，95% bootstrap 区间下界大于 0；
4. 中介重放分支的重新进入率满足 $P_{replay}(re)\ge P_{joint}(re)-0.10$。

第 4 条是机制保护条件：若重放失败，则不能把恢复完全归因于观察到的路由更新序列。

### H4：表征只在越界前重要

若联合与冻结表征的重新进入率差不超过 0.10，且两者都重新进入的事件中，配对恢复时间中位数延迟不超过 2 步，则支持 H4。

## 4. 竞争解释

| 竞争解释 | 预期结果 | 被哪项干预区分 |
| --- | --- | --- |
| 路由器单独恢复 | 冻结表征仍恢复，$N_{repr}$ 低 | 联合与冻结表征 |
| 中心直接移回 | 冻结路由器仍恢复且 $C>0$ | 冻结路由器与 $C$ 分解 |
| 越界后两条路径都必要 | 两种冻结都删除恢复，且 $C>0$ | 两种冻结与 $C$ 符号 |
| 表征间接塑造未来路由更新 | 两种冻结都删除恢复，但联合 $C\le0$ 且 $R$ 更有利 | 三分支、$R/C$ 与原始梯度 |
| 之前差异来自失败起点不同 | 同状态分支后差异消失 | 事件检查点克隆 |
| 结果来自克隆或更新顺序错误 | 联合克隆不能复现不中断参考 | 确定性复现保护 |

## 5. 数据、模型、路由与目标函数

### 5.1 数据

- 每批固定 32 条序列；每条序列含 33 个词元，对前 32 个下一词位置计算损失。
- 四个均匀特征，四个固定功能匹配专家。
- 不使用位置嵌入。
- 条件一：8/32 条为均匀特征序列，其余为类别 0 背景序列。
- 条件二：4/32 条为均匀特征序列，其余为类别 0 背景序列。
- 每个训练条件反复使用同一个静态批次，因此越界后的三分支共享完全相同的数据流。
- 主判断只使用特征 1、2、3；特征 0 是背景同类公共特征，仅作补充记录。

### 5.2 模型

- 隐藏维度 64，四个注意力头。
- 一层因果自注意力、残差连接、层归一化。
- 一层加权最高分稀疏 MoE：只执行当前得分最高专家，但保留其路由概率权重。
- 四个固定且功能匹配的专家；专家强度 4.0，读出类型强度 1.0。
- 路由器使用特征中心的对偶方向初始化；初始中心匹配间隔的 5% 分位目标为 0.5。

### 5.3 训练目标

使用所有 32 个下一词位置的平均交叉熵损失：

$$
\ell_{LM}=\frac{1}{32B}\sum_{i=1}^{B}\sum_{t=1}^{32}
-\log p_\theta(x_{i,t+1}\mid x_{i,\le t}).
$$

特征位置和背景位置的损失贡献按相同总位置数归一化，使二者及其梯度精确相加为总损失和总梯度。

### 5.4 更新规则

表征参数使用 AdamW：学习率 0.002，$\beta_1=0.9$，$\beta_2=0.999$，$\epsilon=10^{-8}$，权重衰减 $10^{-4}$。

路由器保持上一轮的完整范数原始梯度规则：先维护完整 AdamW 候选更新及其范数，再把当前负原始梯度缩放到相同范数：

$$
\Delta W_t
=-\lVert\Delta W_t^{full\_AdamW}\rVert_F
\frac{g_t}{\lVert g_t\rVert_F}.
$$

因此本实验研究的是“表征如何改变未来原始梯度和实际更新范数”，不是标准 AdamW 方向本身。

## 6. 条件、随机种子和检查点

### 6.1 事件生成

- 随机种子：0--31，共 32 个。
- 每个种子运行两个背景条件。
- 前置轨迹最多运行 50 步。
- 每个非公共特征第一次出现 $\min_{b\ne f}m_{f,b}\le0$ 时，记录 $t_c$ 与 $b_c$，并在该更新完成后克隆状态。
- 同一个前置轨迹可产生多个特征事件；统计推断按随机种子聚类，不把它们当完全独立样本。

### 6.2 越界后条件

| 条件 | 表征更新 | 实际路由更新 | 用途 | 是否进入主判定 |
| --- | --- | --- | --- | --- |
| 联合继续 | 是 | 是 | 参考恢复轨迹 | 是 |
| 冻结表征 | 否 | 是 | 检验表征必要性 | 是 |
| 冻结路由器 | 是 | 否 | 检验直接表征充分性 | 是 |
| 冻结表征并重放联合路由更新 | 否 | 使用联合分支的 $\Delta W_t$ | 检验路由中介是否充分 | 机制保护 |
| 全部冻结 | 否 | 否 | 零变化实现保护，只运行 1 步 | 否 |

每个因果与重放分支继续 50 步，每一步都记录；不只记录稀疏检查点。

## 7. 主指标

### 7.1 重新进入事件

主事件是固定临界特征对在 50 步内第一次变正。保持与上一轮相同的“第一次变正”定义，避免事后更换指标。

### 7.2 表征冻结必要性

$$
N_{repr}(re)
=\frac{\sum_i\mathbf 1[re_i^{joint}=1,re_i^{freeze\_repr}=0]}
{\sum_i\mathbf 1[re_i^{joint}=1]}.
$$

主统计以事件为单位计算点估计，以随机种子为重采样单位计算 95% 置信区间。

**为什么它主导决策：** 它直接删除越界后的表征更新，同时保持失败状态、未来批次和路由更新规则一致。若该比例高，第一种保持方法不能假定越界后恢复是路由器局部过程。

**它不能证明：** 表征通过哪一种隐藏方向起作用，也不能证明真实大语言模型需要同样的联合控制。

## 8. 二级指标

1. 路由器冻结必要性 $N_{router}(re)$。
2. 临界特征对和特征级重新进入率、首次重新进入时间。
3. 联合重新进入时的累计 $R$、$C$ 和有限步闭合误差。
4. 联合与冻结表征之间的 $D_R$。
5. 总损失、特征位置损失、背景位置损失对应的 $v^{raw}$、梯度范数和实际边界投影。
6. 完整候选更新范数、实际更新范数和路由器动量状态范数。
7. 路由身份、特征路由归一化互信息、最小中心间隔和语言建模损失。
8. 重放分支重新进入率。

原始梯度指标用于进一步区分：联合分支的优势来自更有利的梯度方向、较大的纠偏范数，还是二者共同作用。该区分是解释层，不改变 H1 主判定。

## 9. 已知正常、已知异常和易混淆情况

### 已知正常

- 联合克隆应逐步复现不中断的联合参考轨迹。
- 全部冻结后，参数、中心、$R$、$C$ 和间隔应保持不变。
- 冻结表征分支的 $C$ 应为 0；冻结路由器分支的实际 $R$ 应为 0。
- 总损失来源梯度应等于特征位置梯度与背景位置梯度之和。

### 已知异常

- 克隆后第一步前，三个因果分支的损失、间隔、原始梯度或优化器状态不同。
- 联合克隆与不中断轨迹在无随机算子的条件下发生可见偏离。
- 固定临界竞争专家在分析过程中被静默替换。

### 易混淆

- 临界特征对重新进入不等于该特征对所有竞争专家都安全，因此同时报告特征级重新进入。
- 中介重放使用联合未来信息，是因果诊断，不是可部署算法。
- 完整范数原始梯度规则只固定了路由方向家族；其更新范数仍由历史 AdamW 候选状态决定。
- 多个特征事件共享同一随机种子，不能按普通独立样本计算置信区间。

## 11. 实现合同

### 输入

- 上一轮配置与模型实现；
- 两个背景条件；
- 32 个随机种子；
- 前置 50 步和越界后 50 步。

### 事件检查点必须包含

- 模型参数与缓冲区；
- 表征 AdamW 的 step、exp_avg、exp_avg_sq；
- 路由器传递器的 step、exp_avg、exp_avg_sq；
- 随机数生成器状态；
- 当前静态批次标识；
- $t_c$、$f$、$b_c$、越界前后间隔；
- 初始成对间隔，用于归一化。

### 每步顺序

1. 在当前分支状态上前向计算全序列损失。
2. 计算总损失、特征位置和背景位置的路由器原始梯度。
3. 保存更新前路由权重、特征中心和成对间隔。
4. 根据分支决定是否应用表征 AdamW 更新。
5. 根据分支决定是否应用路由器更新；冻结路由器时只更新影子诊断状态。
6. 重新计算中心和间隔，写入 $r$、$c$ 与闭合误差。
7. 更新重新进入事件与时间。

更新顺序必须与上一轮保持一致：路由器原始梯度在同一次前向状态上计算，随后先应用表征更新，再应用由该原始梯度决定的路由更新。
