## Current Decision

Keep A14's global shared-linear propagation claim closed and retain the
controlled conditional-functional-rank theorem. E04 supports the local
trained-point Jacobian image, while E05/E06 decisively refute using one point
Jacobian for the full training displacement and support an effectively
low-dimensional exact learned secant. The finite theory now uses the
secant/path-integrated image; the next mathematical question is when NTP
dynamics derive that finite image. A14_02's original shared-composition surface
remains archived for rank interpretation. Revised E02 establishes registered
within-mapping frequency non-inferiority in 10/10 pairs; E03 stops before full
treatment because the raw common AdamW-space gate passes 0/10. Router
architecture design remains parked.
