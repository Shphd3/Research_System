specialization.


## Role

This line defines what must be separated before any method claim is valid:

```text
same-feature route consistency
non-collapse
feature identity
route-function binding
causal expert utility
```

It is not a method line. It supplies the claim boundary inherited by the 05
failure-mechanism line, the 06 proxy/preservation line, and the 07 value line.

## Current Boundary

High route consistency or high route-label agreement can show alignment, but
it cannot by itself prove useful expert specialization. A useful partition must
eventually show that the selected expert has causal value for the routed
feature.
