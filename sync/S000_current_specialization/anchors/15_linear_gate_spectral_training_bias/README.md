# A15: Linear Gate Spectral Training Bias

Status: Q1 E01/E02 evidence is recorded. E03-S passed the controlled
covariance-causality test, whereas E03-R is `insufficient_load_guard`: real
DCLM routing collapsed before the registered formation comparison was valid.
The shallow four-layer pilot is `insufficient_stage_a_capability` because its
admission task saturated for both spectral and random views. A15_02_01_E01
separately completed with an operational Pass and scientific Fail, so
A15_02_E02 remains blocked. The two Q1 common/residual mechanism subanchors
have now completed with a joint Pass: centered top-64 transfers more strongly
than local residual-64, both projectors are highly shared across random
document shards, and the trained Gate prefers the pooled component. A15_04 and
A15_05 have now completed: selected-expert feedback is sufficient to lock a
head-first partition in the controlled task, whereas low variance delays but
does not randomize a learnable route. A15_01_02 has now completed with Pass:
a capability-valid four-layer hierarchy shows reproducible layer-specific
F1-intermediate and F2-coarse identities, while the composed result is not
localized to a fixed covariance band. A15_01_03 has also completed: natural
coarse/fine concept sets differ descriptively, but the same-lexeme parent/child
effect does not replicate across the current MoE and Qwen3-8B, so covariance
rank is not a validated universal semantic hierarchy coordinate. A15_01_05
now adds a balanced Qwen3-8B hierarchy: conditional fine classes become
relatively more discriminable in late blocks, while that gain is broad across
the spectrum rather than specific to middle/tail covariance ranks. The line
is now registered in `PROJECTS.md` but not in the project graph. A15_01_06
further localizes semantic concentration to sparse true pre-`o_proj` heads:
maximum head statistics pass global random repartitions, whereas typical heads,
fixed contiguous MLP-input groups, and fixed within-head eight-band identities
do not.

The condition-stratified follow-up now refines “shared residual” into
document-local modes inside a broad shared envelope: exact document projectors
vary substantially, while coarse domain/topic labels explain only a small,
reproducible part. A15_03 has also completed all nine matched 2B arms with
Fail/distribution-only: fixed H/M/T/N views change dispatch, but no true band
beats native held-out NLL.

A15 asks how much a trained linear MoE Gate can access and currently use the
head, middle, and tail covariance bands of its actual Router input, when strong
head alignment is already present, and whether saved Gate-weight changes
sharpen or broaden it after input-energy and representation-drift rivals are
separated.

## Current Boundary

E01/E02 establish strong actual-input equal-energy head alignment, nonzero but
weaker middle/tail access and use, and saved-interval Gate/basis decomposition.
The alignment is already strongest at 10k and then broadens relatively through
30k. They cannot establish its exact pre-10k onset, per-step gradient cause,
middle/tail functional utility, or spectral-dispatch training benefit.

A15_00_01 now separates two statements. Under a fixed functional target, pure
SGD learns higher-variance directions sooner; flat and whitened spectra remove
that timing preference, so covariance anisotropy is causal in the controlled
system. In the real no-load-loss DCLM run, all three seeds instead crossed the
registered 0.8 load-share guard before a valid spectral-formation conclusion;
that is insufficient evidence, not a refutation of the controlled result.

A15_01 is a separate sibling parent because compatibility and matched-compute
utility are outside A15_00's decision boundary. Its four-layer pilot is a true
subanchor of that functional parent. The pilot's coarse target was perfectly
decoded by every random 64-dimensional view, so it cannot distinguish shallow
head specificity and did not authorize downstream guided training.
The repaired A15_01_02 profile shows that composition reorganizes deeper
information into an F1-intermediate and F2-coarse pattern, whereas the composed
result is readable from the full deep state but not specific to a fixed
covariance band. Native Gates still use F1/head almost exclusively, so encoding
identity is not yet a routing-utility certificate.

A15_01_05 gives the corresponding natural hierarchy result in Qwen3-8B.
Fine-class discriminability relative to coarse-class discriminability rises
reproducibly in late blocks and does not reverse at block 36. Both roles remain
actual-variance head dominant, while the fine-relative gain spans nearly all
bands and fails the registered middle/tail specificity and random-orientation
gates. This is a depth-dependent semantic organization result, not a fixed-band
routing certificate.

A15_01_06 separates architectural-head identity from arbitrary same-sized
coordinates. Sparse pre-`o_proj` attention maxima exceed global random 32×128
repartitions for coarse, fine, and fine-relative discriminability, but attention
medians do not. Fixed contiguous MLP-input groups fail the same specificity
test, and qualified attention candidates contain no fixed 16-d covariance band
that exceeds matched random orientations. This supports sparse head-level
localization on the current taxonomy, not universal head identity or a spectral
Router coordinate.

A15_02 is another sibling parent. Its child A15_02_01 owns only the one-step
compatibility admission metric. That child completed with Fail: static
neighborhood novelty was substantial, but no fixed M/T/N band supplied a
stable compatibility increment beyond native controls and the registered
direction controls in both LB and decommon. The parent alone owns the terminal
matched-FLOP held-out NLL claim, but no candidate unlocked that test.

A15_00_02 and A15_00_03 have completed with a qualified joint Pass.
De-meaned centered top-64 transfers more strongly across documents, but the
local residual-64 also transfers above its matched null. Direct projector
overlap is 0.76--0.79 for centered top-64 and 0.70--0.73 for residual-64,
versus random q95 near 0.09. The trained Gate prefers the pooled component in
equal-energy gain and native-margin support. This is a model-level
geometry/use result, not a semantic or training-utility result.

A15_00_04 refines that shared-geometry statement. Condition-aggregated
residual projectors remain highly transferable, but document-specific
rank-64 projectors overlap only about 0.30. A disjoint-token guard shows this
is not primarily finite-token estimation noise. Same-domain documents are only
slightly more aligned than cross-domain documents, while both are far above
Haar. The supported model is document-local or latent modes inside a broad
shared envelope, not isolated domain residual spaces.

A15_03 completed with Fail/distribution-only. All nine 8×RTX5090 arms reached
2.000683B tokens with valid compute/load/replay guards. True H/M/T/N altered
frozen routes by 4.98%--21.88%, yet each had strictly worse paired held-out NLL
than native. Only head beat its equal-rank random control and it still lost to
native. Fixed covariance-rank identity is therefore a dispatch control, not a
validated expert-learning objective.

A15_04 completed with Pass. With identical Router streams and matched expert
compute, oracle-functional expert coverage increased M/T fine correction from
0.500 to 0.977; the paired effect was 0.477 [0.476,0.479], and all seeds showed
the incumbent-advantage/challenger-starvation direction. A15_05 rejected the
strong random-like-tail conjecture: native H/M/T all reached correct persistent
routing in 32/32 seeds, but restricted mean stability time increased from 552
to 912 to 1,938 steps. Equalized T required 615 steps, while label-free random
T remained at 0.501 accuracy with zero functional crossings. These are
controlled mechanism results, not real-DCLM utility claims.

## Exactly One Next Decision

Decide whether to replace fixed covariance-rank Router targets with a directly
functional coordinate that predicts expert-update compatibility or task
utility. A candidate—such as the replicated A15_01_02 layer-specific
functional readout—must first beat native score, equal-dimensional random,
token-shuffled, wrong-layer, and batch/norm controls on independent tokens.
No further fixed band-only large training is justified. No graph edit, root
publication, commit, or push is authorized by this state.
