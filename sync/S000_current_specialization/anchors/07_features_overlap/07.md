# A07 Nested Singular Interference Mainline Anchor


## 1. Problem Definition

**Parent problem:** A07 asks whether preserved expert partitions have functional value by reducing feature interference.

**Sharper subproblem:** Before testing MoE utility, reproduce the mentor mechanism on a nested surface: frequent parent features form a stable high-gain common subspace that later tail features may overuse.

**Decision question:** Can our nested benchmark reproduce stable common-subspace formation with continued late singular-gain growth under standard cross-entropy training?

**Not in scope:** proving C3S-AdamW, proving MoE utility, claiming natural-language semantic experts, or optimizing a method.

## 2. Physical Priors

**P1: Nested features create temporal order.**  
Meaning: $A$ appears more often than $AB$, $ABC$, and $ABCD$, so the parent feature should stabilize earlier.  
Could be wrong if: child targets are independent markers or the model can solve each level without reusing the parent.

**P2: Singular learning has two phases.**  
Meaning: a matrix first rotates a singular direction toward a useful feature, then keeps increasing the singular value after the direction is stable.  
Could be wrong if: direction drift and gain growth do not separate in checkpoints.

**P3: Interference is an update-space problem.**  
Meaning: bounding hidden representations or balancing routes is insufficient unless the actual update direction stops being dominated by the common subspace.  
Could be wrong if: tail loss is unrelated to $P_C$ update concentration.

## 3. Falsifiable Hypotheses

**H1: Common backbone reproduction.**  
Supported if: after common warmup, $P_C$ is stable while common singular energy continues to grow.  
Weakened if: the top common subspace keeps drifting or never gains energy.

**H2: Nested dependency validity.**  
Supported if: child levels cannot be solved by an independent rare marker or shortcut.  
Weakened if: a shortcut-only probe solves $ABCD$.

**H3: Tail absorption target exists.**  
Supported if: tail updates show measurable concentration in $P_C$ after the backbone forms.  
Weakened if: tail updates mostly live outside $P_C$ or are too noisy to measure.

## 4. Mathematical Model

**Objects:** nested levels $\ell \in \{A, AB, ABC, ABCD\}$ with frequencies $\pi_A \gg \pi_{AB} \gg \pi_{ABC} \gg \pi_{ABCD}$; selected matrix block $W(t)$; common projector $P_C$ estimated after warmup $T_0$.

**Core decomposition:**
$$
W(t)=\sum_i \sigma_i(t)u_i(t)v_i(t)^\top,\qquad
P_C=V_CV_C^\top.
$$

**Mechanism relation:** common examples estimate $P_C$ early; cross-entropy can continue increasing $\sigma_i$ inside $P_C$ after $P_C$ is stable.

**Observable metrics:**
$$
\delta_C(t)=\|P_C(t)-P_C(T_0)\|_2,
$$
$$
S_C(t)=\sum_{i\in C}\sigma_i(t)^2,
$$
$$
\alpha_{\mathrm{tail}}(t)=\frac{\|P_Cu_{\mathrm{tail}}(t)\|^2}{\|u_{\mathrm{tail}}(t)\|^2+\epsilon}.
$$

**Falsifier:** no stable $P_C$, no late gain growth, or tail behavior explainable without nested dependence.

## 5. Computational Realization

**Input objects:** nested-prefix dataset, common/child level labels for audit only, checkpoints, selected matrix blocks such as $W_{\mathrm{out}}$, $W_Q$, and $W_K$.

**Computed variables:** common accuracy, tail accuracy/loss, $P_C(t)$, $\delta_C(t)$, $S_C(t)$, $\alpha_{\mathrm{tail}}(t)$, shortcut probes.

**Algorithm stages:** construct nested data; train standard AdamW/CE baseline; estimate $P_C$ at common warmup; profile singular drift and gain; audit shortcuts and tail update concentration.

**Stage-local evidence:** data validity table, checkpoint singular spectra, drift/gain curves, tail update projection table.

**Expected artifacts:** one protocol, then `summary.md`, `detailed.md`, `tables/`, and `figures/` under a new A07 nested experiment folder.

## 6. Minimal Falsification Tests

**Test: mentor-mechanism reproduction.**  
Question: does CE/AdamW create a stable common subspace whose gain continues to grow?  
Intervention / comparison: standard CE/AdamW on nested data; balanced or shuffled nesting as guards.  
Primary metric: late gain growth under stable $P_C$, i.e. $S_C(T)-S_C(T_0)>0$ while $\delta_C(t)$ stays small.  
Pass / fail / insufficient: pass if the pattern appears and shortcuts fail; fail if no stable-gain pattern appears; insufficient if nesting is not auditable.  
Why it decides: it tests whether our surface can reproduce the mentor mechanism before method work.  
Failure means: the A07 surface or the imported mechanism is wrong for this setup.

## 7. Current Evidence

**Observation:** A07_01 nested full run supports the common-backbone reproduction gate: pass rate `1.0000`, post-warmup drift `0.1373`, late gain `1.5115`.
**Interpretation:** the mentor's two-phase common-backbone mechanism is reproducible on a controlled rank-one nested surface.
**Boundary:** this is not a wide-transformer or real-language claim.
**Evidence links:** `../../experiments/A07/A07_01_nested_common_backbone_reproduction/summary.md`.

**Observation:** A07_02 nested full run supports update-space control on the same surface: combined control improved tail loss by `0.1075` and reduced $\alpha_{\mathrm{tail}}$ by `0.1204`.
**Interpretation:** the cleaner mechanism target is tail update concentration in $P_C$, not route load or route-level conflict alone.
**Boundary:** this is not full C3S and not real-DCLM utility.
**Evidence links:** `../../experiments/A07/A07_02_nested_tail_common_subspace_control/summary.md`.

**Observation:** A07_03 nested full run passed only as a positive-control utility diagnostic: oracle route selectivity `0.5699`, random route selectivity `0.0107`.
**Interpretation:** fixed-route ablation can read route-function binding, but it requires a preserved partition before real utility claims.
**Boundary:** oracle route-function binding does not solve A06 preservation.
**Evidence links:** `../../experiments/A07/A07_03_nested_route_function_binding/summary.md`.

**Observation:** The mentor documents provide the theoretical chain and proposed diagnostics for nested-prefix learning, two-phase singular learning, and common-subspace update suppression.  
**Interpretation:** A07 now has a controlled local reproduction of that chain.  
**Boundary:** the documents plus this run do not prove natural-language semantics.  
**Evidence links:** `../../../../../daily_research_reports/backup/2026/06/0625/docs/c3s_adamw_merged_rigorous_proof_with_negative_results.md`, `../../../../../daily_research_reports/backup/2026/06/0625/docs/two_phase_singular_mode_learning_proof_and_test.md`.

**Observation:** Prior hierarchy and D07 runs support controlled route-utility and conflict-audit tools.  
**Interpretation:** They are useful legacy diagnostics but do not establish nested singular interference or real-DCLM utility.  
**Boundary:** Old hierarchy/D07 evidence cannot support claims about language-like nested feature learning.

## 8. Claim Boundary And Next Decision

**Can claim:** A07 has controlled rank-one evidence for nested common-backbone formation and update-space tail control.

**Cannot claim:** full C3S works, MoE separates real nested features, route preservation is solved, or real language experts exist.

**Next decision:** return to A06 preservation; only after a route/proxy partition survives early training should A07_03 be applied as a real utility audit.
