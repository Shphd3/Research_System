## Role

This line tests whether common or high-frequency directions can dominate score
mass while contributing too little rare-target discrimination.

It can inform A06 route-state formation and A07 utility diagnostics, but it
does not by itself prove that a MoE routing method works.

## Current Boundary

Controlled evidence can support a measurable common/rare mismatch. A method
claim needs both the mechanism metric to move and rare loss to improve under
guards against capacity, random split, and load explanations.
