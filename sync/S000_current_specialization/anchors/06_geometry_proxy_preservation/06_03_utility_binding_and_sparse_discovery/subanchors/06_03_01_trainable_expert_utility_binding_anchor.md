# A06_03_01 Trainable Expert-Utility Binding

Thinking Card source: [06_03_utility_binding_and_sparse_discovery_thinking_card.md](../06_03_utility_binding_and_sparse_discovery_thinking_card.md)
Status: completed subanchor.

**Parent:** [`A06_03`](../06_03_utility_binding_and_sparse_discovery_anchor.md).

## Local Clause

Feature specialization requires experts to develop different conditional
utility before the Router can learn a meaningful assignment.

## Falsifiable Question

When experts are trainable, does staged expert formation followed by Router
release create a stable specialist-generalist utility gap?

## Evidence And Verdict

The controlled expert-training and release experiments show that a supplied
partition can create conditional utility differences, but Router release can
still lose the binding when feedback is incomplete or the rank is wrong.

**Disposition:** retain as the bridge from geometric partition to functional
specialization.

**Boundary:** this does not show spontaneous discovery from random top-1
routing.
