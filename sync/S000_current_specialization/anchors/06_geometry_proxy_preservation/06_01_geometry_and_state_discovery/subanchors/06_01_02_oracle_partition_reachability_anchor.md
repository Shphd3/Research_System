# A06_01_02 Oracle Partition Reachability

Status: completed subanchor.

**Parent:** [`A06_01`](../06_01_geometry_and_state_discovery_anchor.md).

## Local Clause

When the correct routed-state population is supplied, a linear Router can
realize the intended uniform-feature partition.

## Falsifiable Question

Is the failure caused by insufficient linear Router capacity?

## Evidence And Verdict

Route-position feature centers produce perfect feature agreement, balanced
usage, and positive margin in the controlled task. Replaying multiple slot
lengths preserves the result, rejecting a one-token positional artifact.

**Disposition:** retain as the positive control inherited by all discovery
methods.

**Boundary:** this is an oracle reachability result. It does not show that the
correct states or centers can be found without privileged information.
