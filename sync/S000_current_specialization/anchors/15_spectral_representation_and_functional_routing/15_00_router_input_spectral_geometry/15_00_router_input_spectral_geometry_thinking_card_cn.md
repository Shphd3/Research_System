# Thinking Card：A15_00 线性 Gate 对 covariance 频带的访问与训练分配

> 状态：研究者在 2026-07-30 明确修订判断，并授权形成正式 Protocol 审核稿。
> 本卡保留研究者的机制判断；公式、阈值和实验拆分属于后续 AI 建议，
> 不是已经确认的人类结论。

## 我的判断

- **具体现象：** 核心不是预设 Router “只看谱头”，而是判断线性 Gate 对
  实际 Router 输入的 head、middle、tail 各有多少访问和实际决策使用；相对
  head，middle/tail 在训练权重变化中是否得到更弱的分配。
- **机制猜想：** 大奇异值方向会机械放大 logit 响应，训练也可能把更多
  等能 Gate 增益分配给这些方向；middle/tail 可能并非不可见，而是当前响应、
  决策影响或净权重更新相对较弱。
- **最强替代解释：** 谱头 logit 响应大完全来自输入 covariance 特征值更大；
  或者训练期表面趋势来自 Router 表征基底漂移，而不是 Gate 权重把增益更多
  分配给谱头。
- **最不确定的一环：** 如何把“看得到”“当前用于路由”“训练中获得更大
  权重变化”和“用于分发后有功能效用”分开；前三者可由冻结 checkpoint
  审计，最后一项需要独立功能干预。
- **什么证据会改变判断：** 在真实 Router 输入上，完整 coarse/fine 频带
  数据显示 middle/tail 的等能增益和决策影响不弱于 head，或 30k--40k、
  40k--80k 的净 Gate 位移不稳定偏向 head；反之，若两个区间都把增益稳定
  更多分配给 head，并增强固定基底的 endpoint 对比，则支持晚期训练偏头。
- **当前唯一决策：** 审核并批准或修改一个只回答访问、当前使用和训练分配的
  Q1 冻结 Protocol；“用 middle/tail 分发有什么功能效果”留给后续独立
  Protocol。

## AI 审核

- **唯一未定义对象或隐藏假设：** “效用较弱”若指 loss 或共同训练兼容性，
  冻结几何审计不能回答；本 anchor 只能把它操作化为较弱的等能增益、实际
  响应、决策影响或净权重变化。
- **最小反例或区分实验：** 使用直接 hook 的 Router 输入，在 30k、40k、
  80k 上同时给出 coarse 三带与 fine `12×64` 的 $V/S/G$；对两个训练区间
  分别测净 Gate 位移，并用 $W_{30/40/80}\times U_{30/40/80}$ 交叉分离
  Gate 权重变化与表征基底漂移。
- **AI 建议：** pursue。把“看得到”“当前使用”“训练分配”和“功能效用”
  分层；E01 只裁定前三项，后半部分不由静态结果替代。
