# A15_08_04 Thinking Card：不同层对象定义的谱敏感性

- **父方向：** A15_08 同 token 层更新与后续表征分析。
- **现象：** 既有汇报中，相邻 Attention 输出差、相邻 MLP 输入差、同层 $U=Z-X$ 和 residual 状态得到的谱秩并不一致。
- **当前判断：** Unknown；先不判断哪一种对象“更正确”，需要在同一模型和同一批 token 上对齐比较。
- **机制猜测：** RMSNorm、residual 累积以及相邻层差分混入的计算不同，可能系统改变 token 协方差谱。
- **最强竞争解释：** 底层表示的低维结构对 hook 和 RMSNorm 基本稳健，已有差别主要来自数据、样本数或绘图尺度不同。
- **最不确定点：** “低秩/高秩”观察究竟来自模型表示，还是来自被选择的层对象。
- **会改变判断的证据：** 同一批 2,048 个 DCLM token、同一次冻结模型 forward、同一中心化和坐标尺度下，八类对象的完整谱、$r_{80}$ 和 effective rank 对比。
- **当前阻塞：** 不先做对象对齐，就不能把学长的相邻层谱、当前 $U$ 谱和 MLP residual 谱当作同一结论比较。
- **当前下一决策：** 判断谱秩是否对 hook/RMSNorm 定义敏感，从而决定后续报告必须固定哪一个对象。
- **来源：** 研究者于 2026-08-17 明确批准八类对象、2,048 个 DCLM token、全层曲线和总对比图。
