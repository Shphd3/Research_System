# A17_04 R05：候选保留与条件残差分配

## 1. Problem Definition

保留已学模型中的选定方向，能否帮助它学习改变后的条件规则？在相同保护策略下，按可见模式分开其余更新，是否有额外效用？本轮通过一条有界验证链，从选择性更新推进到真实专家及可学习路由，回答这一决策。**候选**指被选中的参数方向，不是已识别的共同功能。**保留**指学会新任务时仍能正确完成旧任务。**分配**指改变各模式能更新哪些残差参数。

现有[条件映射owner](../../../../../../../../../UNAVAILABLE.md)确立了局部问题：可见模式足以区分相反的两套口令规则，但仅学习反转新规则的共享训练丢失了旧规则。联合训练能够学会两者，因此既未证明必须分开参数，也未识别出共享功能分量。当前不确定性是：选择性保留与条件分配，能否带来超过整体减速、容量变化或路由信息的收益？

本文件是既有17_04 owner中的轮次修订，不新设编号，不替换Focus。分配问题继续归[17_04_02](../../../../../../../../../UNAVAILABLE.md)；其历史低秩协议和结果保持原样。研究者上传的Prompt V3已授权0/A–F的实现、常规参数选择、有界训练、修复与分析，无需逐阶段人工审核。执行授权不代表科学假设得到支持。父/子问题的机制接受与关闭仍为`Unknown`。

主要载体是已学会可见模式列表任务的Qwen3-0.6B **Base**。attention实验与后续原生前馈专家实验是不同科学对象。D/E是独立桥接诊断，不能声称attention结果已经推出其成立。支持只推进得到支持的一环；不支持时保留对应普通基线；学习资格不足时该环无法裁定，并继续独立阶段。只有对旧频率方案原资产实际执行匹配干预，才能讨论其因果解释；否则不属于本轮已回答内容。

## 2. Physical Priors

以下是AI根据研究者方向给出的操作性假设，不是已观察机制。

1. 条件规则改变后，部分已学计算可能仍有用。减少不必要的参数移动可能保护它们，但大奇异值本身不标识这种计算。
2. 共享模型能够表达两任务，不代表两任务所需更新相同。参数隔离可能有帮助，也可能同时改变有效容量、更新频率与优化。
3. 选择专家所需的信息可能少于执行计算所需的表征。被保留的方向未必包含这种选择信息。

参数正交是关于指定矩阵内积的精确关系。功能独立、训练中的干扰以及泛化都需要实证。

## 3. Falsifiable Hypotheses

核心假设是：预先登记的候选与分配策略，在学会任务的前提下，能取得超过匹配普通对照的旧新效用。每个阶段检验一个必要环节或独立有用的环节；不能由一个好结果接受整条链。

| 阶段 | 检验什么 | 最强竞争解释与区分对照 |
|---|---|---|
| 0 | 载体、普通学习器和读数足以承载比较。 | 实现或习得失败：先复现父模型与普通全矩阵对照，再解释受限方法。 |
| A | 初始大奇异值方向值得选择性保护。 | 整体减速或任意子空间约束：七臂包含统一小步/调度、随机、尾部和top恒定对照。 |
| B | 相同保护下，按模式分开残差更新有额外效用。 | 容量增加、每模式空间或模式信息：共享/分开×正常/保护，另有全矩阵共享与匹配总自由度对照。 |
| C | 仅用TRAIN重选候选优于固定候选。 | 只是重置优化器、重参数化或放松约束：比较真实重选、固定与假重选/重置。 |
| D | 多个真实专家优于单残差及普通MoE。 | 容量、初始化、活跃计算或模块变化：保留普通及无保护结构，重新资格FFN载体。 |
| E | 路由器能选到有用专家，候选摘要能保留效用。 | 只会预测人工模式或改善负载：固定专家比较oracle、平衡随机、完整hidden、候选摘要及等维随机摘要，再联合训练。 |
| F | 有界效用模式可扩展到列表任务之外。 | 人工任务特有：用已有自然文本留出数据、明确隔离和普通对照检验。 |

在相同起点，某模式的有限更新使另一模式留出损失上升，提供的是局部干扰证据。分开模型的终点更好，不能单独证明干扰造成了整个训练差异。A阴性后仍可检验动态或专家效用，但这些方向继续称为候选。

## 4. Mathematical Model

一个样本含可见模式、中性口令和三个不同列表词，目标是下一个答案token。旧模式第一口令选FIRST、第二口令选LAST；反转新模式交换答案。模式可见使两套规则能够共存。实际模型重新计算原生attention；Q/K/V改变时，不能用固定输入的线性输出近似替代完整前向。

对每个已习得矩阵\(W_0\in\mathbb R^{m\times n}\)，取成对奇异向量\(u_i,v_i\)，把选中的矩阵原子定义为\(B_i=u_iv_i^\top\)。这些原子在Frobenius内积下正交归一。给定固定秩\(k\)，定义

\[
P(X)=\sum_{i=1}^{k}\langle B_i,X\rangle_F B_i,
\qquad C_t=P(W_t),\qquad R_t=(I-P)(W_t).
\]

内积是逐元素乘积之和。投影和重构恒等式是需要数值验证的数学性质，它们定义参数坐标，不定义语义模块。正交补包含交叉方向项，不始终等于当前小奇异值尾部。

令\(d_t\)表示在实际当前权重上，按登记规则裁剪梯度并更新一次动量后，AdamW提出的完整位移。\(a_t\)是候选方向移动倍率，实际应用

\[
W_{t+1}=W_t+a_tP(d_t)+(I-P)(d_t).
\]

正交补保留基础更新。这过滤的是包含Adam坐标缩放的**实际候选位移**；只缩原始梯度是另一种干预。\(a_t=1\)时必须复现普通AdamW。参数移动本身不是效用指标。

B把模式对应的有效attention矩阵写作\(W_m=W_0+\Delta C+\Delta R_m\)：\(\Delta C\)在候选子空间内，各残差在其正交补内。共享条件使用同一残差；分开条件使用独立残差。复制完整残差保持每模式空间，却使残差存储坐标翻倍；匹配总自由度的分区对照会改变每模式可用空间。两者是不同口径，不能同时声称匹配了总存储与每模式容量。Protocol规定可构造的mask/投影及其实际秩，不能假定mask合成后仍正交。

独立FFN桥接使用末层原生SwiGLU：\(\operatorname{down}(\operatorname{SiLU}(\operatorname{gate}(h))\odot\operatorname{up}(h))\)。gate/up共享且冻结；每个被选中的down投影为\(W_i=C+R_i\)。原生门控非线性先于这一线性映射。这是在一个线性位置共享参数，不代表整个SwiGLU非线性函数已拆成共同与残差分支。

**有日期的资格修订：2026-10-22 16:41:48 UTC，R2。** 保留上面的仅down训练方案作为R1。R1五个D臂均未通过学习资格后，使用唯一允许的修订，把专家扩展到完整原生gate/up/down。对三张矩阵分别固定初始top16投影，并在原线性位置内合成共同候选与私有补空间权重。输入改为\(x=\operatorname{post\_attention\_layernorm}(h)\in\mathbb R^{1024}\)，gate/up也在各专家内训练。完整专家有9437184个矩阵元素，R1仅down为3145728。完整router读x1024，候选/随机摘要仍为16维，各router都增加相同64单元SiLU隐藏层。这是新的资格族，不能单独归因于哪张新增投影或router非线性必要。零增量初始化仍复现原始原生FFN。

所有学习条件优化经验答案交叉熵：目标负对数概率之和，除以实际有效目标数。单位为nat/answer；前缀与padding不计分母。自然文本续训采用其自身有效next-token分母。TRAIN可以拟合参数和识别/重选候选。已暴露DEV描述结果，不是未触碰确认集。DEV/test标签不能选择方向、router特征或终点。

## 5. Computational Realization

[来源审计](../../../../../experiments/A17/17_04_conditional_mapping_transfer/rounds/R05_autonomous_retention_20261023/source_audit.md)绑定历史owner及可复用实现。精确设置、选择规则、停止规则和资源核算由本轮[Protocol](../../../../../experiments/A17/17_04_conditional_mapping_transfer/rounds/R05_autonomous_retention_20261023/protocol.md)负责。代码与载荷放在`/data/250010109/MoE_Router/experiments/20261023_autonomous_retention`。

- **0：建立可解释资格。** 复用R02原生四矩阵加载、答案读数、组batch与恢复检查。核验Base/tokenizer/父检查点hash、冻结、重构、一次位移过滤、优化器状态及外部进程下一步重放。复现已学旧规则端点与普通学习，避免把受限学习器失败解释成任务不可达。
- **A：检验选择性保留。** 在看到结果前，从已习得矩阵构造top/tail/random各16个候选。仅用reversed TRAIN续训末层Q/K/V/O。运行普通、统一小步、统一调度、top恒定、top调度、random调度、tail调度七臂。A不重放旧标签，记录候选/正交补位移和旧新预测。
- **B：检验条件分配。** 各臂使用完全相同的old+reversed联合监督。以全正交补参数化替代历史未合格rank-bank，并重新资格。运行共享/分开×正常/保护四臂、普通全矩阵共享参考与总自由度分区对照，披露分开残差的存储翻倍。在相同共享起点、实际幅度匹配下做双向有限更新，区分候选和正交补。A/B监督不同，原始终点不能直接比较胜负。
- **C：检验动态选择。** 比较固定候选、400/800步仅用TRAIN的重选、以及匹配假重参数化/优化器重置。换坐标时保存各模式当前有效矩阵及输出。记录哪些旧方向退出保护并随后更新；切换瞬间守恒不代表它们始终受保护。迁移或重置规则及对应对照保持一致。
- **D：资格真实专家。** 在末层原生FFN down投影处，共享冻结gate/up，使用两个top-1专家。比较独立参数普通MoE、共享候选+一个残差、共享候选+两个残差的正常/保护条件，先用已知模式控制路由。报告总/活跃参数、FLOPs、曝光与初始化；存在额外容量时，收益只能作为有边界的策略收益。
- **E：学习选择专家。** 先冻结合格专家，训练完整hidden、16维候选摘要及等维随机摘要router；保留已知模式oracle与负载匹配随机路由参考。再执行最小联合训练。Protocol必须写清可导门控或估计器、权重、归一化与辅助损失。测实际专家反事实代价/遗憾和任务损失，不只看模式分类或负载。router只看当前表征，不接收next-token目标。
- **F：限定外推。** 使用已有可访问DCLM自然文本，冻结来源身份、训练/留出边界与配对预算。重新资格模块接口和分母。短续训只能提供短预算自然文本证据。必要资产不可访问时，记录精确失败并继续独立任务。若另跑嵌套规则，它仍是人工数据。解释旧A15_24频率路由失败，需要独立回到其原模型/数据/路由做匹配干预。

## 6. Minimal Falsification Tests

先确认资格，再作解释。数值、冻结、数据或恢复检查失败，使对应比较不合格。列表任务要求每个模式×口令×DEV面板cell的全词表准确率至少95%；每cell有200个答案。这是防止均值掩盖某条规则失败的实用约定，不是总体显著性阈值。普通模型失败时阻止依赖性机制裁决，但继续独立可达性测试。

A的主要效用比较是在相同新答案终点，top调度保护对比每个已登记普通/减速/随机/尾部对照，同时要求新任务合格且准确率最多低1个百分点。旧准确率高5个百分点是预登记实用标记。统一减速同效则不能认定选择效用；随机/尾部同效则不能认定top特异性；top恒定同效则不能认定调度必要。不能换成后来好看的检查点挽救主结果。

B主比较是受保护分开残差对受保护共享残差，读最弱模式准确率、学习资格与不退步条件。正常/保护差异及其差之差检验两策略交互。总自由度对照和每模式空间披露，决定正结果能削弱多少容量解释。共享达到天花板时没有终点分开收益；预登记的达到资格曝光量只支持速度描述。

C/D/E分别按登记效用对比假重选、单残差/普通MoE及路由参考。候选重选需超过重置对照；oracle失败先问专家能力；oracle成功而learned失败指向选择信息/优化缺口。F在配对预算下读自然文本留出NLL并保留普通对照。Protocol在结果前定义其辅助读数与实用容忍度。

逐顺序、逐配对样本报告；续训顺序共享一个已习得旧状态。按无序列表组bootstrap只描述样本不确定性，不代表独立模型重复；自然文本按来源block分组。已暴露DEV和反复开发任务限制各阶段为探索证据。缺失比较是证据不足；完成阴性实验仍是完成实验。
