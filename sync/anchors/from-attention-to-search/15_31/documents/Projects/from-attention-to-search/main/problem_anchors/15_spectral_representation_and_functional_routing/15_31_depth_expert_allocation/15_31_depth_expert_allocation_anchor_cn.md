# 跨深度专家容量分配与 token 频率

## 1. 问题定义

在训练曝光相同、计算量尽可能公平的条件下，把固定总量的专家容量从浅层移到深层，能否改善相对低频 token 的学习，并保持整体语言建模能力？研究者于2026年11月6日在 MoE 与长尾学习主线下激活本独立问题。本轮要帮助研究者决定：这种分配是否有足够潜力，值得继续做实体／关系与表征验证。

本轮“低频”指 token 类型在实际共同训练曝光中的计数较低。这是操作性代理。低频 token、低频实体或关系、低频稀疏自编码器特征与语义长尾知识是不同对象。本轮只改变各层专家数，固定残差维度；不检验深层专家是否是独立记忆。

支持结果可推动后续验证；出现权衡则需判断代价；未发现优势会削弱这一具体分配；公平性或数据支持不足则保留未知。上述结果均不关闭更广泛的架构问题。

## 2. 物理先验

**研究者认可的待检验假设，并非既定事实：**不同深度学习信息所需的容量可能不同，均匀分配专家未必最优。导师关于浅层少专家、深层多专家的直觉提供动机。来源是勘误文字转写与会议总结；未提供原音频，待核词仍保留待核。

**实验假设：**专家总数、专家矩阵形状和 top-k 相同，可排除主要的总容量与选中容量差异。但 dispatch、attention、通信、吞吐和墙钟时间仍可能不同。

**测量假设：**仅由训练数据统计的频率，以及独立留出 token 的预测损失，可测量本轮按频率分组的预测行为。它们不能识别语义知识或梯度信噪比。

## 3. 可证伪假设

H1：共同冻结的训练 token 预算下，深层递增组相对均匀组具有更低的低频 token 负对数似然。H2：收益可能不存在，也可能伴随高频或整体损失增加。H3：路由负载与各专家实际接收的 token 数可能改变；本轮测量这些变化，不预认定它们是 H1 的原因。

最强竞争解释是：同量专家重新分配没有低频优势，或只是交换不同频率组的性能。不同初始化、数据顺序、总参数和实际计算量是需要控制或量化的其他解释。仅有负载变化不能识别因果中介。

## 4. 数学模型

模型的每层由因果 attention 与 top-k 独立前馈专家混合构成。令层号为 \(\ell\)，专家数为 \(E_\ell\)，残差维度为 \(h\)，专家中间维度为 \(m\)，每 token 选中专家数为 \(k\)。无 bias 的 SwiGLU 专家有三个矩阵，参数量为 \(3hm\)。固定 attention、归一化、共享组件及绑定的词表接口后，专家与 router 总参数取决于 \(\sum_\ell E_\ell\)，因此匹配该和即可精确匹配两者。跨 \(L\) 层，一个 token 选中的专家矩阵参数为 \(3hmkL\)。router 会计算全部行，不是仅计算选中行。这些是参数恒等式，不是执行开销相同的证据。

判据比较同一组留出位置的预测损失。对频率桶 \(b\)，定义

\[
\Delta_b=\frac{1}{N_b}\sum_{i\in b}\left[-\log p_B(y_i\mid x_{<i})+\log p_A(y_i\mid x_{<i})\right].
\]

A 是均匀组，B 是递增组，\(N_b\) 为合格目标位置数；单位是 nat/token。\(\Delta_b<0\) 表示 B 更好。分桶只使用训练计数，训练未见的类型独立成桶。主估计按 token 加权；按类型平均的诊断必须另行标明。该量本身不说明 token 的语义或路由机制。

## 5. 计算实现

1. **核验账本和共同起点。**复用已检查的原生普通 MoE，只适配逐层专家数和必要记账，并枚举实际参数张量。A 每层8专家；B 为 `[6,6,6,8,8,10,10,10]`，8层分成3／2／3层三个阶段。两组专家总数均为64，残差维度1024、专家宽度1536、top-2固定。共同结构与共同专家身份对齐随机权重；新增或移除专家使用事先冻结的初始化映射，避免暗中比较预训练移植或额外容量。
2. **冻结曝光和测量。**从已核验来源固定训练数据、顺序、去重与切分，统计本轮实际共同曝光，不读取测试答案。最终评估前固定桶并抽查样例。输出独立保存，不修改旧 checkpoint 或语料。文档边界无法恢复时如实报告，不能把序列重采样称为文档级区间。
3. **训练和比较。**在指定4卡 H100 reserved 上短测两组，冻结共同可用的配置和预算，再完成两组。按共同 token 数评估起点、中间和终点，报告分桶与整体损失、区间、实测计算、吞吐、显存和负载。初始化、checkpoint 与数据顺序检查保障可解释性，路由统计仍是观察。

精确流程、配置和运行证据由 [R01 Protocol](../../../experiments/A15/15_31_depth_expert_allocation/R01_paired_token_frequency/protocol_cn.md) 持有。浅层窄、深层宽只列未训练参数草图，不是额外已测组。

## 6. 最小证伪检验

主比较是终点低频 token NLL 的 B−A。报告成对差及双侧95%重采样区间：文档单位需先核验；否则声明实际单位及相关性限制。零是无差异参考，不虚构实用收益阈值。区间仅描述评估采样，不能代替多训练种子。

差值为负且区间低于零，是该代理上存在潜力的证据。须同时报告高频和整体差异，包括代价，不能用更好的次指标挽救主指标。点估计非负表示未观察到低频优势；区间跨零表示符号仍不确定。缺失组、公平性失效、低频覆盖为空或曝光无法核验，使原定比较证据不足。这些分支帮助研究者作下一决定，不自动宣告普遍机制。

## 7. 当前证据

已检查的普通 MoE 为8层、残差维度1024、SwiGLU中间维度1536、每层8专家、top-2；唯一可训练参数共507,988,992，每专家4,718,592，embedding 与输出头绑定。候选成对架构的专家与 router 总参数精确相等。训练前仍须用适配模型的实际张量与前向独立核验。

[会议来源](../../../experiments/A15/15_31_depth_expert_allocation/R01_paired_token_frequency/supporting_sources/meeting_1106_source.md)包含导师直觉与口头既往观察，未给出足以证明本轮分配收益的完整对照、计数或效应数值。独立的 [R17_D1 SAE结果](../../../../../../../UNAVAILABLE.md)保留答案／读出依赖、频率混合未优于两个基线及内容覆盖不足，不能建立深度到频率的机制。

**本轮成对训练及测试在注册时为 NOT RUN。**科学接受与机制判断为 **Unknown**。之后的执行事实与合格观察由本轮结果记录持有。

### R01执行事实（2026-11-06，科学判断待研究者）

A／B已各完成229,113,856个有效预测token、874次更新及起点／中点／终点评估。两组总参数与可训练参数均507,988,992，理论激活参数均281,496,576，数据顺序与预算冻结。终点低频NLL为A12.694702、B12.911912，B−A=+0.217210，按文档成对95%区间[+0.125969,+0.300351]；整体NLL为4.289854／4.304112。该实测结果没有低频优势，同时整体更差。单种子、低频测试1481token、有限语料循环与文档相关性限制保留；未测试语义长尾表征或路由因果机制。科学接受、机制判断与问题关闭仍Unknown。

精确过程、输出资格和独立复核由[R01 Summary](../../../experiments/A15/15_31_depth_expert_allocation/R01_paired_token_frequency/summary_cn.md)与[Detailed](../../../experiments/A15/15_31_depth_expert_allocation/R01_paired_token_frequency/detailed_cn.md)持有。原注册时NOT RUN记录保留为历史；本段新增执行事实，不改写H1–H3或自动选择下一训练。

## 8. 结论边界与下一决定

即使得到正结果，也最多说明在所测数据、分配、token预算和种子下有潜力。不能据此证明语义长尾表征、独立专家记忆、梯度信噪比改善、路由因果解释或所有分层架构优越。负结果也不能否定所有分层架构。

唯一下一研究者决定是：完成的成对 token 频率证据是否值得推动后续实体／关系与表征或功能验证。完成标准是两组冻结预算、完整评估、参数与曝光审计、实测开销、原始指标，以及明确的失败或缺失项。续接从 R01 已记录产物开始；不自动训练下一架构或进行因果干预。
