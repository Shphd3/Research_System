# 下一版浅窄深宽：参数草图，NOT RUN

**这是AI建议的可计算草图，未实现、未训练、未验证。**它落实导师浅层窄、深层宽的直觉，并保留原模型embedding／输出头绑定。是否值得训练仍需本轮A／B结果与研究者判断，不能把账本当收益证据。

8层仍分3／2／3层，hidden为512／768／1024，SwiGLU中间宽度为768／1152／1536，专家数为6／8／10，top-2。各阶段Q／KV heads分别8／4、12／6、16／8，head dim128，沿用原模型Q输出为2hidden、K／V各hidden的接口关系。各层无bias的attention主矩阵共6hidden²，另有QK norm各128；block两个norm共2hidden。各专家参数为3hidden×FFN宽度，router为hidden×E。

输入与输出继续共用同一151,936×1024词表矩阵。token embedding先经无bias的1024→512投影；第3层后以512→768投影整个残差流；第5层后以768→1024投影。每个block内的残差加法维度一致，跨阶段只在block之间做映射。末层与最终norm保持1024，输出直接用原绑定词表矩阵。没有另加未绑定的大词表输出头。投影是新增可训练参数，计入下表；尚未检查训练稳定性。
