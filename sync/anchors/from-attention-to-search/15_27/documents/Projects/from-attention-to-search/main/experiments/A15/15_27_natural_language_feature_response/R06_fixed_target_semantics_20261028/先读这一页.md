# 先读这一页：固定目标词之后，认识改变了什么

**我们问：** 同一个目标词的含义变化，能否让已有feature跨措辞稳定响应，并抵抗对侧代表词的干扰？先回答这点，再看144-token距离；没有新增Attention、层分析、聚类或训练。

**近距认识。** 按预冻结标准，SAE和CrossCoder各26个“概念×feature”对象同时满足：含义方向复现、相关变化超过无关编辑、指定词面诱饵下仍随前景含义。共52个，来自32个留出措辞家族，不是52次独立概念验证；它们是本轮固定词/含义的响应候选，不是通用概念模块。

|目标词与含义|SAE合格／新候选|CrossCoder合格／新候选|
|---|---:|---:|
|plant：植物／工厂|7/8|7/8|
|bank：河岸／银行|4/8|3/8|
|organ：身体器官／管风琴|7/8|8/8|
|bass：鱼／低音乐器|8/8|8/8|

两套各32个新候选，另检验预指定旧f447、f8194，共66个对象；SAE新候选实际涉及30个不同坐标，CrossCoder32个。另5个对象只通过原含义区分及超无关编辑，诱饵未完整通过；9个基础证据不足，包含发现尺度为0、不可估的旧f447。没有对象完整支持反向词面敏感性；未完整合格不等于证明只跟词走。

**真实成功例与反例。** 留出plant_01中，CrossCoder f557在植物／工厂线索下的最后层重构贡献为44.197／0；加入被明确排除的“factory”标签后，植物版本仍为40.038。该对象在8个留出家族均保持方向，支持本轮有限的含义响应。反例是旧SAE f8194：organ_05原始两义为0／3.952，但两种诱饵都为0；整个留出抗诱饵仅5/8家族为正，未达冻结6/8要求，不能只凭显著性改判。[逐字文本与原数值](examples_cn.md)

**远距认识。** 只迁移近距合格对象，运行已冻结的128条同家族远输入。51/52对象的远处“相关减无关”仍满足效应/区间/校正条件；10个出现符合相应条件的近减远差异。后者受近距筛选和句序变化影响，全部是条件性／探索性，不是独立确认的距离衰减；远距也没有再测诱饵。

**两条认识更新。**

1. 固定目标词、扩展独立措辞和候选后，可以找到跨措辞、抵抗指定对侧词的响应；旧45候选未过，不能推出字典没有这些含义。R05/R06同时改变候选、文本和对照，不能把改善唯一归因于固定目标。
2. 这些响应不随距离统一消失，部分保持、部分变弱；旧f447本身也非近强远弱。单个远距失败不足以判定“短程专属”，本轮仍未确认纯距离机制。
