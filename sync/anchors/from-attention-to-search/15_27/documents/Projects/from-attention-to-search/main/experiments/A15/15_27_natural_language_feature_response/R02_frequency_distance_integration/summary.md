# R02: response groups, frequency, distance and two-clue integration

**We study whether fixed SAE features change together under controlled semantic edits, then ask how that response relationship relates to independent activation frequency, clue relocation and joint use of two clues.** Q1, Q2 and Q3 are all **insufficient** this round. Counts, descriptive effects, three figures and failure records are complete.

The [object comparison](../../../../../../../../UNAVAILABLE.md) separates older meanings of hierarchy. Conservative 21 October transcripts were found; the specified 26 October cluster/cosine original was not found within the declared search. Older inclusion graphs directly used frequency. Decoder cosine, label taxonomies, network depth, response dendrograms and this round's two-clue interaction are different objects.

The four combinations use 00 as baseline: 10 changes only clue one, 01 changes only clue two, and 11 changes both. The interaction is 11−10−01+00; it tests whether the two single-clue effects add. Group magnitude is the root mean square (RMS) of member contributions after scaling by the fixed discovery-set scales.

## Two reportable updates

1. Older hierarchies refer to different objects, and some old graphs include frequency in construction. Matched reference members of one response group can differ about 103-fold. Frequency cannot replace a relationship definition.
2. Old context responses reproduce, but do not yet establish different group ranges or semantic height. Target-conditioned support, semantic output correspondence and numerical prefix qualification each require evidence.

**One AI-suggested next experiment:** hold weights, visible prefix and input shape fixed, compare the current SDPA path with a reference attention implementation, and first repair h/z prefix replay under the original tolerance.
