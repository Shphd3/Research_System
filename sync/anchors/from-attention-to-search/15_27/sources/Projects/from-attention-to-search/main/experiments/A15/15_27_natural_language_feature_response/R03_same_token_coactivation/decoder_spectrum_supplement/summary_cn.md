# 固定共激活簇的decoder方向与表征谱：补测首页

**我们在问什么？** 已有共激活簇的成员，写入表征的方向是否相似、落在哪些方差谱段，这些谱段是否能区分独立语义标签？

**已经知道什么？**

- 一个聚类点是固定feature；C03由参考文本中的共激活边得到，不是按decoder或本次句子分组。原始共激活簇R、校正共激活簇C、旧上下文响应簇G02/G04不能混名。
- 在已执行的crane案例中，鸟线索换机器后，C03的f12277从0.01909降到0.01140，f5409从0.03463升到0.04098：同簇不保证同向响应。[先读真实输入和计算](old_analysis_explained_cn.md)
- 旧近远响应有明确的句序、编辑量和稀疏成员边界；它不是整簇语义或专家功能证据。本次没有新模型前向、训练或重新聚类。

**新测量改变了什么认识？**

- 不能把共激活簇直接当作方向相似簇。C03平均decoder cosine为0.00176，匹配随机组中位数0.00049；三组比较校正后q=0.126，尚未确立更相似。同簇f12277/f5409的cosine为0.0262，跨簇f12277/f1478反而为0.0561。[图1](figures/figure1_fixed_groups_decoder_cosine.png)
- 谱位置必须区分方向和实际活动量：同为128维，头部承载参考表征63.5%的方差；C03单位方向平均18.9%落在头部，激活平方贡献加权后为33.6%，两者都不是“语义含量”。频率另列，不参与谱排序。[图2](figures/figure2_decoder_spectral_locations.png) · [同批近远案例](figures/figure3_same_panel_spectral_edits.png)

**还不知道什么？** 哪些谱段含有可留出验证的语义区分信息：已查标签与匹配raw h没有合格配对，分类器和随机子空间分类对照均未运行；前向预算仍为1500/1500。旧参考缓存另有历史Base哈希缺口，谱结果限于可核查来源链，完整边界与缺失计算见[附录](appendix_cn.md)。
