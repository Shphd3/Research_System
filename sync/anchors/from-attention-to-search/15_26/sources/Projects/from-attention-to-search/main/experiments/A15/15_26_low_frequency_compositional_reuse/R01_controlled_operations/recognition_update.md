# Recognition update after R01

Status: AI_PROPOSAL awaiting researcher review. [Facts](summary.md) precede [comparison analysis](result_analysis.md), then [possible causes](mechanism_conjectures.md), then this belief update. Researcher result judgment, mechanism acceptance and closure remain Unknown.

The prior working expectation was that fitting atomic tables would move the central uncertainty to composition reuse. That expectation must be weakened: original-format100%, much poorer changed-format access and weak held-out composition coexist. “Learned” needs a specified calling context; training accuracy alone cannot define callable components.

The core possibility of learning help and actual use remains open. R01 did not obtain its necessary callable-competence starting point, so it is not a general refutation. Complete freezing remains a distinct stronger hypothesis: the tested conditions did not qualify, without ruling out all freezing schemes.

Exposure controls also distinguish operation totals from operation–input joint practice: only registered marginals were matched, so all component-computation exposure was not held fixed.

The practical update separates four levels: familiar-prompt execution; access under new wording; qualified single-forward composition; specific composition changes caused by component changes under qualified behavior. Before composition training the first level is established; second/third guards fail and the fourth is ineligible. Retention is an additional axis: original-format atomic behavior drops after composition, so the parent’s100% cannot be carried forward to the endpoint.

One AI proposed next decision: prioritize establishing cross-context callable components before repeating help and reuse comparisons. If qualified components still fail composition, the uncertainty narrows toward composition computation. If composition improves with the prerequisite, interface conjectures gain support but still require functional controls against generic training. New design, strongest rival and execution scope remain next-round choices.

This record authorizes no new experiment, does not attribute the AI update to the researcher and does not import unmeasured parallel order-V2 results. R01 evidence, thresholds and provenance remain frozen.
