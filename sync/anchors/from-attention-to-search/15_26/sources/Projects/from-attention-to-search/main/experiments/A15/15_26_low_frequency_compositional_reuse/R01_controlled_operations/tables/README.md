# Selected R01 evidence

All accuracy/CE fractions are stored without percentage scaling. Differences are fractions; multiply by100 for percentage points. `all_runs.csv` contains each formal trajectory, including pilot and repairs. `learning_curves.csv` contains milestone measurements, not independent runs. `pairs.csv` contains16 pair means per tested condition (six TEST rows per pair). `help`, `freeze`, `exposure` and `revisions` are paired derived comparisons. `factual_results.json` includes eligibility fields, positive controls and intervention summaries. `coverage.json` records execution coverage; DONE_VALID there refers to successful numerical execution and does not override failed scientific prerequisites. `scientific_coverage.json` explicitly labels each formal trajectory, discovery candidate and confirmation condition by scientific eligibility and failed dependency; it is the scientific coverage ledger.

Displayed percentages and percentage-point differences use two decimals with half-up rounding after removing floating-point noise at1e−10 percentage points; raw fractions are unchanged.

Every row derives from the frozen dataset and native full-vocabulary predictions. Original per-example outputs remain in the execution root. The [Detailed record](../detailed.md) owns interpretation and evidence eligibility. These are selected evidence exceptions, listed in the project curated-evidence manifest.
