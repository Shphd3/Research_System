# AI interpretation: capability and invocation gaps coexist

[中文](ai_interpretation_cn.md) · [Observations](observations.md) · [One next hypothesis](hypothesis_update.md)

The strongest recognition update is to test both global component mastery and availability in composition-related contexts. Order arithmetic is not globally qualified, while fixed matched cases show a large gap between independently correct components and one-pass composition. Symbolic results isolate instability of the same mappings across input contexts at the behavioral level. These are AI interpretations; researcher acceptance of an internal mechanism and question closure remain Unknown.

## Orders: insufficient acquisition does not explain every local failure

Amended parents score66.41/71.09/75.78% on fixed128-case-per-task TRAIN discount audits, versus38.28/41.80/46.88% on full discount validation. Both incomplete acquisition and held-out generalization matter. A small final-minibatch loss cannot replace task evaluation. The one attention+MLP expansion did not establish95% qualification; capacity, optimization and exposure explanations remain unresolved within the bounded setting.

Formatting is separate. Seed29 Base strict multiplication accuracy is0%, but a target-independent first-line-unique-amount diagnostic is92.5%, equal to the amended parent's strict score. That strict-score gain cannot all be attributed to new multiplication. Discount output is100% format-valid in the amended seed29 parent but only38.28% correct. Accuracy is64.8% on125 cases with80/90 multipliers and12.98% on131 with85/95; for the latter, fractional-cent-part accuracy is61.83% and whole-yuan-part accuracy16.03%. This describes error structure without independently manipulating numeric difficulty.

## Independently correct components do not guarantee a correct order

All48 preselected orders per seed are retained. The four cells (all five components correct and BOTH correct; all correct and BOTH wrong; not all correct and BOTH correct; not all correct and BOTH wrong) are respectively(2,29,0,17), (4,27,1,16), and(4,30,1,13). These are post-composition P-J endpoints, not evidence that the original P parents passed the global gate. The diagnostic enriches equal-base controls, uses80% discount, and21/48 canonical S2a inputs overlap atomic TRAIN. It does not create a new qualified population.

The29/27/30 local counterexamples weaken an account attributing every full-order error to failure on the independent component questions. They motivate invocation/sequencing hypotheses, without establishing that identical internal functions already exist and merely need connecting. Prompt-specific mappings, partial arithmetic and whole-composition memorization remain rivals.

Original BOTH accuracy is2/5/5 out of48. Adding the true base amount within the original order wording gives5/3/6; the direction is inconsistent. Providing the true discounted subtotal in a clean S2d prompt gives41/43/43. Paired net gains are39/38/38 cases for S2d and3/−2/1 for true-base input. Information, wording and remaining computation all change. Thus neither a missing multiplication nor a uniquely identified discount mediator explains the gap. The strongest behavioral observation is that a clean downstream-rule input is usually answerable while the complete order context fails to achieve the same performance. Sources are in execution-side analysis/interpretation_support.json.

## Symbolic mappings are unstable across wording

All three parents answer the original256 atomic mappings correctly. The same mappings score16.41/20.70/15.63% in validation wording and6.25/6.25/7.03% in test wording. Validation has224/228/213 format-valid outputs, of which182/175/173 are incorrect; output format alone is insufficient.

Sequential original-wording native calls and the true-intermediate control score100% on96 held-out composition inputs in each seed. With perfect atomic lookup and a closed symbol set, this is expected implementation calibration. Composability is an external task definition. The new observation is context instability, while two-call success distinguishes neither abstract-operation gating from prompt-specific lookup nor reuse within one forward pass.

Two live explanations are an operation that a new context fails to invoke and a learned mapping tied to a particular prompt form. The order counterexamples also retain a sequencing/binding explanation even when individual answers are available.

## Evidence boundary and recognition update

Independent counts, masks, loss synthesis, update scopes and endpoints pass for14 trajectories. Six independent-process reloads reproduce all predictions, and an external-process next update is byte-exact. These constrain save/load/counting-error explanations. Legal incorrect outputs constrain a format-only account, and the complete matched four-cell tables constrain an entirely component-error account. Capacity, budget, optimization, general instruction adaptation and internal binding are not separately identified. Three fine-tuning parents share one pretrained Base; item uncertainty cannot stand in for across-training uncertainty.

No internal candidate reaches qualified independent TEST confirmation; reuse remains UNKNOWN. S3–S6 dependent comparisons are not applicable under the frozen gates, and do not estimate slow-update, exposure or expert utility. The order test also has a93.945% never-add-shipping shortcut, so actual shipping cases and boundary strata remain necessary.

Two updates follow: define mastery together with callable contexts, and allow global acquisition failure and local composition-specific failure to coexist. The [one next hypothesis](hypothesis_update.md) changes atomic context coverage at matched mappings, labels, exposure and optimization budget. If atomic context transfer improves without composition, an invocation-coverage explanation is weakened in favor of binding or independent composition mappings. This is a future AI suggestion, not added training; concurrent R01 retains independent ownership. The [primary literature context](literature_context.md) provides methodology rather than this round's evidence.
