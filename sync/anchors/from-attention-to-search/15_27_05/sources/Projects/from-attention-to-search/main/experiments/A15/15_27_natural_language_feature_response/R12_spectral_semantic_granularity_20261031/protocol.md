## 1. Terminology / Definitions
Spectrum means PCA of centered real model representations, not model weights or feature occurrence. A feature is one A22 native shared-z coordinate. Readability means linear heldout classification; incremental readability is a fixed-head augmentation contrast. Residual means actual h minus complete native reconstruction.

## 12. Known Good / Known Bad / Known Confusing Cases
Known good: complete orthonormal projection preserves full norm; h=reconstruction+residual; frozen logits equal bias+signed contributions+residual. Bad comparator: sum of squared member energies; random split of positions from the same document; fitting scaler on H. Confusing: all-zero feature at a common target is inadequate coverage, not pure lexical identity; source-predicted topic is confounding, not semantic proof.

## 15. Success / Failure / Insufficient Evidence
Support: positive interval for a named band/task or increment survives matched controls and source/scale checks; any coarse-to-fine statement additionally requires a fine-versus-coarse difference. Non-support: adequate precision gives contrary/no meaningful advantage; no significant difference alone is not equivalence. Insufficient: full-space task unavailable, wide intervals, unusable labels, inadequate source/target coverage or failed numerics. Operational5percentage-point difference is a prespecified practical reference, not a researcher scientific truth. Reconstruction loss limits the explainable task claim; a failed text hypothesis is retained.
