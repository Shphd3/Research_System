# R13 原生谱解码协议（中文伴读）

0. 本轮属于 A15_27_05。研究者已授权冻结前向与分析，最多两张既有获准 5090 spot；不训练模型或分类器、不占正式训练资源、不新开对话、不提交发布。CPU 审计后可运行，正式分析由内嵌 smoke 放行。
1. 目的：在固定原生输出接口下观察下一 token 预测恢复；分开准确性、接近原模型、词频及语义阅读。
2. 假设与竞争解释见 anchor 第2–3节。没有预想顺序也是有效结果；词频本身不裁决语义层级。
3. 沿用 R12 官方 Qwen3-0.6B-Base、tokenizer 与 h27 缓存；精确路径／哈希在 manifest。1024维、28层、输出权重与词嵌入绑定；先原生最终 RMSNorm（epsilon=1e-6），再原生输出头。
4. 测点为索引27 block 的 residual-post、全局 norm 前。位置 t 读完 x_t 后预测 x_(t+1)。无 BOS／聊天模板；旧前向1×256、前192有效。BF16、SDPA、eval、无梯度；CPU FP64 投影后转 BF16，无主分析范数补偿或温度校准。
5. 主面板：R12 H/the 全37篇、原位置，已暴露的探索性评估。191末端必须从冻结原文核对前192 ID 后恢复后继。补充：R11 H的180篇、每篇在32..190按种子20261101抽4个不同位置，避开主位置，排除五篇已命名错例；因此175篇700位置。与 R04 谱拟合文档分离。两个面板分别报告，先抽样后看输出。
6. 复用 R12/R10/R04 精确均值与谱基，9600发现侧位置、池化中心化。检查全部谱值、秩、正交和间隙。不新拟合 PCA／分类器；恒等独立验证。
7. 条件：原表征恒等、仅均值；前 k=1/4/16/64/128/256/512/768/1024；R12头1–64、中481–544、尾961–1024；头＋中、头＋尾、头128；旧随机1031/1032/1033各64维；头64＋三个正交新增随机64维（1034/1035/1036）。重复条件别名不重算，全部加同一训练均值。
8. 指标：后继负对数概率 NLL、KL(full||投影)、输出熵（均为nat）、原模型top1一致率、top10交集比例、真实目标概率与排名、top1准确率、表征范数／中心化保留能量；各条件训练协方差保留方差。全部位置保存前20候选ID、片段、概率及真实目标排名。
9. 参考频率：DCLM global01首个训练bin的前4,194,304个uint32 ID，固定切片哈希；非特殊词表加0.5平滑。特殊／padding输出质量另列，不解释成词频。报告非特殊质量归一后的期望log频率，以及最高频1%、后9%、后40%、末50% ID的概率质量。原bin tokenizer生成来源追溯不完整，保留限制并核对解码片段；不用评估集定义常见。
10. 固定展示：282/292/262/297/090，另按种子每域抽一篇普通主面板文档。事后最大改善／恶化另列。子词放回上下文。先读输出，再形成对象／关系／格式解释；用其他文档检查，不从词频直接命名语义层级。
11. 按篇先平均，再跨篇平均；成对文档bootstrap2000次、种子20261102、95%百分位区间。同篇位置不当独立文档；保留逐位置／逐篇表，不追逐显著性。
12. smoke：哈希、谱秩／正交、shift／mask、测点、缓存重放。相同路径恒等logits/NLL必须相同；FP64全部PC原向量误差<=1e-8且转BF16相同。跨运行时缓存／因果前文重放的h相对L2<=0.02，NLL差<=0.05、logits最大差<=0.5。记录实际误差，越界停止诊断，不事后放宽。
13. RMSNorm几乎消除全向量标量范数。若仍疑虑尺度，k64/k256补全向量范数匹配，明确为敏感性；不替代主结果、不调温度。
14. 优先一张5090 spot；没有已登记单卡档才用最多两张。复用shphd-lite-0911、已挂载SM120运行时及Qwen依赖；CPU做审计统计作图。3篇全模型smoke，输出分布每批<=16，分块原子保存可恢复。预计新增<2GB、<1GPU小时，记录实际。
15. 生成仅可选：数值实验后最多3个固定前文、k64/256/全维、贪心最多64新token，每步投影；分叉后不再是同前文对照。若省略标NOT RUN OPTIONAL。
16. 交付三组图：随k的NLL/KL/熵；词频／等秩参照；固定例输出分布。附原始输出、前文、逐篇配对及区间。分别写观察、竞争解释、边界、唯一AI建议；允许没有预想顺序或证据不足，不推广为机制／架构收益。
17. GPU输出前冻结数据、代码、协议及资产哈希；三轮审计分别针对识别、数据统计、实现数值。修改追加原因并保留失败；不覆盖R12。执行侧保存可复算全量，项目侧保留精选证据与代码。

输出前补充 A1：增加“解码完全由 Unicode 标点或空白组成”的非特殊 ID 概率质量，作为表面格式代理；不等于句法或语义，不包括纯数学符号。看输出前冻结掩码；条件、样本、参数均不变。

A2 实现修正（尚无有效输出）：R12 的 B 为 PC 坐标选择器／旋转，原生坐标投影列必须是 Q=V@B；随机参照也一样，精确索引不变。首个 GPU 尝试在前向前因镜像 FlashAttention ABI 不兼容而失败；仅在本进程禁用可选 FlashAttention，仍用 SDPA，不修改共享库或权重。旧代码／冻结清单保留为无效前解码来源，数值容差不变。

A3 恒等检查修正（尚无变换器前向／有效输出）：FP64全PC误差6.82e-13，满足原1e-8限制。754688个元素中562个原零值转BF16后保留<=1.50e-13的微小非零，其余逐位相同。以全部737位置的原生logits最大误差<=1e-4、目标NLL最大误差<=1e-6直接检验全PC与恒等（匹配批形状），替代不恰当的输入逐位相等停止条件。真恒等仍必须精确；保留cast不相等事实与失败记录，缓存重放阈值不变。

A4 同接口重缓存：旧缓存在当前5090上重放未过原0.05 NLL阈值（292差0.1153），h相对差1.03–1.61%。保留失败，旧h不用于主原生解码。在完全相同官方权重／tokenizer／block27 norm前测点上，用BF16 SDPA、固定1×256／mask192重新提取180篇原文，每篇独立保存，再重放3篇新缓存。原训练均值／谱基、所有位置／目标／条件／词频选择不变；不换模型测点，不重拟合PCA。因果前文对照保持1×256批形状，将未见后文ID置零并mask，避免BF16形状换核。原数值阈值不变。新增180+6次模型前向，无训练。

A5 并列规则：恒等校准发现 BF16 同分候选在 torch.topk(10)/(20)中顺序可能不同，造成虚假不一致。概率、NLL、KL完全不变。top1/top10统一按概率降序、ID升序。全部15477个输出的第20候选概率均低于第10，故已保存前20完整覆盖top10并列边界；top1最多3个并列。可在CPU精确更正，不重跑GPU、不选择样本；保留原chunk及首次失败校准。

A6 描述性分层（输出后CPU分析）：以输出前已冻结的格式掩码及独立频率箱，对原模型首选恢复率分层；非格式常见为参考频率最高1% ID，其他为其余非格式。报告组支持与原模型置信度。全部固定位置参与，不新推理、不筛样本、不改阈值、不拟合；中尾部直接与既有每个随机／前部新增参照配对。属于探索分析，不是独立语义确认。
