# R13：累积谱投影与原生解码（轮次扩展）

科学主属：A15_27_05；本文件只承接 R13 轮次，不建立另一主设计，不覆盖 R12。

## 1. 问题定义
固定 Qwen3-0.6B-Base 原生输出头，依次加入方差排序方向，哪些下一 token 预测先恢复？是否可复现地先恢复常见词／格式，再恢复上下文相关内容？不宣称复现未知 T5 设置。

## 2. 物理先验
R12 测点在 block27 residual-post、最终 RMSNorm 之前。分类器可读性不等于原模型使用。方差、参考语料词频、预测概率和语义细粒度是不同对象。旧评估文档已被查看，本轮属于探索。

## 3. 可证伪假设
小 k 可能先恢复常见／格式输出质量，再恢复上下文目标。竞争解释包括训练均值造成的输出偏置、维数或能量恢复、归一化与角度改变、只在 the 后成立。词频下降不能单独证明语义变细。

## 4. 数学模型
用既有训练侧均值与完整谱基，投影为 mu+V_B V_B^T(h-mu)，再经原生最终 RMSNorm 和绑定的冻结输出头。真实恒等直接用 h；全部 PC 重建另列。目标负对数概率衡量准确性；KL(full||投影) 衡量接近原模型，两者分开。

## 5. 计算实现
沿用 R12 的 37 篇 H/the 文档及位置，缓存末端位置从冻结原文核实后继。另按固定规则抽取不参加谱拟合的自然位置面板。没有模型、分类器或字典训练；看输出前冻结条件、展示样本和独立训练词频参考。

## 6. 最小区分检验
检查测点、因果移位、padding、原文 token 连续性、谱秩与间隙、恒等和缓存重放。比较等秩谱段与随机空间，以及头部增加中尾部的结果。报告范数、保留方差和熵；按文档重采样。

## 7. 当前证据
R12 粗分类头／中／尾均衡正确率 94.74/62.28/51.32%；生物细分类头、中均 88.89%，错例不重合。这些是已有读出证据，不能替代原生输出证据。参考谱拟合于 R04 发现侧 9,600 个位置，1024 个特征值均为正；详细数值审计在清单。立项时NOT RUN；现已完成737位置／21条件，新缓存重放与恒等PASS。常见参考ID预测较早恢复，但仅均值即有强格式偏置；尚无外部语义层级结论。[结果](summary_cn.md)。
