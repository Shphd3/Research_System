# A10_03：Router 的数值误差是否改变一次实际学习更新？

## 1. 问题定义

**决策问题：固定同一个 MoE 模型与优化器状态，仅改变同一路由目标的数值计算方式，是否会让一次有限更新的任务损失作用发生超出回放误差的变化？**

研究者在 2026-10-24 要求评估数值方向，并在有意义时完成一小轮研究、放入合适的 Anchor。本文的问题与后续比较是供审阅的 **AI 具体化方案**，尚不是既有失败现象的已确认解释。文献、源码与合成校准已完成；真实 token 比较 NOT RUN。本轮不创建或重置 Focus。

A10 研究共同方向与优化器如何影响学习稳定性。本问题与 A10_01/A10_02 平级，检查进入优化分析的梯度是否忠实于原目标。A05 仍负责 Top-1 塌缩机制，A16 负责负载控制，A15_24_01 负责裁剪及 AdamW 历史耦合；它们的结果不被重解释成数值问题。

这个问题要改变的判断是：数值误差是否值得作为本模型的学习解释继续研究。仅发现 logit 梯度之和不为零，还不足以回答。

## 2. 物理先验

1. **精确关系：**选中专家集合固定时，只依赖 softmax 概率的损失，对所有专家分数一起加同一个数保持不变，因此 logit 梯度之和为零。Top-K 边界须另查；直接依赖 logits 的 z-loss 不必满足这个关系。
2. **已核实的数值可能性：**数学等价的 softmax 算法可以给出不同导数。本轮在不再归一化的 Top-1 源码路径中复现了这种可能性，同时保留了归一化路径中的反例。
3. **AI 假设：**误差可能经过门控归一化、输出精度转换、其他梯度路径、裁剪及优化器历史，仍足以改变真实 token 上一次有限更新的作用。是否如此为 Unknown。

## 3. 可证伪假设

**H-N，AI 建议：**原生与稳定算法的导数差异可以重复，稳定版本更接近合格的高精度参考，并造成超过配对回放误差的一步任务损失差。

**竞争解释：**真实状态没有进入敏感区间，归一化抵消了差异，或实际优化器使差异对任务损失可以忽略。真实任务干扰与共同特征学习仍是其他解释。检验不预设稳定版本一定有利。

## 4. 数学模型

对一个 token，Router 将输入 \(h\in\mathbb R^d\) 映射为 \(E\) 个专家分数 \(z=Wh\)，其中 \(W\in\mathbb R^{E\times d}\)，再算概率 \(p=\operatorname{softmax}(z)\)。记 logit 梯度为 \(g=\nabla_z L\)，每行权重拆成 \(w_e=\bar w+\widetilde w_e\)，其中 \(\bar w=E^{-1}\sum_e w_e\)。输入梯度精确满足

\[
\nabla_h L=\sum_e\widetilde w_e g_e+\bar w\sum_e g_e.
\]

对可平移不变的损失分量，\(\sum_e g_e=0\)。若计算破坏了它，就可能沿**专家权重的行均值**引入额外分量。这个行均值不同于共同输入特征或 CrossCoder 特征。该式指出误差路径，尚不说明真实出现频率或任务后果。即使原始梯度严格零和，AdamW 也可能因各坐标历史不同而产生非零的行均值更新。

后续比较中的 \(S\) 包含相同参数、优化器矩与计数、裁剪规则及学习率。\(U(S,G)\) 表示完整参数梯度 \(G\) 实际产生的参数增量。唯一主观测量是

\[
D=L_{\mathrm{probe}}\!\left(\theta+U(S,G_{\mathrm{native}})\right)
 -L_{\mathrm{probe}}\!\left(\theta+U(S,G_{\mathrm{stable}})\right).
\]

两项都使用同一批固定探针 token、同一评估计算，单位为每个有效预测 token 的 nat。\(D>0\) 表示稳定更新在这一步的探针损失更低，\(D<0\) 则相反；它不能直接推出长期训练收益。更新向量差与梯度残差用于解释这个比较，不能替代它。

## 5. 计算实现

**已完成的范围审查。**读完论文八节与两个本地路由实现。合成校准通过 AST 提取复用原始门控表达式，仅为稳定版本和 float64 参考改动 softmax 计算。没有复用训练器、预训练模型、已存表征或数据集。[源码与校准记录](../../research_notes/router_numerical_fidelity/20261024_scope_audit_cn.md) 保留固定网格、来源、归属判断和完整边界。

**拟议的有界真实回放，NOT RUN。**先绑定实际执行过的源码/配置、包含优化器状态的准确 checkpoint、一层 Router、源 batch 与不重叠的探针 batch；检查真实精度和分数间隔。固定同一个上游导数，比较原生、稳定和高精度路由导数。隔离反向效应时保持相同前向值与专家集合；前向量化及接近并列时的选取变化另报。将导数替换传播进完整梯度，再从相同 \(S\) 克隆虚拟更新、评估 \(D\)，不修改原 checkpoint。

任务、实际生效的负载均衡及可能存在的 z-loss 分开求导后再合并；只有平移不变分量检查零和。真实 checkpoint、层、token 选择、误差校准和有限步长仍待在 Protocol 中冻结，本 Anchor 不能直接执行。

**相关研究的取舍。**[Barron 等](https://jonbarron.info/softmaxfix/) 提供保持数学目标的稳定计算对照；[Switch Transformers](https://jmlr.org/papers/volume23/21-0998/21-0998.pdf) 已有 Router 局部高精度基线；[ST-MoE §3.3–3.4](https://arxiv.org/html/2202.08906v2) 提示检查 logit 大小及 z-loss。新增 z-loss 会改变目标，暂缓。简单减去梯度均值只作诊断，不当成等价数值修复。

## 6. 最小证伪检验

先做一次真实冻结状态回放，再考虑重新训练。主量为 \(D\)，同时保留相同评估计算下的同方法重复与无改动对照。

- **支持局部数值作用：**干预只改变指定导数；稳定版本更接近合格参考；有限损失差超过预先冻结的回放误差。保留 \(D\) 的任一符号。
- **不支持在该范围继续：**导数差被抵消，或有限作用低于误差分辨率；搁置这个状态下的数值解释。
- **证据不足：**源码/目标、优化器历史、前向匹配、参考质量或测量分辨率仍不清楚。

尚未批准数值阈值或样本预算。真实运行前须用独立校准冻结误差界、准确资产和划分，不能看过 \(D\) 后调判据。很小的相对误差分母或很大的梯度残差，都不能补足未分辨的任务作用。

## 7. 当前证据

[本轮 CPU 校准](../../research_notes/router_numerical_fidelity/20261024_scope_audit_cn.md) 使用五个预定、无分数并列的向量、两个源码核、Top-1/Top-2、三种算法，共 60 行合成结果。不再归一化的原生 Top-1，在该构造网格上的平均相对 logit 梯度误差为 0.316676；归一化 Top-2 为 \(6.6444\times10^{-8}\)。原始实现的归一化 Top-1，在所有版本中任务梯度均为零。这些是实现校准，不是训练状态的总体估计。

同一记录保留了构造的上游梯度、零初始矩 AdamW 例子和阴性对照。它说明这条数值路径可实现，也说明抵消边界必须保留。真实间隔、自然梯度出现率、已有优化器历史下的作用、\(D\)、专家选择变化及长期后果均为 **NOT RUN / Unknown**。

## 8. 声明边界与下一决定

正式更新是加入一个范围清楚的数值竞争解释和证伪办法。A05/A15/A16/A17 的既有科学结论不变。校准尚不能确认 Router 塌缩原因、真实跨任务干扰、有用专家分工或替换 softmax 的收益。

**AI 建议的唯一下一决定：**在一次合格的真实冻结状态回放后，保留或搁置这个数值解释。恢复时先绑定实际执行源码及含优化器的准确状态，再在 Protocol 中冻结小比较。广泛精度扫描与新训练暂缓，直到出现值得追查的局部有限作用。
