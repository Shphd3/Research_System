# 64文档门槛的依据、筛选损失与最小修订建议

状态：DESIGN_REVIEW_AND_AMENDMENT_PROPOSAL_NOT_RUN。原冻结协议与R01数据停止结果不改。本轮只补做固定token304的TRAIN文本支持数分解；没有模型前向、训练、资源申请或EVAL／TEST读取。

## 目的与假设

目的：在同一个token的不同上下文中，实际削弱源层共同激活候选C，检验它是否特异影响后层上下文计算候选R及预测，为后续保持共享路径提供局部机制依据。不是重新做频率—罕见词关联，也不直接检验专家训练收益。

H1：当前对象存在特异依赖。H2：只有共激活，没有本干预可检测的特异依赖。H3：一般激活破坏、重构误差或方向读数串扰造成观察。R和预测均特异改变才支持当前范围H1；只有一项变、对照同样变或测量失败都收窄／停止，不强选故事。

后续本研究对话开头按研究者要求重申目的与假设，避免围绕门槛或方法名偏离主问题。

## 64到底从哪里来

64是AI在原协议草案中提出的操作性门槛，原配置明确标记AI_PROPOSAL。它没有由配对效应方差、预期效应、统计功效或置信区间宽度推导。用户后来批准按协议执行，使其成为该次运行应遵守的规则，并不补足这个统计依据。原执行按规则停止是合规的；把这个停止概括为“现有数据不能检验目的”则过强。

统计上，所需文档数取决于每文档“C相对匹配对照”的配对效应波动，以及我们希望分辨的效应尺度。原方案在任何模型干预前就停止，并未测到这个波动，故不能说64是必要或充分的科学样本量。原先EVAL每类24的数字同样没有功效推导，也应在修订时处理；不能只是将64换成一个更小整数。

此外，这里的“独立文档”实际是不同对话／首个用户prompt哈希。原数据仅做此级别精确去重，近重复独立性未知；不同哈希不等于严格统计独立。

## 数据不够，还是规则过严

以下固定为已报告的token` in`、目标` the`／` a`，不按模型效果另选对象。只读原TRAIN重新计数，复现既有91／43和23／23结果。

| 规则阶段 | ` the`不同对话 | ` a`不同对话 |
|---|---:|---:|
| 原答案位置中的同token／两种续词，尚未要求16个后续目标 | 149 | 74 |
| 要求16个后续答案目标及完整前缀≤512 | 124 | 59 |
| 每token每对话只按固定SHA保留一处 | 91 | 43 |
| 再只按来源平衡 | 43 | 43 |
| 再加答案位置16token箱 | 34 | 34 |
| 再加前缀长度32token箱，即原最终规则 | 23 | 23 |

前两行一份对话可能同时提供两类上下文，不能把两列相加当独立对话总数；后续按每token每对话一处取样。分层各类数相同来自平衡，较多一类的丢弃不是额外独立性证据。

因此，**现有文本确实包含跨对话的两类上下文；不足发生于这组筛选规则和64门槛的组合。** 严格分层进一步压缩了数据，但门槛在分层前已失败。要求16个未来目标是为了测一般预测损害，逐文档取样是为了避免伪重复，分层是为了控制位置／来源；这些都有目标，具体16／32以及64却不是理论必需常数。不能简单全部删除，也不能宣称旧组合已经是最小必要条件。

这份只读分解没有测量C/R、没有估计干预效应方差，因此既不能承诺23对足够，也不能认定23对不足。支持JSON与实际CPU源码见[分解数据](../../../../../../../../sources/Projects/from-attention-to-search/main/experiments/A15/15_25_03_context_computation_dependency/R01_bounded_execution_20261026/provenance/support_decomposition.json)；原始代码在执行侧同名source，当前支持数不是干预结果。

## 从头看分析链条

1. 固定原模型、字典和同一token，选出不同上下文。CrossCoder只提供候选坐标：跨这些上下文较稳定的响应叫C候选，随上下文变化并与固定预测区别相关的响应叫R候选。先定义候选，再记录频率。
2. 在发现集选择并冻结C、R、层和上下文预测目标。共同z联合读取14层，可以离线定位候选，不能当作前层已具有后层信息。
3. 在原模型真实第14层激活中小幅减去C贡献，保留其他部分与重构残差。每个相同输入分别做原样、C与两类等实际位移对照，独立恢复。
4. 在真实第28层激活中读取预定R方向分数，同时测目标词相对foil的对数概率优势与一般预测损失。检查decoder串扰和源位移直接携带；不在干预后重跑联合z来表示传播。
5. 以同输入的C−对照配对差为证据，再按对话汇总不确定性。两项特异效应支持当前局部依赖；共同变化不证明R中介，更不自动证明专家收益或训练顺序。

## 最小修订方案：改变充分性判定，保留实质性对照

这是提案，未执行，也没有修改原Protocol。

**对象与数据先固定。** 只研究已经由支持数确定的` in`及` the/a`，不为更大效果替换token。保留原TRAIN发现／EVAL探索性留出，保持原词片、16未来目标、每文档一处和分层匹配；现有TRAIN各23个匹配对话可用于发现，但23不是新的合格门槛。EVAL可用数仍未知，不据此承诺有足够留出。当前先不同时放松位置／长度或增加同文档位置，以保持修订最小。

**撤销没有统计依据的64／24前置硬闸，改由测量质量和证据精度决定能说什么。** 不换一个小整数。C稳定性、R区分／局部重构资格、原样预测能力、数值／实际位移匹配及残差携带守卫照旧；找不到合格C/R仍停止。

**在冻结候选后加一个小型精度试算。** 在发现集固定挑一小批文档，最多16个上下文、两类等额，走同样20条件，最多320条序列前向；16是计算上限，不是科学样本量门槛。样本名单、候选、方向、剂量及指标先冻结。用实际每文档配对差估计波动，仅判断既有留出能否分辨原登记效应；试算样本不进入留出主检验，也不因结果方向／大小换对象、阈值或剂量。小批方差估计不精确，要如实给不确定范围，不能宣称它保证了统计功效。

**实质性证据标准不降低。** 主剂量0.10、次剂量0.05；五个随机方向和三个其他候选集、两类控制、R与预测共同主要指标、一般损害守卫照旧。原操作效应标尺R=0.10发现SD、预测优势=0.02nat以及原多重比较校正保持。留出按固定可用文档一次性分析，不因未显著追加数据；报告每文档效应、区间与少数文档影响。若样本太少导致区间不稳定，只能报告所测个案；若区间宽，结论证据不足；只有可靠区间排除预定大小的效应，才削弱对应版本的H1。不得把不显著等同于独立。

**预算和边界不变。** 发现、资格、精度试算和留出都计入原计划4864条及硬上限12000，不追加训练、字典、模型或资源，不读TEST。未用额度不自动授权新搜索。旧R01结论保留为“未满足旧冻结数据规则”；修订若执行，必须单独登记版本并在看到任何C干预结果之前冻结。

本方案允许出现“能测到局部作用，但证据不足以裁决跨上下文依赖”。这比无依据的固定N门槛更贴近主问题，也比为了跑完放宽功能标准更诚实。
