# 预定结果判定表（全部NOT RUN）

| 观察条件 | 允许的认识更新 | 结论边界 |
|---|---|---|
| 资格通过，C相对两类匹配对照同时特异损害R及预测，去直接携带后仍有R效应，一般损害守卫通过 | 支持本对象与干预范围内H1，值得后续测试共享路径 | 尚未证明R中介、模块独立或专家收益 |
| 只有功能损害，R不变 | 可能涉及其他路径 | 未定位C→R |
| 只有R读数变化，功能不变 | 几何／方向读数变化 | 不能据此指导分工 |
| 编辑有效且测量可靠，两项上界均低于预定实用阈值 | 削弱当前阈值规模的具体H1 | 不证明完全独立 |
| 区间宽、文档数不足、匹配不足 | 证据不足 | 不挑点估计讲故事 |
| 匹配对照同样受损，额外一般损害过大，或局部重构／读数不可靠 | H3不能排除，测量不足 | 停止，不自动训练新字典／扩大搜索 |
| R变化去掉源位移直接携带后消失 | 串扰／直接携带解释仍成立 | 不称后续上下文计算依赖 |
| 写回无效、过大或实际位移长度不匹配 | 干预不合格 | 不能用无效编辑的阴性支持H2 |

H1／H2／H3可并存。协议主剂量0.10，0.05次要；频率只在候选定义后描述。判据先于任何干预结果，当前没有结果。
