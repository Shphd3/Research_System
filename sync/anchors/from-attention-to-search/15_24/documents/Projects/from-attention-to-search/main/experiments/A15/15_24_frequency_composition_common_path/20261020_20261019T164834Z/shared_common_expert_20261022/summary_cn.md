# 新增 common 专家与层级混合：结果摘要

[English](summary.md) · [冻结协议](../../../../../../../../../UNAVAILABLE.md)

**八个模型和层级诊断均已完成。保留原两位专家再增加common，两种分发都没有稳定的低频收益。高、低频专家的实际输入均跨层级，h1事件都占多数。** 频率名单不等于实际输入组成；这些事实还不能把旧性能差异归因于混层。

## 目的、假设与对照

旧条件 T_H 用高频专家替换原来的一个搭档。本轮保留两个原专家，增加一个每个位置都会经过的 common 专家，检查这条额外学习路径能否改善低频 feature 相关位置的预测。common 在这里表示全体位置共享调用，不预设它已学到共同语义。

分别比较普通 MoE 与普通 MoE＋common、频率分发 T_F 与 T_F＋common。两类各两个配对种子11/22，共八个模型。每类一个独立单卡 H100 Reserved 任务，任务内串行训练。各模型沿用一轮、168步、85,548个回答预测目标；原专家初始化和样本顺序配对一致。Qwen3-0.6B、CrossCoder、最终归一化及词表头冻结，训练残差专家和普通 MoE 的路由器。

原两条路径保留各自权重：T_F为0.5/0.5，普通 MoE 为归一化门权重。common 单独乘1后相加，不替换或将三条路径除以3。其输出投影从零开始，初始预测与基线一致；额外增加3,145,728参数。用户本轮不要求参数匹配，因此额外容量、计算和优化变化均是竞争解释。

假设是：同一家族两个种子的最终 DEV 低频 feature 宏平均 NLL 都下降。计算时先在每个低频 feature 的激活位置上平均，再对有 DEV 支持的 feature 等权平均；它不同于整体位置平均或低频位置并集平均。两个种子同向改善只构成当前设置的探索性支持，种子方向不一致则没有稳定支持。DEV已经在之前分析中看过。

## 新增 common 的训练结果

## 层级定义和覆盖

使用10/14已画图的**同一个最终14层联合 CrossCoder、16,384个 feature** 的图标签，沿用原图而不重新分层。图边从较少出现的 A 指向更常出现的 u，要求 P(u|A)≥0.8、P(A|u)≤0.5、u的支持至少为A的两倍，另有节点/共同支持门槛；先发现再复核约简。层级 h 是沿边到无出边节点的最长路径，合格叶节点为h0。因此h是统计包含关系的位置，不是Transformer层号，也没有被认证为语义抽象深度。

全部16,384个ID身份对齐；15,537个原图支持合格且非孤立，847个孤立节点独列，未映射0。每条边的频率倍增约束使h与频率天然相关。这里把原DCLM图标签带到Tulu输入上，尚未确认全部图边在Tulu仍满足原包含阈值。[原图身份与核对](../../../../../../../../../UNAVAILABLE.md)

## 导师思路怎样映射到分发：AI建议

先明确自然文本中的feature组合及其聚类，再讨论该组合共享哪部分计算。相同h并不等于同一组合，频率或层级标签本身不能确定共享算子。

对一个待验证的**线性残差算子**，记总计算为 \(W=C+R\)，其中C为已提取部分、R为剩余部分。从R提取一个方向 \(D=\sigma uv^\top\)，把它移入共享部分：

\[
C'=C+D,\qquad R'=R-D,\qquad C'+R'=W.
\]

这保证搬移当下的输出相同。若D对整个组合共享，可在该组合的公共路径计算D，再让后续专家学习剩余部分。冻结已提取方向、约束后续学习正交，是需要检验的训练安排；当下恒等不能保证之后的训练仍无损。把共享路径推广到所有文本，还需要证明不同组合也都需要它。

将导师四步映射成一个候选实现，可以依次做：①仅在初始化时把选定线性残差的奇异值设为相同尺度；②在明确归一化后监测阈值1，达到时提取实际的 \(\sigma uv^\top\)（越过1时不能把系数强截成1后仍声称恒等）；③已提取项留在共享路径，在各组合内学习剩余部分，并明确采用哪种正交约束；④在子组重复提取。初始尺度、归一化和触发规则尚待设计，不能冒充学长的原loss。

分发也可以保持转移当下的等价：先给每个后续专家同一份 \(R'\)，门权重满足 \(\sum_e g_e(x)=1\)，则 \(C'x+\sum_e g_e(x)R'x=Wx\)。之后各专家再分别学习。保证的是初始计算相同，不保证改变学习约束后还能到达普通训练的最优解，也不保证优化器轨迹相同。

已有[15_11合成实验](../../../../../../../../../UNAVAILABLE.md)提供了相关先例：在已知分组、平衡采样和指定正交条件下，正确分组可逐级学习rank-one组成；错误分组使一个rank-one叶节点面对rank-two剩余算子。精确下界另依赖双侧正交和祖先精确正交等条件，[原推导](../../../../../../../../../UNAVAILABLE.md)保留这些假设。该toy没有证明层级模型比匹配flat模型更好，也不能直接解释当前自然文本。

当前SwiGLU专家是非线性函数，不能对整个专家直接做单矩阵SVD。采用线性残差作为第一次提取对象，是**AI建议、尚未执行**；谱打平的尺度、提取阈值和正交约束仍需具体定义。本轮新增的全宽common专家没有实施Rank-one提取，不能作为导师算法的复现。

## 当前结论与证据边界

已确认：频率名单跨图层级，完整输入都跨层；新增common改善TRAIN拟合，却没有在两个种子上稳定改善低频DEV主指标。各专家相似的层级份额不代表同一批feature，更不等于相同计算。更新冲突、裁剪效应和旧NLL差异的成因仍未被隔离。

**AI建议的下一问题：在可跨文本复现的feature组合内，是否存在可保留的共同计算，而组合间的差异能交给后续专家学习？** 聚类对象应是自然文本位置的feature组合，允许一个原子被多个组合使用。先检查组合能否超出词/来源/模板在其他对话复现；再检查候选提取方向是否被这些组合共同使用。直接按h或频率硬分组不能替代这两步。

本地诊断没有模型前向或训练。原图哈希、层级递推、路由/标签对齐及独立直接计数通过；完整计算17.3秒、峰值RSS约0.934GiB。[诊断与检查记录](../../../../../../../../../UNAVAILABLE.md) · [独立验证](../../../../../../../../../UNAVAILABLE.md)
