# Anchor A15_24_02：保留频率相关方向，限制剩余更新

[English](15_24_02_frequency_complement_anchor.md) · [执行契约](../../../../experiments/A15/15_24_frequency_composition_common_path/frequency_complement_20261023/protocol_cn.md) · [结果首读](../../../../experiments/A15/15_24_frequency_composition_common_path/frequency_complement_20261023/summary_cn.md)

本 Anchor 回答一个局部问题：**如果要保留一个矩阵对指定输入方向的响应，更新是否必须限制在正交补；这样限制后，低频预测实际怎样变化？** 数学条件与预测效果分别检验。研究者已授权本轮有界分析；科学判断仍等待“先阅读、再讲解、讨论后更新认识”。

本文是执行后补全解释的阅读版本。公式、对象、比较及预算均沿用结果计算前的冻结设计；未依据结果改换假设。原始设计字节、时间与哈希由 [Detailed](../../../../experiments/A15/15_24_frequency_composition_common_path/frequency_complement_20261023/detailed_cn.md) 追溯。Protocol 保留冻结字节。

## 1. 问题定义

父问题 [A15_24](../15_24_frequency_composition_common_path_anchor_cn.md) 研究按 feature 激活频率分配专家后，低频样本的学习是否改善。这里的 feature 是固定 CrossCoder 的一个激活坐标；“低频”指它在原 TRAIN 中较少激活，不指词频、任务难度或某项能力已经掌握。

已有方向诊断比较过参数净变化与全局输入主方向。它只测几何关系，还没有回答某个方向当前是否有预测作用。本轮把研究者提出的“找出要保留的方向，更新剩余方向”拆成两个有限问题：

1. **已有变化的作用。** 从已有参数中，部分撤回沿候选方向形成的净变化，低频损失怎样变？
2. **后续变化的作用。** 同一起点产生的一次完整优化器位移，去掉候选方向的分量后，与原位移和随机限制相比，低频损失怎样变？

第一个问题测回退；第二个问题测一个局部更新政策。它们不能相互代替。本轮使用原 T_F 模型，原 Base 路径和两个被选专家始终存在，没有加入第九个 common 专家。不转向一般遗忘问题，不新建独立 Focus。

## 2. 物理先验

**线性保持关系是确定的。** 对一个固定矩阵及固定输入子空间，能精确写出哪些参数位移不改变该子空间上的响应。它是下文的代数条件，不是从损失数据发现的经验规律。

**候选方向的功能尚未认证。** 本轮使用原 TRAIN 隐状态中心化 PCA 的前 16 个方向。PCA 找的是输入变化较大的方向；它不是对权重矩阵做 SVD，也没有把激活除以奇异值。已有频带贡献分析为检查这些方向提供动机，但不能把它们直接命名为“高频任务专属方向”。

**低频事件可能需要共同成分。** 一个低频 feature 激活的位置同时包含许多高频 feature。共同方向可能帮助该位置的预测。因此，“保留共同方向的当前作用”与“禁止它继续变化”是两个不同主张；后者的价值必须另测。

## 3. 可证伪假设

经验候选是：在相同保存模型、相同 TRAIN 批次、相同 AdamW 历史状态下，将完整参数位移限制到候选方向的正交补，且保持总位移范数可比时，其低频预测损失低于原始完整更新，也低于同秩随机补空间更新。预先在两个原种子中分别检查这两个差值。

最强竞争解释包括：差异只是位移变小；任何同秩限制都有类似作用；共同方向本来就对低频预测有用；全局 PCA 并未找到要讨论的功能方向。范数匹配、随机基底与参数回退分别约束这些解释，但一个局部结果不能排除全部解释。

“更新必须落在补空间”只有在**严格保持指定矩阵响应**这个目标下是必要条件。若目标改为任务损失在容许范围内变化，补空间限制只是一个候选方法，必要性不由本轮代数推出。

## 4. 数学模型

### 4.1 输入、专家和损失

令 \(h\in\mathbb R^{1024}\) 为冻结 Base 模型缓存的最终层隐状态，\(s>0\) 为原 TRAIN 固定的尺度，专家读取完整输入 \(u=h/s\)。固定路由给出两个专家的集合 \(\mathcal R(h)\)。每个专家都有 gate、up、down 三个矩阵，计算为

\[
h'=h+\frac{s}{2}\sum_{e\in\mathcal R(h)}
W_{e,\mathrm{down}}\left[\operatorname{SiLU}(W_{e,\mathrm{gate}}u)
\odot(W_{e,\mathrm{up}}u)\right].
\]

其中 \(\odot\) 是逐元素乘法。冻结的 RMS 归一化和输出头将 \(h'\) 转为下一 token 的概率。损失 \(\ell=-\log p(y\mid h')\) 使用真实下一 token 标签 \(y\)，单位为 nat，越低越好。这里不重新运行完整 Transformer。

唯一允许临时变化的参数为低频名单专家 E0 的 up 矩阵 \(W\in\mathbb R^{1024\times1024}\)。其余矩阵、头、输入、路由和尺度全部固定。E0 的名单属于低频档，不意味着它的完整输入只含低频成分。

### 4.2 所谓“保留方向”约束了什么

令 \(V\in\mathbb R^{1024\times16}\) 的列为已有 TRAIN PCA 的单位正交方向，满足 \(V^\top V=I\)。投影矩阵为 \(P=VV^\top\)。矩阵 \(WV\) 逐列记录 \(W\) 对这些单位输入方向的线性响应；它不是激活频率，也不是损失贡献。

给定参数位移 \(U\)，严格保留这组响应的充要条件是

\[
(W+U)V=WV
\quad\Longleftrightarrow\quad UV=0
\quad\Longleftrightarrow\quad U=U(I-P).
\]

证明：第一步直接相减；若 \(UV=0\)，则 \(UP=UVV^\top=0\)，因此 \(U=U(I-P)\)。反过来，\((I-P)V=0\)，所以右侧条件推出 \(UV=0\)。也就是说，\(U\) 的每一行都要与 \(V\) 的列空间正交。任意斜补空间并不能仅凭“补”这个名字保证这一条件。

在这个矩阵内，允许位移构成 \(1024\times1008=1{,}032{,}192\) 维线性空间。它并非把原矩阵的其余部分删掉。可以写成

\[
W_*=W_*P+W_*(I-P),\qquad
W_{\mathrm{new}}=W_*+U(I-P).
\]

两部分都保留在前向中，只限制这一次新增变化。这里 \(W_*\) 为原第 168 步保存矩阵。对于混合输入 \(u=Pu+(I-P)u\)，补空间成分仍会受到变化，所以整网预测仍可能改变。

### 4.3 回退与更新是两种干预

令 \(W_{\mathrm{init}}\) 为原初始化，\(D=W_*-W_{\mathrm{init}}\) 为整轮留下的净变化。回退使用

\[
W_{\mathrm{rollback}}=W_*-aDP,\qquad a\in\{0.25,0.5\}.
\]

它撤回候选方向上的部分已形成变化，不删除 \(W_*P\)。同秩随机基底 \(Q\) 的回退 \(DQQ^\top\) 缩放到同一实际改动范数，以比较方向选择与一般扰动。

更新实验先从同一保存状态构造完整 AdamW 位移 \(U\)，再比较 \(U\)、\(U(I-P)\)、\(U(I-QQ^\top)\)。两种补空间另各有一项缩放到 \(\lVert U\rVert_F\) 的版本；\(\lVert\cdot\rVert_F\) 是矩阵所有元素平方和的平方根。自然范数与匹配范数均报告。

仅投影原始梯度一般不等价：AdamW 还使用历史一阶、二阶矩、逐坐标缩放和权重衰减。本轮保留“先投影梯度、再调用 AdamW”作为独立诊断，直接检查最终位移是否满足 \(UV=0\)。

### 4.4 主指标怎样计算

原 TRAIN 的低频档称为 B1。对某个 B1 feature \(j\)，集合 \(S_j\) 包含它在 DEV 激活、且路由命中 E0 的位置。有支持的 feature 集为 \(J=\{j:|S_j|>0\}\)。主指标是

\[
L_{\mathrm{low},E0}
=\frac{1}{|J|}\sum_{j\in J}
\frac{1}{|S_j|}\sum_{i\in S_j}\ell_i.
\]

先在一个 feature 内平均，再让每个有支持的 feature 等权。一个位置可能进入多个 feature 的平均；这不是把所有位置当作独立重复实验。无支持 feature 记 NA，不填零。完整 DEV 低/高频宏平均和总体 NLL 是另外的读出，不替换主指标。

## 5. 计算实现

只使用原 T_F 的两个种子 11、22 的初始化与第 168 步完整保存状态，以及既有 TRAIN 基底、频率名单和路由。每个种子按保存 TRAIN 顺序取最前 512 个命中 E0 的位置，微批次 64，以交叉熵总和除以 512 得到梯度。恢复原 AdamW 状态，使用终点学习率 \(3\times10^{-5}\)，仅对唯一可变矩阵裁剪范数到 1。

每个种子构造一次普通完整位移，另构造一次仅投影梯度的诊断位移。它们各自从原保存状态出发，互不接续。所有干预读出后恢复原参数。没有接受任何后续训练步，也不保存新的训练模型。

主前向和梯度统一采用 FP32，关闭 TF32；投影采用 FP64，再写入 FP32 参数。这样明确测量环境，不能把本轮微小差值与历史 BF16 损失直接拼接。DEV 完整评估；只有 E0 命中位置需要为每次改动重新前向，其余位置复用严格不变的基线。完整数量、资源上限、资产身份和失效条件由 Protocol 固定。

## 6. 最小证伪检验

预先记录的局部方向模式是：两个种子中，范数匹配的 PCA 补空间相对完整更新、相对范数匹配随机补空间的主指标差，都小于 \(-10^{-6}\) nat。这个数值下限只是描述性口径，不是显著性水平、实用非劣界或科学接受阈值。另报告每个条件相对原模型的差，避免把“少变差”写成“学习有增益”。

必须同时检查原值写回逐位置 NLL 一致、原模型与优化器身份、其他参数冻结、投影残差、实际位移范数、有限性和完整覆盖。失败项保留并标记 INVALID。高频及总体损失全部报告；本轮没有擅自为它们设置科学接受边界。

## 8. 主张边界与下一决策

边界是一个专家的一个矩阵、两个保存种子、每种子一个临时批次、固定全局输入基底和已暴露 DEV。既没有分离高低频独立任务，也没有证明候选基底是某项任务的专属参数方向。结果不能推出长期训练收益、频率的因果作用、一般遗忘机制或导师算法复现。
