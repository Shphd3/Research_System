# Anchor A15_24_01：common 是否通过全局裁剪改变路由专家的学习？

## 1. 问题定义

**决策问题：**保持频率分发模型、新增 common 专家、初始化、样本顺序和训练预算相同，只把 common 梯度从路由专家的裁剪分母中排除，能否改善最终低频 feature 相关位置的预测？

父问题 [A15_24](../../../../../../../../UNAVAILABLE.md) 检查高频路径或新增 common 路径是否改善低频学习。已经完成的新增 common 实验保留两个路由专家，改善了 TRAIN 拟合，却没有在两个种子上稳定改善留出低频损失。同时，全局裁剪触发次数增加。在把结果归因于 feature 组织方式之前，优化过程仍是一个未排除的解释。

本子 Anchor 只检查这个竞争解释。它不重新划分 feature，不替换表征，也不检验语义可分性。A15_25 独立负责 feature 关系的构造；这里固定原输入与路由，只改变 common 梯度参与其他参数梯度缩放的方式。

研究者已授权自主完成与引用对话不同的机制分析和执行，无需中间批准。本文的局部假设、干预和判据是**授权范围内的 AI 操作化**，不冒充研究者逐项确认的机制判断。不创建或重置 Focus。支持结果使这一优化解释值得保留；不支持结果削弱这条裁剪策略作为补救方法的依据；执行不完整则保留未知。

## 2. 物理先验

1. **已核实的实现关系：**所有可训练参数共用一个梯度范数，决定全局裁剪系数。因此，即使路由专家的原始梯度固定，common 也可能改变其裁剪后梯度。
2. **数学限制：**AdamW 使用裁剪后梯度的一阶和二阶矩。裁剪后梯度较小，并不意味着参数更新按相同比例缩小。第一步对正比例缩放近似不敏感，是必须检查的竞争解释。
3. **AI 假设：**这种耦合在训练中的变化，可能通过改变路由专家的更新轨迹影响低频预测。方向和大小需要测量；裁剪次数增加本身不能证明学习受损。

## 3. 可证伪假设

**H-C：**排除 common 对路由梯度裁剪分母的直接贡献，会在两个配对种子上降低最终 DEV 低频 feature 宏平均负对数似然（NLL），并伴随可归因于该操作的实际路由 AdamW 更新差异。

**竞争解释：**AdamW 基本吸收裁剪尺度差异，或者产生的轨迹变化不能改善低频预测。额外容量、分支之间的函数作用以及一般的泛化差异，仍然可能解释原 common 结果。这里固定架构并检验一条裁剪策略；它并没有消除所有分支交互。

## 4. 数学模型

令 \(g_R\) 拼接八个路由专家以及存在时的 router 的全部原始梯度；当前 T_F 没有可训练 router。令 \(g_C\) 拼接 common 专家的梯度。完整有效批次反向传播结束后，定义

\[
q=\min\left(1,\frac{1}{\sqrt{\lVert g_R\rVert^2+\lVert g_C\rVert^2}+10^{-6}}\right),
\qquad
r=\min\left(1,\frac{1}{\lVert g_R\rVert+10^{-6}}\right).
\]

阈值为 1。这里的 \(10^{-6}\) 属于裁剪分母，与 AdamW 的 \(10^{-8}\) 不同。`global` 使用裁剪后梯度 \((qg_R,qg_C)\)；`route_isolated` 使用 \((rg_R,qg_C)\)。common 仍使用全局系数。在同一组原始梯度上，只有路由梯度发生变化；训练轨迹分开后，两组原始梯度都可能随之变化。

令 \(S\) 表示更新之前的完整 AdamW 状态。实际路由参数更新记作 \(U(S,\widetilde g_R)\)，包含原偏差修正、学习率和权重衰减。配对影子更新在固定 \(S\)、参数和原始梯度时，比较 \(U(S,rg_R)\) 与 \(U(S,qg_R)\)。它隔离优化器当步的反应；完整重训测量策略积累后的效应。

第一步的矩状态为零时，自适应项逐坐标正比于 \(cg/(|cg|+\epsilon)\)。当 \(|cg|\) 远大于 \(\epsilon\)，正系数 \(c\) 的变化大部分抵消。后续变化的裁剪系数才会与矩历史相互作用。因此，裁剪次数和累计更新路径长度均不能单独证明学习能力损失。

## 5. 计算实现

1. **审计已发生的耦合。**从原八个已完成模型重新计算裁剪、分支原始梯度和实际参数更新路径长度。这些已观察量用于提出假设，不作为事前预测。保留原模型家族和 baseline/common 配对。
2. **干预裁剪分母。**仅重训 T_F plus common，比较 `global` 与 `route_isolated`，种子 11/22。两种策略在相同本地硬件上使用原初始化和数据顺序。架构、预测目标、参数量、优化器设置和曝光预算相同。全局裁剪对照也在本地重跑，不仅与历史远端结果比较。
3. **区分当步反应与积累效应。**在五个固定更新步，从相同的当前原始梯度与优化器状态计算两种影子更新，不改变真实轨迹。最后比较逐位置 NLL 与原低频 feature 宏平均指标。[Protocol](../../../../experiments/A15/15_24_frequency_composition_common_path/common_optimizer_coupling_20261022/protocol_cn.md) 规定精确设置和工程检查。

复用原冻结表征训练器，改动裁剪和测量部分；不引入新的 Base、字典、分组或 Rank-one 实现。

## 6. 最小证伪检验

主指标为每个种子最终第 168 步的 DEV 低频 feature 宏平均 NLL：`route_isolated` 减 `global`。先平均每个有支持 feature 的激活位置损失，再对 feature 等权平均；重叠位置并不独立。两个种子均为负，且干预和实际更新测量有效，才构成**对当前设置中这条策略的探索性支持**。方向混合或非负不支持稳定改善；缺失或无效配对为证据不足。

两个种子就是完整计划，不构成显著性检验。DEV 已经暴露。必须同时报告整体 NLL、低频并集位置 NLL、TRAIN/EVAL 曲线和更新差异；这些次指标不能挽救失败的主判据。整体明显恶化时，有利解释只能局限于低频指标。接近运行或重放数值精度的差异必须如实报告，不能称为实际收益。

当步诊断还直接检查“裁剪后梯度减少 40%，学习就减少 40%”这一简单说法。如果分母策略明显改变梯度，却几乎不改变实际 AdamW 更新，即使全局裁剪很频繁，这一说法也不成立。

## 7. 当前证据

已完成父实验中，T_F 新增 common 后的低频宏平均变化为 +0.002998 和 -0.000958；全局裁剪次数由 25/24 增至 161/159，总步数均为 168。这是历史观察，不是本轮干预结果。它证明收益不稳定与裁剪改变同时出现，没有识别因果。[已完成 Summary](../../../../../../../../UNAVAILABLE.md) 保留完整分母、对照及伴随分析。

已完成[历史日志审计](../../../../../../../../UNAVAILABLE.md)发现，四个家族/种子配对中，新增 common 后八个路由专家的累计参数更新路径长度均增加，幅度为 1.916%–2.309%。首步裁剪系数减少 39.760%–43.734%，实际路由更新范数只减少 0.032%–0.042%。该步日志中的各专家原始梯度范数完全相同，但日志本身不能证明梯度张量逐字节相同。这些观察反对“common 减少了路由参数总体移动量”的简单描述；它们既不测量有用进步，也不排除矩历史效应。草稿登记时尚未运行的配对干预，现已按冻结 Protocol 完成。


2026-10-22 的本地配对干预完成四个模型，每个模型 168 步、85,548 个有效训练目标。最终 DEV 上，`route_isolated - global` 的低频 feature 宏平均 NLL 为 seed11 −0.000332028、seed22 +0.000529222 nat，方向混合，未满足两个种子均改善的预定规则。低频并集位置 NLL 分别变化 +0.000137646、+0.000411952 nat。838 个低频 feature 有支持，856 个保持 NA；DEV 已经暴露，结果属于探索性证据。

20 次固定状态影子比较中，common 的实际更新均逐元素完全相同，路由更新可以改变。例如 seed11 全局策略第 42 步，路由裁剪系数从 0.774878 改为 1，更新向量的差异范数为原更新范数的 9.979%，更新范数本身只增加 3.009%。这识别了裁剪到 AdamW 更新的局部作用；完整重训没有建立低频收益。新旧 global 轨迹在训练后并非数值完全重演，因此本轮效应只比较本轮同环境的两条策略。详见[本轮 Summary](../../../../experiments/A15/15_24_frequency_composition_common_path/common_optimizer_coupling_20261022/summary_cn.md) 与[独立复算](../../../../experiments/A15/15_24_frequency_composition_common_path/common_optimizer_coupling_20261022/detailed_cn.md)。

## 8. 声明边界与下一决策

本问题只涉及冻结末层 T_F 适配器与 always-on common 的一项优化耦合。它不能解释所有频率分发失败，不能从 feature 推出语义功能，不能证明 Rank-one 提取有效，也不能直接推广到普通 MoE 或预训练。

唯一下一决策是：是否保留排除这一裁剪分母耦合作为有用的局部解释和补救。完成标准是两个有效配对终点、实际更新诊断，以及支持／不支持／证据不足的事实记录。固定 Protocol 已执行完毕。AI 建议保留全局策略作为当前参照，不把这项裁剪修改推广为低频学习补救；若继续研究，应另行区分 common 学到的函数与优化历史带来的作用。原 common 实验与独立的 feature 关系工作各自保留。研究者层面的机制判断在审阅前保持 Unknown。
