# Summary：区分 common 的梯度裁剪与路由专家的实际学习

[English](summary.md) · [冻结 Protocol](protocol_cn.md) · [完整证据](detailed_cn.md)

**四个模型已完成。从路由专家裁剪分母中排除 common，确实改变了实际 AdamW 更新，但没有稳定改善低频预测。**最终低频 feature 宏平均 NLL 在种子 11 下降 0.000332，在种子 22 上升 0.000529，没有满足预定的双种子改善判据。这是在已暴露 DEV 上的探索性结果；研究者的机制判断与问题关闭状态保持 Unknown。

## 目的与独立贡献

之前新增 common 改善了 TRAIN 拟合，却没有稳定的低频 DEV 收益，同时全局裁剪更频繁。本轮检查这种优化耦合是否解释了结果，归属 [A15_24_01](../../../../problem_anchors/15_spectral_representation_and_functional_routing/15_24_frequency_composition_common_path/subanchors/15_24_01_common_optimizer_coupling_anchor_cn.md)。引用的 A15_25 对话研究 feature 关系与冻结表征；这里固定 feature 分组、输入、路由和架构。

本轮实际完成的贡献是拆开三件事：**梯度被缩小多少、优化器真正移动多少、预测是否变好。**这使一个合理的竞争解释得到直接检验，再讨论原 common 结果能否归因于表征空间。

## 比较与主结果

两组都训练同一个 T_F 模型：八个专家按固定 top-2 路由、权重 0.5/0.5，再加系数为 1 的 always-on common。各专家读取完整冻结末层 hidden state，经冻结 head 预测下一个回答 token。`global` 对全部可训练参数使用同一裁剪系数；`route_isolated` 只用路由梯度计算路由系数，common 仍使用原全局系数。

同种子保持初始化、顺序和预算相同：一个 epoch、168 次更新、85,548 个有效目标。对照和处理都在同一块**本地 H100 MIG 3g.40gb** 上运行，没有新增远端资源。工程检查、四次训练和评价的进程执行时间合计 307.25 秒，低于 1,200 秒上限。

主指标先平均每个有支持低频 feature 的 DEV 激活位置 NLL，再对 feature 等权平均。原 1,694 个 feature 中，838 个有 DEV 支持，856 个没有。同一个面板有 10,340 个位置，其中低频 feature 并集覆盖 1,701 个不重复位置。NLL 单位为上述加权方式下每个有效回答目标的自然对数损失（nats），越低越好。

## 机制测量回答了什么

原实验中，裁剪更多并没有对应更少的总参数移动。已完成历史审计发现，新增 common 后，路由累计更新路径长度增加 1.916%–2.309%。首步裁剪后的梯度尺度减少约 40%–44%，实际路由更新范数却只减少 0.032%–0.042%。路径长度度量移动量，不度量有用学习。[历史审计](../../../../../../../../UNAVAILABLE.md)

Adam 解释了这两种量为何不同。第一步的矩状态为零时，梯度乘上正系数 \(c\)，自适应更新正比于 \(cg/(|cg|+\epsilon)\)。除接近零的梯度坐标外，尺度大部分抵消。后续每步系数变化，会与累积的一阶、二阶矩相互作用，进而改变更新方向。

新实验直接检查了这一点。种子 11 第 1 步，固定相同原始梯度与 Adam 状态，两种策略得到路由裁剪后范数 **0.562684 与 0.999999**，实际更新范数却为 **0.096449567 与 0.096484435**，仅增加 0.0362%。在 global 轨迹第 42 步，两策略更新向量的差值达到 global 更新范数的 **9.979%**，夹角为 **5.373 度**。全部 20 次预定影子比较中，common 自身的更新完全相同。这些是在固定状态下测得的真实优化器影响，没有额外反向传播。[种子 11 步骤记录](../../../../../../../../UNAVAILABLE.md)

完整训练中，路由裁剪次数由 161/160 次降至 21/18 次；累计路由参数移动却由 37.5284/37.4601 降为 36.5212/36.4992，两个种子的最终 TRAIN 整体 NLL 都上升。因此，允许更大的梯度，并不单调地带来更大的参数移动或更好的预测。完整诊断与五个影子检查点见 [Detailed](detailed_cn.md)。

## 有边界的理解与下一决策

**直接结果：**common 确实参与了优化器耦合；去掉这项耦合，没有得到预定的稳定低频收益。**AI 解释：**“common 缩小了路由专家总体 Adam 步长，因而把它们饿死”的简单说法，被历史移动量审计和本轮干预共同削弱。其他函数交互、矩历史及表征解释仍然开放。

本轮 global 与历史远端 global 并非数值完全相同。干预效应只由本轮同环境配对识别，不能把新处理与旧 baseline 拼接比较。这些结果也没有建立 Rank-one 机制或一般 MoE 架构优劣结论。
