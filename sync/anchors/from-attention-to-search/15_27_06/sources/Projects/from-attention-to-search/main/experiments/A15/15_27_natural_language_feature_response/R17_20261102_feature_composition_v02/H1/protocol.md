## 数据和划分

## 候选选择

1. 独立自然参考缓存统计 p(z>0)、正激活位置数、覆盖文档数。推荐合格门槛为 20 个位置、5 篇文档；零激活和不足单列。激活判据服从核验后的现有模型，若与 z>0 不同先记录口径差异。
2. 只用发现集得到每个原子均值与标准差；零方差单列。定义标准化响应。开发和留出不重算标准化参数。
3. 对三种矩阵条件分别计算相对匹配域外文本的标准化均值差，保留三者均为正者，按三项差值的最小值降序选最多 8 个形成 C。数量不足如实保留。
4. 方阵内按可逆与奇异标准化均值差的绝对值降序选最多 8 个形成 F，保存方向。额外候选 A=F\C；这只表示未进入 C 的前 8 名，不等于粗概念条件中没有激活。C 与 F 可重叠，联合去重后至多 16 个。并列按固定原子 ID 排序。
5. 候选 ID、排序、阈值及所有预处理在打开留出结果前冻结。不将未进入前 8 名解释为弱分布式效应不存在。

## 分析和匹配对照

- 对每条文本导出原始 z、激活指示、decoder 范数、活跃数量和响应范数。报告 C 的成员共享、A 的出现、条件内外配对变化和跨改写方向。
- 对 A 的每个成员额外报告同家族粗概念→细概念的 0→1、1→0 转变与激活率配对差，区分实际成员新增与原有成员强度变化，检查两种措辞。再用相同排序的共同候选前 16／32 名作预定截断敏感性（合格者不足则用实际数量），不新增搜索；若所谓新增只因 C 截断而产生，明确收缩该说法。
- 粗对应主分数为 C 内标准化响应的平均值；对三个矩阵条件分别与同家族匹配域外对照做差。逐原子表为解释性报告，不择优替代集合主分数。
- 细节任务只含可逆与奇异。发现集拟合逻辑回归；开发集在同一正则网格、同预算下选择；同一训练损失和类别权重规则用于 C、C∪F、最佳单原子及随机对照。
- 主随机对照为 C 加 |A| 个其余合格原子，频率和文档覆盖匹配，20 个预固定种子。保存目标及随机原子的匹配距离；匹配失败明确标注，不悄悄放宽。|A|=0 时新增成员主张无候选支持，不运行虚假维度增量。
- 联合超过最佳单原子的结果作为组合必要性的诊断，不作为粗对应成立的门槛。另报二值、总范数、L2 归一化及完整连续读出；控制每位置活跃数和范数并检查方向。维度匹配是主比较，加 8 个随机原子只可作次级容量诊断。
- 显式／无术语版本分别报告，沿用同一冻结模型；同划分的词 unigram／bigram 逻辑回归是词面诊断，不以其胜负自动排除语义。

## 指标和统计

五项主对比：三项粗响应配对均值差，以及细节任务的 `LL(C)-LL(C∪F)`、`平均种子 LL(C+随机A)-LL(C∪F)`。正号表示支持预测。粗对应与新增增量分层判定，不把后两项失败当作前三项必然无效。

家族 bootstrap 2000 次，家族内全部条件和改写一起重采样，所有模型用相同重采样索引。为五项主对比给 Bonferroni 同时 95% 区间，即各项双侧 99% 区间；同时报告未校正区间、点估计和有效家族数。随机对照用固定 20 种子的平均作为主基线，并完整报告种子分布。少家族或尾部不稳需明确写统计能力不足，不用 token 数充当独立样本量。

新增主张要求两项增量区间下界均大于零，并结合跨改写方向；粗对应要求三项粗差同向且可复现。次指标为 balanced accuracy、家族逐项损失差、词面挑战、活跃数／范数敏感性。没有人为设置通用“语义提升阈值”。
