# 数据、对照与频率组

## 本轮实际观察什么

模型是原始 Qwen3-0.6B Base。没有 chat template。英语前缀长320tokens，在答案前最后一个位置 p=319（冒号，token ID25）提取两套已有原生 SAE。Attention 输出取第28层（零起编号27）o_proj 的输出；MLP 输入取该层实际 MLP 前的、经过残差与 post_attention_layernorm 的输入。两个位置分别编码，各30000个字典成员、ReLU 后保留32个正激活。字典之间相同数字不是同一个 feature。

距离 d=p−e−1，两个端点都不计入；e 是目标物品最后一个 token 的位置。主任务 d16/64/128 分别 e302/254/190。主任务的证据绝对位置、填充顺序也随距离改变，因此只能研究这组三个任务条件，不能分离纯距离机制。候选为前导空格+物品+句号；保存每个 token 的条件分数和总分，不做长度平均。本面板每家族的两个候选 token 数相同。完整分数还包含后续候选 token 与句号的预测，不能全归因于 p319 的激活。

## 文本矩阵

|条件|目标词|近处词|关键比较|
|---|---|---|---|
|main16/main64/main128|A/B|无竞争条款|同事实跨距离；同距离跨事实|
|nearN，d128|A/B|object 或 small object|近处有不明物品的匹配基准|
|nearA，d128|A/B|本家族的A词|固定近处词，比较远目标A/B|
|nearB，d128|A/B|本家族的B词|固定近处词，比较远目标A/B|

近处一致条件取 AA 与 BB；近处相反条件取 AB 与 BA。nearN 是“近处有一个未指明物品”，不是“没有近处句子”。匹配矩阵中 e190、p319、问题和填充全部固定；改变指定角色的物品短语。旧 R18 相反条件48条原样复用，补中性/一致96条。旧主任务144条、旧相反48条、补96条与4smoke，共292条；正式表征面板288条。旧主任务与旧竞争任务还改变填充和条款，不能直接作单因素竞争解释。

384条干净比较：事实144、距离144、近处变化96。另存48条旧条件非直接配对审计，不混入主要比较。`text_pairing.csv`逐行标记事实、近处词、e/p、token多重集是否一致。新补文本继承的96个`local_suffix`字段不再对应实际改写，该旧元数据被审计并在可携带视图中按真实文本重建；冻结数值输入的文本、token、角色位置均未改动。

## 划分与选择

原24个行为家族按每个四家族模板组的前二/后二划为12发现/12表征留出。每家族12条全部同侧；六种模板两侧共享。这不是未见模板测试，原行为已知也不是新行为确认。先按发现侧六个主任务位置的共同支持选择6个固定成员 C，再选最多6个响应候选 R。主要强弱几何严格要求相关行全部 C 激活，缺失和零值在原始表中保留。第一批3个 C 与固定6个含零结果仅作预定敏感性，不替代主要支持门槛。

## 参考频率

直接复用 R17_D1 两个原生字典各300篇自然语料发现文档、38400位置的频率表，不使用本次留出分组。阳性位置数≥20且文档覆盖≥5才进入高/中/低组。Attention计数边界35/70；MLP输入33/62，等于边界归入较高一组。零次与支持不足分别保留。原始完整频率表、边界与源哈希均保存，计数和文档覆盖已由原始稀疏缓存复核。此频率不等于训练频率，更不决定 feature 的语义。

## 文件字段

`panel_portable.jsonl`保留每条真实全文、全部320个tokenID、偏移、证据/近处位置、候选完整token序列及实际问题后缀。包内名为`data/panel.jsonl`，与冻结输入逐ID验证全文和token完全相同。`cache/{discovery,heldout}.npz`中各字典的`__indices`与`__values`给出32个真实ID/激活；未列坐标严格为零。原执行缓存另有真实1024维输入h，包内省略h并列出原文件地址与哈希。`behavior_*.jsonl`保存两个完整候选的逐token和总对数概率。`sparse_activations.csv`是可读的全阳性长表；`fixed_member_values.csv`给出共同列表每家族的原始/相对强度与T/N/I。所有分母与缺失保留。
