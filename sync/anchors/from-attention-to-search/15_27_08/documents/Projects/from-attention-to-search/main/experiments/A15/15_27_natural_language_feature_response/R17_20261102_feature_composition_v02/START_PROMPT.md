## 只做一轮五项必要预检

1. **模型和 hook**：核验 checkpoint、tokenizer、CC、层索引、dtype 和源码。预期 Qwen3 0.6B、28 层、1024 维，A22 CC 16384 原子、联合层 1、3、…、27；不匹配就记录实际配置与影响，不能伪称匹配。固定回答前统一后缀最后 token；末 block 27 pre-final-norm 用于重建。联合 encoder 的 z 不是末层专属。
2. **数据、语义和划分**：主标签跨所有家族保持可逆／奇异一致，家族仅是实例与模板。粗概念可逆性未知，不能当奇异。旧 R14／R15 或其他多任务中的候选 A／B 若语义随家族变化，只能用于原生候选评分或独立任务，不能混入本轮统一 probe。按家族和近重复分组冻结发现／开发／留出。
3. **频率参考**：确认独立自然语料、文档 ID、token 范围、缓存指纹、正值口径、分段和文档覆盖；高频原子不等于高频概念。H4另核验自然发现／开发／验证的文档隔离。
4. **全部坐标恒等流程**：在小样本做端到端无改动往返，确认 token、层、维度、批次索引、残差和输出对齐。用与 dtype 对应的已验证数值容差，记录最大误差；失败先修复，不靠改统计阈值掩盖。
5. **共享 CC 重建**：核验 encoder 范围、各层 decoder、激活规则与末层重建误差，区分模型原本的重建误差和管线错误。保留原始 z、decoder 列范数、原表示与残差，并确认四路线能复用同一前向缓存。

这是一轮定向预检，不是无限审计。修复可恢复问题、做一个小样本 smoke test 后就执行四条协议。不要为非语义实现细节反复等我决定；作可审计的合理选择并冻结。真正缺失授权或关键语义条件时一次问清，并继续其他不依赖它的部分。

## 数据、拟合和随机性共用约定

推荐面板为 48 个矩阵语义家族 × 三条件 × 两改写 288 条，加 48 个非矩阵数学家族 × 两改写 96 条，合计 384。发现／开发／留出对齐为 24／12／12 家族。优先复用可核验的现有资产，必要时按冻结规则自行构造并检查初等数学材料；不能因为眼前没有 384 条就只写计划。材料要求显式术语和无术语描述、肯定否定平衡、无粗概念泄漏。

确有资源或有效性原因无法满足默认规模时，在看留出结果前冻结可用面板，保存具体原因、实际数量和证据能力；不能因结果不好缩换面板，也不能以配额未满阻塞所有路线。新构造材料要逐条保存标签依据和来源，不当作自然语料频率证据。

默认 CPU probe 为 L2 logistic regression：`C∈{0.01,0.1,1,10,100}`，`solver=lbfgs`，`max_iter=5000`，`class_weight=balanced`，拟合在发现集；开发集按未加权平均 log loss 选择，平局选更强正则。各比较臂保持相同损失、网格和选择预算；所有预处理只在发现集估计。若已有经过验证的等价实现，启动前记录并冻结替代配置，不做额外多轮搜索。

固定 split seed `20261102`，bootstrap seed `20261103`，20 个随机对照种子 `11021..11040`。家族 bootstrap 2000 次，所有比较共享相同索引；自然语料按文档重采样。主比较按各协议做同时区间，次分析明确标注，不伪装成预定主比较。成员并列按原子 ID，频率同值保持整组。

## 结果不是文件堆砌

每路线 `conclusion_update.md` 必须依次写：
1. **一句话更新**：对哪一种具体文本性质，我们现在多知道了什么。
2. **观察**：带原始数字、实际 N、区间、可定位例子的事实。
3. **完整性**：哪些检查和对照通过，哪些失败或不足。
4. **竞争解释**：哪些解释变弱、哪些仍然能解释结果，原因是什么。
5. **结论与边界**：支持文本对应、成员新增、强度信息、来源优势或配置增量中的哪一级；不能外推什么。
6. **假设更新**：保留、缩窄、修改或放弃哪一条，不能只写“区间跨零”。
7. **下一决策**：剩余哪个具体不确定性最能改变方向，是否值得单独的下一阶段授权。

总更新先回答导师关心的组合问题，给四路线结论表和最关键数值，再链接原始表、文本、图、脚本、日志与失败记录。不能把分类准确率或原子数量直接叫作功能分工，也不把静态结果写成稀有信息学习已经改善。
