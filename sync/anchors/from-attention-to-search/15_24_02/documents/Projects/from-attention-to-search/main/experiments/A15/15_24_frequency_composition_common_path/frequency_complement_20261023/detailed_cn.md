# Detailed A15_24_02：频率相关方向的回退与补空间更新

[结果首读](summary_cn.md) · [冻结 Protocol](protocol_cn.md) · [Anchor](../../../../problem_anchors/15_spectral_representation_and_functional_routing/15_24_frequency_composition_common_path/subanchors/15_24_02_frequency_complement_anchor_cn.md) · [English](detailed.md)

**事实状态：24 项条件全部完成，测量检查通过；研究者机制判断 Unknown。** 完整位移投影实现了指定矩阵响应的近似数值保持。范数匹配 PCA 补空间在两个模型里比另两种更新有更低的主损失，但比各自未更新模型略高；部分回退的主损失也升高。下面给出全部结果及其可用范围，不替研究者更新认识。

## 对象、控制和实际计算

对象是原 T_F 频率分发模型的 E0 up 矩阵，参数数为 1,048,576。原模型每个输入选两个专家，权重各 0.5；输入为冻结 Qwen3-0.6B Base 的 1,024 维最终隐状态，先除以原 TRAIN 标量尺度。专家执行 gate/up 的 SwiGLU 乘法后经 down 返回残差。Base 缓存、其余 23 个专家矩阵、尺度、路由、输出头及归一化均固定。修改一个专家不会影响没有调用它的位置。

**方向控制。** V 为既有 TRAIN 中心化 PCA 的前 16 列；Q 为同一历史文件中保存的 16 列随机正交基底。它们在本轮不重拟合、不按 DEV 选择。这里没有把激活除以奇异值，没有作权重 SVD，也没有认证方向属于某个独立任务。

**回退控制。** D 是第 168 步参数减原初始化。移除 0.25DP 或 0.5DP，比较相同秩、实际矩阵改动范数匹配的随机方向回退。一般扰动也能增加损失，因此必须保留随机对照。

**更新控制。** 每种子按保存的 TRAIN 排列选最前 512 个 E0 命中位置。用真实下一 token 的交叉熵总和除以 512，微批次 64；每个种子仅在这一个批次上求一次原始梯度。恢复保存第 168 步的完整 AdamW 状态，用它独立构造普通完整位移和仅投影梯度的位移。两次 optimizer 调用均从计数 168 临时到 169，随后丢弃提议状态；没有串接成两步，也没有接续训练。

实际学习率 0.00003，betas=(0.9,0.95)，eps=1e-8，weight decay=0.01；只对可变矩阵做范数 1 裁剪。两个原始梯度范数为 0.176753 / 0.180659；投影梯度为 0.077283 / 0.078746，均未触发裁剪。两个 TRAIN 批次分别跨 337 / 325 段对话，基线批损失为 0.526664115 / 0.512897465 nat。普通位移包含原历史矩和权重衰减的作用，不等于纯当前批次梯度。

原始完整位移分别产生 PCA 补空间、随机补空间，以及这两者缩放到完整位移范数的版本。只投影梯度的版本是实现诊断；它的最终范数没有额外匹配，不能混充同一实际位移投影。

## 数据和主指标支持

原 TRAIN 是 85,548 个有效下一 token 目标、1,024 段对话；DEV 是 10,340 个位置、128 段对话。它们是已有缓存，不是新抽取的确认集。频率由原 TRAIN CrossCoder 激活定义，沿用原 B1/B4 名单，没有使用缓存里的旧 low_ids/high_ids 替代。

E0 在 DEV 命中 693 个位置、109 段对话。这 693 个位置都属于低频 feature 联集，也都包含高频 feature。完整 DEV 的低频联集为 1,701，高频联集为 10,340，重叠为 1,701。**低频与高频是重叠读出，不是互斥任务或可独立归因的样本。**

主指标在 E0 命中子集内，先算每个 B1 feature 的平均 NLL，再对有支持 feature 等权平均。原 B1 共 1,694 个编号；417 个有支持、1,277 个 NA。支持中位数为 1，最少 1，最多 16；没有编号达到 20 次支持。完整 DEV 原口径有 838 个有支持低频 feature、856 个 NA；本轮 417 是增加 E0 条件后的子集，不能与 838 的指标直接当成同一个量。

两个种子共享 DEV，不是两次独立数据抽样。位置、feature 和对话符号不能扩充成独立模型样本量。本轮不报告由两个种子构造的总体置信区间。所有条件保留，没有按结果选择赢家、秩、幅度或支持阈值。

## 数值资格

全部分支/头用 FP32；原输出头 BF16 存储值提升为 FP32，而不是重新加载另一套模型。TF32 关闭，采用确定性算法；投影用 FP64，写回参数时为 FP32。未执行历史 BF16 基线的可选复测，因此不声称逐点重现旧损失，也不把新旧环境的微小差作为效应。

为保护原值对照，基线分别计算 E0 命中与未命中子集；所有干预重复相同命中子集微批。两种子的原值写回 NLL 均逐元素完全相同。模型四个初始化/终点 tensor 摘要匹配原来源；每次提议的初始 optimizer 摘要相同，其他参数及输出头均不变；最后恢复的全模型摘要等于原终点。

沿 V 幅值比定义为 \(\lVert \Delta W V\rVert_F/\lVert\Delta W\rVert_F\)，响应残差定义为 \(\lVert\Delta W V\rVert_F/\lVert W_*\rVert_F\)。前者不是平方能量。约束门槛仅适用于宣称保留相应基底的补空间条件；回退与完整位移本来就允许改变 V 响应，不能把它们的非零值记成失败。
