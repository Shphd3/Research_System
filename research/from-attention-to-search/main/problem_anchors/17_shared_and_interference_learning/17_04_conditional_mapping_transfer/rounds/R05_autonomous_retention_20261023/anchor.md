# A17_04 R05: Candidate retention and conditional residual allocation

## 1. Problem Definition

Can preserving selected directions of an acquired model help it learn a changed conditional rule, and does allocating the remaining updates by visible mode add useful capability? This round tests that decision through a bounded chain from selective updating to actual experts and learned routing. A **candidate** is a selected parameter direction; it is not an identified common function. **Retention** means preserving old-task predictions while acquiring the new rule. **Allocation** means changing which trainable residual parameters each mode can update.

The existing [conditional-mapping owner](../../17_04_conditional_mapping_transfer_anchor.md) establishes the local question: a visible mode can distinguish two opposite command rules, yet reversed-only shared training lost the old rule. Joint training can solve both, so neither parameter separation nor a shared functional component has been established. The blocking uncertainty is whether selective retention and conditional allocation provide utility beyond slowing all learning, changing capacity, or supplying routing information.

## 2. Physical Priors

The following are AI operational hypotheses motivated by the researcher's stated direction, not observed mechanisms.

1. Some already learned computations may remain useful after a conditional rule changes. Reducing unnecessary parameter movement could preserve them, but a large singular value alone does not identify such computation.
2. Different conditional tasks can need different updates even when a shared model can express both. Parameter isolation may help, but may also change effective capacity, update frequency and optimization.
3. Information sufficient to select an expert can be smaller than the representation needed to execute its computation. A retained direction need not contain that selection information.

Parameter orthogonality is an exact statement about a chosen matrix inner product. Functional independence, interference over training, and generalization remain empirical questions.

## 3. Falsifiable Hypotheses

The central hypothesis is that a predeclared candidate-and-allocation policy yields qualified old/new utility beyond its matched ordinary controls. Each stage tests one necessary or independently useful link, rather than accepting the complete chain from one favorable result.

| Stage | Tested claim | Strongest live alternative and decisive comparison |
|---|---|---|
| 0 | The carrier, ordinary learner and measurement can support the comparisons. | Implementation or acquisition failure: reproduce the parent and full-matrix ordinary control before interpreting restricted methods. |
| A | Top initial singular directions merit selective protection. | Generic slowing or arbitrary subspace restriction: compare seven arms including uniform small/scheduled, random, tail and top constant controls. |
| B | Mode-specific residual updates add utility at the same protection policy. | Added capacity, per-mode available space or information: compare shared/separate × normal/protected, full shared reference, and a matched-total-degree control. |
| C | TRAIN-only reselection improves on a fixed candidate. | Optimizer reset, reparameterization or released constraints: compare real reselection with fixed and sham/reset conditions. |
| D | Multiple actual experts add utility beyond a single residual and ordinary MoE. | Capacity, initialization, active compute or module change: retain ordinary and unprotected structures, and qualify the FFN carrier independently. |
| E | A trained router selects useful experts; a candidate summary can preserve utility. | Route-label prediction or load balancing without useful choice: compare oracle, balanced random, full hidden, candidate and equal-dimensional random summaries at fixed experts, then joint training. |
| F | A bounded utility pattern extends beyond the list task. | A synthetic-task-specific effect: use existing natural-text held-out data with explicit separation and ordinary controls. |

A local finite update that increases another mode's held-out loss supplies local interference evidence. A split model's better endpoint alone does not establish that interference caused the complete training difference. Dynamic or expert utility can be tested after a negative A result, but the selected directions must continue to be called candidates.

## 4. Mathematical Model

An example contains a visible mode, a neutral command and three distinct list words; the target is one next token. Old mode maps the first command to FIRST and the second to LAST. Reversed new mode swaps those outputs. Both rules coexist because the mode is visible. The actual model recomputes native attention; changing query/key/value matrices does not permit a frozen-input linear-output approximation.

For each selected acquired matrix \(W_0\in\mathbb R^{m\times n}\), let \(u_i,v_i\) be paired singular vectors and \(B_i=u_iv_i^\top\) the selected matrix atoms. They are orthonormal under the Frobenius inner product. With a fixed rank \(k\), define

\[
P(X)=\sum_{i=1}^{k}\langle B_i,X\rangle_F B_i,
\qquad C_t=P(W_t),\qquad R_t=(I-P)(W_t).
\]

The inner product sums elementwise products. The projector and reconstruction identities are exact mathematical properties to verify numerically. They define parameter coordinates, not semantic modules. The complement includes cross-direction terms and is not always the current small-singular-value tail.

Let \(d_t\) be one AdamW candidate displacement after the registered gradient clipping and one moment update at the actual current weights. If \(a_t\) is the candidate movement multiplier, apply

\[
W_{t+1}=W_t+a_tP(d_t)+(I-P)(d_t).
\]

The complement keeps its base update. This filters the **actual proposed displacement**, including Adam's coordinate scaling; multiplying only raw gradients is a different intervention. At \(a_t=1\), the implementation must reproduce ordinary AdamW. Parameter movement is not itself a utility metric.

For stage B, write the effective mode-specific attention matrix as \(W_m=W_0+\Delta C+\Delta R_m\), where \(\Delta C\) lies in the selected subspace and each residual lies in its complement. Shared conditions use the same residual for both modes. Separate conditions use independent residuals. Copying the complete residual doubles its stored coordinates while preserving each mode's space. A matched-total-degree partition control changes each mode's available space. These are distinct comparisons; neither simultaneously matches total storage and per-mode capacity. The Protocol fixes the constructive masks/projections and records their ranks rather than assuming a mask remains orthogonal after composition.

For the separate FFN bridge, the final native SwiGLU block computes \(\operatorname{down}(\operatorname{SiLU}(\operatorname{gate}(h))\odot\operatorname{up}(h))\). Gate/up are shared and frozen. Each selected down projection is \(W_i=C+R_i\); the native gate nonlinearity precedes that linear map. This is parameter sharing at one linear position. It is not a proof that an entire SwiGLU function decomposes into common and residual nonlinear branches.

## 6. Minimal Falsification Tests

Eligibility precedes interpretation. Numerical/freeze/data/resume failures make affected comparisons ineligible. For the list task, learning qualification requires at least 95% full-vocabulary accuracy in every mode × command × DEV-panel cell. Each cell has 200 answers. This practical convention prevents a high average from hiding one failed rule; it is not a population significance threshold. An ordinary-model failure blocks dependent mechanism conclusions while independent reachability tests continue.

Stage A's primary utility comparison is top scheduled protection against each registered ordinary/slowing/random/tail control at the equal new-answer endpoint, conditional on new-task qualification and at most 1 percentage point new-accuracy loss. A 5-point old-accuracy advantage is the preregistered practical marker. If uniform slowing matches it, selection is not established; if random/tail matches it, top specificity is not established; if top constant matches it, scheduling necessity is not established. None is rescued by selecting a later favorable checkpoint.

Stage B's primary comparison is protected separate versus protected shared residuals, using weakest-mode accuracy, qualification and non-regression guards. Normal/protected contrasts and their difference test whether protection and allocation interact. The total-degree control and per-mode-space disclosure determine how far a positive difference weakens the capacity rival. A shared ceiling gives no endpoint separation benefit; predeclared time-to-qualification may describe speed only.

Stages C/D/E use their registered task-utility contrasts against sham, single-residual/ordinary-MoE, and routing references respectively. Candidate reselection must beat its reset control; oracle failure questions expert capability; oracle success with learned failure localizes a selection/optimization gap. Stage F reports held-out natural-text NLL under its paired budget and retains the ordinary control. The Protocol defines secondary diagnostics and practical tolerances before their results.

All comparisons report each continuation order and paired examples; orders share one acquired old state. Bootstrap intervals over unordered-list groups describe example uncertainty, not independent-model replication. Natural-text intervals preserve their source-block grouping. Exposed DEV and repeated task development limit every stage to exploratory evidence. Missing comparisons yield insufficient evidence, and a completed negative experiment remains a completed experiment.
