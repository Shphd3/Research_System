# Anchor：单处 Dense／路由 LoRA 支路的习得与保持

## 1. 问题定义

**本轮要判断：先学旧任务、再学新任务时，在相同训练计算预算下，每个预测位置只选择一条低秩支路，是否能减少旧任务的留出损失上升，同时保留新任务的损失改善？**

状态：**研究者要求起草的待审科学设计，尚未批准正式实验**。[English](17_14_s7_single_branch_retention_anchor.md)。研究者已确认目的、8 层 fresh S7＋固定末层 Attention 输出稀疏自编码器，以及一个插入位置：Dense 一条支路，MoE 每个位置选择一个专家，不另加共享专家。下述插入点、优化器、数据、预算和科学阈值仍为 `AI_PROPOSAL`。本文件不新建或重置 Focus。本轮对话记录问题激活；稳定的 Focus 身份登记另待审核。

根本问题是：不同数据更新同一套参数时，为什么会互相帮助或伤害？实际目的是学到新任务的预测规律，同时更少损伤旧任务预测。已有混合训练和固定模型一次更新选择，尚未确认当前架构中的顺序学习现象。因此，先确认现象是当前最小、能改变下一步判断的工作；SAE 是分析准备，不是实验目的。

把两个可训练矩阵的乘积加到一处冻结投影上，称为**低秩支路（LoRA）**。Dense 让所有位置使用同一对矩阵。MoE 保存多对矩阵，由**路由器**根据当前可见前文的表征算出概率，再为每个位置选择一对。新阶段中，旧任务曾使用的支路仍允许训练；当前样本是否给它直接任务梯度，取决于路由。不能通过冻结旧支路来获得保持优势。

支持结果才值得进入独立的机制问题；不支持结果削弱解释当前保持优势的理由；证据不足，包括新任务没有学到，应先修复现象检验，不能立即铺开子空间分析。主要结论限定为参考答案预测，暂不扩大为独立生成正确答案的能力。

## 2. 先验与假设条件

1. **分析条件：**对同一条给定参考前文，上游权重冻结时，末层 Attention 输出投影的输入保持相同。支路可以改变投影输出，而不改变它自己的输入。
2. **需要检查的测量条件：**固定留出题目的参考答案交叉熵，可以衡量小模型的任务预测习得和保持；它不能单独衡量独立生成正确解答。答案格式和长度仍可能影响读数。
3. **候选机制，不是已知规律：**将不同样本分给不同专家，会改变哪些样本给哪些专家贡献直接任务梯度。这可能减少有害更新，也可能减少有益迁移或新任务学习。可训练路由、优化器状态和更大存储容量仍是竞争解释。

## 3. 可证伪假设

首轮检验的是**现象假设**：在事先规定的计算预算终点，MoE 的旧任务损失增加更少，而新任务损失改善及终点损失均满足不劣于 Dense 的要求。最直接的竞争解释是：MoE 只是新任务学得更少，因此旧任务损伤更少。联合检查新任务学习程度和旧任务损伤，才能在规定的损失尺度上区分这个解释。只看改善量不够：起点更差的架构，可能改善更多但终点仍更差。

首轮仍不能排除更大存储容量、旧阶段起点能力不同、保留路由概率导致支路强度更小，以及路由和优化器计算未对齐。必须报告这些问题。即使比较有利，也只能说明完整的已注册架构在该预算下有优势，不能说已因果证明路由缓解梯度冲突。

留给后续审批的**机制假设**是：实际参数更新让旧样本在增加损失的表征方向上少移动，同时保留对新任务有用的改变。表征距离更小或 SAE 编码更分离，都不能单独证明这句话。

## 4. 数学模型

AI 建议把支路加在最后一层 Attention 输出投影，即零起算 `blocks[7].attn.o`。对每个 token 位置，冻结投影的输入为 2048 维向量 \(c\)，冻结矩阵 \(W_O\) 为 1024×2048，尚未加入残差的输出为 1024 维向量 \(a\)。秩为 \(r\) 的支路有矩阵 \(A\)（\(r\times2048\)）、\(B\)（\(1024\times r\)），缩放系数 \(s\) 固定。两种架构计算为

\[
a_{\rm Dense}=W_Oc+sBAc,\qquad
a_{\rm MoE}=W_Oc+p_k sB_kA_kc,
\quad p=\operatorname{softmax}(Rc+b),\quad k=\arg\max_j p_j.
\]

MoE 保存 \(E\) 个专家。路由器矩阵 \(R\) 为 \(E\times2048\)，偏置 \(b\) 为 \(E\) 维。保留被选概率 \(p_k\)，不把它重新设成 1；这使任务损失能训练路由器，也会减小专家输出幅度。固定的残差、完整下游 MLP、归一化和词表输出，将 \(a\) 转成预测概率。不能用线性探针或 SAE 重构代替这段原生计算。

单个答案 token 的损失为 \(\ell=-\log P_\theta(y\mid X)\)，用自然对数。\(X\) 是当前可见前文，\(y\) 是下一个参考答案 token。路由器和 SAE 不读这个目标。令 \(e=\partial\ell/\partial a\)，即损失对 1024 个激活分量的导数。Dense 因子梯度精确为 \(\nabla_B\ell=s e(Ac)^\top\)、\(\nabla_A\ell=sB^\top e c^\top\)；被选专家的梯度再乘 \(p_k\)。选中索引固定时，路由器第 \(j\) 个分数 \(q_j=(Rc+b)_j\) 的导数为 \(\partial\ell/\partial q_j=p_k(\mathbf1[j=k]-p_j)e^\top sB_kA_kc\)。离散索引本身没有普通导数。实际训练按规定的有效答案 token 分母汇总这些梯度。

优化器产生的是低秩因子增量，不是任意完整矩阵增量。任何优化器下，矩阵乘积变化都精确满足

\[
\Delta(sBA)=s(B\Delta A+\Delta B A+\Delta B\Delta A).
\]

上述因子恒等式属于实数运算。BF16 类型转换和加法后的实际原生激活差另行测量，不能假定舍入残差为零。AdamW 还使用历史动量、逐坐标缩放、裁剪和权重衰减。未被选专家没有当前 token 的直接任务梯度，但已分配零梯度不保证参数不动：历史动量或衰减仍可能改变它；候选优化器会跳过独立参数的 `grad=None` 情形。路由器更新也可能改变旧样本选择哪个专家。只有在小变化且选择保持不变的区域内，才能用一阶近似解释损失；跨越路由选择时必须复算有限变化。

评价阶段 \(t\) 的 \(L_{d,t}\)，是在任务 \(d\) **同一份固定留出数据**上，把参考答案损失加总后除以有效答案 token 数。它是经验留出总交叉熵，单位为 nat／有效 token；不是训练批次误差，也没有扣除不可约噪声。阶段 1 是旧任务训练结束；阶段 2 是新任务训练结束。联合判断量为

\[
G_{\rm new}=L_{{\rm new},1}-L_{{\rm new},2},\qquad
F_{\rm old}=L_{{\rm old},2}-L_{{\rm old},1},\qquad
D_F=F_{\rm old,Dense}-F_{\rm old,MoE}.
\]

\(G_{\rm new}>0\) 表示新任务预测改善；\(F_{\rm old}>0\) 表示旧任务预测受损；\(D_F>0\) 有利于 MoE 保持。最后一个量必须与新任务改善、终点损失、起始损失和计算预算一起读。实用意义边界和正式计算预算仍为 `BLOCKED`，待研究者审核。

固定的**稀疏自编码器（SAE）**把 \(a\) 编成只有少量非零坐标的 \(z\)，再用固定解码矩阵 \(D\) 和偏置 \(b_{\rm SAE}\) 重构。定义重构残差 \(\varepsilon=a-b_{\rm SAE}-Dz\)，则精确有 \(\Delta a=D\Delta z+\Delta\varepsilon\)。这只是在记账，不会自动指出有害方向。因此原生位移与未被 SAE 表示的残差都要保留。SAE 重构不加入训练目标，不替换预测链中的原生激活。

## 5. 计算实现

**目标是得到可测的学习与保持轨迹。怎样做：**从同一个冻结 fresh S7 检查点建立两组支路，先学 GSM8K，再学 MMLU；首轮 AI 建议不重放旧数据。**为什么：**顺序接触数据提供旧任务训练前后及新阶段前后的比较，已有混合训练不提供这个证据。数据和不重放的选择仍为 `AI_PROPOSAL`；旧缓存采用内部重新切分，MMLU 来源记录含官方 test，科学切分资格仍待审核。确切来源和切分由[正式 Protocol](../../../experiments/A17/17_14_s7_single_branch_retention/20261007/protocol_cn.md)规定。

**目标是闭合参数到损失的计算。怎样做：**对阶段边界的同一批旧记录，保留末层投影输入、原生输出、残差、完整冻结后续计算和参考目标。**为什么：**支路直接改变现有 SAE 观察的向量，原生损失检验后果。已核查的 [S7 实现](/data/250010109/MoE_Router/experiments/20260920_s7_lambda0p1_from_scratch_4h100/dense_sae/model/modeling_qwen3_sae.py)将该向量定义在 Attention 输出投影之后、残差加入之前。

**目标是在正式科学投入前获得可信测量。怎样做：**运行独立、有限的训练＋分析 [Smoke 协议](../../../experiments/A17/17_14_s7_single_branch_retention/20261007/smoke_protocol_cn.md)。研究者已授权使用 4 卡 H100 reserved。**为什么：**先检查权重冻结、梯度路径、目标对齐、计数、恢复训练和 SAE／原生后续计算，不把工程结果当成科学支持。

## 6. 最小证伪检验

AI 建议只做一个配对的 Dense／MoE 两阶段比较。决定性表格保留旧任务习得、新任务习得、旧任务损伤、起始损失、累计有效答案 token、训练计算的实际／估计分项、全部存储参数和活跃参数。秩相同或更新步数相同，均不能代替计算对齐。

支持分支要求：两组先学到旧任务；两组新任务改善达到批准的最低标准；Dense 出现有意义的旧损伤；MoE 的新任务改善和终点损失满足各自批准的不劣要求；在注册计算预算和不确定性规则下，MoE 减少旧损伤超过批准的实用界。它只支持此处的现象。

若比较合格，且可靠排除注册的保持优势，进入不支持分支。若两组均未损伤旧预测，本设置没有提供需要解释的旧损伤现象。学习失败、计算不匹配、起始能力差异过大、区间与判断界重叠或测量无效，均属证据不足。数字边界、种子汇总和区间规则仍在正式 Protocol 中作为提案或 `BLOCKED`；审批前不能宣判科学通过。

## 7. 当前证据

包含 GSM8K 的八任务混合 Qwen3-0.6B 训练中，末层 Dense rank-16 与可训练路由 MoE 三种子的平均留出答案交叉熵分别为 0.737787 和 0.689914。旧 MoE 含一个无条件共享 rank-8 支路和一个被选 rank-8 专家；本设计取消共享支路，使用 fresh S7。该观察支持混合损失不同，不能支持顺序保持或当前架构。存储容量和实际计算并未同时对齐。[原 Summary](../../../experiments/A15/15_13_semantic_supervision_middle_layer_formation/A15_13_E20_sae_flat_router_eight_task_mixed_training/summary.md)。

已有精确 33B token 的 S7 分析，在固定模型上构造矩阵增量、比较选择规则。它没有持续训练 LoRA 专家，也没有测习得与遗忘。[原证据边界](../../../../../../daily_research_reports/1002/candidates/ntp_representation_update_channels/probe_33b_summary.md)。

当前两阶段现象实验：**NOT RUN**。Smoke 状态由独立执行收据记录；不能在本文件中预写完成或科学结论。

## 8. 结论边界与下一判断

梯度和因子乘积关系精确闭合候选计算，但没有证明 MoE 有益。SAE 编码移动、激活距离、聚类分离、线性探针准确率不能代替原生留出损失；表征干预也不能直接叫可实现的参数训练方法。

**唯一下一判断：**审核并冻结两阶段现象 Protocol，已授权的 Smoke 只用于修复测量与执行。完成条件是架构细节、数据切分、算量定义与预算、实用界和判断规则获批，并完成工程资格检查。之后只运行另行批准的正式范围；若现象不支持或尚未测到，不升级为大量 SAE 方向分析。
