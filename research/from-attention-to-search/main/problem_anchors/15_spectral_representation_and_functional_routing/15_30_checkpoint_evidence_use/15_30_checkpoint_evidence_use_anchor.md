## 2. Physical Priors
A visible fact can affect a causal decoder's next-answer distribution. A lexical prior can select one answer without using it; success in both fact versions guards that alternative. These are task assumptions, not a law of distance decay. Long text, distant dependence, rare features and long-tail knowledge are different objects. The teacher's question concerns classification and learning efficiency; the senior's discussion motivates a matched local comparison and distinguishing general skill, domain knowledge and particular facts.

## 3. Falsifiable Hypotheses
The user leaves the direction open: far evidence may be learned later, at similar progress, or inconsistently. The main observable is correct paired switching versus actual pretraining tokens. Live rivals include task/completion-format difficulty, lexical priors, position/filler competition and unknown pretraining exposure. No gradient-interference mechanism is tested.

## 4. Mathematical Model
A family fixes entity, answer pair and wording. In each condition replace only the decisive fact A/B. Score each complete candidate by its conditional token log probabilities, summed in nats. The correct-minus-other margin is positive for a correct ranking. A family succeeds only if both A and B margins are strictly positive. Evidence gap counts tokens between the last fact-value token and the last prefix token: gap = prefix_last - evidence_last - 1. Candidate ranking is the observed behavior, not open-ended generation.
