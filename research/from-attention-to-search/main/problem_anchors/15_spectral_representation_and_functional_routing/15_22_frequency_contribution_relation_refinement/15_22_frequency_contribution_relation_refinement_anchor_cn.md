# 频率贡献桥梁与同频关系细分

状态：**DRAFT_NOT_EXECUTABLE／待研究者确认**。本文件是用户提供附件的八节整理稿，不是新实验批准，也不报告本轮已执行结果。附件将“原始末层贡献份额优先、常态校准为对照”记为已确认方向；本次整理未独立核实该历史批准，未将建议默认参数提升为研究者决定。完整原文见[来源副本](sources/feishu_report_anchor_v0.1_cn.md)；执行参数及待确认项由[Protocol](../../../experiments/A15/15_22_frequency_contribution_relation_refinement/20261019_bridge_dispatch/protocol_cn.md)承接。

## 1. 问题定义

**当前输入的末层表征中，各频率段 feature 的贡献组成，能否提供超出当前词片身份的输入画像；在频率相近的范围内，φ 共现关系细分是否进一步改善可复核的实际输入组织？**

母问题是在固定参数与计算预算下，让专家分工帮助模型学好并保留更多内容。已有记录提示：名单组织、实际接收和学习收益是三个不同环节，校准改善接收并未保证留出学习改善。本轮选择先检查分工依据，不将这条路线写成改善学习的必要条件。

“当前位置”是模型预测下一个 token 时使用的当前 token 及可见前文；“低频”指 feature 在 TRAIN 有效预测位置上的命中率低，不等于词片罕见、知识罕见或学习困难。分析对象是冻结基座、冻结字典下的输入画像、关系及固定路由；不在此轮自动训练专家，也不测容量倍数。

若画像包含词片身份之外的差异，且关系细分在匹配随机对照外保留可复核组织信息，可保留这一路线进入后续设计讨论；若词频桥梁方向被否定，撤回该方向预测；若关系不提供增量，保留频率基线而不追加关系复杂度。支持不足或数据隔离不足时只记录不确定，不把不足写成无结构。

## 2. 先验或候选直觉

1. **候选直觉：**当前位置的上下文化表征包含不同频率的 feature；其末层贡献组成可能比单个词片 ID 更细致地描述输入。这是待检查的表征画像，不是已定位语义功能。
2. **候选直觉：**先确定贡献最突出的频率段，再按该段具体 feature 关系细分接收者，可能避免仅按词片身份分发，或把全部低频内容交给同一专家。频率相近与共现关系都不保证共同学习相容。
3. **测量前提：**冻结字典及原门控提供同一套共享 feature 坐标；末层 decoder 幅度用于构造贡献代理。这个代理不能替代信息量、因果作用或梯度帮助。完整表征仍携带高频信息，路由不删除 common。

## 3. 可证伪假设

**H1：词频桥梁。**低频 feature 的末层贡献份额与当前 token ID 的稀有程度正关联。竞争解释是画像主要重复词片身份、格式或位置；关联弱或反向则反对所提出的正向桥梁。固定同一 ID 后的上下文差异仅提示额外变化，不能把剩余差异全部解释成语义。

**H2：关系增量。**在相同频率段、相同专家数，并匹配子组成员数及细频率分布后，φ 子组相对随机子组在复核对话上保留额外共现，并使实际接收输入的原子组成更一致。竞争解释是 TRAIN 高 φ 只来自构造目标、有限样本或边际频率偏好，未形成可复现且被路由使用的差异。

**H3：后续学习价值，NOT RUN。**在共同训练预算和评价规则下，频率优先加关系细分相对匹配随机细分改善留出任务表现，并保持原有能力；原始规则与常态校准分别比较。H1/H2 成立并不推出 H3，当前无训练分析不填写 H3 结论。

## 4. 数学模型

**输入和冻结状态。**TRAIN 有 \(N\) 个有效答案预测位置，字典范围为全部 \(F=16{,}384\) 个 feature。\(x_t\) 是当前 token 与可见前文，\(v_t\) 是当前 token ID，预测目标为 \(v_{t+1}\)。\(h_{28}(x_t)\) 是末层表征。\(z_i(x_t)\) 是冻结 CrossCoder 经原门控后的非负共享激活，仍由 14 层联合编码产生；\(d_{28,i}\) 是 feature \(i\) 的末层 decoder 向量。模型门控不被替换为“每位置恰好 Top256”。

**频率与贡献是不同量。**定义命中指示 \(A_i(x_t)=\mathbf 1[z_i(x_t)>0]\)，feature 频率 \(p_i=N^{-1}\sum_t A_i(x_t)\)，当前 token ID 频率 \(f(v)=N^{-1}\sum_t\mathbf 1[v_t=v]\)。两者的分母均为指定 TRAIN 有效预测位置；完整输入词频只能作为辅助定义。

末层贡献幅度代理及频率段画像为

\[
c_i(x_t)=z_i(x_t)\lVert d_{28,i}\rVert_2,\qquad
M_b(x_t)=\sum_{i\in F_b}c_i(x_t),\qquad
R_b(x_t)=\frac{M_b(x_t)}{\sum_{j=1}^{F}c_j(x_t)}.
\]

\(F_b\) 是仅用 TRAIN 冻结、从低到高排列的正频率段。\(M_b\) 是贡献总量，不除以组人数；\(R_b\) 是原始贡献份额，不是校准分数，也不是解释方差。TRAIN 零命中 feature 另列未知频率集合 \(U\)，不能当作最低频。\(F_1,\ldots,F_B,U\) 覆盖完整字典；画像分母保留 \(U\) 及最高频 feature 的贡献。复核中 \(U\) 的贡献单列，不能用复核频率重新分段；总贡献为零时份额不可估。\(B\)、边界等参数保持待确认，见 Protocol。

**原始贡献主规则。**令 \(G_{b,k}\) 是频率段 \(b\) 内第 \(k\) 个子组，每个正频 feature 只属于一个子组，\(\sum_b K_b=K\)。路由先在 TRAIN 已观察频率段中选择总贡献最大的段，再在该段选择贡献最大的子组：

\[
b^*=\operatorname*{arg\,max}_{b}M_b(x_t),\qquad
k^*=\operatorname*{arg\,max}_{k}\sum_{i\in G_{b^*,k}}c_i(x_t).
\]

总贡献为正时，第一步等价于在这些段中最大化 \(R_b\)。将**完整** \(h_{28}(x_t)\) 送入专家 \((b^*,k^*)\)，不只发送子组分量。平局及所有已知候选贡献为零时使用预先冻结、与答案标签无关的位置哈希回退，单列回退比例，不将其称有效路由。

**常态校准对照。**只将第一步换成最大化 \(M_b(x_t)/\mu_b\)，其中 \(\mu_b=\mathbb E_{\mathrm{TRAIN}}[M_b(x_t)]\)；第二步及其他条件不变。它比较“绝对贡献最多”与“相对平时最突出”。\(\mu_b\) 须可估且支持充分；零或不可估时报告阻塞，不用任意小分母放大优势。均值校准不保证专家负载相等。

**同频段关系。**令 \(p_{ij}=\mathbb E_{\mathrm{TRAIN}}[A_iA_j]\)，二元激活相关系数为

\[
\phi_{ij}=\frac{p_{ij}-p_ip_j}
{\sqrt{p_i(1-p_i)p_j(1-p_j)}}.
\]

仅在同频段内将 \(w_{ij}=\max(\phi_{ij},0)\) 作为正共现候选；\(p_i\) 或 \(p_j\) 为 0 或 1 时 φ 不可定义，须单列而非称为不相关。分段不能消除全部边际偏好，故随机对照仍匹配细频率分布。

**实际接收。**对 split 内专家分配 \(e(x_t)\)，\(q_{i,e}=P(A_i=1\mid e(x_t)=e)\) 是专家内部命中频率；\(r_{i,e}=P(e(x_t)=e\mid A_i=1)\) 是 feature 命中时的接收率。所有 feature、包括组外高频 feature，都进入统计。空专家的 q 为 NA；命中但零接收的 r 保留 0。同一 split 且分母可估时，

\[
q_{i,e}=\frac{p_i(\mathrm{split})\,r_{i,e}}
{P_{\mathrm{split}}(e(x_t)=e)}.
\]

这是条件概率恒等式，解释接收率与专家内频率的区别，不是新的经验机制。

## 5. 计算实现

**画像与词频桥梁：**来源建议复用当前 Tulu SFT 相同 TRAIN 的 85,548 个答案预测位置。先核对原始 h、共享 z、样本 ID、目标及因果位置逐位置对齐，区分第一答案预测位置可能仍处在 prompt 末尾的情况。TRAIN 冻结 p、f、分段和校准均值；保存当前位置/目标 ID、对话、来源、答案内位置、各段 M/R、总贡献、非零原子数及 U 贡献。目标 token 和未来文本不参与路由。此步的目的，是把画像定义落实成可追溯位置，而非先赋予语义标签。

**桥梁检验：**比较低频份额与当前 ID 稀有程度，并检查同 ID 跨上下文变化。用 TRAIN 的逐 ID 平均份额预测复核位置，与 TRAIN 全局均值预测比较误差；剩余误差不自动代表语义。按对话而非独立位置估计描述性不确定性；随机文本与高低份额实例分别标明，保留可见前文，右文仅辅助阅读。

**关系复核：**在当前 TRAIN 重新计算同频段关系，冻结候选子组后与匹配成员数、细频率分布的随机子组比较复核共现及实际输入组成。旧 DCLM 关系只作历史参照。聚类、分段、随机化、可靠性诊断、复杂度和稳定性检查均由 Protocol 指定；建议默认值尚未批准，不在 Anchor 中另设参数。

**实际分发：**比较原始规则／常态校准与关系／随机子组的交叉条件，保持同一输入、频率段、专家数及段内原始贡献选择。报告 q、r、富集、负载、零接收、未知频率、回退以及随机/高贡献文本。以选中频率段的归一化贡献向量检查组成一致性；该指标不等于语义一致或学习相容。

以上均为待执行分析。后续学习需另冻结共同预算、初始化配对、监督目标、优化器、独立 DEV 与未用于选型的新留出；不可自动启动，也不可按已看 EVAL 选择最好轮次后称正式成功。

## 8. 边界及下一决策
