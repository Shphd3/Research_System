# Context relations: composition, distance and prediction use

## 1. Problem Definition

In a frozen Qwen3-0.6B Base, how do required relation count and evidence distance accompany changes in answer preference, layerwise information and bounded state interventions? This is a researcher-activated representation audit within the MoE direction: understand information use before drawing conclusions about sharing or expert learning. ## 2. Physical Priors

The candidate intuition is that different contextual relations can contribute to prediction. It remains unproven that a fixed language granularity belongs to a layer, that useful states are globally low rank, or that common and remaining parameters should learn separately. A task dependency path can be defined independently of the model; its length is not a count of internal reasoning operations.

## 3. Falsifiable Hypotheses

Exploratory question: do answer preferences and registered internal measurements differ between one/three necessary relations and nearer/farther evidence? Rivals include serial position, language-template transfer, magnitude, answer information in a patched state and intervention distribution shift. All are retained where controls do not separate them. No practical-effect threshold or mechanism verdict is invented from test results.

## 4. Mathematical Model

The external directed-graph solver assigns Yes only if the query direction is reachable and No only if the reverse is reachable; ambiguous or cyclic cases are invalid. C is the unique required path length (1 or 3), verified by deleting each necessary edge. D records token distances from the query to those edges; moving a fixed five-fact neighborhood changes order as well as distance. Total facts, lexical content and entity counts are matched. F is unavailable as a relation-exposure quantity and stays BLOCKED.

For each prefix, margin is the correct candidate log probability minus the incorrect candidate log probability, in nat. The primary descriptive comparison is the deep far-minus-near margin difference minus the shallow far-minus-near difference, first averaged within graph/entity families. Family bootstrap describes item variation in one trained model. Complete block residual states and output-minus-input increments are distinct matrices. Train-only statistical fitting and linear readouts do not update the model.
