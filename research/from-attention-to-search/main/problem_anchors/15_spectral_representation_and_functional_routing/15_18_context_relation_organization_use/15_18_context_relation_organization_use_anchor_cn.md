# 上下文关系：组合、距离与预测中的使用

## 1. Problem Definition

本轮问题是：冻结 Qwen3-0.6B Base 中，一条或三条必要关系、较近或较远证据，分别伴随怎样的答案偏好、逐层信息和限定状态干预结果？它属于研究者新近激活的 MoE 表征审计，先理解信息怎样参与预测。既有 A17 条件映射训练和领域更新几何保持各自身份。本轮是一项实验内的 E00–E10 分析，不是十一项独立问题。V3 及随后的任务、模型、预算确认授权完整第一流程；机制判断待研究者审阅。

## 2. Physical Priors

候选直觉是不同上下文关系可能共同参与预测。每层对应固定语言粒度、有效表征必然整体低秩、common/remaining 应分开更新，均未成立。题目必要路径长度不等于模型内部实际推理步数。

## 3. Falsifiable Hypotheses

探索性问题：必要关系数和证据远近改变时，答案偏好及登记的内部量怎样变化？竞争解释包括顺序、模板泛化、整体幅度、供体状态携带答案，以及干预造成分布偏移。没有区分的解释保留；不从测试结果制造科学成功阈值。

## 4. Mathematical Model

外部有向图求解器只在查询方向可达且反向不可达时标 Yes；反向可达时标 No，未知不能当 No。C 是必要关系数 1 或 3，逐边删除验证必要性。D 是查询到必要事实的实际 token 距离；移动包含查询实体两侧邻边的固定五事实邻域，仍同时改变顺序。总事实数、词项和逐实体出现次数匹配。没有可靠的关系暴露频率 F，相关栏保持 BLOCKED。

主要连续量为正确答案相对错误答案的条件对数概率差，单位 nat。主比较为深组合远减近差值，再减浅组合远减近差值，先在题族内平均。按题族重采样的区间只描述这一模型的题目变化，不覆盖训练随机性。完整残差状态、block 输出减输入的新增量是不同矩阵。统计拟合和线性读出只使用训练划分，不更新主模型。

## 5. Computational Realization

E00–E02 校准资产、标签与原生行为；E03–E07 保存全部 28 层原生量、谱、读出和相似性，字典只覆盖实际登记接口；E08–E09 使用训练方向、独立开发选层和测试干预；E10 核对覆盖和关键数值。按研究者要求省去重复流程检查，保留无操作、真值、泄漏与预算检查。精确设置由 Protocol 和执行清单拥有。

## 6. Minimal Falsification Tests

报告原始候选概率、题族配对 C/D 差值及区间、全部登记层和干预对照。区间不跨零不等于科学成功。行为弱或失败不自动取消描述分析，但不能把错误预测上的干预解释成正确推理路径。标签、接口、无操作失败仅阻塞依赖项目。研究者审阅前不发布机制支持或否定判断。

## 7. Current Evidence

登记时已生成 128 个题族、2048 个匹配变体；可达性、逐边必要性、反转答案和划分检查通过。原生模型结果为 NOT RUN。持续产生的事实和失败由执行输出及事实报告持有；科学判断保持待研究者审阅。


当前事实交付：E00–E10均有最终记录；适用的原生C×D、28层谱/读出、合格A22特征及105组投影条件已运行。最终同组批功能无操作误差为0。F仍未识别，SAE在当前任务重构无效。[事实报告](../../../experiments/A15/15_18_context_relation_organization_use/first_flow_v3/summary_cn.md)持有全部数值和限制。机制判断继续待研究者审阅。

## 8. Claim Boundary And Next Decision

本轮不识别 common 参数，不证明路由收益、固定语言层级、受控预训练暴露作用或学习率策略收益。唯一下一决定：研究者先读事实结果，复述观察并判断是否值得形成更窄的问题；AI 机制分析随后进行。[Protocol](../../../experiments/A15/15_18_context_relation_organization_use/first_flow_v3/protocol_cn.md)持有执行范围和设置。
