# A15_17: SAE Sidecar and Reusable Representation Organization

## 1. Problem Definition

The mechanism question is whether sparse reconstruction pressure applied through a sidecar during training changes how the backbone organizes relations across different wording and contexts so that the relations become easier to retrieve and, in a later test, usable in prediction—or whether it mainly changes vector scale, within-class spread, surface-cue responses, or the dictionary's view. This is not a contest among named models. The immediate decision is narrower: at exactly 21B training tokens, does the original eight-layer sparse-autoencoder (SAE) sidecar make relation direction more linearly accessible from the backbone's native attention write than the Dense checkpoint on unseen entity pairs and paraphrased templates? This frozen, single-lineage comparison decides whether a targeted test of actual model use is worth designing; it does not establish use itself. The block-8-only S7 branch, continued with a smaller reconstruction coefficient from an earlier parent, is a diagnostic endpoint, not a matched layer or coefficient effect.

Here “attention write” \(a\) means the output after attention output projection \(W_O\) and before residual addition, without a new side normalization. The sidecar observes \(a\) but its reconstruction is not fed to the MLP in normal inference. A linear probe shows what a fixed simple reader can extract from frozen vectors, not what the language model uses. Academic M2D2 tests domain organization and PAWS tests natural paraphrase contrast as separate scope checks; neither replaces the controlled relation test. Language-prediction cost remains an adverse-result guard. The immediate rival is that earlier geometric differences arose from scale, compression, lexical/template cues, or the SAE observer rather than reusable native information.

## 2. Physical Priors

The human-confirmed working possibility is that an auxiliary reconstruction gradient can reshape upstream native attention writes even when the sidecar reconstruction is not used in normal inference. The observable is a same-input, same-site change in \(a\) with a held-out relation readout. The prior would fail as an explanation of improved accessibility if only the reconstruction/code changes while native \(a\) does not, or if an apparent native change is exhausted by scaling, common directions, or surface cues. A linear probe can expose information inaccessible to the model's own downstream computation, so behavior is a separate link.

## 3. Falsifiable Hypotheses

Primary hypothesis: original SALL's 21B native \(a\) carries relation direction in a form that a fixed-capacity linear probe generalizes better than Dense across both entity and expression holdouts. Strongest rival: sidecar training changes magnitude, covariance, template response, or online-dictionary reconstruction without improving that native cross-expression readout. The two predict different outcomes on paired held-out entity groups after model-blind lexical checks and fit-only scale/common-direction sensitivities. A positive probe result supports only conditional accessibility, not causality, overall semantic quality, or model use. A negative resolved result weakens this particular accessibility hypothesis. Data, identity, position, or uncertainty failure leaves it unresolved.

## 4. Mathematical Model

For frozen model \(m\), layer \(\ell\), input \(x\), and valid content position \(t\), let \(a_{m,\ell,t}(x)\) be the native \(W_O\) output. Let \(p\in\{\mathrm{last},\mathrm{mean}\}\) select either the last content position or the arithmetic mean over exactly the same content positions. A linear classifier \(f_{m,\ell,p}\) is fitted on the designated fit groups only. The primary decision quantity is the equal-relation-family, equal-test-entity-group difference

\[
\Delta_{\ell}=\operatorname{Acc}_{\mathrm{joint}}(f_{\mathrm{SALL},\ell,\mathrm{last}})-\operatorname{Acc}_{\mathrm{joint}}(f_{\mathrm{Dense},\ell,\mathrm{last}}),\qquad \ell\in\{4,8\}.
\]

Accuracy is a proportion or percentage-point difference on P's joint entity-and-template holdout; it is not a probability that the model internally uses the relation. For a sidecar dictionary, \(z\) is sparse activation, \(\hat a\) its reconstruction, and \(e=a-\hat a\) the residual. These are distinct observables; information in \(e\) alone does not prove that \(\hat a\) lacks it. Norm, spectrum, linear centered-kernel alignment (CKA), between/within-class variation, and both poolings diagnose different alternatives but do not redefine \(\Delta\) after test scores are seen.

## 5. Computational Realization

The primary panel is a model-blind controlled relation dataset: each example gives a fixed two-entity reference order and one statement about left/right, above/below, before/after, or inside/contains. Both truth directions for each template use the same words in different bindings. Fit, development, and confirmation separate entity groups and template pools; the joint confirmation shares neither. The researcher delegated strict semantic inspection to Codex before model results. The initial candidate exposed one ambiguous containment template and two awkward sequence templates, so a separately named P_rel_v2 candidate was generated and all 64 canonical direction examples were semantically rechecked. This is AI review, not independent human annotation; source-group and tokenization guards still apply. Published M2D2 configuration labels provide a natural-domain task but not token-level meaning, and PAWS labels the equivalence of sentence pairs, not individual sentences. Neither substitutes for the controlled primary question.

The learning task is to map a frozen native write to the relation direction for its family. The probe sees only \(a\) and fit labels; it cannot see sample IDs, source metadata, confirmation labels, or another model's predictions. A regularized linear classifier minimizes fit-set cross-entropy plus an L2 penalty; development data chooses its permitted regularization and no confirmation truth chooses layers, thresholds, or templates. Both last and mean vectors are extracted from identical input IDs and masks for all three datasets and all three models. The same native site is captured at all eight blocks; blocks 4 and 8 are preselected for detailed comparison. Online SAE codes, reconstructions, errors, and pre-TopK activation ranks are descriptive observer checks only at layers where a dictionary actually exists. No offline dictionary fitting, new backbone training, inference-K sweep as a fair training comparison, or intervention is in scope.

## 6. Minimal Falsification Tests

The decisive test is the paired 21B SALL-minus-Dense P_rel_v2 joint-holdout linear accuracy difference in native \(a\), reported separately for blocks 4 and 8. Each entity group is one independent resampling unit; template and direction results are balanced within relation family and group. Positive differences whose paired uncertainty excludes zero and whose two preselected tests survive their registered multiplicity rule support a bounded accessibility increase at the corresponding layer, provided model identity, exact hook, leakage, fit-only transforms, and metadata/word-bag controls pass. A resolved negative difference does not support the improvement; an interval crossing zero is insufficient rather than proof of equivalence. If a difference exists only in \(\hat a\) or \(z\), it supports an observer difference, not native backbone improvement. If P is positive but PAWS or N8 is not, the claim stays restricted to P's controlled relations and formats.
