# A15: Representation Geometry and Functional Routing

A15 contains several independent research questions. Its common boundary is
that a readable or concentrated representation does not by itself establish
model use, expert utility, or a mechanism. No single A15 next decision is
assigned by this index.

## Direction snapshot

- **Root question:** Which representation properties are accessible, how do
  training and layer transitions change them, and which, if any, matter for
  routing function?
- **Current answer:** The parent Anchors and their result records contain
  bounded answers for different models, panels, layers, and interventions.
  Geometry, external linear readability, actual model use, and expert utility
  remain separate claims.
- **Claim boundary:** Do not move from variance rank, clustering, domain readout,
  or SAE atom reuse to a causal or functional Router claim without the matched
  test owned by the relevant Anchor and Protocol.
- **Blocking uncertainty and next decision:** There is no umbrella verdict or
  single experiment for all of A15. Use the [project roadmap](../../roadmap.md) and
  [Focus index](../../focus/README.md), then the named Focus and owning Anchor. `Unknown` in a Focus remains `Unknown` here.
- **Resume action:** Use the project roadmap to locate the named question before
  opening its Protocol. Read its Summary first for a completed result and its
  Detailed record only for evidence or deviations. No item below grants
  execution approval.
