## Current Boundary

The controlled conditional-functional-rank theorem is retained. E04 supports a
shared local Jacobian image, while E05/E06 show that a single endpoint or
reference Jacobian does not represent the complete training displacement.
The exact learned ROOT secant is nevertheless effectively low-dimensional and
functionally sufficient. This supports a finite secant/path-integrated bridge,
not a global single-point linearization.

E02 now establishes a narrower result: after a zero-exposure held-out cell gate
confirmed cross-surface use of one common mapping, lowering exact target
frequency from 8 to 1 changed frozen-readout ROOT functional rank by only 0.2
directions on average; the one-sided 95% upper bound was 0.5 against a frozen
two-direction non-inferiority margin. This does not establish that shared
structure beats matched independent mappings, or that frequency is universally
irrelevant. E03 also shows that state-functional reuse does not automatically
identify a stable low-dimensional raw AdamW step space: held-out common capture
was 0.478--0.631, so the causal rare-direction treatment was correctly parked.

## Exactly One Next Decision

Define and independently validate a leave-target-out common *functional/secant*
space before retrying the rare-direction intervention; do not tune the failed
raw-update space on its current confirmation probes.
