# Shared-update research line

[中文](README_cn.md) · [Project route](../../roadmap.md)

This is a placement and reading index of existing questions. The new storage
family does not activate questions, pool verdicts or select a new mechanism.
The long-term question concerns which data should share parameters; the registered
current route remains the domain-update Focus.

Bounded current answer: domain-average activation profiles replicate, but the
current domain-mean gradient descriptor did not improve held-out error. Weak
population domain association and high-dimensional estimation remain unresolved.
This does not reject all update structure or decide Expert allocation.
[Evidence and boundary](../../experiments/A17/17_12_domain_update_geometry/20260930/summary.md)

Active question: [domain-update Focus](../../focus/focus_domain_update_geometry.md).
Human scientific judgment remains Unknown. Its pending next decision is whether
prospective readout is justified or grouping/scale first needs clarification.
The later statistics/compatibility analysis remains a separate record; relocation
does not promote it to another current Focus.

Decision dependencies: controlled effects, post-hoc attribution, prospective
prediction, domain means and functional sensitivity test different relations.
Local updates do not establish long-term sharing benefit. Reading order is not a
universal experimental prerequisite. Completion and resume conditions remain in
the owning Focus, Protocol and results; unconfirmed choices stay unknown.
