1. 假设（研究者提出的对照）。少量全局共同项配独立细节，或不同背景配不同的细节。归入现有问题 2「特征层级与 expert 分发」。
2. 先验 → 模型 → 计算。如果只有边际频率与激活预算在起作用，在保留每列频数和每行度数的域内随机化之后，搭档差异应消失。长度和网页模板是对「几乎每篇有」的竞争解释。复用 HD4-T E16 v2 的 BF16 Qwen、FP32 SAE 稀疏缓存和原始文档映射；使用实际正值。验证 DCLM JSONL 正文、token 与缓存逐行对齐，以原始文档为单位，沿用互不跨文档、互不共享教师上下文的 DEV/EVAL 两段；固定种子 20261121 用于窗口及所有随机对照。每篇每个 L 同一均匀分位点取起点，在 ≥512 的同一子集再次比较。去除规范化正文重复；对共享连续文本和首部做敏感性检查。
3. 跑前预测（AI 建议）。在 discovery 固定排名、搭档筛选、角色和背景，再测 held-out。若控制网站类型、固定每个 token 的度数后仍可重复地预测尾部组成，保留背景条件项；若域内打乱即可解释，则保留域内边际；若稀疏、域不平衡或留出结果相反，判断 Unknown。第三解释是跨网站的词法/位置背景：应看到域内结构和对 token 表面形式的依赖同时存在。分开检验单个网站类型和全语料的覆盖率。词元个数由 TopK 限制，与“主要细节”的功能强度分开。
4. 结果待填。用本地主机读缓存；小样本核验后执行，不训练。
5. 研究者决定：Unknown。
6. 链条位置：表征现象 → 候选组合模型，供路由假设选择。

## 2026-11-21｜原文映射、分布和留出复核

1. 假设。沿用跑前分支，区分全局独立、来源条件组合和更局部的词形背景。
2. 先验 → 模型 → 计算。稀疏预算和长窗口都可能制造表面共享。将 E16 v2 的 64 个分片逐 token 映射回原始 DCLM 正文，先用六篇原文和一对手算概率验方向，再求同位置计数和各篇覆盖。用域内保双边际重排区分预算与具体搭档。额外用同 token ID 对照、同批原文文首上下文重置、按源内原文散列重分复核。
3. 跑前预测。域内打乱若已足以解释具体搭档，则保留域内边际。若独立留出上仍能借助共同项预测细节，给数据生成器增加条件分布。稀有或跨域、功能主张证据不足处留为 Unknown。
4. 结果。3,517 篇原文、4,189,818 个有效 token。主留出 1,870 篇，整篇覆盖 ≥95% 有 43/30,000，256 窗口有 33/30,000（1,477 篇）。四类来源逐一达标的同一组分别有 33、20。逐篇重置后为 66、34；种子 20261121 重分原文后为 63、35。2,094,941 个留出位置全部为 32 个正值，平均 12.736 个 common、19.264 个 tail。域内保双边际重排可复现粗计数。按来源和共同项抽取的条件模型将留出 512 个尾项加“其余”的加权 TV 从 0.03142 降至 0.01485；再给表面词元后，尾项预测改善 0.08234 nat/尾项。两个代表搭档控制词形后，域内约百倍的共现富集降到 1.14、1.07。HIFER 的 34,657 条直接边有 30,530 条在留出再达阈值。本轮只做观测统计及冻结前向。
5. 研究者决定：Unknown。按跑前分支的 AI 建议为保留少量跨来源共同项，用“背景下的多项细节”代替独立单细节。在把背景解释成语义域前，纳入词形。专家收益、下一词贡献与单一路由的充分性仍 Unknown。

## 句末与词元组合补测｜跑前
1. 假设。相同词元会反复招来一部分 common 和 tail，句末可能强化共同项。
2. 先验 → 模型 → 计算。词形、标点与语义可能混杂。复用相同原文、tokenizer、E16 正激活、发现集前 300；适配为原句的标点末位、末个词及同句内部词对照。以词元内的激活比例画图，以同批频率排序比较 Zipf。只读 CPU，概念没有真值标注。
3. 预测。若两类坐标均在同 ID 多次重复，保留两类词形背景；若主要只有 common 则限制结论。若末标点差异在末词消失，优先解释为位置与词形；若两者均复现，保留句末状态假设。稀少或结果不稳则 Unknown。
4. 结果待补。5. 研究者决定：Unknown。6. 链条位置：表征现象 → 条件组合模型。

## 句末与词元组合补测｜留出结果

4. 结果。在 1,863 篇留出原文中识别 74,336 个有终止标点的可比句末。精确对齐右边界的 48,051 句来自 1,808 篇，句末每位置平均 14.29 个 common、17.71 个 tail，正激活和分别 262.81、80.25，逐位置 common 幅度平均占 76.68%。同批末词与内部词分别为 69.66%、65.61%。937 个双半支持 ≥200 次的 ID 中，803 个有至少一个在两半各 ≥50% 位置激活的 tail。温度词组发现的八项，在原词组留出 76 句中平均亮 2.32 个，对照 1.29 个；跨措辞仅 4 句。全部正文发现集 rank 100–10,000 的斜率指数 0.678，句末 1.647。句末未见 12,703 个，等量同篇随机位置 20 次未见 144–173 个。

## Common／tail 的方向｜跑前
1. 假设。高频坐标的解码方向可能更集中；频繁同亮或更大幅度本身均不能推出同向。
2. 先验 → 模型 → 计算。以原 E16 字典列为写入方向，单位化，复用 discovery 前 300 与其余 29,700 划分；算组内全部异项的有符号余弦、绝对余弦、对组中心（含自身及剔除自身）、两组中心之间余弦。用已有留出同位置共现数重加权，检查活跃组合不同于字典等权的程度。
3. 跑前预测。若同组有符号余弦明显偏高且高于等规模 tail 对照，考虑引入共享方向；若主要仅绝对值偏高，保留有正负朝向的相关结构；若两组近似且均接近零，边际高频不足以支持共享方向。只解释本字典几何，任务学习另需标签与干预。
4. 结果待补。5. 研究者决定 Unknown。6. 链条位置：表征几何 → 候选语义模型。

4. 结果。decoder 单位列的异项两两有符号均值：common/common 0.004948、tail/tail 0.004226、跨组 0.002218；逐项对去自身中心的均值分别为 0.054682、0.064751。1,000 次从 tail 无放回抽 300 项，各次组内均值的中间 95% 为 [0.003179,0.005316]。按留出同 token 共激活次数加权后，common/common、tail/tail、跨组分别为 0.015523、0.078173、0.026306。向量求和恒等式独立复核两两均值，权重总和等于 2,094,941 × 496。输入 checkpoint SHA-256 与上轮身份相符。
5. 研究者决定 Unknown。按跑前分支，当前数据不足以给 common 设一条所有成员共同朝向的解码轴，建议把局部搭档与整体频率区分。6. 链条位置：表征几何 → 数据模型。资产 `analysis_e16_common_tail_direction_cosines_20261121`。[结果](/data/250010109/MoE_Router/experiments/1121_sae_corpus_model/directions/pair_cosines.csv) · [计算](/data/250010109/MoE_Router/experiments/1121_sae_corpus_model/directions/measure.py)

## 2026-11-21｜成对反事实与 feature overlap｜评测点子
1. 假设（AI 建议）。一项因子在任务中学到的标准，是替换该因子时，模型在新背景中能按任务规则改变答案。竞争解释是模型记住了背景或搭档。
2. 先验 → 模型 → 计算设计。合成器保留背景，只切换目标因子的两个合法取值，造出正确候选相反的一对题。固定候选与温度，对每对取两题正确候选概率的较小值；按背景类求均值，再取该因子应适用的各类中的最低值为 S_i。各模型用正常选路。11/19 手稿的同一路径正交投影特例中，若固定候选分差为 d₊ 和 d₋，则半差 G=(d₊−d₋)/2 等于目标单位方向的平方投影 overlap，半和 B=(d₊+d₋)/2 表示背景偏移，较弱一题的正确分差为 G−|B|。该成对评分比原手稿的逐题均值更严。
3. 跑前分支。成对留出达标且训练前未达标，支持本轮学会；overlap 高而成对行为不达标，记录可表示但使用未达标；不能合法单独切换、任务不依赖该因子或样本不足，记 Unknown。common/tail 沿用发现集定义；逐 feature 等权报告分数、达标数和待定数。比较容量时可固定 common 达标约束，再比较同一套参数同时保住的 tail 数。
4. 结果。仅设计与代数推导；无模型测量。5. 研究者决定：Unknown。6. 链条位置：表征几何 → 任务可用性判据。
今日认识更新：在原线性模型中，一对同背景题能同时读出方向保留量与背景偏移；它们分别解释“有无可读信号”和“在该背景能否正确使用”。
