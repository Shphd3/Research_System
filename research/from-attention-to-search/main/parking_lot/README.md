## P01 — 稳定判别子空间是否具有专家相对效用？

- **为什么重要：**几何可分和细类可读不能证明某个 expert 比其他 expert 更适合处理该 token；这是从候选坐标走向 expert specialization 的必要功能门。
- **当前为什么不做：**本周期只裁定方向是否真实、稳定及其共享/特有结构。
- **重开条件：**A15_07_E01 在密封表达上通过非平凡低秩与稳定性门，且研究者确认进入功能 admission。

## P02 — 通过的方向能否被无标签、在线且低成本地估计？

- **为什么重要：**当前方向使用细类监督；若无法用部署时可获得的信号近似，就不能直接成为 Router 输入规则。
- **当前为什么不做：**先确认监督目标本身找到的是可靠对象，否则研究部署近似没有对象基础。
- **重开条件：**稳定方向通过，并且后续专家相对效用也通过。

## P03 — 共享/特有结构能否跨数据、模型和相邻层迁移？

- **为什么重要：**只有一个模型、两个层和一个层级任务上的结构不能支持普遍性主张。
- **当前为什么不做：**复制不能修复当前对象尚未通过新表达稳定性的问题。
- **重开条件：**本周期得到合格共享或特有成分，并先冻结一个最小跨域复制问题。

## P04 — A06 的训练时选择性共享是否值得进入真实稀有/常见工作负载？

- **为什么重要：**这是 A06 在冻结最后一层 headroom 失败后的既有项目级决策，关系到是否继续训练期功能修正路线。
- **当前为什么不做：**它不回答本周期的方向真实性问题，并行推进会重新造成多个组会主问题。
- **重开条件：**当前 Focus 关闭，且研究者明确把 A06 设为下一周期唯一核心任务。
