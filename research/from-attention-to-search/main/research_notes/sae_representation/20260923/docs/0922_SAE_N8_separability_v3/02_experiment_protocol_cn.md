## 1. 目的、假设和研究边界

**目的：在同一 N8 数据、同一训练词元进度和同一读点上，检验 SAE 模型的几何变化是否伴随领域信息更容易被简单方法区分。**

本轮“语义可分”只操作化为：八个学术来源类别在未参与拟合的记录上，能否被线性分类器更准确地辨认；另用固定的无标签聚类检查类别是否更符合所选距离下的分组。它不是语言模型全部语义能力。

**候选假设：** 领域相关区别可能在 SAE 重构约束下更便于简单方法利用。若进一步形成更明显的类别团，应有聚类和类间／类内散度比的对应证据。

**竞争解释：** 正则主要改变共同方向、幅度或字典使用集中度，没有改善领域区别；或者改变只在 SAE 重构后可见，原生注意力写入没有相应改善。

这是对候选训练方案的冻结诊断。现有模型训练历史并非严格匹配，不能把方案差异全归因于一个正则系数，也不能用相关变化证明“几何变化导致分类改善”。

**本轮不做：** 主干续训、新 SAE 拟合、关系数据、低秩扫描、专家路由、梯度重测、全层全时刻扫描。历史 21B 结果只作已知背景，不与新 17B 数字拼接。

## 2. 固定模型集合和比较

### 2.1 模型角色

### 4.4 备用重建路径：`N8_sep_v2` 的完整规则

此节是新构造建议，不是对旧 N8 原生成器的倒推。优先使用已下载、带哈希的 M2D2 原始记录。上游数据集登记为 `machelreid/m2d2`，按上述八个配置取得 `text` 字段；官方数据卡给出了按配置加载及 `text` 字段示例。citeturn193805view2

上游页面提示旧加载脚本涉及 Python 执行；不要为了下载数据直接在正式实验环境运行未经检查的远程脚本。优先复用已验收的本地原始数据或原加载环境。需要重新下载时，先固定完整数据版本、检查加载器并记录哈希；若来源仍无法取得，停在 `DATA_UNAVAILABLE`，不能用 AI 生成文章替代。

**逐条处理规则：**

1. 适配八个配置的真实记录到 `raw_records.jsonl`。字段固定为 `label_name, text, source_revision, source_file, source_split, source_row, source_document_id`。来源字段依据实际元数据填写；原始文本字段必须是 `text`，标签来自配置，不从正文猜测。
2. 对原文只做 Unicode NFKC、换行规范化和空白折叠以生成**去重哈希**；分词仍使用原始 `text`，不得删除正文中真实出现的领域词。
3. 用训练时相同的已核验分词器，`add_special_tokens=False` 编码。少于 256 词元的记录剔除；其余取前 256 个词元，恰好一个窗口。禁止填充、复制或跨记录拼接来补正文长度。
4. 建立重复组：相同真实 `source_document_id`、相同规范化全文哈希，或相同 256 词元窗口哈希，满足任一项即合并为连通组。同文档 ID 要带来源命名空间。无文档 ID 时只按后两项处理，并标为记录级、未证明论文级隔离。
5. 一个连通组若含多个领域标签，整组排除；只含一个标签则保留稳定排序最小的一条。稳定键为 `source_revision|label_name|source_split|source_file|source_row|text_hash`。剔除量按类别和原因记录。
6. 对每类所有剩余记录，以 `SHA256("20260923|N8_sep_v2|" + stable_key)` 升序排列，哈希相同按稳定键排序。取前 600 个不同重复组；不足 600 则失败，不重复采样，不减少样本量。
7. 每类排序后前 300 条为 fit，随后 100 条为 dev，随后 200 条为 test。三划分的重复组严格不交叉。原来源 split 仍保存在元数据，但此处是一个重新定义的分析划分，不能声称保留官方划分。
8. `sample_id = SHA256("N8_sep_v2|" + stable_key)`。输入就是步骤 3 的 256 个词元，正文掩码全部为真。保存分词器版本、源数据文件哈希、全部入选稳定键及排除记录。
9. 导出 `records.jsonl`、`label_map.json`、`manifest.json`、`data_audit.json`。先冻结文件哈希再采集模型表征，不根据模型结果改变样本。

若新 v2 与旧 N8 有重合，记录重合数量；本方案不宣称它是全新独立确认集。没有近重复或论文 ID 的完整审计时，也不能据这些精确去重步骤声称“所有来源泄漏均已排除”。

## 5. 表征采集：主对象只能是原生写入

### 5.1 取点和张量定义

记第 8 层注意力输出投影之后、残差相加之前的原生输出为 \(a_t\)。主干正常计算使用 \(a_t\)；在线 SAE 的稀疏系数为 \(z_t\)，重构为 \(\hat a_t\)。本轮主对象是 \(a\)，不是 \(z\)、\(\hat a\)，也不是 `norm2` 后的输入。

只读第 8 层（零基索引 7）。主汇聚为：

\[
a_i^{\rm mean}=\frac{1}{256}\sum_{t\in \mathrm{body}_i}a_{it}.
\]

同一次前向额外保存最后正文词元的 \(a_i^{\rm last}\)，作为位置敏感性分析；不能在结果出来后改主读点。

**最小采集：** 三模型的 `a_mean` 和 `a_last`。**解释性附加：** 两个 S7 同次前向的 `recon_mean`、`recon_last`；只有确有在线字典且可无歧义读取时采集。没有字典的 Dense 不拟合新字典。

不能先求平均输入再经过 SAE，并称之为“逐词元重构的正文均值”：SAE 含非线性／截断，这两个操作一般不同。

### 5.2 冻结和执行方式

模型与在线 SAE 均设评估模式；禁用主干更新和优化器，关闭前向缓存，所有模型使用一致的生产注意力实现和右填充规则。需要批处理填充时，正文与填充掩码分开。

使用原 17B 模型的实际构造和加载器；不得用通用预训练 Qwen 权重代替定制的 8 层实验模型。模型隐藏宽度、输出投影模块路径从源码和 checkpoint 解析，不从历史聊天猜测。

采集前做每类 2 条开发记录，共 16 条的真实模型检查：确认取点；比较 `residual_before + a` 与送入后续残差路径的张量；比较手算与工具的正文均值／末位；同记录单条与批处理输出一致；重复前向不变；所有参数前后不变。

使用已有生产取点容差。若未登记：残差相加恒等式在相同 dtype、相同加法顺序下应逐值相同；批形状改变造成的浮点差异单独记录，禁止把过宽阈值当作取点正确。先报告最大绝对误差与相对均方根误差，再按真实实现核验，不用“图看起来相似”放行。

### 5.3 缓存契约

## 6. 主分析：全部计算口径固定

### 6.1 预处理

只用 fit 计算逐维均值 \(\mu\)，以及单一整体尺度

\[
s=\sqrt{\frac{1}{N_{\rm fit}d}\sum_{i,j}(a_{ij}-\mu_j)^2}.
\]

三划分统一使用 \(\tilde a=(a-\mu)/s\)。每个模型、每种读点分别拟合其预处理参数；保存参数。\(s=0\) 或非有限值应返回退化状态，不硬加一个常数把全零空间变成可用数据。

这不是逐维白化，也不是主成分降维。主分析不做白化或主成分投影，避免在评价几何前先改造几何。此规格明确本轮尺度分母；历史结果复现则须使用原代码的原口径，不能拿新口径宣称精确复现。

### 6.2 线性领域读出：主指标

使用带平方权重惩罚的多类别逻辑回归，即线性分类器（linear probe）。每个模型分别在 fit 上拟合，保持相同算法和调参预算。

```text
solver            = lbfgs
penalty           = L2
fit_intercept     = true
class_weight      = None
C_grid            = [0.01, 0.1, 1, 10, 100]
max_iter          = 10000
tol               = 1e-6
warm_start        = false
输入               = float64 的中心化、整体缩放表征
```

C 是分类器正则强度的倒数，不是 SAE 系数。按 dev 准确率选 C；准确率相同选更小的 C。保持只在 fit 上拟合的模型，不将 dev 并入重新训练。模型选择和预处理均不得读取 test。

捕获收敛警告；不收敛的候选按预定规则仅增加迭代上限到 20000 重试一次。仍不收敛则报告该读出失败，不选择一个未收敛模型、不更换分类器或扩大 C 网格。

实现时记录实际软件版本。已核对官方接口：较新版本使用 `l1_ratio=0` 表示 L2，旧版本可用 `penalty='l2'`；适配 API 但不改变目标、求解器或多类别方式，不依赖已变动的默认参数。citeturn221104view2

输出逐记录真实标签、预测标签、8 类概率、正确与否；汇总准确率及每类准确率、混淆矩阵。数据严格类别均衡时总体准确率与类别平均准确率一致；分组重采样后仍统一使用类别平均准确率。

### 6.3 几何集中与质心分离

在同一 **test 1,600 条原生正文均值表征**上计算下面各量；仅作结果描述，不用于挑模型或调参。历史图在 fit 2,400 条上的谱摘要不能直接作为本轮 test 谱。

对 test 自身中心化协方差 \(C\)，有效方差维数及前 16 主方向方差占比分别为：

\[
d_{\rm eff}=\frac{(\operatorname{tr}C)^2}{\operatorname{tr}(C^2)},
\qquad q_{16}=\frac{\sum_{j=1}^{16}\sigma_j}{\sum_j\sigma_j},
\]

其中 \(\sigma_j\) 为按降序排列的协方差特征值。可对中心化数据矩阵作奇异值分解后用奇异值平方等价计算；保存全部特征值。若总方差为零，标 `ZERO_VARIANCE`，这两个归一化指标不定义，不能随意填 0 或 1。

令 \(\mu_c\) 是 test 内第 c 类均值，\(\bar\mu=\frac18\sum_c\mu_c\)：

\[
B=\frac18\sum_{c=1}^{8}\|\mu_c-\bar\mu\|^2,
\qquad
W=\frac18\sum_{c=1}^{8}\frac1{n_c}\sum_{i:y_i=c}\|a_i-\mu_c\|^2.
\]

报告 B、W、B/W；W 为零则标明退化情形，不输出有限比值。另报告原始总方差与范数摘要，避免把整体缩小误称为选择性压缩。

跨模型 B、W 的绝对量受坐标尺度影响。主比较看 B/W；另可用 fit 的整体尺度报告 B/s² 和 W/s²。**B/W 是类别中心相对散布，不是线性可分性的充要判据，更不是聚类结果。**

有效维数和 q16 默认只报点估计，不套用其他指标的置信区间；不执行 2,000 次全维谱分解来增加无必要成本。

### 6.4 无标签聚类：解释性指标，不是替换主指标

使用相同预处理后的 fit 表征，不使用领域标签，拟合中心均值聚类（K-means）。本轮明确采用欧氏距离；其“能否成团”结论只针对这一距离和方法。

```text
n_clusters = 8
init       = k-means++
n_init     = 20
max_iter   = 300
tol        = 1e-4
algorithm  = lloyd
seeds      = [17, 29, 43, 71, 97]
```

K=8 来自本轮八类别分析对象，不意味着发现自然世界恰好八个簇。每个外层种子内部按 fit 的簇内平方距离选 20 次初始化中的最小值；不得用 dev/test 的领域标签选初始化或种子。之后固定中心，为 test 分配簇，不在 test 上重新聚类。以上初始化和预测接口已据官方说明核对。citeturn193805view1

用经随机一致性校正的分组一致性指标（调整兰德指数，ARI）比较 test 簇划分与领域标签；它不要求簇编号与领域编号相同。报告每个种子的 ARI、五种子均值、簇大小和 fit 目标值。ARI 接近零是随机一致性附近，不是分类准确率；不要把它换算成“语义保留百分比”。citeturn221104view0

另做 100 次标签置换作为粗参照：保持预测簇不动，打乱 test 领域标签；所有模型使用同一置换。若存在多记录的真实来源组，按组置换其类别，保持组内一致；每次同时报告类别数量，不能把记录级置换称成组置换。

旧参考配置提出过单位长度预处理，本轮主聚类明确改为与线性读出相同的中心化、整体缩放输入；这是**新分析选择**，不是复述一个已完成旧聚类结果。单位长度仅在第 7 节做敏感性检查。

## 7. 必要敏感性分析：不扩成新课题

按下列顺序，主分析结果无论正负都保留，不挑选最有利版本。

**位置敏感性：** 在同次前向的 `a_last` 上重复线性读出和几何摘要，不重新选择层。主次方向相反时，结论限定为读点相关；不能让末词元正差替换均值主结果。

**幅度敏感性：** 对正文均值的已中心化、整体缩放向量再逐样本除以其长度，重复线性读出和聚类。零向量保持零并计数，不除以零。单位长度处理改变了读法，应独立报告，不宣称它“修复了真实语义”。若结果只在该处理下出现，结论限定为该读法；不再加白化或选主成分救结果。

**观察器检查：** 只有完整、同样本的 `recon_mean` 已取得时，使用同样的线性分类器和预处理在该重构上读领域，并列原生结果。重构取每词元 SAE 输出再平均；不把外部读出优势当作主干前向优势。没有对应缓存就写 `OBSERVER_NOT_AVAILABLE`，不阻止原生主分析。

**词面参照：** 固定面板上的领域标签可能有明显词汇线索。可直接复用旧 N8 相同文本／划分的已保存词面预测；只有汇总分时只能作为背景。需重算时，对正文窗口使用词频逆文档频率特征（TF-IDF），词表与权重只在 fit 学习：

```text
tokenizer      = 对窗口文本 casefold 后，用 r'(?u)\b\w+\b' 提取单词
ngram          = 仅单词，无二元词
min_df         = 2
max_features   = 20000
特征选择        = fit 总词频降序，同频按词字符串升序
TF             = 出现次数 tf>0 时 1+log(tf)，否则 0
IDF            = log((1+N_fit)/(1+df))+1
每文档归一化    = L2；全零行保留零
分类器          = 与 6.2 相同的 C 网格、拟合/开发规则
```

这只是判断标签是否容易由词面统计预测，不是容量匹配的模型排名。旧 N8 词面准确率 89.8125% 的记录不能自动用于新 v2。fileciteturn27file0L2-L2

语言损失和梯度不属于本轮主要检验。不因它们仍有争议而扩大本次采集；已有训练损失图仅留在组会备查。

## 8. 配对统计：不要把小正差或跨零解释成已经改善／保持

固定重采样次数 2000，种子 20260923。对准确率、B/W 和 ARI 差做配对重采样；所有模型每次使用相同的记录／来源组权重。

- 有可靠文档 ID 且同文档含多记录：以文档组为单位，在类别内有放回抽样；同组所有记录一并进入，计算类别平均准确率。
- 没有可靠文档 ID：以记录为单位，在八类内分别有放回抽取原类样本数；必须写“记录级条件性区间，来源相关性未完全控制”。
- 同一来源组跨类别时不得直接使用类别内组重采样；先依数据规则处理并报告，不能静默拆组。

区间条件于当前主干、当前 fit 数据以及拟合好的读出／聚类器。Bootstrap 时不重新拟合分类器；它不包含主干训练或拟合样本的不确定性。

完整模式两个预定准确率差各报 95% 区间；**用于宣布两个比较中出现明确方向时，使用各自 97.5% 区间**，以 Bonferroni 方式控制两个方向判断的整体错误率。受限模式只有一个差值，使用 95% 区间。95% 百分位区间取重采样分布的 2.5%／97.5% 分位数；97.5% 区间取 1.25%／98.75% 分位数，分位数插值固定为 linear。B/W、ARI 和所有敏感性结果为解释性读数，不用于“任一个阳性即成功”。

ARI 每次重采样都对五个固定种子分别计算后取均值，再计算模型差。五个聚类种子不是五个独立训练模型。置信区间与五次初始化的离散程度分开报告。

判断规则：准确率差区间完全大于 0，才支持当前范围内的正差；完全小于 0 支持负差；跨 0 就是方向不足以确定，**不是相等、无影响、信息已保留或非劣**。本轮没有注册等效界限，不作等效／非劣声明；效应量大小仍需单独解释。

B/W 的重采样可通过类别和来源组的样本计数、向量和、平方范数和加速复算；不需要重算主成分谱。所有统计脚本必须保存抽样种子、单位和实际样本／组数。
