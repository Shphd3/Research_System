## 3. 与假设分开的竞争解释清单

| 竞争解释 | 它如何伪装成想看到的现象 | 最小区分对照 | 单独出现时应怎样收缩结论 |
|---|---|---|---|
| SAE适应当前状态，而非模型新形成关系 | 编码或重构越来越好 | 固定同一h，只训练或替换SAE；冻结读法读不同h | 只证明读法适应 |
| 分组统计定义变化 | 类别重排、组中心变化 | 固定z，只换统计单位或组映射 | 只证明分类定义变化 |
| 格式/词频/位置因素 | 同模板样本更聚集 | 同义异格式、异义同格式的交叉面板 | 关系可能是形式而非目标内容 |
| 初始化、采样、聚类随机性 | 组出生、消失、分裂 | 同检查点重复SAE拟合、按整条记录重抽样 | 无法区分训练变化与工具噪声 |
| 表示尺度或归一化改变 | 方差比变好、点距离变小 | 原始范数、单位化关系、同一权重分解 | 仅为尺度效应，未证语义 |
| 人为正则强迫结构 | 聚类图变干净 | 自然观察臂，与匹配一般重构/打乱关系对照 | 只能叫干预诱导结构 |
| 教师植入结构 | 更早出现学生关系 | 相同起点、数据与预算下有/无教师分支 | 不能代表无教师的自然形成 |
| 选择性报告 | 最漂亮时间点/特征得出积极结论 | 先锁面板、时间点、选特征规则，保留全覆盖 | 仅为探索案例 |

不要把所有竞争解释都写成“噪声”。其中有些是不同但真实的机制；例如格式特征也可能有功能，只是不是你最初声称的内容关系。

## 4. 不预设答案的判断树

**入口：模型和测量能否回答这个问题？**

模型未通过学习健康检查，或探针关系在数据中没有合理学习机会 → `不足：学习机会/能力未建立`。SAE重构或覆盖明显不足 → `不足：读法不合格`。这些都不是“语义不会形成”。

模型健康、读法合格 → 固定面板比较时间变化与重复测量噪声。

变化未超过校准分辨率 → `未检出`，给出本设置下的最小可检出范围；不要宣布不存在。

变化超过分辨率 → 在固定h上换编码器/分组，并在固定读法下换h。

只有换读法显著改变判断 → `工具变化解释更有力`，暂不主张模型形成了该关系。

固定读法下h的变化也改变了外部关系 → 检查它是目标语义还是格式/位置。

目标语义对照与格式负对照无法区分 → `有变化，但语义归属未定`。

目标关系在确认集上得到支持，且强竞争解释受到约束 → `在该模型、该前缀关系、该区间形成了可读取关系`。是否值得正则化是下一决策，不自动进入“路由有效”。

## 5. 统计规则不是事后挑阈值

主指标建议采用匹配三元组差值：同一锚点a与正例p、负例n比较，m=sim(a,p)−sim(a,n)。正例与锚点同含义异格式，负例异含义同格式；定义仍由你确认。正负值的含义由此明确，但“超过多少才重要”不能由我替你拍一个普适阈值。

先用**发现/校准集**估计同模型重复测量的变化范围，登记可实际检出的效应尺度；研究者给定最小有意义差值δ。再封存**确认集**：相同事实/模板衍生出的多个样本归入同一统计块，以块为单位计算置信区间，不能把每个词元当作独立样本。

如果校准噪声本身大于δ，结论应为分辨率不足，应缩小问题或增加独立记录；不以放宽δ来挽救确认结果。所有画图检查点预先保存，但只预先选定少量时间对做主要检验；其他轨迹作为探索，不把大量挑选后的显著值当主要证据。

两个主模型种子才开始讨论该设置下的可重复性；多个SAE种子只重复测量工具，不能伪装成多个预训练种子。32小时只有一个主模型种子时，要把结论写为“单轨迹机制观察”，不写“普遍规律”。

## 7. “根因完全解释”应改成可检验的解释边界

组会最后分三句：已排除的解释是什么；现有证据最支持哪一个计算环节；还有什么无法区分。即便干预支持某一环，也不声称解释了所有模型、所有语义和所有训练阶段。

可以完整交付的认识更新包括：过去把分类重排当形成，现在知道哪一部分是分组定义变化；过去把重构提升当监督改善，现在知道它没有改善指定关系；过去以为无需更新字典，现在在固定关系上看到更新确实恢复了可读性。是否出现这些结果，要由实验回答，它们不是预先设定的假设答案。
