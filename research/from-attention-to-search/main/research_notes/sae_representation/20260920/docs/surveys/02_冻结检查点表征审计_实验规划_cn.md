# 冻结检查点上的SAE表征审计：实验规划

日期：2026-09-18  
状态：**AI建议；NOT RUN；尚未批准训练或远程执行。**  
研究依据：本轮组会共识、用户已展示结果，以及配套《表征几何与SAE语义对应：文献调研》。  
边界：不创建或修改项目正式Focus、Anchor或Protocol；实际执行前须由研究者确认范围与未知配置。

## 摘要与唯一的下一步决定

本轮的核心问题是：**现有SAE旁支是否改变了主干的语义组织，还是主要改变了观察方式；固定稀疏预算是否漏掉了有用因素？**

先冻结现有检查点，用三项实验回答，不开展新一轮主模型预训练：

- E1：原始表征的几何变化是否对应跨条件语义，而非词汇/模板。
- E2：SAE单特征和特征组能否稳定预测独立语义标签。
- E3：K=32是否在稀疏—失真—语义保留曲线上形成有害瓶颈。

**首要行动：用Dense与SALL的共同10B检查点，复核原P/N结果并增加一个受控语义方向面板。**离线SAE只读取冻结表示；对主干的梯度始终关闭。后续是否采用可变K、分组表示、Matryoshka或MP-SAE，由这三项结果决定。

## 1. 已知、未知与不可偷换的定义

### 1.1 目前已知的入口

这些信息来自用户此前在本对话展示的实验，不代表本轮已核查执行目录。

| 项目 | 当前描述 | 本轮处理 |
|---|---|---|
| 主干 | 8层；Dense、S7、S37、SALL | 首轮Dense与SALL；其他条件仅在定位层位时追加 |
| 共同训练坐标 | 0、0.5、1、3、5、10B有效预测词元 | 先10B；0为低成本未训练参照；5B只用于定位10B突变 |
| P面板 | 360条构造英文，120/60/180 family划分，4粗领域 | 原样复现，不更换标签口径 |
| N面板 | 1,200条M2D2，600/200/400，8学术类别 | 原样复现；旧报告集已被看过，只作探索 |
| 旧取点 | 末层Norm2后、MLP前；P句末，N前256位置均值 | 保留以复现，并另存真实注意力输出 |
| 稀疏预算 | 32 | 必须确认是逐词元Top-K，还是平均L0等其他实现 |

### 1.2 执行前必须补齐

主干实际d、SAE字典M、实际激活函数及L0分布、是否归一化输入/解码列、是否存在跳接、字典和检查点继承关系、辅助损失及梯度截断定义、原P/N样本ID与family、模型训练种子数、准确的DCLM采样视图。

没有以上记录时，不把旧运行称为“完全匹配”；未知项直接标Unknown。若只存在一条主干训练轨迹，所有结论首先限于该轨迹。Probe种子、聚类种子、SAE种子和主干训练种子不是同一种重复。

### 1.3 统一符号

\[a_\ell=\operatorname{Attention}_\ell(\operatorname{Norm}(r_{\ell-1})),\quad s_\ell=r_{\ell-1}+a_\ell.\]

\(a_\ell\)指注意力输出投影之后、残差相加之前；\(r_\ell\)指整层输出。用\(h_{\rm old}\)单独表示旧Norm2取点，避免错叫注意力输出。

\[z=E(a),\quad \hat a=Dz+b,\quad e=a-\hat a.\]

K：每词元稀疏预算；M：字典宽度；Q：样本聚类簇数；q：稀疏Probe最多使用的特征数。四者不能混用。

## 2. 数据设计：旧结果保留，新语义问题另建独立面板

### 2.1 P/N旧面板

原样保留现有训练/开发/报告划分、预处理和指标。所有新增分析标为探索，不能因为看到旧报告结果后换指标，就重新称其为未见确认结果。

自然数据确认建议另取800篇、每个原N类别100篇，文档与旧N面板不重叠。仅用于最终确认，不参与超参选择。若无法满足配额，先统一缩减并冻结清单。这里的“未见”是指评测流程未见；没有训练语料排重证据时，不声称底座预训练从未见过这些文本。

### 2.2 R：受控语义关系面板

**目的不是替代真实语言，而是以可核验真值区分语义关系、主题和表面形式。**

建议因素：

- 关系类型4种：因果、时间先后、大小比较、包含关系。
- 方向2种：相对指定实体E1/E2，关系为E1→E2或E2→E1。
- 语境4种：数学、物理、生物、历史相关的短上下文；不要求底座掌握外部事实。
- 表述家族12组，每个因素组合10个实例。

总量为\(4\times2\times4\times12\times10=3,840\)条。它们由规则生成、可人工核对；标签来自生成的关系结构，不能来自SAE聚类或另一个LLM的解释。

在句子末尾使用统一、不给出答案的读出位置，例如在完整陈述后加入“Consider E1 and E2. Relation:”并在最后有效词元取表示。实体提及顺序、主动/被动、正向/逆向表达需同时平衡。示例“A causes B”与“B is caused by A”标签相同，“B causes A”方向相反；三者只说明构造原则，不是完整测试集。

**主要目标变量为关系方向；关系类型为次要语义标签；语境、模板、长度是竞争解释变量。**只做四种关系类型分类容易识别关键词，不能单独作为强语义证据。

### 2.3 划分与防泄漏

12个表述家族按6/3/3分为拟合/开发/确认；一个命题的同义改写、方向反例和同实体变体必须在同一个划分内。实体词汇集合也按划分隔离，模板不是简单随机按句子拆分。

跨条件测试采用预先固定的四折留一语境：每折拟合使用三个语境的6个拟合家族，开发使用三个语境的3个开发家族，确认使用被留出的语境及3个确认家族。每折理论配额：拟合1,440，开发720，确认240。

四折是预先定义的泛化检验，不是四次独立主模型训练。所有参数选择仅看该折拟合/开发结果；报告每折、每模板家族和汇总，不用确认得分选择最佳语境。

确认模板只有3个家族，不能精确代表所有语言模板。对命题块重抽样得到的区间只表示固定模板条件下的不确定性；模板外推另用逐家族结果展示。若需要更强普遍性，必须增加独立模板家族。

### 2.4 数据验收

检查标签计数、模板与标签列联表、实体跨划分重叠、近重复、方向规则、句尾答案泄漏。对每个关系×模板至少人工核对若干正反例；先做分层抽样审核，不允许只看总体随机样本。

词袋和词/字符n-gram模型作为表面线索参照。词袋表现好提示数据有简单捷径；n-gram表现好则需检查任务是否主要是有限语法模式。它们的弱表现也不是“纯语义”的证明。

## 3. 共同的统计、表示和控制约定

### 3.1 表示对象

E1至少抽取：\(a_4,a_8,h_{\rm old}\)。必要时追加对应整层输出\(r_4,r_8\)解释后续传播。不要首轮保存所有位置和所有层的巨量密集张量。

P/N旧结果严格复用旧位置。R取固定句尾表示。SAE语义检测使用同一词元的\(z\)；N的句级分析另报“逐词元编码再平均”的\(\bar z\)，不能把\(E(\bar a)\)与\(\overline{E(a)}\)混为一谈，也不能给平均后的向量套上K=32上限。

### 3.2 预处理

所有估计器只能在拟合集学习均值、尺度、PCA或协方差参数。以未做逐样本归一化的原始统计复现旧B/W；余弦距离是新邻域/三元组分析主口径，原始欧氏距离为预先声明的敏感性分析。

稀疏激活不对稀有特征盲目做单位方差缩放，避免少量事件被放大。死特征过滤阈值仅依据拟合集。不能按确认集表现挑选特征、簇数或降维数。

### 3.3 三个便宜但必须做的尺子校准

1. 标签在合法条件内置换：保持类别比例，必要时在模板/语境内置换；完整重跑标签相关选择过程，不能只置换最终指标输入。
2. 同一检查点重复评测：区分拟合算法随机性与真实条件差异。
3. 已知真值的小型几何数据：包括随机轴上的K=1数据、连续高维数据、语义信号加高方差无关噪声。先确认当前指标分别响应的是张成空间、局部维度、噪声还是语义。

这些是E1–E3内部校准，不作为第四个大型实验。

### 3.4 不确定性和主要终点

主要语义终点：R面板\(a_8\)上的跨语境/模板方向Probe平衡准确率；旧取点和其他层作为定位。建议最小有意义增益暂设2个百分点，需在看新确认结果前由研究者批准。若原始Dense在开发集已近满分，先调整并冻结新的任务难度，不能看确认集后再换题。

同一事实块、同一文档在各条件之间成对比较，建议2,000次分组自助重抽样；另展示不同Probe/SAE种子的结果。对固定语境和少数模板所得区间不外推到全部自然语言。

本轮三个主要问题分别报告，不做十几个指标的“多数投票总分”。探索性多重特征筛选不能靠单次最大值获得语义真值；确认集与必要的多重比较控制单独处理。

## 4. E1：主干语义组织审计——本轮优先项

### 目的

判断SAE旁支是否改变了主干原始表示中可跨条件利用的语义，而不是仅改变幅度、总体距离或模板组织。

### 假设与最强竞争解释

H1：SALL原始表示相对Dense，关系方向跨语境/模板读出更稳定，且不是由原生语言模型表现恶化或表示塌缩换来的。

竞争解释：旧P上Fisher差异来自无关类内波动变化；主题/词汇足以完成分类；只在SAE重构上换了一种更容易读出的非线性变换。

### 方法

**E1-A 复现与定位。** 同批样本复现旧P/N的B、W、B/W、Probe。补\(a_4,a_8\)并保留\(h_{\rm old}\)。如果Dense在10B发生突变，再读5B及相邻可用检查点，并核对取点、归一化和样本清单；没有这一步，不将突变解释成语义塌缩。

**E1-B 主要检验。** 在R面板上做跨条件线性读出。正则化逻辑回归在开发集选择C∈{0.001,0.01,0.1,1,10,100}，所有主干相同选择预算。报告平衡准确率、交叉熵、每折与每种表述的错误。旧两层MLP按原配置复用为次要读出，不为本轮结果临时加深。

**E1-C 可解释几何。** 使用以下两项，不先加入全部候选指标：

- 匹配三元组间隔：\(m=d(h_A,h_{反向})-d(h_A,h_{同义})\)；正值表示相同关系比词汇相近的反向关系更近。匹配随机三元组作参照。
- 排除同模板家族后的近邻语义一致率，邻居数k_nn∈{5,10,20}，完整报告，不挑最高值。

补充RSA比较语义、模板、词汇与长度距离矩阵；若因素不可区分，回到数据构造。CKA只用于定位Dense/SALL变化发生在哪，不作为成功指标。

### 允许的结果分支

| 结果 | 认识更新 | 下一步 |
|---|---|---|
| 原始\(a_8\)跨条件收益明确，旧取点也保留 | 支持当前关系语义的主干塑形 | E2找出对应因素，再做小规模选择性干预 |
| 仅\(a_8\)改善，后续取点无收益 | 局部变化未稳定传递 | 检查残差/MLP作用，不称整个模型更好 |
| Fisher或AMI改善，跨条件语义无改善 | 几何改变尚未转化为语义可访问性 | 审计模板/尺度，不增加正则权重追求更大间距 |
| 仅重构表示改善 | 更支持读法而非主干改善 | E2比较离线字典与非SAE读出 |
| 两者都无稳定收益 | 在本测试范围未支持塑形假说 | 不启动更大预训练；用E3定位预算是否确有损失 |
| 差异小于测量精度或区间跨阈值 | 证据不足，不是等效 | 增加独立语义条件或样本，不搜更多指标替代 |

`e1_raw_geometry.csv`、`e1_cross_condition_probe.csv`、`e1_triplet_and_neighbors.csv`、每个数据划分的清单与样本哈希、未训练/置换对照、失败例。标题中明确表示对象和数据来源。

## 5. E2：特征与语义对应审计

### 目的

判断SAE是否提供可泛化的语义因子；区分单原子语义、多原子组合、模板特征与未经证实的解释。

### 假设与竞争解释

H2：同样预算的SAE在少量特征下能够识别特定语义，并在未见表达上保留对应关系。

竞争解释：高激活文本只共享词汇；字典宽度带来的大量候选允许挑出偶然高分特征；解释模型在合理命名无语义结构；SAE只是普通非线性特征映射。

### 公平的字典来源

在线SAE只作描述。主要比较使用冻结Dense/SALL上分别训练、同样M、K=32、数据量与训练过程的离线SAE。它们与E3的K32条件共享，不重复训练。首轮只做\(a_8\)；E1明确显示中层变化时才扩\(a_4\)。

### E2-A：样本聚类和语义对应

对同一批样本的h、z、hat h及PCA基线分别聚类。P使用Q∈{4,8,16}，N使用Q∈{8,16,32}。簇中心和预处理拟合后固定，再分配新样本。主结果为AMI，保留NMI、ARI、簇大小和10个种子变化。

同时检查簇与domain、模板/来源等标签的对应。上述指标是样本标签层面的关系，不对特征列分组直接套NMI。标签置换参照需重跑相关选择部分。

### E2-B：单特征与少特征的语义检测

对每个预先定义的语义，比较q∈{1,4,16,64}个特征的受限读出。推荐在拟合集按单变量关联提出候选，再用开发集选择正则化；无论采用哪种特征选择，过程在所有方法中固定。L1探针的“实际非零坐标数”要报告，不能把不同实际q冒充相同预算。

报告每类AP/精确率—召回率、基率、覆盖率与失败例；对于稠密标签可补平衡准确率。单特征AP高但只覆盖少数模板，不叫普遍语义对应。

对照包括：原始h上的强正则化线性Probe、原始坐标/PCA坐标上的相同q预算、同等训练数据的既有两层读出，以及必要的随机映射。原始坐标的稀疏性依赖基底，因此“q特征”更好主要表示轴对齐优势，不代表信息总量更多。

### E2-C：从特征说明到留出预测

选特征只能基于探索数据；同时保留频率分层随机抽取的特征，避免只展示最高分。建议首批24个：12个按频率分层随机选、12个按开发集语义检测候选选，分别报告选择方式。

对每个特征查看高、中、低激活的完整上下文，形成一句可证伪的说明。测试说明对未见同义正例与词汇匹配负例的预测；不允许解释者在看到确认错误后改写说明，再在同一确认集评分。

### E2-D：多维特征组

使用解码方向相似性和同一文本的响应关系提出分组；两者的分歧本身需要记录。对组的部分重构\(D_Gz_G\)做PCA、PR和语义读出。与匹配大小、频率、范数的随机组比较，避免把“大组更有信息”当作语义分解。

跨SAE种子以同一输入上的响应匹配为主，允许一对多的分裂/合并；不强迫相同feature ID，也不把主干变动后的直接字典余弦当作无条件可比。

### 结果与决策

| 结果 | 允许解释 | 方法方向 |
|---|---|---|
| 少量特征跨表述稳定检测语义 | 语义在这些坐标上容易读取 | 再验证模型是否使用它 |
| 单特征差、小组好且稳定 | 支持多维/组合语义 | 分组读出，不强行单原子解释 |
| IID好、跨词汇/模板差 | 可能主要是表面特征 | 改语义数据与表示目标，不夸大NMI |
| Dense和SALL离线字典表现相近 | 尚未建立旁支塑形价值 | SAE可以保留为观察器 |
| 只有在线SALL字典更好 | 可能只是共同适应/字典训练差异 | 以独立离线复拟合结果为准 |
| 所有方法包括随机对照都很高 | 评测可能太容易或无效 | 先修标尺，再讨论SAE |

## 6. E3：稀疏预算与语义保留审计

### 目的

不猜语义维度，而是判断固定K=32在当前输入与字典下，是否漏掉任务相关信息；进一步区分预算限制、编码误差和无关噪声。

### 假设与竞争解释

H3：提高K在部分语义条件下减少可用信息损失；若样本复杂度不同，可变预算可能在相同平均激活数下更合适。

竞争解释：更大的K只重构了更多噪声；字典M不足；字典尚未拟合充分；编码器推断不准确；h的幅度改变导致表观NMSE差异。

### 初始实验矩阵

Dense/SALL的共同10B、同一\(a_8\)，每个条件分别训练K∈{16,32,64,128}的离线SAE，M固定为实际运行字典宽度。初筛种子17、29，共16次离线字典拟合；真正需要确认的配对才追加第三个种子43，不重复训练主干。

建议第一阶段冻结一个由训练语料提取的\(2^{22}\)个有效词元激活清单，开发与重构确认各\(2^{18}\)个，按文档排重。它们与P/N/R语义确认集分开。各方法读取相同词元位置、同样更新数和优化器日程。以上为建议预算，不表示已有缓存；实际M较大时必须先确认显存和计算上限。

若开发重构仍明显受训练不足限制，不比较“哪个K真实更优”；按共同规则为所有相关条件增加到同样预算，再判定。保留字典列范数、死特征率、实际L0分布和训练曲线。训练tokens相同不代表FLOPs相同，需记录计算成本。

### 主要测量

1. **归一化重构误差。** \(\mathrm{NMSE}=E\|a-\hat a\|^2/E\|a-\mu\|^2\)。均值及预处理在拟合集确定，整体与每语义条件分别报告，并保留分子分母。
2. **语义保留。** 用相同读出流程比较a、hat a、z与e在旧面板和新R确认集上的表现；主要看语义泛化而非只看NMSE。
3. **遗漏诊断。** e能预测标签不自动等于hat a丢失该标签，信息可能冗余。需要检查在公平验证下，加入e是否补足hat a的错误，并与增加同规模控制特征的读出比较。
4. **功能失真，列为次要保护线。** 冻结模型，在固定留出语言数据上用hat a替换该位置a，测原生交叉熵差。它衡量观察器的替换保真度，不是旁支训练的收益；与保持原始a的模型严格区分。
5. **有效支持。** 记录每条输入使用的实际特征数、贡献幅度集中度、支持集合变化及不同语义条件的误差分布。不能仅根据平均重构误差推断所有类别预算相同。

### 编码误差的廉价诊断

固定已训练字典和选中支持，对系数做有非负约束的局部重拟合，观察误差能否下降；另可比较不同支持搜索方法，但应标为额外编码计算。若同样K已能明显降低误差，问题可能在编码推断，不是K必然太小。局部优化未改善也不是求得全局最优的证明。

### 维度分析作为解释，不作K的直接选择器

报告总体及类条件PR、TwoNN的样本量/尺度敏感性；优先用已知真值合成数据检查估计器。拟定三个校准族：

- A：很多坐标轴，每个样本只在一轴变化；局部稀疏但全局线性张成维度高。
- B：已知16、32、64、160维的连续信号嵌入更高维空间，叠加可控噪声。
- C：低维语义加高维模板/噪声，标签只由低维部分决定。

对每族观察样本数与估计变化。如果当前样本规模下估计器连B的160维都恢复不了，就不能把真实文本上的某个数当作精确语义维度。

### 决策分支

| 结果 | 解释 | 下一步 |
|---|---|---|
| K增大同时降低失真、改善语义保留，且多个条件复现 | K32可能过紧 | 先扩预算或比较等平均L0的BatchTopK |
| K增大只改善重构，语义与替换损失不改善 | 多出的方向可能不是当前任务所需 | 不把更低重构误差当成功 |
| 同K改系数推断就明显改善 | 编码器存在推断误差线索 | 研究编码器/残差读取，不先扩大K |
| 不同语义条件的误差—K拐点不同 | 固定预算可能分配不当 | 单个平均L0=32的可变预算对照 |
| K改变后所有离线观察器都相近 | 当前预算不是主要瓶颈或测试不敏感 | 回到E1/E2，不无目的扫更大K |
| 增大K和M都需要，且死特征/收敛差异很大 | 尚不能区分容量与优化 | 先修复离线拟合匹配，不改主干 |

## 7. 结果之后才启动的功能验证

只有E1或E2给出稳定语义候选后，才选择少数特征组做干预。不要把TPP/SCR默认分数作为本轮决定性结果；文献中其可靠性已有明确质疑。

可采用：在原始\(a\)中只减去候选组贡献\(a'=a-\alpha D_Gz_G\)，保留其余内容与重构误差；或做有对应关系的供体替换。比较目标任务、非目标任务和匹配随机组，使用多个干预强度。

对RAVEL式“改变属性但保持其他属性”的任务，先确认当前小模型原本能正确回答，否则负结果不能区分特征不正确和底座根本不会。选择性效应支持功能关联，不证明唯一机制、完整解耦或专家收益。

## 8. 方法选择树

```text
原始主干跨条件语义改善了吗？
├─ 是 → SAE字典能稳定定位相关因素吗？
│       ├─ 是 → 小范围选择性干预，再考虑专家/持续学习
│       └─ 否 → 改观察器；不能否认已独立测到的原始语义变化
├─ 否，但离线SAE读法更好 → 保留读取/分组工具，暂不强化主干正则
└─ 否，且离线SAE也无优势 → K预算诊断是否显示有用信息被遗漏？
        ├─ 是 → 定点比较可变预算或编码推断改进
        └─ 否/未知 → 当前稀疏假设缺少作用证据；不扩大预训练
```

多维特征组、Matryoshka、MP-SAE并非顺序必做模块。它们分别对应组合语义、粗细特征吸收、条件性读取这几种不同失效。没有相应证据时，保持最简单方法。

## 9. 最小执行顺序与学习安排

**开始前的阅读与理解输出：** 先读Gao的Top-K及改变推理K部分，再读多维特征论文的特征组方法，最后把SAEBench与2026可靠性审计配对阅读。各写三句话：测量对象是什么、最强竞争解释是什么、什么结果会否定当前解释。

**阶段1：不拟合新SAE。** 核对数据与取点，复现P/N，构造并冻结R面板，做E1及便宜随机/置换校准。实际抽取成本取决于已有缓存，未估计固定GPU时长。

**阶段2：只拟合两主干的K32离线观察器。** 它们同时服务E2和E3。先判断能否稳定拟合，再做语义检测、样本AMI和少量特征解释，不立即标注整个字典。

**阶段3：补K16/64/128。** 只有前面工具和数据通过验收后，扩展E3曲线。训练字典仍属于待批准执行，不是本次调研已完成动作。

**阶段4：研究者决定路线。** 根据明确结果，选择继续训练正则、保留SAE读法，或改变稀疏假设。没有证据时结论是未支持或不足，而不是再加一项损失保证得到正结果。

## 11. 下次组会应该形成的认识更新

不要求一次证明SAE有效。合格的更新可以是：

- “原始几何的变化主要对应模板而非语义，因此当前正则目标与所需语义不匹配。”
- “语义并非单特征可读，但小组在未见表达上稳定，这提示应研究多维因素而非单原子命名。”
- “K32在复杂条件下丢失了可用信息；可变预算值得定点测试，而不是把32解释为真实语义维度。”
- “换读法可以改善读取，但正则主干没有额外收益；SAE应暂时作为观察器。”

这些都是有证据价值的结果。共同底线是：每一项结果必须说明它测到哪一种‘好’，不能用可读性、几何、重构、模型使用或持续学习之间的任意一项，替代其他项。
