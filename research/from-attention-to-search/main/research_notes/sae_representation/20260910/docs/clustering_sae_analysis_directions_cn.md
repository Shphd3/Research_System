### 1.2 必须收窄的四处表述（不是推翻，是改口径）

**A. "剧烈变化在第 64 步完成"不成立。** u64 相对 t0 是 77.06%、u512 相对 t0 是 76.77%，两个比例接近**只说明两点离起点的距离相近**。直接比较 u64 与 u512，仍有 **31.93%** 的记录换了专家【复核】。正确表述："相对起点的重掷在前 64 次更新内完成大部分；此后相对起点的位置基本不动，但**分配本身继续移动**（u64→u512 还有 31.9% 改选）。"这同时说明"前 1/8 内完成"这个说法要限定为"相对起点的距离"，不是"停止变化"。

**B. "聚类几乎不动"必须带对象。** h（路由输入）与 v（最终表征）不是同一个量：U 条件下 h 净换组 1.55–1.85%，v 是 **4.98–8.78%**【复核】。只说 h 会漏掉输出侧；只拿 v 的大数值当方法成功的证据则属事后换主要对象。另外中间时刻并非始终贴近终点：个别 U 轨迹的 h 划分相对起点差异可达约 15%【文档】，所以"终点换组少"推不出"全过程不变"，更不能直接命名为"边界抖动"——**求解波动与真实重组尚未分离**（这正是 D1）。

**C. "固定八簇 ⇒ 没有新类"不成立。** 无论数据里有多少自然结构，算法都被要求给出 8 组。它能回答"这 8 个格子怎样变"，不能回答"自然界有几个类"。同理，来源纯度变化不等于语义结构改善。目前唯一可说的是：**在这套固定读出下，格子的成员构成几乎不变**（加权来源纯度 0.814 → 0.816）。

**D. `0.8040` 这个"独立重抽期望"没有可追溯来源。** 我在 `analysis/postprocess/routing_churn.json` 与 `change_timing.json` 里都搜不到该量（两文件均无 `independent` / `null` / `expect` 字段）【复核】；它在 `sft_matrix_training_dynamics_cn.md` §3(b) 与 §4 被引用。用 `temporal_recheck.json` 的 `independent_mismatch_record_weighted` 独立重算得 **0.80627**，比值 0.7677 / 0.8063 = **0.952**（原稿写 0.955）。**结论方向不变，但数字必须换成可追溯来源，或把该量的算法与产物补上。** 另外 `clustering_results_explained` §6B 已指出该推理本身逻辑不充分（编号可由旧编号完全决定而比值仍等于独立期望），所以这条只能当**描述性对照**，不能当"t0 归属无预测力"的证明。

### 1.3 这批数据能答什么、不能答什么

**能答（证据已足够，且其中前两条不需要统计推断）**
1. **留出损失的改善不依赖输入几何变化**：F 条件 h 逐位不变，测试 NLL 仍从 2.83464 降到 0.87919–0.92404（降 1.91–1.96 nats）【文档】。这是全轮最干净的一条。
2. **可测的剧烈变化在路由分配侧**：u512 有 76.77% 的记录落到与 t0 不同的专家【复核】，且这一重掷在前 64 次更新（1/8）内完成大部分【复核】。
3. **固定读出层近乎平线**：h 净换组 1.55–1.85%（U）、0（F）；v 4.98–8.78%（U）。
4. **当前这套教师没有表现出稳定任务增益**：high28 两种开放条件三种子一致变差（+0.00659 / +0.00690）【产物】；另有两个均值为负的组合三种子符号不一致。

**不能答（缺的是哪一环，要说清）**
- 自然类别何时诞生 / 语义解释 —— 超出固定 K8 读出的能力，不是精度问题。
- 专家功能是否不同 —— 缺"教师关系 → 路由概率 → 实际路径 → 专家有用"这条链的中间测量（D2 补前两环；末环仍缺）。
- 任何稳定方法排序 —— CI95 只覆盖面板记录抽样、不含种子间训练方差；312 行里 99 行种子符号不一致【文档】。
- high28 的机制归因 —— 主面板覆盖 34/1480（≈2.3%），训练目标位置覆盖 ≈0.344%【文档】；在这么窄的支持上不能谈普适效果（D6）。

## 3. 候选推进方向（表征空间聚类 + SAE 分析）

**全部为 `AI 建议`，不是已确认的科学决定。** "零重训"＝纯 CPU、只读现有产物、新产物写独立目录（先例 `audits/clustering-explanation-20260910/`），不触碰 `fm/**`、不重写 `run_identity.json`。

| # | 方向 | 未决问题 | 零重训？ | 建议优先级 |
|---|---|---|---|---|
| D1 | 聚类求解波动的分离 | 中间时刻的分组变化，是真实重组还是 KMeans 自身波动？ | 是 | **P0** |
| D2 | 教师约束是否真正进入路由 | q→p 变了吗？p 变了路径变了吗？（P1 原样） | 是 | **P0** |
| D3 | 把固定 SAE 当作探针的时间线 | 同一本字典在新 h 上的原子激活与共激活关系，随训练怎样变？ | 是 | P1 |
| D4 | 输出侧与专家贡献的时间线 | F 下 h 不动，只有补 v/专家/共享才能看输出侧变化（P2 原样） | 是 | P1 |
| D5 | 具体文本案例 | 哪几条记录在换？换的是格式、长度还是内容？ | 是 | P1 |
| D6 | 解耦"高层节点身份 vs 监督暴露" | high28 的差是节点选得好不好，还是监督位置少？ | **否，需新训练** | P2（researcher-owned） |

### D1（P0，零重训）分离聚类求解波动

- **做法**：在主方法（固定 K8、20 次初始化择优）不变的前提下，对固定的 0/32/64/256/512 时刻、每个已有条件与种子，用**同一份表示**重复聚类 5 个随机种子；比较"同一表示的求解差异"与"跨训练时刻的结构差异"。主比较用**不依赖簇编号**的成对同组关系与近邻保持率，簇编号对齐只用于显示。
- **判据**：若跨时刻差异落在同一表示的重复聚类波动范围内 ⇒ 只能报"求解波动内未见结构重建"；若稳定超出 ⇒ 才有资格讨论重组，并须跨种子复现。
- **成本/风险**：先在一个时刻计时，再决定 5 个种子是否放得下；开发集拟合、测试集应用，不得用测试集选设置。风险是把波动校准本身做成新结论——它只是**门槛**。
- **依赖产物**：`analysis/clusters/*`、分片 `h`/`v`。

### D2（P0，零重训）教师约束是否真正进入路由

- **可行性已核**：分片里 `teacher_q_sae / teacher_q_gmm / teacher_q_high28`、`teacher_valid_*`、`p`、`native`、`actual`、`actual_expert` 全部在位【复核：`representations/task_f__seed17/update_0512/development.npz` 共 27 个成员】。
- **A（逐输入对齐）**：在教师有效记录上算 KL(q‖p)，与同 F/U 的 task 对照比较，看 t0→t512 的走向。
- **B（关系约束）**：在固定记录对上分列吸引项与排斥项，沿用原训练的距离、margin、归一化定义；B **不要求**专家组号与教师组号逐一对应，因此不能只用逐记录 KL 判它失败。用"同路/异路 × 教师相似关系"这种不依赖编号的统计。
- **同时报告**：native argmax 与平衡后 actual 的一致率、每专家实际负载、覆盖量与共同支持集合（无足够跨来源记录对时写明不足，不填值）。
- **解释分支**：q→p 没变 ⇒ 不能声称先验进入路由；p 变了路径没变 ⇒ 只能说概率层变了；路径也变了 ⇒ 才有理由继续问输出是否不同。**三条都不证明专家功能有用。**
- **依赖**：分片（只读）；判据与算法在 `analysis_review` §P1 已写好，可直接照做。

### D3（P1，零重训）把固定 SAE 当作探针，做出"结构—时间"曲线

这是把 SAE 线路从**训练前静态图**推进到**训练时间线**的唯一零重训路径，也是最能直接回应 R2 的一条。

- **做法**：SAE 字典与映射保持冻结（`sae_full_final.pt` 在位 245 MB、`groups.pt` 在位、`teachers/high28_phi.npz` 在位【复核】），把它施加到每个检查点的 h 上，测：① 原子激活率与 top-32 质量分布；② 28 个高层原子的共激活 phi 关系；③ 8 个组的组间包含度/相似度矩阵（即 Y3）随 21 个时刻的变化。
- **判据**：结构（组间关系谱、phi 图）是否随训练移动出"同一 h 重复编码"的数值底噪；F 条件必须恒定（与 h 逐位不变互证）。
- **成本/风险**：每个分片 h 为 1480×1024，编码是廉价矩阵乘法，但分片总量大 ⇒ 先抽固定时刻子集（0/64/512）跑通再加密度。风险是把它误读成"SAE 在训练中学习"——**字典不变，变的是被编码的 h**。

### D4（P1，零重训）输出侧时间线（原 P2）

`metrics.csv` 已有逐对象行；补 v、实际专家贡献、共享贡献的同种子配对对照（范数、方向有效数量、来源分散）。注意 t0 专家/共享输出严格为 0，**方向量在 t0 不可定义，不许填 0**。

### D5（P1，零重训）固定文本案例

对"稳定 / 反复换组 / 终点持续换组"三类各按固定哈希取 5 条记录，给原文、来源、长度、旧邻居、新邻居与出现时刻；先看同来源同长度段的例子，判断是否只是格式/长度变化。样本不足时报实际数量，不凑数。

### D6（P2，需新训练，researcher-owned）解耦节点身份与监督暴露

high28 与 SAE 的差同时含"节点集合不同""有效监督暴露不同"（0.344% vs 全覆盖）。**要机制结论就必须做等暴露或共同支持对照**；这是本轮唯一真正需要 GPU 的候选，范围由研究者拥有，未陈述前不启动。
