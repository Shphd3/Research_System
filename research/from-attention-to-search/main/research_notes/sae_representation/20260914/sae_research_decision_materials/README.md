`verify_sae_identity.py` 是小型合成检查，需要 Python 3.10+ 和 PyTorch：

```bash
python verify_sae_identity.py --output identity_checks.json
```

它检验特征置换不改变重构、同槽位可以改变响应、停止梯度的位置会改变主干梯度。它不读取你的模型权重，不验证真实特征的语义漂移。

本材料包不包含远程训练代码的完整实现，不能当作已经获准启动昂贵训练的执行包。
