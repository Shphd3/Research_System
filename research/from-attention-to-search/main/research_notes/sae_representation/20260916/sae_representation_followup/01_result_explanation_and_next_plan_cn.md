# 三模型结果怎样解释，以及下一步怎样检验 SAE 的梯度是否有用

日期：2026-09-16。性质：结果解释、梯度故事审计与后继决策草案。已有结果与新增回溯图分开；所有后继模型计算均为 `AI_PROPOSAL / NOT RUN`。不以本文改变既有 Protocol、Anchor 的科学状态或授予训练权限。

先读：[本次组会稿](../../../../../../../daily_research_reports/backup/2026/09/0916/meeting_report/history/meeting_brief_sae_representation_update_cn.md)、[正式 Summary](../../../../experiments/A15/15_17_three_model_sae_representation_trajectory/A15_17_E01_three_model_sae_representation_audit/summary_cn.md)。本文件解释组会稿背后的判断，不替代正式证据账本。

## 1. 先回答中心问题：目前支持到哪里

**支持：现有训练配置产生了可复核的领域相关表征差异，SAE 能把其中一部分差异读成稀疏使用模式。尚不支持：额外重构梯度使主干普遍更语义化，或让语言模型更好。**

这不是“什么都没得到”。本轮已把三个问题分开：

| 问题 | 当前直接证据 | 当前认识及边界 |
|---|---|---|
| 表征是否随着训练变化？ | 固定样本的领域读出、细领域几何和稀疏使用在 0–10B 不同 | 支持训练轨迹上的领域相关变化；0B 的随机表征也保留词面信息，不能说语义从绝对零开始 |
| SAE 配置是否与 Dense 不同？ | M1 实际 MLP 输入的细领域 Fisher 在 1/3/5/10B 高于 M0，去第一方向后保留 | 支持该对象的剩余几何不同；不是全指标优势或新增信息量证明 |
| 新版比旧版好吗？ | 3B 实际输入读出偏向 M1；10B 原始 h 读出偏向 M2；N 的 raw-h 配对区间都不分离 | 没有统一排序；只报 M1 3B 会遗漏 M2 的局部优势，只报 M2 10B 同样会误导 |
| 辅助梯度进入主干了吗？ | M1 重构主干梯度为零；M2 非零；AuxK 直接只更新 SAE | 梯度接线已核实；有梯度不等于有益梯度 |
| 是否更理解同一个命题？ | 两模型全部六点的命题加权重合间隔区间均包含零 | 尚未支持稳定的命题特异复用；不能由领域块状热图替代证明 |
| LM 代价如何？ | 本轮没有新增 DCLM held-out 评价；M0 现有 TensorBoard 身份审计未通过 | 不给出合格的三模型 LM 成本排序；不能直接搬旧截图的 7B/19B loss 图来回答本轮 0–10B 问题 |

“语义化”在这里至少分三层：**领域标签容易读出；同内容换说法后关系仍保持；语言模型计算或任务真的获益。**本轮主要检验第一层，第二层证据不足，第三层没有做因果验证。领域是有意义的内容属性，但也可能由术语和写作风格识别，不等于已经读懂命题。

## 2. 我们到底比较了什么模型，公平到什么程度

### 2.1 模型和梯度的准确身份

三者都是随机初始化的 8 层 Qwen3-style Dense 主干，隐藏维度 1,024、MLP 中间维度 3,072。这里是**一个 SAE 插在第 8 层 MLP 前**，不是 8 个 SAE 各插一层。M0 主干约 281.43M 参数；M1/M2 各多约 61.47M SAE 参数，总计约 342.90M。

| 项目 | M0 Dense | M1 旧版串联 SAE | M2 新版串联 SAE |
|---|---|---|---|
| 最后 MLP 真正收到的向量 | 原始 h | 重构 R(h) | 重构 R(h) |
| 语言损失更新 SAE | 无 SAE | 是 | 是 |
| 语言损失更新上游 | 是 | 是，包括经过 SAE 的路径 | 是，包括经过 SAE 的路径 |
| 额外抽样重构损失更新 SAE | 无此项 | 是 | 是 |
| 额外抽样重构损失更新主干 | 无此项 | 否，分支输入停止梯度 | 是，分支输入保持梯度 |
| 重构目标、能量分母 | 不适用 | 停止梯度 | 停止梯度 |
| 重构系数 | 不适用 | 1 | 1 |
| 防死特征 AuxK | 无 | 无 | k=256，权重 1/32，直接只更新 SAE |
| SAE | 无 | 宽 30,000，Top-32，连续在线训练 | 同左，另有 AuxK 活动状态 |

语言损失问“能不能预测下一个词”；重构损失问“能不能用少数字典方向把当前向量拼回来”；AuxK 给长期不活跃的字典项一次拟合剩余误差的机会。三者目标不同。**当前重构项没有领域标签，也没有明确的‘同义更近、异义更远’约束。**

M2 辅助梯度作用于产生 h 的上游参数，不直接经过最后 MLP 或最终归一化。输入 embedding 与输出词表权重共享：这同一张参数表可能通过输入端收到梯度，不能看见 output weight 非零就断言辅助梯度穿过了下游输出层。

### 2.2 公平性结论

**作为同内容、同训练量的描述性配置比较，比较有资格；作为‘只改变一个梯度开关’的因果试验，还不够。**

已匹配的部分：相同主干初始种子 17，审计 0B 原始 h 相同；相同 tokenizer、DCLM 冻结训练视图与数据顺序契约；共同的精确有效预测词元快照；相同抽取位置、内容、拟合／调参／报告划分、线性读出容量、正则候选、配对统计。全局常规更新量为 262,144 有效词元，M0 的 8 卡×微批 2×累积 8 与 M1/M2 的 4 卡×微批 2×累积 16 对齐。主干 AdamW 学习率 3e-4，1000 步线性预热后恒定，主干 betas=(0.9,0.95)、weight decay=0.1；SAE 使用自己的参数组和预热。它不是“同一步号就假定同训练量”。

必须保留的限制：

1. **M2−M1 同时改变输入 detach 和 AuxK。**即使 AuxK 当下范数很小，它也可能累计改变字典，再间接改变串联前向与 LM 梯度，不能据此排除混杂。
2. **M1/M2−M0 改变前向函数、参数量和计算量。**可比较实际配置，但不能说纯正则效果或同算力效率。
3. **训练硬件不同且只有一个训练种子。**M0 为 8×5090，M1/M2 为 4×H100；共同初值和数据契约不消除不同精度内核、归约顺序和轨迹偶然性。新审计本身使用同一个合格的 H100 管线。
4. **原始 h 和实际输入不是同一个问题。**M0 两者相同，M1/M2 两者不同；同一个模型上各自重训线性探针的差异也不能称为无损变换。原协议另有固定 h 探针直接迁移到实际输入的检查，应与重新拟合的读出分开解释。
5. **逐点区间不等于全局显著性。**5,000 次 bootstrap 是重抽样同一批家庭／文本，未重训模型，也未重新随机抽一个预训练种子；没有多重比较校正。检查点连贯支持有界描述，不让 6 个点变成 6 次独立训练。

本次不把“共享 manifest”夸大成重新逐 token 回放所有训练日志；训练身份以提交源、run config、checkpoint manifest 和已有身份审计为据。

## 3. 数据是什么，是否可信

### 3.1 训练数据与审计数据必须分开

三个语言模型用 **DCLM** 做无标签的下一个词预测；P/N 是训练之后读取模型时使用的评价面板。P/N 的领域标签用于拟合小型读出器和计算指标，**没有在这三个模型预训练时监督领域结构**。因此本轮不是“给主干上领域标签后再测领域标签”。

| 属性 | P：构造短句面板 | N：学术 M2D2 开发面板 |
|---|---|---|
| 内容 | 数学、物理、生物、历史；12 细领域 | 计算机、数学、定量生物、物理；8 个学术细类 |
| 数量 | 72 命题家庭×5句=360句 | 每细类150行，共1200行 |
| 一组的含义 | 原句、近/远词面同义句、近/远词面异义句；不是5句都同义 | 自然学术文本行；没有同命题改写标签 |
| 本轮划分 | 120 fit / 60 tune / 180 report；24/12/36家庭互斥 | 600 fit / 200 tune / 400 report；原100条fit按哈希拆75/25，原50条dev作report |
| 实际读取 | 同一换行规则后的最后有效词元 | 前256个词元均值为主；位置255为辅助 |
| 优点 | 可控制领域、命题和词面相似度；适合有针对性的关系检查 | 自然文本、更长、术语和表达更丰富；可检验短句现象能否复制 |
| 限制 | 小、人工构造、模板和词面规律强；不能代表自然语言总体 | 开发面板已使用过；领域可由术语辨认；无完整独立源文档ID支持文档级重采样 |
| 本次身份 | 哈希前缀 7aaf0ec9 | 哈希前缀 16eaced1 |

P 的四个粗领域分别包含算术/几何/概率、力学/光学/热力学、细胞生物/生态/遗传、古代/中世纪/近现代史。研究者确认保留家庭后，AI 对 44 句做了措辞一致性修订；冻结记录有来源参考，但不能把 `human_reviewed` 解释成每一句经过独立多人盲审。家庭互斥控制了同一家族泄漏，尚未证明所有写作模板也完全独立；没有证明与 DCLM 全语料无重叠。

N 的细类是 cs.CL / cs.CV、math.AP / math.NT、q-bio.GN / q-bio.NC、physics.optics / physics.flu-dyn。本地构造记录检查了内容哈希、词元前缀重复和近重复；这使加工可复核，不保证所有文章来源独立。它不是旧 Wikipedia 16,128 packed windows，也不存在两个独立的“M2 数据”和“D2 数据”。**M2D2 是数据集名，M2 是本轮模型名。**

具体来源与处理证据见[既有数据审计](../../20260915/formal_representation_audit/01_measurement_reference_and_dataset_audit_cn.md)。公开数据集的身份可对照 [M2D2 原论文](https://aclanthology.org/2022.emnlp-main.63/)；本地 1200 行配额与拆分属于本项目加工，不是官方测试集规模。

### 3.2 可信到什么程度

这两套数据**足以复核当前有边界的领域读出与几何观察，不足以单独确认‘更深的语义形成’**。一个直接提醒是：只用词频与词组的 TF-IDF 线性基线在 P 达到 72.78%，在 N 达到 83.50%；N 在1–10B的原始表征读出大约79%–83%。所以“领域准确率很高”本身不新鲜，模型配对提升及换词、换来源后的保持才重要。

后续若要加强语义解释，应只补最相关缺口：保留领域内容但换术语/表达，同时加入词面接近而内容不同的对照；按来源或构造家庭隔离；在打开新报告样本前冻结规则。无需先建大型政治标签体系，也不能用 SAE 自己给的标签再证明 SAE 有语义。P 现有 report 及 N 的 dev 都已看过，后续重复使用只能称开发验证，不再称全新的盲确认。

## 4. 本轮具体用了哪些方法，各自说明什么

### 4.1 领域线性读出

冻结语言模型，在 1,024 维表征上训练逻辑回归分类器。仅 fit 拟合标准化及分类器，tune 从 C={0.001,0.01,0.1,1} 选择正则强度，report 计分。分数是每个类别召回率的平均，即类别平衡准确率；它避免某个类别多就主导总分。

粗领域、全局细领域和给定真实父领域后的细分类分别计算。最后一项使用真实父标签条件，不能假装模型自己已经正确选择了父领域。另有稀疏系数读出、固定 h 探针对重构的迁移、N 的末词元敏感性和词面 TF-IDF 对照。稀疏输入宽度不同，不能直接把其分数优势称为新增信息。

它回答“一个简单读出器能否利用这里的领域信息”，不回答“原生 MLP 是否使用它”，也不排除词面捷径。近天花板的粗领域分数不灵敏，因此细领域是更有用的主要阅读面。

### 4.2 Fisher 比：类间分开，还是类内压缩

对于等权类别均值 \(\mu_c\)、总体均值 \(\mu\)：

\[F=\frac{K^{-1}\sum_c\|\mu_c-\mu\|^2}{K^{-1}\sum_c n_c^{-1}\sum_{i:y_i=c}\|h_i-\mu_c\|^2}.\]

分子测类别中心相距多远，分母测每一类内部多分散。细领域先在每个真实父领域内部计算，再平均，避免只靠“物理远离历史”就得到细领域好看的分数。

Fisher 升高可能是中心拉开，也可能是内部变化被压小。两者都改变几何，但后者可能压掉重要细节。因此应与读出、同命题控制、实际 LM 代价分别报告。**整体平移不改变这个 Fisher 比**，所以 B1 中心化前后相同是数学预期，不是额外一份独立支持证据。下一步用缓存拆开分子/分母即可，不需要重训模型。

### 4.3 余弦关系间隔

将锚句与正例的余弦相似度减去锚句与指定竞争反例的相似度。粗领域正例是同粗域不同细域，细领域正例是同细域不同家庭；命题关系另用冻结等价/不等价三元组。先在家庭等独立单元内汇总，再配对重采样。正值说明这个指定关系相对更接近，不说明所有语义关系都正确。

### 4.4 SAE 稀疏使用、重构与新激活图

特征集合交并比衡量是否用相同编号；加权交并比同时考虑用得多不多。每个非负系数的展示量为

\[p_{ij}=\frac{z_{ij}\|d_j\|}{\sum_k z_{ik}\|d_k\|}.\]

这是解码贡献的**幅度份额**，不是概率、触发频率或可相加的独立解释方差，字典方向可以互相相关。FVU 则是总重构平方误差除以总中心化表征方差；effective L0 是每个读点非零项数，覆盖率是面板上至少使用一次的编号比例。P 与 N 的位置总数相差很大，不能用二者覆盖率高低直接排名。

原 A06 每个 checkpoint 重新选列；本次为满足轨迹阅读需要，新增回溯固定列图：每模型独立，用 0.5/1/3/5/10B 的 **fit** 家庭等权均值选共享6项、每领域偏好6项，共30项，排除重复；0B 和 report 不参与选择。共享分数是各领域平均份额的最小值；偏好分数是本域均值减其他域最大均值。平分按ID升序。每家庭样本数相同，因此句均值等价于家庭等权。固定180个报告句和统一色阶跨期显示。

新图只补充可读性，不替换原注册分析。10B 这30项承载的平均份额为 M1 48.22%、M2 42.11%；未显示的多数编号仍可能有作用。两模型各自选项且只展示30/30000，不能把图中块更深称为全字典更语义化。各自的“本域减其他域”轨迹也只是描述，无新的确认性检验。

### 4.5 中心化和去第一奇异方向：导师要求检查的是什么

把 fit 中每个样本表征排成矩阵 \(H\)。奇异值分解找出其中能量最大的方向 \(v_1\)。**去第一方向就是从每个向量中减掉它沿这个方向的投影，不是只把图表里的第一个数删掉：**

\[h'=h-(h^\top v_1)v_1.\]

三种固定处理分别是：B1 只减 fit 均值；B2 在未中心化矩阵上求第一方向后投影；B3 先减 fit 均值，再去中心化矩阵的第一方向。参数只用 fit 估计，报告数据不参与；投影后读出器重新拟合，沿用原始分析选好的 C。

未中心化的第一方向可能主要承载共同偏置；中心化后的第一方向是围绕均值最大的变化。二者不相同，也不天然分别等于“语法”和“语义”。当前数据中 B2 可去掉大量能量，M1 的某些 Fisher 差仍保留，说明**一根主导轴解释不完这些差异**。这不证明剩余结构全部是语义，也不构成训练时删除该方向的理由。

### 4.6 梯度分解与图像检查

每个快照用相同四个 N-fit 批次，每批8行、每细类一行；LM 分母2048预测词元，重构/AuxK分母256抽样位置。分别求 LM、重构、AuxK 的原始与加权参数梯度，按互斥参数组报告范数、每参数均方根、比值及方向余弦。**这些是当前 checkpoint 上的局部导数，不是过去10B的梯度历史，也不是优化器真实更新。**

已有表保存了参数组范数和余弦；没有保存足以重建每个 h 节点梯度、完整雅可比或梯度奇异谱的张量。因此不能只凭现表声称发现“新语义方向”或“有效秩提高”。本次仅对互斥组做平方和汇总，得到 M2 10B 全主干范数比 2.65%–3.21%。全主干 LM/重构梯度余弦在四批为约 −0.065 至 −0.108：它们不是简单同向放大，但轻微相反不等于对独立领域任务有害，仍需真实更新验证。

PCA、UMAP、t-SNE 是把高维结构展示在二维的描述工具，不能用二维簇是否漂亮替代上述高维指标。原审计 UMAP 的谱初始化曾回退固定种子随机初始化，故仅描述使用。本次不重跑这些降维，也不依据它们选择胜出模型。

### 5.1 当前新增梯度的关键推导

令 \(h\) 是 SAE 输入，\(R_\phi(h)\) 是重构；\(\operatorname{sg}\) 表示保留数值但不让梯度经过。单读点重构项可写为

\[L_R=\frac{\|R_\phi(h)-\operatorname{sg}(h)\|^2}{Z},\quad
Z=\max(\|\operatorname{sg}(h)\|^2,d\times10^{-4}).\]

这里分子、分母同为逐维均值时已约去 d，保留实现的下限。总损失还对抽样位置求平均。对于 M2，

\[g_{R,h}=\frac{2\lambda}{Z}J_R^\top\big(R_\phi(h)-\operatorname{sg}(h)\big).\]

白话：**它不是直接把 h 拉向一个固定语义标签；它借当前 SAE 的编码—重构通道，推动产生 h 的参数，让下一次重构更容易。**目标本身来自模型当前表示，下一步又随主干变化，没有外部语义方向作保证。

固定当前激活集合 S 后，线性编码器和归一化解码字典给出 \(J_R=D_S W_{E,S}\)，秩至多32。重构梯度位于所选**编码器行方向**的张成空间，不能一般说成解码器列空间；两者只在特定权重关系下等价。串联 MLP 路径的 LM 梯度也经过 \(J_R^\top\)。因此，**新增重构项不会自动为同一节点打开 Top-k 以外的反向通道**；它可以改变这些方向的权重、通过未来参数与激活集合变化影响训练，但没有立刻消除局部限制。

如果目标端也不停止梯度，梯度会多出直接误差项，形式成为 \(2(I-J_R)^\top(h-R(h))/Z\)（仍假定分母停止梯度）；这已经是另一个损失契约，不能在当前实验解释中混用。若连分母也放开，还有额外导数。本次不提出直接换 detach 规则，以免又引入一个变量。

网络参数更新后的 \(\Delta h\) 还取决于主干雅可比、共享参数、AdamW 动量/二阶统计、裁剪与衰减。更宽的梯度谱、更大的范数、甚至与训练 LM 梯度同向，都不保证独立领域任务改善。这就是为什么后续需要一小步真实更新，而不是继续只画梯度谱。

### 5.2 两篇论文给什么启发，不能替我们证明什么

**Matryoshka SAE** 对嵌套字典前缀分别加重构损失，让小前缀也承担重构任务。它提供的是多尺度结构约束；“小前缀=我们想要的粗领域、大前缀=细语义”仍需验证。论文也展示重构指标与下游表现可以分离，恰好提醒我们不把更低重构误差当作语义收益。[原文与损失代码](https://arxiv.org/html/2503.17547v1)

**MP-SAE** 用残差引导的顺序选择逐步解释输入，针对层级、条件正交和非线性可读结构。它首先提供更合适的读取假设；不能从“更会提取已有结构”直接推出“反传给随机初始化主干能形成更好的结构”。[MP-SAE 原文](https://arxiv.org/html/2506.03093v2)

**下一步均不默认加入。**如果原始 h 的细信息可读而标准 SAE 读不出，先做离线、等预算读取比较；如果单尺度重构梯度明确压缩掉有用细节，才提出多尺度约束及对应控制。离线读取结果不影响主干，无法独自回答从零形成问题。[端到端字典学习](https://arxiv.org/abs/2405.12241) 用输出分布差异约束字典也是一个目标设计启发，但它不等于当前项目已做了这种训练。

为什么先固定读出器：避免一步后重新拟合的波动遮住更新方向的作用。其代价是只能测“对当前读出方式有无帮助”，不能立刻判定全部信息量；若有信号，后续再用预先固定流程的重新拟合读出和换来源样本检验稳健性。

为何不用 M1 3B 作主点：它是旧报告里最显眼的功能候选，但当前问题是“新版新增梯度此刻是否有帮助”。固定 M2 的共同终点减少按结果挑状态的自由度。M1 3B 的计算利用问题保留为另一后继候选，首轮不两路并行扩张。

**此卡待批准的是 G0+G1 的固定范围，不包括从零训练。**现有state保存实现包含optimizer/scheduler且manifest完整；本次没有为计划额外加载大模型状态。执行时须严格检查恢复成功，不可在缺优化器状态时静默改用新AdamW。如果人只批准G0，则结束时明确“只有梯度诊断，没有一步收益证据”。

## 8. 是否需要旁路小模型：最终需要，当前不必直接重跑大模型

**要回答“从零预训练中是否促进形成”，最终需要匹配的从零训练；现有checkpoint分析和一次微步都不能替代。**旁路是有用的设计，因为 LM 继续直接用 h，能够隔离“额外重构梯度”而不同时施加前向重构瓶颈；它不是预先被证明更好的架构。

好消息是，这不是从头搭建：已有[小模型 Smoke 报告](/data/250010109/MoE_Router/experiments/20260915_sae_sidecar_small/reports/smoke_report_cn.md)与[配对验收](/data/250010109/MoE_Router/experiments/20260915_sae_sidecar_small/reports/pair_verification.json)已经验证 C_v2/T_v2 两臂各100更新、26,214,400有效预测词元，恢复下一更新数据摘要一致。随机改变SAE不改变logits；LM-only不给SAE梯度；重构C只更新SAE，T另到达42个上游张量。自然AuxK在这100步未触发，因为抽样位置未达到1000万窗口；强制触发分支通过，不能写成自然防死机制已长期见效。
