# 02｜目的与假设：对齐参考与自写练习

**日期：2026-09-24**  
**定位：这是一份用于理解写法的参考，不是替你确定科学机制的最终组会稿。**

> **先解释“为什么需要分开”，再提出“SAE 能否识别这种需要”。**
>
> 写目的时说清楚要减少什么不确定性；写假设时提出一个候选答案；写预测时说明这个答案与竞争解释会在哪里表现不同。

## 一、先把三种层级分开

**大问题：** 不同语义的数据在同一套参数中共同学习时，负面干扰在什么条件下产生？什么条件下共享反而是兼容的？

**本轮问题：** 在一个指定参数块、训练阶段和任务上，是否存在一种明确的冲突过程，能够解释某些语义组共享时的损失，并预测有针对性的隔离何时有效？

**后续工具问题：** SAE 的少量特征组合，是否能够识别上述条件，而不只是识别类别？

导师在 01:39—03:08 追问的是共同学习低效的来源；学长在 04:30—04:50 将需要验证的内容分为“所假设的共同学习条件是否造成损害”和“SAE 是否抓得到”。因此，第二、第三个问题必须衔接，但不能互相冒充答案。【M，第一部分 01:39—03:08；S，04:30—04:50】

## 二、一套供你对齐的简要表述

以下选择“共享参数中的不相容学习要求”作为**教学用候选机制**。它不是导师已经证实的结论，也不是本次审计认定的真实机制。你可以不接受这个机制，但自己的版本必须具有同样清楚的逻辑结构。

### 现象与边界

> 导师以“某些语义组分开学习可能更好”为讨论前提；目前提供的材料还不足以确认，这一收益是否已排除容量、数据暴露和优化配置等差异。我们需要解释的是经过适当对照后仍存在的学习损失，而不是先默认所有类别都应该分开。

### 目的参考

> **明确某些语义组共享参数时的学习损失，是否来自同一组参数自由度上不相容的学习要求；进一步判断 SAE 特征组合能否识别这种条件，为何时共享、何时隔离提供依据。**

这里保留“是否”，让不支持结果也能推进认识。第一句要回答来源，第二句才接回工具与路由。

### 机制假设 H_M

> **在指定的可训练参数块中，如果两组数据依赖重叠的参数自由度，但各自改善要求不相容的参数改变，那么混合学习会反复抵消其中一组的改善。有针对性地隔离这些冲突依赖，应比同预算、非针对性的隔离更能降低跨组损害。**

这条假设的重点不是“语义不同”，而是“同一自由度承受不相容的学习要求”。它给出了为什么共享可能有害，也给出了为什么针对性的分开可能有效。

### 机制层竞争解释 R_M

> **此前分开学习的收益主要来自额外容量、不同的数据暴露或优化设置，并不需要假定你所指定的冲突位置是关键原因。**

它不是 H_M 的简单反义词。它也可以解释“分开更好”，但不要求针对冲突位置的分配具有特殊收益。现实中两种因素可能并存，检验的目标是区分各自能解释多少，而不是强迫世界只有一个原因。

### SAE 信号假设 H_S

> **在相同取点和一致的特征定义下，SAE 特征组合包含与上述冲突条件相关的信息，能够在未用于定义信号的数据组对上，预测独立测量的跨组损害或隔离收益，而不只是复现语义类别。**

这是工具有效性的工作假设，不是另一条机制解释。它目前仍需补齐“究竟是哪种组合关系”；不能只写“存在关键特征”便宣告可执行。原子共现、原子重叠或低维距离，都只能是待检验的候选信号，不自动等于参数冲突。

### 信号层竞争解释 R_S

> **SAE 组合只是类别、频率或一般几何差异的代理，并不比这些简单信息更有助于判断共享学习是否有害。**

H_M 与 H_S 是前后衔接的两条假设；真正的竞争分别发生在 H_M 与 R_M、H_S 与 R_S 之间。

## 三、为什么要这样写，而不是继续写“可分性提高”

| 表述中的关键部分 | 它修复了什么问题 |
|---|---|
| “指定的可训练参数块” | 让冲突有明确位置；不能把整个模型中的任意现象都归给 expert。 |
| “重叠依赖，但学习要求不相容” | 把共享和冲突分开；共享本身既不等于有害，也不等于有益。 |
| “反复抵消另一组改善” | 指定被解释的学习过程，不再用分类分数替代功能损失。 |
| “同预算、非针对性隔离” | 让一般容量收益成为真正的竞争解释，而不是被忽略。 |
| “独立测量、未参与定义信号的数据组对” | 避免先用结果挑出特征，再用相同结果证明这些特征会预测。 |
| “不只是类别” | 把 SAE 的目标从标签识别改为学习兼容性识别。 |

**仍然需要你回答的一个问题：** 在看最终损害结果之前，你依据什么独立信息判断“重叠依赖”与“要求不相容”？

若唯一答案是“因为它们共享以后变差”，机制假设仍然是循环的。若你只能提出一个可能过程、暂时没有独立识别办法，就诚实地写成“待明确的机制候选”，而不是用数学符号把它包装成已完成的假设。

## 四、什么预测会让这两类假设真正有用？

### 对机制假设

真正有区分力的预测，不是“分开就更好”，而是：**在可比较的预算和学习机会下，分开的位置应当重要。** 若预先指认的冲突依赖确实关键，针对它们的隔离应有区别于非针对性分配的效果。

若任意同预算分配都类似改善，或者改善随配置差异消失，H_M 的特定解释就受到削弱；若对照没有匹配、隔离同时破坏信息或证据精度不足，则仍未分清 H_M 与 R_M。

### 对 SAE 信号假设

真正有区分力的预测，不是“SAE 更能分类”，而是：**即使两个候选信号的类别判别表现相近，学习兼容性的预测也可能不同。** SAE 需要在类别信息、频率或合适的原表示基线之外，表现出与目标问题有关的预测价值。

若 SAE 很会识别类别却不能预测损害，应该调整信号假设；这不能自动否定共享学习的机制候选。反过来，SAE 即使能预测损害，也不自动证明 H_M 是原因。

这些只是未来实验必须区分的逻辑，不是现在开始运行的协议。

## 五、别把“为什么”写成另一个名词

“因为有梯度冲突”“因为特征发生干扰”“因为语义不兼容”，都可能只是在给现象重新命名。

你需要能继续往下解释：**什么条件使哪些可训练变量被共同调用？它们为什么不能同时满足两组改善要求？这种过程为什么会在你关心的时间尺度上形成损失？改变哪一处应缓解，而哪些无关改变不应同样有效？**

同样，不要把“一次更新损害另一组”直接写成“长期联合训练必然更差”。局部更新、固定预算内学习速度、训练完成后的任务表现，是不同时间尺度上的问题。选定其中一个作为当前目标，其他结论留到相应证据出现以后。

## 六、你现在自己写什么：只写一张问题卡

先读懂前文，再暂时关掉参考，用自己的语言填写。每格一到两句话，不需要公式，也不要先选指标。

```text
1. 已有现象及边界
   材料真正显示了……；尚未排除……。

2. 本轮唯一未知
   我这次只想弄清……，不是只想把……分得更开。

3. 机制候选
   在……条件下，……通过……过程，造成……后果。

4. 最强竞争解释
   同一个现象也可能是由……造成，而不需要上述机制。

5. 可区分预测
   我的机制预期……；竞争解释预期……；差别在于……。

6. SAE 的角色
   若机制候选有依据，SAE 需要识别的是……，而不是仅识别……。
   这里尚未明确的信号定义是……。

7. 认识更新与边界
   支持时我会……；不支持时我会……；证据不足时我暂不判断……。
   本轮最多能够说明……，还不能说明……。
```

写完之后，只做一次“全部成功检查”：**假设这张卡里所有正面预测都出现了，导师还会不会原封不动地问“为什么这些语义要分开学”？**

若仍会，就不要急着增添实验。找出尚未回答的那个“为什么”，它才是下一轮要补的未知。
