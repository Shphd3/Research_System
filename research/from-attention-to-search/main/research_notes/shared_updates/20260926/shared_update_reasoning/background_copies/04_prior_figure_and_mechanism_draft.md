# 下次组会分析草稿：先画表征结构，再连接更新伤害
## 目的—假设—分析方法—结论

**本轮唯一问题：两组数据在当前模型中的共同表征方向，是否承载了会相互伤害的更新，还是主要承载无害的共享成分？**

本文是分析与图稿设计，尚未执行新实验，也没有生成真实的新分布图。现有附件只有转写和汇总结果，没有生成新图所需的逐样本表征、梯度与 checkpoint。下文的待填结果不能作为已有发现。

## 一、目的

### 1.1 大问题保持不变

不同数据共享同一套参数学习时，什么情况下会产生负面干扰？这种干扰通过什么过程产生？我们最终希望据此判断哪些数据适合共享专家、哪些值得隔离，而不是先按能否区分类别决定分发。

这个方向来自学长要求的“先解释共同学习为什么不好，再问 SAE 能否找到相关结构”，也对应导师对参数空间与 feature 关系的追问。fileciteturn0file1L15-L16 fileciteturn0file1L54-L55

### 1.2 本轮只推进一段联系

> 看清两组数据在原始表征中的方向分布，并检查一次有利于 A 的共享参数更新，是否沿这些方向把 B 推向对其任务不利的位置。

本轮不以“证明语义越远越该隔离”为目的，也不以“证明 SAE 有用”为目的。

研究链条暂时固定为：

```text
原始表征占据哪些方向
→ 共享参数更新如何改变另一组的表征
→ 这种改变对另一组的任务是有利还是有害

以上联系有证据后：
→ SAE 能否读取或预测其中的关键关系
→ 再考虑 Router 是否能利用它
```

这里的箭头是待检验的联系，不是已经确认的因果链。

### 1.3 为什么不能只把对象改成“更新分布”

研究更新有价值，是因为共享参数正是两组数据发生相互作用的通道。但“更新分布差异很大”并没有指定两组更新会互相帮助、互不影响，还是相互伤害。

因此，本轮不先比较一堆分布距离。必须同时保留三个对象：

| 对象 | 本轮含义 | 它单独不能回答什么 |
|---|---|---|
| 原始表征 `h` | 各组样本在模型中的实际分布 | 不独自决定哪种改变有害 |
| 实际参数更新 `Δθ` | 用 A 学习时，共享参数发生的变化 | 更新不同不等于相互冲突 |
| B 的任务损失及其局部敏感方向 | 判断 B 的表征变化是否有害 | 不能仅凭一次变化解释全部长期训练结果 |

SAE 系数是后续候选观测坐标，不在本轮预先充当正确答案。

## 二、假设

### 2.1 核心机制假设：共同方向上的不利更新

> 在当前模型和所选数据对中，部分局部负面干扰由两组共同占用的表征方向传递：使 A 变好的参数更新，也改变了 B 在这些方向上的表征，而该改变对 B 的任务是不利的。

其中，“存在相互作用”与“作用为负”必须分开。只看到两组分布重叠，最多支持前者的结构线索，不能直接支持后者。

“主要由少数高能方向传递”可以作为本轮要检验的**附加假设**，不是默认前提。导师关于能量集中到较少维度的描述提供了这个候选方向，但材料中没有其测量结果。fileciteturn0file1L60-L67

### 2.2 最强的局部竞争解释：共同方向主要是无害共享成分

> 两组数据在主要方向上的重叠，主要反映共同的输入或任务成分。这些方向未必传递负面作用；即使观察到不利更新，它也可能主要位于其他方向，或者不呈现稳定的少数方向结构。

这两个解释都允许“表征低维”“两组分布重叠”成立，因此一张静态分布图本身不能区分它们。

对于原来的最终 loss 差，还要保留一个更上游的竞争解释：**容量配置与优化条件差异**。现有表格在等每样本秩和等总参数量两种口径下给出不同的相对结果，所以本轮即使发现局部冲突，也不能宣称已经排除了容量因素对长期结果的影响。（《Draft》第2页。）fileciteturn0file0L30-L30

### 2.3 真正能区分解释的预测

| 观察或操作 | 核心假设较可信时 | 竞争解释较可信时 |
|---|---|---|
| 主要方向上有分布重叠 | 可以出现 | 同样可以出现；不是区分证据 |
| A 的有效更新后，B 是否变差 | 在部分数据对、更新批次上稳定出现不利作用 | 可以不出现；即使出现，也未必来自主要共同方向 |
| 把 B 的变化分解到预先确定的方向 | 一些共同方向反复贡献使损失上升的位移 | 主要方向贡献接近零或有利；不利作用在残余方向，或不稳定 |
| 后续诊断性恢复这些位移，并与匹配对照比较 | B 的伤害应选择性减轻，而非仅因为取消了全部学习 | 恢复这些方向没有选择性作用，或与一般性削弱更新无区别 |

最后一行是进一步识别作用通道的干预，**不是本轮出静态主图的前置条件，也不是要立刻开发的新训练方法**。

## 三、分析方法

### 3.1 先固定样本与模型，不再同时改太多对象

建议首轮直接使用本次配对表中的三个已有主题：A为高中数学，B为大学数学，C为高中生物。这样 A—B 对应已列出的近主题配对，A—C 对应已列出的远主题配对，不再另造一套与训练结果无对应关系的 SAE 数据。（《Draft》第1页。）fileciteturn0file0L16-L16

这些名称只是既有数据的分组标签，不代表已经定义了一个客观的语义距离。首轮的目标是做两个可解释案例，不是用两个案例证明普遍的语义规律。

优先沿用本次共享/隔离实验的底座、数据和损失定义。当前材料没有完整提供 checkpoint、层号、可训练参数块、监督 token 规则、优化器及数据原文，这些应先从实际实验配置中核验，不能凭旧项目记忆指定另一个模型或层号。

一次性记录以下信息即可：

| 必须固定的项目 | 为什么重要 |
|---|---|
| 同一个 checkpoint 与同一个模型状态 | 不把训练历史或两个模型的差异当作数据关系 |
| 同一个被观测的表示位置与层 | 避免把不同空间中的坐标硬作比较 |
| 指定的可更新共享参数块 | 使一次更新的作用范围清楚 |
| 实际训练损失与监督位置 | “对任务有害”必须相对于具体任务定义 |
| 按记录或模板分开的拟合集、评估集 | 不在同一批样本上选方向又宣称稳定发现 |

**特别注意测量位置：**需要观测会被所选参数更新改变的表征。若只更新某模块，而你测的是该模块之前、且上游冻结的输入，表征当然可能完全不变；这不能解释成“没有干扰”。优先将局部机制观测放在被更新模块的输出，并固定其下游计算。

本轮不先训练新 SAE，不等待新 Router，不改变损失函数。先用已有模型把必交图和局部作用检查做出来。

### 3.2 图1：原始表征在共同方向上的分布

#### 图题

**不同数据组在共同表征方向上的占用与分布**

#### 图1A：能量谱——变化究竟集中在哪里

在拟合集上，将 A、B、C 三组均衡混合，用同一个全局均值中心化，计算共同的主方向。为两组分别计算 PCA 后再比较“各自 PC1”是不允许的，因为它们通常不是同一个方向。

记原始表征为 `h`，全局均值为 `μ`，共同协方差为 `C`，其特征值为：

\[
\lambda_1\geq\lambda_2\geq\cdots\geq0.
\]

能量比例使用：

\[
e_j=\frac{\lambda_j}{\sum_i\lambda_i},
\qquad
R(k)=\frac{\sum_{j=1}^{k}\lambda_j}{\sum_i\lambda_i}.
\]

横轴是方向序号，纵轴是单方向方差占比或累计方差占比；注明达到90%、99%累计方差所需的经验维数。若从 SVD 的奇异值 `σ` 计算，方差比例对应 `σ²`，不是直接对 `σ` 求和。

**读图边界：**这部分反映中心化后的方差集中，不代表语义信息量，不代表任务信息被保留，更不代表这些方向会造成冲突。公共均值本身的能量另行注明，不能混进“中心化方差低秩”的说法。

若维数估计接近样本数允许的秩上限，或者跨记录重采样不稳定，要报告样本限制，不能把有限样本的低秩说成模型固有低维。

#### 图1B：同一方向上的组条件分布——导师要求的主体

取同一拟合得到的方向 `v₁、v₂、v₃`，在独立评估集上计算：

\[
s_j(x)=v_j^{\top}\big(h(x)-\mu\big).
\]

每个小图对应一个固定方向。

| 图元素 | 具体规定 |
|---|---|
| 横轴 | 样本在同一个方向 `v_j` 上的投影值 `s_j` |
| 纵轴 | 经验概率密度，或经验累计概率 |
| 不同曲线 | A、B、C 三组；同图使用相同分箱和归一化规则 |
| 方向来源 | 拟合集共同方差最大的前三个方向；不是事后挑分得最好或冲突最大的方向 |
| 均值处理 | 所有组使用同一个全局均值；不要分别中心化后抹掉组间均值差 |
| 样本单位 | 明确是记录还是 token；不能默认为每个 token 都独立 |

不预先拟合正态分布，不预先假定 Zipf 或某种混合分布。导师画了若干正态形状，不等于数据已经服从正态。先画真实经验分布，再描述它是单峰、多峰、偏斜，还是有长尾。

有监督 token 时，优先使用与本轮损失对应的 token 表征，并控制每条记录的贡献。句均池化可以用于辅助展示，但不能直接把“句均表征的梯度”代替实际逐 token 损失的梯度。

**这张图要读出的不是“谁应该分专家”，而是：**两组在相同坐标上的中心、宽度与支持范围是否相近；主要方向是大家共同使用，还是存在明显的组差异。

三个投影的边际分布相似，并不能证明高维联合分布相同。前三个方向未显示差异，也不能推出剩余方向没有任务相关差异。

#### 图1的图注草稿

> 在同一 checkpoint 的同一表征位置，对均衡混合的拟合集建立共同坐标系，并在独立评估集上展示各组分布。A展示中心化方差的能量谱；B展示不同数据组沿相同主方向的经验分布。该图描述当前表征的方向结构与组间关系，不把分布重叠或低维集中直接解释为负面干扰。

#### 导师手绘图中容易混淆的两种横轴

“奇异值随序号衰减”与“样本在某个方向上的概率分布”是两种图。前者横轴为方向编号；后者横轴为投影取值。不能在同一条横轴上把 `σ₁、σ₂、σ₃` 当作三个样本分布的坐标区间。

原始表征维数、SAE 字典大小、可训练参数数也不是同一件事。本轮统一分别写成 `D、M、P`，不因口头比喻而混用。

### 3.3 更新检查表：将主图连接到“相互伤害”

这一步不是泛泛地再计算一个“更新距离”，而是检查明确的作用：**同一初始状态下，让 A 学得更好的更新，有没有使 B 或 C 变差？**

每次从同一模型和优化器状态复制一个分支，只对指定共享参数块做一次更新，记录实际参数变化 `Δθ_A`，然后在独立评估数据上测量 A、B、C 的损失变化。每次测完回到原状态，不将 A、B、C 顺序训练混在一次比较里。

统一记：

\[
D_{A\rightarrow B}
=
L_B(\theta+\Delta\theta_A)-L_B(\theta).
\]

`D>0` 表示这次来自 A 的更新对 B 不利；`D<0` 表示有利。这里使用的符号与原报告的“Split−Shared”不是同一个量，图表必须标清。

一次更新只有在 A 自身的独立评估损失确实改善时，才能作为“对 A 有效但伤害 B”的证据。若 A 自身也变差，应先检查步长、梯度噪声或任务设置，而不是直接解释为跨组冲突。

最终先交一个表即可：

| 更新来源 | A评估损失变化 | B评估损失变化 | C评估损失变化 | 是否满足来源组自身改善 |
|---|---:|---:|---:|---|
| A：高中数学 | 待测 | 待测 | 待测 | 待判断 |
| B：大学数学 | 待测 | 待测 | 待测 | 待判断 |
| C：高中生物 | 待测 | 待测 | 待测 | 待判断 |

需要重复不同的更新微批次，并报告结果的波动，不能仅选一个有冲突的例子。评估不确定性以记录或模板为重采样单位；不能把来自同一记录的 token 全当成独立样本。更新随机性与评估样本随机性应区分说明。

若使用带动量或自适应预条件的优化器，应复制相同优化器状态，保留实际 `Δθ`。不能只用原始梯度余弦，代替该优化器真实的一步影响。可检查缩小步长后符号是否稳定，以识别大步长的非局部效应。

**这一表最多确认当前状态附近的局部作用，不自动解释完整训练中的 Shared/Split 差距。**

### 3.4 在同一组方向上，找出 B 的哪些变化与伤害有关

只画“B更新前后分布动了”仍然不够，因为移动方向未必有害。需要把位移与 B 的任务敏感方向相联系。

记：

\[
\Delta h_B^{(A)}
=
 h_B(\theta+\Delta\theta_A)-h_B(\theta),
\qquad
\delta_B=\nabla_{h_B}\ell_B.
\]

`δ_B`在更新前的模型状态上计算。对于共同方向 `v_j`，观察其局部损失贡献：

\[
r_{A\rightarrow B,j}
=
\big(v_j^\top\delta_B\big)
\big(v_j^\top\Delta h_B^{(A)}\big).
\]

`r_j>0` 表示该方向上的位移在一阶近似下推高 B 的损失；`r_j<0` 表示有利。对序列模型，应在实际参与损失路径的 token 位置上计算并汇总；公式不是对任意句均池化向量都自动成立。

使用拟合阶段固定的同一组方向，并保留未展示方向的残余贡献：

\[
\delta_B^\top\Delta h_B^{(A)}
=
\sum_{j=1}^{k}r_{A\rightarrow B,j}
+
\delta_B^\top(I-P_k)\Delta h_B^{(A)},
\qquad P_k=\sum_{j=1}^{k}v_jv_j^\top.
\]

这样才能区分“主要共同方向承载伤害”与“图看着低维，但真正伤害在没有画出的方向”。不要只展示前三个方向，随后默认它们解释了所有损失变化。

这一步成立的边界是：所选表征处于本次可更新参数到损失的共同计算边界，其下游固定；实际损失变化与一阶近似也需要核对。否则应报告遗漏路径或近似误差，不强行给出完整归因。

**执行优先级：先交图1和更新检查表，再补方向贡献。**若没有稳定的局部不利作用，本轮就不继续搜“冲突方向”，也不事后挑一个最符合故事的样本。

### 3.5 后续最小干预：恢复被怀疑的位移，而不是开发新方法

当上一步确实定位到稳定候选方向时，下一步才考虑诊断性恢复：在评估 B 时，将 A 更新导致的候选方向位移恢复到更新前值，观察 B 的伤害是否减轻。

例如，对预先确定的投影 `P`：

\[
\widetilde h_B
=
 h_B^{\mathrm{after}}
 -P\big(h_B^{\mathrm{after}}-h_B^{\mathrm{before}}\big).
\]

这只是临时的激活干预，不修改常规训练方案，不据此声称已经发明更好的 Router。

对照至少要排除“把学习取消得更多，所以 B 看起来更好”：报告改动的维数与范数，与匹配的随机/非候选方向干预比较，并检查对 A 的改善是否也被同样取消。候选方向必须由独立拟合数据选择，不能在 B 的测试损失上挑出来再用同一数据验证。

若不能匹配相关改动量，或者候选干预只是更强地削弱了整个更新，结论应保留为不充分。即使成功，也只支持这些位移参与传递局部伤害，不证明它们是全部长期干扰的唯一成因。

## 四、结论：按不同结果填写，不提前写成发现

### 4.1 当前能够写入组会的结论

> 现有实验观察到部分共享/隔离配置的损失差异，以及领域级 SAE 激活统计差异。但共享/隔离比较对参数预算口径敏感，目前也没有展示表征关系与跨组更新伤害的对应结果。因此，本轮先分析原始表征的方向分布，并在同一模型状态下核验其与局部不利更新的关系。

### 4.2 新结果出来后的判断分支

| 结果 | 允许更新的判断 | 接下来改变什么 |
|---|---|---|
| 有共同方向；有稳定不利更新；不利贡献集中于这些方向 | 支持“这些方向可能传递局部伤害” | 做匹配的诊断干预，而不是立即做 Router |
| 有共同方向，但更新主要有利或接近零 | 这些共同方向更像兼容共享，重叠本身不是隔离理由 | 放弃“重叠就干扰”的判断 |
| 不利更新存在，但主要在残余/低能方向 | “主要高能方向解释冲突”的附加假设不受支持 | 不再把低秩主方向当作默认路由依据 |
| 静态分布差异明显，但交叉更新并不有害 | 可区分性与是否应该隔离可以分离 | 下调“分布差异直接指导隔离”的判断 |
| 结果跨批次、步长不稳定，或来源组自身没有改善 | 尚未建立可靠的局部伤害现象 | 先核对测量与更新设置，不包装为机制结论 |
| 只完成静态主图，没有更新作用结果 | 只得到表征结构描述 | 明确把机制连接列为尚未完成，不能宣布机制得到验证 |

这些分支不排除多个原因同时存在。尤其不能因为检测到了局部梯度冲突，就宣布容量和训练历史不再重要。

### 4.3 建议保留的组会四段式草稿

**目的**

> 我们希望解释不同数据共享参数时，负面干扰通过什么表征和更新关系产生。本轮先分析共同表征方向是否承载了相互伤害的更新，而不先按人类语义距离决定如何分发。

**假设**

> 我们假设，部分局部干扰来自共同表征方向上的不利更新：使 A 改善的参数变化，也沿这些方向使 B 的任务损失上升。竞争解释是，共同方向主要承载无害共享成分，伤害并不主要由这些方向传递。

**分析方法**

> 在同一 checkpoint 和同一层上，先绘制均衡数据的共同能量谱及各组在相同方向上的经验分布，再从同一模型状态分别进行一次更新，检查跨组损失变化，以及不利位移是否落在这些共同方向。

**结论**

> 当前观察到【填写结构结果】。单步更新显示【填写来源组改善、目标组变化及稳定性】。方向分析【支持／不支持／尚不足以判断】共同方向传递局部伤害的假设。目前不能据此推出完整训练中的共享/隔离优劣，也不能直接推出 SAE 路由有效。

## 五、给 Agent 的任务边界草案

> 本轮不设计新 Router、不训练新 SAE、不搜索一套最优分布距离。先核验现有共享/隔离实验的数据、checkpoint、可训练参数块和损失定义。
>
> 以已有高中数学、大学数学、高中生物数据为首轮固定案例，在同一模型状态和同一表征位置上，使用独立拟合集建立共同坐标，并在评估集输出“共同能量谱 + 各组沿相同主方向的经验分布”。禁止分别对每组拟合坐标后直接比较，禁止把示意正态曲线当成实测结果。
>
> 从同一模型及优化器状态进行可回滚的一步更新，分别记录来源组和其他组的独立评估损失变化，检查来源组是否改善，报告不同更新批次的波动。不得仅输出梯度余弦而不记录实际参数更新与实际损失变化。
>
> 若稳定不利更新存在，再沿预先确定的共同方向分解目标组表征位移对损失的一阶贡献，并保留残余方向和近似误差。若局部伤害不稳定，停止机制归因，报告现象未建立及具体原因。
>
> 输出中的事实、解释和未验证假设分开。缺失数据、模型状态或控制条件应列为缺失，不用旧项目默认值补齐。汇报沿用“目的—假设—分析方法—结论”，结论按上述结果分支填写。

## 附录：为什么这条链不是换一个指标——最小数学解释

以下是本文提出的局部数学说明，不是导师的原话，也不是已有实验结果。

### A. 表征和参数更新之间缺的那个联系

设只更新一块上游共享参数 `θ`，从完整表征边界 `h` 到损失的下游计算固定。对样本 `z`，链式法则给出：

\[
g_z=\nabla_\theta\ell_z
=J_z^\top\delta_z,
\qquad
J_z=\frac{\partial h_z}{\partial\theta},
\quad
\delta_z=\nabla_{h_z}\ell_z.
\]

对 A 样本做小步长 SGD 更新 `Δθ_A=−ηg_A`，对 B 的一阶影响为：

\[
\Delta\ell_B
\approx
-\eta\,\delta_B^\top J_BJ_A^\top\delta_A.
\]

这说明需要同时知道：参数变化怎样传到两个样本的表征，以及两个样本各自需要表征向哪个方向改变。只知道 `h_A` 和 `h_B` 的距离，通常没有给出这些信息。

因此，“更新分布”与大问题的联系不是“它也是一种距离”，而是：它携带任务目标与参数耦合的信息，能够用于检验一次共享更新是否伤害另一组数据。但这种联系仍需在当前模型和任务中落到实测结果。

若用 Adam 等优化器，局部影响首先应按实际更新写成 `ΔL_B≈g_BᵀΔθ_A`，不要不加条件地套用 SGD 的负梯度内积。

### B. 一个容易理解的共享线性层例子

假设只有共享线性层 `W` 可更新，输入表征 `h` 固定，层输出为 `s=Wh`，输出侧损失梯度为 `δ`。单个位置的梯度为：

\[
\nabla_W\ell=\delta h^\top.
\]

于是：

\[
\left\langle\nabla_W\ell_A,\nabla_W\ell_B\right\rangle_F
=(h_A^\top h_B)(\delta_A^\top\delta_B).
\]

在这个限定模型中，若两组输入相同或正向重叠，输出侧调整要求同向时可以相互帮助，反向时可以相互伤害；若输入正交，对这一共享线性层的一步更新没有对应的一阶交叉作用。

**相同表征可以对应不同的共享学习后果。**所以“表征重叠”不是“干扰”的同义词，负面作用还取决于任务要求。

该分解不能直接宣称对任意完整 Transformer、序列聚合、LoRA 因子参数化或自适应优化器都逐项成立；这些场景要回到实际梯度、实际更新与实际损失变化。

### C. 哪一部分才是需要实验验证的新假设

“一个有效更新让另一组 loss 上升”是局部伤害的观察判据；小步长下的梯度关系是局部展开。重复验证它们，不能独自构成完整的机制贡献。

本轮真正不确定、值得检验的是：

> 在真实数据与当前模型中，这种不利作用是否具有稳定的表征方向结构？它是否主要由两组共同占用的少数方向传递？对这些方向的诊断性干预是否有超出一般削弱更新的选择性作用？

只有这一层得到证据后，才值得继续问 SAE 能否以更便宜、更可解释的方式读取这些结构，以及这种信号是否有助于专家分配。
