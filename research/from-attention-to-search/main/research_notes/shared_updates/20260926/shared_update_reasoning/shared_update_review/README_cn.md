# 阅读说明

本包包含三份讨论文档与所引用的原始材料副本。

1. `01_research_outline_cn.md`：先读核心判断、简短审计与第5—6节，再看第9—10节的导师原话和绘图方案。
2. `02_mini_paper_en.md`：英文探索性论文草稿，按问题—理论—实验—结果—边界—下一步组织。
3. `03_mini_paper_cn.md`：英文稿的完整中文译版。

`sources/` 保留用户上传的记录，未改写其中结果或历史建议。来源记录内链接的代码、数组和图片原本没有包含在上传包中，本包也不包含这些文件。三个新文档的直接来源链接在解压后可使用。

本次只进行了材料审计、公式辨析与文档整理；没有执行新实验、修改科研状态或宣称独立复现原始结果。
