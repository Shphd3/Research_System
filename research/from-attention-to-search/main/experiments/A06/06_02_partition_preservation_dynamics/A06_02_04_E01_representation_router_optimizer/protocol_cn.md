# 实验协议：A06_02_04_E01 表征—路由器—优化器共同动力学

## 0. 审核摘要

**审核状态：** 用户已明确要求沿 specialization 主线继续推进，每轮形成确定 anchor，并执行下一轮完整实验。

**目的：** 在神经网络全序列语言建模桥接中，定位匹配间隔首次越界与后续重新进入分别需要哪条可训练路径。

**主 anchor：** `../../../../problem_anchors/06_geometry_proxy_preservation/06_02_partition_preservation_dynamics/06_02_partition_preservation_dynamics_anchor.md`

**唯一问题：** 越界与恢复需要路由行移动、表征移动、二者联合耦合，还是 AdamW 的历史梯度缩放？

**物理先验：** \(m_{f,a,b}(t)=(w_a(t)-w_b(t))^\top\mu_f(t)\) 同时受路由行和特征中心控制；优化器会改变原始梯度到实际边界更新的传递。

**主指标：** 首次越界与条件恢复的配对冻结必要性比例 \(N_k(E)\)。

**最小设置：** 每个 batch 含 32 条完整序列，每条序列有 32 个下一词损失；四个均匀特征、一层因果注意力、四个固定功能匹配专家、加权最高分专家路由、全位置交叉熵。

**完整配置：** 32 个随机种子、1000 步、远程 4 卡、每步记录越界事件，在第 0/1/2/5/10/20/40/80/160/320/500/750/1000 步记录完整诊断。

**主条件：** 在类别 0 偏置公共背景下，比较 8/32 与 4/32 特征序列；SGD 与 AdamW 都分别运行只训练路由器、只训练表征和联合训练。全特征信号与“数量相同、任务已解、位于路由正交子空间”的背景只运行联合 SGD/AdamW，作为安全对照。

**通过：** 至少一个联合条件在非公共特征—种子单元中的越界比例不低于 0.25，并且冻结或优化器干预给出预注册的必要路径分类。

**证据不足：** 第 0 步路由或专家功能不匹配、完整 32 seeds 未完成，或联合训练没有进入越界区间。

**不能声称：** 可部署 Router、自然语言专家专业化、MTP 收益或下游干扰降低。

**执行决定：** 先 smoke，再提交远程 4 卡 full run。smoke 只能修正数值或实现问题，不能改变决策问题和主指标。

## 2. Anchor 对齐

**决策问题：** 哪条可训练路径是越界与重新进入的必要组成？

**核心干预：** 通过冻结删除 \(\Delta w\) 或 \(\Delta\mu\)，再与联合训练比较。

**证伪条件：** 冻结被声称必要的路径后，事件仍保持不变。

**边界：** 只覆盖固定专家功能的合成神经桥接。

## 3. 可证伪假设

\[
N_k(E)=\Pr(E_{joint}=1,E_{freeze(k)}=0\mid E_{joint}=1).
\]

1. 在每种优化器内部，联合条件事件比例至少为 0.25 且 \(N_k(cross)\ge0.75\) 时，才把路径 \(k\) 判断为首次越界所必需。
2. 只在已经越界的单元中，用同样规则判断重新进入的必要路径。
3. AdamW 与 SGD 的配对事件比例差至少为 0.25，或事件时间中位数相差至少 2 倍时，才保留优化器传递解释。

联合训练不发生事件时，结论是证据不足，不是证明所有路径安全。

## 4. 竞争解释

- 路由行单独移动已经充分。
- 表征单独移动已经充分。
- 单路径都不充分，只有联合反馈产生事件。
- AdamW 改变实际边界方向，而原始梯度解释不完整。
- 背景位置数量而非类别偏置解释现象。
- 第 0 步专家功能或路由身份错误，使后续轨迹不可解释。

## 5. 数据、模型与目标

### 5.1 数据

每个训练 batch 含 32 条完整序列。每条序列有 33 个重复 token，对应 32 个下一词损失位置。特征信号序列在 \(f\in\{0,1,2,3\}\) 上均匀分配。

- `signal_only_s32`：32 条特征序列，每个特征 8 条；每条序列是 33 个重复 \(F_f\)。
- `biased_s8`：8 条特征序列，每个特征 2 条；另有 24 条重复 \(C_0\) 的公共序列。
- `biased_s4`：4 条特征序列，每个特征 1 条；另有 28 条重复 \(C_0\) 的公共序列。
- `solved_orthogonal_s4`：4 条特征序列，每个特征 1 条；另有 28 条重复中性 token 的序列。中性输入与读出方向正交于特征类别方向，并在第 0 步已经解出。

类别偏置公共 token 共用同一个可训练 embedding；已解背景使用独立的路由正交 embedding 与读出方向。不使用位置 embedding。每条序列都计算完整的 32 位置 LM loss；特征比例由完整序列数量控制，而不是在一条混合序列内遮掉损失。

### 5.2 模型

- 维度 64、四头一层因果自注意力、残差与层归一化。
- 路由输入 \(h=\operatorname{LN}(X+A)\)。
- 四行线性路由、温度 1.0、加权最高分专家选择。
- 四个固定仿射专家，对应固定输出方向 \(\beta u_e\)，其中 \(\beta=4\)。
- 固定类别方向和 token 类型方向组成输出读出；专家 \(e\) 对 \(F_e\) 与 \(C_e\) 目标均有局部功能优势。

### 5.3 初始化

每个 seed 的所有条件共享同一个基础模型状态。路由行由第 0 步特征信号位置中心初始化，跨专家去均值后统一缩放，使第 0 步匹配间隔低尾值等于 0.5。固定匹配为 \(a(f)=f\)。

第 0 步必须满足：每个特征中心选择专家 \(f\)；全部匹配间隔为正；对目标 \(F_f\)，强制专家 \(f\) 的损失低于任一竞争专家。

### 5.4 全位置损失

\[
L=\frac1{32}\sum_{t=1}^{32}\ell_t=L_{signal}+L_{background}.
\]

按原始 \(1/32\) 权重分别计算特征与背景原始梯度，使二者之和与总原始梯度在数值误差内闭合。

### 5.5 优化器

- SGD：学习率 0.002，无动量、无权重衰减。
- AdamW：学习率 0.002，\(\beta_1=0.9\)、\(\beta_2=0.999\)、\(\epsilon=10^{-8}\)、权重衰减 \(10^{-4}\)。
- 主实验不做梯度裁剪；出现非有限值则该单元无效。

只有 smoke 出现非有限值或前五步破坏第 0 步有效性时，才允许同步降低两种优化器的共同名义学习率，并在 full run 前记录。

| 数据条件 | 训练条件 | 作用 | 证据等级 |

## 7. 主指标

\[
N_k(E)=\frac{\sum_i\mathbf1[E_i^{joint}=1\land E_i^{freeze(k)}=0]}{\sum_i\mathbf1[E_i^{joint}=1]}.
\]

\(i\) 是一个特征—种子单元。由于类别 0 偏置背景可能帮助特征 0、损害特征 1--3，主因果判断只使用特征 1--3，并单独报告特征 0。

该指标能判定当前受控表面上的必要性，不能证明充分性或模型外普遍性。

## 8. 次要指标

- 首次越界与重新进入步数；
- 最终正间隔比例和最终匹配专家比例；
- 间隔低尾轨迹；
- 特征信号位置的特征—路由归一化互信息；
- 全位置损失，以及特征/背景目标准确率；
- 路由行项、表征项与交互项的有限步闭合；
- \(X/A/Q/h\) 的特征中心与公共中心移动；
- 特征/背景原始路由梯度的边界投影；
- 实际 SGD/AdamW 更新的边界投影；
- Adam 路由行的一阶与二阶矩。

## 9. 已知混淆项

- 高聚类纯度可以在专家身份交换后仍然很高。
- 首次越界不等于最终失败。
- 精确代数闭合不等于因果证据。
- 特征 0 改善可能掩盖特征 1--3 失败。
- 固定专家功能只用于隔离动力学，不代表专家会自然学出该功能。

## 11. 算法步骤

1. 构造固定正交类别方向和 token 类型方向。
2. 为每个 seed 初始化一份共享神经网络基础状态。
3. 为每种数据条件生成 32 条序列，并精确控制特征/背景数量。
4. 从特征信号位置中心初始化路由行，并把初始低尾间隔缩放到 0.5。
5. 将完全相同的状态复制到所有训练条件。
6. 应用参数冻结和优化器选择。
7. 对全部 32 个下一词位置训练。
8. 每步在固定四特征评估集上记录全部成对间隔、越界与重新进入。
9. 在诊断步记录来源中心、来源梯度、实际更新、优化器矩、语言建模指标与有限步闭合。
10. 聚合四个 GPU shard 的配对特征—种子事件。

## 12. 通过、削弱与证据不足

**路径必要：** 联合事件比例 \(\ge0.25\)，且该路径的配对冻结必要性比例 \(\ge0.75\)，安全对照通过。

**耦合必要：** 联合训练产生事件，但两个单路径条件都在至少 0.75 的联合事件单元中不能复现。

**优化器效应：** 事件比例差 \(\ge0.25\) 或事件时间比 \(\ge2\)，安全对照通过。

**削弱：** 单路径与联合轨迹相近，或 AdamW 与 SGD 事件轨迹相近。

**证据不足：** 联合训练无事件、第 0 步 guard 失败、seed 不完整、出现非有限值，或安全对照复现同一失败。

## 13. 不能声称

该实验不能声称自然语言 MoE 专业化、下游功能价值、专家功能自然形成、优化器普遍规律、MTP 改善路由，或在因果路径定位前声称应采用某个新 Router。

## 14. 审核记录

- 本协议执行 canonical A06 story 与 0710 specialization meeting brief 中已经明确的下一决策。
- 固定仿射专家用于保持已知功能映射，避免“专家功能同时漂移”混淆表征—路由器因果审核。
- Smoke 修正 1：原先把特征段与公共段放在同一序列，因果注意力把特征前缀带入后续公共位置，使类别均衡公共背景不再具有相同隐藏状态。正式协议改为在同一 batch 中混合彼此独立的完整特征序列和公共序列；每条序列仍计算完整 LM loss。
- Smoke 修正 2：共同名义学习率从 0.01 降到 0.002，因为 0.01 的 AdamW 在无背景安全对照中产生瞬时越界。0.002 与既有长训神经桥接一致，并在 full run 前同步应用于两种优化器。
- Pilot 修正 3：相同公共输入配四类均衡目标会形成不可学习的冲突任务，并持续制造路由轮换，因此不是可训练桥接中的有效“无压力”对照。正式对照改为背景数量相同、在第 0 步已解出且位于路由正交子空间的背景；此前冻结模型中的类别均衡证据仍只在原边界内成立。
- Pilot 修正 4：增加 router-only AdamW 与 representation-only AdamW。pilot 已显示优化器会改变事件区间；若不增加这两个冻结条件，只能观察 AdamW/SGD 不同，不能定位 AdamW 下的因果路径。
