# 实验协议：优化器预条件下的路由边界压力

## 0. 审核摘要

**目的：** 区分 AdamW 路由更新中的逐坐标二阶矩、一阶矩方向和总实际更新范数，哪一个造成上一轮观察到的前 50 步越界。

**唯一问题：** 逐坐标二阶矩归一化是否是必要原因，还是路由器总更新幅度已经足够？

**主指标：** 完整 AdamW 早期越界事件在干预条件中的配对复现比例 \(R_q\) 和删除比例 \(N_q=1-R_q\)。

**最小设置：** 完全复用上一轮数据、模型、初始化、固定专家功能和全序列语言建模损失；所有条件的表征都用 AdamW，只改变 Router 更新。

**完整运行：** 32 seeds、1,000 步、两种有偏背景、两个安全对照、四种 Router 更新、远程四卡。

**有效性要求：** 完整 AdamW 早期越界率至少 0.25；范数匹配相对误差小于 \(10^{-5}\)；手写完整 AdamW 与 PyTorch AdamW 的参数误差小于 \(10^{-6}\)；安全对照越界率低于 0.25；32 seeds 全部完成。

## 1. 四种 Router 更新

1. **完整 AdamW：** 表征与 Router 都使用标准 AdamW。
2. **二阶矩各向同性化并匹配范数：** 表征使用 AdamW；Router 保留一阶矩方向，把二阶矩替换为一个标量，再把更新范数匹配到同状态完整 AdamW。
3. **原始梯度方向并匹配范数：** 表征使用 AdamW；Router 沿当前 \(-g_t\) 更新，范数匹配同状态完整 AdamW。
4. **名义 SGD：** 表征使用 AdamW；Router 使用学习率 0.002 的普通 SGD，作为相同名义学习率参考。

内部 Adam 矩在所有条件中都更新，用于在每个条件自己的当前状态上计算完整、各向同性化和原始梯度反事实更新。

## 2. 判定规则

对前 50 步越界事件：

\[
R_q=\Pr(C^{(q)}=1\mid C^{(full)}=1),
\qquad
N_q=1-R_q.
\]

- \(N_{scalar\_v\_norm}\ge0.75\)：支持逐坐标二阶矩必要。
- \(R_{raw\_norm}\ge0.75\)，且原始梯度范数匹配的事件率最多比完整 AdamW 低 0.10：支持 AdamW 特定的方向历史不必要。
- \(R_{scalar\_v\_norm}\ge0.75\) 且 \(R_{raw\_norm}<0.25\)：支持一阶矩方向充分而原始梯度不充分。
- 其余结果：多机制或当前证据不足。

机制指标是前 50 步累计负路由边界压力：

\[
B_i^q(50)=\sum_{t=1}^{50}
\left[-\left\langle\Delta w_a^q(t)-\Delta w_b^q(t),\mu_f(t)\right\rangle\right]_+.
\]

## 3. 数据、模型与运行

- 每批 32 条完整序列，每条 32 个下一词损失，不使用位置 embedding。
- 两种主条件分别有 8/32 和 4/32 条均匀特征序列，其余为类别 0 背景序列。
- 两个安全对照是全特征信号和任务已解的路由正交背景。
- 一层因果注意力、残差和层归一化；四专家加权最高分路由；固定功能匹配专家和固定读出。
- 第 0 步身份绑定正确，低尾匹配间隔为 0.5。
- 32 seeds、1,000 步、4 GPUs；前 50 步逐步记录事件、更新范数与边界投影。

## 4. 结论边界

本实验只能识别当前受控桥接面上的优化器组成，不能推出自然语言 specialization、学习专家、真实下游收益、MTP 收益或最终 Router。完整运行后必须形成 `summary.md`、`detailed.md` 并更新 anchor，再进入方法设计。
