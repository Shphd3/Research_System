研究 Anchor 草案 v0.1｜常见组成要素能否支持低频组合学习？
日期：2026-10-24。状态：待执行 Agent 对齐项目规则，尚无本轮实验结果。

一、目的与组会衔接
上次讨论提出：保留已经掌握、可被后续使用的计算，再对尚未解决的细粒度差异进行学习。
本次研究：当组成要素已学会、但特定组合较少出现时，模型能否复用已有处理，主要学习组合条件，而不必大幅重学组成要素？

长期问题：哪些计算适合共享，哪些差异需要专家分别学习？
本轮裁决问题：在组成要素曝光相同的条件下，保护已有模型、仅开放受限的新增学习路径，能否支持低频组合的学习和留出泛化？若有收益，是否有证据表明它使用了已有功能，而非记忆组合答案？
“只需要学习如何组合使用”是较强的用户直觉，不是结论。将其收窄为“已有计算可复用，有限新增学习可能足够”；允许一部分已有计算仍需调整。

二、已有证据与缺口
1. 旧按频率分发方案没有获得预期收益。它按 CrossCoder feature 激活频率组织路由，并不直接识别计算复用关系。
2. R05 A 阶段保护的是学会旧任务后完整权重的前16个奇异秩一系数，不是已确认的共同功能。系数变化被压低，但旧任务保持没有改善。
3. 对新增残差更新做干预，能恢复部分旧任务表现，同时损害新任务表现。这说明更新有功能影响，不能据此说旧知识存放在残差里。
4. 首/末项条件规则反转是顺序学习诊断，不直接对应“共同基础上增加细分处理”。因此本轮应换为明确的组合任务，保留旧任务作为历史边界，不冒充直接延续同一机制检验。
以上依据是已有对话中的报告，执行 Agent 必须回查原记录。未经核实不升级为独立审计结论。

三、对象与最小模型
输入 x，基础操作 f_i，后续操作 g_j；中间结果 z=f_i(x)，目标 y=g_j(z)。
训练数据明确包含操作身份 i、j，但组合任务不提供正确 z。给出 z 的条件只能作为额外信息的正对照。
候选学习形式：保留已学模型 F，新增可训练路径 r；预测器 H(F(x,i,j), r(x,i,j))。
注意：这里只规定可检验的输入输出关系，不声称模型内部真的逐步实现 f_i、g_j，也不默认 r 就是纯“组合功能”。

四、必须分开的四种量
1. 组成要素频率：某操作/语义要素在训练中出现多少次。
2. 组合频率：某对 (i,j) 同时出现多少次。
3. 实际 feature 激活频率：固定编码器和阈值下，某个表示特征的激活比例。
4. 功能复用：同一种已有计算是否对多个组合的正确预测有可干预的贡献。
前两项可由合成任务控制；第三项需测量；第四项需行为与干预证据。不得相互替代。

五、假设及竞争解释
H1（已有能力可提供迁移）：已掌握组成操作的模型，比未接受组成操作训练的同源模型，在相同组合监督下学得更快或泛化更好。
竞争解释：仅增加训练、熟悉格式或答案词表带来收益。需要等预算、等格式的非对应操作预训练对照；若对照无法匹配，结论降级。
H2（受限新增学习足够）：固定已有模型、训练有限新增路径，在通过组合学习门槛时，能保持组成操作，并接近允许原参数继续更新的表现。
竞争解释：只是整体学得慢；新增容量足够记忆；显式格式使任务过于简单；共同模型原本就会组合。必须测起点、完整学习曲线、留出输入和容量/参数量。
H3（组合稀少是独立困难）：在组成要素边际曝光保持相同时，减少某些组合曝光会降低这些组合的泛化；把高低频身份交换后，差异随曝光而非固定组合身份变化。
竞争解释：某组合本来更难。频率交换设计与起点难度分层用于区分。
H4（后续问题）：对组合差异分开学习，相比共享新增路径有额外价值。它不是 H1–H3 的自动推论，本轮仅准备后续对照，不以当前结果宣称 MoE 必要。

六、如何更新认识
- H1成立、H2成立且有功能干预证据：支持本任务中保留已有处理、通过有限新增学习解决组合；仍不证明所有功能已解耦。
- H1成立、H2失败：已有处理有帮助，但当前冻结范围/新增容量/优化方式不足；不能说必须重学全部功能。
- H2行为通过，但未找到复用证据：仅证明某种受限适配可行，机制保持未知。
- H1不成立且阳性对照通过：削弱当前组成预训练有益的直觉；检查任务是否需要该功能，不无限搜索方向。
- H3成立：获得组合曝光的效应，不等于 CrossCoder feature 激活频率的因果效应。
- 数据、正对照、训练资格不通过：结果为证据不足；不得判定导师直觉错误。
