## Naming And Provenance Rules

- `A15_00`--`A15_12` name decision-owning parent lines; child numbers test one
  inherited clause.
- Experiment IDs follow their canonical parent even when immutable worker
  directories and run IDs retain historical lowercase names.
- Legacy IDs in this index are provenance aliases, not active paths.
- Geometry or information evidence does not become a routing-function claim
  without an A15_05 admission test.
