# CrossCoder同token上下文计算依赖

problem_key: 同一token不同上下文的C到R功能依赖
question_state: 研究者本轮明确激活
task_state: 只读准备完成
design_state: 精确操作规则草案，不能执行
result_state: NOT_RUN

研究者已确认唯一问题、H1／H2／H3与结果分支。本轮一个核心实验：在已有模型中先完成候选与层局部测量资格，再作有匹配对照的冻结干预。三条路径：①资产／读数是否可用；②发现侧冻结C、R与上下文目标；③在探索性文档留出上比较R及功能的配对效应。最多两个候选token，只固定第14→28层，不训练。完成标准是授权后在12000条前向内交付支持、不支持或证据不足；当前只授权资产读取与设计。

下一项研究者决定：当前具体依赖是否值得后续测试共享路径。数值阈值属于协议AI建议，尚未执行或假称研究者已接受；收到“继续执行本协议”才进入所述有界流程，资格失败则停止。不会自动进入专家／路由。
