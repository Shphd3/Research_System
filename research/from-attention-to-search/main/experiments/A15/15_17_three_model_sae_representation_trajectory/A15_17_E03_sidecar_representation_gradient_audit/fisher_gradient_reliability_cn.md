# E03 事后可信度审计：Fisher、梯度随机基线与 Loss

上级结果：[summary_cn.md](summary_cn.md)  
英文伴随文件：[fisher_gradient_reliability.md](fisher_gradient_reliability.md)  
状态：事后可信度审计（POST_HOC_RELIABILITY_AUDIT）；只读取已合格缓存、梯度收缩量和训练日志；优化器更新为 0；不修改冻结 Protocol。

## 1. 目的

本补充回答三个容易被原始图误读的问题：

1. Fisher 比是否按“类间方差除以类内方差”正确计算，而且是否真的对应有意义的类别可分性；
2. 重构梯度与语言梯度约成 90°，究竟是特殊的正交结构，还是高维空间中随机方向本来就会出现的现象；
3. 梯度范数、方向与训练语言 Loss 的现有关系，能否支持现在就确定重构正则系数。

## 2. 假设

如果 Fisher 反映稳定而非偶然的类别结构，那么真实标签下的 Fisher 应明显超过保持类别数不变的随机标签置换，而且独立报告集上的线性分类器应明显高于机会水平。若 SAE 重构改善这种结构，Fisher 的变化还应能由类间量与类内量解释，并与独立读出大体同向。

如果两种梯度具有“特殊正交性”，观测余弦的绝对值应比同维独立随机方向更接近 0；仅仅看到角度约为 90° 不足以支持该命题。若正则梯度范数影响语言 Loss，这种影响最终必须在共享参数空间的合计梯度和严格匹配的系数干预中出现，而不能只由局部激活梯度或 Loss 数值比例推断。

## 3. 分析方法

### 3.1 Fisher 的固定公式

对类别 \(c\)，令类别均值为 \(\mu_c\)，类别均值的等权中心为

\[
\bar{\mu}=\frac{1}{C}\sum_{c=1}^{C}\mu_c.
\]

本实验使用类平衡的类间量、类内量与 Fisher 比：

\[
B=\frac{1}{C}\sum_{c=1}^{C}\lVert\mu_c-\bar{\mu}\rVert_2^2,
\]

\[
W=\frac{1}{C}\sum_{c=1}^{C}
\mathbb{E}_{x\mid c}\lVert x-\mu_c\rVert_2^2,
\qquad
F=\frac{B}{W}.
\]

因此“Fisher 比是类间方差除以类内方差”是正确的。逐类别诊断使用

\[
B_c=\lVert\mu_c-\bar{\mu}\rVert_2^2,\qquad
W_c=\mathbb{E}_{x\mid c}\lVert x-\mu_c\rVert_2^2,\qquad
F_c=B_c/W_c.
\]

总体值必须按 \(\operatorname{mean}_c(B_c)/\operatorname{mean}_c(W_c)\) 恢复，不能直接平均 \(F_c\)。

### 3.2 Fisher 的不确定性与意义检查

- 对每个模型、checkpoint、数据集、层、坐标变换和表征面，使用相同的类别分层报告行进行 256 次配对 bootstrap；报告 \(B/W/F\) 及“重构相对原始 Attention”的对数比 95% 区间。
- 在 3B 原始坐标中进行 256 次保持类别大小的平衡标签置换；比较观测 Fisher 与置换分布的第 95 百分位。
- 在线性探针中只用 fit 拟合、tune 选超参数、report 报告；原始 Attention 选出的正则强度也用于对应 B3 检查，避免为 B3 单独挑最漂亮参数。报告平衡准确率、宏平均 F1 和最差类别召回。
- 原始坐标和只用 fit 决定的去首方向 B3 坐标分开。所有分析都是事后可信度审计；256 次重采样给出探索性区间，不升级为预注册确认性检验。

### 3.3 梯度的同维随机方向基线

当前可信比较使用 SAE 实际 32 个位置上的公共支撑。每批有 8 个样本，每个位置隐藏维度为 1024，因此

\[
d=8\times32\times1024=262{,}144.
\]

若两个单位向量在 \(d\) 维球面上独立、各向同性随机，则余弦 \(C\) 满足

\[
C^2\sim\operatorname{Beta}\left(\frac12,\frac{d-1}{2}\right),
\qquad
\operatorname{SD}(C)=\frac{1}{\sqrt d}.
\]

在本维度下，随机余弦标准差为 0.001953，平均绝对余弦为 0.001558，随机方向 95% 的绝对余弦上界为 0.003828，对应角度区间约为 89.781°–90.219°。每个观测量报告 \(C\sqrt d\) 和精确 Beta 尾概率；同一模型、checkpoint、层的四个不重叠批次再用标准化余弦平方和做组级检查，并对 44 个组的“更靠近 0”与“离 0 更远”概率分别做 Benjamini–Hochberg 校正。

该零假设只回答“相对独立各向同性随机方向是否特殊”。现有运行没有保留原始梯度向量，因此还不能做保持坐标结构的符号翻转、坐标置换、经验有效维度或跨批次错配方向检验。

### 3.4 Loss 与系数解释

训练语言 Loss 使用不可变训练日志，按累计有效预测 token 的 100M 区间求均值，并只在共同 token 区间作横向展示。局部重构梯度沿用训练时的层平均和 Loss 归一化。

若语言梯度和正则梯度是在同一个参数空间中的 \(g_{\mathrm{LM}}\) 与 \(g_{\mathrm{reg}}\)，总梯度满足

\[
\lVert g_{\mathrm{LM}}+\lambda g_{\mathrm{reg}}\rVert_2^2
=
\lVert g_{\mathrm{LM}}\rVert_2^2
+\lambda^2\lVert g_{\mathrm{reg}}\rVert_2^2
+2\lambda\lVert g_{\mathrm{LM}}\rVert_2\lVert g_{\mathrm{reg}}\rVert_2\cos\theta.
\]

所以即使 \(\cos\theta\approx0\)，大的正则梯度仍会增大实际更新长度，并可能通过曲率和后续状态改变影响语言 Loss。当前测得的是局部激活空间梯度，不是共享参数空间合计梯度；上式只能解释为什么“接近 90°”不等于“没有影响”，不能直接代入当前数值选择最终系数。

## 4. 结论

### 4.1 Fisher 的计算正确，而且真实标签结构明显高于随机；但它不是单独充分的质量指标

3B 时，44 个“模型×数据集×层×表征面”的原始坐标 Fisher 全部高于平衡随机标签第 95 百分位，观测值是该分位的 4.49–23.46 倍；256 次置换下每一项的一侧 \(p=1/257\)。报告集线性探针也都明显高于机会水平，最差类别召回没有塌成只识别少数类别。因此，本实验中的 Fisher 不是由随机标签或单一多数类制造出来的空比值，它确实描述了可读的类别几何。

![Fisher 相对随机标签的距离](figures/fisher_permutation_margin_3b.png)

读图：纵轴大于 1 表示真实标签 Fisher 超过随机标签的第 95 百分位；所有点均远高于 1。它证明“标签相关几何存在”，不证明语言模型会使用它。

但“Fisher 变大”不能直接写成“重构表征更好”。3B 的 44 个配对 Fisher 检查中，22 个区间在 0 上方、7 个在 0 下方、15 个覆盖 0；这些区间未做跨层多重比较校正。更关键的是，3B 所有 22 个原始坐标面板中，重构都同时压低了 \(B\) 和 \(W\)：\(B_{\rm recon}/B_{\rm attn}=0.532\)–0.911，\(W_{\rm recon}/W_{\rm attn}=0.440\)–0.826。Fisher 上升只表示 \(W\) 缩得比 \(B\) 更快，下降则相反。

![3B Fisher 变化由 B 与 W 的哪一部分驱动](figures/fisher_bw_ratio_3b.png)

独立探针给出更严格的限制：44 个 Attention/重构配对中，重构的报告集平衡准确率有 42 个更低、1 个相同、1 个更高。也就是说，Fisher 在其定义下有意义，但不足以单独排序表示质量；以后必须同时报告 \(B\)、\(W\)、置换基线、独立探针和最差类别召回。

![3B 独立报告集线性可分性](figures/internal_probe_accuracy_3b.png)

### 4.2 原先的“正交性”应收紧为“高维随机相容的近 90°”

176 个支撑梯度比较组成 44 个 checkpoint-layer 组。维度校准并做组级校正后：

- 43/44 组与同维独立各向同性随机方向相容；
- 0/44 组比随机方向更接近严格的 0 余弦；
- 唯一偏离是 SALL 在 1B、L0：其绝对余弦整体比随机更大，而不是更正交，校正后 \(q=9.67\times10^{-6}\)；四批符号并不完全一致；
- 3B 的 11 个模型-层组全部与随机方向相容。

![梯度余弦与同维随机方向](figures/gradient_cosine_vs_dimension_matched_random.png)

白话解释：在 26 万维空间里，两支没有关系的箭头本来就几乎是 90°。因此现有结果支持“没有稳定同向或反向分量”，不支持“模型学出了特殊的正交机制”。这也修正了主 Summary 中较强的“近似正交结构”措辞。

### 4.3 梯度范数仍可能影响 Loss，但现有相关轨迹不能确定因果或最优系数

3B 时，正则项标量约为语言 Loss 的 5.55%–6.33%，但局部支撑上的重构/语言梯度比在完整轨迹中分别达到 S7 0.099–0.763、S37 0.153–1.564、SALL 0.012–0.073。Loss 数字接近，梯度比例却相差近两个数量级，说明不能按 Loss 数值占比配系数。

在共同的 3.0–4.4B、100M-token 完整区间中，相对 Dense 的平均语言 Loss 差为：M2 +0.00065、S7 +0.01254、S37 +0.00333、SALL −0.00378 nats/token。它说明训练轨迹确实不同，也复现了附件图中的主要相对位置；但每个条件只有一条训练轨迹，目标拓扑同时不同，因此这些数值不能证明差异由梯度范数、角度或某个系数单独造成。

![源日志重建的训练语言 Loss](figures/training_lm_loss_multimodel_100m.png)

### 4.4 当前可固定的判断

1. Fisher 继续保留，但从现在起只作为“类中心距离相对类内散布”的几何量；任何“更好”判断必须通过标签置换与独立报告集探针，并同时展示 \(B\) 和 \(W\)。
2. “梯度正交”改称“观测余弦接近 0”；只有超过同维随机、保持坐标结构的零假设后，才允许称为特殊正交。
3. 当前不能宣布最优正则系数。用于下一轮工程 Smoke 的共同候选仍为 \(\lambda_{\rm rec}=0.1\)，因为固定状态线性缩放下，已见最大局部比例 1.564 会降到约 0.156；这只是保守候选，不是科学结论。
4. 真正的系数门控必须先量共享参数空间的“全部正则项合计梯度/语言梯度”，再做同起点、同数据顺序的短程系数干预。未来 checkpoint、随机正交基线和系数候选由独立的 [E05 草案 Protocol](../A15_17_E05_multimodel_fisher_gradient_coefficient_audit/protocol.md) 固定；该草案不授权执行。

## 证据边界

可以声称：Fisher 公式与回算一致；真实标签几何显著超过当前置换零假设；报告集可读性明显高于机会水平；3B 重构普遍同时压缩类间量与类内量；当前近 90° 角度大多与 262,144 维随机方向相容；Loss 数值占比不能代替梯度比例。

不能声称：Fisher 上升等于表征更好或语言模型使用它；当前梯度比随机更正交；局部激活梯度等于共享参数更新；附件中的训练 Loss 差由正则梯度范数单独导致；0.1 已是最优系数；或任何现有结果证明因果收益。
