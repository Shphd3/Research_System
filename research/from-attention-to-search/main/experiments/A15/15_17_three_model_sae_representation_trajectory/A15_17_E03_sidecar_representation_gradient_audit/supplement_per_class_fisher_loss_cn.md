## 1. Fisher 比到底是什么

类别间方差：不同类别中心彼此离得有多远。类别内方差：同一类别的样本围绕本类中心散得有多开。总体 Fisher 比就是

\[
F=\frac{B}{W}.
\]

因此您前面的理解是对的：这里确实是“间方差除以内方差”。数值大表示“类别中心之间的距离”相对“类别内部的散布”更大；它只说明当前表示中类别更容易分开，不证明语言模型真的使用了这种类别结构。

为了得到逐类别结果，同时保持与旧总体值完全一致，本次对类别 (c) 定义

\[
B_c=\lVert\mu_c-\bar{\mu}\rVert_2^2,
\qquad
W_c=\mathbb{E}_{x\in c}\lVert x-\mu_c\rVert_2^2,
\qquad
F_c=\frac{B_c}{W_c}.
\]

其中 \(\mu_c\) 是本类中心，\(\bar{\mu}\) 是所有类别中心的等权平均。总体值按

\[
F=\frac{\operatorname{mean}_c B_c}{\operatorname{mean}_c W_c}
\]

恢复，而不是直接平均各类 (F_c)。重新汇总后的所有总体数值都与已合格 E03 表格精确一致。

## 2. 两种表征的准确含义

本次术语：

- 原始 Attention 表征：挂接 SAE 之前、由 Attention 模块直接产生的向量；它进入原生语言模型后续计算，也作为 SAE 编码器输入。
- SAE 重构表征：SAE 根据原始 Attention 表征重构出的向量；在 S7、S37、SALL 中，它没有送回语言模型主前向，只参与重构目标。

所以需要纠正一个架构表述：三个模型都把原始 Attention 表征作为 SAE 输入；它们没有作为主模型输入使用的是“SAE 重构表征”。比较两者可以回答 SAE 保留、增强或压低了哪些可读类别结构，但不能证明主模型使用了重构结构。

## 4. Loss 量级

语言损失：下一词预测的平均损失。加权重构损失：乘上训练系数并按挂载层取平均后的重构项。加权辅助损失：乘上 `1/32` 后的辅助项。为减少单批次噪声，0.5/1/3B 均报告检查点之前 128 个更新、约 3355 万有效词元的中位数。

3B 时：

| 模型 | 语言 Loss | 加权重构 Loss | 加权辅助 Loss | 总正则 / 语言 Loss |
| --- | ---: | ---: | ---: | ---: |
| S7 | 3.459 | 0.161 | 0.031 | 5.55% |
| S37 | 3.443 | 0.184 | 0.031 | 6.24% |
| SALL | 3.436 | 0.188 | 0.031 | 6.33% |

![训练 Loss 量级轨迹](figures/training_loss_scale_trajectories.png)

白话解释：从目标函数的数字加法看，正则项只占语言 Loss 的约二十分之一。但是这个比例不能告诉我们“参数被推了多大”，因为不同 Loss 的归一化方式和导数尺度不同。

## 5. 梯度余弦、比例与系数

已核验证据：在 SAE 实际抽样位置上，重构梯度与语言梯度的数值夹角始终接近 90°。后续[同维随机基线审计](fisher_gradient_reliability_cn.md)表明，44 个 checkpoint-layer 组中 43 个与 262,144 维独立随机方向相容，没有任何一组比随机更接近严格正交。因此这里的可信表述是“余弦接近 0”，不是“学得了特殊正交性”。当前系数为 1 时，各检查点和层的平均“重构梯度 / 语言梯度”范围为：

- S7：`0.099–0.763`；
- S37：`0.153–1.564`；
- SALL：`0.012–0.073`。

![局部梯度比例、夹角与系数敏感性](figures/local_gradient_coefficient_sensitivity.png)

这暴露出关键问题：三个模型的正则 Loss 数值都约占语言 Loss 的 5%–8%，但梯度比例相差接近两个数量级。因此不能使用“把两个 Loss 数值调成同一量级”作为系数规则。

如果把重构系数从 \(\lambda\) 改为 \(\lambda'\)，在模型状态固定的瞬间，重构梯度范数按 \(\lambda'/\lambda\) 缩放而方向不变。增大系数会放大这支高维、随机基线相容的局部梯度；它不会自动变成帮助语言目标的方向，而且即使余弦接近 0，大范数仍可能通过更新长度与曲率影响后续 Loss。

## 6. 后续系数建议

**AI 建议，等待研究者确认：**

1. 第一轮匹配 Smoke 保持按层取平均，不改成求和；辅助损失系数暂时保持 `1/32`。
2. 若三种挂载拓扑需要公平比较，先统一使用重构系数 (lambda_{rec}=0.1)，不要分别为 S7/S37/SALL 选不同系数。按固定状态线性外推，当前最大的局部比例将从 `1.564` 降到约 `0.156`。
3. Full run 前必须补一次共享参数空间的合计梯度审计。若“总重构梯度 / 语言梯度”低于 `0.05`，再把系数提高到 `0.3`；若高于 `0.25`，或出现跨批次稳定的反向分量，则降到 `0.03`。
4. 不要因为 SALL 每一层的局部比例小就直接放大它：八层项进入共享参数后可能相加、抵消或作用于不同参数组，现有局部测量不能判断总效果。

这里的 `0.1/0.3/0.03` 是用于控制更新扰动的候选门槛，不是已经证明的最优系数。真正应冻结的系数要由参数空间合计梯度和小规模配对续训共同决定。
