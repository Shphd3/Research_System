## 3. 必须先拿到的 CPU 验收

- [ ] 同参数同输入切换开关，前向logits/h/重构/激活/两项损失不变；此要求不用于训练后已分化的两组。
- [ ] 只反传辅助项：C主干无梯度或精确零；T上游整体有限且非零；两组SAE有梯度并在同状态一致。只反传LM项：两组都经过SAE到上游。
- [ ] 辅助梯度不会到最后MLP的gate/up/down和最终输出归一化；共享 `embed.weight` 可通过输入路径获得梯度，不误判它“也作输出头所以必须零”。按参数身份去重，不要求每个词表行或每个上游张量都非零。
- [ ] 0/.1/1权重在裁剪前满足梯度比例；分别记录原始辅助梯度和加权梯度，保留零向量的未定义余弦原因；验证target与分母没有反向路径。
- [ ] 不等各rank/各microbatch目标数的构造批，分布式结果与单进程参考一致。两项各自全局求和/计数；不能平均局部均值或二次除以accum。
- [ ] 第0步LR=0时有梯度但参数不动是预期；正LR更新后再核验应变化的参数。
- [ ] 外部进程恢复对比下一批、mask、LR、优化器/日程、所有随机生成器和完整模型状态；不是仅证明“能加载”。
- [ ] 新分析导出与训练接点在同一小批一致；所有缓存写明 `h_pre_sae` 与 `hhat_mlp_input` 的定义。
- [ ] 数据/分类器的小型已知可分和错误标签夹具能发现索引、划分和泄漏错误，不把夹具效果当自然面板结果。

数值容差及不通过处理以协议§12为准，不在失败后现场放宽。预期回执：`checks/gradient_contract.json`、`checks/reduction_contract.json`、`checks/resume_replay.json`、`audit/pair_identity.json`。
