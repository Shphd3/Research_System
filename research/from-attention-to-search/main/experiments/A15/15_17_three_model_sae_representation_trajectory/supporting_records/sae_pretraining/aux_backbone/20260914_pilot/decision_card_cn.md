2026-09-14 · **AI 建议，待研究者采用；当前仅获文档审计与草案授权。**

**推荐下一步：采用这一对最小串联设计用于准备，先授权隔离副本实现、CPU 梯度/恢复验收和 1200 篇开发面板准备；GPU 启动检查与开发训练按下表单独授权。** 本卡是[唯一协议草案](protocol.md)的中文审阅摘录，不是另一份执行合同。

本次术语：稀疏自编码器（SAE）将表示编码为少量非零特征后重构；前馈模块（MLP）指最后 Transformer 块内的前馈计算；语言模型（LM）的代价用平均负对数似然衡量，即对真实下一个词元赋予的概率越低，损失越大。控制组记为 C，干预组记为 T；停止梯度（detach）只阻断反向传播，保留前向值。

| 决策项 | 具体候选 |
|---|---|
| 问题 | 辅助重构梯度进入主干后，最后块归一化后、SAE 之前的原始表示，是否更容易被简单分类器读出领域，以及 LM 代价多大？ |
| 读出对象 | 主指标用 `h_pre_sae`，当前源码键为 `sae_input`；实际进入串联 MLP 的是重构 `hhat_mlp_input`，只作附加读出。两者不得混名。 |
| 唯一条件差异 | C 的抽样辅助编码输入 detach；T 不 detach。两组 LM 梯度均经过 SAE；辅助目标与能量分母均 detach。 |
| 共同固定项 | 同一份 seed=17 随机初态复制；8层、hidden1024、SAE宽30000/最多32个正激活；总参数342902064；串联前向与残差不变；原分组 AdamW、分别裁剪1、预热后恒定日程。 |
| 目标 | LM全局有效目标平均交叉熵 + **0.1 ×** 全局辅助抽样平均能量归一化重构误差。两项各用各自分母；不新增防死辅助项。 |
| 比较坐标 | 四卡×每卡每微批2序列×累计16微批×2048目标，每次更新262144有效预测目标；主横轴用累计有效目标数，保持两组输入与抽样位置一致。 |
| 数据 | 复用现有训练视图。自然学术文本八类，各100篇拟合+50篇开发，共1200篇；分类器参数仅在拟合集内五折选择。LM代价用固定512条×2048目标开发窗口。配额、来源文档身份和数据哈希须准备验收，当前未下载。 |
| 主指标 | 各领域等权的分类综合分数（宏平均F1），取 T−C 的百分点差；主终点固定为4096次更新/1073741824有效预测目标。给出配对文档重采样区间，但不把文档数当训练种子数。 |
| LM代价 | 同一窗口上的 T−C 平均负对数似然，正值表示更差；旧验证流已经使用过，本轮只能称开发数据。 |
| 不能声称 | 领域可读性不等于事实理解、模型功能使用、稀疏性必要性或下游收益；一对单种子训练不能证明跨种子稳定。 |

**停止分支（以下数值均是本次新增的 AI 建议，待采用）：**

- 非有限损失/梯度、计数或输入错配、恢复失败、数据或评测不合格、存储/墙时超限：停止相应任务，不推进另一组越过当前配对阶段。
- 在512和1024两个检查点都出现 **LM损失差 T−C >0.10**，暂停，不进入D2。
- 在同样两个点，任一组的拟合面板重构误差均超过自身0点的2倍，且实际辅助训练活动中前300特征占正激活次数超过90%，暂停。这是联合退化门，单独未用率高不触发。
- 100步只有约328万辅助位置，不足1000万位置窗口；活动覆盖应报不足，不把它当特征死亡或健康结论。
- 4096终点：主差区间全正且未触发0.10代价警戒，记“开发方向支持”；区间非正记“开发方向不支持”；跨零或比较不合格记“分辨率/证据不足”。代价大于0.10先记“LM代价警戒”。**这些标签不拥有最终科学判断，也不自动授权正式确认。**
