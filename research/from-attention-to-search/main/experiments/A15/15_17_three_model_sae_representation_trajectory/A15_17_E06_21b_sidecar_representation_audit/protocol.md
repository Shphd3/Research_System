## 1. Terminology / Definitions

The native attention write \(a\) is each block's attention output after \(W_O\) and before residual addition. Human layer numbers 1–8 map to code indices 0–7. `last` selects the last valid正文 token; `mean` averages exactly the same valid正文 positions in float32. `z` denotes the online SAE's selected sparse coefficients; \(\hat a\) is its reconstruction; \(e=a-\hat a\) is the error. `pre-TopK scores` means the full 30,000 nonnegative encoder scores before selection, not a dense backbone coordinate system. CKA compares centered linear sample Gram structure, not semantic goodness. P relation labels apply to a sentence with two ordered referents; N8 labels apply to source records; PAWS labels apply to pairs.

## 2. Anchor Alignment

The Anchor's tested clause is whether sidecar regularization reshapes native \(a\) into a more cross-expression-readable relation representation. The strongest rival is scale, class compression, surface format, or observer-only reconstruction change. Same-input Dense/SALL contrasts isolate a checkpoint-level association, not training causality; S7 has a different fork/coefficient history. The primary falsifier is P's joint holdout in raw \(a\) with model-independent lexical controls and fit-only normalization sensitivity. Exact domain and PAWS results qualify generality; existing behavior and measured NLL qualify cost and use.

## 3. Tested Hypothesis

SALL-21B has a positive relation-direction linear-readout difference versus Dense-21B on both new entity groups and new templates in the original write. A positive P result is not required to coincide with a CKA decrease. If the effect appears only in \(\hat a\), \(z\), or a single scale-dependent representation but not native \(a\) under the registered guards, the native semantic hypothesis is not supported.

## 4. Rival Explanations

1. Scale/common-direction and within-class compression: inspect \(\lVert a\rVert\), first spectral direction, between/within-class terms, and fit-only normalization or centering without refitting on confirmation.
2. Lexical/template/identifier shortcuts: preserve paired opposite-direction examples with identical word/token bags; use disjoint entity groups and template pools, metadata/length/last-token baselines, and same-suffix/natural-name development diagnostics.
3. SAE observer artifact: measure raw \(a\), pre-TopK scores, selected \(z\), \(\hat a\), and \(e\) separately on the same tokens; check error's incremental label value under matched readout capacity.
4. Readable-but-unused: compare existing per-task behavior and matched 21B language cost without calling probe success functional use.

## 6. Learning Task And Permitted Supervision

P's probe input is the pooled native \(a\) vector and its relation family; target is direction of first relative to second referent. Fit labels alone train four family-specific binary classifiers; development labels select a shared regularization setting. N8 uses eight published category labels for a record-level classifier. PAWS scores a pair of separately encoded sentences by cosine similarity; optional pair-interaction classifier is secondary and cannot be called single-vector linear accessibility. Invalid labels, empty content masks, missing paired examples, or over-context inputs fail closed. No label, sample ID, metadata, or other model output enters the frozen backbone forward pass.

## 7. Model / Architecture And Frozen Variants

Three existing exact-21B checkpoints are `21b_dense`, `21b_sall_original`, and `21b_s7_reweighted` from the 0919 benchmark plan. All are eight-block hidden-size-1024 Qwen3-style models, native \(a\) taken from `blocks[i].attn.o`. Dense has no SAE; SALL has online sidecars at all eight blocks with width 30,000 and Top-K 32; S7 has one at code block 7, width 30,000 and Top-K 32. ## 8. Training Objective And Optimization

No backbone or SAE training is in scope. This is a probe optimization, not a change to the LM. ## 10. Primary Metric And Frozen Analysis Plan

For each human layer \(\ell\in\{4,8\}\), the estimand is SALL minus Dense `test_joint` relation-direction accuracy in native last-token \(a\). The observation unit is one sentence, but uncertainty unit is the entity pair group (40 test groups). Within each group, balance two directions and two test templates per family; then average four families equally and groups equally. Use the same bootstrap group indices for all models: 2,000 paired resamples, seed 20260920, 95% percentile interval. For an affirmative significance claim, perform group-level paired label-exchange tests for the two layers and Holm-correct their p-values to familywise 0.05. A positive point difference with interval excluding zero and adjusted p<0.05 is supporting for that layer; a negative interval excluding zero is evidence against an improvement; any interval crossing zero is insufficient, not equivalence. Both layers and both poolings are reported even if unfavorable. Mean P is a registered sensitivity, not a post-result replacement primary. Missing group member, failed probe convergence, or incomplete paired model artifact makes the corresponding contrast ineligible. Report full-sample results; outliers may only be added as labeled post-hoc sensitivity using one frozen exclusion list across models.

## 11. Secondary Metrics And Guards

Eight-layer pooled write norm, variance spectrum, between/within-class \(B\) and \(W\) and ratio, and standard plus U-corrected linear CKA locate structural changes. CKA uses matching `sample_id + input_ids_sha256`, float64 matrices, matched sample counts, 100 group-constrained permutations, first-PC sensitivity, and 256/512/1024 nested sizes where available; it does not act as an analysis gate. P single-factor holdouts, same-suffix/natural-name development diagnostics, token-bag and metadata baselines test surface explanations. N8 report fine eight-class, coarse four-class and within-domain pair diagnostics; PAWS reports cosine AUROC/AP and prevalence, both poolings. SAE observer diagnostics at available dictionaries include reconstruction error/fidelity, pre-TopK rank-32 versus rank-33 and tail distributions, positive-score counts, atom activation sparsity and combinations, and matched-capacity incremental probes for \(e\) beyond \(\hat a\). `Top-K=32` is not a claim of global 32-dimensional backbone semantics. Reuse 0919 per-task behavior with both gains and losses; evaluate fixed N8 test language NLL if eligibility and alignment permit, otherwise mark missing rather than hide adverse cost.
