# A15_08_05 对齐谱秩实验：结论摘要

**状态：** `AI_DRAFT_AWAITING_HUMAN_JUDGMENT`  
**注册裁定：** `METHOD_OBJECT_GAP`

## 这次只回答什么

在同一个 Qwen3-0.6B、同一批1,048,576个 DCLM token、同一中心化 covariance 与 \(r_{90}\) 规则下，比较 CAR、ZX 与我们的 \(R_U\)，判断此前“层间表征差高秩”与“我们的对象较低秩”的差别是否仍存在。

## 确定结果

| 对象 | 白话定义 | 层中位 \(r_{90}\) | 归一化 \(r_{90}\) |
| --- | --- | ---: | ---: |
| CAR | 相邻完整 Transformer block 输出之差 | 576 / 1024 | 56.25% |
| ZX | 相邻 Attention write 之差投到 TRAIN 构造的500维末层参考空间 | 297 / 500 | 59.40% |
| \(R_U\) | 本层归一化更新中，旧状态无法被仿射岭回归预测的剩余 | 445.5 / 1024 | 43.51% |

三个结果从524,288到1,048,576 token 的变化都小于0.005，已稳定在注册的0.02阈值内。CAR 相对 \(R_U\) 宽13.77个百分点，ZX 相对 \(R_U\) 宽14.98个百分点，因此对象构造带来的秩差异是真实且稳定的。

**对“我们的模型是否出现层间表征差高秩”的回答是：出现了。** CAR 要约576个方向、ZX 要约297/500个方向才能解释90%方差，不能描述成一个很小的公共低秩子空间。\(R_U\) 更集中，但也要约446个方向，因而只是“相对较低”，不是“极低秩”。

## 哪一种最奇异

“最奇异”有两种口径：

1. **看典型层的整体集中程度：\(R_U\) 最集中。** 它的层中位 \(r_{90}/d=43.51\%\)，低于 CAR 和 ZX。这说明线性去掉旧状态可预测的共同运动后，剩余变化的能量更集中。
2. **看单个最极端的层：CAR 的目标 block 3 最奇异。** 它只需一个方向就解释90%方差，第一方向实际占99.88%。去掉每段序列的第一个 token 后第一方向仍占90.95%，所以序列边界只会放大这个现象，不能完全解释它。

这个局部秩一异常更像“一批特别大的、方向高度一致的更新压过了其他 token 的变化”，而不是“模型把所有新增语义压进了一个方向”。CAR 去除边界 token 前后的层中位 \(r_{90}\) 为576与575，总体高秩判断不受它影响。

## 直观认识更新

- 小样本会把谱看得过窄：三种方法的层中位 \(r_{90}/d\) 从2,048 token 时的33.2%、38.0%、26.2%，升到百万 token 时的56.3%、59.4%、43.5%。
- 完整 block 差和 Attention 相邻差混合了很多 token 相关的计算变化，因此总体宽谱；投到一个公共500维空间并不会自动让它低秩。
- \(R_U\) 去掉了旧状态能线性解释的共享变化，所以谱更集中；但几何上仍有数百个活跃方向。
- 各层曲线起伏明显，没有观察到“越深越高秩”的单调规律。
- 协方差高秩不等于功能高秩。它只说明自然 token 上的变化分散，不能说明每个方向都对细粒度分类或 Router 有用。

## 建议的白话汇报

> 我们把模型、token 数和 \(r_{90}\) 的算法完全对齐后，确实复现了学长说的层间差高秩：完整 block 的层间差通常需要一半以上的方向，投到500维公共参考空间后也仍要接近300个方向。我们的 \(R_U\) 因为先去掉旧状态能线性预测的部分，谱会更集中，但也不是几十维就能概括。换句话说，之前看起来更低秩，一部分来自 token 太少，另一部分来自我们分析的是经过“去旧”的不同对象。最极端的是 CAR 第3层差分几乎被一个方向主导，但这更像大幅同向更新或离群效应，不能解释成一个语义方向。下一步如果要用于路由，仍要单独检验哪些方向保留任务收益。

## 边界

本结果只支持“几何谱宽”和“对象口径影响秩”。它不证明高秩方向是新增语义，不证明 \(R_U\) 是非线性意义上的新信息，也不证明任何子空间能改善 Router。
