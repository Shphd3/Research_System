# A15_08_05 Qwen3-0.6B CAR / ZX / \(R_U\) 对齐谱秩实验详细记录

**记录状态：** `AI_DRAFT_AWAITING_HUMAN_JUDGMENT`  
**实验日期：** 2026-08-18  
**注册裁定：** `METHOD_OBJECT_GAP`

## 1. 问题与证据边界

本实验只检验：在模型、评价 token、中心化方式与 \(r_{90}\) 估计器完全一致时，CAR、ZX 和 \(R_U\) 的几何秩是否仍有材料性差异。这里的秩是 token 总体 covariance 的方差维数，不是语义维数、功能维数或 Router 决策维数。

不能由本实验声称：方向表达了新增语义；高秩方向都被模型功能使用；\(R_U\) 是非线性意义的新信息；某个低维投影足以路由。

## 2. 对象与对齐设置

模型为本地 Qwen3-0.6B，共28个 block、hidden width 1024。数据来自同一 DCLM token 文件，序列长度2048。TRAIN、DEVELOPMENT 各131,072 token，EVALUATION 1,048,576 token；三者 hash 不同且不重叠。

- CAR：\(D_l^{CAR}=H_{l+1}-H_l\)，即相邻完整 block 输出之差，目标 blocks 2--28，维数1024。
- ZX：\(D_l^{ZX}=Q_{500}^{\top}(a_{l+1}-a_l)\)，即相邻 Attention write 之差投到 TRAIN 最后 block 状态 PCA 的前500维，目标 blocks 2--28。
- \(R_U\)：\(U_l-\widehat{\mathbb E}_{lin}[U_l\mid X_l]\)，其中 \(X_l=N_l(h_l)\)、\(U_l=N_l(h_l+a_l)-N_l(h_l)\)。预测器只在 TRAIN 拟合，正则只在 DEVELOPMENT 选择，维数1024，blocks 1--28。

所有 EVALUATION 矩阵按 token 中心化，计算 covariance 完整特征值。\(r_{90}\) 是累计90%方差所需的最少方向数；跨不同维数的主比较为 \(r_{90}/d_{object}\)。

## 3. 执行与有效性检查

- 环境：NVIDIA H100 80GB HBM3 MIG 3g.40gb；PyTorch 2.5.1+cu121；固定 seed 8180501。
- hook 覆盖28层；原生 MLP 输入身份检查最大相对误差0。
- ZX 基形状1024×500，正交误差0.0002129，投影能量相对误差0.00001638，均通过 \(5\times10^{-4}\) 阈值。
- TRAIN/DEVELOPMENT 每层统计均为131,072 token；EVALUATION 为1,048,576 token。
- 产生492行谱指标和492条完整谱记录；三个条件层数分别为27、27、28。
- 聚焦测试12项全部通过，代码编译检查通过。

没有改变注册的对象、token、阈值或主分析。注册的边界 norm guard 触发了 CAR 异常诊断；该诊断只分解异常来源，不更改主总体或裁定资格。

## 4. 收敛结果

| 条件 | 524,288 token 中位 \(r_{90}/d\) | 1,048,576 token | 绝对变化 | 判定 |
| --- | ---: | ---: | ---: | --- |
| CAR | 0.55762 | 0.56250 | 0.00488 | 收敛 |
| ZX | 0.59000 | 0.59400 | 0.00400 | 收敛 |
| \(R_U\) | 0.43262 | 0.43506 | 0.00244 | 收敛 |

三者均远低于预注册0.02阈值，因此百万 token 的主比较不再受明显样本秩增长支配。

## 5. 主结果

| 条件 | 维数 | 层数 | 中位 \(r_{90}\) | 范围 | 中位 \(r_{90}/d\) | 中位 effective-rank / d |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| CAR | 1024 | 27 | 576 | 1--663 | 0.5625 | 0.4993 |
| ZX | 500 | 27 | 297 | 264--331 | 0.5940 | 0.5032 |
| \(R_U\) | 1024 | 28 | 445.5 | 335--531 | 0.4351 | 0.4323 |

在目标 blocks 2--28 配对后：

- CAR-\(R_U\) 中位差为+0.13770；25/27层为正。
- ZX-\(R_U\) 中位差为+0.14981；27/27层为正。

两组差的绝对值都超过注册的0.10阈值，且全部收敛与有效性 guard 通过，因此注册裁定为 `METHOD_OBJECT_GAP`。

## 6. 高秩问题的回答

对 CAR 与 ZX，答案是明确的“出现高/宽秩”：CAR 通常需要576/1024个方向，ZX 即使已经限制在500维参考空间里仍通常需要297个方向。这不是几十维就能覆盖的单一公共变化空间。

\(R_U\) 比二者集中约14--15个百分点，说明去除旧状态可线性预测的更新确实改变了谱。但 \(R_U\) 的典型层仍需约446/1024个方向，所以当前证据只能称其“相对更低秩”，不能称为“绝对低秩”或“小秩语义空间”。

## 7. 哪个对象最奇异，以及两个口径

### 7.1 典型层的谱集中度

按层中位 \(r_{90}/d\)，\(R_U\) 最集中：0.4351，低于 CAR 的0.5625与 ZX 的0.5940。直观上，旧状态能够仿射线性预测的共同变化被减去后，剩余更新分布在更少的方向中。

### 7.2 单层极端奇异性

CAR 目标 block 3 是最极端的单层谱：\(r_{90}=1\)，top-1 方差份额0.998824。目标 block 28 次之，\(r_{90}=263\)、top-1份额约0.4674。

按协议补做的边界诊断结果：

| CAR 人口 | 层中位 \(r_{90}\) | block 3 | block 28 |
| --- | ---: | ---: | ---: |
| 全部位置 | 576 | 1 | 263 |
| 排除每段 position 0 | 575 | 1 | 384 |
| 仅 position 0 | 81 | 1 | 7 |

block 3 在去除 position 0 后 top-1份额仍为0.909529，说明序列边界会放大异常，但不能完全造成异常。更稳妥的解释是：这一层存在少量幅值远大或方向高度一致的全局/离群更新，使 covariance 被单方向支配。它不等价于“新增语义只有一维”。总体 CAR 中位从576到575几乎不变，因此高秩结论并非边界 token 的假象。

## 8. token 数为什么改变结论

层中位 \(r_{90}/d\) 在2,048 token 时分别为 CAR 0.332、ZX 0.380、\(R_U\) 0.262；百万 token 后升至0.5625、0.594和0.4351。2,048个 token 虽然在数值上不小于对象维数，但并未充分覆盖自然文本中稀有、异质的变化方向；随着样本扩大，更多小能量方向获得稳定估计，累计90%方差所需方向数继续增长。

这解释了此前“我们的结果更低秩”的一部分：小样本与较低累计阈值会压低表观秩；同时我们的 \(R_U\) 与学长的完整 block 差/参考空间 Attention 差本来就是不同对象。

## 9. 逐层结构

CAR 除 blocks 3与28外大多位于约0.47--0.65；ZX 位于0.528--0.662；\(R_U\) 位于0.327--0.519。三条曲线都有层间起伏，没有随层深单调上升的模式。因此本实验不支持“越深，层间差的几何秩越高”。

## 10. 自然语言解释与路由关系

CAR 把 Attention、MLP、residual 传播以及尺度变化混在一个完整 block 差里，宽谱意味着不同 token 的完整计算运动分散在许多方向。ZX 表明，即便强制在同一个500维参考坐标里比较，Attention 层间差也没有收缩为少数方向。\(R_U\) 更窄，意味着可由旧状态线性延续的运动占据了部分宽谱，去掉它后剩余更集中。

但 Router 关心的是“哪些坐标能改善专家选择”，不是“哪些坐标有方差”。高方差可能是格式、位置、尺度或其他 nuisance；低方差方向也可能对任务很关键。因此后续若冻结 \(R_U\)，应检验投影维数与细粒度任务增益/专家效用的保持曲线，而不能直接按 PCA 方差宣布功能低秩。

## 11. 认识更新

1. 同模型对齐后，CAR/ZX 的高秩现象复现，排除了“只因为学长使用0.6B模型”的解释。
2. token 扩充是必要的；2,048 token 对三种对象都系统性低估 \(r_{90}\)。
3. 对象定义同样关键；\(R_U\) 比 CAR/ZX 稳定地更集中，但并非极低秩。
4. CAR 的局部秩一谱是异常主导的几何现象，不是可直接使用的语义子空间。
5. 几何秩与功能秩仍需分开。当前实验完成的是前者的口径对齐，不是 Router 证据。

## 12. 下一决策

研究者需要闭卷判断是否接受以下更新：冻结 \(R_U\) 作为后续功能分析的候选对象，因为它明确执行“去除旧状态线性可预测部分”；但不预设其功能低秩。若接受，下一实验只需比较完整 \(R_U\) 与不同维数投影在严格独立数据上的细粒度增益保持率，并与同维随机/尾部/监督子空间做匹配预算对照。
