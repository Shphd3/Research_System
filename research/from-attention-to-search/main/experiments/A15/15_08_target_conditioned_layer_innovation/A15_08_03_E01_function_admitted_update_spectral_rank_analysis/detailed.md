## 0. Quick Recap
目的：比较不同层同一 token 的候选新增更新，分别检验功能新增、参数谱位置、表征秩、跨层 CKA、低维功能保留与聚类。
假设：深层更能区分细粒度语义；更新表征可由低秩空间稳定抓取。
实验思路：先由实验一的 same-X 匹配对照裁定功能，再对所有层的 TRAIN 拟合几何对象并原样迁移到 DEVELOPMENT/CONFIRMATION。
结论：功能新增只在 24、28 层通过；严格表征低秩无层通过；跨深度功能差不显著；Mean Response 谱后移但 Rank Consensus 反向。
证据：实验一全层同时区间、512 个坐标打乱秩零假设、64 个 Haar 子空间、三切分 CKA、PCA/Haar 功能保留和聚类对照。

# A15_08_03_E01 Detailed Report

## 1. 核心问题

同一 token 在不同 block 的旧状态不可线性预测更新，是否同时呈现更深的功能增益、参数谱后移和稳定低秩；这些性质是否为同一件事。

## 2. 功能锚点

实验一 verdict 为 `CONDITIONAL_FINE_ADDED_ACCESSIBILITY_FOUND`，全层 familywise 同时校正后的 \(\mathcal{L}^+=[24, 28]\)。因此只有 24、28 层允许使用“新增细粒度可访问性”语言，其他层几何仍完整展示但不赋予功能含义。

## 3. 跨层功能与公共参数谱

- \(\Delta T=-0.0046\)，同时区间 [-0.0260, 0.0169]：早/深中位差未确定。
- Mean Response \(\Delta C=0.0285\)，同时区间 [0.0218, 0.0352]：后移。
- Rank Consensus \(\Delta C=-0.0397\)，同时区间 [-0.0471, -0.0322]：反向。

Typed outcome：`INSUFFICIENT_BASIS_SENSITIVE`。这表明公共参数集上的“后移”不是基无关结论。

本层 MLP 参数谱也不是平滑后移：TRAIN 的主能量带在 block 2–25 基本保持 F1，block 26 首次跳到 F16，block 32–36 多落在 F15/F16；功能准入的 block 24、28 在 TRAIN 都仍以 F1 为主。CONFIRMATION 的 block 25 已转为 F16，说明最大带还具有切分敏感性。因此参数谱位置不能替代功能判据。

补充的完整公共谱曲线使用 CONFIRMATION 上已冻结的逐方向方差，先对每层归一化为 \(p_{\ell j}=e_{\ell j}/\sum_k e_{\ell k}\)，再画方差密度 \(4096p_{\ell j}\)。展示层为 [2, 6, 10, 14, 18, 24, 25, 28, 32, 36]，同时给出 Mean Response 与 Rank Consensus；129-rank 移动平均只改善可读性。它回答“更新方差形状分布在哪里”，不是 \(R_U\) 的奇异值曲线，也不重新裁定新增信息或谱后移。

## 4. 表征低秩

严格合取通过层为 无。真实 \(r_{80}\) 普遍小于坐标独立打乱的 q05，说明更新维度间有联合结构；但多数层 \(r_{80}/632\) 高于 10%，且 TRAIN PCA 的 \(r_{80}\) 在新模板 DEVELOPMENT/CONFIRMATION 上通常保留不足 75% 方差。因此“训练云可压缩”不能升级为“稳定低秩表征”。

## 5. CKA 与聚类

完整 35×35 CKA 在 TRAIN、DEVELOPMENT、CONFIRMATION 均已保存，并为相邻层提供 2,000 次配对重采样。确认集相邻层 CKA 中位数约 0.861；23→24 为 0.926，27→28 为 0.739，28→29 为 0.682。质量复核发现，点估计落在有放回 percentile 区间之外的相邻对数量为 TRAIN/DEVELOPMENT/CONFIRMATION=34/1/1；这是重复抽中同一 token 会抬高高维 Gram 相似度的校准警告。因此完整点矩阵只作描述，不用该区间认定层间断点。CKA 只回答 token–token 关系是否相似，并不会自动在功能新增层形成断点。第 24/28 层 PCA 聚类确认 ARI 分别为 0.184/0.251，均未超过对应 Haar ARI q95，且聚类稳定性较低；不能替代功能裁定。

## 6. 低维功能保留

注册秩为 [1, 2, 4, 8, 16, 32, 64, 128, 256, 512]，每个秩与 64 个等秩 Haar 子空间比较，并复用 bit-identical base logits。功能新增层中通过完整判据的层为 [24, 28]，两层最小通过秩均为 256；1–128 维均未通过全层×秩同时下界。256 维是隐藏宽度的 6.25%，但占可识别上限 632 的 40.5%，所以应表述为“功能可压缩到 256 维”，而不是“极低秩”。该结果与第 4 节“协方差低秩”是两个不同结论。

## 7. 认识更新

1. “越深越有新增信息”不成立为整体趋势；新增可访问性是局部层现象。
2. “谱后移”在 Mean Response 上成立、在 Rank Consensus 上反向，必须标注 basis-sensitive。
3. 更新云明显非独立噪声，但没有通过稳定表征低秩合取。
4. 功能、谱几何、PCA 秩、CKA 与聚类必须分别报告；任何一个几何量都不能替代 same-X 功能对照。
