# A15_08_07_E03 详细记录

## 1. 本轮为什么重跑

E02 与 0817 有两个统计错位：其一，错配 \(R_U\) 使用“目标细类对应唯一不同来源细类”的类别级置换，来源细类可反推出目标标签；其二，H-ADMIT 两个主对比与约 200 个秩、方法、随机和 rival 对比放进同一个 max-\(t\) 家族。E03 在打开新确认集前修正为：

1. 同 split、同粗类内的样本级双射；每个目标细类接收八种来源细类的次数差不超过 1，不强制来源细类不同；
2. H-ADMIT 只含 block 24、28 两个 full-minus-null 对比；功能维数曲线使用另一统计族。

两对比 H-ADMIT 临界值为 2.044，探索性曲线家族临界值为 5.301。E02 结果未被覆盖。

## 2. 数据与对象

- 数据为 8 个粗类 × 每粗类 8 个细类；TRAIN、DEVELOPMENT、CONFIRMATION-v3 各 640 条，每个粗类—细类单元 10 条。
- 每条文本用若干主题事实描述一个学科子领域，以 `Classification:` 结尾。
- v3 每单元含 5 条二事实和其补集的 5 条四事实表达；相对旧 1,920 条和已打开 v2 的事实子集重合为 0，模板、文本、record ID 与标签泄漏守卫均通过。
- 模型为冻结 Qwen3-8B；正式功能层为 block 24、28。10 层解释性诊断固定为 2、6、10、14、18、22、24、28、32、36。
- \(R_U=U-\widehat{\mathbb E}_{lin}[U\mid X]\) 只删除由 \(X\) 线性预测的部分，不排除非线性重编码。

## 3. 实验一：图中方案是否正确

图中方案是正确的，关键是三项必须合取：

1. 每条样本先减自己的粗类 TRAIN 均值；同粗类和跨粗类任务都固定 8 类×10 条；
2. 同粗类谱必须更窄；局部方向要在重复切分中复现，且不同粗类方向更不相同；
3. 八个局部子空间合并后的有效维数必须超过“同一粗类反复重采样八次”的 null。

这里“谱宽”指归一化方差谱下降慢，达到 90% 方差要更多方向。它不是分类功能维数。

### 3.1 正式裁定

- B24：谱宽差 0.0127、同时 LCB -0.0253；方向差 0.0639、LCB 0.0346；union 48.84 > null q95 22.36。
- B28：谱宽差 0.0443、同时 LCB -0.0063；方向差 0.0933、LCB 0.0480；union 48.68 > null q95 25.01。

两层都只有 union 通过，所以正式结论为 `GEOMETRY_INSUFFICIENT`。

### 3.2 10 层能量谱

左右两侧都固定 80 行和最多 79 个方向，因此可以直接比较。浅层单粗类与跨粗类曲线几乎重合；深层跨粗类尾部通常更高、更平。中位 \(r_{90}\) 的例子：

- B24：单粗类 53，跨粗类 54；
- B28：单粗类 45.5，跨粗类 49；
- B32：单粗类 45.5，跨粗类 48；
- B36：单粗类 46，跨粗类 48。

这是“深层出现更明显宽化趋势”的描述性证据，不替代 B24/B28 的正式 bootstrap 裁定。

### 3.3 PCA 头部与不同谱段

用每个细类 5/5 半切、20 个冻结 seed，比较同粗类重复 PCA 子空间与不同粗类 PCA 子空间：

| 层 | 谱段 | 同粗类复现 | 跨粗类重合 | 差值 |
| --- | --- | ---: | ---: | ---: |
| B24 | 1–4 | 0.166 | 0.028 | 0.138 |
| B24 | 5–12 | 0.074 | 0.037 | 0.038 |
| B24 | 13–24 | 0.050 | 0.033 | 0.017 |
| B24 | 25–32 | 0.024 | 0.015 | 0.009 |
| B28 | 1–4 | 0.304 | 0.028 | 0.276 |
| B28 | 5–12 | 0.137 | 0.042 | 0.095 |
| B28 | 13–24 | 0.085 | 0.045 | 0.040 |
| B28 | 25–32 | 0.038 | 0.022 | 0.016 |

差别主要在 PCA 头部；尾部的“跨粗类不重合”同时伴随很低的同粗类复现，因此更多像小样本/弱能量方向，而不是可靠的粗类特异信息。

### 3.4 对用户图片结论的核对

| 图片中的认识 | 本实验是否一致 | 原因 |
| --- | --- | --- |
| 单个 domain 方差集中在低秩子空间 | 仅部分一致 | B28 比较集中，但 B24 及浅层并未正式显示单粗类显著更窄 |
| 不同 domain 子空间不同 | PCA 头部支持；正式监督条件不足 | PCA 头部复现−跨域差明显，但注册的监督方向点阈值未同时通过 |
| 多个局部子空间解释整体高秩 | 证据不足 | union 增长通过，但“局部窄且稳定”两项没有合取通过 |
| 每个全局方向主要对应一个 domain | 大体不一致 | 前 8 个全局方向有效贡献粗类数为 B24 7.14/8、B28 6.73/8；多数方向是共享混合 |
| domain 标签在方向轴上不连续 | 现象可能存在，但不是核心困难 | PCA 方向有旋转/符号/近简并不唯一性；更应看子空间重合和贡献熵，而非逐方向硬贴标签 |

图片使用的是不同数据集和 layer 27 的 union spectrum，且没有同规模 null、重复切分稳定性和区间，因此其图本身不足以推出 a、b 两条结论。

## 4. 实验二：低维还能保留多少功能

### 4.1 完整 \(R_U\) 准入

| 层 | full gain | matched null | full−null | 两层同时 LCB |
| --- | ---: | ---: | ---: | ---: |
| B24 | 0.1361 | 0.0188 | 0.1173 | 0.0890 |
| B28 | 0.0715 | 0.0320 | 0.0394 | 0.0215 |

两层均通过。因此此前正式 80%/90% 为 NA 的原因已被定位为 E02 对照与校正口径错位，而不是“完整 \(R_U\) 没有正收益”。

### 4.2 维数结论

- **PCA 头部：**B24 点估计在 256 维达到 80%/90%，区间确认在 512；B28 点估计分别为 32/128，区间确认均为 512。确认维数处没有胜过同维 Haar 随机 q95，因此类型化为“高维可保留，但高方差方向没有独特优势”。
- **PCA 尾部：**grid 到 512 仍未达到 80%/90%。
- **监督降秩岭：**两层在 grid 点 8 均确认达到 80%/90%，且胜过随机子空间和标签置乱 RRR。由于 8-way centered 输出最多有 7 个独立对比，正确表述是“监督线性细分类修正可由至多 7 个判别坐标表达”；不能写成“\(R_U\) 是 8 维”。

### 4.3 补充诊断：监督功能子空间位于哪些 PCA 谱段

![监督功能子空间与 PCA 谱段的方向重合](figures/figure_8_functional_subspace_spectral_overlap.png)

- **性质：**这是正式结果之后增加的 TRAIN-only 解释性诊断，不改变注册的功能维数 verdict。
- **对象：**对每个粗类，取监督降秩岭系数矩阵，先删除所有类别 logits 共同变化的方向，再正交化为至多 7 维的判别输入子空间。
- **比较：**把该子空间投到同一 TRAIN 标准化 \(R_U\) 的 639 维可识别 PCA 基中；谱段之间只比较投影方向，不使用奇异值作为权重。
- **归一化：**颜色为 \(\log_2\) 方向重合富集倍数。0 表示与“639 维可识别空间内的同秩 Haar 随机子空间”相当；星号表示超过 2,048 次冻结随机抽样的 q95。单元格数字是该谱段覆盖的监督子空间比例。
- **直接结果：**B24 的 PCA 1–32 段中位覆盖 2.86%，257–639 段覆盖 68.05%；B28 分别为 2.26% 和 69.73%。最末 513–639 段的中位 Haar 富集为 B24 1.27、B28 1.41，两个 block 的 8/8 粗类都超过 q95。
- **允许结论：**当前细分类监督方向明显向 PCA 中尾部和尾部偏移，不能由少数最大方差方向等价替代。
- **不能推出：**方向重合不等于单独使用某个尾段便能恢复同样的 held-out 功能，也不证明模型原生 Router 使用这些方向；后者仍由功能曲线和未来 expert-utility 实验裁定。
- **数据链：**TRAIN RRR state + TRAIN `pca_basis.npz` → 去 common-logit 后的系数列空间 → PCA 分段投影 → 2,048-draw 同秩 Haar 校正 → [机器表](tables/functional_subspace_spectral_overlap.csv)。

## 5. 为什么最大方差方向不是最优分发方向

PCA 解的是“用同样维数重构 \(R_U\) 时丢失的平方误差最小”；Router 要解的是“这个 token 交给哪个 expert 会带来更高效用”。大方差可能来自共享格式、表述长度或多粗类共同变化，对 expert 选择没有区分力。当前实验中，全局 PCA 方向是多粗类混合，PCA 到 512 维才稳定保留增益，且没有胜过随机；监督方向却在至多 7 个判别坐标内完成任务。这正说明“方差大”与“分类/专家效用大”不是同一目标。

## 6. 更直观的后续分析

1. **leave-one-domain-out 宽度变化：**每次删掉一个粗类，重画各谱段和 \(r_{90}\)；直接回答“哪个粗类让谱变宽”。
2. **跨粗类子空间迁移矩阵：**在粗类 A 学 PCA/监督子空间，在粗类 B 测方差保留和功能增益；对角高、非对角低才是真正局部专属。
3. **功能加权谱段图：**对头、肩、中、尾每段分别测 CE 增益，不只看方差；这一步才能直接连接 Router 输入方向。
4. **expert-utility 相对效用矩阵：**Router 的监督目标应是每个 expert 相对 shared baseline 的 held-out utility，而不是 PCA 方向或粗类标签。
