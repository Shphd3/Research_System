# A15_08_07_E03 对齐重跑总结

状态：`ELIGIBLE`。预确认作业 `pt-fc1joh77`、正式确认作业 `pt-eo99x2t0`、10 层解释性作业 `pt-5ygnvipw` 均为 `SUCCEEDED`。

## 一句话结论

实验一没有证明“整体宽谱就是多个窄而稳定的粗类内子空间简单拼接”：合并不同粗类的局部判别方向确实增秩，但单粗类谱显著更窄和监督方向稳定性没有同时达到预注册标准。实验二则确认，正确配对的完整 \(R_U\) 在 block 24、28 都有独立于 \(X\) 和错配样本的正增益；监督任务方向在冻结 grid 的 8 维点即可保留 80%/90% 增益，而无标签 PCA 需要 512 维才被区间确认，且没有胜过同维随机子空间。

## 白话认识

1. **谱宽不是“方向属于很多领域”。** 它只表示方差掉得慢、要更多 PCA 方向才能覆盖 90% 能量。单粗类和跨粗类的谱差在深层更明显，但只在 block 28 有较大的点估计，区间仍跨过 0。
2. **不同粗类最稳定的差别主要在 PCA 头部。** block 28 的前 1–4 个 PCA 方向，同粗类重复切分的重合度中位数为 0.304，不同粗类为 0.028；中尾部差距明显缩小。
3. **全局 PCA 方向通常是多个粗类的混合。** 前 8 个全局方向的有效贡献粗类数，block 24 为 7.14/8，block 28 为 6.73/8。因而不能把每条全局 PCA 方向直接贴成某一个粗类的标签。
4. **功能低维与表征低维不是一回事。** 监督降秩岭知道细类目标，所以能找出少量判别坐标；PCA只保方差，不保证这些方向对分类最有用。
5. **监督功能方向主要不在 PCA 头部。** 在 TRAIN 可识别的 639 维空间内，前 1–32 个 PCA 方向只覆盖监督判别子空间的中位 2.86%（B24）和 2.26%（B28），而 257–639 段覆盖 68.05% 和 69.73%；这是方向重合诊断，不等价于某个尾部投影已经通过功能检验。

## 对 Router 的直接更新

不能用“最大方差方向”直接分发。当前证据更支持：Router 先学习任务/专家效用方向，再把 PCA 当重构基线。监督方向可很低维，但全局高方差方向是多粗类混合，而且 PCA 与同维随机空间没有确认优势。

## 不能声称

- 不能声称每个粗类天然低秩；
- 不能声称整体宽谱已经被多个局部低秩子空间解释；
- 不能把 RRR 的 grid 点 8 写成 \(R_U\) 的内禀秩；
- 不能把本实验直接写成 Router、expert utility 或不遗忘已经提升。
