# 领域监督方向在共享 56 维空间中的位置

## 问题

八个领域分别学到的低秩监督映射，在一个共享 56 维空间中究竟使用哪一部分？它们只是几何上落在那里，还是对应的部分在 held-out 分类功能上也确实有用？

## 冻结设置

- 不重新提取表征，也不重新选择领域子空间或共享子空间。
- 每个领域复用原实验的 rank-8 监督 RRR 映射；共享空间复用由八个任务映射等权构造的前 56 个左奇异方向。
- 共享方向按 SVD 顺序记为 S1–S56，并按 8 维分成 S1–S8、S9–S16、…、S49–S56 七段。
- 几何量是领域监督系数矩阵投到每个共享方向后的 Frobenius 能量，占该领域监督映射总能量的比例。
- 功能量在冻结的 confirmation TEST 上计算。分别只保留一个 8 维段，或从完整 56 维修正中删除一个 8 维段，再比较交叉熵增益。

## 图 1：领域方向具体位于共享空间哪里

[查看领域到共享方向的几何热力图](figures/figure_11_domain_location_inside_shared56.png)

- 左列横轴是共享方向 S1–S56，纵轴是八个领域，颜色是单个共享方向承载的该领域监督映射能量百分比。
- 右列把相邻 8 个方向合并；每一行加起来是 100%。
- block 24/28 中，前 8 维平均分别承载 32.3%/31.5%，前 16 维累计约 54.7%/53.5%。因此不同领域都总体偏向共享 SVD 前部。
- 但精确峰值方向不同。例如 block 28 中，数学峰值是 S3，化学是 S1，生物是 S5，计算机科学是 S12，经济学是 S10。故“都偏共享前部”不等于“使用同一方向”。
- 共享 56 维覆盖每个领域监督映射的 99.81%–100.00%，说明该图确实在展示原有领域映射的位置，而不是只画了一个很小的残片。

## 图 2：这些位置是否真的承载 held-out 功能

[查看共享分段的 held-out 功能热力图](figures/figure_12_shared56_chunk_heldout_function.png)

- 上排：只保留横轴这一段后，还能保留完整共享 56 维增益的多少；越大表示这一段单独越能工作。
- 下排：从完整共享空间删掉这一段后损失多少完整增益；越大表示这一段越不可替代。
- 不同领域最重要的段不同。block 28 中，数学/化学/物理主要依赖 S1–S8；计算机科学/语言学主要依赖 S9–S16；生物/经济学/医学主要依赖 S17–S24。
- 任一 8 维段单独最多只保留 36% 左右完整增益；删除最关键段造成的最大损失约 37%。所以功能也不是集中在同一个公共 8 维核心中，而是分散在多个段中。
- 交叉熵是非线性的，因此七段的功能比例不能简单相加。热力图用于定位和比较，不把它解释成严格的 Shapley 分解。

## 图 3：要覆盖一个领域，需要共享空间的多长前缀

[查看累计覆盖曲线](figures/figure_13_domain_shared56_cumulative_coverage.png)

- 横轴是保留共享 SVD 的前多少维，纵轴是累计覆盖该领域监督映射能量的比例。
- block 24：达到 80% 需要 28–32 维，达到 90% 需要 37–42 维。
- block 28：达到 80% 需要 26–33 维，达到 90% 需要 38–43 维。
- 这说明即使各领域都偏前部，也仍需要一个较宽前缀才能覆盖任一领域的完整监督映射；共享空间更像多个局部空间的有序并集。

## 结论边界

当前结果支持：八个领域的监督方向在共享 SVD 排序下都有“前部偏置”，但精确方向及关键功能段因领域而异；共享 56 维主要是多个局部低秩方向的较宽并集，而不是一个所有领域共同使用的极小核心。

这里的 S1–S56 是监督任务映射构造出的共享 SVD 坐标，不是原始 \(R_U\) 的 PCA 谱段。因此该实验回答“领域方向在共享监督空间的哪部分”，不能直接替代“这些方向位于原始或领域去均值后的 \(R_U\) 频谱哪一段”。本分析属于冻结结果上的 post-hoc 诊断，不改写原注册结论。
