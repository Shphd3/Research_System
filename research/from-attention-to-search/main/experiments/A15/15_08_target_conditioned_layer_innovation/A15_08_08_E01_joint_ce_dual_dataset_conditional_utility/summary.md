# A15_08_08_E01 结果摘要

Status: `AI_DRAFT_AWAITING_HUMAN_CONFIRMATION`

## 问题

在同一层、同一父类或 domain 内，联合训练交叉熵分类头后，真实配对的
\(R_{U,\ell}\) 是否比“再复制一份 \(X_\ell\)”的双分支对照，在未见数据上提供额外的
细粒度线性可访问性？

这里训练的只是每层的线性 softmax 读出头；Qwen3-8B、\(X_\ell\)、\(R_{U,\ell}\)
和残差化模型全部冻结。

## 判据

主统计量为

\[
T_\ell=\operatorname{CE}(X_\ell+\text{duplicate-}X_\ell)
-\operatorname{CE}(X_\ell+R_{U,\ell}).
\]

\(T_\ell>0\) 表示真实更新分支降低了 held-out 交叉熵。每个数据集分别使用覆盖
block 2--36 的 simultaneous 95% 区间，并要求：

1. 区间下界大于 0；
2. same-\(X\) 恒等对照与单分支 \(X\) 数值一致；
3. 正确配对的收益超过 64 次组内错配 \(R_U\) 的 95% 分位数；
4. 所有入选解的梯度范数不超过 \(10^{-3}\)。

## 实验一：合成父类—子类数据

- 确认正增益：block **9、11、12、15、17、19、20、21、23、24、25、28**。
- 确认非正：block **7、14**。
- 其余 21 层未决，不能写成“没有新增信息”。
- 最强 CE 收益在 block 24：\(T_{24}=2.0391\) nats，simultaneous 95% CI
  \([1.8726,2.2056]\)；准确率由 31.25% 升至 56.25%。
- block 25：\(T_{25}=1.9200\) nats，CI \([1.7535,2.0865]\)；准确率由
  40.16% 升至 76.88%。
- block 28：\(T_{28}=0.4227\) nats，CI \([0.2562,0.5892]\)；准确率由
  78.28% 升至 90.16%。

因此，原来在 24、28 层观察到的结果在联合 CE 判据下仍然成立，但不是逐层单调
增加；浅层和中层也存在确认正增益，7、14 层甚至确认负增益。

## 实验二：CLINC150 真实意图数据

- 只有 block **9** 确认正增益：\(T_9=0.008758\) nats，simultaneous 95% CI
  \([0.003039,0.014476]\)。
- block 9 的准确率由 94.02% 升至 94.18%，仅增加 0.156 个百分点。因此证据主要
  是正确类别概率的小幅改善，不是大规模样本翻转。
- 其余 34 层全部未决；没有任何一层满足“确认非正”。
- block 24 和 28 分别为 \(-0.005284\) 与 \(-0.000245\) nats，区间都跨 0，均未决。

因此，在真实意图数据上没有复现“24、28 是稳定涌现层”；当前只支持第 9 层存在
很小但通过多重比较与错配对照的额外线性可访问性。

## 认识更新

1. 联合 CE 修复后，两个数据集都至少有一层出现严格正证据，说明此前的符号问题
   不能简单解释为“\(R_U\) 必然无用”。
2. 涌现层位置不是模型自身固定属性，而是“模型 × 数据表达 × 条件分类目标 × 线性
   读出”的联合属性。合成数据的模板和标签结构稳定，\(R_U\) 能形成跨 split 的强线性
   信号；CLINC 表达多样，而且旧状态准确率已约为 94%--98%，新增分支的边际空间很小。
3. CE 正收益不等于准确率必然提高。例如合成数据 block 11、12 的 CE 改善，但
   argmax 准确率点估计下降；它们首先证明概率读出的改善，而不是更多样本被判对。
4. 本实验只建立条件线性可访问性，不证明模型“理解”了意图，不证明 \(R_U\) 低秩，
   也不证明该空间可直接用于 Router。
