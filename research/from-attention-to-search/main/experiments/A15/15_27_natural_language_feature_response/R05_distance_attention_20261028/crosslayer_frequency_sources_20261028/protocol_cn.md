# 远近 Attention 来源的跨层实际 feature 贡献：冻结协议

状态：本轮用户明确授权全部缓存内计算。原 Focus/Anchor 的 R06 设计不改写；此处是用户激活的 R05 观察性补充，不能借旧 R06 的“无层扩展”限制否定本轮新授权。研究者机制接受与问题闭合仍为 Unknown。

问题：远高来源的低频贡献份额从前7个覆盖层到后7个覆盖层增加得是否更多，且是否超过中等 Attention 对照？竞争解释为一般位置分配、其他频率组减少、词面和绝对位置差异。对象是来源 token 的 A22 联合共享 z 及各层 decoder 重构贡献，不是14套独立激活。

只用原 R04/R05 40篇留出真实文本（数学、生物各20），原 Attention 配对、固定 DCLM 四频率组、所有16384坐标。主分层沿用旧分析的不同 token ID 且非标点层（stratum0）；其余三层只作完整性附表。近远主支持取距离档0、4共同 query/head；五档图取五档共同 query/head。窗口敏感性先要求原配对两端来源都在32:192，再求共同支持，不重匹配、不放宽规则。

贡献=z×训练空间decoder向量L2范数，不平方，不乘Attention。原模型空间另乘各层TRAIN_RMS。量A先除固定组成员数，未激活包含0。量B先每位置算组贡献范数和/四组总和，分母0记NA。按位置→head→query→文档等权；领域独立。两层统计空间不能混用。量B的层尺度在分子分母抵消，是代数恒等式，不是独立复现。

前7接口blocks1,3,...13，后7接口15,17,...27（0起点）。每文档先计算低频份额的后半均值−前半均值。主量1=高组远−近的上述变化；主量2=主量1−中组对应变化。两域四项主检验统一BH校正；5000次文档配对bootstrap、19999次双侧signflip（假设文档差值零假设下符号对称），种子见config。少于10篇有效文档不计算推断。逐层和五档曲线只描述，不增加逐层p值。窗口敏感性不扩充主检验家族，不以其替换主结果。
