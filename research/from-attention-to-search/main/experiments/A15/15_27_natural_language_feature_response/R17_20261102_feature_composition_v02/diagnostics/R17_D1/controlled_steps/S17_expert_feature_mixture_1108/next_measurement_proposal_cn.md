# 唯一下一步建议：既有自然文本中的普通正文位置

状态：AI_PROPOSAL / NOT RUN。当前旧缓存CPU分析不受此审批影响；本文件不授权新位置或模型前向。

目的：区分“末尾读取标点造成的低路由多样性”与“普通正文也缺乏激活结构对应的专家选择”。保持同模型、同层、同SAE和原load_bias，不训练或干预。只先解决路由测量支持域，不把相似性准则直接作为训练目标。

| 项目 | 拟议固定配置 |
| --- | --- |
| 已有来源 | S14的`data/reference_general.jsonl`，实际6000条DCLM记录；每条保存原文前128token、原source_row与normalized_sha256。当前文件存在，约10.8MB；无需下载 |
| 来源与权限 | 既有项目内部分析缓存，不外发。来源元数据可追踪到DCLM holdout；具体许可字段未在已读记录中核实，批准后先核对原manifest，不能补造许可。无法核对则暂停该依赖 |
| 文档与位置预算 | 去重后768文档：DEV64、评估192、独立频率参考512；每文档在原正文token索引32–127内按固定种子均匀无放回取2个位置，共1536观测。768次文档前向；先DEV64，之后评估与参考 |
| 文档隔离 | 用normalized文本/sha与近重复簇隔离三个集合，固定排序/种子2026110818；至少768合格文档，不足则报告，不换来源补齐。该语料旧文本已用于参考频率，新路由响应未看过，不称新语义盲确认 |
| 采样原则 | 保留自然抽样的expert负载，不挑路由变化大、也不为均衡expert换token。正文常规位置不附Description后缀；按实际token类型、绝对位置/可见上下文长度与来源做分层报告，保留原总体权重 |
| feature定义 | DEV只按激活出现与支持筛选少量坐标/搭配，不能看路由选。自然文本没有可靠粗细类标签，所以只做频率、激活相似和富集，不套旧类共享角色或语义名字 |
| 频率 | 在512隔离参考文档的同采样位置规则上估计，分母1024位置；旧末冒号频率只作外部描述，不替代该位置频率 |
| 最低支持 | 每成员活跃/未活跃均≥12位置且≥8文档；expert入选/未入选同样检查；近乎全选/极少入选仍标不足。两个位置按文档/近重复簇聚类，不能算独立文档 |
| 质量与停止 | 先核验token/hook/实际路由、有限值、Top32、重建误差与重建路由敏感性。DEV若无expert具有足够入选/未入选支持，不因扩大样本或换token强行制造对照，报告当前样本不足 |
| 资源 | 获批后使用仍可用的既有本机H100 MIG，FP32、batch≤16、显存≤12GiB、总前向≤600秒；按DEV实测预算决定是否能在上限内完成，不申请或提交新GPU作业，超限停留已完成部分 |
| 输出与裁定 | 三集合/位置清单预响应冻结，频率和富集全表、支持/失败、独立复算。若普通正文有可比较的路由，再判断相似激活是否对应分发；若仍无对照，就维持测量不足 |

这是一项新位置测量建议，不是功能干预或续训。是否采纳该方案及相似性准则的科学地位，由研究者确认。
