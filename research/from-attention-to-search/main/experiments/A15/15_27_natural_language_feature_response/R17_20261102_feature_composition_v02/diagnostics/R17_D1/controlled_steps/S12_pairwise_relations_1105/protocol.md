## Binary relation metric and null

For each edge/category, save counts n11,n10,n01,n00 (denominator32 or64families), marginal proportions, n11/N, P(j|i) and P(i|j). Natural-log odds ratio L=log[(n11+.5)(n00+.5)/((n10+.5)(n01+.5))]. Smoothing is an estimator convention, never evidence from zero cells. Primary category contrast Delta=L_B-L_A. A marginal difference in coactivation n11/N alone is not an interaction contrast.

Null: independently within site,split,wording,category, Curveball row trades on the FULL N by30000 binary matrix; not just selected nodes. Each trade retains common entries and uniformly repartitions exclusive entries between two equal-length rows. This exactly preserves every row32, every full-dictionary feature count and structural zeros/ones while changing within-row cooccurrence. It does not preserve cross-category family coupling; family bootstrap addresses paired sampling uncertainty, not all template confounding. This null asks whether within-class pairings and their class contrast are surprising relative to exchangeable fixed-margin tables. It is not a semantic randomization experiment.

Four independently seeded chains,500burn sweeps,256retained draws/chain,20sweeps between draws. One sweep is ceil(N/2)random row-pair trades. Every retained snapshot checks row size, unique IDs, exact full-column counts. Save original-edge retention, stationary expected retention sum(colcount^2)/(N^2*32), locked always-active columns, changed proposals, moved edges and unique states. For all selected edge metrics report split-Rhat and conservative positive-sequence ESS; degenerate null is not evidence of good mixing. If Rhat>1.05 or ESS<200, perform one preauthorized extended run (burn2000,thin80,same1024draws), preserving original. If still inadequate, mark affected inference insufficient. Mixing diagnostics are finite diagnostics, not proof of uniformity.
