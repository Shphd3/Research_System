# S13共享结构补充：中文口径

本轮已获用户授权，仅复用S13和必要旧S11缓存，属于事后探索。英文完整规则及代码在新集合结果前冻结；没有新数据、前向、训练、干预或交互拟合。研究者科学接受Unknown。

- 数据：S13确认48家族、16场景簇，开发24家族、8簇；8粗类16细类、4措辞、两独立Top32字典。
- 固定粗参照：动物/交通、水果/家具、衣物/乐器、花/餐用器具。C为粗类交集，F为同父细类交集；R=C∩F、L=C\F、E=F\C。逐家族记录数量、R/C、E/F和R/F，空组频率缺失。
- 父类P与两细类A/B另拆PAB、AB_only、PA_only、PB_only、P_only、A_only、B_only七互斥区域；占比使用三方并集或该侧32个成员，不能混用粗/细交集分母。
- 频率：独立Q6000题干和G6000 DCLM，各末冒号Top32正激活比例；连续频率主分析。辅助高中低来自各参考支持≥5次字典成员频率三分位；未观察、支持不足单列。
- 每区域记录原始z、完整Top32L2归一化q、频率均值和线性四分位数；先家族再簇等权。分位数的汇总是家庭内分位数的簇均值，不是池化事件分位数。
- 不确定性：固定参考频率，2000次整16场景簇重采样，种子2026110613；不替代原S13参考/场景联合区间，不新增显著性筛选。
- 稳定标签：出现率≥.75且≥.75场景簇内至少2/3家族激活。跨类候选需≥4父类和≥4个双细类域稳定；组内限定候选需本域双细类稳定、其他14细类平均≤.25、至多1其他域共激活≥.5。细类出现率候选需一侧≥.75另一≤.25、差≥.5且≥.75开发簇同方向。强度候选需共同覆盖稳定、原始与归一化差同号，≥.75共同激活家族及开发簇同方向。
- 候选仅从复用DEV显式选择，确认不替换失败ID；所有数据已讨论，不能称新盲确认。各字典独立。新旧措辞同ID复查亦是事后描述。
- 反例保留：首家族、中位、最低保留域及最小动物频率差案例分别注明选法。隐式仅原行为合格条件解释语义。
