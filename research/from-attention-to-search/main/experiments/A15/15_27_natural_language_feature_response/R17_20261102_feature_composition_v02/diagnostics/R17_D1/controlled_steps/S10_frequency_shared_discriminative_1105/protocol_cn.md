# S10：共同与区分 feature 在独立激活频率上的分布

当前用户已授权本轮离线分析和必要的有限 CPU 前向；无需再次确认。操作定义由 AI 在新结果前固定，科研接受与问题关闭仍 Unknown。精确协议见 protocol.md，机读配置与哈希见 frozen_plan.json、evidence/protocol_freeze.json；后续修订只追加 amendments.md。

目的：区分“本来常出现，所以共享”和“在特定类别关系中稳定共享／区分”。检验 H1（跨大类共享偏高频、同父细类还共享较低频）、H2（细类区分向较低频延伸）、H3（成员更替、相同成员强度、超边际联合结构是三个不同对象）。不预设方向直觉成立。

沿用 Qwen3-0.6B Base 和两个各30000维的原生 Top32 SAE。Attention 为末块27的 o_proj 输出；MLP 输入为末块27的实际 mlp 输入，二者分别统计。统一在末尾换行 Description: 的冒号读取。原 S06 的384行原文／全稀疏 z 不改；F01–F08只能用于新名单选择，F09–F16的新统计是事后探索。本轮另外冻结 N01–N16 共384条，包含6类和4措辞；其中原3措辞复用旧词组以检验模板迁移，第4措辞是额外词面控制。新确认前锁定所有候选与联合方向。

主频率不从类别面板估计：使用 S09 已固定的384篇发现题干（Magicoder/GSM8K/MMLU各128），保留原首至多128 token，追加同一后缀并读取末冒号。每个feature的频率是384个文档位置中的非零比例；至少8文档激活才进支持充分组，该组按频率三分位分低／中／高，同次数不拆。0次单列“参考未出现”，1–7次单列“不足”。这只是有限题干语料的频率。S09原3072正文位置的频率另作敏感性，并核对原 marginals，不冒称普适频率。

11种配对分别报告：动物–交通工具、猫–狗、汽车–自行车、4父子和4跨父细类。直接父类词与由两个子类等权汇总的类别分开；汇总类别的重叠是四种跨父细类 Jaccard 的平均，出现率／强度是子类等权平均，不能把并集当作另一条Top32输入。

共同成员逐对定义交集，并列发现集固定的稳定名单（显式共现至少6/8，另两措辞各至少4/8）；频率分布同时报告组基数、激活机会、标签边际预计交集和家族配对打乱参照。换入／换出只是Top32名单变化。每条原始强度、整体L1/L2和相对搭配一起保存。

区分成员用发现集的多家族、多措辞方向选择：显式出现率差绝对值至少.25，另两措辞同向且至少.125，并至少2/3强度差同向。全部合格名单锁定。强度单独变化另外选列，不混成出现率区别。新确认中不重筛；主频率比较使用原名单及原方向的连续效果，包括反向，不能先按确认显著性挑选再计算同一确认集的频率规律。逐feature的检验另作BH校正。

相同名单的相对强度用发现集最多8个共同成员及归一化方向，在新16家族投影；要求两侧support一致且至少2成员，每措辞至少12/16对合格。联合结构另用保持每行32、每列次数的Curveball零模型；按类别／措辞分层，4链、100预热、10间隔、每链64样本。检查锁定成员、变化率、Rhat和ESS；最多固定扩展到128，仍不足就报告不足。零方差约束不能当成发现。

统计单位为完整家族，2000次家族bootstrap和家族符号随机化；H1、H2、强度、联合各4个主要检验分别Holm，探索另列。基本行为用原4个完整两token候选求条件log概率和子类二选一正确率；父类不编正确答案，不因失败删除文本。保留至少4案例、反例、全部原始表和源文件。原始数据/权重不覆盖，不训练router或模型。
