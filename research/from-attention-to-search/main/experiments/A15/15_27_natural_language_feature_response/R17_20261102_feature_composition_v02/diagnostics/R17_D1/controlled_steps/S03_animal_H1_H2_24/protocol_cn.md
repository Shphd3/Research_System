# S03 协议：动物—猫狗的成员与相对强弱

本轮由用户当前指令授权，仅完成24条、两套冻结SAE的H1／H2描述性探索。原H1的“新增成员提供额外信息”和原H2的“控制成员身份、总幅值后相对强弱仍有额外信息”保持不变。本步只观察共同／新增成员复现和比例变化，不能完成原命题的功能验证。结束后等待共同审阅。

保留S02全部12条猫狗原文、完整前缀和行为分数。各家族增加P（只知animal，猫狗未知）和N（chair，非动物），形成24条。为避免重复，P正文以object指代对象；为保持语义自洽，N后缀为“The object is a”，其余沿用“The animal is a”。这些实际差异逐条记录，animal/object后缀差异是共同响应的重要竞争解释。P不是猫狗否定例。

运行前固定F01–F03探索，F04–F06保留检查。先只读取探索表征、固定候选和方向，再开放保留家族。候选不足时不补选，检查结果不用于改阈值或排序。每套字典分别选择：

- H1共同候选：探索中至少2/3家族P／猫／狗均激活，且至少2/3家族min(u_P,u_cat,u_dog)>u_N。依次按共同覆盖数、正对照差覆盖数、平均对照差降序、ID升序排序，最多6个。
- H1新增候选：猫狗分别选择，至少2/3探索家族满足P为零、细类为正。按覆盖数、这些新增事件中细类平均加权值降序、ID升序，最多各6个。不要求另一细类为零；它的响应始终报告。
- H2共同候选：至少2/3探索家族猫狗均为正。按共同覆盖数、mean(min(u_cat,u_dog))降序、ID升序，最多6个；不按猫狗差异挑选。固定列表后分别计算原始z和加权u的L2归一化；零范数不可定义，表中为空，图中灰色。每原子探索平均(q_cat-q_dog)的符号固定为方向，绝对值≤1e-8为零。保留家族逐对核对，全部反向／缺失／不可定义均保留。

模型与tokenizer沿用S02实际加载文件并核对哈希。两套SAE都用原编码：线性编码+偏置→ReLU→Top32，激活定义为最终z>0；没有额外输入归一化或减decoder偏置。attention为block27 o_proj输出、残差相加前；MLP输入为block27 mlp前hook，已经过残差相加及post_attention_layernorm。两接口独立观察，不解释成MLP输入输出或因果前后对照。每条在完整可见前缀最后一个token取样，随后不加入任何答案。记录完整token、位置及目标字符串。

原始激活为z；每原子自己的decoder列L2范数为d；加权响应u=z*d只表示单一解码方向的幅值，不等于非正交方向合成后的贡献。共同列表上的相对值为z/||z||2及u/||u||2，保留原始总范数。同一固定列表支持集相同与全字典支持集相同分开报告；归一化只去除该列表的标量尺度，不能宣称控制模型所有总幅度或证明额外预测信息。
