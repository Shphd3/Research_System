# S11：四组粗细类别的相对频率检验

状态：用户已批准本轮有界推理和统计。科学接受、机制判断与问题关闭仍为 Unknown。英文 protocol.md 是完整计算合同；本页给出相同的主要定义与分母。现有 15_27_06 / 15_27_07 继续拥有科学问题，本轮不新建平行 Anchor。

## 问题与数据

检验共享成员、成员差异、共同成员强弱差异的独立参考频率，是否随粗细比较发生相对移动。不预设高、中、低频分段。类别为动物—猫/狗、交通工具—汽车/自行车、水果—苹果/香蕉、家具—椅子/沙发。

新写96个背景家族，固定32个开发、64个确认；每家族12类别×4措辞，共4608条（开发1536、确认3072）。显式类别词、名称改写、属性与场景四种措辞分别报告。后面三种措辞在开发/确认使用不同预写表述。旧家族和旧激活不计入新增数据。

两个独立频率轴：新6000条题干（Magicoder/GSM8K/MMLU各2000）和新6000篇DCLM文档，排除可识别旧样本及重复。正文前128 token后统一追加 `\nDescription:`，主频率在末尾冒号读取；8个正文位置另做位置敏感性分析。各轴分别使用6000文档作为分母，不能称普适频率。

## 对象与分母

| 对象 | 分子或质量 | 分母与独立单位 |
|---|---|---|
| 每对共同成员 | 两条正激活集合的交集 | 每对交集数 I；家族等权 |
| Jaccard | 交集数 I | 并集数 U，不含激活幅值 |
| 开发固定共有清单 | 开发显式文本中共同出现至少24次 | 32个开发家族；确认出现率分母64 |
| 成员差异方向 | B正激活指示减A指示 | 32开发家族的均值；全字典，无事后显著性筛选 |
| 强弱差异方向 | 共同激活指示×(B/全向量L2−A/全向量L2) | 32开发家族，未共同激活贡献0 |
| 开发权重 W | 上述开发均值的绝对值 | 全字典绝对值之和；方向符号另存 |
| 确认差异频率分布 | W×实际差异绝对值；强弱通道再要求共同激活 | 该家族非负质量之和；零分母记缺失 |
| 确认有符号复现 R | W×固定开发符号×确认实际差异 | 固定权重和1；不得去掉反向贡献 |
| 参考频率 | 独立语料中正激活次数 | 6000文档，每文档一个主位置 |

所有实际配对使用完全相同的共同成员交集定义。直接父类比较、父子比较、同父细类、跨父细类分别报告；子类混合的粗类对象用四个跨父细类配对的均值，不能替代直接写出的父类词。两套SAE分别分析，不对齐ID。

主比较：动物/交通工具作为猫狗与汽车自行车的粗比较；水果/家具作为苹果香蕉与椅子沙发的粗比较。每组计算“粗比较的频率均值−细比较的频率均值”；正值才符合细类相对较低频的预测。2字典×4类别×3通道=24项/参考轴。其余关系与措辞是预设次要/探索比较。

## 确认集反向结果

确认集幅值分布保留所有反向成员；同时单独报告其有符号复现贡献，绝不因取绝对值就写成方向复现。负的频率差、负的成员贡献、反向家族、反向措辞均按原符号展示；不换成员、不翻方向、不调阈值、不改确认文本。首个、居中及最负家族按预写规则选例，至少四个不同家族覆盖四组类别。

每项须有至少48/64个可定义家族；粗细两侧参考计数至少5的成员质量覆盖均须≥80%。每个细类的候选评分正确率须≥75%。达标后，联合参考文档/家族2000次重采样区间为正且9999次家族符号检验经Holm24校正通过，才记局部支持；差异通道还须固定方向R复现（Holm16）。区间显著为负保留为明确相反；跨零记有效但未决；样本、行为或参考覆盖不足记证据不足。零次出现单列并给上界敏感性，不能直接叫低频。

## 顺序、控制与预算

核验权重/加载器/数据/资源→冻结文本、协议、代码哈希→开发集评分与预算校准→完整开发集→锁定方向、权重、共有清单→新参考语料→完整确认集→预设统计、措辞/位置/总幅值/Top-k边缘/家族打乱对照→审计、报告和结果包。

使用官方Qwen3-0.6B Base；Attention为第27层o_proj输出，MLP输入为第27层mlp实际输入，均为既有30000维Top-32字典。原模型完整候选序列log概率用于能力检查，父类不造细类正确答案。CPU4线程，推理上限10800秒，内存额度128GB、输出上限20GB。先用64开发条目估算，不申请GPU/云任务。不训练，不干预，不启动router。

参考语料中的频率不等于词频或语义深度；共同激活不等于共同功能；本轮也不能证明超出所有单成员边际的语义组合。措辞、后缀、位置、总强度、Top-k排序与来源仍需逐项解释。256次整家族打乱保留每侧实际向量和边际，仅检验背景配对影响。
