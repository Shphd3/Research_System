# 本次实际采用的对象与设置

**用户已确认：E16 SAE 做最后一个 block 的局部读数主分析；A22 CrossCoder 使用原共享 z，计算最后层解码贡献作为另一套分析。两套共用文本，独立选候选、独立验证；新增前向合计上限仍为512条。** 先前接口预检停止记录保留，当前修订见 `amendment_A01.json`。

| 对象 | SAE 主分析 | CrossCoder 另一套分析 |
|---|---|---|
| 同一冻结模型 | Qwen3-0.6B-Base，28 blocks；核对两路径权重及tokenizer一致后才可共用前向 | 同左 |
| 固定字典 | E16，30000个坐标 | A22，16384个坐标 |
| 输入 | block27的MLP输入，即post-attention layernorm之后 | 同位置block1,3,…,27的14层residual-post，最终全局RMSNorm之前 |
| 激活 | 原FP32编码、ReLU及Top32，命中为z>0 | 原14层分别投影后相加、共享bias、ReLU、原保存阈值门控，命中为共享z>0 |
| 归一化 | 按原SAE接口，不临时做输入单位化 | 冻结TRAIN逐层均值与向量L2 RMS |
| 贡献幅度 | z乘原空间decoder列范数 | 共享z乘block27 decoder范数，再乘原TRAIN RMS27，回到该hook原尺度 |
| 解释 | 最后block该局部张量上的字典响应 | 联合14层得到的共享坐标在最后层重构中的贡献；不是最后层独立激活 |

数学、生物是人工文本领域标签，图中对象是feature。仅检查数学偏向、生物偏向、两域共享候选的留出复现、DCLM参考频率与固定目标token的上下文敏感性。候选不是无监督自然簇，编号不得跨字典对应。

仍只做两个实验：实验一120篇真实英文独立文档，每域60篇，发现/开发/留出30/10/20；每篇192tokens，统计第33–192位。实验二12个家族、72条受控编辑文本，发现/留出各6家族，相同目标完整token序列、局部后缀、目标位置与长度对齐。共享最多32个，偏向合计最多32个、每域16个；不足用等维较小偶数k，最低8，不按留出重选，不改变字典Top-K。

参考频率仅称DCLM参考频率，使用完全匹配旧缓存或最多256个可追踪、与实验去重的文档窗口。不用平衡领域面板冒充总体频率。所有前向含检查、重放、参考校准合计≤512条；共用一次Base前向同时捕获两个合法hook不重复计数，分开调用则分别计数。模型及字典不更新。

本轮不做第三种截取encoder分支读数，不做Attention、干预、重聚类、谱分析、跨模型比较、新任务或资源申请，不读取封存TEST。两套字典的差异受hook、训练等混杂，不能作为架构优劣结论。固定目标的领域编辑只测上下文敏感性，不测物理远距离机制或纯概念。

数据来源已落实到具有URL、WARC记录ID与原始行号的既有DCLM网页。M2D2缺article ID，未作为独立文章使用。实际完成120篇文档、72条受控前缀与256个参考窗口，完整分割与资格边界见Detailed。
