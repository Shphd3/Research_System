# 这批领域区分成员，在哪里、何时被使用？

**回答：它们的decoder方向相对匹配背景更偏谱前部，但这不等于在远处强Attention来源位置使用得更强；全部活跃坐标也没有一致地向低频移动。** 本轮把两种测量接到同一批固定成员上，使用40篇原留出文档（每域20）；旧留出已多轮查看，全部是探索性补充。前向、训练、重聚类、PCA重拟合、重选成员和新任务均为0。

**认识更新一：谱位置与使用位置可以分开。** SAE数学9／生物7个Top-16成员在前64个主成分方向的平均平方投影为50.75%／51.80%；各自匹配背景中位为39.31%／41.10%。CrossCoder对应为23.29%／21.34%，背景8.29%／10.11%。这些是方向几何，不是激活强度，也不能按两字典原始百分比排“语义多少”。回到真实来源位置，同域方向集合的标准化含零平均贡献：SAE数学近高0.413→远高0.314，生物0.245→0.204；CC数学0.696→0.687，生物0.484→0.432。高、中两组的近远变化直接相减后，8个主差中差区间均跨零；24项主比较均未达到统一校正门槛。当前数据不足以支持“这批区分成员整体在远高更强”，也没有证明所有成员都不随位置变化。[图1](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/R04_domain_usage_20261027/domain_discriminability_spectrum_20261028/attention_source_link_20261028/figures/figure1_spectrum_position.png) · [图2](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/R04_domain_usage_20261027/domain_discriminability_spectrum_20261028/attention_source_link_20261028/figures/figure2_zero_inclusive_usage.png)

**认识更新二：远高不等于低频，也不等于某种已知语义角色。** 统计前文端全部活跃坐标后，低频占比近高→远高：SAE数学7.85%→7.54%、生物9.98%→8.50%；CC数学1.92%→2.06%、生物2.95%→2.90%。方向不一致，削弱“远处强关注普遍偏低频”的简单判断。CC数学的低频绝对数量其实从5.96升至6.20，说明占比与数量必须分别看。远高来源包括术语、普通词、结构词和换行；词形规则覆盖全部事件，语义作用仅为候选。[图3](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/R04_domain_usage_20261027/domain_discriminability_spectrum_20261028/attention_source_link_20261028/figures/figure3_all_active_low_frequency_share.png) · [图4](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/R04_domain_usage_20261027/domain_discriminability_spectrum_20261028/attention_source_link_20261028/figures/figure4_real_text_sources.png)
