# 活跃feature贡献的近远谱位置：冻结离线补充

本轮只问：远高来源处全部活跃feature的实际贡献方向，是否比近高更偏谱尾？沿用既有40文档、原Attention配对、原生SAE/联合CC和旧PCA完整基，不增加前向或候选。

主量每位置先把各成员贡献投影平方后相加，再除以成员完整贡献平方范数之和；不加交叉项、不乘特征值、不做feature RMS标准化。命名“活跃feature的贡献加权谱分布”。按1024逐方向权重计算平均排名，不用16段中点近似。等权成员、合成向量和中心化真实表征单独记录。合成向量不含bias/residual，先相加再平方。

近1–32/远129–160，档内高/中沿原规则。原同query/head近远共同支持及位置→head→query→文档等权不变。主要比较远高减近高，以及该变化再减远中减近中。两字典×两领域×两对比共8项，BH统一校正；5000次文档配对重采样95%区间，19999符号翻转。原文档重复查看，全部探索性。

窗口检查：原高/中pair两端均在32:192才保留，之后重新取近远query/head交集，不补位置。报告剩余文档、query、cells、pair和截断。诊断原Attention、距离、绝对位置、前32比例、空白/结构词比例。四种读数不一致时完整报告，不据结果换谱段或选择有利口径。

详细冻结参数、随机种子和输入哈希在config.json；正常缓存内工作全部授权。无训练、新字典、重聚类、PCA重拟合、模型前向、新任务或封存TEST。
