# 实际计算与证据边界

本轮只回答远高的活跃贡献是否更偏谱尾。行为与因素对照沿用旧观察分组、没有新增行为测试；表征分析计算四个不同谱分布；功能干预未运行，核验只检查公式与数据。没有研究簇形成、频率原因或新候选。

## 1. 对象、输入与原尺度

SAE为原生E16，block27 MLP输入（模型原生post-attention RMSNorm之后）、30000坐标；CrossCoder为A22，14层blocks1,3,…27 residual-post联合编码的共享z、16384坐标。本轮CC仍用原共享z乘最后block27原尺度decoder；原尺度方向为TRAIN_RMS27=374.3495121024576乘保存decoder方向，偏置与训练均值不归入某个feature贡献。不能把共享z说成最后层独立激活。SAE原native ReLU/Top32、CC原推理阈值0.051281172782182693不变；没有重新编码或更改稀疏设置。

两套hook空间不同，各自使用原发现集共同PCA基，绝不拼接空间或对齐feature编号。原PCA只在每域30篇发现文档、每文档160tokens的32:192窗口拟合；合并均值中心化、领域和文档等权，无额外逐维标准化。完整1024基、每段64方向。旧数据仅保存1114/8145坐标投影，本轮从原生decoder补算全30000/16384坐标在**相同基**上的投影，这是固定线性变换，未拟合新PCA。

checkpoint SHA256实际重新读取并核对：SAE e4e2049aced8ba9a3b043bbb2b3308b497b7ec22f107531e37197873ee545b65；A22 09b432e98dd7426f9ea4170809d75068a2ada2ed38c1e97d3fa18e119cd79628。原Base为冻结Qwen3-0.6B-Base BF16，本轮未载入或调用语言模型。逐token原z、真实h与token ID均来自旧缓存；旧表征补取已通过原z/复放检查，本轮不新增前向。

## 2. 四个分布，先定义再比较

记u_j为固定第j个PC、d_i为原hook尺度decoder、z_i为该来源位置的原生激活、v_i=z_i d_i。

主量“活跃 feature 的贡献加权谱分布”：第b段分子为sum_i sum_{j在b段}(u_j·v_i)^2，分母为sum_i||v_i||^2。先逐支投影/平方，再成员求和，没有交叉项。分子并没有额外乘特征值、奇异值或feature RMS；真实z和decoder范数通过v保留。全16段之和1，分母0记NA。主指标为逐PC的sum_j j×份额，**不用谱段中点近似**。

等权成员：对活跃d_i单位化后计算方向平方投影，再成员等权；这是组成参照，不是实际贡献。合成向量：先s=sum_i v_i，再计算各段||P_b s||^2/||s||^2；它包含2×成员间内积的交叉项，没加decoder偏置/训练均值，也没加重构残差。真实表征：使用实际h−原发现合并均值mu，然后投影平方并归一；它是逐位置方向分布，不是原先全语料的方差比例。

所有口径每个位置先归一，再依原Attention采样层级平均。不同来源位置不会因总激活量大而占更大权重；主量在**同一位置内部**刻意保留真实贡献幅度差。没有使用DCLM频率当权重、没有只数Top16，也没有把谱尾定义为高级语义。

## 5. 幅度、组成和交叉项的界限

等权成员与实际贡献的水平明显不同，主量更偏前；但其近远变化差的区间仍跨零，不能确定近远差主要来自组成还是幅度，不能声称纯z强度已被分离。[辅助结果](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/R04_domain_usage_20261027/domain_discriminability_spectrum_20261028/attention_source_link_20261028/active_contribution_spectrum_20261028/auxiliary_cn.md)保留所有读数与直接配对比较。

合成与各支平方之和不一致时报告交叉项，不挑某个有利读数。SAE数学近高交叉总项相对独立平方和约+48%，CC数学约+14%；这不是信息增加或原表征解释率。CC数学近远排名差，单支−6.22、合成−1.25、真实表征+3.08，均有宽区间；真实表征还包括偏置、残差和中心化原点差别，不能将其全部不同归因于成员交叉项。表征谱排名也不能等同长程语义。

固定角色只做辅助分解：原R04共有32/数学16/生物16/其他四组是贡献平方和的一个分区，其power_fraction及rank_contribution四组加总精确还原整体。旧共有在SAE数学近高/远高占独立贡献平方和73.54%/77.67%，CC49.66%/51.11%；这是当前样本的幅度占比，不是通用功能或形成原因。新Top16数学9/生物7另列，和旧角色有重叠，不能把两套标签相加。[逐文档辅助分解](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/R04_domain_usage_20261027/domain_discriminability_spectrum_20261028/attention_source_link_20261028/active_contribution_spectrum_20261028/tables/fixed_domain_group_decomposition_by_document.csv)

## 6. 完成程度与数值核验

两个完整decoder都可用；40篇真实h缓存全部可用；所有选中位置四种分母均有定义，没有用0填不可估项。没有资产缺项。全字典方向、每文档192位置的四口径、原支持/窗口支持、全部诊断、两主图和九附图均已保存。旧材料没有被覆盖。

位置阶段1052项自动恒等式/归一/边界检查通过：全字典PC投影的Parseval、与旧1114/8145投影一致、每位置16段和1、排名1–1024、原角色分区、交叉项恒等式。独立audit.py另用实际贡献矩阵直接计算，在固定位置复核四口径和逐PC平均排名；独立展开位置权重、重算窗口选择、bootstrap和BH，共231项通过。实际渲染PNG已检查，没有用单feature案例替代集合结论。

位置计算约47.55秒（CPU checkpoint读取/哈希、固定矩阵投影和80组位置缓存），文档汇总约16秒；另有统计、绘图和审计，未单独采集CPU秒。设置CPU BLAS4线程，GPU/模型前向为0，无资源申请。分析代码只从checkpoint读取decoder矩阵，不创建语言模型/SAE forward或优化器。一次绘图启动路径错误在运行前发现并修正，没有产生测量或改变设置。统计随机种子在执行统计前按冻结配置实现，未依结果调参。
