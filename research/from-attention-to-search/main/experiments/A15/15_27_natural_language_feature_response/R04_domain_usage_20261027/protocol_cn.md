# R04 执行协议

用户已授权原定两个实验，后续明确采用E16原生单层SAE主分析与A22原生14层共享z的最后层解码贡献另一套分析。共用文本、独立筛选与验证、总新增前向≤512；无第三套读数。完整精确条款见英文同名文件和执行侧 `analysis_config.json`，本文件是中文阅读伴本。

我们问：数学/生物人工领域标签参照下筛出的共享、数学偏向、生物偏向feature，在留出真实文档中是否复现；固定目标token改变领域前文时，其变化是否超过无关编辑。它连接1027交流中“先定义关系、再统计feature性质”的建议；只操作化上下文依赖，不把它叫物理长程或纯概念。

实验一两域各60文档，每域发现30/开发10/留出20。两域都45篇说明文本+15篇问答，均可追踪WARC记录、原始文件行、网页URL及文本hash；每文192tokens，统计33–192。按页面/书籍和全文档近重复筛查分割。M2D2缺文章ID，因此未用于此处。DCLM网页具体网站和子体裁仍不完全匹配，分类可能利用词面/格式/来源。

每字典独立选择共享最多32、偏向合计最多32（数学/生物各16），不足采用相同较小偶数k，最低8。共享要求两域各≥5发现文档、p≥.005且率比严格在.5与2之间，按min(pM,pB)排序；偏向优势域≥5文档、p≥.005、率比≥2，以Jeffreys平滑率比排序；均按featureID打破平局。冻结后不看留出重选。原SAE Top32和CC阈值不改。

固定标准化+L2 logistic C=1仅拟合发现集。各20组同维随机集合匹配发现命中率四分位×文档支持三分位；池不足NA、不放宽。1000次分割内标签置换每次重做筛选和分类，凑不够原k时BA=.5并计数。文档bootstrap2000次，两个主probe在字典内BH校正，并补报四检验合并校正。有效读出要求BA≥.65、区间下界>.5及q<.05；另报匹配随机对比和token-ID词袋基线。

实验二12家族/72条英文受控构造文本，发现/留出各6家族；每家族两域×两措辞+两域各一次星期无关编辑。目标完整token、局部后缀、长度和绝对位置对齐。为了对齐有不同中性前导语，保留这一混杂；不测距离。原生贡献除以实验一发现token RMS（含零）得到x，实验二发现家族定方向s。每留出家族计算D=平均有向域差、U=平均绝对无关变化、E=D-U；两措辞分别保留。家族bootstrap2000、枚举64种家族符号翻转（要求零中心对称假设），字典内两组BH并补四组校正。两措辞平均方向均正、E区间>0且q<.05才称强于无关编辑；不足不扩样。

参考频率独立选256个DCLM文档窗口，每条256token，记录WARC/URL/行/seed，与领域文档及近重复去重。原生z>0的计数/65536，<20hits低支持，文档窗口bootstrap；只代表有限DCLM参考，不冒充普遍频率。

原空间贡献：SAE为z×decoder列范数；CC最后层为共享z×decoder27范数×原TRAIN RMS27。后者是联合编码坐标在最后层重构中的向量长度，不是最后层独立激活、方差份额或功能重要性。两套hook、训练不同，不据差异判架构优劣。

先8条资格/重放/可见前缀检查，固定LM1×256、SAE256位置、CC1024位置，沿用重构阈值与数值一致性阈值；失败分支不可解释为科学结果，不放宽门槛。120+72+256+8=456条，剩56仅限必要资格检查，硬上限512；每次尝试提前记账。只用现有本地资源，无模型/字典训练、干预、Attention、重聚类、谱分析或封存TEST。三项统计/对象/实现审计及精确hash在冻结记录；科学机制判断与问题关闭保持Unknown。
