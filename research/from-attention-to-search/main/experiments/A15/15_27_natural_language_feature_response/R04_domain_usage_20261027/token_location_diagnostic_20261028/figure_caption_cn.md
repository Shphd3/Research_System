# token×feature图的读法

研究问题：文档能读出领域，但旧通用目标处常沉默，领域偏向候选在前面的哪里出现？

测量对象：每行是事前固定的旧feature，每列是实际token；左SAE、右CC，三排分别F08/F09/F11，每格是原空间重构贡献除旧发现token RMS。数学M1和生物B1分开。黄条标领域线索句，灰条共有后缀，橙条完整目标；橙框是旧最终目标。术语词用蓝色标签提示，token序号是零起始。

直接观察：例如CC f12630在F09的protein及其后普通词with亮起，末method为空；CC f12314则延续到这个method。SAE f12478在F11生物difference亮起。F08仍有许多空白，SAE f11399在全部受控文本都无激活。

允许的解释：末位置选择漏掉了部分前文响应；另一些候选与短受控文本的内容/写法不匹配。白色也可能是很小数值；精确0以CSV/JSON为准。固定色标上限4，部分值饱和，不按图像颜色判显著。

不能推出：候选唯一语义、信息传递、独立末层CC激活、功能重要性或新的确认结论。普通词位置的响应仍可能由之前术语触发。图只展示固定8行，全部32个的覆盖统计才用于总体描述。

数据源：执行侧display_values.json、已保存原始CSR激活与原R04decoder_scales.npz；规则在provenance/rules_frozen.json。详见summary_cn.md与detailed_cn.md。
