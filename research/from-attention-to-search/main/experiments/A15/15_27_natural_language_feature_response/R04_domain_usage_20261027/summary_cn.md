# R04：数学／生物领域使用与固定目标上下文响应

**我们问什么：以数学／生物文本标签为参照，已有 feature 的共享与领域偏向使用能否留出复现，并在同一目标 token 上随前文改变？** 这对应1027交流中“先定义要看的关系，再统计feature性质”。它是初步领域参照分析。

已经知道什么：

- SAE主分析读取最后block27的MLP输入；CrossCoder另一套分析用原14层共享z，并报告最后层residual-post的解码重构贡献。两套共用文本、分别选候选；没有自然簇发现或跨字典编号对应。
- 已完成120篇真实文档、72条受控前缀和256个DCLM窗口；含8条检查共**456/512**次前向。没有模型或字典训练。重放与可见前缀检查通过。
- DCLM共享候选的激活率中位数：SAE **32.73%**、CrossCoder **58.15%**；数学/生物偏向候选分别为SAE **0.170%/0.0397%**、CrossCoder **0.378%/0.164%**。这是有限DCLM参考频率；共享筛选本就偏好广泛出现，不能由此解释形成原因。

新测量改变了什么认识：

1. **文档层面的领域使用可复现。** 两套各32个偏向候选均在留出保持偏向；各32个共享候选均在两域出现。共享/偏向32维分类的留出平衡准确率：SAE **95%/100%**，CrossCoder **92.5%/97.5%**。匹配随机集合平均为SAE **75.9%/73.5%**、CrossCoder **85.6%/95.6%**；CrossCoder随机组也可达100%，因此未显示其候选独有信息。词袋为95%，词面和来源仍是竞争解释。见[图2与精确结果](figures_cn.md#图2领域可读性与dclm频率)。
2. **文档可分类尚未延伸为稳定的同目标组级响应。** SAE共享/偏向组校正q均为**0.375**；CrossCoder为**0.219/0.125**。后者偏向组E=**0.0325**、家族bootstrap区间[0.0083,0.0605]，但精确p=0.0625，仍未达到预设标准。真实局部例子：CrossCoder f12314在同一 `method` token，数学z=0、生物z=0.03484；最后层重构贡献**0→19.36**原空间单位。反例：换到 `example` 目标，该feature六个版本均为0。见[例子](examples_cn.md)和[图3](figures_cn.md#图3固定目标的领域编辑与无关编辑)。

还不知道什么：这些使用模式能否排除前文术语、子体裁和中性前导语差异，成为跨目标稳定的领域上下文响应。当前没有证明纯概念、自然簇、频率因果、功能重要性或长短程分工；机制判断待讨论，未自动扩展实验。
