# CrossCoder频率分组：按成员数三等分，还是按频率数值等宽？

**之前采用的是按feature人数三等分；“中频”明确指字典中间三分位，不是激活概率在33%—66%。** 本次固定上一轮数学/生物各32名单，使用同一DCLM缓存比较两种分法，没有重选候选、新增前向、训练或假设检验。等宽统计是新增探索性口径，未覆盖旧频段。

## 频率到底是什么

对每一个feature，DCLM频率=原生共享z>0的参考token位置数/65536。一次token可以同时激活多个成员，feature频率之和不必为1。它不是当前数学/生物面板命中率、强度、谱位置或累计激活次数占比。

原字典共16384坐标，其中3027参考命中不足20次，继续单列低支持；剩余13357用于两种分组，保证比较同一总体。两种都在整个参考字典上定界，再查询固定候选，不在候选内部硬分三组。

## 两种边界

|方法|低频|中频|高频|
|---|---|---|---|
|A：人数三等分，原口径|20—170次，即0.03052%—0.25940%|171—881次，即>0.25940%至1.34430%|≥882次，即>1.34430%|
|B：频率数值等宽三分|0.03052%—33.01188%|>33.01188%至65.99325%|>65.99325%至98.97461%|

A按频率排序后取成员数量约三分之一，相同命中数不拆开，所以人数4469/4437/4451略有差别。B把同一总体实际频率最小0.03052%至最大98.97461%的数值范围分成三段，段宽相等，人数不保证相等。这里明确“频率均分”是线性数值等宽，不是按累计激活次数三等分。

## 同一批候选的结果

各单元格顺序都是**高 / 中 / 低**。

|固定候选|A人数三等分|B频率数值等宽|
|---|---|---|
|数学前16|3 / 13 / 0|0 / 0 / 16|
|生物前16|1 / 11 / 4|0 / 0 / 16|
|数学前32|9 / 20 / 3|0 / 0 / 32|
|生物前32|4 / 20 / 8|0 / 0 / 32|

前32两域合并：A为高13/中40/低11；B为高0/中0/低64。64候选全部参考支持≥20，因此没有低支持成员参与这张候选表。它们的连续频率范围是0.05341%—4.19312%。

## 为什么会出现这样的差别

|整个合格字典，不是候选|低频人数|中频人数|高频人数|
|---|---:|---:|---:|
|A人数三等分|4469|4437|4451|
|B数值等宽|13281|63|13|

B把99.43%的合格字典都放入低频；只有76个进入中/高。因此候选全落低频，主要说明等宽法在当前偏斜分布上分辨率很低，不能说领域候选特殊地富集低频，更不能把0/64高频说成排除了高频作用。作为边界敏感性，固定理论范围0%—100%等宽33.33/66.67也得到全部64低频；其字典人数为13284/60/13，保留在CSV。

实例CC f5072参考频率572/65536=0.87280%，在人数组是中频，在等宽法是低频；f652的1.59454%在人数组为高频，在等宽法仍是低频。数值没有改变，只是“中/高”的定义不同。

## 哪种更符合研究目的

没有脱离问题的唯一标准。若问题是“这些候选相对整套字典处于什么频率层次”，A更合适：背景每档人数接近，有能力描述相对位置；应写“参考频率中间三分位”，不能把它叫普遍的中等出现率。若问题是“每个成员在多少比例token上出现”，直接给连续频率最清楚；B是数值区间描述，但当前大多数坐标都挤第一档，不宜作为主要区分工具。

建议在本项目中以**连续DCLM频率+人数三分位标签**为主，同时明确切点；等宽结果作为敏感性对照。此前“候选主要中频”应准确表述为“候选主要位于同字典参考频率的中间三分位”，不等于经常在三分之一至三分之二token激活。

可以保留的认识：这些候选绝对出现率均小于4.20%，相对字典排名却多在中段；两种说法相容。不能由分箱推出语义专一、训练形成机制或长短程。候选选择要求多文档/同词支持，旧留出反复使用，相关偏差不因换分箱消失；本轮没有新的富集显著性检验。
