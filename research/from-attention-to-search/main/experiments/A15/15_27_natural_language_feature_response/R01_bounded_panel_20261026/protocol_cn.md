## 1. 术语与定义

一个基础案例最多含四个受控版本，各版本均在同一目标 token 结束。一个样本是目标位置及其截至该 token 的可见前缀，不能前向后文或用后文解释该位置。特征是已有 SAE 的 30,000 个坐标之一。关系组是按配对响应变化定义的特征聚类，不是已验证的专家或知识模块。发现集用于固定候选与处理；留出是本轮新构造的确认面板，不是封存 TEST。

来源组（source group）记录独立构造的线索措辞。同组若有多行，先平均再做主要关系统计，并按整个来源组重采样。最终文本有 72 个不同来源组，当前每组对应一个基础案例。各例仍共享目标 token 和关系概念，因此向更广总体推广有边界。

## 2. Anchor 对齐

本轮检查固定响应定义能否经过受控编辑并跨隔离的措辞家族复现，分别检验 H1 线索响应、H2 响应关系组和 H3 近远差异。核心对象是每个特征在多个案例中的同 token 贡献差向量。Token 热图解释实例，热图外观或二维投影不决定复现。测量合格不等于功能有用。

## 3. 待检验假设

H1：部分线索响应可跨表达家族复现，且在留出中超过无关编辑。H2：部分配对响应组可超出支持／边际和频率／强度解释而复现。H3：在保留同关系与目标的条件下，可以区分距离敏感性与线索依赖。各自主要证伪条件是固定的留出条件失败或与随机对照相近，前提是测量和支持度合格。

## 4. 竞争解释

A 比较局部修饰／搭配效应与无关星期编辑。B 改变前文明示词义线索，保持目标及其紧邻措辞。C 将相同中性文本块移到同一线索两侧，保留关系、文本内容、token 长度与目标位置；同距离语义对比用于区分线索内容与位置移动。句序仍随距离一起改变，因此 H3 的正结果表述为本构造下的距离／顺序敏感性。全局幅度回归与两类随机对照处理共同强度和稀疏边际解释；跨分割模板／实体／来源隔离和移除单模板检查处理表达依赖。

## 5. 文本构造与来源

每类固定 24 例，发现／留出各 12 例，每例四版：共 72 例、288 条序列。全部文本由 Codex 代理按研究者约束人工构造英文自然语言，再作受控编辑，不是未经修改的自然语料摘录。固定六个目标词为 bank、bass、bat、crane、port、seal。不需要封存 TEST 或自然语料提取。

A／B 四版是 base、changed、neutral-base、neutral-changed；无关编辑只改星期，token 数与目标位置完全匹配。C 四版是 near-base、near-changed、far-base、far-changed，通过移动相同中性块，在每个词义下保留线索内容；B／C 对相同关系概念使用独立构造的线索措辞。意图词义不明确的案例在观察特征前排除并记录，不按 SAE 响应筛选。

每行记录序列／案例 ID、面板、分割、来源与构造代理、模板／实体／来源组、文本、目标 token／字符位置、完整线索区间、线索末端距离、改变／保持对象及配对角色。模板／实体／来源组无跨分割重叠，近似版本始终同侧。与模型结果无关的分词资格核验目标 ID、匹配长度／位置及无后文。合格案例权威是 `panel/qualified_cases.jsonl`，执行 token 及偏移由 `panel/tokenized_sequences.jsonl` 拥有。原 `panel/cases.jsonl` 仅为初始构造视图，不是合格案例权威。最终文本长 14—77 token；C 的线索末端距离为近 1、远 40／41／45／46 token。完整线索区间另存，避免只用末端距离遗漏线索宽度。

## 7. 模型、架构与冻结对象

使用 `model_qwen3_0p6b_base_official_a5`、`tokenizer_qwen3_0p6b_base_official_a5`、`sae_qwen3_0p6b_e16_layer27_final_1b`，及参考 `representation_qwen3_0p6b_e17_dclm_sparse_activation`。Official 模型目录为 `/data/250010109/model_cache/Qwen3-0.6B-Base-official`。模型为 28 层 Qwen3-0.6B，原生 BF16、eval、无梯度、SDPA、`use_cache=False`，不用聊天模板或特殊 token。SAE 用原生冻结 FP32 `TopKSAE.from_pretrained`：1,024 输入、30,000 特征、ReLU Top32，不先将输入单位归一化或减 decoder 偏置。Hook 是零起始第 27 层 MLP 的 `forward_pre_hook(args[0])`，位于 post-attention 归一化之后。只选一套资产，不比较架构。

令原生输入为 h、激活为 z、保存的 decoder 列为 d，则原始贡献幅度 c=z·L2(d)，重构为 W_dec z+b_dec。分别保存绝对 z、c、c/L2(h) 和原始差／比例差，贡献向量可抵消，幅度不是可加的方差。本单层 SAE 不涉及共享 z 的层间生成主张。[资产审计](asset_audit_cn.md) 记录 loader、状态与哈希。

## 10. 主指标与冻结分析计划

**读数与主要对比。**A／B 的主 delta 为 c_changed−c_base。有符号无关编辑向量为 (neutral-base−base) 和 (neutral-changed−changed) 的均值；绝对对照为两者绝对值的均值，避免正负抵消。C 主 delta 为 near-changed−near-base，另存远距离对比、关系保留的 far-base−near-base 以及交互。每个特征尺度 s 为发现集全部案例／版本原始贡献的均方根，下限 1e-8，留出固定使用。比例变化不能替代绝对变化。

**资格与候选冻结。**特征需至少在六个发现案例和六个独立来源组激活，并在至少六个案例和六个来源组有非零主 delta（绝对值>1e-8）。按来源组平均后主 delta 的平均绝对值除以 s 降序排名，同分按 feature ID 升序。最多取 64 个，移除控制后响应零方差的聚类对象。保存所有特征的资格及支持，包含不可估项。另冻结稳定池：只需发现激活案例／组支持≥6，不要求响应支持。

**共同幅度控制与关系。**将每个特征的发现 delta/s 对截距、全部特征总 c 的对数变化、hook 范数的对数变化作 OLS 回归，对数下限 1e-8。来源组平均后拟合，留出不改系数。主关系是控制后响应向量的 Pearson 相关，行单位为来源组均值。未定义相关保留 NA。平均连接层次聚类采用距离 1−Pearson r、截断 0.5、组至少三个特征，不换算法。用 200 次发现来源组自助抽样，固定候选、尺度、系数、连接法与截断；抽样后零方差特征作单点。组稳定度为原组全部特征对的平均共簇概率，后续支持要求≥0.70。

**H1。**仅在发现 A／B 的面板×目标 token 分层内固定语义 delta 方向。留出 A／B 检验方向乘语义 delta 后减绝对无关编辑，再除以 s；先平均来源组。以 9,999 次单侧来源组符号翻转检验有符号语义变化的方向性；无关对照固定，另用 2,000 次自助法检验相对无关编辑的超额。对全部冻结候选作 BH FDR≤0.05。支持需留出 A／B 至少六个独立激活支持组、至少三个模板家族、有效非零响应组方向一致率≥2/3（至少六组，另报全案例一致率）、超额的双侧 95% 自助区间下界>0、q≤0.05、移除任何单模板后超额仍>0，且最大单案例绝对超额占比<0.35。一般留出候选激活／响应支持亦需六个案例与六组。可估超额的 95% 上界≤0 时削弱；其余未通过为证据不足。

**H2。**每个冻结组以留出控制后响应的全部特征对相关均值为效应。各成员至少六个独立激活组，整组至少六个独立响应组；每对至少四个独立组有任一成员的非零原始响应；所有成员方差须有限且非零。第一随机对照独立置换各特征的来源组响应行 1,000 次，保持其确切边际值及支持。第二对照从所有发现合格特征、排除当前组成员后抽 1,000 个匹配随机组。匹配三维：log1p(发现独立激活支持)、log(参考频率+1e-9)、log(s)。按合格池各维标准差缩放，下限 1e-8。每维差异须≤一个标准差；按标准化平方距离保留最近 20 个候选，在组内不放回抽样。不放宽范围；有效完整随机组不足 800 个时，匹配证据不足。

两类随机 p 值分别在各冻结组间作 BH FDR0.05。支持需资格通过、匹配合格、发现共簇率≥0.70、两个 q 均≤0.05、相关均值>0 且 2,000 次来源组自助 95% 下界>0，并且移除任何单模板后相关仍>0。资格和匹配合格但未过条件则削弱；资格或匹配不足则证据不足。频率只作注释和匹配，E17 TRAIN discovery 缺旧父模型哈希，且旧 SAE 读数采用 BF16 autocast，本轮则为原生 FP32，TopK 临界并列可能不同。频率匹配解释同时保留身份及精度条件；历史 NMSE 不能替代本地资格。

**H3。**交互为 (far-changed−far-base)−(near-changed−near-base)，先用原始 c，再除以 s；另报基准近远差。每个候选的交互方向由发现集固定，以留出定向交互作 9,999 次单侧来源组符号翻转、跨候选 BH0.05 和 2,000 次自助 95% 区间。至少六个独立 C 激活组及六个非零交互组，有效非零交互组方向一致率≥2/3（至少六组）、q≤0.05、区间下界>0，且先通过同目标、同长、同位置及关系保留资格。支持表述为该位置移动构造下的距离／顺序敏感性。未通过为证据不足，不证明无距离效应或长程专属。

**稳定。**仅在冻结稳定池检验：留出至少六个独立组有激活，平均原始 delta/s 的来源组自助 90% 区间严格落在 ±0.2 内，平均绝对原始 delta/s 的单侧 95% 上界≤0.2。先保留组内绝对值再平均，使用 2,000 次抽样。这是注册对比下的操作性稳定，不是普遍上下文不变；“不显著”不能替代该条件。

不确定性一律按来源组／基础案例整块处理，版本始终一起保留。不自适应换算法、放宽门槛、替换候选或在留出拟合。精确机器版本为 [statistical_plan.json](/data/250010109/MoE_Router/experiments/20261026_natural_language_feature_response/offline/statistical_plan.json)，与根目录 `analysis_config.json` 及本协议一同冻结。

## 11. 辅助指标与资格保护

记录原始／归一化响应、支持度、当前面板命中率、独立参考频率、全局幅度、实际线索距离及按模板的删除检查。缺失／未定义／失败保留 NA、不可估或证据不足，不变成零。观察特征后不删离群值。辅助候选对数概率不带正确性主张。

发现及留出均须目标激活／hook／重构有限、目标 NMSE 均值≤0.15、p90≤0.30。NMSE 是重构误差平方和除以原生目标 h 的平方和。手工稀疏 decoder 和加偏置须以相对 L2 误差≤1e-5 匹配原生重构。发现集四条序列作同条件复放，目标 z 最大绝对差≤1e-5+1e-4×参考最大绝对 z。失败时停止依赖分析并记录具体条件，不另选模型／字典。留出重构失败，则对应假设证据不足。
