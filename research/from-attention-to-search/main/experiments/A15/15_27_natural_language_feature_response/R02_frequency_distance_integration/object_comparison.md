## Minimal formula audit

The older composition graph computes P(B given C)=nBC/nC and explicitly requires frequency(B)/frequency(C)≥1.5,with a highest-frequency4096 constituent pool. E17 joint gain is P(C given allB)−maxB P(C given B),not the present four-clue-response interaction. Code assigns leaves depth0 and every other node1+maximum child depth. This frequency-dependent construction cannot establish that independently grouped features share a frequency.

A residual decoder is r=d−projection of d onto its constituent-decoder span. Residual cosine is the cosine between two such r vectors; the inspected code returns NA if their norm product≤1e−30. This differs from cosine/correlation between paired semantic-edit trajectories. A CrossCoder's one shared z multiplied by fourteen decoder vectors yields fourteen contributions,not fourteen independent activations.
