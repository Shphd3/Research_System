# A15_02_E01 结果摘要：Qwen3-8B 粗细语义的深度与 16 带画像

## 结论

本实验得到一个分条结论：

- **深度命题 Pass：**在 Qwen3-8B 中，同一父类内的细粒度语义相对跨父类的粗粒度语义，确实在深层变得更容易区分。
- **实际方差的 head 主导 Pass：**粗、细语义的实际类别间方差都以 F1（前 256 个自然背景高方差方向）最大。
- **细语义 middle/tail 特异富集 Fail：**深层细语义相对优势同时出现在多数谱带，没有稳定、超过随机同维方向地集中到 F2--F8 或 F9--F16。

因此，当前最准确的认识是：

> Qwen3-8B 的深层表征把同一粗类别内部的细分类组织得更清楚，但这种改善是跨谱的表征重组，不是已经定位到某个固定 covariance rank 的“细语义通道”。

## 实验在测什么

数据包含 8 个粗类别，每类 8 个细类别；每个细类别有 4 种模板和 2 组不重叠事实，共 512 条不出现正确标签名的英文自然描述。模型读取共同的 `Classification:` 末尾冒号状态，同时预测粗类和条件于粗类的细类。

这里的“区分度”不是分类准确率，而是：

\[
D=\frac{\text{不同类别中心之间的方差}}{\text{同一类别内部由模板和措辞造成的方差}}.
\]

\(D\) 越大，表示类别中心彼此更远、同类文本更紧凑。定义

\[
R_\ell=\log\frac{D_{\ell,\mathrm{fine}}}{D_{\ell,\mathrm{coarse}}}.
\]

\(R_\ell>0\) 表示该层对细类别的相对区分度高于粗类别；它不表示细语义具有更大的绝对激活方差。

## 决定性结果

早层 blocks 1--12 的中位 \(R\) 为 0.0009，细/粗区分度比约为 1.00；晚层 blocks 25--35 的中位 \(R\) 为 0.4523，比值约为 1.57。预注册早晚差分为

\[
T_{\mathrm{depth}}=0.4514,
\qquad 95\%\ \mathrm{CI}=[0.3327,1.1891].
\]

四种模板的差分都为正，八次父类留一也全部为正。第 35 个 block 的粗/细 \(D\) 为 0.871/1.590，细/粗比为 1.82；最后一个 block 36 为 0.823/1.513，比值 1.84，所以**最后一层没有单独反转**。

![决定性层深×频带区分度热力图](figures/figure4_decisive_depth_band_discriminability_heatmap.png)

左图横轴是 16 个等秩谱带，纵轴是 embedding 与 36 个 block 输出；颜色是 \(\log(j_{fine}/j_{coarse})\)，其中 \(j\) 是该谱带内的类别间方差/类别内方差。红色表示细类更可分，蓝色表示粗类更可分，黑点表示配对 95% 区间不跨零。约从 block 28 起，红色同时覆盖 head、middle 和 tail。右图是不依赖频谱基底的全状态 \(R_\ell\)，它给出同一深层上升。

## 频谱画像

![层×16带粗细语义方差画像](figures/figure2_layer_band_coarse_fine_heatmaps.png)

- \(b\) 是每方向实际类别间方差，保留背景奇异值尺度；粗、细语义在 blocks 1--35 的最大 \(b\) 都是 F1。
- \(q\) 是 \(b\) 除以独立自然语料的背景特征值，表示相对该方向日常波动的异常程度；它不等于类别可分性。
- \(j\) 是频带内类别间/类别内方差，直接表示该频带能否把类别分开。

以 block 35 为例，粗语义的 head/middle/tail 每方向实际方差为 38.08/17.49/15.91，细语义为 24.97/15.04/13.42；所以细语义的绝对方差并没有超过粗语义。相反，细语义的 \(j\) 为 1.43/1.53/1.72，高于粗语义的 1.05/0.82/0.88：深层细类更可分，主要是因为同一细类在不同模板下更紧凑，而不是因为细类产生了更多激活能量。

细语义在晚层 middle/tail 的相对份额只高约 3.5%/3.7%，95% 区间分别为 \([-0.4\%,5.8\%]\) 和 \([-1.2\%,10.8\%]\)（由对数区间换算），均跨零，且小于随机同维方向的晚层 q95（对数比 0.0617）。因此不能声称细语义特异位于 middle/tail。

## 有效性与边界

- 模型固定为 `/data/share/Qwen3-8B`；读取 embedding 与全部 36 个 block 的 raw residual output；512 条记录的重放最大误差为 0。
- covariance 来自 128 篇独立 DCLM 文档、65,536 token；本次完整文本、定义和模板在这 128 篇文档中的完全匹配数均为 0。
- 所有上下文层的粗/细变量都可被完整状态读出；长度单变量准确率仅为 0.191/0.184。site 0 是所有文本共享的冒号 embedding，尚未接收上下文，正式标为 N/A。
- F1 在 calibration 两半之间稳定；若干 middle/tail 单带在近简并谱中会旋转，所以单个 F2--F16 身份只能描述，不能作普遍语义坐标。
- 结果只适用于这一冻结模型、英文 8×8 学术 taxonomy 和共同读出提示。它不证明深层执行了组合计算、频谱 rank 产生语义、某个频带适合 Router，或专家训练会受益。

## 裁定与下一决策

正式 verdict 为 `depth_pass_spectral_fail`。这项实验支持继续研究“深层细语义区分度”本身，但**不准入固定 middle/tail 频带作为路由坐标**。

唯一下一决策是：是否用一套独立 taxonomy 复现不依赖频谱基底的深度差分 \(T_{\mathrm{depth}}\)；在复现前，不进入固定频带 Router 训练。
