# 新增 common 专家：执行协议（中文伴随版）

这是用户直接授权的探索：分别在普通 MoE、按频率分发 T_F 上保留原来两位专家，额外增加一个所有位置都经过的 common 专家。暂不匹配参数量。两个独立任务，各申请一张 H100 Reserved；每个任务串行训练 baseline/+common × 种子11/22，共八个模型。没有申请四卡任务。

目的：检查旧实验“替换一个专家”没有稳定收益后，真正“额外加一条共享学习路径”能否改善同一低频目标。不是提前认定高频专家缺能力，也不是 Rank-one 方法的复现。common 在这里仅指所有位置都经过，不代表已证明它学习了共同语义。

计算：原残差输出是两位专家的加权和；T_F 各乘0.5，普通 MoE 保留原来归一化门权重。新增 common 单独乘1后相加，不替换，不把三条路径除以3。它与其他专家同宽（1024），新增3,145,728参数；down 权重从0开始，初始预测与基线完全一致。配对模型原专家、router与样本顺序逐项相同。

沿用冻结 Qwen3-0.6B 第28块完整 hidden、原最终归一化和词表头、原CrossCoder和Tulu缓存。TRAIN 85,548个有效回答预测位置、EVAL 22,446、DEV 10,340。只训练残差专家及普通MoE的router；不训练基础模型或CrossCoder。每模型168步、一轮、有效batch512（末批44）、microbatch128；AdamW和学习率日程完全沿用。新增分支也参与原全局梯度裁剪，所以会记录裁剪系数及各分支梯度/实际更新。

主要判断：固定最后168步，比较同家族、同种子新增common减去baseline的DEV低频feature宏平均NLL。每个原B1低频feature先对其活跃位置取均值，再在有DEV支持的feature之间等权平均。两个种子均为负只称“当前设置的探索性支持”；方向不一致则没有稳定支持；都为正则不支持；缺失/无效配对则证据不足。同步报告整体位置平均和低频位置并集平均，不能混用分母。旧DEV已经看过，不是新确认集。

共同激活分析提前固定：沿用此前只根据TRAIN选出的每个低频feature的8个伙伴和8个频率匹配随机伙伴。按当前位置活跃伙伴数分0、1–2、3–4、5–8四组，报告各家族/种子配对NLL变化，列出feature事件、去重位置和对话数。同位置多个事件不当作独立样本；输入共激活关系在两种训练条件下本来就相同。分析只描述收益差异，不证明原因。

训练后还会在新增common模型上关闭common或只保留common，测冻结预测变化。它回答“训完的模型依赖哪条路径”，不能代替“加分支后重训是否更好”的配对比较。额外容量、计算和优化变化仍是可信解释；这轮不作参数效率或唯一机制结论。

执行先经过CPU静态检查和独立审查；每个远端任务先做真实GPU smoke，检查初始化、标签/计数、梯度、恢复后下一步一致性和TensorBoard，再根据估计时间进入正式训练。每任务活跃时间上限35分钟，GPU实际分配内存/RSS各16GiB，2 CPU线程，输出总量16GiB上限。失败保留证据，不自动重试、不换资源。正常latest/final包含优化器、随机状态、顺序和游标；CLI尚无自动续训入口，异常快照不能未经核对就续训。最后登记实际保存的checkpoint。
