本轮问题是：固定表征、名单、预算时，评分校准是否改变实际接收，并改善留出 NTP 学习。S1 是预先指定主方案；S2/S3 是本次追加、训练前登记的扩展。

1. B−A 区分同一 T 名单的组尺度校准；B−C 比较 T 与固定 R11 在相同 S1 下的整体组织。负载和曝光是策略结果，不能仅凭 B 优于 C 将收益唯一归因于同频。
2. 接收上升、输入频率更接近、学习改善是三个不同观测。所有安全数值条件都训练；不存在按覆盖筛掉负结果的门槛。
3. 原 z 与第28层解码幅度在训练前后不变。旁支改变末层输出，不能画成原子激活被重新学到。共享 z 来自14层冻结教师，路由有额外教师计算成本。
4. EVAL 来自与 TRAIN 不同 bin，但文档去重未知、该窗口此前已被查看。两训练种子与块 bootstrap 只提供本设置下描述性证据，不能称独立总体确认。
5. 目标留出场景的背景模型排除目标命中位置更新，统计仍可见其无标签特征。它不是真正从未见的知识；推荐只用 TRAIN，回顾性最佳归属不能冒充已部署算法。
6. 旧 φ 名单调整曾改变名单而没有改变实际路由。本轮不训练 φ 副本，不能将 T 学习结果称为 φ 的学习效用证据。

竞争解释包括：曝光分散而非同频组织；统一标量归一化下旁支优化；当前缓存上的泛化；专家输出幅度差异。功能探针固定同一输入，参数谱与响应谱仅辅助解释。科学批准与更大路径的状态保持 Unknown。

实现修复仅限本轮：旧 SCO 客户端忽略 API 新增的非资源字段；TensorBoard 使用 Python protobuf 实现避免环境 ABI 冲突。旧实验文件不改。
