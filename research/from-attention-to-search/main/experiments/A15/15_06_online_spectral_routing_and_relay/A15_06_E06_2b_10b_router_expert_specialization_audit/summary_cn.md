# 结果摘要：Router 是否真正利用了专家专业化？

主 Anchor：[A15_06_02 Router--Expert 专业化](../../../../problem_anchors/15_spectral_representation_and_functional_routing/15_06_online_spectral_routing_and_relay/subanchors/15_06_02_router_expert_specialization_anchor_cn.md)  
冻结 Protocol：[protocol_cn.md](protocol_cn.md)  
完整证据账本：[detailed.md](detailed.md)  
证据资格：**可用于单 seed、冻结 checkpoint、2B--10B 范围内的机制判断。**

## 一句话认识更新

> 五组模型的专家已经对同一输入产生不同且有损失后果的功能，但 Router 只利用了其中一部分；按 covariance 排出的 H/M/T 并不比同维随机子空间更能预测“哪个专家对当前 token 更好”。

正式裁定为 **`mixed_not_supportive`**：存在局部有利点估计，但没有一条 HMT 路径同时通过两个预注册功能指标。

## 我们究竟测了什么？

对同一个 token、同一层，冻结模型后依次把八位稀疏专家各执行一次，并读取下一词损失。这样得到“如果此处换成专家 \(e\)，当前 token 会付出多少损失”的反事实表。

**选专家遗憾**是原生 Router 所选专家的损失，减去八位专家中最低的损失：

\[
r=L_{selected}-\min_e L_e\quad\text{nat/token}.
\]

- \(r=0\)：Router 恰好选到当前反事实最优专家；
- \(r=0.3\)：相比最优专家，当前选择让该 token 多付出约 0.3 nat 的下一词损失；
- 数值越低越好，但它只描述一次局部替换，不代表长期训练收益。

**分数—效用秩相关**比较八个 Router 分数与八个专家的负损失：正值表示 Router 越偏好的专家通常越有即时效用；1 表示排序完全正确，0 表示没有单调排序关系。它比只看 top-1 更严格。

## 专家有没有真正分化？

有，而且证据不是只看参数不同。

1. **同输入 CKA 为 \(0.326\)--\(0.335\)。** CKA 比较两位专家对完全相同的 8,192 个输入所形成的样本关系几何；1 表示几乎相同，0 表示没有共同关系结构。本实验均值远低于 1，第三、四层的逐层均值约 \(0.24\)--\(0.32\)，说明深层专家输出尤其不同。
2. **强制专家后的 NLL 标准差为 \(0.467\)--\(0.505\) nat/token。** 换专家会真实改变下一词损失，低 CKA 不是只有坐标变化而没有决策后果。
3. **oracle 专家不是一个全局赢家。** 最优专家的归一化熵为 \(0.996\)--\(0.997\)，最大专家只赢 \(14.5\%\)--\(15.5\%\) 的目标，接近八专家均匀参考 \(12.5\%\)；不同 token 确实需要不同专家。
4. **Router 有效但不充分。** Router 选中反事实最优专家约 \(34\%\)，高于机会水平 \(12.5\%\)；分数—效用相关为 \(0.130\)--\(0.162\)，说明它学到部分效用结构，但还有很大 headroom。

![专业化证据梯](figures/figure2_specialization_ladder.png)

这张图不能只看一个面板：参数主子空间仍高度共享，同输入输出已经分化，换专家也会改变损失，但 Router 对效用排序仍然有限。最重要的结论不是“专家没分化”，而是“Router 的坐标没有把已有分化充分转化为正确选择”。

## CKA 的理论意义

设两位专家对同一组 \(n\) 个输入的输出为中心化矩阵 \(X,Y\)，线性 CKA 为：

\[
\operatorname{CKA}(X,Y)=
\frac{\|X^\top Y\|_F^2}
{\|X^\top X\|_F\,\|Y^\top Y\|_F}.
\]

它比较的是“哪些样本彼此相似”这一几何，而不是逐坐标相减。正交换基或整体缩放不会改变 CKA，因此两位专家仅仅使用不同坐标表达同一几何时仍会得到高 CKA。低 CKA 表示它们重新组织样本关系，但不自动表示更有用：也可能是噪声、尺度非线性或无关变化，所以必须与本实验的替换损失和 oracle 多样性一起读。

本实验给出的组合判断是：**低 CKA + 明显替换代价 + 高 oracle 熵**，支持“专家具有 token 条件化的功能差异”；它仍不能证明这些差异具有可命名的语义职业。

## PCGrad 是否有效？

PCGrad 不是 checkpoint 指标，而是训练时的梯度干预，因此本实验没有执行它，也不能给出本模型上的有效性结论。

若语言模型损失梯度为 \(g_{LM}\)、负载均衡梯度为 \(g_{LB}\)，当
\(g_{LM}^{\top}g_{LB}<0\) 时，两者在一阶上冲突。PCGrad 把冲突梯度投影到另一梯度的法平面，例如保护 LM 目标时：

\[
g_{LB}^{\perp}=g_{LB}
-\frac{g_{LB}^{\top}g_{LM}}{\|g_{LM}\|^2}g_{LM}.
\]

投影后 \(g_{LB}^{\perp\top}g_{LM}=0\)，负载目标仍可沿不伤害 LM 的一阶方向更新。它的理论价值是把“目标本身冲突”与“仅仅梯度尺度不平衡”分开，并提供一种局部的一阶修复。

但 PCGrad 并不保证长期更优：高阶曲率、AdamW 预条件、多个参数组、离散 top-1 反馈和被删除的冲突分量都可能改变结果。对本模型，只有 Gate 和产生 Router 输入的上游参数同时接收 LM/LB 梯度；专家 MLP 参数并不直接接收 Switch LB 梯度。因此在实测 \(g_{LM}\) 与 \(g_{LB}\) 的分组余弦、范数比和一步损失变化之前，不能说 PCGrad 有效，更不能用当前 CKA 结果替代梯度证据。

## 最终认识边界

**可以说：** 专家已形成有下一词损失后果的功能差异；Router 部分知道哪个专家更好；在 seed17、2B--10B 与冻结局部干预下，covariance H/M/T 身份没有超过匹配随机子空间。

**不能说：** 专家没有语义专业化；随机路由普遍更优；CKA 下降导致了模型质量；H/M/T 永远无效；结论跨 seed/规模成立；LB 梯度必然冲突；或 PCGrad 会改善训练。

**唯一下一决策：** 不继续后验调 H/M/T，而是先让 A15_07 的 conditional-fine 方向通过跨表达语义证书，再用同一套专家遗憾与分数—效用指标做独立功能准入；A16 的 PCGrad 资格需要另一份 raw-gradient Protocol，不由本实验启动。
