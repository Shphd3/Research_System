# H2 待批配置（一页）：新 expert 收哪些 token，决定它能学多快

状态：**NOT RUN，待研究者批准**。本页是配置草案，不是批准，也不是 Protocol 冻结稿；执行前需按 `docs/execution_envelope.md` 解析资源与镜像，并按 `docs/training_observability_contract.md` 补全遥测。

## 问题与假设

H2：分工有用，是因为它把同一条长尾信息的信号集中到同一组参数，并挡住无关 token。对目标 feature i，记覆盖率 c = P(进入新 expert | i 激活)，纯度 π = P(i 激活 | 进入新 expert)。一步更新的信号随 c·N_i 增长，无关 token 只贡献噪声，所以 SNR_i ∝ c·π·N_i·μ²/σ²。R02 测得的 η\* ∝ n（近似）给出可检验推论：**集中策略的可用学习率更高，收益随 c·π 单调。**

如果对：收益与 c·π 秩相关为正；按频率分组不胜过等量随机；集中策略的最优学习率高于随机。如果错：收益与 c·π 无关，或随机与集中相同，或频率分组同样有效（说明作用的是频率，而不是共同出现）。

## 设置

- 起点：33B MoE（`checkpoint_family_moe_baseline_saved_20261104`，token_033000000000），全部原参数冻结，load bias 冻结。
- 干预：block 7 新增第 9 个 expert，结构与原 expert 相同（1024→1536→1024，SwiGLU），**零初始化 down 投影**（其余按原 initializer_range=0.02），从而起点函数与原模型逐位一致；新 AdamW（β=(0.9,0.95)，wd=0）。
- 分发：新 expert 作为额外的第 3 条路径，按策略给出的 token 集合接收，gate 权重固定为该位置原 Top-2 权重的均值（避免 router 学习混入）。唯一自变量是“收哪些 token”。
- 四种策略，token 总数、步数、学习率完全相同：
  1. **共激活簇集中**：R02 冻结的 DEV 共激活簇（同一 SAE 字典、同一聚类规则）中预选的若干簇；
  2. **等量随机**：同 token 数的随机位置；
  3. **按频率分组**：按 token 上激活 feature 的参考频率分层，取与 (1) 等量的低频层；
  4. **打乱簇标签**：保留 (1) 的簇大小，簇标签在 token 间随机置换。
- 学习率：每策略 3 个，{1e-4, 3e-4, 1e-3}（原训练 lr=3e-4）。
- 数据：DCLM `dclm_pair_v1` 的未用于 33B 前缀之后的训练流片段（待确认），评估用 global-shard_02 留出；按文档划分，近重复同侧。

## 读数

- 事前：对每个目标 feature（DEV 上定义，支持 ≥ 预设下限），在训练 token 集上算 c、π，以及 c·π·N_i。
- 事后：该 feature 支撑集上**留出 token** 的 NTP 下降量（nat/token），相对冻结原模型。
- 同时报告全体留出 token 的 NLL（通用能力不受损的检查）与新 expert 收到的 token 数。

## 判据（预设）

- 支持：(a) 收益与 c·π 的 Spearman 秩相关 >0，家族 bootstrap 区间下界 >0；(b) 频率分组不胜过等量随机（差值区间包含 0 或为负）；(c) 集中策略的最优学习率 ≥ 随机策略的最优学习率，且在最高学习率下集中策略不发散而随机策略的收益下降。
- 削弱：(a) 不成立，或打乱簇标签与集中相同。
- 不足：feature 支持不够或区间覆盖效应。

## 资源与停止规则

- 4×H100 reserved；4 策略×3 学习率=12 条轨迹，每条 500 步×262,144 token（≈0.13B token）。主干冻结，只需对 block 7 与输出层反向，成本以前向为主。按 R02 实测 MIG 3g 前向 40.8k token/s 推到整卡约 9 万 token/s（粗估，未在整卡实测），单条约 25–30 分钟，4 卡并行共约 1.5 小时；单种子。若需 2,000 步，总时长约 6 小时。
- 停止：任一条 loss 非有限或 2× 初值即停该条并记录；全体留出 NLL 恶化 >0.01 nat 记为“伤通用能力”，不停止其他条。
- 对照：零初始化等价性检查（步 0 输出与原模型逐位一致）；每 200 步存档、外部进程恢复检查；遥测按观测契约。
