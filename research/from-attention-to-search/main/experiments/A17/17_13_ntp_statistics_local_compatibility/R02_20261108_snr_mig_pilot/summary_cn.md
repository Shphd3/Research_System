# R02 结果：一步更新中的均值项与噪声项（33B MoE 末层单 expert，MIG 先导）

[English](summary.md) · [Detailed](detailed_cn.md) · [执行契约与修订](protocol_cn.md) · [Anchor](../../../../problem_anchors/17_shared_and_interference_learning/17_13_ntp_statistics_local_compatibility/17_13_ntp_statistics_local_compatibility_anchor_cn.md) · [H2 待批配置](h2_4xh100_config_NOT_RUN_cn.md) · [记忆实验诊断设计](memory_diagnostic_design_NOT_RUN_cn.md)

执行：2026-11-08，本机 H100 MIG 3g.40gb，GPU 墙钟约 10.4 分钟；无训练、无续训、模型/SAE/load bias 未改。研究者科学判断：**Unknown**。下文解释为 AI 分析。归属说明：本轮按研究者指示归入 A17 线；放在 A17_13 之下是 AI 的归类选择（该 Anchor 的数学模型已区分“有符号均值需求”与梯度协方差），待研究者确认。

## 一句话结论

**噪声项的标度按预测出现：一次 SGD 更新对另一组数据的“噪声伤害”随 η² 增长、随 batch 大小 n 约按 1/n 下降，并在 η 超过交叉点后迅速压过均值项（n=32、η=1/4 时约 17 倍；n=128、η=1/2 时约 9 倍）。跨组“均值帮助”在主比较对上小到无法与零区分（z=1.28），所以“帮助在 η\* 处翻转为伤害、η\* 随 n 右移”只得到推导和事后估计的相容证据，没有在预先的网格内被直接观测到。** 按冻结判据，H1 的噪声部分支持；翻转部分不足；“方向冲突是主因”的削弱条件没有出现。

## 1. 目的与问题

导师 11/6 提出：稀疏导致信噪比低，信噪比高时可以加大学习率。本轮要把这句话变成一个可测的分解：一次更新对另一组数据 B 的影响，有多少来自“方向”（帮助或冲突），有多少来自“噪声”（小 batch 梯度的随机误差）。

## 2. 必要模型

对象：33B token 的 8 层 MoE（d=1024，8 expert，Top-2）。只让末层（block 7）expert 7 的 FFN 参数做一步纯 SGD，其余全部冻结，路由与 load bias 保持原生。

记号：A 的一个 minibatch 含 n 个 token；ḡ_A 是 A 的平均梯度；Σ_A 是单 token 梯度协方差；g_B、H_B 是 B 留出损失的梯度和 Hessian。用单个 minibatch 梯度 ĝ_A 走一步 −ηĝ_A 后，

E[ΔL_B] ≈ −η g_B·ḡ_A + (η²/2) tr(H_B Σ_A)/n + (η²/2) ḡ_Aᵀ H_B ḡ_A。

第一项是“迁移/干扰”，符号由方向决定，正比于 η；第二项是“噪声”，总是伤害，正比于 η²/n。若第一项是帮助，存在交叉学习率 η\* = 2 g_B·ḡ_A / (tr(H_BΣ_A)/n + ḡᵀHḡ)，超过它帮助翻转为伤害；当噪声主导分母时 η\* ∝ n。

测量：均值分支 ΔL_B(−ηḡ_A)；噪声分支为 R 次独立单 batch 更新的平均 ΔL_B(−ηĝ_A)；两者之差估计噪声项。

## 3. 假设与预先判据

H1：长尾学得慢，主要是信噪比低，不是方向冲突。支持需同时满足：噪声项为正；对 log η 斜率约 2，对 log n 斜率约 −1（预设窗口 [1.6,2.4] 与 [−1.4,−0.6]）；跨组帮助在 η\* 翻转且 η\* 随 n 右移；效应超过零更新底噪与重复间区间。削弱：噪声项不随 η²、1/n 变化，或跨组均值项在所有 η 下都是伤害。

## 4. 设置（一句话版）

S14 的 5589 篇 DCLM 留出文档（每篇 128 token，目标位置 32–126），按文档与近重复组划分 DEV/GRAD/EVAL；只用 DEV 的 SAE Top32 共激活把 expert 7 的 137,386 个位置聚为 8 簇；按冻结规则 B = 最大簇（簇 7），A = 与它质心余弦最低的合格簇（簇 1，余弦 0.28）；B′ = 簇 7 的 GRAD 文档（与 B 文档不重叠）。n ∈ {32, 64, 128}，R = 32，ḡ 来自 ≥32 个互不重叠的 128-token minibatch，η 网格 1/32–4（倍数 2，由 DEV 预检确定，看 EVAL 前冻结）。

## 5. 结果

### 5.1 控制项全部通过

零更新的 ΔL 精确为 0；同一参数重复评估逐位相同；每个分支后恢复的参数与快照 `torch.equal`；float64 尾部与原生 fp32 前向的单 token CE 最大差 3.1×10⁻⁵ nat；原模型参数版本号与 load bias 不变。

### 5.2 噪声项按 η² 与 1/n 标度

![噪声项标度](figures/fig1_noise_term_scaling.png)

读图：纵轴是噪声项（平均单 batch ΔL_B 减去均值梯度 ΔL_B），只画区间下界 >0 的点；三条线近乎平行且斜率接近虚线 2，n 每翻一倍整体下移约一半。

| 比较 | n | 对 log η 斜率 [95% 区间] | 对 log n 斜率（η=1）[95% 区间] |
|---|---|---|---|
| 跨组 A→B | 32 / 64 / 128 | 2.06 [1.70, 2.61] / 2.04 [1.86, 2.34] / 1.95 [1.77, 2.32] | −1.18 [−1.83, −0.26] |
| 同组 B′→B | 32 / 64 / 128 | 2.17 [2.09, 2.32] / 2.01 [1.95, 2.11] / 2.02 [1.91, 2.22] | −0.99 [−1.25, −0.74] |

由梯度本身也能独立看到 1/n：E|ĝ|² − |ḡ|² = trΣ/n，三个 n 推回的 trΣ 基本恒定（A：41/45/39；B′：215/214/202）。

**为什么会这样。** 单 batch 梯度 = 平均梯度 + 零均值误差，误差的方差是 Σ/n。误差在一阶上平均为零，所以它不在第一项里出现；但损失是凸向上的（H_B 正定方向占优），误差走出去的每一步在二阶上都让 B 变差，量级是 (η²/2)·tr(HΣ)/n。这就是“噪声总是伤害、随 η² 增长、随 n 变小”的来源。

### 5.3 信噪比极低：单 batch 梯度几乎全是噪声

| 梯度来源 | \|ḡ\|² | trΣ/n（n=32 / 128） | 单 batch SNR = \|ḡ\|²/(trΣ/n) |
|---|---|---|---|
| A（簇 1，5377 token） | 0.0074 | 1.29 / 0.31 | 0.006 / 0.024 |
| B′（簇 7，9090 token） | 0.0280 | 6.72 / 1.58 | 0.004 / 0.018 |

更关键的是：A 的“平均梯度”本身也在噪声底上。5376 个 token 的均值自带噪声能量 trΣ/5376 ≈ 0.0077，而 |ḡ_A|² 只有 0.0074。B′ 的 |ḡ|² = 0.028，噪声底约 0.024。换句话说，在这个 33B 状态的单个 expert 上，每 token 的可学信号能量大约只有其噪声能量的 2×10⁻⁵（B′ 估计），需要数万个同类 token 才能把信号压过噪声。

### 5.4 均值项：同组大，跨组小到测不出

| 方向（EVAL 上） | g_eval·ḡ | 标准误 | z |
|---|---|---|---|
| 同组 B′→B | 2.73×10⁻³ | 5.2×10⁻⁴ | 5.23 |
| 跨组 A→B（主） | 5.67×10⁻⁵ | 4.4×10⁻⁵ | 1.28 |
| 反向 B′→A | 4.46×10⁻⁵ | 5.9×10⁻⁵ | 0.76 |
| 自身 A→A_eval | −5.38×10⁻⁵ | 6.9×10⁻⁵ | −0.77 |
| 次要跨组：簇 0/2/3/4/5→B | 全为正 | — | 1.48 / 2.45 / 2.86 / 2.36 / 0.27 |

同组均值项约为跨组的 48 倍。6 个跨组对的一阶项点估计全部是“帮助”，3 个 z>2；没有一个是伤害。均值分支在小 η 下与一阶预测一致（η=1/32：实测 −1.733×10⁻⁶，预测 −1.770×10⁻⁶）。跨组均值分支在 η≤1 时为帮助，η≥2 时转为伤害（二阶 ḡᵀHḡ 接管）。

反例与需要正视的事实：DEV 预检中同一 X→Y 的均值分支是**伤害**（η=1/16 时 +4.8×10⁻⁶），EVAL 上是帮助。符号随数据切分翻转，正说明这个均值项在噪声底上；A 自己的均值步也没有改善 A 的留出 token（z=−0.77）。

### 5.5 帮助→伤害的交叉点 η\*

![交叉点](figures/fig2_help_to_harm_crossing.png)

读图：橙线是用平均梯度走一步，始终在 0 以下（帮助）；蓝线是单 batch 一步的期望效果（事后控制变量估计），n 越大，穿过 0 的位置越靠右。

- **预先估计量（网格内直接观测）：**跨组单 batch 平均 ΔL_B 在任何 η 都没有显著为负，所以没有直接观测到翻转点。原因是帮助只有约 10⁻⁶ nat，R=32 的分辨率约 ±5×10⁻⁶。按判据，这一项为“不足”。
- **事后控制变量估计（A01，看过主表后加）：**每次抽样的一阶项可精确算出，扣掉后再加回均值的一阶项，方差大降。跨组 η\*：n=64 为 0.042，n=128 为 0.075；n=32 低于网格下限。同组 B′→B：n=128 为 0.040。
- **推导值（由测得的两项代入公式）：**跨组 η\* ≈ 0.018 / 0.036 / 0.057（n=32/64/128），同组 ≈ 0.016 / 0.022 / 0.048。η\* 随 n 右移，近似 ∝ n^0.8。

注意：控制变量估计和推导值都以测得的跨组均值投影为前提，而这个投影本身 z=1.28。

### 5.6 预测“跨组噪声占比更高”没有出现

在同一 η 下，噪声系数与帮助的比值（c_n / g_B·ḡ，n=32）跨组约 108，同组约 125；两者的 η\* 也几乎相同（0.018 vs 0.016）。原因：同组的 B′ token 损失高（4.30 vs 1.59）、gate 权重高（0.49 vs 0.20），所以它的梯度信号和梯度噪声一起变大（trΣ 约 210 vs 41）。信号和噪声来自同一批高损失 token，比值不会自动变好。

## 6. 判据对照

| 判据 | 结果 | 状态 |
|---|---|---|
| 噪声项 > 0，超过零更新底噪 | η≥1/8 起区间下界 >0；零更新 ΔL=0 | 通过 |
| η 斜率 ≈ 2 | 12 个 (来源, n) 组合均在 1.95–2.35 | 通过 |
| n 斜率 ≈ −1 | η=1/16–2 下点估计 −0.77 至 −1.39；η=4 时同组变陡到 −1.28、反向 −1.58（高阶项） | 基本通过 |
| 跨组帮助在 η\* 翻转、η\* 随 n 右移 | 网格内直接观测不到；事后估计与推导相容 | 不足 |
| 削弱：均值项在所有 η 都伤害 | 未出现（EVAL 上 η≤1 帮助） | 未触发 |

**H1 状态：部分支持（AI 判定）。** 噪声机制成立且主导；“跨组帮助被噪声翻转”只到推导与事后估计。研究者判断 Unknown。

## 7. 对原认识的更新

- 原来以为：长尾学得慢，主要是因为跨组方向冲突把它的更新抵消了。现在认为：在这个固定状态下，跨组一阶项要么是小帮助、要么测不出，未见显著冲突；真正决定一步更新后果的是噪声项。因为它对所有组都是伤害，且在 η 越过交叉点后很快压过均值项（n=32、η=1/4 时约 17 倍）。
- 原来以为：分组只要把“同类”放在一起就能提高信噪比。现在需要补一个条件：把高损失、高 gate 的 token 集中在一起，信号和噪声会同时变大；能提高 SNR 的是“同一信号被更多 token 重复”（有效 n 变大），不是“同一簇”本身。这是 H2 要在训练中检验的东西。

## 8. 边界

- 一个 checkpoint（33B）、一个 expert、一层、一种 SGD 步；不是 Adam、不是多步训练、不是长期学习速度。
- A 与 B 的初始损失和 gate 权重没有匹配（1.59/0.20 vs 4.30/0.49）；同组/跨组差别混入了难度和 gate 差别。按“不反复换簇”的规则没有重选。
- 簇是 SAE 共激活簇，不是“长尾 feature”；本轮没有直接测低频 feature 的学习。
- η\* 的直接观测需要更大的 R（约 400–1000 次抽样）；本轮 NOT RUN。
- 控制变量估计与 η\* 推导是看过主表后的事后分析，已标为 A01。
