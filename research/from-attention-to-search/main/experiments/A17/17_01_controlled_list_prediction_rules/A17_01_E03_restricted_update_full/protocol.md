## 1. Terminology / Definitions

FIRST returns list position one, LAST position three. Rule prompts differ, so both labels are simultaneously satisfiable. A valid answer is one next token; full-vocabulary cross entropy is nats/answer. Order-new holds out order of a seen unordered group; combination-new holds out the entire unordered group. A recipient effect is after-minus-before loss; negative is help. Effective source learning requires an independent same-rule recipient loss decrease, separately from source training loss.
