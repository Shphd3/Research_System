# Smoke 协议：S7 单处支路训练与分析资格检查

[English](smoke_protocol.md)。研究者在 2026-10-07（北京时间）明确授权：准备并提交包含训练与分析的有限 Smoke，使用 **4 卡 H100 reserved**。此授权独立于仍为 `DRAFT_NOT_EXECUTABLE` 的[正式 Protocol](protocol_cn.md)。本文件不新建 Work／Codex 任务。

## 1. 目的、假设与边界

目的：检查单处 Dense／MoE 支路能否产生可信的两阶段训练、固定 SAE 记录和原生留出损失。工程假设是：输入、可训练路径、检查点、计数和分析满足已声明的恒等式与冻结边界。竞争解释是实现错误：目标多移了一次、SAE 损失仍驱动支路、主干意外可训练、路由梯度错误、恢复失败或后续损失复算不一致。

Smoke **不判断** MoE 是否更少遗忘。每阶段 8 次更新和每任务 8 条开发记录不足以支持正式科学假设。学习改善、旧损伤和 SAE 距离只作诊断输出，不设科学通过门槛。不能据这些效果挑选有利于某架构的正式实用界。

## 3. 架构与可训练路径

冻结 8 层 S7 主干、共享词嵌入／输出头、全部归一化，以及宽度 30,000、Top-K 32 的固定 SAE。唯一可训练支路位于 `blocks[7].attn.o`（2048→1024）。Dense 一对 rank-8 因子、缩放 1/8；MoE 八对独立 rank-8 专家因子，无共享专家。路由器读投影前同一个 2048 维向量，选 Top-1，并保留其 softmax 概率；不读目标或任务标签。

Dense 有 24,576 个可训练因子参数；MoE 有 196,608 个专家因子参数和 16,392 个路由参数，共 213,000。每个位置两组都只调用一对因子，但总容量、路由与优化器成本不同。本 Smoke 记录参数、路由、耗时、显存和 token 暴露量；没有完成全训练 FLOPs 核算，不宣判公平比较的科学胜负。

适配后的专家使用独立参数（`nn.ModuleList`），不同于旧实验的堆叠参数库。将梯度清为 `None` 后，未命中专家可以没有梯度，AdamW 会跳过该参数；若已分配零梯度，动量或衰减仍可改变参数。要检查实际梯度和增量，并分别验证这两种情形。两个阶段所有专家都保持 `requires_grad=True`，不手动冻结旧任务专家。即使某个专家权重不变，路由更新也可能改变旧样本的选择。

精度设置：冻结主干用 BF16 计算；固定 SAE 保留源 FP32 权重；支路、路由权重与优化用 FP32。冻结检查在相同载入精度下与初始状态比较，另保留原检查点身份。这里的原生 BF16 损失变化不能与此前 1002 的 FP32 面板逐值等同。实数运算下的因子乘积恒等式，不代表类型转换和加法舍入后的激活逐值精确相等；实际激活差独立测量，舍入残差另记。

SAE 只在脱离训练梯度的评价中使用。不能加入重构或 AuxK 训练损失，也不能用 SAE 重构替换原生 Attention 输出。输出因子零初始化时应在相同精度下复现冻结模型的 logits 和留出损失。专家输出最初为零时，路由器梯度也可为零；这是合理的首步情形。

## 4. 训练、调度与恢复

四个独立的单 GPU 进程，**不使用 DDP，不跨架构汇总损失**：Dense seed 17、MoE seed 17、Dense seed 29、MoE seed 29。同种子配对数据次序和梯度累积窗口。每进程微批次 2、累积 2，有效批次 **4 条记录**，序列上限 512。统计实际有效答案目标，不能将填充位置都计为目标。

每组先训练 GSM8K 8 次更新，再训练 MMLU 8 次更新。跨阶段延续因子、路由器和优化器状态。AdamW：因子学习率 2e-4、衰减 0.01；路由学习率 5e-4、衰减 0；betas (0.9,0.999)、epsilon 1e-8；所有可训练梯度联合裁剪上限 1。Smoke 使用恒定学习率、无预热，仅用于工程检查。目标为整个累积窗口的有效答案交叉熵总和除以有效目标总数，没有附加目标项。

在新任务第 4 次更新后，保存全部支路／路由权重、优化器、随机状态、采样次序／位置、累计有效目标 token 与更新计数。连续执行一次参考第 5 步并保存结果。从第 4 步检查点启动独立进程，复现第 5 步，核对模型／优化器／随机状态／token 状态，再完成第 6—8 步。恢复不能使坐标回退或事件重叠；必要时使用明确命名的恢复事件段。被丢弃的连续参考只是工程检查，不是额外科学轨迹。

成本：4 组 ×（8 次旧任务＋8 次新任务）＝**64 次逻辑更新**；另加 4 次参考更新，共 **68 次实际更新**。分析和恢复的额外成本另记，不能根据 Smoke 学习曲线选择正式终点。

## 5. 分析资格检查

对同一批 8 条旧任务开发记录，在旧任务训练前、旧任务结束、新任务结束时读数。两任务分别计算按 token 加权的原生答案交叉熵，保留每记录损失总和／有效计数、原生 Attention 输入／输出及路由 ID／概率，记录起点和两阶段状态。不设生成正确率门槛。

同一旧前文的投影输入应保持相同，因为此前计算均冻结。保存 Attention 输出 \(a\)、SAE 编码 \(z\)、重构残差 \(\varepsilon=a-b_{\rm SAE}-Dz\)，检查精确记账关系 \(\Delta a=D\Delta z+\Delta\varepsilon\)。保留前后重构质量和未解释变化；恒等式通过不证明有害稀疏方向。

经过同一残差、完整末层 MLP、归一化和输出头，复算前后原生损失。将整份旧 Attention 输出送回这段冻结计算，检查损失能否恢复；这验证接口，不是已选方向的机制证据。与普通前向比较所用数据类型和数值容差写进冻结配置。可输出一阶损失近似及其相对有限变化的误差，但不能代替有限损失；路由切换不能默认可微。近似精度只报告，不当科学机制阈值。本 Smoke 不做已选方向的移除／恢复科学实验。

## 6. 必须保留的工程证据与停止规则

工程通过要求：提交前 CPU 的结构／零支路／梯度边界检查通过；80 条数据来源清楚；损失和梯度有限；冻结主干／SAE 哈希不变；因子确实更新；路由梯度语义正确；原生后续计算和 SAE 分析完整；独立进程恢复满足注册的精确或容差比较。二者分别记账。

每组写 `arm_run`，并按[可观测性规范](../../../../../../../docs/training_observability_contract.md)记录：`tokens/train_lm_loss`、`updates/train_lm_loss`、`tokens/train_total_loss`、`updates/learning_rate`、`progress/tokens_seen`、`progress/optimizer_step`、`progress/effective_tokens_per_update`。主 token 计数须与至少一次完整更新的独立目标统计相同，只在完成逻辑累积窗口后增加。分别记因子／路由学习率和阶段；不为关闭的正则项伪造训练目标标签。

遇到非有限值、冻结权重变化、错误目标／结构、来源哈希不一致、计数错误、恢复／原生后续复算失败或时间上限，停止并保留明确失败类型的收据。实现失败不是架构科学负结果；没有损失下降本身也不是 Smoke 失败。
