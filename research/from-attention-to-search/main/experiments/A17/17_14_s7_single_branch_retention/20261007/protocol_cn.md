## 1. 对象与术语

把两矩阵乘积按固定系数加到一处冻结线性投影上，称为 **LoRA 低秩支路**。Dense 对所有位置使用一对因子；MoE 保存多对，由**路由器**根据当前前文算概率，每位置选一个专家。选择规则不等于为数据集永久指定专家。

**习得**是同一任务留出预测损失在自身训练阶段的改善。**保持／损伤**是继续学另一任务时，同一旧任务损失的变化；升高表示损伤，降低仍保留为改善。**参考前文预测（teacher forcing）**把此前参考答案给模型作前文，再评分下一个参考 token，不能等同于独立生成答案。

固定 **SAE** 将 Attention 输出编码为少量非零坐标，再重构供分析。其权重、重构损失及编码不驱动支路训练。**直接任务梯度**指当前小批次的导数，还未经过动量或衰减；没有直接梯度，不一定代表参数不动。

## 2. 与 Anchor 的对应

阻塞问题是：当前架构尚无合格的顺序学习比较。AI 提案先学 GSM8K，再学 MMLU，在每个边界评价同一留出记录。结果若有利，支持完整架构的预测保持差异，才值得另行检验机制；它不会把差异唯一归因于路由。

根本目的已确认；数据、无重放、插入点及精确判断规则仍为 `AI_PROPOSAL`。本草稿不重置已有问题，也不把旧混合训练说成已经回答当前问题。

## 3. 被检验假设

在注册的新阶段计算预算终点，MoE 旧损失增加更少，同时新任务改善量和最终损失均满足注册的不劣要求。两组必须先学到旧任务，Dense 必须出现有意义的旧损伤，才谈得上减轻遗忘。起始损失不同，改善更多不等于最后更好。

令架构 \(a\) 的新任务改善为 \(G_{{\rm new},a}\)，旧损伤为 \(F_{{\rm old},a}\)。保持差异 \(D_F=F_{{\rm old},Dense}-F_{{\rm old},MoE}\)，正值有利于 MoE。终点新质量差 \(Q_{\rm new}=L_{{\rm new},2,MoE}-L_{{\rm new},2,Dense}\)，正值表示 MoE 最后更差。学习、损伤和两项不劣边界均 **BLOCKED，待研究者判断**，不能从 Smoke 效果中挑选。

## 4. 竞争解释

| 解释 | 本轮如何防止误判 | 仍不能排除什么 |
|---|---|---|
| MoE 新任务学得少 | 最低学习改善＋改善量和终点损失的不劣要求 | 边界需有实用意义；交叉熵不等于生成能力 |
| 计算或数据暴露不同 | 单列计算账、输入／有效目标 token 曲线，有效批次固定 | 相同 FLOPs 可能看不同数据，不能同时声称 token 也相同 |
| 旧阶段能力起点不同 | 报告共同底模和各组旧阶段终点损失／习得 | 独立训练后的状态不会完全相同；过大差异使归因不足 |
| 存储容量更多 | 分别报告总存储和每位置活跃参数 | 两组比较不能唯一分离容量与路由 |
| 保留概率令支路更弱 | 记录被选概率、支路位移和因子增量 | 这些诊断不能代替新学习要求，也不能排除优化差异 |

SAE 重合、表征距离和专家使用率仅为描述记录，不能挽救主要结果。

## 6. 学习任务与允许的信息

模型接收题目、提示及此前参考答案 token，预测下一个参考答案 token。提示、填充和缺目标位置不计损失。任务身份仅调度和报告使用，不输入路由器；未来答案 token 不能进入路由。

候选分词器使用检查点对应 Qwen3 身份，不能加载其预训练模型权重；长度上限提案 512。目标**已经移位**：位置 \(t\) 对应输入 \(t+1\)，末位及非答案目标为 `-100`。核查移位、题目／答案边界、截断后有效答案；排除规则与各任务数量须冻结。MMLU 短标签和 GSM8K 推理答案监督长度不同，必须报告，不能默默当作同一训练量。

## 7. 模型架构与冻结对象

研究者确认主干体系及固定分析 SAE。**AI_PROPOSAL：**使用精确预训练 33,000,000,000 token 的 fresh S7 检查点，而非 330 亿参数模型：`/data/250010109/MoE_Router/experiments/20260920_s7_lambda0p1_from_scratch_4h100/runs/S7_lambda0p1_from_scratch_4h100/milestones/token_033000000000/state.pt`，SHA256 `c30b78e5bcba8f0a09c5e215389be86778874e87fcbb9fe5211175d370bb0803`。只加载模型／SAE 权重，后训练优化器新建。

主干 281,431,040 参数、8 层、隐藏宽 1024、末层 Attention 投影输入 2048。SAE 61,471,024 参数、宽 30,000、Top-K 32。两阶段均冻结主干、归一化、共享嵌入／输出头和 SAE。SAE 读取加入支路后的 Attention 输出、残差加入前的向量，只作脱离梯度的分析，不替换原生激活。

插入提案 `blocks[7].attn.o`，秩 \(r=8\)、专家数 \(E=8\)、固定缩放 \(s=1/8\)。Dense：\(W_Oc+sBAc\)；MoE：\(W_Oc+p_k sB_kA_kc\)，其中 \(p=\operatorname{softmax}(Rc+b)\)、\(k=\arg\max_jp_j\)，\(c\) 为 2048 维。保留被选概率，无共享专家、无归一化到 1、无离散索引直通估计。初始化提案沿用 Smoke：输入因子在 \([-1/\sqrt{2048},1/\sqrt{2048}]\) 上均匀，输出因子为零；路由权重为标准差 0.01 的正态初始化，偏置为零；精确并列取首个最大值。最终采纳规则须冻结。只有有效答案位置贡献注册交叉熵梯度；提示位置被路由，不等于该位置直接训练专家。

Dense 因子 \(A:8\times2048\)、\(B:1024\times8\)，共 24,576 参数；MoE 八对共 196,608 因子参数，加 16,392 路由参数，总共 213,000。每位置只活跃一对因子，路由和优化器成本不同。两个阶段允许全部因子／路由更新，不冻结旧任务专家。候选独立专家参数不同于旧堆叠库：未选参数 `grad=None` 时 AdamW 跳过；已分配零梯度仍可能产生动量／衰减增量。直接梯度和实际增量分别记录。

## 8. 训练目标与优化

唯一目标提案：整个完成的梯度累积窗口中，有效答案交叉熵总和除以有效答案目标总数，用自然对数；不能平均分母不同的小批次／各卡均值。没有 SAE 重构、AuxK 或负载平衡目标，新增目标须重审 E 和结论。精度提案：冻结主干 BF16，SAE 保留源 FP32，支路／路由权重和优化 FP32。实数更新恒等式与机器实际激活／损失差分开；不与此前 1002 FP32 面板逐值等同。

AdamW 提案：因子学习率 2e-4、路由 5e-4；betas (0.9,0.999)、epsilon 1e-8；因子衰减 0.01、路由 0；联合梯度范数裁剪 1。它们明确改编自 E20 后训练，不继承 S7 预训练设置。正式预热／衰减、有效批次和阶段预算 **BLOCKED**，待 Smoke 成本记录与研究者审核。Smoke 恒定学习率只作工程检查。

跨任务提案延续因子／路由优化器状态，不能通过重置动量抑制旧专家变化。检查点包含因子、路由、优化器、调度、随机状态、数据位置、token 与更新计数。科学 token 轴只在完整窗口后增加；跳过更新显式记录。

## 9. 条件、种子与检查点

两组主要条件：Dense 一条 rank-8 支路；MoE 八个 rank-8 专家、可训练 Top-1 路由。种子提案 17、29、43，相同种子配对阶段数据次序，共六条轨迹／十二个阶段，不是十二个独立种子。正式 GPU 资源、壁钟与成本上限尚未授权。

保存并评价零支路共同起点、旧阶段终点及事先注册的新阶段有效目标 token 检查点。主要比较用冻结计算预算终点，配对 token 曲线辅助理解。不能按确认集最佳损失挑检查点。精确检查点网格和预算取整规则在提升前 **BLOCKED**。

## 10. 主要指标与分析规则

对固定任务 \(d\)、检查点 \(t\)、架构 \(a\)，留出损失为

\[
L_{d,t,a}=\frac{\sum_{i,u}m_{i,u}[-\log P_{t,a}(y_{i,u}\mid X_{i,u})]}{\sum_{i,u}m_{i,u}}.
\]

\(i\) 为固定题目记录，\(u\) 为答案预测位置，\(m\) 标记有效目标，\(X\) 仅含此前 token。它是经验留出总交叉熵，nat／有效 token，不是训练误差或超额风险。保留每题损失总和与计数，按 token 加权，不能平均每题均值。

记录旧任务习得 \(G_{{\rm old},a}=L_{{\rm old},0,a}-L_{{\rm old},1,a}\)、新任务习得 \(G_{{\rm new},a}=L_{{\rm new},1,a}-L_{{\rm new},2,a}\)、旧损伤 \(F_{{\rm old},a}=L_{{\rm old},2,a}-L_{{\rm old},1,a}\)、配对保持差异 \(D_F\) 和第 3 节终点质量差 \(Q_{\rm new}\)。阶段 0 为共同底模、1 为旧阶段结束、2 为新阶段结束。前后采用相同题目和掩码，负损伤不能截成零。

区间提案：以整道题为单位配对重采样，保留题内全部答案 token，同种子架构／检查点配对。分别报告每个种子和配对种子差异。95% 整题区间只对已训练状态成立，不能代替训练种子不确定性。种子区间／检验、重采样数、多重比较和精确单侧／双侧规则 **BLOCKED**，待批准。只有一个主假设，描述指标不能事后提供另一种胜利标准。

缺失或失败组使比较证据不足，不能按结果换种子或删离群值。只评价冻结终点。最低旧／新习得、旧损伤、保持收益、新改善量与终点损失不劣界、允许起点差异均 **BLOCKED**；正式评价效果出现前冻结，不能从 Smoke 中选有利阈值。

## 11. 次要读数与保护条件

记录总／存储／活跃参数、优化器状态大小、输入／有效答案 token、序列／填充数、路由位置、专家直接梯度和实际增量、被选概率、支路／输出位移范数、耗时／显存。正式完整算量核算须列前向、下游反向、路由、活跃因子和优化器 FLOPs，以及测量遗漏。GPU 壁钟是系统效率，不等于科学计算坐标。当前 Smoke 只记录成本与暴露，没有完整 FLOPs 核算，正式计算对齐仍受阻。

同一旧记录保存投影输入 \(c\)、输出 \(a\)、SAE 编码 \(z\)、残差 \(\varepsilon\)、logits／损失和原生后续复算误差；检查 \(\Delta a=D\Delta z+\Delta\varepsilon\)，保留前后重构质量。该关系在实数记账中精确，机器检查用注册容差。它只验证分析，不证明有害子空间；编码移动不能替代损伤，残差大可说明工具覆盖不足。

本正式协议不包含 SAE 方向选择、移除或恢复科学条件。以后若提出，要分开候选选择与效果评价数据，设置维数／幅度随机对照，并说明激活干预不等于可实现的参数方法。

## 12. 已知正确、错误与易混情形

正确：输出因子零初始化复现同精度原生冻结模型；检查点不变时损失／激活差为零。错误：多移一次目标、非答案位置有目标、未来 token 泄漏或 SAE 损失梯度，必须被识别并阻断资格。

易混：零输出因子起点可以令路由梯度为零，不是路由失败；未命中专家可无直接梯度，但分配零梯度时仍可由动量／衰减改变；任务 token 数不同，混合均值可改变而各任务读数未改善。独立 Smoke 检查这些情形，不赋予科学结论。

## 15. 支持、不支持与证据不足

**支持：**计算／数据保护条件通过；旧新习得满足批准标准；Dense 旧损伤有意义；MoE 新学习及终点质量符合批准不劣规则；注册不确定性支持有实用意义的正 \(D_F\)。

**不支持：**合格比较可靠排除该注册优势。旧损伤不存在意味着当前遗忘现象未成立，不能编造架构负结论。
