# A17_04_E01：同向与反向条件映射

执行与测量已完成。注册结果为 `INSUFFICIENT_OLD_MAPPING_NOT_ACQUIRED`：旧映射没有达到本轮学习资格。机制接受与问题关闭仍为 `Unknown`。

## 目的

判断新任务的条件预测映射改变时，共享学习对旧任务的作用是否改变。我们先识别任务关系何时产生学习代价，再决定是否值得分开参数。

## 模型

实际模型是登记的 Qwen3-0.6B Base，只训练最后一层 Attention 的输出投影 `model.layers.27.self_attn.o_proj.weight`，其余权重冻结。输入含可见模式、中性口令和三词列表。模式一教甲取首项、乙取末项；模式二分别保留或反转映射。例如 `红 蓝 绿`：模式一甲应输出红，反向模式二甲应输出绿。模式可见，所以两套映射在同一实验世界内没有矛盾标签。

三个训练顺序 seed 都先训练旧模式 240 步，再从各自相同旧终点分出同向／反向新训练。所有 seed 使用相同预训练权重，不是三套随机权重初始化。每对分支的新输入、答案边际、批次顺序和 4,800 个答案目标相同，只改标签。训练用答案 CE 和普通 SGD。联合反向分支额外提供旧监督，只作可行性检查，不是等监督性能比较。

旧答案优势是正确端点词的 log 概率减去另一端词的 log 概率。主效应是反向变化减同向变化。负差只表示反向带来较少收益；净损害还须相对共同起点绝对恶化。并列测 CE、全词表准确率、最强竞争词和列表三词内部选择。输出对比是预测坐标，不是内部参数模块。

## 假设

相同新曝光后，反向映射可能比同向更降低旧规则答案优势。最强竞争解释是难度、初始能力或学习路径不同。一般候选词适应与更新幅度也仍可能解释差异。同范数探针、可比学习点和联合训练分别约束这些解释，但不识别完整参数机制。

## 结论

1. **本轮不能判断“熟练学会的旧映射是否被新任务损害”。** 旧终点 DEV 每口令／分项准确率只有 33%–54%，三个 seed 都没有通过预设 80% 资格；旧 TEST 准确率为 49.75%。训练和测量全部完成，但科学问题的结果是证据不足。这不证明模型什么都没学，而是本轮没有建立“旧规则已经充分学会”的起点。
2. **反向只有一个小的相对代价，没有出现平均旧 CE 或答案优势的净损害。** 主效应为 −0.005165 nat，三个 seed 都负，但小于操作报告约定的 0.01 nat 幅度。同向与反向都改善旧平均 CE。这些是在不充分学习的映射上的变化，不能说反转损害了已掌握的旧规则，更不能推出必须分开专家。
3. **正确词 CE 的收益主要由列表候选总概率提高解释。** 两分支的旧列表访问 CE 都改善，合并的候选内部选择 CE 反而略变差。因此，本轮 CE 改善不能被称为已确立的共享规则学习迁移。这是精确输出账本支持的有限解释，不是唯一内部原因已经识别。

下列主值和诊断均来自[注册分析](/data/250010109/MoE_Router/experiments/20261011_a17_conditional_mapping_transfer/runs/mapping_20261011T095038Z/analysis/results.json)。科学机制接受仍由研究者判断。

## 分析

旧终点是全部继续分支的共同基线。下表是在每 seed 相同 800 个旧 TEST 答案上计算，再对 seed 和两种未见分项等权汇总。CE 越低越好，答案优势越高越好。

| 旧 TEST 指标 | 旧终点 | 再学同向新映射 | 再学反向新映射 |
|---|---:|---:|---:|
| 正确词 CE，nat | 1.120444 | 1.038598 | 1.041736 |
| 准确率 | 49.7500% | 49.7083% | 49.9583% |
| 正确端点相对另一端优势，nat | 0.045724 | 0.064280 | 0.059115 |

反向比同向少改善优势，但两者平均优势都上升，损失都下降。三个 seed 的主效应为 −0.005229、−0.005132、−0.005135 nat，样本标准差 0.0000552。这是在一套固定数据上的描述重复，不是总体显著性结论。旧学习资格失败，优先阻止已学规则保持的解释。

| 留出分项 | 反向减同向的旧优势变化，nat |
|---|---:|
| 未见顺序 | −0.001529 |
| 未见组合 | −0.008802 |
| 两分项等权合并，主指标 | −0.005165 |

未见组合上的差异更大，是应保留的描述现象，但它不能修补旧映射没达到资格这个前提。

设三词列表集合为 \(S\)。正确词 CE 精确分为“列表总概率的代价” \(-\log\sum_{w\in S}p(w)\)，以及“正确词在列表内部份额的代价” \(-\log[p(y)/\sum_{w\in S}p(w)]\)。相对旧终点，同向旧 CE 变化 −0.081846 = 访问 −0.086275＋选择 +0.004429；反向 −0.078708 = −0.085028＋0.006319。也就是说，列表总概率提高已经足以解释全部平均 CE 收益，内部选择略差。端点平均优势同时改善并不矛盾：内部选择还包含中项竞争，而且平均的是非线性损失，两量不等价。

新任务 CE 也改善：同向 1.192306→1.078515，反向 1.197546→1.088236；准确率分别 46.75%→47.2083%、46.25%→48.1667%。六条 seed／新世界 DEV 轨迹都没有达到固定的 80% 可比能力门槛，所以可比能力分析不可用。反向模式二的口令响应仍为 +0.005931 nat，而反转希望它为负；本轮没有确立按模式成功反转。联合反向训练的旧／新 TEST 准确率为 50.2083%／47.50%，联合可行性仍 Unknown。联合失败不证明模型容量不足。

同一旧状态下的同范数即时探针通过资格检查。反向减同向的旧优势效应为 −0.00001656、−0.00001497、−0.00001284 nat，两个探针在全部 seed 都改善旧 CE。这些小的局部作用不解释整个轨迹，也不解除旧学习资格失败。

Smoke、四次独立精确恢复及 Full worker 检查通过。Full 共完成 2,880 次更新、57,600 个答案目标；核验并登记 120 个实际检查点状态，归入 28 个 adapter family，另有两个读数 family。独立数值重算查 102 文件、460,920 条记录出现，最大误差 0.000001013 nat。资产枚举错误曾导致初次 strict access 失败，分析误在修正前启动；临时结果已保留。修正 schema 并通过 strict access 后，重跑分析，结果不变。没有重跑 GPU，也没有改变科学参数。[Detailed](detailed_cn.md) 保留这项偏离及完整来源。

本合并在此前更新成分研究之外，增加了任务关系干预。此前[轨迹 Summary](../../17_03_old_task_sensitive_update/A17_03_E03_trajectory_mechanism/summary_cn.md)已表明 CE 与答案竞争须分开。本次认识更新是：要把概率变化解释成规则迁移或规则保持，必须先证实条件映射及有意义的旧学习起点。**AI 建议：**先用有限诊断让旧任务的中性口令映射通过资格，再考虑新旧关系比较；目前不追加昂贵的分开参数或 SAE 实验。这是建议，不是新实验激活。
