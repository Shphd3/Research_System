# A→C与B→C：完整O大通道和端点差值的直接比较

## 1. 目的

**A、B、C的O矩阵有可测差别；直接比较后，B比A更接近C，而不是A更接近C。** 这既体现在完整矩阵的差值，也体现在各自前16项构成的处理算子。本轮回答“大参数方向有什么变化”，不计算梯度。

总问题仍是何时共享学习、何时需要按条件分开处理。本轮的小问题：同向续训端点A和反转续训端点B，各自与保留两套映射的联合端点C相比，最强O处理通道及端点差值是否不同？比较参数线性作用可以收紧“参数接近代表功能相容”的候选解释，但不直接确定旧规则遗忘的原因。

## 2. 模型

沿用已训练Qwen3-0.6B最后一层Q/K/V/O检查点，只读取O。A学习同向新映射；B只学习反转新映射；C从共同已掌握旧规则的状态出发，混合监督旧映射与反转新映射。三个续训顺序共用一个旧状态。既有1200步行为：A旧／新准确率100%／100%，B为0%／99.25%，C为99.83%／99.67%。

O将注意力读取向量c映射成a=Wc。矩阵的SVD是

\[
W=\sum_i\sigma_i u_i v_i^\top,\qquad
Wc=\sum_i\sigma_i u_i(v_i^\top c).
\]

σ_i是第i个通道的放大强度，v_i是它读取的输入方向，u_i是输出方向。因此“大方向体现处理功能”的先验可以准确表述为：**大奇异方向体现矩阵最强的线性处理通道。** 具体输入在v_i上有多少分量，也决定这个通道实际发挥多少作用。σ排名本身没有首项、末项或旧保护的语义。

直接计算端点差值T_AC=W_C-W_A、T_BC=W_C-W_B，并分别SVD；这描述从一个算子换成另一个算子的差别，不是实际走过的续训轨迹。另从已保存基构造各完整矩阵的前k项算子

\[
W_{X,k}=\sum_{i=1}^{k}\sigma_{X,i}u_{X,i}v_{X,i}^{\top},\qquad
d_k(X,C)=\frac{\|W_{C,k}-W_{X,k}\|_F}{\|W_{C,k}\|_F}.
\]

这同时保留左右方向、强度、符号和配对，比只比较两个子空间更直接。**差值的前16项与两个完整矩阵各自前16项的差值，是两种不同对象。** k16主要，8／32为预定敏感性。无新训练、前向、梯度或TEST；行为读数复用父R04的既有DEV。

## 3. 假设

候选预期：A/C在主要参数通道上可能比B/C更接近。竞争解释是：A/C的新映射要求不同，B/C的新映射相同；参数距离可能更多反映共同新要求，而不反映是否保持旧规则。旧监督、新曝光和Q/K/V也不同，因此仅有O差值不能独立解释旧功能。

子空间重合忽略了系数和符号，本轮的截断算子差值补上这项缺口。截断处重根仍可能改变前k基；固定8／16／32可以检查排序是否依赖单一维数。[先写定的Protocol](protocol_cn.md)拥有具体契约。

## 4. 结论

12个差值SVD已完成。以下是1200步、三个续训顺序等权平均；参数空间读数没有任务单位。

| 直接参数比较 | A→C | B→C |
| --- | ---: | ---: |
| 完整差值Frobenius范数 | 3.799585 | 2.988761 |
| 完整差值范数／完整C范数 | 8.876% | 6.982% |
| 差值最大奇异值 | 1.223322 | 1.047897 |
| 差值最大奇异值／C最大奇异值 | 34.286% | 29.326% |
| 差值自身前16项平方能量 | 79.621% | 78.237% |
| 完整矩阵前16项算子距离／C前16项算子范数 | 38.697% | 30.316% |
| 完整矩阵前16项算子的有符号余弦 | 0.9222 | 0.9526 |

三个续训顺序中，完整范数及前16项算子距离都是B/C更小。前8／16／32项算子的归一化距离分别为：A/C 37.947%／38.697%／32.929%，B/C 32.638%／30.316%／28.644%，均值排序一致。前16不是唯一得出该排序的截断。

两个端点差值T_AC、T_BC自身的左／右16维重合为0.8239／0.2953，有符号矩阵余弦0.5005。它们存在共同处理变化，也有不同的输入侧配对，不能视为相同变化。

**认识更新：主要参数通道确实有差别，但“旧功能相容的端点在大方向上更近”这一排序预期没有得到支持。** B/C参数更近却旧表现不同；A/C参数更远却都保持旧规则。旧保持与O距离不能直接互换解释。结果不否定矩阵方向具有线性处理含义，也不证明全模型没有功能分工。

## 5. 分析

### 参数差别主要发生在哪里

用完整C的前16左右基定义“主要输入／输出坐标”，将每个差值正交拆成四块。下表为各块平方范数占完整差值平方范数的百分比，不是任务因果贡献：

| 相对完整C前16通道 | A→C | B→C |
| --- | ---: | ---: |
| 主要输出＋主要输入 | 1.708% | 2.642% |
| 主要输出＋其余输入 | 5.937% | 7.209% |
| 其余输出＋主要输入 | 3.770% | 4.269% |
| 其余输出＋其余输入 | 88.584% | 85.880% |

这说明：**续训端点的差别大多在完整O最强16个通道之外，但差值自己又有约八成能量集中在16项。** 两句话没有矛盾：共同旧矩阵的强通道与不同续训端点之间的主要差异通道，不是同一组坐标。完整C前16项原本只占约5.5%矩阵能量，不能把其余坐标称作没有功能。

另外，以C相对旧起点的变化D_C为参照，A/C差值有65.114%能量位于D_C主要输入和输出内；B/C为34.548%。B/C另有38.383%位于D_C主要输出、其余输入的块，A/C对应12.593%。这是参数侧的具体区别：B/C差别较多保留C变化的主要输出坐标，但涉及不同的输入耦合。它不能独自命名为“旧规则修复”。完整W_C与变化D_C参照在表中明确区分。

### 为什么B/C会比A/C更近

直接证据是上述范数、完整前16算子差值及左右配对读数。一个符合训练设置的解释是：B和C都要实现新模式的反转映射，因此部分处理改变更接近；A保持同向映射，与C最终的新要求不同。该解释是**AI候选解释**，本轮没有独立操纵新要求并保持其他因素完全一致，不能判为已确定原因。

C额外获得旧模式监督，能够保留旧映射；B没有该监督。新要求的接近与旧规则的保持是两个因素，因此B/C在O上更接近，旧准确率仍可以不同。原1200步B的新答案曝光为24000，C为12000，同时C多12000旧答案；O所面对的Q/K/V读取向量也不同。这些仍是存活解释。

### 大方向如何与功能连接

最大奇异值衡量同一单位长度输入下两个O可能产生的最大输出差别：σ1(T)=max_{||c||=1}||Tc||。完整范数差约7%–9%，并不排除某个方向的处理差别较大：T_BC的最大增益已达C最大增益的29.326%，T_AC为34.286%。这是参数算子能力，尚未测量自然输入实际用到了多少，不能当作任务输出变化百分比。

前16截断算子距离约30%–39%，说明强通道的方向／强度／配对也发生了可测变化；不能再把“完整O空间较近”说成“处理完全不变”。但前16／17奇异值较近，截断算子变化可能含边界方向替换，截断差值还能超过完整差值范数；它不是完整差值的正交能量组成。8／32敏感性保留了B/C更近的均值排序，不能消除所有截断解释。

### 对共享与分开研究的意义

本轮把参数结论说得更精确：共用的大矩阵背景、续训形成的主要变化通道、以及按模式选择答案的任务功能，需要分开测量。C已经是当前共享模块兼容两映射的实例；本轮没有证明按前16方向分开参数会有净收益。

若下一步要判定这些大方向对旧规则是否有实际作用，可以保持其余参数不变，仅插入T_BC前16项或其余项，再测旧新预测；这是**AI建议、尚未执行**的参数干预，不需要梯度。本轮只完成参数空间定位。研究者机制裁决及问题闭合仍Unknown。
