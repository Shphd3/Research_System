# All-Seed Feature Heatmaps

Each condition has three all-seed figures:

- `<condition>_feature_main_expert_composition_by_seed.png`: fraction of \(B_i\) keys in each slot whose main expert is each expert. This is the main figure for different-feature composition.
- `<condition>_main_expert_feature_map_by_seed.png`: main expert for every atomic feature key \((slot,B_i)\).
- `<condition>_feature_to_expert_probability_matrix_by_seed.png`: full \(P(expert \mid slot,B_i)\) matrix.

Each panel title includes the seed, collapse status, max expert load, and number of active experts.
