# A14 总结：存在树对齐压缩，但稳定线性低秩传播没有得到支持

## 总体裁决

条件定理成立，真实成分、预训练模型与受控训练中也都能观察到树对齐的子空间
几何；但完整机制**没有得到支持**。叶子的绝对低秩依赖表示坐标，父子可预测性很大一部分
在随机初始化时已经存在，而所有预训练或训练模型中的注册理论界都是空泛的。

| 审计 | 直接判定 | 决定性结果 |
| --- | --- | --- |
| [E01 理论/合成](../../A14_E01_theory_synthetic/summary.md) | 通过 | 最大归一化越界 $2.92\times10^{-8}$；17/17 反例复现 |
| [E02 金标准句法 + PPMI](../A14_E02_gold_syntax_ppmi/summary.md) | 证据不足 | 真实成分投影优势 34.2%，但 $k/d=32.1\%>25\%$ |
| [E03 预训练解码器](../A14_E03_pretrained_tree_geometry/summary.md) | 证据不足 | Qwen 差异明显，但界比 10.80；Pythia 不复现训练增量 |
| [E04 因果训练](../A14_E04_causal_hierarchy_training/summary.md) | 证据不足 | 描述性树效应 +0.180、组合效应 -0.047，非空泛界 0/48 |
| [E05 同父节点切分](../A14_E05_same_parent_split_stability/summary.md) | 证据不足 | Qwen 切分优势 -0.0415；Pythia +0.1486 但随边界方向反转；Qwen 最小界比 1.3369 |
| [E06 双侧切分](../../boundary/A14_E06_two_sided_split_robustness/summary.md) | 证据不足 | 方向平衡后 Qwen/Pythia 效应为 +0.0064/-0.0001，稳定兼容点为 0 |

## 可以主张什么

1. 在假定的共享线性模型下，秩-$k$ 最佳逼近误差确实满足递推上界。
2. 在测试坐标中，真实成分比匹配非成分更共享训练子空间。
3. 受控层次顺序可以使树边界对齐压缩从接近零的初始差异中出现；12/12 个
   hierarchy-minus-shuffle 树效应均为正。
4. 受控生成器的潜状态数与叶层有效秩相关，Spearman 相关为 0.949。

## 不能主张什么

1. 不能说语言叶子普遍低秩：PPMI 需要 657/2048 个方向保留 95% 能量。
2. 不能说模型学到了统一共享线性父算子：原对照混入内容变化；固定同一父节点后，
   Qwen 没有 5% 真实切分效应，Pythia 的 E05 正效应在双侧平衡后消失。
3. 不能说递归范数界解释了真实几何：Qwen/Pythia 的界比分别为 10.80/1.77，
   E04 的 48 个最终转移没有一个小于 1。
4. 不能说真实切分具有与方向无关的优势：E06 的 Qwen/Pythia 效应只有
   +0.0064/-0.0001，两个区间都跨零。

## 当前最合理的机制读法

证据更接近“树或尺度条件下的子空间选择/压缩”，而不是一个全局稳定的线性传播
算子。同父节点对照已经固定内容，仍未恢复方向无关的真实切分优势。后续模型可能
需要节点类型/尺度特异子空间、非线性或门控组合。这是当前解释，不是替代定理。

## 唯一下一决策

关闭 A14 的全局共享线性传播主张。若继续该方向，应另开一个可裁决问题，研究节点
类型/深度条件化或门控子空间，而不是继续增加全局线性切分探针。
