# A14_E06 协议：同父节点双侧切分鲁棒性

> 一句话证伪目标：对每个父节点同时使用向左和向右移动一个词的错误边界并等权平均，检验 E05 的切分效应是否在消除方向不平衡后仍成立。

状态：用户已于 2026-07-18 授权直接执行。本协议在 E05 方向审计后、任何 E06 表示编码前冻结。

## 1. 问题

E05 虽固定父文本和 token，但 83--84% 的替代边界向右移动；Pythia 的效应在右移为正、左移为负。E06 只保留真实边界左右各能移动一个词的自然二叉父节点，并同时构造

\[
b^- = b^{gold}-1,\qquad b^+ = b^{gold}+1.
\]

三种条件的父节点与有序 token 完全相同。

## 2. 可证伪假设

1. **H6a Qwen 双侧切分特异性**：真实切分相对双侧等权错误切分优势至少 5%，句子级 bootstrap 下界大于 0。
2. **H6b Pythia 双侧复现**：Pythia 满足同一标准，用于检验其 E05 正效应是否依赖方向不平衡。
3. **H6c 跨模型一般性**：H6a 与 H6b 同时通过。
4. **H6d 稳定性兼容**：至少一个 Qwen 验证集合格点同时具有至少 5% 双侧优势和小于 1 的通用界比；它只能维持、不能挽救 E05 H4。

## 3. 模型与指标

沿用 E05 的训练叶子子空间 \(U\) 和严格有序输出瓶颈。真实、左移和右移条件分别拟合并由验证集选岭系数。定义

\[
CE_{2s}=\frac{CE_-+CE_+}{2},\qquad
Adv_{2s}=\frac{CE_{2s}-CE_{gold}}{CE_{2s}}.
\]

逐父节点先平均两个错误切分的平方残差，再做 1,000 次句子簇 bootstrap。效应阈值 5%、验证容差 1.05、岭系数网格和通用界阈值 1 均继承 E05。

使用 Penn Treebank 相同文件划分、Qwen2.5-0.5B 与 Pythia-410m 的预训练/同构随机初始化。最多使用 8,192 个训练叶子和 3,500/500/480 个训练/验证/测试内部父节点。父 token 一致、文件互斥、样本形状和岭回归内部点守卫必须通过。

## 4. 结果更新规则

- 两个模型均通过：增强“切分信息不依赖移动方向”的描述性证据。
- 任一模型置信上界不高于 0：该模型上的切分特异性被证伪。
- 模型方向不一致或效应不足：不能提出模型一般性结论。
- H6d 失败：继续维持真实系统中稳定递归界空泛的结论。

## 5. Claim Boundary

即使通过，也只能说明这两个表示在严格线性探针下偏好金标准切分；不能说明 Transformer 内部执行该递归，不能说明句法树唯一，也不能外推到自然语言、MoE、扩散模型或世界知识的全局低秩。
