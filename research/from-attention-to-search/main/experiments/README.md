## Formal records and supporting material

Protocol owns design, review, approval and amendments. Summary is the first result reading surface; Detailed preserves full evidence and deviations. A run-local automatic report does not replace the experiment-level record. Folder existence does not establish that a missing result was run or completed.

`supporting_records/`, `historical_support/` and `sources/` preserve assigned supporting material and provenance. SAE pretraining/representation support belongs to A15_17. A15_19 and A17_12 historical support stays background rather than additional formal Anchors. [archive/](archive/) retains retired material; old run names do not create scientific identities.

Raw outputs, model/dictionary weights, full activations, large caches and unfiltered logs remain in execution repositories. This repository holds formal text, scripts, configuration and small auditable evidence. [Project rules](../../AGENTS.md) and the owning Protocol govern execution and storage. The [migration record](../organization_migrations/20261022/README.md) traces old paths, new locations and preserved immutable run identities.
