# A16_00_01_E01 最终结果摘要

## 直接结论

注册裁定为 **`necessary_only`**。独立语料估计出的 token 共享均值，是
Vanilla-Full 当前冻结深层路由坍缩的方向特异、即时维持因素：去掉它后，注册
层与保存点上最忙专家占比平均下降 0.68678，远超同幅随机平移。反向干预没有
通过：向另一条独立训练的 Centered-Full 加回保存中心虽然会改变路由，但效应
小于普通同幅随机方向。因此，去中心改变了共同学习路径；公共偏置本身并不是
对任意已训练 Gate 都足以造成坍缩的普遍原因。

这解释了为什么相同的 \(\lambda_{LB}=0.01\) 没有产生相同专家使用：目标相同，
但 Vanilla 暴露了一个跨 token 一致、专家之间不同的 DC logit 偏置，赢家很早
就被统一；Centered 没有暴露该项。当前仍不能确定这项对齐最初由语言模型
梯度、LB 梯度、AdamW 状态还是专家反馈形成。

## 注册裁定

**最忙专家占比**是八个专家中接收验证 token 最多者的比例；0.125 是均匀，
1.0 是全部进入同一专家。正效应表示“去均值恢复 Vanilla”或“加中心破坏
Centered”。

| 冻结反事实 | 平均效应 | 文档配对 95% 区间 | 匹配随机 q95 | 裁定 |
| --- | ---: | ---: | ---: | --- |
| Vanilla：去独立均值 | 0.68678 | [0.68435, 0.68922] | 0.18326 | 必要性方向通过 |
| Centered：加回保存中心 | 0.14225 | [0.14010, 0.14446] | 0.22588 | 充分性方向未通过 |

Vanilla 的真实效应超过全部 256 个聚合随机平移；Centered 的真实效应只超过
其中 6.64%，而且平均小于错误层平移。因此，Centered 的非零响应不能特异归因
于它的 covariance center。

## 训练过程中发生了什么

约 50M token 时，原生 Vanilla 第 3/4 层已经把 98.7%/97.8% token 送给
一个专家；约 100M token 时达到 99.9%/99.9%。同一冻结检查点去掉独立均值，
占比立即降到 27.7%/30.0%；20B 时仍从 99.9%/99.8% 降到 20.5%/21.5%。

在 14 个主单元上，去均值平均使 72.63% token 更换专家。真实 DC 对原生赢家
相对第二名的 margin，在 99.75% token 上为正；逐单元中位贡献约为最终原生
margin 的 1.09 倍。比值大于一表示 token 变化残差往往在部分抵消公共偏置，
而不是创造这个赢家。

## LB 诊断说明什么

**Switch LB 数值**在均匀使用时为 1；单个专家接收全部 token 且软概率也同意
时接近 8。**logit 梯度杠杆**是只经过软概率的解析局部梯度 RMS；为比较状态，
图中去掉了共同 token 数和同一系数，不能代表叠加语言模型梯度与 AdamW 后的
真实参数更新。

Vanilla 深层 LB 数值随坍缩升近 8。局部梯度杠杆在 50M--100M 的部分形成
阶段很高，但第 4 层完全饱和后可以降得很低，即使惩罚仍接近 8；第 3 层在
10B/20B 又不呈现普遍的梯度消失。因此不能下结论说“坍缩后 LB 总是没有
梯度”。更准确的认识是：惩罚有多大与它当下能否改变赢家是两个依层、依阶段
变化的量；辅助损失很大并不保证硬 top-1 路由会自行恢复。

![LB 惩罚与局部杠杆](figures/figure3_lb_penalty_and_gradient_dynamics.png)

## 边界与唯一下一决策

本冻结审计证明当前 Vanilla 坍缩即时依赖真实公共分量；它不能证明历史唯一
成因，没有执行反事实专家，也不能测 NLL 收益或证明应提高 LB 系数。

唯一下一决策由 A16_00 接管：做配对早期梯度—影子更新审计。主指标比较从完全
相同 AdamW 状态出发，加入 LB 梯度后，独立文本的一步 NLL 是否变差；机制指标
是在完整全局 batch 上计算语言模型梯度与 LB 梯度的原始余弦。只有同时确认
held-out 代价、硬负载改善与负梯度方向，才把动态 expert bias 作为第一干预。
