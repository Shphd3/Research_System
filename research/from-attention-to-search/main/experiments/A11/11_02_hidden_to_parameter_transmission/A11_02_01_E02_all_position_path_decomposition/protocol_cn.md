# Protocol：A11_02_01_E02 全位置语义路径分解

## 0. 审批摘要

**状态：** 用户已于 2026-07-10 授权实现和远程四卡执行。  
**目的：** 判断 K=2 MTP 是否比 NTP 的后续全位置语义损失更早地给 \(h_T\) 增加一个正的模型自身语义更新。  
**Anchor：** `../../../../problem_anchors/11_informative_future_branch_mechanism/11_02_hidden_to_parameter_transmission/subanchors/11_02_01_reachability_and_background_sign_anchor.md`。
**唯一问题：** 把后一位置语义迁移和共享损失分开后，当前位置 H2 损失是否仍给 \(h_T\) 的语义速度增加可分辨的正项？  
**实验角色：** 根因审计和受控到真实任务的桥接。  
**主指标：** 同一参数检查点上的精确分量速度分解。  
**最小设置：** clean K=2 全位置序列；一层 Transformer；冻结词嵌入和预测头；决策状态参考折叠；五个随机种子；四个 loss-mask 条件。  
**通过：** 分解守卫通过；至少 `4/5` 种子 \(G_D>0\)；full 净速度、真实一步保真和早期 direct 条件排序通过；Y1 本地守卫通过。  
**失败：** direct 项不可分辨/不为正，后一位置间接路径在模型自身速度和轨迹上追平，或差异由本地学习损害解释。  
**证据不足：** 参考折叠、输出几何、分解、冻结参数、任务覆盖或数值守卫失败。  
**不能声称：** 自然语言/LLM 收益、样本效率、更大 K、AdamW 或 MoE 收益。

## 1. 术语解释

| 术语 | 直白含义 | 计算 | 为什么重要 | 不能证明什么 |
|---|---|---|---|---|
| direct 语义损失 | K=2 从更早状态预测 \(S_Z\) | \(L_D=\ell_{T,2}\) | MTP 独有路径 | 全局效率 |
| indirect 语义损失 | NTP 读入 \(A\) 后预测 \(S_Z\) | \(L_I=\ell_{T+1,1}\) | NTP 全位置路径 | \(h_T\) 已被模型自身使用 |
| local shared loss | 从 \(h_T\) 预测共享 \(A\) | \(L_S=\ell_{T,1}\) | 本地学习守卫 | 长程语义 |
| remaining loss | 其他所有有效全位置损失 | \(L_R=L_2^{all}-L_D-L_I-L_S\) | 剩余背景 | 单一因果路径 |
| 模型自身 margin | \(h_T\) 与 H2 的 \(S_Z\) 输出行对齐 | \(M_Z=m^{-1}\sum_zv_z^\top h_T(z)\) | 测模型可直接使用的语义状态 | 下游收益 |
| 分量速度 | 某损失分量对 margin 的一阶参数更新 | \(G_c=-\langle\nabla M_Z,\nabla L_c\rangle\) | 分开直接和间接路径 | 长期收敛 |

## 2. 数据与路径

每个分支的序列：

```text
BR_z F00 ... F15 U00 U01 U02 U03 A_SHARED S_z
```

`U03` 是决策位置 \(T\)。语义词元有两条监督路径：

```text
K=2 直接路径： U03 --H2--> S_z
NTP 后续路径：  A_SHARED --H1--> S_z
```

损失分解为：

\[
L_D=\ell_{T,2},
\quad L_I=\ell_{T+1,1},
\quad L_S=\ell_{T,1},
\quad L_R=L_2^{all}-L_D-L_I-L_S.
\]

同一检查点上：

\[
G_{total}=G_D+G_I+G_S+G_R,
\]

\[
G_{full}-G_{mask-D}=G_D.
\]

## 3. 条件

| 条件 | 激活损失 | 回答什么 |
|---|---|---|
| `ntp_all_h1` | 所有 H1 | NTP 后续语义迁移能做什么 |
| `ntp_plus_direct_h2` | 所有 H1 加 \(L_D\) | 当前位置 direct 项是否充分 |
| `mtp_all_k2` | 所有 H1/H2 | 完整 K=2 MTP |
| `mtp_mask_direct_h2` | 所有 H1/H2，但去掉 \(L_D\) | 当前位置 direct 项是否必要 |

随机种子：`971,972,973,974,975`。  
训练共 `15000` 步；检查点为 `0,1,2,5,10,20,50,100,200,500,1000,2000,5000,10000,15000`。前 200 步用于密集机制审计，长窗口与 A11_10 的全位置训练尺度对齐。  
共 20 个训练任务，分到四张 GPU。

## 4. 主指标与公式

模型自身语义 margin：

\[
M_Z=\frac1m\sum_z(u_{2,S_z}-\bar u_2)^\top h_T(z).
\]

每个损失分量的参数语义速度：

\[
G_c=-\langle\nabla_\theta M_Z,\nabla_\theta L_c\rangle.
\]

SGD 一步保真：

\[
\Delta M_Z\approx\eta G_{total}.
\]

主判定先看 \(G_D\) 是否为正，再看 full/mask 的同检查点差是否由它精确解释，最后才看真实一步和早期 margin 曲线。负余弦或高 probe 都不是单独判据。

## 5. 有效性守卫

1. step 0 各分支折叠后的 \(h_T\) 与 logits 必须相同。
2. H1/H2 的 \(S_Z\) 中心化输出行必须对齐。
3. 词嵌入和预测头更新范数必须为 0。
4. \(G_{total}\) 必须能由四个分量数值精确重构。
5. full/mask 同参数反事实差必须等于 \(G_D\)。
6. Y1 最终准确率必须不低于 `0.90`。

## 6. 通过、失败与边界

**通过：** 有效性守卫全部通过；至少 `4/5` 种子 \(G_D>0\)；真实一步方向与一阶预测一致；direct 条件的早期模型自身 margin 高于对应 mask 条件；本地 Y1 保持。

**部分通过：** 同检查点 \(G_D\) 为正，但真实一步或早期轨迹不稳定；只保留局部参数传递结论。

**失败：** 实现有效但 \(G_D\le0\)，或后一位置间接路径在模型自身速度与轨迹上追平 direct 路径。

**不能声称：** NTP 学不到 \(Z\)、自然语言 MTP 已经更高效、K 越大越好、局部速度等于样本效率、MoE 收益成立。

## 7. 下一步

无论结果正负，本实验后不再继续向更细的受控切向核审计下钻。若通过，下一 anchor 操作性定义真实长文档语义：局部窗口不足、早期语义改写不变、改变早期状态会改变远期正确决策；随后才比较 MTP 与 NTP 的训练 token/更新效率。若失败，则先收缩 all-position 理论，再设计真实任务。

Smoke 修订：一个有效的 200 步单种子运行已经看到 direct/mask 的语义 margin 排序，但全位置 H2-background 条件尚未完成 Y1 学习，因为每个位置只占平均损失约一个序列长度分之一。因此 full run 改为 15000 步；问题、四个条件、指标和结论边界均未改变。
