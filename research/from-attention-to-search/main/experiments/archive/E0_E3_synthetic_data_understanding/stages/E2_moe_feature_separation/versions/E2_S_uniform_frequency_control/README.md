# E2-S Uniform Frequency Control

This folder records the uniform-frequency control for the E2-S spectral covariance router side branch.

It asks whether the negative long-tail E2-S result came from the feature frequency imbalance itself. The control keeps the same total planted feature count as the long-tail setting, but sets all four features to equal count.

Read:

1. `summary.md` - concise result and claim boundary.
2. `detailed.md` - run setup, metric meanings, and full table.
3. `figures/` - advisor-facing plots copied from the ignored run workspace.
