# Experiment Archive

This folder stores historical or supporting experiments that are not the first
reading path for the current active proposition.

Use archive material only when it helps explain a claim boundary, prior failure,
or motivation for the current hypothesis.

| `R4_attention_output_router_retrieval/` | attention-output router retrieval support |

## Rule

Do not promote an archived experiment back to active unless it directly changes
the current hypothesis, claim boundary, or next decision.
