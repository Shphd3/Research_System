# 与 AI 迭代的格式（一页）

一个对话只处理一个问题。对话日志用 `MMDD-名称` 命名（`research-memory`）。

## 每一轮

1. **研究者给出**：当前假设；它依据的先验与推出的数学量（AI 可帮忙补全，研究者确认）；跑前预测（结果 A 就做什么、结果 B 就做什么）；资源约束（GPU、时间）。
2. **AI 给出**（每项标 `AI 建议`）：
   - 最强的竞争解释或反例；
   - 能区分两者的最小实验，以及所需算力；
   - 可运行的代码，放在项目仓库 `Projects/<项目>/code/` 或执行侧；探索日志里写它的路径。
3. **研究者批准后运行。**
4. **结果回来以后**：先按跑前写下的分支做决定，再讨论怎么解释。决定写进 `log.md` 的“研究者决定”；没有决定时写 `Unknown`。
5. 当天最后一条写 `今日认识更新：…`。

## 组会

组会前运行：

```sh
python tools/meeting_digest.py research/<project>/main/explore --since MMDD [--until MMDD]
```

它把两次组会之间各探索日志里的“今日认识更新”和对应假设汇总成简报草稿（目的、结论、假设、实验分析）。草稿标为待研究者确认，不生成科学结论；保留 2–3 条最重要的结论并附上原始数据链接。

## 升级

只有要进入组会正式结论、论文或长期地图时，才按 `docs/formal_lane.md` 补正式记录，并引用探索日志里的原始数据。
