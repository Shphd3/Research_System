# 简明科研写作与媒介选择

[English](report_writing.md)

目标是让读者首次阅读就能理解问题、推理、证据和边界。这些规则用于报告与解释，
不增加审批环节，也不改变科学判断的归属。

## 文字

- 优先使用短句、明确的主语和具体动词。把观察、解释、后果写清楚；一句话装不下
  它们之间的关系时就拆开。知道行动者时优先主动表达。
- 同一个对象使用同一个术语。必要术语和符号在首次影响理解时解释，不为修辞更换叫法。
- 尽早给出主要回答。一段展开一个要点，来源链接用于核查，正文仍需把意思讲清楚。
- 保留假设、量词、不确定性和适用范围。简化语言不能把局部结果变成普遍结论，
  也不能把假设写成结果、把数学关系写成因果发现。
- 中文保持自然，英文清楚直接。不把英文词数限制套到中文，不强行限制数学术语，
  未经专门检查不声称符合 ASD-STE100 全部标准。

## 内容与深度

从读者的问题开始，说明对象、论证或比较、证据、有界回答与剩余决定之间的最短必要链条。
组会先放主讲，再放细节与问答；完整报告应能独立理解。简短回答不必生成报告。

章节随研究类型调整。证明、观察、干预、工程比较需要不同证据，不为填模板编造实验或模型。
既有 Anchor 八节和 Summary 四部分仍由其各自规范负责。

## 按理解收益选择形式

| 读者需求 | 合适形式 |
|---|---|
| 直接回答、稳定记录、引用 | 文字或 Markdown |
| 关系、计算过程、依赖 | 小型且标注清楚的图解 |
| 实测比较与不确定性 | 有来源的科学图表 |
| 调整参数、切换条件、逐步展开推导、搜索长报告 | 带静态阅读入口的本地 HTML |
| 为明确受众解释随时间变化的过程 | 按需制作动画或视频 |

HTML 是解释视图。它读取同一组来源文档和核验过的数据，标明来源版本，不另存一套可编辑结论。
示意模拟必须与测量区分；交互控件不能隐藏单位、范围、不确定性或比较条件。

普通回答不必做网页。核心结果应能离线阅读，不依赖服务、账号或视频。
发布和外部同步仍需明确范围；生成本地阅读包不等于发布。

## 验收

检查初次阅读者能否说清：研究什么、比较或论证为何有效、认识改变了什么、还有什么未回答。
没有独立读者时称为自审。能够渲染时检查实际图页、导航、标签、来源链接与静态阅读入口；
源文件检查不能证明渲染正确或理解效果已经改善。

这吸收了 [Karpathy 帖子](https://x.com/karpathy/status/2105819303471976479)的简明表达和媒介选择建议，
没有另立一套报告模板。[STE 官方说明](https://asd-ste100.org/STE_faq.html)也支持把短句、明确术语、
主动表达应用到其他写作中。帖子所说的“80%”不是正式合规等级。
