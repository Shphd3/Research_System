一项实验如何追溯到研究问题

  1. Anchor · 定义问题

    为可证伪的问题保留稳定编号、原文路径和判定条件。Anchor 登记它所拥有的实验。

  2. 实验名 · 对应 Anchor

    每项实验有唯一名称。Protocol 开头写明所属 Anchor 的编号与链接，约定比较对象、预期与判断标准。

  3. 项目代码 · 可执行入口

    在 Projects 下的项目仓保存启动脚本、配置、依赖和复现命令。记录代码版本、配置路径及输入资产编号。

  4. 执行 · 可在项目之外

    在执行工作区按同一版本运行。记录实验名、运行 ID、实际目录和输出清单。日志、原始结果和检查点可保存在执行侧。

  5. 结果 · 回到实验目录

    Summary 和 Detailed 回链 Anchor、Protocol、代码版本和运行记录。精选证据随记录保留，大文件通过资产编号与位置定位。

  6. 版本与归档 · 保留来路

    检查正式记录及项目代码可被所属 Git 仓跟踪，核对相对链接和复现入口。获授权后提交并推送。归档时一并保留 Git 历史、启动入口和路径映射。在新位置复跑最小示例，检查依赖与输入路径。

已归档的真实例子 router_representation_gradient_feedback 的 Protocol 明确链接 所属 Anchor 。同一实验目录保留 结果摘要 与 证据明细 。
