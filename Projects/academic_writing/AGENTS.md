# Academic Writing Project Rules

This project is for course deliverables derived from ongoing research.

Default artifact language is English. Chinese companion notes may be added only
when they help local planning.

Do not update research graphs, root sync, external collaborator sync packages,
or the `from-attention-to-search` research mainline from this project unless the
user explicitly asks for that action.

Use this project to manage:

```text
course requirements
slides
paper source planning
poster planning
reusable presentation templates
small curated assets for course deliverables
```

Do not use this project to store:

```text
raw experiment logs
checkpoints
datasets
full result directories
temporary exports
compiled PDF/ZIP deliverables unless explicitly force-added
```

Claim boundary for the current topic:

```text
The course deliverables may present MoE gating specialization as ongoing
research. They must separate observed route consistency, interpretation about
specialization, and unresolved route-utility binding.
```
