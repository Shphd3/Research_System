# Poster

The poster should compress the final Project 2 story into a single visual
argument.

Recommended structure:

```text
1. Problem: MoE gating needs useful, stable expert specialization.
2. Risk: route consistency can be a misleading proxy.
3. Diagnostic decomposition: feature axis, collapse guard, composition,
   utility binding.
4. Key evidence: current diagnostics support weak consistency but not the full
   functional claim.
5. Boundary and next step.
```

Use only curated figures copied from the source research records. Do not embed
raw logs or unreviewed generated figures.
