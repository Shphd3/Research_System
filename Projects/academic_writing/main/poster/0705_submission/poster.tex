{\Huge\bfseries Uniform Feature Routing in Controlled Top-1 Mixture-of-Experts}\par
\vspace{0.12in}
{\Large Deng Xingyu \quad Student ID: 250010109 \quad Academic Writing Project 2}\par
\vspace{0.16in}
{\color{muted}\large Main claim: uniform expert usage is a two-sided geometric sufficient-condition result, not evidence of semantic expert specialization by itself.}
\vspace{0.28in}

\begin{multicols}{3}
\raggedcolumns

\panel{Problem}{
\large
Sparse MoE routers decide which experts see each token. A balanced load vector
is useful, but it is ambiguous. It can come from spherical token geometry,
well-spread expert cells, finite sampling, assignment constraints, or training
dynamics. This poster isolates the static unconstrained top-1 question.

\vspace{0.14in}
\textbf{Question.} Under which representation-geometric assumptions does
uniform expert usage arise naturally from top-1 routing?
}

\panel{Four Uniformities Must Be Separated}{
\large
\begin{tabular}{@{}p{0.36\linewidth}p{0.55\linewidth}@{}}
\toprule
Term & Concrete meaning \\
\midrule
Feature frequency & labels occur equally often \\
Directional uniformity & centered directions cover the sphere \\
Spectral uniformity & covariance has no dominant direction \\
Usage uniformity & expert counts are close to $1/E$ \\
\bottomrule
\end{tabular}

\vspace{0.12in}
The count metric is the outcome. It cannot prove the representation geometry
unless rival explanations have been separated.
}

\panel{Theoretical Baseline}{
\large
For normalized token directions $z\in\mathbb{S}^{d-1}$ and expert prototypes
$u_e$, expert $e$ owns
\[
V_e=\{z:\langle z,u_e\rangle\ge \langle z,u_j\rangle,\ \forall j\}.
\]
If $z$ is uniform on the sphere and the cells $V_1,\ldots,V_E$ have equal
spherical measure, then
\[
\mathbb{P}(a(z)=e)=1/E,\qquad \mathbb{E}[\widehat p_e]=1/E.
\]
This is sufficient, not necessary, and not a utility claim.
}

\panel{Audit Pipeline}{
\large
\textbf{1. Define the routed population.}\\
\textbf{2. Check directional mass, not only covariance.}\\
\textbf{3. Estimate prototype-cell geometry.}\\
\textbf{4. Split finite-sample noise from geometry floor.}\\
\textbf{5. Separate natural top-1 routing from forced assignment.}

\vspace{0.1in}
Only after these checks should uniform load be used as evidence for meaningful
routing structure.
}

\panel{Takeaways and Boundary}{
\large
\textbf{Supported.} In a controlled static top-1 router, uniform usage has a
clean geometric sufficient condition: spherical token directions plus
equal-measure expert cells.

\vspace{0.1in}
\textbf{Not supported.} The paper does not prove semantic expert identity,
downstream utility, or training-time preservation.

\vspace{0.1in}
\textbf{Next audit.} For real models, check routed population, directional
mass, prototype-cell geometry, finite-sample noise, capacity controls, and
then margin/utility under training.
}
