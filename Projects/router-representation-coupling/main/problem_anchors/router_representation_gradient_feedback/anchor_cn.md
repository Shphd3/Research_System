# Anchor：路由返回表征的直接梯度反馈

## 1. 问题定义

版本说明（2026-10-07表达修订）：正文零辅助项说明对应原R1历史条件；当前训练条件由末尾“当前设计修订A3”及Protocol A3持有。A3两臂辅助梯度共同不返回r，干预仍只改变语言模型反馈边。这是版本辨识，不改变假设、审批、八节设计或研究者判断。

在固定预算的因果语言模型中，LM 门控分支返回共享主干的直接梯度，是帮助还是损害独立预测和专家功能分工？研究者已激活本独立临时问题，并在[直接请求](../../../handoff/researcher_request_cn.md)中委托设计具体化、实现、Smoke 和提交。根本方向是改进 MoE 的学习分配。此前固定动作选择未超过强共同动作，但没有检验共同训练的专家。本轮只改变一条反向边；同状态前向保持相同。范围为共同 seed 的一对有限轨迹。科学机制判断和实际采用门槛仍 Unknown。

## 2. 物理先验

AI 工作假设：门控梯度可能形成任务相关分工，也可能扭曲共享表示。链式法则是数学关系，不是任一方向的经验支持。梯度幅度及 Adam 预条件、实际专家样本暴露和硬件数值路径都是可信替代解释，不假定其为零。

## 3. 可证伪假设

双向开放：coupled 反馈可能降低 heldout CE 并形成对因果、保持使用率的路由替换更敏感的专家；detached 反馈也可能更好。只有几何变化不能支持效用。CE 改善缺少功能干预支持，或硬件/负载解释未分清时，只能得到有界差异。研究者最强对手排序仍 Unknown；登记的替代解释是受托设计中的 AI 审计选择。

## 4. 数学模型

第 l 层的 r 是残差相加前 Attention 输出；h 是相加后的归一化隐藏状态，即专家完整输入。W r 是 router logits，p 是八专家 softmax，K 是 top-2 集合。所选权重不重新归一化。共享专家 S 和路由专家 E 都读完整 h；层内贡献为

\[
m=S(h)+\sum_{i\in K}p_i(Wr)E_i(h).
\]

A 读 live r；B 仅在 W r 内用 stop-gradient(r)。同状态同样本的前向相同。aux=0 时，B 只去掉 LM gate 返回 r 的贡献；W、E、S、h 与残差路径正常接收梯度。在选择不变的光滑分支，参数梯度差是上游 Jacobian 转置乘 gate-path 梯度并跨层求和。这里不主张 top-k 边界导数，也不把隐藏状态梯度当 AdamW 更新后的状态位移。主 CE 差定义为 B 减 A，单位 nat/有效预测 token，正值支持 A。

## 5. 计算实现

目的：把反向反馈与前向变化分开。方法：独立适配实际核验的 342M/12 层原生 MoE，关闭 EMA 与无关正则；全部层 router 输入作干预，加载共同随机初态，在不同卡数上保持同一全局 token 批次与顺序。理由：这检验直接反向边，不是冻结表示或专家。autograd 单独读 gate 与 expert 路径，并核验共同状态 router/专家参数梯度。两种授权 Smoke 硬件分别跑 A/B 短窗口；数值差异仅作诊断。

目的：在结果出现前确定效用与功能后测。方法：冻结独立文档 CE，模型内部作因果 route-bundle 置换，保持各层使用次数与门控权重集合；几何和有限更新另报。理由：簇或秩不能代替有用分工。X-MoE 的路径分解及低维路由提供先例，不证明整体必然坍缩或本 detach 有效。DeepSeek-V3 §4.5.3 的 batch 辅助损失可追平 aux-free，因此不混入均衡算法比较。精确操作由[分析 Protocol](../../experiments/router_representation_gradient_feedback/analysis_protocol_cn.md)持有。

## 6. 最小反驳实验

主要反驳是共同 token 终点的配对、token 加权 heldout CE 与整文档 bootstrap。AI 建议的可解释差异为 0.01 nat/token，和零效应区间分开报告；研究者采用门槛 Unknown。支持某一方向需要超过该建议差异的区间、工程资格完整，以及符合专家功能分化的干预证据。反向结果削弱该方向；只几何变化、区间跨相应差异、终点缺失或重要对手未分清，均为 INSUFFICIENT。支持也限于本对轨迹，不识别排除硬件后的算法因果。

## 7. 当前证据

登记时新轨迹 NOT RUN。scaffold 与历史硬件回执仅证明可复用工程行为。此前固定库负结果不能判定本问题。Smoke 与本地梯度检查记入 Detailed，不提升为科学结果。

## 8. 结论边界与下一决定

这是单 seed、硬件混杂的探索性比较。不能证明普遍表征坍缩、所有共同适应机制、seed 不确定性或广泛 MoE 改善。下一决定由研究者持有：保留、移除还是继续验证直接反馈。完成条件是合格且 token 对齐的终点 CE、功能后测及替代解释读数；后续只查看既有任务/检查点并按冻结分析执行，不自动重训或增提。
