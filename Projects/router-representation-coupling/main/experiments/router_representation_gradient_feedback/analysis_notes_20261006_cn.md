# 重训后的分析思路：从预测收益到学习分配

[English](analysis_notes_20261006.md) · [当前训练合同A3](protocol_cn.md) · [冻结后测合同](analysis_protocol_cn.md)

这是阅读1002完整对话记录及其当前证据后提出的AI分析思路，不是新增科学裁决。旧零均衡条件已在早期集中退出；本次研究两臂共同加入0.01均衡项的新条件。两者不能合并为同一次对照。当前新条件已完成本对训练；这不证明均衡普遍防止负载集中。事实以[当前Summary](summary_cn.md)和Detailed为入口，独立TEST与功能后测仍未执行。

## 1. 先问是否产生净预测收益

主问题仍是：在相同数据暴露后，切断LM路由反馈是否改变保留文档的预测损失？沿累计有效目标对齐两臂，在冻结终点读纯LM CE，不用含均衡项的总损失选胜者。纯LM CE、原始均衡项、加权均衡项和总目标分别记录。640篇TEST文档只按原合同在终点评价；整文档配对bootstrap不代表seed不确定性。早期checkpoint只描述演化，不事后挑最优终点。

1002旧固定动作实验提示：有输入相关匹配收益，仍可能输给强固定动作。它支持我们认真设置效用对照，却不能否决可学习专家。本新项目训练router、专家和主干，检验的是反馈边改变完整轨迹的效果，不是重复旧固定库选择器。现有共享专家也不能被称为“单独共享模型基线”，因为没有训练第三臂。来源：[1004认识更新§2–3](/data/250010109/Research_System/daily_research_reports/1004/cognition_update_cn.md)。

## 2. 再问路由是否形成有用的功能分工

每层负载、有效专家数、零分配专家数和route churn先给出使用状况；使用更多专家或负载更均匀，不能单独证明更好的分工。原失败臂中专家集中是真实读数，但共享专家仍参与，不能仅由负载集中断言预测能力塌缩。

关键功能检验仍使用每个模型内部的路由束置换：同位置交换top2专家与门控权重，保持专家使用次数、权重集合及激活计算量，完整h仍由原接收样本提供。若置换增加保留CE，说明原输入与专家分配有功能关联；A/B增幅差和主CE一起读。它不是另训练一条路径，也不证明长期学习机制。跨模型专家编号不直接对齐，领域名称只是有来源时的分层变量。

## 3. 将“当前计算”与“下一次学习作用”分开

1002的有限更新观察表明，平均受益与大量单事件受损可同时出现。因此，原登记的DIAG有限更新诊断要同时报告接收样本平均帮助、分布和不利比例，比较同路由/异路由及词频、长度、负载匹配的随机接收对照，不能只画梯度cosine。它使用checkpoint副本上的单位范数、步长1e-3纯LM SGD诊断；这并不复现训练的AdamW或共同均衡目标。修改正式检查点被禁止。来源：[1002研究报告§4.1](/data/250010109/Research_System/daily_research_reports/1002/candidates/ntp_representation_update_channels/research_report_cn.md)。

必须分开LM gate反馈、expert/residual路径和均衡项。A/B辅助项均不沿r回主干，但会更新router W。归因读数告诉我们差异从哪条边进入，不保证该方向在未来有利。全网络与单层固定下游伴随梯度的读数也分别命名。

1004进一步说明，Adam矩的汇聚与未来训练会改变一次更新的作用。即时帮助可能在相同后续程序下反转。因此当前有限更新只能支持即时相容性；不能据此宣称长期保持。若后续要做接受/拒绝某次更新、再重放相同未来数据的实验，必须另登记完整参数、Adam状态、未来数据/RNG和有限评价时点，估计额外成本，取得范围授权；本次不自动新增分支训练。来源：[1004认识更新§4–6](/data/250010109/Research_System/daily_research_reports/1004/cognition_update_cn.md)。

## 4. 表征分析先测真实变化，再考虑坐标解释

这里需要区分参数位移 \(\Delta\theta\) 与同输入的真实表示差 \(r(x;\theta+\Delta\theta)-r(x;\theta)\)。已有几何计划描述模型或检查点间关系，不等于已测某次训练更新的表示位移；静态激活、返回r的梯度及SAE编码差都不能替代更新前后的真实前向。后测合同固定了几何描述对象，本说明只澄清其边界。

登记的几何量是在相同前缀、位置与长度下，比较r、h及专家输出的中心化有效秩和CKA，保留原值与单位L2归一化两个版本、词频组成控制。有效秩描述方差分布在多少方向，CKA比较两个激活矩阵的样本关系；它们不是语义维度或效用指标。geometry_capture入口尚未实现，本段没有新增范数终点。

1002表明，SAE静态重构好，不保证其编码差可以忠实表示参数更新产生的位移。若解释有限更新，先从更新前后模型真实前向得到representation displacement，再讨论投影或坐标，不能把SAE编码差当原生位移。当前合同没有大规模SAE训练。来源：[1002研究报告§4.4](/data/250010109/Research_System/daily_research_reports/1002/candidates/ntp_representation_update_channels/research_report_cn.md)。

1002的来源迁移还提示，平均响应易读与来源差异可预测是不同目标。后续AI建议在DIAG中复用或前瞻登记不重叠来源批次，分开来源平均与来源差异，并让预测输入严格停在被评价目标之前；需先与原DIAG32程序衔接，不能读TEST后挑来源或特征。新增读出器同时保留强简单基线/PCA或随机投影作为竞争解释，但本次不自动实现新的预测实验。来源：[来源迁移续研](/data/250010109/Research_System/daily_research_reports/1002/candidates/ntp_representation_update_channels/source_transfer_addendum_cn.md)、[可见信息边界](/data/250010109/Research_System/daily_research_reports/1002/candidates/ntp_representation_update_channels/domain_response_structure_cn.md)。

## 5. 保留四个结果分支

| 可能结果 | 可报告的边界 |
| --- | --- |
| 终点纯LM CE更低，并有登记的功能干预支撑 | 指定预算下的效用与分配依赖证据；不能消除硬件/seed混杂 |
| 仅几何或负载不同，主CE无明确收益 | 描述性变化，不宣布反馈机制有效 |
| CE不同，但负载暴露、梯度规模/Adam或硬件解释仍未分清 | DIFFERENCE_WITH_UNRESOLVED_RIVAL，机制仍不足 |
| 保护退出、终点/功能缺失或区间不足 | INSUFFICIENT；完整记录事实，不以早期曲线替代主终点 |

复杂后测入口当前仍有PREPARED_NOT_IMPLEMENTED项。研究者拥有机制、采用、最强竞争解释和问题关闭的判断；本思路不更改这些Unknown。
