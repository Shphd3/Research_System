# Research Files

This repository is a research-process workspace for the Feature-Zipf / Hierarchical MoE project. It is not the remote experiment codebase.

The goal is to preserve research judgment: mainline, hypotheses, evidence, claims, daily reports, paper reading cards, and meeting-ready PRISM reports.

## Start Here

- `CURRENT.md`: current research state and today's focus.
- `mainline.md`: long-term research mainline.
- `claim_board.md`: claim status and evidence boundary.
- `AGENTS.md`: project-level Codex instructions.

## Working Areas

- `daily_research_reports/`: dated folders for daily reports, daily conclusions, experiment summaries, and report bundles.
- `experiments/`: experiment cards organized by research question.
- `meetings/`: advisor/group-meeting materials, including PRISM reports.
- `paper_reading/`: literature cards and reading notes.
- `codex_skills/`: repo-tracked source copies of personal Codex skills.
- `prompts/`: reusable project prompts and older workflow prompts.
- `docs/`: setup notes for tooling and workflow maintenance.

## Daily Loop

1. Read `CURRENT.md`, `mainline.md`, and relevant evidence.
2. Decide whether today's work updates the mainline.
3. Write a compact daily report or experiment card.
4. Add one viewpoint update: what became clearer, and what is still weak or attackable.
5. Update `CURRENT.md` / `claim_board.md` only when evidence changes them.
6. Commit the research-system update.

Daily reports should be placed at `daily_research_reports/MMDD/daily_report.md`. Use `daily_research_reports/_templates/daily_log_template.md`.
