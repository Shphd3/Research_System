# Meeting Brief Template

组会简报只负责回答当前最重要的问题，不复制实验报告。默认不超过两页；中文
正文建议控制在 1,200--1,800 字，来源索引不计入。详细设置、完整表格、图和失败
记录统一链接到 `summary.md` 或 `detailed.md`。

固定阅读顺序：

```text
执行摘要 -> 必须回答的问题 -> 最小模型与确切数据 -> 逐题回答
-> 一个下一决策 -> 来源索引
```

标题直接写研究问题，不加“会议简报”前缀。正式文件放在：

```text
daily_research_reports/MMDD/meetings/<topic>_meeting_brief.md
daily_research_reports/MMDD/meetings/<topic>_meeting_brief_cn.md
```

## 完成前检查

1. 执行摘要读完后，能否说明本次更新、当前结论、边界和下一步？
2. 是否只回答两到三个问题？
3. 问题是否先于数学模型和数据？
4. 合成数据是否给出一条可手算实例、输入、中间变量和输出？
5. 是否只保留最多两个公式，并定义全部符号？
6. 是否删除实验流水账、项目代号和未解释英文缩写？
7. 是否只有一个下一决策，并同时写出通过和停止条件？
8. 详细证据是否链接到现有 `summary.md`/`detailed.md`，而不是复制进简报？
9. 所有链接和可选图片是否存在？
