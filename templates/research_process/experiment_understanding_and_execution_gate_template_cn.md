# 最小实验思考卡

使用顺序：`AI解释 -> 我闭卷复述 -> AI判断能否执行 -> 我总结结果`。

## 卡1：让 AI 解释实验

**用途：**快速看懂实验为什么能改变判断。

```text
请只回答：
1. 要区分哪两个解释？
2. treatment/control 各举一个具体例子。
3. 唯一改变什么；必须保持什么？
4. 测量哪个对象，唯一主指标是什么？
5. 支持、反对、证据不足分别是什么？
6. 即使通过，仍不能说什么？

材料：[路径或内容]
```

## 卡2：我闭卷复述

**用途：**确认这是我的理解，不是“AI 看起来合理”。

```text
真正问题：
主解释 / 最强替代解释：
唯一改变 / 必须保持：
测量对象 / 主指标：
三种结果及含义：
不能声称：
下一决策：
最不确定处：
```

## 卡3：执行判断

**用途：**决定 full run、smoke、继续审核或暂停。

```text
请对照我的复述与 approved Protocol，只检查：
- 问题、对照、主指标是否一致；
- 控制是否排除最强替代解释；
- Pass / Fail / Insufficient 是否冻结；
- Protocol、实现、smoke、full run 的授权范围。

只指出一个阻塞点，并返回：
判定：EXECUTE_FULL_RUN / SMOKE_ONLY / CONTINUE_AUDIT / PARK
理由：最多3句
唯一阻塞点：
下一步唯一动作：

我的复述：[粘贴卡2]
Protocol：[路径]
```

## 卡4：结果与组会

**用途：**把结果转成我能亲自讲的认识更新。

```text
问题：
关键比较：
主指标及结果：
因此我认为：
仍然不能说：
与学长或前项工作的联系：
希望导师裁定：
下一步唯一动作：
```

交给 AI 核对时：

```text
只核对数字、证据边界和逻辑顺序，不扩写新结论。
返回：READY / NEEDS_ONE_REWRITE / INSUFFICIENT
必须修改的一句话：
导师最可能追问：
```

原则：我能闭卷讲清问题、对照、主指标、结果和边界，才执行 full run。
