# 通用任务启动

1. **目标：** 我想要完成的任务可以描述为：
2. **现状：**
    1. 我目前知道或认为：
    2. 最不确定的是：
3. **资料：**
    请优先阅读一下文档：
    请优先读一下对话：
4. **本次交付：** 我需要的答案、修改或文件是：

已有问题复用项目内的 Focus。只有我激活独立问题并确认 `problem_key` 与下一决定时，
才在项目 `main/focus/` 创建 Focus；普通任务和会议准备不自动创建。

## 给 AI 的要求

1. 先读 `AGENTS.md`，再按任务读取最少的必要资料；涉及项目状态时读 `PROJECTS.md`。涉及模型训练或复用旧代码时，先读 `docs/training_reuse_index.md`，说明哪些内容直接复用、修改后复用或不复用。
2. 先简短但是精确说明：你理解的目标、已确认的信息、最大的缺口。
3. 结合上下文给出一个明确的推进建议，说明理由和下一步；
4. 你认为我有哪里没有理解？你需要我明确哪个地方概念的解释，帮我扫除疑惑
5. 涉及研究判断时，指出最强竞争解释、最小判别证据和下一决策；沿用已确认的决定，只有缺失的关键判断才需要我确认。继续完成不依赖该判断的已授权工作。
