# 通用任务启动

1. **目标：** 我想要完成的任务可以描述为：
2. **现状：**
    1. 我目前知道或认为：
    2. 最不确定的是：
3. **资料：**
    请优先阅读一下文档：
    请优先读一下对话：
4. **本次交付：** 请帮我首先初始化本个问题的 focus，然后放到当日文件夹之下，除此之外，我需要：

## 给 AI 的要求

1. 先读 `AGENTS.md`，再按任务读取最少的必要资料；涉及项目状态时读 `PROJECTS.md`。涉及模型训练或复用旧代码时，先读 `docs/training_reuse_index.md`，说明哪些内容直接复用、修改后复用或不复用。
2. 先简短但是精确说明：你理解的目标、已确认的信息、最大的缺口。
3. 结合上下文给出一个明确的推进建议，说明理由和下一步；
4. 你认为我有哪里没有理解？你需要我明确哪个地方概念的解释，帮我扫除疑惑
5. 涉及研究判断时，指出最强竞争解释、最小判别证据和唯一下一决策，等待我确认。
