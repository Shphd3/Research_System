# Daily Logs

Use this folder only for new lightweight daily logs if a daily note does not belong in `daily_research_reports/`.

Existing historical reports remain in `daily_research_reports/`.

## Required Daily Viewpoint Update

Every daily log or daily research report should include one short viewpoint update. This is the part that trains research thinking.

Use this compact shape:

```markdown
## Viewpoint Update / Self-Audit

Updated view:

Why this view changed or became clearer:

Weakest / most attackable part:

How I will make it more rigorous:
```

Rules:

- The updated view must be a research judgment, not a mood or task summary.
- The weak point should name a real vulnerability: unsupported assumption, ambiguous concept, missing control, counterexample, or over-strong wording.
- If nothing changed, write `No viewpoint update today` and explain whether the day only added background, implementation progress, or raw material.
